# [インデックス 2458] ファイルの概要

このコミットは、Go言語の公式フォーマッタである `gofmt` ツールを、初期の実験的な場所 (`usr/gri/pretty`) から、Goコマンドの標準的な配置場所である `src/cmd/gofmt` へ移動させることを主目的としています。これに伴い、`gofmt` のビルドとテストに必要な `Makefile` の新規作成、テストスクリプトの更新、そしてプロジェクト全体のビルドスクリプト (`src/make.bash` と `src/run.bash`) の修正が行われました。また、`usr/gri/pretty` ディレクトリから `godoc` に関連する複数のファイルが削除されており、これは `godoc` ツールの再編成または別の場所への移動を示唆しています。

## 変更の背景

このコミットは、Go言語プロジェクトの初期段階におけるコードベースの整理と標準化の一環として行われました。当時のGoプロジェクトはまだ開発途上にあり、ツールの配置やディレクトリ構造が確立されていませんでした。

`gofmt` はGo言語のコードを自動的にフォーマットするツールであり、Goコミュニティ全体で一貫したコーディングスタイルを強制するために不可欠な存在です。初期には `usr/gri/pretty` のような個人ユーザーの作業ディレクトリに置かれていましたが、その重要性から公式のコマンドとして `src/cmd` ディレクトリに昇格させる必要がありました。これにより、`gofmt` はGoツールチェーンの一部として認識され、ビルドシステムによって適切に管理されるようになります。

また、`godoc` に関連するファイルの削除は、`godoc` ツール自体が別の場所へ移動したか、あるいはその実装が大幅に再構築されたことを示唆しています。`godoc` もまた、Goのパッケージドキュメントを生成・表示するための重要なツールであり、`gofmt` と同様にプロジェクトの標準的な構造に統合される必要がありました。

これらの変更は、Go言語のツールエコシステムが成熟し、より組織化された形で提供されるための基盤を築くものでした。

## 前提知識の解説

*   **`gofmt`**: Go言語のソースコードを自動的にフォーマットするツールです。Goのコードベース全体で一貫したスタイルを維持するために広く利用されており、Goプログラミングのベストプラクティスの一部と見なされています。インデント、スペース、改行などをGoの公式スタイルガイドに従って整形します。
*   **`godoc`**: Go言語のソースコードからドキュメントを抽出し、HTML形式で表示したり、コマンドラインで参照したりするためのツールです。Goのパッケージや関数のコメントから自動的にドキュメントを生成し、開発者がコードの利用方法を理解するのに役立ちます。
*   **Goプロジェクトのディレクトリ構造 (初期)**:
    *   `src/`: Goの標準ライブラリ、ツール、およびユーザーが作成するGoパッケージのソースコードが配置される主要なディレクトリです。
    *   `src/cmd/`: Goの公式コマンド（例: `go build`, `go run`, `gofmt` など）のソースコードが配置される場所です。ここに置かれることで、それらのツールがGoのビルドシステムによって公式に管理・ビルドされることを意味します。
    *   `usr/`: 初期Goプロジェクトでは、開発者の個人作業スペースや実験的なコードが置かれることがありました。`usr/gri/pretty` は、Robert Griesemer氏 (gri) の作業ディレクトリで、`gofmt` や `godoc` の初期バージョンが開発されていた場所と考えられます。
*   **`Makefile`**: `make` ユーティリティが使用する設定ファイルで、ソフトウェアのビルドプロセスを自動化するために使われます。依存関係を定義し、ソースコードのコンパイル、リンク、テストなどのコマンドを記述します。
*   **`bash` スクリプト (`make.bash`, `run.bash`)**: Goプロジェクトのビルドやテストの実行を自動化するためのシェルスクリプトです。`make.bash` は主要なGoツールやライブラリのビルドを調整し、`run.bash` はテストの実行など、より高レベルな操作を管理します。

## 技術的詳細

このコミットの技術的な変更は、主にファイルの移動、新規ファイルの追加、および既存のビルド・実行スクリプトの更新に集約されます。

1.  **`gofmt` の移動と `Makefile` の追加**:
    *   `usr/gri/pretty/gofmt.go` が `src/cmd/gofmt/gofmt.go` へ移動しました。`similarity index 100%` が示す通り、ファイル内容は変更されずに場所だけが移動しています。
    *   `usr/gri/pretty/test.sh` が `src/cmd/gofmt/test.sh` へ移動しました。`similarity index 97%` は、ファイル内容にごくわずかな変更があったことを示唆しています（実際には `#!/bin/bash` の位置の変更など）。
    *   `src/cmd/gofmt/Makefile` が新規作成されました。この `Makefile` は `gofmt` コマンドをビルドするためのルールを定義しています。具体的には、`gofmt.go` をコンパイルして `gofmt` という実行可能ファイルを生成し、テスト (`test.sh`) やスモークテスト (`smoketest`) を実行するターゲット、そしてクリーンアップ (`clean`) やインストール (`install`) のルールが含まれています。インストールルールでは、ビルドされた `gofmt` を `$HOME/bin` にコピーするようになっています。

2.  **`godoc` 関連ファイルの削除**:
    *   `usr/gri/pretty/godoc.go`
    *   `usr/gri/pretty/package.html`
    *   `usr/gri/pretty/package.txt`
    *   `usr/gri/pretty/parseerror.html`
    *   `usr/gri/pretty/parseerror.txt`
    これらのファイルが `usr/gri/pretty` ディレクトリから完全に削除されました。これは、`godoc` ツールの実装がこの場所から完全に撤去されたことを意味します。この時点では、`godoc` がどこに移動したのか、あるいはどのように再実装されたのかは、このコミットからは直接読み取れませんが、Goプロジェクト全体でのツールの再編の一部であることは明らかです。

3.  **ビルドスクリプトの更新**:
    *   `src/make.bash`: このスクリプトは、Goプロジェクトの様々なコンポーネントをビルドする役割を担っています。変更前は `cmd/gobuild` や `cmd/godoc` などがビルド対象としてリストされていましたが、このコミットで `cmd/gofmt` がそのリストに追加されました。これにより、`gofmt` がGoプロジェクトの標準ビルドプロセスの一部として扱われるようになりました。
    *   `src/run.bash`: このスクリプトは、ビルド後のテスト実行などを担当しています。変更前は `usr/gri/pretty` ディレクトリに `cd` して `gofmt` のテストを実行していましたが、このコミットにより `cmd/gofmt` ディレクトリに `cd` するようにパスが修正されました。また、`godoc` のコピーに関するコメントアウトされた行 (`cp godoc $HOME/bin`) が削除されており、`godoc` の管理方法が変更されたことを裏付けています。

これらの変更は、Goのツールチェーンがよりモジュール化され、各ツールが自身のディレクトリ内で独立してビルド・テストされるような構造へと移行していることを示しています。

## コアとなるコードの解説

### `src/cmd/gofmt/Makefile` (新規追加)

```makefile
# Copyright 2009 The Go Authors. All rights reserved.
# Use of this source code is governed by a BSD-style
# license that can be found in the LICENSE file.

include $(GOROOT)/src/Make.$(GOARCH)

TARG=gofmt
OFILES=\
	gofmt.$O\

$(TARG): $(OFILES)
	$(LD) -o $(TARG) $(OFILES)

test: $(TARG)
	./test.sh

smoketest: $(TARG)
	./test.sh $(GOROOT)/src/pkg/go/parser/parser.go

clean:
	rm -f $(OFILES) $(TARG)

install: $(TARG)
	cp $(TARG) $(HOME)/bin/$(TARG)

%.$O:	%.go
	$(GC) $<
```
この `Makefile` は、`gofmt` コマンドをビルドするための標準的なGoプロジェクトの `Makefile` の構造に従っています。
*   `include $(GOROOT)/src/Make.$(GOARCH)`: Goのビルド環境変数（コンパイラ `GC`、リンカ `LD` など）を読み込みます。
*   `TARG=gofmt`: 最終的に生成される実行可能ファイルの名前を `gofmt` と定義します。
*   `OFILES=gofmt.$O`: オブジェクトファイルとして `gofmt.go` から生成される `gofmt.$O` を指定します。
*   `$(TARG): $(OFILES)`: `gofmt` 実行可能ファイルをビルドするためのルール。オブジェクトファイルをリンクして実行可能ファイルを生成します。
*   `test`: `test.sh` スクリプトを実行してテストを行います。
*   `smoketest`: `test.sh` に特定のGoソースファイル (`$(GOROOT)/src/pkg/go/parser/parser.go`) を引数として渡し、より広範なテスト（スモークテスト）を実行します。
*   `clean`: ビルドによって生成された中間ファイル (`.O` ファイル) と実行可能ファイルを削除します。
*   `install`: ビルドされた `gofmt` 実行可能ファイルを `$HOME/bin` にコピーし、ユーザーのパスからアクセスできるようにします。
*   `%.$O: %.go`: `.go` ファイルから対応するオブジェクトファイル (`.O` ファイル) をコンパイルするための汎用ルールです。
