## 前提知識の解説

### Go言語の`flag`パッケージ

`flag`パッケージは、Go言語の標準ライブラリの一つで、コマンドライン引数（フラグ）を解析するための機能を提供します。Goアプリケーションを開発する際、ユーザーがコマンドラインから設定やオプションを指定できるようにするために広く利用されます。

**主な機能と概念:**

1.  **フラグの定義**:
    *   `flag.String()`, `flag.Bool()`, `flag.Int()`などの関数を使用して、文字列、真偽値、整数などの型のフラグを定義します。これらの関数は、フラグ名、デフォルト値、およびヘルプメッセージを引数として受け取ります。
    *   例: `var ip *int = flag.Int("flagname", 1234, "help message for flagname")`
    *   定義されたフラグはポインタとして返され、そのポインタを介してフラグの値にアクセスします。
    *   既存の変数にフラグの値をバインドすることも可能です。`flag.StringVar()`, `flag.BoolVar()`, `flag.IntVar()`などの関数を使用します。
    *   例: `flag.IntVar(&flagvar, "flagname", 1234, "help message for flagname")`

2.  **フラグの解析**:
    *   すべてのフラグを定義した後、`flag.Parse()`関数を呼び出す必要があります。この関数は、コマンドライン引数を読み込み、定義されたフラグの値を解析し、対応する変数に格納します。

3.  **非フラグ引数へのアクセス**:
    *   `flag.Parse()`の実行後、フラグではない残りのコマンドライン引数は、`flag.Args()`関数によって文字列のスライスとして取得できます。個々の引数は`flag.Arg(i)`でアクセスできます。

4.  **コマンドラインフラグの構文**:
    *   フラグは通常、`-flag`、`-flag=x`、`-flag x`のような形式で指定されます。
    *   単一または二重のハイフン（`-`または`--`）を使用できます。
    *   フラグの解析は、最初の非フラグ引数（例: `-`）またはターミネータ`--`の直前で停止します。
    *   整数フラグは10進数、8進数（`0`プレフィックス）、16進数（`0x`プレフィックス）をサポートし、負の値も可能です。
    *   真偽値フラグは`1`, `0`, `t`, `f`, `true`, `false`, `TRUE`, `FALSE`, `True`, `False`などの値を認識します。

5.  **カスタムフラグ型**:
    *   より複雑なシナリオでは、`flag.Value`インターフェースを実装することで、カスタムのフラグ型を定義できます。これにより、特定の検証ロジックやカスタムデータ構造への解析が可能になります。

6.  **`FlagSet`**:
    *   `flag`パッケージは、独立した`FlagSet`オブジェクトの作成もサポートしています。これは、サブコマンドを持つコマンドラインアプリケーションを実装する際に特に有用で、各サブコマンドが独自のフラグセットを持つことができます。

7.  **使用方法の表示**:
    *   `flag.Usage`変数をカスタマイズすることで、アプリケーションのカスタム使用メッセージを提供できます。これは、フラグ解析中にエラーが発生した場合や、`-help`または`-h`フラグが呼び出された場合に表示されます。
