## 変更の背景

Go言語の開発プロセスにおいて、`api/next.txt` ファイルは、次のメジャーリリースまたはマイナーリリースで導入される予定の新しい公開API（関数、メソッド、型、定数など）を追跡するために使用されます。Goは厳格なAPI互換性ポリシーを持っており、一度リリースされたAPIは原則として変更または削除されません。そのため、新しいAPIが追加される際には、その変更がコミュニティに明確に伝わるように、このファイルに記録されます。

このコミットは、開発中のGoのバージョン（おそらくGo 1.6またはそれ以降）で導入される予定の様々な新機能や改善に伴うAPIの追加を反映するために行われました。これにより、Goの標準ライブラリが進化し、より多くのユースケースに対応できるようになります。

## 前提知識の解説

### GoのAPI互換性ポリシー

Go言語は「Go 1 Compatibility Promise」という厳格な互換性ポリシーを掲げています。これは、Go 1でリリースされた公開APIは、将来のGo 1.xリリースにおいても互換性が維持されることを保証するものです。これにより、Goユーザーは安心してコードをアップグレードでき、既存のコードが壊れる心配が少なくなります。`api/next.txt` のようなファイルは、このポリシーを維持しつつ、新しいAPIを導入するための透明なプロセスの一部です。

### `api/next.txt` とは

`api/next.txt` は、Goの標準ライブラリに追加される予定の新しい公開APIのシグネチャを一覧表示するテキストファイルです。Goのリリースサイクルにおいて、新しいAPIが提案され、レビューされ、承認されると、このファイルに追加されます。これにより、開発者は次のリリースでどのようなAPIが利用可能になるかを事前に確認できます。このファイルは、APIの変更履歴を追跡し、互換性チェックを行うための重要なツールでもあります。

### 関連するGoパッケージの概要

このコミットで言及されている主なパッケージとその役割は以下の通りです。

*   **`bufio`**: バッファリングされたI/O操作を提供し、効率的な読み書きを可能にします。
*   **`debug/dwarf`**: DWARFデバッグ情報へのアクセスを提供します。
*   **`html/template` および `text/template`**: HTMLおよびプレーンテキストのテンプレート処理を提供します。
*   **`image` および `image/color`**: 画像の表現と操作、および色のモデルを扱います。
*   **`math/big`**: 任意精度の整数および浮動小数点数演算を提供します。
*   **`math/rand`**: 擬似乱数生成機能を提供します。
*   **`net` および `net/http`**: ネットワークI/OとHTTPプロトコルを扱います。
*   **`net/url`**: URLの解析と構築を扱います。
*   **`strconv`**: 基本データ型と文字列間の変換を扱います。

## 技術的詳細

このコミットで追加されたAPIは多岐にわたりますが、いくつか注目すべき変更点を詳細に解説します。

### `image` および `image/color` パッケージの `NYCbCrA` 型

*   **`image.NewNYCbCrA`**: 新しい `NYCbCrA` 画像を作成する関数。
*   **`image.NYCbCrA` 型**: YCbCrAカラーモデルの画像を表現する構造体。
*   **`image/color.NYCbCrA` 型**: YCbCrAカラーモデルの単一の色を表現する構造体。
*   **`image/color.NYCbCrAModel`**: `NYCbCrA` カラーモデル。

**NYCbCrAカラーモデルとは？**
YCbCrは、輝度（Y）と2つの色差成分（CbとCr）で色を表現するカラーモデルです。人間の目は輝度情報に敏感であるため、YCbCrは画像や動画の圧縮によく利用されます（例: JPEG、MPEG）。`NYCbCrA` は、これにアルファ（A）チャネル（透明度）を追加したものです。これにより、透明度を持つYCbCr画像を効率的に扱うことが可能になります。これは、特にWebPなどの画像フォーマットや、動画処理において有用です。

### `net/http` パッケージの新しいHTTPステータスコード

*   **`StatusPreconditionRequired` (428)**: RFC 6585で定義されたステータスコード。リクエストが条件付きであることを示すヘッダー（例: `If-Match`）を要求する場合に使用されます。
*   **`StatusTooManyRequests` (429)**: RFC 6585で定義されたステータスコード。ユーザーが指定された時間内にあまりにも多くのリクエストを送信した場合（レート制限）に返されます。
*   **`StatusRequestHeaderFieldsTooLarge` (431)**: RFC 6585で定義されたステータスコード。サーバーが処理できないほどリクエストヘッダーフィールドが大きすぎる場合に返されます。
*   **`StatusNetworkAuthenticationRequired` (511)**: RFC 6585で定義されたステータスコード。ネットワークアクセスを得るために認証が必要であることを示します。通常、プロキシやキャプティブポータルで使用されます。

これらのステータスコードの追加により、GoのHTTPサーバーおよびクライアントは、より新しいRFCで定義された標準に準拠し、より詳細なエラーハンドリングとクライアントへの情報提供が可能になります。

### `math/big` パッケージのテキストマーシャリング

*   **`(*Float) MarshalText()` および `UnmarshalText()`**: `big.Float` 型の値をテキスト形式でエンコード/デコードするメソッド。
*   **`(*Int) Append()` および `Text()`**: `big.Int` 型の値をテキスト形式で操作するメソッド。

これらのメソッドは、任意精度の数値（`big.Int` や `big.Float`）を文字列として表現したり、文字列から復元したりする際に便利です。特に、設定ファイル、データ交換フォーマット（JSONなど）、またはデバッグ出力において、これらの大きな数値を人間が読める形式で扱う必要が生じた場合に役立ちます。

### `strconv` パッケージのグラフィック文字関連関数

*   **`AppendQuoteRuneToGraphic`**, **`AppendQuoteToGraphic`**: グラフィック文字のみを引用符で囲んでバイトスライスに追加します。
*   **`IsGraphic`**: 指定されたルーンがグラフィック文字であるかどうかを判定します。
*   **`QuoteRuneToGraphic`**, **`QuoteToGraphic`**: グラフィック文字のみを引用符で囲んだ文字列を返します。

これらの関数は、文字列を安全に表示したり、ログに出力したりする際に、非グラフィック文字（制御文字など）を適切にエスケープしつつ、グラフィック文字はそのまま表示したい場合に有用です。これにより、出力の可読性を向上させることができます。

### その他の注目すべき変更

*   **`bufio.Scanner.Buffer([]uint8, int)`**: `bufio.Scanner` が使用する内部バッファのサイズと初期バッファを設定できるようになります。これにより、特定のユースケース（非常に長い行をスキャンする場合など）でパフォーマンスを最適化できます。
*   **`math/rand.Read([]uint8)`**: `math/rand` パッケージにバイトスライスを乱数で埋める `Read` メソッドが追加されました。これは `io.Reader` インターフェースを満たし、乱数ストリームが必要な場面で利用できます。ただし、暗号学的に安全な乱数が必要な場合は `crypto/rand` パッケージを使用すべきです。
*   **`net.DNSError` および `net/url.Error` の `IsTemporary()` / `Temporary()` および `Timeout()` メソッド**: ネットワーク関連のエラーが一時的なものか、タイムアウトによるものかをプログラムで判断できるようになります。これにより、一時的なネットワークエラーに対してはリトライロジックを実装しやすくなります。

## コアとなるコードの変更箇所

このコミットにおけるコアとなるコードの変更は、`api/next.txt` ファイルへの53行の追加です。具体的な変更内容は、各行が `pkg <パッケージ名>, <要素の種類> <シグネチャ>` の形式で新しいAPI要素を記述している点です。

例:
*   `pkg bufio, method (*Scanner) Buffer([]uint8, int)`
*   `pkg image, type NYCbCrA struct`
*   `pkg net/http, const StatusTooManyRequests = 429`

これらの行は、Goの標準ライブラリのソースコード自体を変更するものではなく、あくまで将来のAPI変更を文書化するためのメタデータです。

## コアとなるコードの解説

`api/next.txt` に追加された各行は、Goの標準ライブラリの特定のパッケージに導入される新しい公開APIの「契約」を定義しています。これは、GoのツールチェーンがAPIの互換性をチェックする際に使用する情報源の一つです。

このファイルにエントリが追加されるということは、そのAPIがGoの次のリリースに含まれることがほぼ確定したことを意味します。開発者はこの情報を見て、新しい機能を利用したり、既存のコードを新しいAPIに合わせて調整したりする準備を始めることができます。

例えば、`pkg image, type NYCbCrA struct` の追加は、`image` パッケージがYCbCrAカラーモデルをネイティブにサポートするようになることを示唆しています。これにより、開発者はより効率的に透明度を持つYCbCr画像を扱えるようになります。同様に、`pkg net/http, const StatusTooManyRequests = 429` の追加は、HTTPクライアントやサーバーがレート制限エラーをより具体的に処理できるようになることを意味します。

これらの変更は、Go言語が継続的に進化し、現代のソフトウェア開発の要求に応えるために標準ライブラリを拡張していることを示しています。
