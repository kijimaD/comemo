## 元コミット内容

このコミットは `mime/quotedprintable` パッケージを作成します。これは `mime/internal/quotedprintable` にあった QP リーダーを移動し、エクスポートするものです。コードはコミット履歴を保持するため、ほとんど変更されていません。Issue #4943 を更新します。

## 変更の背景

Go言語の標準ライブラリでは、特定の機能が他のパッケージから直接利用されることを意図しない場合、その機能を `internal` ディレクトリ配下に配置することがあります。`mime/internal/quotedprintable` パッケージは、元々 `mime/multipart` パッケージの内部で Quoted-Printable エンコーディングされたデータをデコードするために使用されていました。

しかし、Quoted-Printable エンコーディングはMIME (Multipurpose Internet Mail Extensions) の一部として広く利用されており、電子メールやHTTPなど、様々なプロトコルでテキストデータを効率的に転送するために使われます。`mime/multipart` 以外の文脈でも Quoted-Printable デコーダーが必要となるケースが考えられます。

このコミットの背景には、`mime/internal/quotedprintable` に実装されていた Quoted-Printable リーダーを、より汎用的な目的で利用できるように公開したいという要望があったと考えられます。Issue #4943（具体的な内容は不明ですが、コミットメッセージから推測）が、この公開の必要性を示唆していたのでしょう。これにより、Go開発者は `mime/quotedprintable` パッケージをインポートするだけで、Quoted-Printable 形式のデータを簡単にデコードできるようになります。

## 前提知識の解説

### Quoted-Printable エンコーディング (RFC 2045)

Quoted-Printable (QP) は、MIMEで定義されているコンテンツ転送エンコーディングの一つです。主に、7ビットのASCII文字しか扱えない環境で、8ビットの非ASCII文字（日本語の文字など）を含むテキストデータを安全に転送するために使用されます。

QPエンコーディングの主な特徴は以下の通りです。
*   **可読性**: ほとんどの文字はそのまま表示されるため、エンコードされたデータも比較的読みやすいです。
*   **エスケープシーケンス**: ASCII範囲外の文字や、QPエンコーディングで特別な意味を持つ文字（`=`、`?`、`_`など）は、`=XX` の形式で16進数にエスケープされます。例えば、`=` は `=3D` とエンコードされます。
*   **ソフト改行**: 長い行を分割するために、行末に `=` を付けて改行することができます。これはデコード時に結合されます。
*   **空白文字の扱い**: 行末の空白文字は、デコード時に失われる可能性があるため、`=20` や `=09` のようにエスケープされることがあります。

### Go言語のパッケージと `internal` ディレクトリ

Go言語では、コードはパッケージに分割され、再利用可能なモジュールとして機能します。パッケージはディレクトリ構造によって定義されます。

`internal` ディレクトリはGoモジュールにおける特別なディレクトリです。`internal` ディレクトリ内のパッケージは、その `internal` ディレクトリを含むモジュール内からのみインポートできます。つまり、`internal` パッケージは、そのモジュール外の他のモジュールからはインポートできません。

この仕組みは、ライブラリの作者が特定の機能をモジュール内部でのみ使用し、外部に公開したくない場合に利用されます。これにより、APIの安定性を保ちつつ、内部実装の自由度を確保できます。

今回のコミットでは、`mime/internal/quotedprintable` にあった Quoted-Printable リーダーが `internal` ディレクトリから外に出され、`mime/quotedprintable` という独立したパッケージとして公開されました。これは、その機能がもはや `mime` モジュール内部に限定されるべきではなく、より広範な利用が期待されるようになったことを意味します。

func NewReader(r io.Reader) io.Reader {
	return &reader{
		br: bufio.NewReader(r),
	}
}

// fromHex converts a hex character to its byte value.
func fromHex(b byte) (byte, error) {
	switch {
	case b >= '0' && b <= '9':
		return b - '0', nil
	case b >= 'a' && b <= 'f':
		return b - 'a' + 10, nil
	case b >= 'A' && b <= 'F':
		return b - 'A' + 10, nil
	}
	return 0, fmt.Errorf("quotedprintable: invalid hex byte 0x%02x", b)
}

// readHexByte reads two hex characters and converts them to a single byte.
func (q *reader) readHexByte(v []byte) (b byte, err error) {
	if len(v) < 2 {
		return 0, io.ErrUnexpectedEOF
	}
	b1, err := fromHex(v[0])
	if err != nil {
		return 0, err
	}
	b2, err := fromHex(v[1])
	if err != nil {
		return 0, err
	}
	return b1<<4 | b2, nil
}
