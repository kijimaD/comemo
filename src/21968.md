# [インデックス 21968] ファイルの概要

このコミットは、Go言語の標準ライブラリである`image`および`image/color`パッケージにCMYK (Cyan, Magenta, Yellow, Key/Black) カラーモデルのサポートを追加するものです。これにより、GoプログラムでCMYK形式の画像を扱うための基本的な型と変換機能が提供されます。

## 元コミット内容

`image: add image.CMYK and color.CMYK types.`

このコミットは、Goの`image`パッケージに`image.CMYK`型を、`image/color`パッケージに`color.CMYK`型を追加します。

## 変更の背景

Goの`image`パッケージは、様々な画像フォーマットを扱うための基本的なインターフェースと実装を提供しています。これまでのバージョンでは、主にRGB (Red, Green, Blue) やRGBA (Red, Green, Blue, Alpha)、Gray (グレースケール) などのカラーモデルがサポートされていました。しかし、印刷業界や特定の画像処理アプリケーションでは、CMYKカラーモデルが広く使用されています。

CMYKは減法混色モデルであり、インクの混合によって色を表現します。これは、光の三原色であるRGBの加法混色モデルとは根本的に異なります。CMYKのサポートがない場合、GoでCMYK画像を直接処理したり、CMYK形式で画像を生成したりすることが困難でした。このコミットは、このようなニーズに応えるために、CMYKカラーモデルの基本的なサポートをGoの標準ライブラリに追加することを目的としています。これにより、Go言語が画像処理の分野でより幅広い用途に対応できるようになります。

## 前提知識の解説

### カラーモデル

*   **RGB (Red, Green, Blue)**: 光の三原色に基づいた加法混色モデル。ディスプレイやデジタルカメラなど、光を発するデバイスで広く使われます。各成分は0から255（または0から1）の範囲で表現され、すべてが0だと黒、すべてが最大だと白になります。
*   **CMYK (Cyan, Magenta, Yellow, Key/Black)**: 色の三原色（シアン、マゼンタ、イエロー）とキープレート（ブラック）に基づいた減法混色モデル。印刷物で色を表現するために使われます。インクを混ぜるほど色が暗くなり、すべてが最大だと黒になります。K（Key）は純粋な黒を表現するために追加され、CMYの混合では表現しにくい深い黒や、文字などのシャープな表現に適しています。

### Go言語の`image`および`image/color`パッケージ

*   **`image.Image`インターフェース**: Go言語で画像を表現するための基本的なインターフェース。`Bounds()`, `ColorModel()`, `At(x, y int) color.Color`の3つのメソッドを持ちます。
*   **`image/color.Color`インターフェース**: 単一の色の値を表現するためのインターフェース。`RGBA()`メソッドを持ち、色をRGBA値として返します。
*   **`image/color.Model`インターフェース**: あるカラーモデルから別のカラーモデルへ色を変換するためのインターフェース。`Convert(c Color) Color`メソッドを持ちます。

### 色空間変換

異なるカラーモデル間で色を変換する際には、数学的な変換式が用いられます。RGBからCMYKへの変換、またはその逆の変換は、通常、非線形な計算を伴います。このコミットでは、単純な線形変換に近いアルゴリズムが採用されていますが、これは特定のプロファイルに依存しない汎用的な変換を提供するためと考えられます。

## 技術的詳細

このコミットは、主に以下の2つの新しい型と関連する関数・メソッドを導入しています。

1.  **`image/color.CMYK`型**:
    *   `C`, `M`, `Y`, `K`の4つの`uint8`フィールドを持つ構造体で、それぞれシアン、マゼンタ、イエロー、ブラックの成分を表します。各成分は0から255の範囲で、255が最大濃度を示します。
    *   `RGBA()`メソッドが実装されており、`CMYK`色をRGBA形式に変換して返します。これは`image.Color`インターフェースを満たすために必要です。
    *   `RGBToCMYK`関数: RGB値をCMYK値に変換します。
    *   `CMYKToRGB`関数: CMYK値をRGB値に変換します。
    *   `CMYKModel`変数と`cmykModel`関数: `image/color.Model`インターフェースを実装し、任意の`color.Color`を`color.CMYK`に変換するためのロジックを提供します。

2.  **`image.CMYK`型**:
    *   `image.Image`インターフェースを実装する具体的な画像型です。
    *   `Pix` (`[]uint8`): 画像のピクセルデータをCMYKの順序で保持するバイトスライス。
    *   `Stride` (`int`): 垂直方向に隣接するピクセル間のバイト数（行のバイト幅）。
    *   `Rect` (`image.Rectangle`): 画像の境界（矩形領域）。
    *   `ColorModel()`: `color.CMYKModel`を返します。
    *   `Bounds()`: 画像の境界を返します。
    *   `At(x, y int)`: 指定された座標のピクセル色を`color.Color`インターフェースとして返します。
    *   `CMYKAt(x, y int)`: 指定された座標のピクセル色を`color.CMYK`型として返します。
    *   `PixOffset(x, y int)`: 指定された座標のピクセルが`Pix`スライス内で始まるインデックスを計算します。
    *   `Set(x, y int, c color.Color)`: 指定された座標のピクセル色を`color.Color`インターフェースで設定します。
    *   `SetCMYK(x, y int, c color.CMYK)`: 指定された座標のピクセル色を`color.CMYK`型で設定します。
    *   `SubImage(r image.Rectangle)`: 指定された矩形領域のサブイメージを返します。
    *   `Opaque()`: 画像が完全に不透明であるかどうかを報告します（CMYKは通常不透明なので常に`true`を返します）。
    *   `NewCMYK(r image.Rectangle)`: 指定された境界を持つ新しい`image.CMYK`画像を生成します。

これらの追加により、Goの画像処理ライブラリはCMYK画像をネイティブにサポートし、RGBとの相互変換も可能になります。

## コアとなるコードの変更箇所

### `src/image/color/ycbcr.go`

```go
// RGBToCMYK converts an RGB triple to a CMYK quadruple.
func RGBToCMYK(r, g, b uint8) (uint8, uint8, uint8, uint8) {
	rr := uint32(r)
	gg := uint32(g)
	bb := uint32(b)
	w := rr
	if w < gg {
		w = gg
	}
	if w < bb {
		w = bb
	}
	if w == 0 {
		return 0, 0, 0, 255
	}
	c := (w - rr) * 255 / w
	m := (w - gg) * 255 / w
	y := (w - bb) * 255 / w
	return uint8(c), uint8(m), uint8(y), uint8(255 - w)
}

// CMYKToRGB converts a CMYK quadruple to an RGB triple.
func CMYKToRGB(c, m, y, k uint8) (uint8, uint8, uint8) {
	w := uint32(255 - k)
	r := uint32(255-c) * w / 255
	g := uint32(255-m) * w / 255
	b := uint32(255-y) * w / 255
	return uint8(r), uint8(g), uint8(b)
}

// CMYK represents a fully opaque CMYK color, having 8 bits for each of cyan,
// magenta, yellow and black.
//
// It is not associated with any particular color profile.
type CMYK struct {
	C, M, Y, K uint8
}

func (c CMYK) RGBA() (uint32, uint32, uint32, uint32) {
	r, g, b := CMYKToRGB(c.C, c.M, c.Y, c.K)
	return uint32(r) * 0x101, uint32(g) * 0x101, uint32(b) * 0x101, 0xffff
}

// CMYKModel is the Model for CMYK colors.
var CMYKModel Model = ModelFunc(cmykModel)

func cmykModel(c Color) Color {
	if _, ok := c.(CMYK); ok {
		return c
	}
	r, g, b, _ := c.RGBA()
	cc, mm, yy, kk := RGBToCMYK(uint8(r>>8), uint8(g>>8), uint8(b>>8))
	return CMYK{cc, mm, yy, kk}
}
```

### `src/image/image.go`

```go
// CMYK is an in-memory image whose At method returns color.CMYK values.
type CMYK struct {
	// Pix holds the image's pixels, in C, M, Y, K order. The pixel at
	// (x, y) starts at Pix[(y-Rect.Min.Y)*Stride + (x-Rect.Min.X)*4].
	Pix []uint8
	// Stride is the Pix stride (in bytes) between vertically adjacent pixels.
	Stride int
	// Rect is the image's bounds.
	Rect Rectangle
}

func (p *CMYK) ColorModel() color.Model { return color.CMYKModel }

func (p *CMYK) Bounds() Rectangle { return p.Rect }

func (p *CMYK) At(x, y int) color.Color {
	return p.CMYKAt(x, y)
}

func (p *CMYK) CMYKAt(x, y int) color.CMYK {
	if !(Point{x, y}.In(p.Rect)) {
		return color.CMYK{}
	}
	i := p.PixOffset(x, y)
	return color.CMYK{p.Pix[i+0], p.Pix[i+1], p.Pix[i+2], p.Pix[i+3]}
}

// PixOffset returns the index of the first element of Pix that corresponds to
// the pixel at (x, y).
func (p *CMYK) PixOffset(x, y int) int {
	return (y-p.Rect.Min.Y)*p.Stride + (x-p.Rect.Min.X)*4
}

func (p *CMYK) Set(x, y int, c color.Color) {
	if !(Point{x, y}.In(p.Rect)) {
		return
	}
	i := p.PixOffset(x, y)
	c1 := color.CMYKModel.Convert(c).(color.CMYK)
	p.Pix[i+0] = c1.C
	p.Pix[i+1] = c1.M
	p.Pix[i+2] = c1.Y
	p.Pix[i+3] = c1.K
}

func (p *CMYK) SetCMYK(x, y int, c color.CMYK) {
	if !(Point{x, y}.In(p.Rect)) {
		return
	}
	i := p.PixOffset(x, y)
	p.Pix[i+0] = c.C
	p.Pix[i+1] = c.M
	p.Pix[i+2] = c.Y
	p.Pix[i+3] = c.K
}

// SubImage returns an image representing the portion of the image p visible
// through r. The returned value shares pixels with the original image.
func (p *CMYK) SubImage(r Rectangle) Image {
	r = r.Intersect(p.Rect)
	// If r1 and r2 are Rectangles, r1.Intersect(r2) is not guaranteed to be inside
	// either r1 or r2 if the intersection is empty. Without explicitly checking for
	// this, the Pix[i:] expression below can panic.
	if r.Empty() {
		return &CMYK{}
	}
	i := p.PixOffset(r.Min.X, r.Min.Y)
	return &CMYK{
		Pix:    p.Pix[i:],
		Stride: p.Stride,
		Rect:   r,
	}
}

// Opaque scans the entire image and reports whether it is fully opaque.
func (p *CMYK) Opaque() bool {
	return true
}

// NewCMYK returns a new CMYK with the given bounds.
func NewCMYK(r Rectangle) *CMYK {
	w, h := r.Dx(), r.Dy()
	buf := make([]uint8, 4*w*h)
	return &CMYK{buf, 4 * w, r}
}
```

## コアとなるコードの解説

### `image/color/ycbcr.go`の変更点

*   **`RGBToCMYK`関数**:
    *   この関数は、RGB (Red, Green, Blue) の各8ビット値をCMYK (Cyan, Magenta, Yellow, Key/Black) の各8ビット値に変換します。
    *   変換ロジックは、まずRGB値から最も明るい成分（`w`、白の度合い）を特定します。
    *   CMY成分は、`w`から各RGB成分を引いた値を`w`で割ることで計算されます。これにより、RGBの補色としてのCMYが導出されます。
    *   K（ブラック）成分は、`255 - w`として計算されます。これは、最も明るい成分が白（255）に近いほどKが0に近づき、暗いほどKが255に近づくことを意味します。
    *   `w == 0`（完全な黒）の場合、CMYは0、Kは255（純粋な黒）を返します。
    *   この変換は、特定のICCプロファイルに依存しない、一般的なRGBからCMYKへの変換アルゴリズムの一つです。

*   **`CMYKToRGB`関数**:
    *   CMYKの各8ビット値をRGBの各8ビット値に変換します。
    *   K成分から`w`（白の度合い）を計算し、これを用いてCMY成分をRGB成分に逆変換します。
    *   この変換もまた、特定のプロファイルに依存しない汎用的なものです。

*   **`CMYK`構造体**:
    *   `C`, `M`, `Y`, `K`の4つの`uint8`フィールドを持ち、それぞれシアン、マゼンタ、イエロー、ブラックの濃度を表します。
    *   `RGBA()`メソッドは、`CMYKToRGB`関数を使用してCMYK値をRGBに変換し、さらにGoの`color.Color`インターフェースが要求する`uint32`形式のRGBA値を返します。アルファ値は常に`0xffff`（完全不透明）と設定されています。

*   **`CMYKModel`と`cmykModel`**:
    *   `CMYKModel`は`image/color.Model`インターフェースを実装しており、任意の`color.Color`を`color.CMYK`型に変換する役割を担います。
    *   `cmykModel`関数は、入力された`Color`が既に`CMYK`型であればそのまま返し、そうでなければ`RGBA()`メソッドでRGB値を取得し、`RGBToCMYK`関数でCMYKに変換して新しい`CMYK`構造体を生成します。

### `src/image/image.go`の変更点

*   **`CMYK`構造体**:
    *   この構造体は、CMYKカラーモデルのピクセルデータを保持するインメモリ画像を表します。
    *   `Pix`は、CMYKの順序でピクセルデータを格納するバイトスライスです。各ピクセルは4バイト（C, M, Y, K）で構成されます。
    *   `Stride`は、画像の行ごとのバイト数を示します。
    *   `Rect`は、画像の論理的な境界を定義します。

*   **`image.Image`インターフェースの実装**:
    *   `ColorModel()`: この画像が`color.CMYKModel`を使用することを示します。
    *   `Bounds()`: 画像の境界矩形を返します。
    *   `At(x, y int)`: 指定された座標のピクセル色を`color.Color`インターフェースとして返します。内部的には`CMYKAt`を呼び出します。
    *   `CMYKAt(x, y int)`: 指定された座標のCMYKピクセル値を直接`color.CMYK`型で返します。`PixOffset`を使って`Pix`スライス内の正しい位置を計算します。
    *   `PixOffset(x, y int)`: 指定された(x, y)座標に対応するピクセルデータの開始インデックスを`Pix`スライス内で計算します。
    *   `Set(x, y int, c color.Color)`: 指定された座標のピクセル色を`color.Color`インターフェースで設定します。入力された`color.Color`を`color.CMYKModel`で変換し、そのCMYK値を`Pix`スライスに書き込みます。
    *   `SetCMYK(x, y int, c color.CMYK)`: 指定された座標のピクセル色を直接`color.CMYK`型で設定します。これは`Set`よりも効率的です。
    *   `SubImage(r Rectangle)`: 画像の一部を切り出して新しい`CMYK`画像を返します。元の画像とピクセルデータを共有するため、メモリ効率が良いです。
    *   `Opaque()`: CMYK画像は通常不透明であるため、常に`true`を返します。
    *   `NewCMYK(r Rectangle)`: 指定された境界を持つ新しい`CMYK`画像を生成し、そのピクセルデータのためのバイトスライスを割り当てます。

### `src/image/color/ycbcr_test.go`の変更点

*   **`TestCMYKRoundtrip`の追加**:
    *   このテストは、RGBからCMYKへの変換、そしてCMYKからRGBへの逆変換が正しく行われることを検証します。
    *   ランダムなRGB値の組み合わせを生成し、`RGBToCMYK`と`CMYKToRGB`を適用した後、元のRGB値と変換後のRGB値の差が許容範囲内（1/256の誤差）であることを確認します。これは、浮動小数点演算の丸め誤差を考慮した一般的なテスト手法です。
*   既存の`TestRoundtrip`関数が`TestYCbCrRoundtrip`にリネームされました。これは、CMYKテストの追加に伴い、テスト関数の命名規則をより明確にするための変更です。

これらの変更により、Goの`image`パッケージはCMYKカラーモデルをネイティブにサポートし、CMYK画像の読み込み、操作、保存（対応するエンコーダがあれば）が可能になります。
