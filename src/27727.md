## 変更の背景

Go言語の `go test` コマンドは、パッケージ内のテスト関数やベンチマーク関数を実行するための非常に強力なツールです。ユーザーは `-run` フラグを使用して、実行するテストを正規表現でフィルタリングできます。しかし、全てのテストを意図的にスキップしたい場合、どのような正規表現を使用すればよいのかがドキュメント上で明確ではありませんでした。

このコミットの背景には、ユーザーが特定の状況下でテストの実行を完全に抑制したいというニーズがあったと考えられます。例えば、CI/CDパイプラインにおいて特定のステージではテストを実行せず、別のステージで実行する場合や、開発中に特定のテストのみに集中したいが、他のテストが誤って実行されるのを防ぎたい場合などが挙げられます。

正規表現 `^$` は、文字列の先頭 (`^`) と末尾 (`$`) の間に何も文字がない、つまり空文字列にのみマッチするパターンです。テスト関数名が空文字列であることはありえないため、このパターンを使用することで確実に全てのテストをスキップできます。この挙動は正規表現の基本的な知識を持つ開発者にとっては自明かもしれませんが、Goのドキュメントとして明示することで、より多くのユーザーにとって `go test` の利用が容易になり、混乱を避けることができます。

また、同様に `-bench` フラグについても、全てのベンチマークを実行するためのパターン `.` が明記されていましたが、このコミットでは `-bench .` という形式が削除され、`-bench=.` の形式に統一されています。これは、フラグの引数指定の一貫性を高めるための微調整と考えられます。

## 前提知識の解説

### Go言語のテスト (`go test`)

Go言語には、標準ライブラリとしてテストフレームワークが組み込まれています。`go test` コマンドは、Goのソースコードディレクトリ内で実行され、`_test.go` で終わるファイル内のテスト関数（`TestXxx`）、ベンチマーク関数（`BenchmarkXxx`）、および例（`ExampleXxx`）を自動的に発見し、実行します。

### `go test -run` フラグ

`-run` フラグは、実行するテスト関数や例を正規表現パターンでフィルタリングするために使用されます。例えば、`go test -run "Foo"` は名前に "Foo" を含むテストのみを実行します。この正規表現は、テスト関数の完全な名前にマッチングを試みます。

### 正規表現 (`regexp`)

正規表現は、文字列のパターンを記述するための強力なツールです。Go言語の `regexp` パッケージは、RE2構文（Perl、Python、その他の言語で一般的に使用される正規表現のサブセット）をサポートしています。

*   **`^` (キャレット)**: 行または文字列の先頭にマッチします。
*   **`$` (ドル記号)**: 行または文字列の末尾にマッチします。

したがって、正規表現 `^$` は「文字列の先頭に始まり、直後に文字列の末尾が来る」というパターン、つまり空文字列にのみマッチします。テスト関数の名前は決して空文字列ではないため、このパターンはどのテスト関数名にもマッチしません。

### `go test -bench` フラグ

`-bench` フラグは、実行するベンチマーク関数を正規表現パターンでフィルタリングするために使用されます。`-run` と同様に、この正規表現はベンチマーク関数の完全な名前にマッチングを試みます。デフォルトではベンチマークは実行されません。全てのベンチマークを実行するには、通常 `.` (任意の1文字にマッチ) を使用した正規表現 `.` または `.` を指定します。

## 技術的詳細

このコミットは、Goコマンドのドキュメントを生成する `src/cmd/go/alldocs.go` と、`go test` コマンドのヘルプメッセージを定義する `src/cmd/go/test.go` の2つのファイルに変更を加えています。

変更の核心は、`go test -run` フラグの説明に「全てのテストをスキップするには、`-run=^$` のような、どのテスト名にもマッチしないパターンを使用してください」という文言を追加したことです。これにより、ユーザーはテストを完全に実行しない方法を明確に理解できるようになります。

また、`-bench` フラグの説明も微調整されています。以前は「To run all benchmarks, use '-bench .' or '-bench=.'」と記載されていましたが、このコミットにより「To run all benchmarks, use '-bench=.'」と変更され、`-bench .` の形式が削除されました。これは、フラグの引数指定において `=` を使用する形式に統一することで、一貫性と明確性を高める意図があると考えられます。

これらの変更は、Goのユーザーエクスペリエンスを向上させるための、細かではあるが重要なドキュメントの改善です。特に、正規表現に慣れていないユーザーにとっては、全てのテストをスキップする方法が明示されることで、より直感的に `go test` を操作できるようになります。
