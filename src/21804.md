# [インデックス 21804] ファイルの概要

このコミットは、Go言語の`math/big`パッケージにおける`Float`型の文字列フォーマット機能に、指数表記（`%e`, `%E`）、固定小数点表記（`%f`）、および一般表記（`%g`, `%G`）のサポートを追加するものです。これにより、`math/big.Float`型の値を、標準ライブラリの`strconv`パッケージが提供する浮動小数点数フォーマットと同様の形式で出力できるようになります。

## 変更の背景

Go言語の`math/big`パッケージは、任意精度（arbitrary-precision）の数値演算を提供します。これには、非常に大きな整数（`Int`）、有理数（`Rat`）、そして浮動小数点数（`Float`）が含まれます。コミット以前は、`Float`型の値を文字列として表現する際に、バイナリ形式（`%b`）や16進数形式（`%p`）のフォーマットは利用できましたが、一般的な科学技術計算や金融計算で広く用いられる10進数表記の`%e`, `%f`, `%g`フォーマットが欠けていました。

この欠如は、`math/big.Float`を使用して計算された結果を人間が読みやすい形式で表示する際に大きな制約となっていました。特に、標準の`float64`型では精度が足りないような計算結果を正確に表示するためには、これらの10進数フォーマットが不可欠でした。このコミットは、`math/big.Float`の利便性と実用性を向上させるために、これらの基本的なフォーマット機能を追加することを目的としています。

## 前提知識の解説

### `math/big`パッケージ

`math/big`パッケージは、Go言語の標準ライブラリの一部であり、任意精度の数値演算をサポートします。これは、標準の組み込み型（`int`, `float64`など）では表現できない、非常に大きな数値や高い精度が要求される計算を扱うために設計されています。
*   **`big.Float`**: 任意精度の浮動小数点数を表す型です。内部的には、符号、仮数部（mantissa）、指数部（exponent）で構成され、その精度は動的に調整可能です。

### 浮動小数点数の文字列フォーマット

浮動小数点数を文字列に変換する際には、いくつかの標準的なフォーマットが用いられます。これらは、`fmt`パッケージや`strconv`パッケージで提供されるものと同様です。
*   **`%e` (または `%E`)**: 科学技術表記（exponential notation）。例: `1.23456e+03`。数値が非常に大きい、または非常に小さい場合に用いられます。`%E`は指数部の`e`が大文字になります。
*   **`%f`**: 固定小数点表記（fixed-point notation）。例: `1234.567890`。小数点以下の桁数を指定できます。
*   **`%g` (または `%G`)**: 一般表記（general notation）。数値の大きさに応じて、`%e`と`%f`のどちらか適切な方を自動的に選択します。通常、小数点以下の不要なゼロは省略されます。`%G`は指数部の`e`が大文字になります。

### `strconv.FormatFloat`

Go言語の`strconv`パッケージには、`FormatFloat`という関数があり、`float64`型の値を指定されたフォーマットと精度で文字列に変換します。このコミットでは、`math/big.Float`のフォーマット実装が、`strconv.FormatFloat`の動作に倣うように設計されています。

## 技術的詳細

このコミットの主要な変更点は、`math/big.Float`型に`%e`, `%f`, `%g`, `%G`フォーマット機能を追加したことです。これは、主に`src/math/big/ftoa.go`という新しいファイルで実装されています。

実装のアルゴリズムは、以下の3つの主要なステップから構成されます。

1.  **`Float`から多倍長10進数への変換**:
    `big.Float`の内部表現（バイナリの仮数部と指数部）を、10進数の仮数部と指数部を持つ`decimal`構造体に変換します。この`decimal`構造体は、数値の各桁をバイトスライスとして保持し、10進数の指数部を持ちます。この変換は、`decimal.init(f.mant, int(f.exp)-f.mant.bitLen())`によって行われます。ここで`f.mant`は`big.Float`の仮数部、`f.exp`は指数部です。

2.  **指定された精度への丸め**:
    変換された10進数表現は、指定されたフォーマット（`%e`, `%f`, `%g`）と精度（`prec`）に基づいて丸められます。
    *   `%e`, `%E`フォーマットの場合: 小数点より前の1桁と、小数点以下の`prec`桁を考慮して丸められます。
    *   `%f`フォーマットの場合: 小数点より前の桁数と、小数点以下の`prec`桁を考慮して丸められます。
    *   `%g`, `%G`フォーマットの場合: `prec`は有効桁数を表します。`prec`が0の場合は1として扱われ、指定された有効桁数で丸められます。

    丸め処理は`d.round()`メソッドによって行われます。

3.  **桁の読み出しとフォーマット**:
    丸められた10進数表現から桁を読み出し、指定されたフォーマット規則に従って文字列を構築します。
    *   **`fmtE`関数**: `%e`, `%E`フォーマットを処理します。符号、最初の桁、小数点、小数点以下の桁、そして指数部（`e±dd`形式）を構築します。指数部は常に少なくとも2桁で表示されます（例: `e+00`, `e+01`）。
    *   **`fmtF`関数**: `%f`フォーマットを処理します。符号、整数部、小数点、そして小数点以下の桁を構築します。整数部が0の場合でも`0`が表示され、小数点以下の桁は`prec`で指定された数だけ表示されます。
    *   **`bigFtoa`関数**: `%g`, `%G`フォーマットのロジックを含みます。これは、数値の指数部と指定された精度に基づいて、`fmtE`または`fmtF`のどちらを使用するかを決定します。具体的には、指数が-4未満または精度以上の場合に`%e`形式が選択されます。

この実装は、Goの`strconv/ftoa.go`の対応する実装に密接に倣っていますが、`big.Float`の特性に合わせて修正および簡略化されています。

### `Float.Append` (src/math/big/floatconv.go)

```go
func (x *Float) Append(buf []byte, format byte, prec int) []byte {
	// pick off simple cases
	switch format {
	case 'b':
		return x.bstring(buf)
	case 'p':
		return x.pstring(buf)
	}
	return x.bigFtoa(buf, format, prec)
}
```
このメソッドは、`Float`型の値を指定されたフォーマットと精度でバイトスライス`buf`に追加し、拡張されたバイトスライスを返します。以前は`%b`と`%p`以外のフォーマットではエラーを返していましたが、この変更により、新しい`bigFtoa`関数を呼び出すことで`%e`, `%f`, `%g`, `%G`フォーマットを処理するようになりました。

### `bigFtoa` (src/math/big/ftoa.go)

```go
func (f *Float) bigFtoa(buf []byte, fmt byte, prec int) []byte {
	// TODO(gri) handle Inf. // 無限大の処理はまだ未実装
	// 1) convert Float to multiprecision decimal
	var d decimal
	d.init(f.mant, int(f.exp)-f.mant.bitLen())

	// 2) round to desired precision
	shortest := false
	if prec < 0 {
		shortest = true
		panic("unimplemented") // 短縮表記（最短表現）はまだ未実装
		// ...
	} else {
		// round appropriately
		switch fmt {
		case 'e', 'E':
			d.round(1 + prec)
		case 'f':
			d.round(d.exp + prec)
		case 'g', 'G':
			if prec == 0 {
				prec = 1
			}
			d.round(prec)
		}
	}

	// 3) read digits out and format
	switch fmt {
	case 'e', 'E':
		return fmtE(buf, fmt, prec, f.neg, d)
	case 'f':
		return fmtF(buf, prec, f.neg, d)
	case 'g', 'G':
		// ... (logic to choose between fmtE and fmtF based on exponent and precision)
		exp := d.exp - 1
		if exp < -4 || exp >= eprec { // eprecはgフォーマットでのe形式選択の閾値
			// ...
			return fmtE(buf, fmt+'e'-'g', prec-1, f.neg, d)
		}
		// ...
		return fmtF(buf, max(prec-d.exp, 0), f.neg, d)
	}

	// unknown format
	return append(buf, '%', fmt)
}
```
この関数は、`math/big.Float`の値を`%e`, `%E`, `%f`, `%g`, `%G`フォーマットで文字列に変換する中心的なロジックを担います。
1.  まず、`Float`の内部表現を`decimal`構造体に変換します。
2.  次に、指定されたフォーマットと精度に基づいて`decimal`値を丸めます。負の精度（最短表現）はまだ未実装で、パニックを発生させます。
3.  最後に、フォーマットの種類に応じて`fmtE`または`fmtF`を呼び出し、結果のバイトスライスを返します。`%g`フォーマットの場合は、指数部の値に基づいて`%e`形式と`%f`形式のどちらを使用するかを動的に決定します。

### `fmtE` (src/math/big/ftoa.go)

```go
// %e: -d.ddddde±dd
func fmtE(buf []byte, fmt byte, prec int, neg bool, d decimal) []byte {
	// sign
	if neg {
		buf = append(buf, '-')
	}

	// first digit
	ch := byte('0')
	if len(d.mant) > 0 {
		ch = d.mant[0]
	}
	buf = append(buf, ch)

	// .moredigits
	if prec > 0 {
		buf = append(buf, '.')
		// ... (logic to append fractional digits and pad with zeros)
	}

	// e±
	buf = append(buf, fmt)
	var exp int64
	if len(d.mant) > 0 {
		exp = int64(d.exp) - 1 // -1 because first digit was printed before '.'
	}
	if exp < 0 {
		ch = '-'
		exp = -exp
	} else {
		ch = '+'
	}
	buf = append(buf, ch)

	// dd...d
	if exp < 10 {
		buf = append(buf, '0') // at least 2 exponent digits
	}
	return strconv.AppendInt(buf, exp, 10)
}
```
この関数は、科学技術表記（`%e`または`%E`）の文字列を生成します。
*   符号（負の場合）を追加します。
*   数値の最初の桁を追加します。
*   精度が0より大きい場合、小数点とそれに続く小数部の桁を追加します。必要に応じてゼロで埋めます。
*   指数記号（`e`または`E`）と符号（`+`または`-`）を追加します。
*   指数部の値を10進数で追加します。指数部が1桁の場合でも、常に2桁で表示されるように先頭に`0`を追加します（例: `e+01`）。

### `fmtF` (src/math/big/ftoa.go)

```go
// %f: -ddddddd.ddddd
func fmtF(buf []byte, prec int, neg bool, d decimal) []byte {
	// sign
	if neg {
		buf = append(buf, '-')
	}

	// integer, padded with zeros as needed.
	if d.exp > 0 {
		// ... (logic to append integer digits and pad with zeros)
	} else {
		buf = append(buf, '0')
	}

	// fraction
	if prec > 0 {
		buf = append(buf, '.')
		for i := 0; i < prec; i++ {
			ch := byte('0')
			if j := d.exp + i; 0 <= j && j < len(d.mant) {
				ch = d.mant[j]
			}
			buf = append(buf, ch)
		}
	}

	return buf
}
```
この関数は、固定小数点表記（`%f`）の文字列を生成します。
*   符号（負の場合）を追加します。
*   整数部を追加します。必要に応じてゼロで埋めます。数値が1未満の場合は`0`を追加します。
*   精度が0より大きい場合、小数点とそれに続く小数部の桁を追加します。必要に応じてゼロで埋めます。

    *   **`fmtE`関数**: `%e`, `%E`フォーマットを処理します。符号、最初の桁、小数点、小数点以下の桁、そして指数部（`e±dd`形式）を構築します。指数部は常に少なくとも2桁で表示されます（例: `e+00`, `e+01`）。
    *   **`fmtF`関数**: `%f`フォーマットを処理します。符号、整数部、小数点、そして小数点以下の桁を構築します。整数部が0の場合でも`0`が表示され、小数点以下の桁は`prec`で指定された数だけ表示されます。
    *   **`bigFtoa`関数**: `%g`, `%G`フォーマットのロジックを含みます。これは、数値の指数部と指定された精度に基づいて、`fmtE`または`fmtF`のどちらを使用するかを決定します。具体的には、指数が-4未満または精度以上の場合に`%e`形式が選択されます。

この実装は、Goの`strconv/ftoa.go`の対応する実装に密接に倣っていますが、`big.Float`の特性に合わせて修正および簡略化されています。

### `bigFtoa` (src/math/big/ftoa.go)

```go
func (f *Float) bigFtoa(buf []byte, fmt byte, prec int) []byte {
	// TODO(gri) handle Inf. // 無限大の処理はまだ未実装
	// 1) convert Float to multiprecision decimal
	var d decimal
	d.init(f.mant, int(f.exp)-f.mant.bitLen())

	// 2) round to desired precision
	shortest := false
	if prec < 0 {
		shortest = true
		panic("unimplemented") // 短縮表記（最短表現）はまだ未実装
		// ...
	} else {
		// round appropriately
		switch fmt {
		case 'e', 'E':
			d.round(1 + prec)
		case 'f':
			d.round(d.exp + prec)
		case 'g', 'G':
			if prec == 0 {
				prec = 1
			}
			d.round(prec)
		}
	}

	// 3) read digits out and format
	switch fmt {
	case 'e', 'E':
		return fmtE(buf, fmt, prec, f.neg, d)
	case 'f':
		return fmtF(buf, prec, f.neg, d)
	case 'g', 'G':
		// ... (logic to choose between fmtE and fmtF based on exponent and precision)
		exp := d.exp - 1
		if exp < -4 || exp >= eprec { // eprecはgフォーマットでのe形式選択の閾値
			// ...
			return fmtE(buf, fmt+'e'-'g', prec-1, f.neg, d)
		}
		// ...
		return fmtF(buf, max(prec-d.exp, 0), f.neg, d)
	}

	// unknown format
	return append(buf, '%', fmt)
}
```
この関数は、`math/big.Float`の値を`%e`, `%E`, `%f`, `%g`, `%G`フォーマットで文字列に変換する中心的なロジックを担います。
1.  まず、`Float`の内部表現を`decimal`構造体に変換します。
2.  次に、指定されたフォーマットと精度に基づいて`decimal`値を丸めます。負の精度（最短表現）はまだ未実装で、パニックを発生させます。
3.  最後に、フォーマットの種類に応じて`fmtE`または`fmtF`を呼び出し、結果のバイトスライスを返します。`%g`フォーマットの場合は、指数部の値に基づいて`%e`形式と`%f`形式のどちらを使用するかを動的に決定します。

### `fmtE` (src/math/big/ftoa.go)

```go
// %e: -d.ddddde±dd
func fmtE(buf []byte, fmt byte, prec int, neg bool, d decimal) []byte {
	// sign
	if neg {
		buf = append(buf, '-')
	}

	// first digit
	ch := byte('0')
	if len(d.mant) > 0 {
		ch = d.mant[0]
	}
	buf = append(buf, ch)

	// .moredigits
	if prec > 0 {
		buf = append(buf, '.')
		// ... (logic to append fractional digits and pad with zeros)
	}

	// e±
	buf = append(buf, fmt)
	var exp int64
	if len(d.mant) > 0 {
		exp = int64(d.exp) - 1 // -1 because first digit was printed before '.'
	}
	if exp < 0 {
		ch = '-'
		exp = -exp
	} else {
		ch = '+'
	}
	buf = append(buf, ch)

	// dd...d
	if exp < 10 {
		buf = append(buf, '0') // at least 2 exponent digits
	}
	return strconv.AppendInt(buf, exp, 10)
}
```
この関数は、科学技術表記（`%e`または`%E`）の文字列を生成します。
*   符号（負の場合）を追加します。
*   数値の最初の桁を追加します。
*   精度が0より大きい場合、小数点とそれに続く小数部の桁を追加します。必要に応じてゼロで埋めます。
*   指数記号（`e`または`E`）と符号（`+`または`-`）を追加します。
*   指数部の値を10進数で追加します。指数部が1桁の場合でも、常に2桁で表示されるように先頭に`0`を追加します（例: `e+01`）。

### `fmtF` (src/math/big/ftoa.go)

```go
// %f: -ddddddd.ddddd
func fmtF(buf []byte, prec int, neg bool, d decimal) []byte {
	// sign
	if neg {
		buf = append(buf, '-')
	}

	// integer, padded with zeros as needed.
	if d.exp > 0 {
		// ... (logic to append integer digits and pad with zeros)
	} else {
		buf = append(buf, '0')
	}

	// fraction
	if prec > 0 {
		buf = append(buf, '.')
		for i := 0; i < prec; i++ {
			ch := byte('0')
			if j := d.exp + i; 0 <= j && j < len(d.mant) {
				ch = d.mant[j]
			}
			buf = append(buf, ch)
		}
	}

	return buf
}
```
この関数は、固定小数点表記（`%f`）の文字列を生成します。
*   符号（負の場合）を追加します。
*   整数部を追加します。必要に応じてゼロで埋めます。数値が1未満の場合は`0`を追加します。
*   精度が0より大きい場合、小数点とそれに続く小数部の桁を追加します。必要に応じてゼロで埋めます。
