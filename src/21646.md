# [インデックス 21646] ファイルの概要

このコミットは、Go言語の`math/big`パッケージに多倍長浮動小数点数型`Float`を導入する初期段階の実装です。これにより、標準の`float32`や`float64`型では実現できない、任意の精度での浮動小数点数演算が可能になります。

## 変更の背景

Go言語の標準ライブラリには、固定精度の`float32`（単精度）と`float64`（倍精度）の浮動小数点数型が存在しますが、これらはIEEE 754標準に準拠しており、精度が固定されています。科学技術計算、金融計算、暗号学など、より高い精度が求められる分野では、これらの固定精度では不十分な場合があります。

このコミットは、このような要求に応えるため、`math/big`パッケージに任意の精度を持つ浮動小数点数型`Float`を導入するものです。これにより、ユーザーは計算に必要な精度を自由に設定できるようになり、丸め誤差の蓄積による問題や、特定の計算における精度不足を回避することが可能になります。

コミットメッセージにもあるように、この実装は「starting point（出発点）」であり、将来的にはより完全な機能（例：文字列への変換、NaNや無限大の適切なハンドリング）が追加されることを示唆しています。また、`float32`や`float64`と同じ24ビットまたは53ビットの精度を設定することで、IEEE 754の挙動をエミュレートできることも強調されており、既存の浮動小数点数演算との互換性も考慮されています。

## 前提知識の解説

### 多倍長浮動小数点数 (Multi-precision Floating-Point Numbers)

多倍長浮動小数点数とは、コンピュータの固定されたワード長（例：32ビット、64ビット）に依存せず、必要に応じて任意に精度を拡張できる浮動小数点数の表現方法です。通常の浮動小数点数が、符号部、指数部、仮数部を固定ビット長で表現するのに対し、多倍長浮動小数点数では、仮数部（mantissa）を可変長の配列などで表現することで、事実上無限の精度を実現します。

Goの`math/big.Float`型は、`sign × mantissa × 2**exponent`の形式で数を表現します。ここで、仮数（mantissa）は`0.5 <= mantissa < 1.0`の範囲に正規化され、そのビット長（精度）をユーザーが指定できます。これにより、標準の`float32`や`float64`よりもはるかに高い精度で計算を行うことが可能になります。

### IEEE 754 (Standard for Floating-Point Arithmetic)

IEEE 754は、浮動小数点数演算に関する国際標準です。この標準は、浮動小数点数の表現形式（単精度、倍精度など）、特殊な値（無限大、NaN）、そして丸めモードや演算結果の正確性に関するルールを定めています。多くのプログラミング言語やハードウェアがこの標準に準拠しており、異なるシステム間での浮動小数点数演算の互換性を保証しています。

`math/big.Float`は、IEEE 754の丸めモードをサポートしており、特に`ToNearestEven`（最近接偶数への丸め）モードを使用し、精度を24ビットまたは53ビットに設定することで、それぞれ`float32`または`float64`のIEEE 754演算の挙動をエミュレートできます。ただし、`math/big.Float`はIEEE 754よりもはるかに広い指数範囲を持つため、アンダーフローやオーバーフローの挙動が異なる場合があります。

### 丸めモード (Rounding Modes)

浮動小数点数演算では、計算結果が指定された精度で表現できない場合、丸め（rounding）が必要になります。IEEE 754および`math/big.Float`は、複数の丸めモードをサポートしています。

*   **ToNearestEven (最近接偶数への丸め)**: 結果が2つの表現可能な数のちょうど中間にある場合、偶数の方に丸めます。IEEE 754のデフォルトモードです。
*   **ToNearestAway (最近接ゼロから遠い方への丸め)**: 結果が2つの表現可能な数のちょうど中間にある場合、ゼロから遠い方（絶対値が大きい方）に丸めます。
*   **ToZero (ゼロへの丸め)**: 結果をゼロの方向に丸めます（切り捨て）。
*   **AwayFromZero (ゼロから遠い方への丸め)**: 結果をゼロから遠い方向に丸めます（切り上げ）。
*   **ToNegativeInf (負の無限大への丸め)**: 結果を負の無限大の方向に丸めます。
*   **ToPositiveInf (正の無限大への丸め)**: 結果を正の無限大の方向に丸めます。

`math/big.Float`では、演算結果の丸めモードは、結果を格納する`Float`オペランドの`RoundingMode`によって決定されます。

## 技術的詳細

`math/big.Float`の実装は、外部ライブラリに依存しない「ゼロからの実装」です。その内部表現は、符号（`neg`）、仮数（`mant`）、指数（`exp`）から構成され、`x = sign * 0.mantissa * 2**exponent`という形式で数を表します。仮数は`0.5 <= mantissa < 1.0`の範囲に正規化され、`x.mant`は仮数のビットを保持する`nat`（多倍長自然数）スライスです。`x.prec`は仮数のビット精度を示します。

`Float`構造体は以下のフィールドを持ちます。

```go
type Float struct {
	mode RoundingMode // このFloatの丸めモード
	acc  Accuracy     // 直前の演算による丸め誤差の精度情報
	neg  bool         // 符号 (true: 負, false: 正)
	mant nat          // 仮数 (多倍長自然数)
	exp  int32        // 指数
	prec uint         // 精度 (仮数のビット数)
}
```

*   `mode`: この`Float`値がどのように丸められるかを決定する`RoundingMode`。
*   `acc`: 直前の演算でこの`Float`値が生成された際の丸め誤差を示す`Accuracy`。`Below`（正確な値より小さい）、`Exact`（正確な値）、`Above`（正確な値より大きい）のいずれかを取ります。
*   `neg`: 符号を表すブーリアン値。`true`なら負、`false`なら正。
*   `mant`: 仮数を表す`nat`型（`math/big`パッケージ内の多倍長自然数型）のスライス。仮数は正規化され、最上位ビットが1になるように調整されます。
*   `exp`: 指数を表す`int32`。
*   `prec`: この`Float`値の仮数ビット精度。

このコミットでは、基本的な算術演算（加算、減算、乗算、除算）、各種丸めモード、基本的な型変換（`float64`、`uint64`、`int64`からの設定）、および文字列から`Float`への変換が実装されています。特に、`round`メソッドは、指定された精度と丸めモードに基づいて仮数を丸める中心的なロジックを担っています。

`uadd`, `usub`, `umul`, `uquo`といった内部関数は、符号を無視した絶対値での加算、減算、乗算、除算を実装しており、これらの結果に後から符号と丸めを適用することで、`Add`, `Sub`, `Mul`, `Quo`などの公開メソッドが実装されています。

テストコード（`float_test.go`）も同時に追加されており、基本的な丸め動作、`float32`および`float64`との互換性、および各種設定関数（`SetUint64`, `SetInt64`, `SetFloat64`, `SetString`）のテストが含まれています。

このコミットの主要な変更は、`src/math/big/float.go`と`src/math/big/float_test.go`の新規追加です。特に`float.go`は`math/big.Float`型の定義と、その基本的な演算ロジックを含んでいます。

```go
// src/math/big/float.go

// A Float represents a multi-precision floating point number
// of the form
//
//   sign * mantissa * 2**exponent
//
// Each value also has a precision, rounding mode, and accuracy value:
// The precision is the number of mantissa bits used to represent a
// value, and the result of operations is rounded to that many bits
// according to the value's rounding mode (unless specified othewise).
// The accuracy value indicates the rounding error with respect to the
// exact (not rounded) value.
//
// The zero value for a Float represents the number 0.
//
// By setting the desired precision to 24 (or 53) and using ToNearestEven
// rounding, Float arithmetic operations emulate the corresponding float32
// or float64 IEEE-754 operations (except for denormalized numbers and NaNs).
//
// CAUTION: THIS IS WORK IN PROGRESS - DO NOT USE YET.
//
type Float struct {
	mode RoundingMode
	acc  Accuracy
	neg  bool
	mant nat
	exp  int32
	prec uint // TODO(gri) make this a 32bit field
}

// NewFloat returns a new Float with value x rounded
// to prec bits according to the given rounding mode.
func NewFloat(x float64, prec uint, mode RoundingMode) *Float {
	// TODO(gri) should make this more efficient
	z := new(Float).SetFloat64(x)
	return z.Round(z, prec, mode)
}

// SetFloat64 sets z to x and returns z.
// Precision is set to 53 bits.
// TODO(gri) test denormals, +/-Inf, disallow NaN.
func (z *Float) SetFloat64(x float64) *Float {
	z.prec = 53
	if x == 0 {
		z.neg = false
		z.mant = z.mant[:0]
		z.exp = 0
		return z
	}
	z.neg = x < 0
	fmant, exp := math.Frexp(x) // get normalized mantissa
	z.mant = z.mant.setUint64(1<<63 | math.Float64bits(fmant)<<11)
	z.exp = int32(exp)
	return z
}

// Rounding is performed according to z's precision
// and rounding mode; and z's accuracy reports the
// result error relative to the exact (not rounded)
// result.
func (z *Float) Add(x, y *Float) *Float {

}

// SetString sets z to the value of s and returns z and a boolean indicating
// success. s must be a floating-point number of the form:
//
//	number   = [ sign ] mantissa [ exponent ] .
//	mantissa = digits | digits "." [ digits ] | "." digits .
//	exponent = ( "E" | "e" | "p" ) [ sign ] digits .
//	sign     = "+" | "-" .
//	digits   = digit { digit } .
//	digit    = "0" ... "9" .
//
// A "p" exponent indicates power of 2 for the exponent; for instance 1.2p3

//
```

## コアとなるコードの解説

### `type Float struct`

この構造体は、多倍長浮動小数点数の内部表現を定義します。
*   `mode`: この`Float`インスタンスに適用される丸めモード。演算結果をこのモードに従って丸めます。
*   `acc`: 直前の演算で発生した丸め誤差の方向を示します。`Exact`（正確）、`Below`（正確な値より小さい）、`Above`（正確な値より大きい）のいずれかです。
*   `neg`: 数の符号。`true`が負、`false`が正です。
*   `mant`: 仮数部。`nat`型（多倍長自然数）のスライスで、仮数のビット列を格納します。仮数は常に正規化され、最上位ビットが1になるように調整されます。
*   `exp`: 指数部。`int32`型で、仮数に掛けられる2のべき乗を示します。
*   `prec`: 精度。仮数部の有効ビット数を示します。

### `func NewFloat(x float64, prec uint, mode RoundingMode) *Float`

このコンストラクタは、標準の`float64`値`x`を基に新しい`Float`インスタンスを作成し、指定された`prec`（精度）と`mode`（丸めモード）で丸めます。内部的には`SetFloat64`で初期値を設定した後、`Round`メソッドを呼び出して丸め処理を行います。

### `func (z *Float) SetFloat64(x float64) *Float`

`float64`値を`Float`型に変換するメソッドです。`math.Frexp`関数を使用して`float64`の仮数と指数を抽出し、それらを`Float`の内部表現にマッピングします。この際、`Float`の精度はデフォルトで53ビット（`float64`の仮数精度）に設定されます。

### `func (z *Float) round(sbit uint)`

このメソッドは、`Float`の丸め処理の核心です。`z.mode`と`z.prec`に基づいて、`z.mant`を丸めます。
丸めは、**丸めビット (rbit)** と **スティッキービット (sbit)** の2つのビット情報に基づいて行われます。
*   `rbit`: 丸め対象の最下位ビットのすぐ下のビット（0.5の位に相当）。
*   `sbit`: `rbit`よりさらに下のビットの中に1つでも1があれば1、そうでなければ0（0.25、0.125などの位に相当）。
これらのビットと丸めモードの組み合わせによって、切り上げ、切り捨て、最近接偶数への丸めなどの挙動が決定されます。丸め後、`z.acc`フィールドが更新され、丸め誤差の方向が記録されます。

### `func (z *Float) Add(x, y *Float) *Float`

`x`と`y`の和を計算し、結果を`z`に格納するメソッドです。このメソッドは、`x`と`y`の符号の組み合わせに応じて、内部的に`uadd`（符号を無視した加算）または`usub`（符号を無視した減算）を呼び出します。例えば、`x + (-y)`は`x - y`として扱われ、`x`と`y`の絶対値の比較に基づいて`usub`が呼び出されます。最終的に、結果の符号が決定され、`z.round`メソッドによって丸め処理が適用されます。

### `func (z *Float) SetString(s string) (*Float, bool)`

文字列`s`を解析し、その値を`Float`型に変換するメソッドです。このメソッドは、一般的な浮動小数点数表記（例: "1.23", "1e-5", "0x1.2p3"）をサポートします。特に、"p"を指数部の区切り文字として使用することで、2のべき乗による指数表現（例: `1.2p3`は`1.2 * 2^3`）も解析できます。解析が成功した場合は`*Float`と`true`を、失敗した場合は`nil`と`false`を返します。
