## 変更の背景

Go言語の標準ライブラリは、その使いやすさと明確なドキュメントで知られています。その一環として、各関数やメソッドには、その機能と典型的な使用方法を示すコード例が提供されることが推奨されています。`strings.HasPrefix`および`strings.HasSuffix`関数は、文字列操作において非常に頻繁に使用される基本的な関数であるにもかかわらず、これまで公式のコード例が提供されていませんでした。

このコミットの背景には、以下の目的があります。

1.  **ドキュメントの改善**: コード例は、関数の動作を言葉で説明するよりも直感的に理解させる強力な手段です。特に、`strings`パッケージのような基本的なユーティリティにおいては、具体的な使用例があることで、開発者が迅速に関数の使い方を把握し、誤用を防ぐことができます。
2.  **学習体験の向上**: Go言語を学習する新規開発者にとって、標準ライブラリの関数に付属する例は、言語のイディオムやベストプラクティスを学ぶ上で非常に役立ちます。
3.  **テストカバレッジの側面**: Goの`Example`関数は、通常のテスト関数と同様に`go test`コマンドによって実行され、出力がコメントと一致するかどうかが検証されます。これにより、例が常に正しく動作することが保証され、ドキュメントの信頼性が高まります。

この変更は、Go言語の「明確さ」と「使いやすさ」という設計哲学に沿ったものであり、ライブラリ全体の品質向上に貢献しています。

## 前提知識の解説

このコミットを理解するためには、以下のGo言語の概念と`strings`パッケージの基本的な知識が必要です。

### Go言語の`strings`パッケージ

`strings`パッケージは、UTF-8でエンコードされた文字列を操作するための多くの便利な関数を提供します。これには、文字列の検索、置換、分割、結合、大文字・小文字変換などが含まれます。

### `strings.HasPrefix(s, prefix string) bool`

この関数は、文字列`s`が`prefix`で始まる場合に`true`を返します。そうでない場合は`false`を返します。
例: `strings.HasPrefix("Gopher", "Go")` は `true` を返します。

### `strings.HasSuffix(s, suffix string) bool`

この関数は、文字列`s`が`suffix`で終わる場合に`true`を返します。そうでない場合は`false`を返します。
例: `strings.HasSuffix("Amigo", "go")` は `true` を返します。

### Go言語の`Example`関数

Go言語のテストフレームワークには、通常の単体テスト（`TestXxx`）やベンチマークテスト（`BenchmarkXxx`）に加えて、`ExampleXxx`という形式の関数があります。
`Example`関数は、以下の特徴を持ちます。

*   **ドキュメント生成**: `go doc`コマンドを実行すると、`Example`関数のコードと出力が自動的にドキュメントに組み込まれます。これにより、開発者は関数の使い方をすぐに確認できます。
*   **実行可能な例**: `Example`関数は、通常のテストと同様に`go test`コマンドで実行されます。関数内の`// Output:`コメントに記述された期待される出力と、実際の`fmt.Print`や`fmt.Println`などの出力が一致するかどうかが検証されます。これにより、ドキュメントの例が常に最新かつ正確であることが保証されます。
*   **可読性**: `Example`関数は、特定の機能の典型的な使用シナリオを簡潔に示し、コードの可読性と理解を深めることを目的としています。

このコミットは、まさにこの`Example`関数のメカニズムを利用して、`HasPrefix`と`HasSuffix`のドキュメントとテストを強化しています。

## 技術的詳細

このコミットは、`src/strings/example_test.go`ファイルに新しい`ExampleHasPrefix`関数と`ExampleHasSuffix`関数を追加することで、`strings`パッケージのドキュメントとテストを強化しています。

追加された`Example`関数は、`fmt.Println`を使用して`strings.HasPrefix`および`strings.HasSuffix`の呼び出し結果を出力し、その直後に`// Output:`コメントで期待される出力を記述しています。`go test`コマンドが実行されると、これらの関数も実行され、実際の出力が`// Output:`コメントの内容と一致するかどうかが自動的に検証されます。

具体的には、以下のケースが例として追加されています。

*   **`HasPrefix`**:
    *   文字列がプレフィックスで始まる場合 (`"Gopher"`, `"Go"`) -> `true`
    *   文字列がプレフィックスで始まらない場合 (`"Gopher"`, `"C"`) -> `false`
    *   プレフィックスが空文字列の場合 (`"Gopher"`, `""`) -> `true` (空文字列は常に任意の文字列のプレフィックスと見なされるため)

*   **`HasSuffix`**:
    *   文字列がサフィックスで終わる場合 (`"Amigo"`, `"go"`) -> `true`
    *   文字列がサフィックスで終わらない場合 (大文字小文字の違い) (`"Amigo"`, `"O"`) -> `false`
    *   文字列がサフィックスで終わらない場合 (`"Amigo"`, `"Ami"`) -> `false`
    *   サフィックスが空文字列の場合 (`"Amigo"`, `""`) -> `true` (空文字列は常に任意の文字列のサフィックスと見なされるため)

これらの例は、関数の基本的な動作だけでなく、エッジケース（空文字列のプレフィックス/サフィックス）についてもカバーしており、関数の挙動を包括的に示しています。

## コアとなるコードの解説

このコミットで追加されたコードは、Goの`testing`パッケージが提供する`Example`関数の慣例に従っています。

1.  **`func ExampleHasPrefix()`**:
    *   この関数は`strings.HasPrefix`の動作を示すための例です。
    *   `fmt.Println(strings.HasPrefix("Gopher", "Go"))` は、文字列 "Gopher" が "Go" で始まるため `true` を出力します。
    *   `fmt.Println(strings.HasPrefix("Gopher", "C"))` は、文字列 "Gopher" が "C" で始まらないため `false` を出力します。
    *   `fmt.Println(strings.HasPrefix("Gopher", ""))` は、空文字列 `""` が常に任意の文字列のプレフィックスと見なされるため `true` を出力します。
    *   `// Output:` コメントブロックは、これらの`fmt.Println`呼び出しによって生成されると期待される出力を正確に記述しています。`go test`実行時にこの出力と実際の出力が比較されます。

2.  **`func ExampleHasSuffix()`**:
    *   この関数は`strings.HasSuffix`の動作を示すための例です。
    *   `fmt.Println(strings.HasSuffix("Amigo", "go"))` は、文字列 "Amigo" が "go" で終わるため `true` を出力します。
    *   `fmt.Println(strings.HasSuffix("Amigo", "O"))` は、文字列 "Amigo" が "O" で終わらないため `false` を出力します（Goの文字列比較はケースセンシティブです）。
    *   `fmt.Println(strings.HasSuffix("Amigo", "Ami"))` は、文字列 "Amigo" が "Ami" で終わらないため `false` を出力します。
    *   `fmt.Println(strings.HasSuffix("Amigo", ""))` は、空文字列 `""` が常に任意の文字列のサフィックスと見なされるため `true` を出力します。
    *   同様に、`// Output:` コメントブロックが期待される出力を定義しています。

これらの例は、`strings.HasPrefix`と`strings.HasSuffix`の基本的な機能と、特に空文字列を引数として渡した場合の挙動を明確に示しており、開発者がこれらの関数を正しく理解し、利用する上で非常に有用です。
