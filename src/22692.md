## 変更の背景

Goコンパイラは、コンパイル時に定数式を評価するために任意精度演算ライブラリを使用しています。この演算に関連する関数は、以前は `mparith1.go`、`mparith2.go`、`mparith3.go` の複数のファイルに分散していましたが、その配置は必ずしも論理的ではありませんでした。特に、整数（`Mpint`）と浮動小数点数（`Mpflt`）の演算関数が混在している状態でした。

このコミットの主な目的は、コードの保守性と理解しやすさを向上させるための「クリーンアップ」です。具体的には、以下の点が背景にあります。

1.  **コードの整理**: 整数演算に関連する関数は `mparith2.go` に、浮動小数点数演算に関連する関数は `mparith3.go` に集約することで、各ファイルの責務を明確にし、関連するコードを見つけやすくします。
2.  **冗長な定数の削除**: `Mpscale` と `Mpprec` という2つの定数が、任意精度浮動小数点数の精度を定義するために使用されていましたが、これらを統合し、より明確な `Mpprec` の定義に置き換えることで、定数管理を簡素化します。
3.  **セマンティックな変更なし**: この変更は、コンパイラの動作や生成されるコードに影響を与えるものではなく、純粋に内部的なコード構造の改善を目的としています。

## 前提知識の解説

### `cmd/internal/gc` パッケージ

`cmd/internal/gc` は、Goコンパイラのフロントエンドとバックエンドの一部を含む内部パッケージです。Goコンパイラは、ソースコードの解析、抽象構文木（AST）の構築、型チェック、最適化、そして最終的な機械語コードの生成といった複数のフェーズで構成されています。このパッケージは、特に型チェックや定数評価など、コンパイルの中核的な処理を担っています。`internal` ディレクトリにあるため、Goの外部からは直接インポートして使用することはできません。

### 任意精度演算 (Arbitrary-Precision Arithmetic)

通常のプログラミング言語では、`int` や `float64` のような組み込み型は固定されたビット数で表現されます。これにより、表現できる数値の範囲や精度に限界があります。しかし、コンパイラが定数式を評価する際には、非常に大きな数値や高い精度の浮動小数点数を扱う必要がある場合があります。例えば、`1 << 100` のようなシフト演算や、`math.Pi` のような高精度な浮動小数点定数です。

任意精度演算は、このような固定長の制限を受けずに、必要なだけ多くの桁数や精度で数値を表現・計算できる技術です。Goコンパイラでは、`math/big` パッケージ（内部的には `cmd/internal/gc/big` として使用）がこの機能を提供しています。

### `Mpint` と `Mpflt`

`Mpint` (Multi-precision integer) と `Mpflt` (Multi-precision float) は、Goコンパイラ内部で任意精度の整数と浮動小数点数を表現するために使用される構造体です。これらは `math/big` パッケージの `big.Int` および `big.Float` をラップしており、コンパイラが定数値を扱う際の内部表現として機能します。

-   **`Mpint`**: 任意精度の整数値を保持します。内部的には `big.Int` を使用しています。
-   **`Mpflt`**: 任意精度の浮動小数点数値を保持します。内部的には `big.Float` を使用しています。

これらの構造体には、加算、減算、乗算、除算、比較などの様々な演算を行うためのメソッドが関連付けられています。

### `big.Int` と `big.Float`

Go標準ライブラリの `math/big` パッケージは、任意精度の数値型を提供します。

-   **`big.Int`**: 任意精度の整数型。非常に大きな整数値を扱うことができます。
-   **`big.Float`**: 任意精度の浮動小数点数型。高い精度で浮動小数点数を扱うことができます。

これらの型は、コンパイラが定数式を評価する際に、オーバーフローや精度損失なしに正確な計算を行うために不可欠です。

これらの変更は、コンパイラのコードベースの健全性を維持し、将来的な開発を容易にするための典型的なリファクタリング作業です。

## コアとなるコードの解説

### `Mpprec` 定数の変更 (`src/cmd/internal/gc/go.go`)

この変更は、浮動小数点数の任意精度演算における内部的な精度設定を簡素化するものです。
-   **旧**: `Mpscale = 29` と `Mpprec = 16` の2つの定数があり、実質的な精度は `Mpscale * Mpprec` で計算されていました。これは、`29 * 16 = 464` ビットに相当します。
-   **新**: `Mpscale` が削除され、`Mpprec` が直接 `16 * 29`、つまり `464` に設定されました。
この変更により、精度設定が単一の `Mpprec` 定数に集約され、コードの意図がより明確になりました。セマンティックな変更はなく、コンパイラの動作に影響はありません。コメントには、将来的に `Mpprec` を `512` または `1024` に増やす可能性が示唆されており、これはより高い精度が必要になった場合の拡張性を示しています。

### 関数移動とファイル再編成 (`src/cmd/internal/gc/mparith1.go`, `src/cmd/internal/gc/mparith2.go`, `src/cmd/internal/gc/mparith3.go`)

このコミットの主要な変更は、任意精度演算に関連する関数を、その機能に応じて適切なファイルに移動したことです。

-   **`mparith1.go` の削除**: このファイルは、整数と浮動小数点数の両方の演算関数が混在していたため、削除されました。
-   **`mparith2.go` への整数演算関数の集約**:
    -   `mpmovefixfix`: `Mpint` 型の値をコピーします。
    -   `mpmovefltfix`: `Mpflt` 型の値を `Mpint` 型に変換します。浮動小数点数を整数に変換する際の丸め処理（`big.ToZero` と `big.AwayFromZero`）が含まれており、精度損失の可能性を考慮しています。
    -   `mpsubfixfix`, `mpdivfixfix`, `mpmodfixfix`: `Mpint` 型の減算、除算、剰余演算を行います。オーバーフローチェックも含まれています。
    -   `Mpshiftfix`: `Mpint` 型の値をビットシフトします。
    -   `Mpcmpfixfix`, `mpcmpfixc`: `Mpint` 型の値の比較を行います。
    -   `mpatofix`: 文字列を `Mpint` 型に変換します。
    -   `Bconv`: `Mpint` 型の値を文字列に変換します。
    -   `mptestovf` の変更: `Mpint` のオーバーフローテスト関数で、`limit` の計算が `Mpscale * Mpprec` から `Mpprec` に変更されました。これは `go.go` での `Mpprec` の定義変更と整合性を保つためのものです。
-   **`mparith3.go` への浮動小数点演算関数の集約**:
    -   `newMpflt`: 新しい `Mpflt` オブジェクトを初期化します。ここで `a.Val.SetPrec(Mpprec)` となり、`go.go` で定義された新しい `Mpprec` の値が直接使用されるようになりました。
    -   `Mpmovefixflt`: `Mpint` 型の値を `Mpflt` 型に変換します。
    -   `mpmovefltflt`: `Mpflt` 型の値をコピーします。
    -   `mpaddcflt`, `mpsubfltflt`, `mpmulcflt`: `Mpflt` 型の加算、減算、乗算を行います。
    -   `mpcmpfltflt`, `mpcmpfltc`: `Mpflt` 型の値の比較を行います。
    -   `mpatoflt`: 文字列を `Mpflt` 型に変換します。
    -   `Fconv`: `Mpflt` 型の値を文字列に変換します。

これらの変更により、Goコンパイラの任意精度演算コードは、整数と浮動小数点数で明確に分離され、それぞれのファイルが特定のデータ型に特化した機能を持つようになりました。これにより、コードの構造がより論理的になり、開発者が特定の演算機能を探したり、変更を加えたりする際の効率が向上します。
