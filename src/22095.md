## 変更の背景

このコミットの主な背景は、`Cbrt`関数のパフォーマンス改善です。コミットメッセージに明記されているように、変更前は1操作あたり45.3ナノ秒かかっていた処理が、変更後には19.9ナノ秒に短縮され、約2.2倍の高速化が達成されました。

立方根の計算は、科学技術計算、グラフィックス、物理シミュレーションなど、様々な分野で利用される基本的な数学関数です。そのため、その性能はアプリケーション全体のパフォーマンスに影響を与える可能性があります。Go言語の標準ライブラリとして、`math`パッケージの関数は高い効率性と精度が求められます。

以前の実装は、Gunter MeinardusとG. D. Taylorによる論文「Optimal Partitioning of Newton's Method for Calculating Roots」に基づいたものでした。この方法はニュートン法を最適化したものでしたが、より高速な代替手段が存在することが判明しました。

新しい実装は、`fdlibm`（Free Distributed Math Library）の`s_cbrt.c`というC言語のコードをGo言語に移植し、修正したものです。`fdlibm`は、Sun Microsystemsによって開発された、IEEE 754浮動小数点標準に厳密に準拠した高品質な数学関数ライブラリであり、その実装は高い精度と効率で知られています。このライブラリのアルゴリズムを採用することで、Goの`Cbrt`関数は大幅な性能向上を実現しました。

## 前提知識の解説

### 1. 立方根 (Cube Root)
ある数 $x$ の立方根とは、$y^3 = x$ となる数 $y$ のことです。例えば、8の立方根は2です。数学的には $\sqrt[3]{x}$ または $x^{1/3}$ と表記されます。

### 2. 浮動小数点数 (Floating-Point Numbers) と IEEE 754
コンピュータで実数を表現するための形式で、通常はIEEE 754標準に従います。これは、数を符号部、仮数部、指数部に分けて表現します。`float64`は倍精度浮動小数点数であり、64ビットで表現されます。
*   **`Float64bits(f float64) uint64`**: `float64`型の浮動小数点数`f`のIEEE 754バイナリ表現を`uint64`として返します。
*   **`Float64frombits(u uint64) float64`**: `uint64`型のバイナリ表現`u`を`float64`型の浮動小数点数に変換して返します。
これらの関数は、浮動小数点数のビットレベルでの操作を可能にし、数値計算の最適化や特殊な処理に利用されます。

### 3. ニュートン法 (Newton's Method)
方程式 $f(x) = 0$ の根を近似的に求めるための反復法です。立方根の計算においては、$f(y) = y^3 - x = 0$ の根を求めることに相当します。ニュートン法の更新式は $y_{n+1} = y_n - f(y_n) / f'(y_n)$ で与えられます。立方根の場合、$f'(y) = 3y^2$ なので、$y_{n+1} = y_n - (y_n^3 - x) / (3y_n^2) = (2y_n^3 + x) / (3y_n^2)$ となります。
このコミットの古い実装では、ニュートン法をベースにした最適化された反復計算が用いられていました。新しい実装でも最終段階でニュートン法が使用されます。

### 4. `fdlibm` (Free Distributed Math Library)
Sun Microsystemsによって開発された、高品質な数学関数ライブラリです。IEEE 754浮動小数点標準に厳密に準拠しており、高い精度と移植性を提供します。多くのシステムや言語の標準数学ライブラリの基盤となっています。`fdlibm`の`cbrt`実装は、初期推定と多項式近似、そしてニュートン法を組み合わせることで、効率的かつ高精度な計算を実現しています。

### 5. ULPs (Units in the Last Place)
浮動小数点数の精度を測る指標の一つです。ある浮動小数点数と、その次に表現可能な浮動小数点数との間の最小の差を指します。ULPが小さいほど、その計算結果は正確な数学的値に近いことを意味します。`fdlibm`の関数は通常、1 ULP以内の精度を目標としています。

### 6. `Frexp` と `Ldexp` (旧実装で使用)
*   **`Frexp(f float64) (frac float64, exp int)`**: 浮動小数点数`f`を仮数部`frac`と指数部`exp`に分解します。`f = frac * 2^exp` となり、`0.5 <= |frac| < 1.0` または `frac = 0` となります。
*   **`Ldexp(frac float64, exp int) float64`**: 仮数部`frac`と指数部`exp`から浮動小数点数を再構築します。`frac * 2^exp` を計算します。
旧実装では、これらの関数を使って入力値を正規化し、計算範囲を限定していました。

## 技術的詳細

新しい`Cbrt`関数の実装は、`fdlibm`の`s_cbrt.c`に基づいています。このアルゴリズムは、以下のステップで立方根を計算します。

1.  **特殊ケースのハンドリング**:
    *   入力`x`が0、NaN（非数）、または無限大の場合、そのまま`x`を返します。これは、これらの特殊な入力に対する正しい数学的振る舞いを保証するためです。

2.  **符号の処理**:
    *   立方根は元の数の符号を保持するため、入力`x`が負の場合、絶対値で計算を行い、最終結果に負の符号を適用します。

3.  **初期推定 (Rough cbrt to 5 bits)**:
    *   `fdlibm`の`cbrt`実装の重要な部分です。浮動小数点数のビット表現を直接操作して、非常に高速に初期推定値を得ます。
    *   `Float64bits(x)/3 + B1<<32` または `Float64bits(t)/3 + B2<<32` のようなビット演算が行われます。これは、浮動小数点数の指数部を3で割ることで、立方根の指数部を近似的に求めることに相当します。`B1`と`B2`は、この初期推定の精度を調整するための定数です。
    *   特に、`x < SmallestNormal`（非正規化数）の場合には、異なる`B2`定数を使用して初期推定を行います。非正規化数は非常に小さい数を表し、通常の浮動小数点演算とは異なる振る舞いをすることがあるため、特別な処理が必要です。

4.  **多項式近似による精度の向上 (New cbrt to 23 bits)**:
    *   初期推定値`t`をさらに洗練するために、多項式近似が使用されます。
    *   `r := t * t / x`
    *   `s := C + r*t`
    *   `t *= G + F/(s+E+D/s)`
    *   ここで使用される`C`, `D`, `E`, `F`, `G`は、特定の範囲で立方根関数を近似するための係数です。これらの定数は、高い精度で初期推定値を23ビット程度まで改善するために、慎重に選択されたものです。このステップは、ニュートン法のような反復計算よりも高速に精度を向上させることができます。

5.  **ビット操作による調整 (Chop to 22 bits, make larger than cbrt(x))**:
    *   `t = Float64frombits(Float64bits(t)&(0xFFFFFFFFC<<28) + 1<<30)`
    *   このステップでは、計算された`t`のビット表現を操作し、精度を22ビットに「切り詰め」ます。そして、その値を真の立方根よりもわずかに大きくするように調整します。これは、次のニュートン法による最終調整ステップで、常に真の値よりも大きい側から収束させるための準備です。これにより、収束の安定性と精度が向上します。

6.  **ニュートン法による最終調整 (One step newton iteration to 53 bits with error less than 0.667ulps)**:
    *   最終的な高精度を得るために、ニュートン法が1回だけ適用されます。
    *   `s = t * t`
    *   `r = x / s`
    *   `w := t + t`
    *   `r = (r - t) / (w + r)`
    *   `t = t + t*r`
    *   このニュートン法の反復は、非常に高い精度（53ビット、つまり倍精度浮動小数点数の仮数部のほぼ全ビット）で結果を収束させます。`fdlibm`の設計目標である0.667 ULPs未満の誤差を達成するために、この最終ステップが不可欠です。

この多段階アプローチ（ビット操作による初期推定、多項式近似、そして単一のニュートン法反復）により、旧実装の反復回数の多いニュートン法よりも、はるかに高速かつ高精度な立方根計算が実現されています。

## コアとなるコードの解説

変更の核心は、`Cbrt`関数の内部ロジックの完全な書き換えです。

**削除されたコード（旧実装）**:
*   MeinardusとTaylorの論文に基づくアルゴリズムのコメントが削除されました。
*   `A1`から`C4`までの多数の定数が削除されました。これらは旧実装の多項式近似や初期推定に使用されていました。
*   `Frexp`と`Ldexp`を使用した入力値の正規化と指数部の処理が削除されました。
*   複数の`switch`ケースによる初期推定と、それに続く2段階のニュートン法反復（`y *= (t + x) / (s + t)` と `y -= y * (((14.0/81.0)*s-(2.0/9.0))*s + (1.0 / 3.0)) * s`）が削除されました。

**追加されたコード（新実装）**:
*   `fdlibm/s_cbrt.c`からの移植であることを示す新しいコメントと著作権表示が追加されました。
*   新しい定数群が導入されました:
    *   `B1`, `B2`: 初期推定のためのビット操作で使用される整数定数。
    *   `C`, `D`, `E`, `F`, `G`: 多項式近似で使用される浮動小数点定数。
    *   `SmallestNormal`: 非正規化数を検出するための定数。
*   **初期推定**:
    *   `t := Float64frombits(Float64bits(x)/3 + B1<<32)`: 入力`x`のビット表現を直接操作し、指数部を3で割ることで、立方根の粗い初期推定値`t`を生成します。`B1<<32`は、この推定を調整するためのオフセットです。
    *   `if x < SmallestNormal`: 非正規化数に対する特別な処理。`t`を一時的に大きな値に設定し、`x`を乗算した後、`B2`を使用して再度ビット操作による初期推定を行います。これは、非正規化数の精度を維持するための重要なステップです。
*   **多項式近似**:
    *   `r := t * t / x`
    *   `s := C + r*t`
    *   `t *= G + F/(s+E+D/s)`: これらの式は、初期推定`t`をさらに洗練するための多項式近似です。`C`, `D`, `E`, `F`, `G`は、この近似の係数であり、`fdlibm`で最適化された値です。これにより、約23ビットの精度が得られます。
*   **ビット操作による調整**:
    *   `t = Float64frombits(Float64bits(t)&(0xFFFFFFFFC<<28) + 1<<30)`: 計算された`t`のビット表現を操作し、下位ビットを切り捨てて22ビットの精度に調整します。さらに、`+ 1<<30`によって、結果が真の立方根よりもわずかに大きくなるように調整されます。これは、次のニュートン法が常に上から収束するようにするための「ガード」ステップです。
*   **単一のニュートン法反復**:
    *   `s = t * t`
    *   `r = x / s`
    *   `w := t + t`
    *   `r = (r - t) / (w + r)`
    *   `t = t + t*r`: 最終的な高精度を得るために、ニュートン法が1回だけ実行されます。この反復は、`t`を53ビットの精度（倍精度浮動小数点数の仮数部のほぼ全ビット）に収束させ、0.667 ULPs未満の誤差を保証します。
*   **符号の復元**:
    *   `if sign { t = -t }`: 最初に保存した符号を最終結果`t`に適用します。

この新しい実装は、ビット操作による高速な初期推定、多項式近似による効率的な精度向上、そして単一のニュートン法反復による最終的な高精度化という、複数の技術を組み合わせることで、旧実装よりも大幅な性能向上と高い精度を実現しています。
