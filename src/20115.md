# [インデックス 20115] ファイルの概要

このコミットは、Go言語の`unicode`、`strconv`、`regexp`パッケージをUnicode 7.0.0にアップグレードするものです。これにより、Go言語が扱うことができる文字の範囲、文字のプロパティ、スクリプト、および一般カテゴリが最新のUnicode標準に準拠するよう更新されます。

## 変更の背景

Go言語の標準ライブラリは、Unicode標準に準拠して文字の処理を行います。これには、文字の分類（数字、文字、記号など）、スクリプト（ラテン文字、キリル文字、アラビア文字など）、およびその他の文字プロパティが含まれます。Unicode標準は定期的に新しい文字やプロパティの定義を追加して更新されます。

このコミットが行われた2014年当時、Unicodeの最新バージョンは7.0.0でした。Go言語の`unicode`パッケージが古いバージョンのUnicodeデータを使用していると、新しい文字が正しく扱えなかったり、既存の文字のプロパティが最新の定義と異なるために予期せぬ動作を引き起こす可能性がありました。例えば、新しい絵文字や、歴史的な文字体系、少数言語の文字などが追加されると、それらを正しく認識・処理するためには、基盤となるUnicodeデータの更新が不可欠です。

特に、`strconv`パッケージの`IsPrint`関数（印刷可能な文字の判定）や`regexp`パッケージ（正規表現での文字クラスマッチング）は、Unicodeの文字プロパティに大きく依存しています。これらの機能が最新のUnicode標準に準拠することで、より正確で網羅的な文字処理が可能となり、国際化対応の改善に繋がります。

## 前提知識の解説

### Unicodeとは

Unicode（ユニコード）は、世界中のあらゆる文字を統一的な方法で表現するために設計された文字コードの国際標準です。これにより、異なる言語やプラットフォーム間での文字化けを防ぎ、多言語対応のソフトウェア開発を容易にします。Unicodeは、各文字に一意のコードポイント（数値）を割り当て、その文字のプロパティ（カテゴリ、スクリプト、双方向性など）を定義しています。

### Unicodeのバージョンアップ

Unicode標準は、新しい文字の追加、既存の文字プロパティの修正、新しいスクリプトの定義などにより、定期的にバージョンアップされます。バージョンアップは、国際的な文字集合の進化に対応するために不可欠です。

### Go言語の`unicode`パッケージ

Go言語の標準ライブラリには、Unicode文字のプロパティに関する情報を提供する`unicode`パッケージが含まれています。このパッケージは、文字が特定のカテゴリ（例: `unicode.IsLetter`、`unicode.IsDigit`）に属するかどうかを判定する関数や、文字のスクリプト（例: `unicode.IsCyrillic`）を判定する関数などを提供します。これらの関数は、内部的にUnicodeデータベースのデータ（文字の範囲とプロパティのテーブル）を使用しています。

### `strconv`パッケージと`IsPrint`関数

`strconv`パッケージは、文字列と数値の変換など、基本的なデータ型間の変換機能を提供します。このコミットで関連するのは`IsPrint`関数で、これは与えられたルーン（Go言語におけるUnicodeコードポイント）が印刷可能かどうかを判定します。この判定は、内部的に`unicode`パッケージのデータに依存しています。

### `regexp`パッケージ

`regexp`パッケージは、正規表現の機能を提供します。正規表現では、`\p{L}`（任意の文字）、`\p{N}`（任意の数字）のようなUnicodeプロパティエスケープシーケンスを使用して、特定のUnicodeプロパティを持つ文字にマッチさせることができます。これらの文字クラスの定義も、`unicode`パッケージのデータに依存しています。

### `RangeTable`

`RangeTable`は、Go言語の`unicode`パッケージで文字の範囲を効率的に表現するために使用されるデータ構造です。これは、連続するUnicodeコードポイントの範囲と、その範囲内の文字が持つプロパティを定義します。`tables.go`ファイルには、様々なUnicodeカテゴリやスクリプトに対応する多数の`RangeTable`が定義されています。

## 技術的詳細

このコミットの主要な技術的変更点は、Go言語のUnicodeデータがUnicode 6.3.0から7.0.0に更新されたことです。この更新は、主に以下のファイルに影響を与えています。

1.  **`src/pkg/unicode/maketables.go`**:
    このファイルは、UnicodeデータベースからGo言語の`unicode`パッケージが使用するテーブルを生成するためのツールです。このコミットでは、このツールが参照するUnicodeデータのURLが`http://www.unicode.org/Public/6.3.0/ucd/`から`http://www.unicode.org/Public/7.0.0/ucd/`に変更されています。これにより、`go generate`コマンドを実行する際に、最新のUnicode 7.0.0のデータがダウンロードされ、それに基づいて`tables.go`が再生成されるようになります。

2.  **`src/pkg/unicode/tables.go`**:
    このファイルは、`maketables.go`によって生成されるGo言語のUnicodeデータテーブルを含んでいます。Unicode 7.0.0へのアップグレードに伴い、このファイル内の`RangeTable`の定義が大幅に更新されています。具体的には、`Version`定数が`"6.3.0"`から`"7.0.0"`に変更され、様々な文字カテゴリ（`_C`, `_Cf`, `_L`, `_Ll`, `_Lm`, `_Lo`, `_M`, `_Mc`, `_Me`, `_Mn`, `_N`, `_Nd`, `_Nl`, `_No`, `_P`, `_Pd`, `_Pe`, `_Po`, `_Ps`, `_S`, `_Sc`, `_Sk`, `_So`など）に対応する`RangeTable`のデータ（`R16`および`R32`スライス内の範囲定義）が変更されています。これは、Unicode 7.0.0で追加された新しい文字や、既存の文字のプロパティ変更を反映したものです。

3.  **`src/pkg/strconv/isprint.go`**:
    `strconv.IsPrint`関数が使用する印刷可能文字の範囲を定義する`isPrint16`および`isPrint32`テーブルが更新されています。Unicode 7.0.0で印刷可能と定義された新しい文字が追加されたり、既存の文字の印刷可能性プロパティが変更されたりしたため、これらのテーブルが調整されています。コメントのバイト数計算も更新されており、データ量の増加を示唆しています。

4.  **`src/pkg/regexp/syntax/parse.go`**:
    正規表現の文字折りたたみ（case folding）に関連する`maxFold`定数が`0x1044f`から`0x118df`に更新されています。これは、Unicode 7.0.0で文字折りたたみの対象となる文字の範囲が拡張されたことを反映しています。

5.  **`api/next.txt`**:
    Go 1.xのAPI互換性チェックに使用されるファイルで、`pkg unicode, const Version = "7.0.0"`が追加されています。また、Unicode 7.0.0で追加された新しいスクリプトに対応する`RangeTable`変数（例: `Bassa_Vah`, `Caucasian_Albanian`, `Duployan`など多数）が追加されています。これにより、これらの新しいスクリプトがGoのAPIの一部として認識されるようになります。

6.  **`src/pkg/unicode/script_test.go`**:
    新しいUnicodeスクリプトが追加されたことを検証するためのテストケースが追加されています。これにより、Goの`unicode`パッケージがUnicode 7.0.0で導入された新しいスクリプトを正しく識別できることが保証されます。

このコミットは、Go言語が最新のUnicode標準に追従し、より広範な文字集合と正確な文字プロパティ処理をサポートするための重要なメンテナンス作業です。

## コアとなるコードの解説

`src/pkg/unicode/maketables.go`は、Go言語の`unicode`パッケージが使用する内部データテーブルを生成するためのGoプログラムです。このプログラムは、Unicode Consortiumが公開しているUnicode Character Database (UCD) のテキストファイル（`UnicodeData.txt`や`CaseFolding.txt`など）をダウンロードし、それらをGoのソースコードとしてコンパイル可能な形式（`RangeTable`構造体など）に変換します。

このコミットでは、`maketables.go`内の`url`フラグのデフォルト値が`http://www.unicode.org/Public/6.3.0/ucd/`から`http://www.unicode.org/Public/7.0.0/ucd/`に変更されました。これは、`maketables`ツールがUnicode 6.3.0のデータではなく、Unicode 7.0.0のデータを取得してテーブルを生成するように指示するものです。

この変更がコミットされると、Goのビルドシステムは通常、`go generate`コマンドを実行して`maketables.go`を再実行し、その結果として`src/pkg/unicode/tables.go`が新しいUnicode 7.0.0のデータに基づいて自動的に再生成されます。

`src/pkg/unicode/tables.go`は、Goの`unicode`パッケージが文字のプロパティを判定するために使用するすべての`RangeTable`定義を含んでいます。このファイルは手動で編集されるべきではなく、`maketables.go`によって生成されるものです。このコミットでは、`tables.go`の`Version`定数が`"6.3.0"`から`"7.0.0"`に更新されていることが確認できます。これは、このファイルが実際にUnicode 7.0.0のデータに基づいて生成されたことを示しています。

この一連の変更により、Go言語のランタイムは、Unicode 7.0.0で導入された新しい文字、スクリプト、および文字プロパティの変更を正確に処理できるようになります。これにより、`strconv.IsPrint`のような関数はより多くの印刷可能な文字を正しく認識し、`regexp`パッケージは最新のUnicode文字クラス定義に基づいてより正確なマッチングを行うことができるようになります。

## コアとなるコードの解説

`src/pkg/unicode/maketables.go`は、Go言語の`unicode`パッケージが使用する内部データテーブルを生成するためのGoプログラムです。このプログラムは、Unicode Consortiumが公開しているUnicode Character Database (UCD) のテキストファイル（`UnicodeData.txt`や`CaseFolding.txt`など）をダウンロードし、それらをGoのソースコードとしてコンパイル可能な形式（`RangeTable`構造体など）に変換します。

このコミットでは、`maketables.go`内の`url`フラグのデフォルト値が`http://www.unicode.org/Public/6.3.0/ucd/`から`http://www.unicode.org/Public/7.0.0/ucd/`に変更されました。これは、`maketables`ツールがUnicode 6.3.0のデータではなく、Unicode 7.0.0のデータを取得してテーブルを生成するように指示するものです。

この変更がコミットされると、Goのビルドシステムは通常、`go generate`コマンドを実行して`maketables.go`を再実行し、その結果として`src/pkg/unicode/tables.go`が新しいUnicode 7.0.0のデータに基づいて自動的に再生成されます。

`src/pkg/unicode/tables.go`は、Goの`unicode`パッケージが文字のプロパティを判定するために使用するすべての`RangeTable`定義を含んでいます。このファイルは手動で編集されるべきではなく、`maketables.go`によって生成されるものです。このコミットでは、`tables.go`の`Version`定数が`"6.3.0"`から`"7.0.0"`に更新されていることが確認できます。これは、このファイルが実際にUnicode 7.0.0のデータに基づいて生成されたことを示しています。

この一連の変更により、Go言語のランタイムは、Unicode 7.0.0で導入された新しい文字、スクリプト、および文字プロパティの変更を正確に処理できるようになります。これにより、`strconv.IsPrint`のような関数はより多くの印刷可能な文字を正しく認識し、`regexp`パッケージは最新のUnicode文字クラス定義に基づいてより正確なマッチングを行うことができるようになります。
