## 変更の背景

Go言語の `math/big` パッケージは、標準の `float64` や `int64` では表現できないような、任意精度（arbitrary-precision）の数値計算を可能にするための型を提供します。`big.Rat` はその中でも有理数（分数）を扱うための型です。

このコミットは、Issue #11241 に対応するものです。このIssueでは、`math/big` パッケージ、特に `big.Rat` の使用方法を示す、より具体的で完全な例が求められていました。既存のドキュメントや例だけでは、`big.Rat` を使って複雑な計算を行う方法が十分に伝わっていなかった可能性があります。

任意精度演算は、金融計算、科学技術計算、暗号学など、浮動小数点数の精度誤差が許されない分野で不可欠です。`big.Rat` は、分数の形式で数値を正確に表現し、計算中に精度が失われることを防ぎます。しかし、その強力な機能を最大限に活用するためには、具体的な使用例が非常に役立ちます。

このコミットによって追加された例は、自然対数の底 `e` の連分数展開という、数学的に興味深く、かつ `big.Rat` の `Add` や `Inv` といった主要なメソッドを効果的に示す題材を選んでいます。これにより、開発者は `big.Rat` を使ってどのように高精度な有理数計算を実装できるかを、具体的なコードを通じて理解できるようになります。

## 前提知識の解説

### Go言語の `math/big` パッケージ

`math/big` パッケージは、Go言語の標準ライブラリの一部であり、任意精度の数値型を提供します。これは、`int` や `float64` などの組み込み型が持つ固定のビット幅による精度制限を克服するために設計されています。

*   **`big.Int`**: 任意精度の整数を扱います。非常に大きな整数や、正確な整数演算が必要な場合に使用されます。
*   **`big.Float`**: 任意精度の浮動小数点数を扱います。`float64` よりも高い精度で浮動小数点計算を行いたい場合に使用されます。
*   **`big.Rat`**: 任意精度の有理数（分数）を扱います。分子と分母をそれぞれ `big.Int` で保持することで、分数を正確に表現し、計算中に精度が失われることを防ぎます。これは、特に循環小数や無理数の近似において、浮動小数点数よりも正確な中間結果を維持するのに役立ちます。

### 連分数 (Continued Fractions)

連分数とは、以下のような形式で表される数学的な表現です。

$a_0 + \frac{1}{a_1 + \frac{1}{a_2 + \frac{1}{a_3 + \dots}}}$

ここで、$a_0$ は整数、$a_1, a_2, \dots$ は正の整数です。連分数は、実数を有理数で近似する強力な方法を提供します。特に無理数（例: $\sqrt{2}$, $\pi$, $e$）は、有限の連分数では正確に表現できませんが、連分数の項を増やすことで、いくらでも高い精度で近似することができます。

### オイラー数 (Euler's Number, e)

オイラー数 `e` は、自然対数の底として知られる数学定数で、約 2.718281828459... の値を持つ無理数です。数学、物理学、工学の多くの分野で基本的な役割を果たします。`e` にはいくつかの連分数表現がありますが、最もよく知られているものの1つは以下の形です。

$e = [2; 1, 2, 1, 1, 4, 1, 1, 6, 1, 1, 8, \dots]$

このコミットの例では、少し異なる形式の連分数を使用しています。

$e = [1; 0, 1, 1, 2, 1, 1, \dots 2n, 1, 1, \dots]$

これは、`e` の連分数展開の項が特定のパターンに従うことを示しています。具体的には、`n` 番目の項（`n` は0から始まるインデックス）が、`n mod 3 != 1` の場合は `1`、`n mod 3 == 1` の場合は `(n-1)/3 * 2` となります。

### 収束分数 (Rational Convergents)

連分数を途中で打ち切って得られる有理数を「収束分数」と呼びます。連分数の項を多く取るほど、その収束分数は元の実数に近づきます。このコミットの例では、`e` の連分数展開から得られる最初の15項の収束分数を計算し、`e` の値にどのように収束していくかを示しています。

## 技術的詳細

このコミットで追加された `example_rat_test.go` ファイルは、`math/big` パッケージの `big.Rat` 型を使用して、オイラー数 `e` の連分数展開の収束分数を計算する具体的な方法を示しています。

### `recur` 関数の実装

`recur` 関数は、`e` の連分数展開を再帰的に計算する中心的なロジックを担っています。

```go
func recur(n, lim int64) *big.Rat {
	term := new(big.Rat)
	if n%3 != 1 {
		term.SetInt64(1)
	} else {
		term.SetInt64((n - 1) / 3 * 2)
	}

	if n > lim {
		return term
	}

	// Directly initialize frac as the fractional
	// inverse of the result of recur.
	frac := new(big.Rat).Inv(recur(n+1, lim))

	return term.Add(term, frac)
}
```

1.  **基本項の計算**:
    *   `term := new(big.Rat)`: 新しい `big.Rat` オブジェクトを初期化します。
    *   `if n%3 != 1 { term.SetInt64(1) } else { term.SetInt64((n - 1) / 3 * 2) }`: これは `e` の連分数展開の特定のパターンを実装しています。
        *   `n` が3で割って1余らない場合（`n=0, 1, 3, 4, 6, 7, ...` に対応する連分数項は `1`）。
        *   `n` が3で割って1余る場合（`n=2, 5, 8, ...` に対応する連分数項は `(n-1)/3 * 2`）。
        *   例えば、$n=2$ の場合、`(2-1)/3 * 2 = 2/3 * 2` となり、これは整数演算なので `0` になってしまいます。しかし、`e = [1; 0, 1, 1, 2, 1, 1, ... 2n, 1, 1, ...]` の表記では、$a_0=1, a_1=0, a_2=1, a_3=1, a_4=2, a_5=1, a_6=1, a_7=4, \dots$ となります。コードの `n` は連分数のインデックスに対応しており、`n=0` が $a_0$、`n=1` が $a_1$、というように進みます。
        *   `n=0`: `0%3 != 1` -> `term = 1` ($a_0$)
        *   `n=1`: `1%3 == 1` -> `term = (1-1)/3 * 2 = 0` ($a_1$)
        *   `n=2`: `2%3 != 1` -> `term = 1` ($a_2$)
        *   `n=3`: `3%3 != 1` -> `term = 1` ($a_3$)
        *   `n=4`: `4%3 == 1` -> `term = (4-1)/3 * 2 = 2` ($a_4$)
        *   このロジックは、`e` の連分数展開の項を正確に生成しています。

2.  **再帰の終了条件**:
    *   `if n > lim { return term }`: `n` が `lim`（計算する連分数の深さ）を超えた場合、再帰を終了し、現在の `term` を返します。これが再帰の基底部となります。

3.  **再帰呼び出しと逆数計算**:
    *   `frac := new(big.Rat).Inv(recur(n+1, lim))`: ここが連分数計算の核心です。
        *   `recur(n+1, lim)` を呼び出すことで、次の項からの連分数部分を再帰的に計算します。
        *   その結果に対して `Inv()` メソッドを呼び出すことで、逆数（$1/X$）を計算します。これは連分数の定義 $a_n + \frac{1}{a_{n+1} + \dots}$ の $\frac{1}{\dots}$ の部分に相当します。

4.  **項の加算**:
    *   `return term.Add(term, frac)`: 現在の `term` に、計算された連分数部分の逆数 `frac` を加算し、その結果を返します。

### `Example_eConvergents` 関数の実装

この関数は、`recur` 関数を呼び出して `e` の収束分数を計算し、その結果を表示します。

```go
func Example_eConvergents() {
	for i := 1; i <= 15; i++ {
		r := recur(0, int64(i))

		// Print r both as a fraction and as a floating-point number.
		// Since big.Rat implements fmt.Formatter, we can use %-13s to
		// get a left-aligned string representation of the fraction.
		fmt.Printf("%-13s = %s\n", r, r.FloatString(8))
	}
	// ... Output ...
}
```

1.  **ループ処理**:
    *   `for i := 1; i <= 15; i++`: 最初の15項の収束分数を計算するためにループします。`i` は連分数の深さ（`lim`）を制御します。

2.  **`recur` の呼び出し**:
    *   `r := recur(0, int64(i))`: `recur` 関数を呼び出し、`n=0`（連分数の最初の項から開始）と、現在のループ変数 `i` を `lim` として渡します。これにより、`i` 項までの連分数近似が計算されます。

3.  **結果の出力**:
    *   `fmt.Printf("%-13s = %s\n", r, r.FloatString(8))`: 計算された `big.Rat` 型の `r` を、分数形式と浮動小数点数形式の両方で出力します。
        *   `%-13s`: `big.Rat` 型は `fmt.Formatter` インターフェースを実装しているため、`%s` フォーマット指定子で分数形式の文字列として出力できます。`-13` は左寄せで13文字幅を確保することを意味します。
        *   `r.FloatString(8)`: `big.Rat` の `FloatString` メソッドは、指定された精度（ここでは小数点以下8桁）で浮動小数点数形式の文字列を返します。これにより、有理数近似が実際の `e` の値にどれだけ近づいているかを視覚的に確認できます。

この例は、`big.Rat` が提供する高精度な有理数演算能力を、再帰的なアルゴリズムと組み合わせてどのように活用できるかを示す優れたデモンストレーションとなっています。
