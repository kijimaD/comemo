## 変更の背景

このコミットは、Go 1.5のリリースノート (`doc/go1.5.txt`) に、新たにサポートされた「Darwin/ARM」ポートについて言及するために行われました。Go 1.5は2015年8月19日にリリースされ、このバージョンで `darwin/arm` および `darwin/arm64` の新しいOS/アーキテクチャポートが導入されました。これは、Go言語がAppleのiOSデバイス（iPhoneおよびiPad）をターゲットにすることを可能にする画期的な変更でした。

このポートの追加は、Goモバイルプロジェクトの重要な基盤となりました。Goモバイルプロジェクトは、Go言語を使用してiOSデバイス上でアプリケーションを構築することを目指しており、この `darwin/arm` および `darwin/arm64` ポートのサポートがその実現に不可欠でした。Go 1.5自体には `gomobile` ツールなどのモバイル関連の機能は含まれていませんでしたが、これらの新しいポートと外部リンキング機能が、その後のモバイル開発の道を切り開きました。

## 前提知識の解説

*   **Go言語のクロスコンパイル**: Go言語は、異なるOSやアーキテクチャ向けにバイナリを生成するクロスコンパイル機能を標準でサポートしています。これは、開発者が自身の環境とは異なるターゲット環境向けの実行ファイルを簡単に作成できることを意味します。
*   **Darwin/ARM**: 「Darwin」はAppleのmacOSやiOSの基盤となるオペレーティングシステムカーネルの名称です。「ARM」は、モバイルデバイスで広く使用されているプロセッサアーキテクチャです。したがって、「Darwin/ARM」は、ARMプロセッサを搭載したAppleデバイス（主にiOSデバイス）上で動作するGoプログラムを指します。
*   **Goモバイルプロジェクト (Go mobile)**: Goモバイルプロジェクトは、Go言語でAndroidおよびiOS向けのモバイルアプリケーションを開発するためのツールとライブラリを提供します。これには、GoコードからObjective-C（iOS）やJava（Android）のバインディングを生成する機能などが含まれます。Go 1.5でのDarwin/ARMポートの追加は、このプロジェクトの実現に向けた重要なステップでした。
*   **リリースノート**: ソフトウェアの新しいバージョンがリリースされる際に、そのバージョンで導入された新機能、改善点、バグ修正、非推奨になった機能などをまとめた文書です。開発者やユーザーが新しいバージョンの変更点を理解するために非常に重要です。

## 技術的詳細

このコミット自体は、Go言語のコンパイラやランタイムに直接的なコード変更を加えるものではなく、Go 1.5のリリースノートというドキュメントファイル (`doc/go1.5.txt`) の更新です。しかし、このドキュメントの変更が示唆する技術的な意味合いは非常に大きいです。

Go 1.5でDarwin/ARMポートが追加されたことは、GoランタイムがARMアーキテクチャ上のDarwinカーネルと適切に連携できるように、低レベルのシステムコール、メモリ管理、スケジューリングなどの部分で多くの変更が加えられたことを意味します。具体的には、以下の点が挙げられます。

1.  **システムコールラッパー**: Goランタイムは、OSの機能を利用するためにシステムコールを直接呼び出します。Darwin/ARM環境でこれらのシステムコールが正しく機能するように、適切なラッパーやアセンブリコードが実装されました。
2.  **ABI (Application Binary Interface) の適合**: ARMアーキテクチャにおける関数呼び出し規約やデータ構造の配置など、ABIにGoランタイムが適合するように調整されました。これにより、GoコードがC/Objective-Cコードと相互運用できるようになります。
3.  **ガベージコレクタ (GC) の調整**: Goのガベージコレクタは、特定のアーキテクチャやOSのメモリ管理特性に合わせて最適化されることがあります。Darwin/ARM環境での効率的なGC動作のために、必要な調整が行われた可能性があります。
4.  **外部リンキングの改善**: iOSアプリケーションは通常、Objective-CやSwiftで書かれており、Goコードをこれらのアプリケーションに組み込むためには、外部リンキングの機能が重要になります。Go 1.5では、この外部リンキングの機能が強化され、Goコードを共有ライブラリとしてビルドし、既存のiOSアプリケーションから呼び出すことが容易になりました。
5.  **ツールチェインのサポート**: `go build` コマンドが `GOOS=darwin` および `GOARCH=arm` または `arm64` を指定してビルドできるよう、コンパイラ、リンカ、アセンブラなどのツールチェインが更新されました。

このコミットは、これらの広範な技術的変更が完了し、Go 1.5の重要な新機能として公式にアナウンスされる準備ができたことを示しています。

## コアとなるコードの解説

変更は非常にシンプルで、`doc/go1.5.txt` ファイルに以下の3行が追加されています。

```
+New Ports:
+Darwin/ARM, a.k.a iOS. (https://golang.org/cl/2118, 2119, 3273, 2121, 2122, ..., 2127)
+
```

*   `New Ports:`: 新しくサポートされたプラットフォームのセクションを開始します。
*   `Darwin/ARM, a.k.a iOS.`: 新しいポートがDarwin/ARMであり、それがiOSとしても知られていることを明記しています。
*   `(https://golang.org/cl/2118, 2119, 3273, 2121, 2122, ..., 2127)`: これは、Darwin/ARMポートの実装に関連する一連の変更リスト（Change List, CL）へのリンクです。これらのCLは、実際にGoランタイムがDarwin/ARM上で動作するようにするための具体的なコード変更を含んでいます。このコミットは、これらの基盤となる変更が完了したことを受けて、リリースノートにその成果を反映させるためのものです。
