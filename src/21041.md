# [インデックス 21041] ファイルの概要

このコミットは、Go言語の`crypto/x509`パッケージにおいて、Solaris 11.2以降のシステムにおけるルート証明書の検索パスを追加するものです。これにより、Solaris環境でGoアプリケーションがHTTPS通信などを行う際に、システムにインストールされている信頼されたルート証明書を正しく利用できるようになります。

## 元コミット内容

`crypto/x509: add Solaris certificate file location`

このコミットは、Go言語の標準ライブラリである`crypto/x509`パッケージに、Solarisオペレーティングシステムにおける証明書ファイルの新しい場所を追加します。これは、Issue #9078を解決するためのものです。

## 変更の背景

Go言語の`crypto/x509`パッケージは、TLS/SSL通信などにおいて、サーバー証明書の検証やクライアント証明書の生成など、X.509証明書に関する機能を提供します。これらの機能が正しく動作するためには、システムに信頼されたルート証明書（CA証明書）がどこに保存されているかをGoランタイムが知っている必要があります。

多くのUnix系システムでは、ルート証明書は特定の標準的なパスに保存されています。しかし、オペレーティングシステムの種類やバージョンによって、そのパスは異なります。Goの`crypto/x509`パッケージは、これらの一般的なパスをリストとして保持し、順に検索することでルート証明書バンドルを見つけ出します。

このコミットが行われる前は、Goの`crypto/x509`パッケージはSolaris 11.2以降のバージョンで採用されている新しい証明書パスを認識していませんでした。その結果、Solaris 11.2以降の環境でGoアプリケーションがHTTPS通信などを行う際に、システムにインストールされている信頼されたルート証明書を見つけられず、証明書検証エラーが発生する可能性がありました。

Issue #9078は、この問題を具体的に報告しており、Solaris 11.2以降のシステムで`go get`コマンドがHTTPS経由でリポジトリからパッケージを取得できないという問題が挙げられていました。このコミットは、この互換性の問題を解決し、GoアプリケーションがSolaris環境でよりスムーズに動作するようにするために導入されました。

## 前提知識の解説

### X.509証明書とPKI

X.509は、公開鍵証明書の標準フォーマットを定義するITU-Tの標準です。これは公開鍵基盤（PKI）の重要な要素であり、インターネット上での身元確認やデータの暗号化、デジタル署名などに広く利用されています。X.509証明書には、公開鍵、所有者の識別情報、発行者（認証局、CA）の識別情報、有効期間、発行者のデジタル署名などが含まれます。

### ルート証明書と認証局（CA）

認証局（CA）は、デジタル証明書を発行し、その証明書に署名することで、公開鍵と所有者の身元を結びつける信頼された第三者機関です。ルート認証局は、自己署名証明書を持つ最上位のCAであり、その証明書は「ルート証明書」と呼ばれます。

クライアント（WebブラウザやGoアプリケーションなど）がサーバーから受け取った証明書を検証する際、その証明書が信頼できるCAによって署名されているかを確認します。この検証プロセスは、証明書チェーンをたどり、最終的に信頼されたルート証明書に到達することで完了します。もし、証明書チェーンのどこかに信頼できないCAが含まれていたり、最終的に信頼されたルート証明書に到達できなかったりすると、検証は失敗します。

### システムのルート証明書ストア

オペレーティングシステムは、信頼されたルート証明書のコレクションを管理しています。これは「ルート証明書ストア」または「トラストストア」と呼ばれます。アプリケーションは、このストアに保存されている証明書を利用して、通信相手の身元を検証します。

Unix系システムでは、これらの証明書は通常、特定のディレクトリに個別のファイルとして保存されているか、または単一のファイルに連結されて保存されています。一般的なパスとしては、`/etc/ssl/certs/ca-certificates.crt`、`/etc/pki/tls/certs/ca-bundle.crt`、`/usr/share/ca-certificates/cacert.pem`などがあります。

### Go言語の`crypto/x509`パッケージ

Go言語の`crypto/x509`パッケージは、X.509証明書の解析、生成、検証、および証明書署名要求（CSR）の処理など、証明書関連の低レベルな機能を提供します。特に、TLS/SSL通信を行う際には、このパッケージが内部的に利用され、サーバー証明書の検証などが行われます。

Goアプリケーションがシステムにインストールされているルート証明書を利用するためには、`crypto/x509`パッケージがこれらの証明書ファイルがどこにあるかを知っている必要があります。Goは、内部的に定義された一般的なパスのリストを順にチェックし、最初に見つかった有効な証明書バンドルをロードしようとします。

### Solarisオペレーティングシステム

Solarisは、Sun Microsystems（現在はOracleが所有）によって開発されたUnix系オペレーティングシステムです。特にエンタープライズ環境で利用されてきました。Solaris 11.2は、2014年にリリースされたバージョンであり、システム構成やファイルパスに一部変更がありました。この変更が、Goの証明書検索パスに影響を与えたと考えられます。

## 技術的詳細

Goの`crypto/x509`パッケージは、Unix系システムにおいて、信頼されたルート証明書をロードするために、`certFiles`という文字列スライス（配列）に定義されたパスを順に試行します。このスライスには、様々なLinuxディストリビューションやBSD系システムで一般的に使用される証明書ファイルのパスが含まれています。

このコミットは、この`certFiles`スライスに、Solaris 11.2以降のシステムで利用される新しいパス`/etc/certs/ca-certificates.crt`を追加します。

Goの内部実装では、`loadSystemRoots`関数（またはそれに相当する関数）が、この`certFiles`リストをイテレートし、各パスのファイルを読み込もうとします。ファイルが見つかり、有効な証明書データが含まれていれば、そのデータがルート証明書プールに追加され、それ以降の証明書検証に使用されます。

この変更により、Solaris 11.2以降のシステムでGoアプリケーションが起動されると、`crypto/x509`パッケージは既存のパスに加えて`/etc/certs/ca-certificates.crt`もチェックするようになります。これにより、Solarisシステムがこのパスにルート証明書を保存している場合でも、Goアプリケーションがそれらを自動的に発見し、利用できるようになります。

これは、Goアプリケーションのクロスプラットフォーム互換性を向上させるための重要な変更であり、特にエンタープライズ環境でSolarisを利用しているユーザーにとっては、Goアプリケーションのデプロイと運用がより容易になります。

## コアとなるコードの解説

変更は、`src/crypto/x509/root_unix.go`ファイル内の`certFiles`という文字列スライスに対して行われています。

元のコードでは、`certFiles`スライスは以下のパスを含んでいました（関連部分のみ抜粋）：

```go
var certFiles = []string{
	"/etc/ssl/cert.pem",                      // OpenBSD
	"/usr/local/share/certs/ca-root-nss.crt", // FreeBSD/DragonFly
	"/etc/pki/tls/cacert.pem",                // OpenELEC
}
```

このコミットによって、以下の行が追加されました。

```go
	"/etc/certs/ca-certificates.crt",         // Solaris 11.2+
```

この追加により、`certFiles`スライスは以下のようになります（変更後の関連部分）：

```go
var certFiles = []string{
	"/etc/ssl/cert.pem",                      // OpenBSD
	"/usr/local/share/certs/ca-root-nss.crt", // FreeBSD/DragonFly
	"/etc/pki/tls/cacert.pem",                // OpenELEC
	"/etc/certs/ca-certificates.crt",         // Solaris 11.2+
}
```

この変更は非常にシンプルですが、その影響は大きいです。Goランタイムがルート証明書を検索する際に、この新しいパスも探索対象に加わるため、Solaris 11.2以降のシステムで標準的に証明書が配置される場所をGoが認識できるようになります。これにより、GoアプリケーションはSolaris環境下で、システムが信頼するCA証明書を利用して、HTTPS通信などのセキュリティ関連操作を正しく実行できるようになります。

コメント`// Solaris 11.2+`は、このパスがどのオペレーティングシステムのどのバージョンに対応しているかを示しており、コードの可読性と保守性を高めています。
