## 元コミット内容

`crypto/x509: ParsePKCS8PrivateKey ドキュメント内の破損したリンクを削除`

このコミットは、`ParsePKCS8PrivateKey`関数のドキュメントに含まれていた、PKCS#8プライベートキーに関する参照リンクが機能していなかった問題を修正します。具体的には、`http://www.rsa.com/rsalabs/node.asp?id=2130`というリンクを削除し、代わりにPKCS#8の標準を定義するRFC 5208への参照に置き換えています。

## 変更の背景

Go言語の`crypto/x509`パッケージは、X.509証明書やPKCS#8プライベートキーなどの暗号関連の標準を扱うための機能を提供します。`ParsePKCS8PrivateKey`関数は、PKCS#8形式でエンコードされた暗号化されていないプライベートキーを解析するために使用されます。

この関数のドキュメントには、PKCS#8に関する詳細情報を提供する目的で、RSA Laboratoriesのウェブサイトへのリンクが含まれていました。しかし、時間の経過とともにこのリンクが破損し、もはや有効な情報源として機能しなくなっていました。

開発者がこのドキュメントを参照した際に、破損したリンクによって適切な情報にアクセスできないという問題が発生していました（Issue #14776）。このコミットは、このユーザビリティの問題を解決し、ドキュメントの正確性と信頼性を向上させることを目的としています。

## 前提知識の解説

### PKCS#8 (Public-Key Cryptography Standards #8)

PKCS#8は、公開鍵暗号標準（Public-Key Cryptography Standards）の一つで、プライベートキー情報を格納するための標準的な構文を定義しています。これには、公開鍵アルゴリズムのプライベートキーと、関連する属性のセットが含まれる場合があります。

*   **目的**: RSAやECC（楕円曲線暗号）などの非対称プライベートキーを、ストレージや交換のために標準化された方法でエンコードすることを提供します。
*   **内容**: PKCS#8プライベートキーは、平文で保存することも、パスフレーズで暗号化して保存することもできます。プライベートキー情報には、プライベートキー自体と、プライベートキーアルゴリズムおよび関連するパラメータを指定するアルゴリズム識別子が含まれます。
*   **エンコード**: PKCS#8プライベートキーは通常、PEM（Base64エンコード）形式で交換されます。これは、ASN.1ベースのバイナリ形式のテキスト表現です。暗号化されていないPKCS#8キーは通常`-----BEGIN PRIVATE KEY-----`で始まり、暗号化されたキーは`-----BEGIN ENCRYPTED PRIVATE KEY-----`で始まります。

### RFC 5208

RFC 5208は、「Public-Key Cryptography Standards (PKCS) #8: Private-Key Information Syntax Specification Version 1.2」というタイトルで、PKCS#8の仕様を定義するインターネット標準です。このRFCは、プライベートキー情報の構文を詳細に記述しており、PKCS#8形式のプライベートキーを実装および解析する際の規範となります。

元のドキュメントが参照していたRSA Laboratoriesのリンクは、PKCS#8に関する情報を提供していましたが、RFC 5208はより公式かつ安定した標準ドキュメントであり、技術的な詳細を正確に記述しています。

### ASN.1 (Abstract Syntax Notation One)

ASN.1は、データ構造を記述するための標準的な記法です。暗号化やネットワークプロトコルにおいて、異なるシステム間でデータを交換する際に、データの形式を明確に定義するために広く使用されます。PKCS#8もASN.1を使用してプライベートキー情報の構造を定義しています。Go言語の`asn1`パッケージは、このASN.1形式のデータをエンコードおよびデコードするための機能を提供します。

## 技術的詳細

`ParsePKCS8PrivateKey`関数は、DER（Distinguished Encoding Rules）エンコードされたPKCS#8プライベートキーのバイトスライスを入力として受け取り、対応するGoの`interface{}`型（通常は`*rsa.PrivateKey`や`*ecdsa.PrivateKey`など）とエラーを返します。

この関数は内部的に、入力されたDERバイトスライスをASN.1で定義された`pkcs8`構造体にアンマーシャル（デコード）します。`pkcs8`構造体は、プライベートキーのアルゴリズム識別子と、実際のプライベートキーデータを含んでいます。

変更前は、ドキュメントに以下の記述がありました。

```go
// ParsePKCS8PrivateKey parses an unencrypted, PKCS#8 private key. See
// http://www.rsa.com/rsalabs/node.asp?id=2130 and RFC5208.
```

このコミットでは、`http://www.rsa.com/rsalabs/node.asp?id=2130`という破損したリンクを削除し、より簡潔かつ正確な参照に修正しています。

```go
// ParsePKCS8PrivateKey parses an unencrypted, PKCS#8 private key.
// See RFC 5208.
```

これにより、ドキュメントの参照先がRFC 5208に一本化され、開発者はPKCS#8の公式な仕様を直接参照できるようになります。

## コアとなるコードの解説

変更されたのは、`ParsePKCS8PrivateKey`関数のGoDocコメントのみです。この関数自体のロジックには一切変更はありません。

`ParsePKCS8PrivateKey`関数は、PKCS#8形式のプライベートキーを解析するGo言語の標準ライブラリ関数です。この関数は、暗号化されていないPKCS#8プライベートキーのDERエンコードされたバイトスライスを受け取り、それをGoの適切なプライベートキー型（例: `*rsa.PrivateKey`, `*ecdsa.PrivateKey`）に変換します。

コメントの変更は、この関数の利用者がPKCS#8の仕様についてさらに深く理解したい場合に参照すべき情報源を、より正確で信頼性の高いものに更新することを目的としています。破損したリンクを削除し、RFC 5208のみを参照することで、ドキュメントの品質が向上し、開発者の利便性が高まります。
