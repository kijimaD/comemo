## 前提知識の解説

### `math/big`パッケージ

`math/big`パッケージは、Go言語において任意精度の数値演算を提供する標準ライブラリです。Goの組み込み整数型（`int`, `int64`など）は固定のビット幅を持つため、非常に大きな数や非常に小さな数を正確に表現するには限界があります。`math/big`パッケージは、`big.Int`（任意精度整数）、`big.Float`（任意精度浮動小数点数）、`big.Rat`（任意精度有理数）といった型を提供し、これらの制限を克服します。これにより、暗号学、科学計算、金融アプリケーションなど、高い精度と大きな数値範囲が要求される分野でのGo言語の利用が拡大します。

### ヤコビ記号 (Jacobi Symbol)

ヤコビ記号 `(a/n)` は、数論における概念で、ルジャンドル記号の一般化です。ルジャンドル記号 `(a/p)` は、`p` が奇素数の場合に、`a` が `p` を法とする平方剰余であるかどうか（つまり、`x^2 ≡ a (mod p)` となる `x` が存在するかどうか）を判定するために用いられます。ヤコビ記号は、`n` が奇数であれば合成数であっても定義されます。

**定義:**
`n` を奇数、`n = p_1^{e_1} p_2^{e_2} ... p_k^{e_k}` を `n` の素因数分解とするとき、ヤコビ記号 `(a/n)` は次のように定義されます。
`(a/n) = (a/p_1)^{e_1} (a/p_2)^{e_2} ... (a/p_k)^{e_k}`
ここで `(a/p_i)` はルジャンドル記号です。

**性質:**
ヤコビ記号は、ルジャンドル記号と同様に以下の性質を持ちます。
*   `a ≡ b (mod n)` ならば `(a/n) = (b/n)`
*   `(ab/n) = (a/n)(b/n)`
*   `(a/mn) = (a/m)(a/n)`
*   `(1/n) = 1`
*   `(-1/n) = (-1)^{(n-1)/2}`
*   `(2/n) = (-1)^{(n^2-1)/8}`
*   **平方剰余の相互法則 (Quadratic Reciprocity Law):** `m` と `n` が異なる奇素数であるとき、`(m/n)(n/m) = (-1)^{((m-1)/2)((n-1)/2)}`。ヤコビ記号はこの法則を合成数に拡張します。

**応用:**
ヤコビ記号は、素数判定（特にSolovay-Strassen素数判定法）、暗号学（例: Goldwasser-Micali暗号システム）など、様々な分野で利用されます。

### モジュラ平方根 (Modular Square Root)

モジュラ平方根とは、与えられた整数 `a` と法 `n` に対して、合同式 `x^2 ≡ a (mod n)` を満たす整数 `x` を求める問題です。このような `x` が存在する場合、`a` は `n` を法とする平方剰余（quadratic residue）と呼ばれ、`x` は `a` のモジュラ平方根と呼ばれます。

**例:**
`x^2 ≡ 5 (mod 11)` を解くと、`x = 4` または `x = 7` です。なぜなら、`4^2 = 16 ≡ 5 (mod 11)` および `7^2 = 49 ≡ 5 (mod 11)` だからです。

**重要性:**
モジュラ平方根の計算は、公開鍵暗号システム（例: RSA暗号の復号の一部、楕円曲線暗号における点のスカラー倍算の一部）や、乱数生成、数論的アルゴリズムにおいて重要な役割を果たします。特に、法が素数である場合のモジュラ平方根の計算は、Tonelli-Shanksアルゴリズムなどの効率的なアルゴリズムが存在します。

## 技術的詳細

`math/big`パッケージに`Jacobi`関数と`Int.ModSqrt`メソッドが追加されたことで、Go言語は数論的な計算においてより強力なツールを提供できるようになりました。

### `big.Jacobi(x, y *Int)`

この関数は、`big.Int`型の `x` と `y` を引数として取り、ヤコビ記号 `(x/y)` を計算します。戻り値は `int` 型で、`+1`, `-1`, または `0` のいずれかです。
重要な制約として、引数 `y` は**奇数**でなければなりません。この制約はヤコビ記号の数学的定義に由来します。`y` が偶数の場合、ヤコビ記号は定義されません。

この関数の内部実装は、ヤコビ記号の性質（特に平方剰余の相互法則）を利用して、再帰的または反復的に計算されます。これにより、大きな数に対しても効率的にヤコビ記号を求めることが可能になります。

### `(*Int).ModSqrt(x, p *Int)`

このメソッドは、`big.Int`型のレシーバ `z` に対して、`x` の `p` を法とするモジュラ平方根を計算し、結果を `z` に設定して `z` を返します。もし `x` が `p` を法とする平方剰余でない場合（つまり、モジュラ平方根が存在しない場合）、メソッドは `nil` を返し、`z` は変更されません。

このメソッドの重要な制約は、法 `p` が**奇素数**でなければならない点です。`p` が奇数でない場合、または素数でない場合の動作は未定義であるか、パニックを引き起こす可能性があります。これは、モジュラ平方根を効率的に計算するための多くのアルゴリズム（例: Tonelli-Shanksアルゴリズム）が、法が素数であるという前提に基づいているためです。

`ModSqrt`の実装は、通常、Tonelli-Shanksアルゴリズムや、より単純なケース（例: `p ≡ 3 (mod 4)` の場合）ではフェルマーの小定理に基づく方法が用いられます。これらのアルゴリズムは、数論的な性質を利用して、指数計算や逆元計算を効率的に行い、モジュラ平方根を導き出します。

### 意義

これらの機能が`math/big`パッケージに追加されたことは、Go言語で以下のタスクをより容易かつ効率的に実装できることを意味します。
*   **暗号学**: 楕円曲線暗号、RSA暗号、ゼロ知識証明など、数論的性質に深く依存する暗号アルゴリズムの実装。特に、モジュラ平方根は楕円曲線上の点の圧縮表現の復元などに利用されます。
*   **数論的アルゴリズム**: 素数判定、因数分解アルゴリズム、その他の数論研究。
*   **分散システムとブロックチェーン**: 暗号学的ハッシュ関数やデジタル署名の検証など、セキュリティと整合性を保証するための基盤技術。

このコミット自体はドキュメントの更新ですが、それが指し示す機能追加は、Go言語の数値計算能力を大幅に拡張し、より高度な数学的・暗号学的アプリケーションの開発を可能にする重要なマイルストーンでした。
