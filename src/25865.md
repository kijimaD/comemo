## 前提知識の解説

このコミットの変更内容を理解するためには、以下のGo言語の基本的なI/Oインターフェースと概念を理解しておく必要があります。

1.  **`io.Reader`インターフェース**:
    *   `Read(p []byte) (n int, err error)`というメソッドを持つインターフェースです。
    *   データソースからバイト列を読み込む操作を抽象化します。ファイル、ネットワーク接続、メモリ上のデータなど、様々なデータソースが`io.Reader`として扱えます。
    *   `n`は読み込んだバイト数、`err`はエラー（EOFを含む）を示します。

2.  **`io.Writer`インターフェース**:
    *   `Write(p []byte) (n int, err error)`というメソッドを持つインターフェースです。
    *   データシンクへバイト列を書き込む操作を抽象化します。ファイル、ネットワーク接続、メモリ上のバッファなど、様々なデータシンクが`io.Writer`として扱えます。
    *   `n`は書き込んだバイト数、`err`はエラーを示します。

3.  **`io.Seeker`インターフェース**:
    *   `Seek(offset int64, whence int) (int64, error)`というメソッドを持つインターフェースです。
    *   データストリーム内の現在位置を変更する操作を抽象化します。`whence`は`io.SeekStart`（ファイルの先頭から）、`io.SeekCurrent`（現在位置から）、`io.SeekEnd`（ファイルの末尾から）のいずれかを指定します。

4.  **`Example`関数**:
    *   Goのテストファイル（`_test.go`で終わるファイル）内に記述される特別な関数です。
    *   `func ExampleFunctionName() { ... }`または`func ExampleType_MethodName() { ... }`のような命名規則に従います。
    *   関数内の`// Output:`コメントに続く文字列は、その例を実行した際の標準出力と一致する必要があります。Goのテストツールは、この出力が一致するかどうかを検証します。
    *   `go doc`コマンドでパッケージや関数のドキュメントを表示する際に、これらの例も一緒に表示されます。

5.  **`bytes.Buffer`**:
    *   バイト列をメモリ上で効率的に操作するための可変バッファです。`io.Reader`と`io.Writer`インターフェースを実装しています。

6.  **`strings.NewReader`**:
    *   文字列を`io.Reader`インターフェースとして扱うためのヘルパー関数です。

## 技術的詳細

このコミットで追加された各`Example`関数は、`io`パッケージの特定の機能の具体的な使い方を示しています。以下に、それぞれの例が示す技術的なポイントを詳述します。

### `ExampleCopy()`

-   **機能**: `io.Copy(dst io.Writer, src io.Reader)`は、`src`から`dst`へデータをコピーします。内部的にはバッファを使用して効率的にコピーを行います。
-   **例のポイント**: `strings.NewReader`で作成した文字列リーダーから`os.Stdout`（標準出力）へデータをコピーしています。これにより、文字列の内容がコンソールに出力されることを示します。

### `ExampleCopyBuffer()`

-   **機能**: `io.CopyBuffer(dst io.Writer, src io.Reader, buf []byte)`は`io.Copy`と同様にデータをコピーしますが、コピーに使用するバッファを呼び出し元が指定できます。これにより、バッファの再利用が可能になり、メモリ割り当てを削減できます。
-   **例のポイント**: `r1`と`r2`という2つの異なるリーダーから`os.Stdout`へデータをコピーする際に、同じ`buf`スライスを再利用しています。これは、特にループ内で大量のコピー操作を行う場合に、GCの負荷を軽減しパフォーマンスを向上させるための一般的なパターンです。

### `ExampleCopyN()`

-   **機能**: `io.CopyN(dst io.Writer, src io.Reader, n int64)`は、`src`から`dst`へ最大`n`バイトのデータをコピーします。`n`バイトに達する前に`src`がEOFになった場合、その時点でコピーを終了します。
-   **例のポイント**: `strings.NewReader`から作成したリーダーから、最初の5バイトだけを`os.Stdout`にコピーしています。これにより、指定したバイト数だけをコピーする挙動を示します。

### `ExampleReadAtLeast()`

-   **機能**: `io.ReadAtLeast(r io.Reader, buf []byte, min int)`は、`r`から`buf`に少なくとも`min`バイトを読み込もうとします。`min`バイト未満しか読み込めなかった場合、エラーを返します。
-   **例のポイント**:
    *   最初のケースでは、十分なサイズのバッファと`min`値で成功する例を示します。
    *   2番目のケースでは、`buf`が`min`よりも小さい場合に`io.ErrShortBuffer`エラーが発生することを示します。
    *   3番目のケースでは、リーダーの残りのデータが`min`よりも少ない場合に`io.EOF`エラーが発生することを示します。

### `ExampleReadFull()`

-   **機能**: `io.ReadFull(r io.Reader, buf []byte)`は、`r`から`buf`の長さと等しいバイト数を読み込もうとします。`buf`が完全に満たされない場合、エラーを返します。これは`io.ReadAtLeast(r, buf, len(buf))`と等価です。
-   **例のポイント**:
    *   最初のケースでは、`buf`のサイズ（4バイト）だけを読み込み、成功する例を示します。
    *   2番目のケースでは、リーダーの残りのデータが`buf`のサイズよりも少ない場合に`io.ErrUnexpectedEOF`エラーが発生することを示します。

### `ExampleWriteString()`

-   **機能**: `io.WriteString(w io.Writer, s string)`は、文字列`s`を`w`に書き込みます。`w`が`io.StringWriter`インターフェースを実装している場合、その`WriteString`メソッドが直接呼び出され、より効率的な書き込みが行われます。
-   **例のポイント**: `os.Stdout`に直接文字列を書き込んでいます。これは、`fmt.Print`などを使用するよりも、`io.Writer`に文字列を書き込むためのより直接的な方法です。

### `ExampleLimitReader()`

-   **機能**: `io.LimitReader(r io.Reader, n int64)`は、基になる`r`から最大`n`バイトまでしか読み込まない`io.Reader`を返します。`n`バイトを読み込んだ後、それ以降の`Read`呼び出しは`EOF`を返します。
-   **例のポイント**: `strings.NewReader`から作成したリーダーを`io.LimitReader`でラップし、読み込みバイト数を4バイトに制限しています。その後、`io.Copy`でその制限されたリーダーから`os.Stdout`へコピーすることで、最初の4バイトのみが出力されることを示します。

### `ExampleMultiReader()`

-   **機能**: `io.MultiReader(readers ...io.Reader)`は、複数の`io.Reader`を連結し、それらを単一の`io.Reader`として扱えるようにします。最初のリーダーがEOFに達すると、次のリーダーから読み込みを開始します。
-   **例のポイント**: 3つの異なる`strings.NewReader`を`io.MultiReader`で結合し、その結果を`io.Copy`で`os.Stdout`へ出力しています。これにより、複数のソースからのデータが順番に読み込まれ、結合されて出力されることを示します。

### `ExampleTeeReader()`

-   **機能**: `io.TeeReader(r io.Reader, w io.Writer)`は、`r`から読み込んだデータを`w`にも同時に書き込む`io.Reader`を返します。これは、データを読み込みながら、そのデータを別の場所（例えばログファイルや別のバッファ）にも複製したい場合に便利です。
-   **例のポイント**: `strings.NewReader`から読み込みながら、そのデータを`bytes.Buffer`にも書き込む`io.TeeReader`を作成しています。その後、`TeeReader`から読み込んだデータと、`bytes.Buffer`に書き込まれたデータが同じであることを示しています。

### `ExampleSectionReader()`

-   **機能**: `io.NewSectionReader(r io.ReaderAt, off int64, n int64)`は、基になる`io.ReaderAt`から指定されたオフセット`off`から`n`バイトの範囲だけを読み込む`io.Reader`および`io.Seeker`を返します。
-   **例のポイント**: `strings.NewReader`を基に、オフセット5から17バイトのセクションリーダーを作成し、そのセクションの内容を`io.Copy`で出力しています。これにより、元のリーダーの一部だけを読み込む方法を示します。

### `ExampleSectionReader_ReadAt()`

-   **機能**: `SectionReader`の`ReadAt(p []byte, off int64) (n int, err error)`メソッドは、セクションの開始位置からの相対オフセット`off`からデータを読み込みます。
-   **例のポイント**: `SectionReader`を作成した後、そのセクション内の相対オフセット10から6バイトを読み込んでいます。これは、セクション内の特定の位置から直接データを読み取る機能を示します。

### `ExampleSectionReader_Seek()`

-   **機能**: `SectionReader`の`Seek(offset int64, whence int) (int64, error)`メソッドは、セクションの開始位置からの相対オフセットで読み取り位置を変更します。
-   **例のポイント**: `SectionReader`を作成した後、`Seek`メソッドでセクション内の相対オフセット10に移動し、その後`Read`で6バイトを読み込んでいます。これは、セクション内でシーケンシャルな読み取り位置を操作する方法を示します。

### `ExampleMultiWriter()`

-   **機能**: `io.MultiWriter(writers ...io.Writer)`は、複数の`io.Writer`を連結し、それらを単一の`io.Writer`として扱えるようにします。この`MultiWriter`に書き込まれたデータは、内部のすべての`Writer`に同時に書き込まれます。
-   **例のポイント**: 2つの`bytes.Buffer`を`io.MultiWriter`で結合し、その結果を`io.Copy`で`strings.NewReader`からコピーしています。これにより、1つの書き込み操作で複数の宛先にデータを同時に送る方法を示します。

## コアとなるコードの解説

追加された`example_test.go`ファイルは、`io_test`パッケージに属しています。これは、`io`パッケージの内部実装に依存せず、公開されているAPIのみを使用して例を作成していることを意味します。これにより、ユーザーが自身のコードで`io`パッケージを利用する際と同じ視点から、これらの例を理解できます。

各`Example`関数は、以下の共通パターンに従っています。

1.  **データソースの準備**: `strings.NewReader`や`bytes.Buffer`などを使用して、`io.Reader`または`io.Writer`のインスタンスを準備します。これにより、実際のファイルやネットワーク接続を必要とせずに、I/O操作をシミュレートできます。
2.  **`io`関数の呼び出し**: テスト対象の`io`パッケージの関数を呼び出し、準備したデータソースとシンクを渡します。
3.  **結果の検証/出力**: `fmt.Printf`や`io.Copy`などを使用して、操作の結果を標準出力に出力します。
4.  **`// Output:`コメント**: 期待される出力結果を`// Output:`コメントの後に記述します。Goのテストツールは、このコメントと実際のプログラムの標準出力を比較し、一致しない場合はテストを失敗させます。これにより、例が常に正しく動作することが保証されます。
5.  **エラーハンドリング**: 各例では、`log.Fatal(err)`や`fmt.Println("error:", err)`を使用して、発生しうるエラーを適切に処理しています。これは、実際のアプリケーション開発におけるベストプラクティスを示しています。

これらの例は、`io`パッケージの多様な機能を、簡潔かつ実践的な方法で示しており、GoのI/O処理の学習とデバッグに大いに貢献します。
