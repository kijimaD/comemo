## 変更の背景

Go言語では、パッケージのドキュメントと使用例は、そのパッケージの理解と利用を促進する上で非常に重要な役割を果たします。特に、`godoc`ツールによって生成されるドキュメントは、コードと密接に連携しており、`Example`関数は実際のコードスニペットとして表示され、テストとしても実行されます。

このコミットの背景には、`strconv`パッケージの利用方法をより明確にし、開発者が一般的な変換操作をどのように行うべきかを具体的に示す必要があったと考えられます。以前は、`strconv`パッケージの機能に関する詳細な説明や、各関数の具体的な使用例が不足していた可能性があります。特に、`quote_example_test.go`という個別のファイルに一部の例が分散していた状況を、より包括的な`example_test.go`に統合することで、ドキュメントの一貫性と発見しやすさを向上させる意図があったと推測されます。

`doc.go`ファイルの追加は、パッケージ全体の目的と主要な機能（数値変換と文字列変換）を簡潔にまとめることで、パッケージの入り口としての役割を果たすことを目的としています。これにより、ユーザーはパッケージの全体像を素早く把握し、必要な機能へと導かれるようになります。

## 前提知識の解説

### Go言語の`strconv`パッケージ

`strconv`パッケージは、Go言語の標準ライブラリの一部であり、基本的なデータ型（整数、浮動小数点数、真偽値など）と文字列表現との間の変換を提供します。例えば、文字列を整数に変換する`Atoi`、整数を文字列に変換する`Itoa`、浮動小数点数を文字列に変換する`FormatFloat`、文字列を浮動小数点数に変換する`ParseFloat`など、多岐にわたる機能が含まれています。これらの関数は、ユーザー入力の処理、設定ファイルの解析、データのエクスポート/インポートなど、多くのアプリケーションで不可欠です。

### Go言語の`Example`関数と`godoc`

Go言語では、`Example`関数はパッケージの使用方法を示すための特別な関数です。これらの関数は、`_test.go`ファイル内に記述され、`Example`というプレフィックスを持ちます。`godoc`ツールがドキュメントを生成する際に、これらの`Example`関数を抽出し、パッケージのドキュメントにコードスニペットとして表示します。さらに重要なのは、`go test`コマンドを実行すると、これらの`Example`関数もテストとして実行され、`// Output:`コメントに記述された期待される出力と実際の出力が一致するかどうかが検証される点です。これにより、ドキュメントのコード例が常に最新かつ正確であることが保証されます。

### `doc.go`ファイル

Go言語のパッケージでは、`doc.go`という名前のファイルにパッケージ全体のドキュメンテーションコメントを記述することが慣例となっています。このファイルは、パッケージの目的、主要な機能、使用上の注意点などを説明するために使用され、`godoc`によってパッケージのトップレベルのドキュメントとして表示されます。

## コアとなるコードの解説

### `src/strconv/doc.go`

このファイルは、`strconv`パッケージの公式ドキュメントの冒頭部分を形成します。パッケージの目的を簡潔に説明し、主要な機能である「数値変換」と「文字列変換」の2つのセクションに分けて解説しています。

*   **数値変換**:
    *   `Atoi`と`Itoa`が最も一般的な変換関数として紹介されています。
    *   `ParseBool`, `ParseFloat`, `ParseInt`, `ParseUint`といったパース関数について、それぞれの引数（基数、ビット幅など）の役割が説明されています。特に、`ParseInt`や`ParseUint`が`int64`や`uint64`を返すものの、`size`引数で指定されたより狭い幅の型にデータ損失なく変換できる点が示されています。
    *   `FormatBool`, `FormatFloat`, `FormatInt`, `FormatUint`といったフォーマット関数についても同様に説明されています。
    *   `Append`プレフィックスを持つ関数群（例: `AppendBool`）は、既存のバイトスライスに変換結果を追記する効率的な方法として紹介されています。

*   **文字列変換**:
    *   `Quote`と`QuoteToASCII`は、文字列をGoの文字列リテラル形式に変換する機能を提供します。`QuoteToASCII`は、非ASCII文字を`\u`エスケープシーケンスで表現することで、結果が純粋なASCII文字列になることを保証します。
    *   `QuoteRune`と`QuoteRuneToASCII`は、ルーン（Unicodeコードポイント）をGoのルーンリテラル形式に変換します。
    *   `Unquote`と`UnquoteChar`は、Goの文字列リテラルやルーンリテラルを元の文字列やルーンに変換する逆の操作を行います。

### `src/strconv/example_test.go`

このファイルには、`strconv`パッケージのほぼ全ての公開関数に対する具体的な使用例が含まれています。各例は`Example`プレフィックスを持つ関数として定義され、`fmt.Println`などを用いて結果を出力し、その直後に`// Output:`コメントで期待される出力を記述しています。

以下に、いくつかの代表的な`Example`関数とその解説を示します。

*   **`ExampleAppendBool()`**:
    ```go
    func ExampleAppendBool() {
    	b := []byte("bool:")
    	b = strconv.AppendBool(b, true)
    	fmt.Println(string(b))
    	// Output:
    	// bool:true
    }
    ```
    この例は、`AppendBool`関数が既存のバイトスライスに真偽値の文字列表現を追記する方法を示しています。

*   **`ExampleFormatFloat()`**:
    ```go
    func ExampleFormatFloat() {
    	v := 3.1415926535

    	s32 := strconv.FormatFloat(v, 'E', -1, 32)
    	fmt.Printf("%T, %v\n", s32, s32)

    	s64 := strconv.FormatFloat(v, 'E', -1, 64)
    	fmt.Printf("%T, %v\n", s64, s64)

    	// Output:
    	// string, 3.1415927E+00
    	// string, 3.1415926535E+00
    }
    ```
    `FormatFloat`関数が浮動小数点数を文字列に変換する際に、精度（ビット幅）によって結果が異なることを示しています。`32`は`float32`の精度、`64`は`float64`の精度を意味します。

*   **`ExampleParseInt()`**:
    ```go
    func ExampleParseInt() {
    	v32 := "-354634382"
    	if s, err := strconv.ParseInt(v32, 10, 32); err == nil {
    		fmt.Printf("%T, %v\n", s, s)
    	}
    	// ... (他の例も続く)
    	// Output:
    	// int64, -354634382
    	// ...
    }
    ```
    `ParseInt`関数が文字列を整数にパースする方法を示しています。基数（ここでは10進数）とビット幅（ここでは32ビット）を指定できることがわかります。戻り値の型は常に`int64`ですが、指定されたビット幅に収まる値であれば、そのビット幅の型として扱えることを示唆しています。

*   **`ExampleQuoteToASCII()`**:
    ```go
    func ExampleQuoteToASCII() {
    	s := strconv.QuoteToASCII(`"Fran & Freddie's Diner	☺"`)
    	fmt.Println(s)

    	// Output:
    	// "\"Fran & Freddie's Diner\\t\\u263a\""
    }
    ```
    `QuoteToASCII`関数が、文字列内の特殊文字（タブ`\t`）や非ASCII文字（スマイリーフェイス`☺`）をエスケープして、ASCII互換のGo文字列リテラルを生成する方法を示しています。

*   **`ExampleUnquote()`**:
    ```go
    func ExampleUnquote() {
    	test := func(s string) {
    		t, err := strconv.Unquote(s)
    		if err != nil {
    			fmt.Printf("Unquote(%#v): %v\n", s, err)
    		} else {
    			fmt.Printf("Unquote(%#v) = %v\n", s, t)
    		}
    	}

    	s := `\"Fran & Freddie's Diner\t\u263a\"\"`
    	// If the string doesn't have quotes, it can't be unquoted.
    	test(s) // invalid syntax
    	test("`" + s + "`")
    	test(`"` + s + `"`)
    	test(`'\u263a'`)

    	// Output:
    	// Unquote("\"\\\"Fran & Freddie's Diner\\t\\u263a\\\"\\\""): invalid syntax
    	// Unquote("`\\\"Fran & Freddie's Diner\\t\\u263a\\\"\\\"`") = \"Fran & Freddie's Diner\t☺\""
    	// Unquote("\"\\\"Fran & Freddie's Diner\\t\\u263a\\\"\\\"\"") = "Fran & Freddie's Diner	☺""
    	// Unquote("'\\u263a'") = ☺
    }
    ```
    `Unquote`関数が、Goの文字列リテラル（シングルクォートまたはダブルクォートで囲まれ、エスケープシーケンスを含む）を元の文字列に変換する方法を示しています。引用符がない文字列はアンクォートできないことや、バッククォート文字列（raw string literal）の扱いについても示唆されています。

これらの例は、`strconv`パッケージの各関数の具体的な挙動と、期待される入出力パターンを明確に示しており、開発者がこれらの関数を正しく、かつ意図した通りに利用するための貴重なリソースとなります。
