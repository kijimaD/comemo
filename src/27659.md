# [インデックス 27659] ファイルの概要

このコミットは、Go言語の`math`パッケージに`s390x`アーキテクチャ向けの関数とスタブを追加するものです。具体的には、`Dim`関数と`Sqrt`関数のアセンブリ実装、およびその他の多くの数学関数のスタブが含まれています。これにより、`s390x`プラットフォーム上でのGoプログラムの数値計算性能が向上し、より多くの数学関数が利用可能になります。

## 元コミット内容

このコミットは、Go言語の標準ライブラリである`math`パッケージに、IBMのメインフレームアーキテクチャである`s390x`向けの最適化された数学関数とスタブを追加します。具体的には、`Dim`関数と`Sqrt`関数がアセンブリ言語で実装され、これによりこれらの関数の実行速度が向上します。また、`Asin`, `Acos`, `Atan2`, `Atan`, `Exp2`, `Expm1`, `Exp`, `Floor`, `Ceil`, `Trunc`, `Frexp`, `Hypot`, `Ldexp`, `Log10`, `Log2`, `Log1p`, `Log`, `Modf`, `Mod`, `Remainder`, `Sincos`, `Sin`, `Cos`, `Tan`といった他の多くの数学関数についても、`s390x`アーキテクチャ固有の外部関数へのジャンプを行うスタブが追加されています。

## 変更の背景

Go言語はクロスプラットフォーム対応を重視しており、様々なCPUアーキテクチャで効率的に動作するように設計されています。`s390x`はIBMのメインフレームで使用される64ビットアーキテクチャであり、エンタープライズレベルの重要なワークロードを処理します。このような環境でGoプログラムが最高のパフォーマンスを発揮するためには、汎用的なGoコードだけでなく、特定のアーキテクチャに最適化されたアセンブリコードを提供することが不可欠です。

特に、`math`パッケージの関数は数値計算を多用するアプリケーションにとって非常に重要です。`Sqrt`（平方根）や`Dim`（正の差）のような基本的な関数は頻繁に呼び出されるため、これらをアセンブリで実装することで、計算コストの高い操作の実行時間を大幅に短縮できます。また、他の数学関数についても、`s390x`のハードウェアが提供するネイティブな命令やライブラリを効率的に利用するためのスタブを提供することで、Goランタイムがこれらの機能を活用できるようになります。

この変更は、Go言語が`s390x`プラットフォームでのサポートを強化し、より広範なエンタープライズ環境での採用を促進するための一環として行われました。

## 前提知識の解説

### s390xアーキテクチャ
`s390x`は、IBMのSystem/390およびz/Architectureメインフレームで使用される64ビット命令セットアーキテクチャです。これらのシステムは、高い信頼性、可用性、保守性（RAS）を特徴とし、金融取引、大規模データベース処理、エンタープライズリソースプランニング（ERP）など、ミッションクリティカルなアプリケーションに広く利用されています。`s390x`プロセッサは、浮動小数点演算ユニット（FPU）を内蔵しており、特定の数学演算をハードウェアレベルで高速に実行する能力を持っています。

### Goのアセンブリ言語
Go言語は、特定のパフォーマンスが要求される部分や、ハードウェア固有の機能を利用するために、Goアセンブリ言語（Plan 9アセンブリとも呼ばれる）を使用できます。これは一般的なアセンブリ言語とは異なり、擬似レジスタや特定の構文規則を持つ独自の形式です。Goのアセンブリは、Goコンパイラによって生成される中間コードと連携し、特定の関数を最適化するために利用されます。

### 浮動小数点数演算の特殊値
IEEE 754標準に準拠する浮動小数点数演算では、通常の数値の他に以下の特殊な値が存在します。
-   **NaN (Not a Number)**: 不定な結果（例: 0/0, 無限大 - 無限大）を表します。
-   **+Inf (正の無限大)**: オーバーフローなどによって発生する正の無限大を表します。
-   **-Inf (負の無限大)**: オーバーフローなどによって発生する負の無限大を表します。
-   **±0 (正負のゼロ)**: ゼロには正と負の符号があり、特定の計算で区別されます。

これらの特殊値は、数学関数の挙動を定義する上で重要であり、アセンブリ実装においても正確に処理する必要があります。

### `math`パッケージの関数
-   **`Dim(x, y float64) float64`**: `max(0, x-y)`を計算します。つまり、`x`が`y`より大きい場合は`x-y`を、そうでない場合は`0`を返します。
-   **`Sqrt(x float64) float64`**: `x`の平方根を計算します。
-   **`Max(x, y float64) float64`**: `x`と`y`の大きい方を返します。
-   **`Min(x, y float64) float64`**: `x`と`y`の小さい方を返します。

## 技術的詳細

このコミットでは、`s390x`アーキテクチャの特性を活かしたアセンブリ実装が行われています。

### `Dim`関数の実装 (`src/math/dim_s390x.s`)
`Dim`関数は、`max(0, x-y)`を計算します。アセンブリコードでは、浮動小数点レジスタ（FPU）を使用して`x`から`y`を減算し、その結果が0より小さい場合は0を返すように処理されます。
特に注目すべきは、浮動小数点数の特殊値（`+Inf`, `-Inf`, `NaN`）に対する厳密なハンドリングです。
-   `(+Inf, +Inf)` や `(-Inf, -Inf)` の場合、`Dim`は`NaN`を返します。これは、無限大同士の差が不定であるためです。
-   いずれかの引数が`NaN`の場合も、結果は`NaN`となります。
-   `Max`関数と`Min`関数も同様に、`+Inf`, `-Inf`, `NaN`, `±0`といった特殊なケースを考慮して実装されています。例えば、`Max(+Inf, x)`は`+Inf`を返し、`Min(-Inf, x)`は`-Inf`を返します。また、`Max(NaN, x)`や`Min(NaN, x)`は`NaN`を返します。`±0`の比較では、符号付きゼロの特性が考慮されています。

これらの特殊値の処理は、IEEE 754浮動小数点標準に厳密に従っており、異なるプラットフォーム間での数値計算の一貫性を保証するために重要です。

### `Sqrt`関数の実装 (`src/math/sqrt_s390x.s`)
`Sqrt`関数は、`s390x`の浮動小数点平方根命令（`FSQRT`）を直接利用しています。これにより、Goの汎用的なソフトウェア実装よりもはるかに高速に平方根を計算できます。アセンブリコードは非常にシンプルで、引数を浮動小数点レジスタにロードし、`FSQRT`命令を実行し、結果を返すだけです。

### スタブの実装 (`src/math/stubs_s390x.s`)
`stubs_s390x.s`ファイルには、`Asin`, `Acos`などの多くの数学関数に対するスタブが定義されています。これらのスタブは、対応するGoの関数が呼び出された際に、`s390x`システムが提供するCライブラリ（通常は`libm`）の関数にジャンプ（`BR`命令）するように設計されています。これにより、Goランタイムは既存の最適化されたシステムライブラリを透過的に利用でき、Goでこれらの関数を再実装する手間を省きつつ、高いパフォーマンスを享受できます。

## コアとなるコードの解説

### `src/math/dim_s390x.s` (抜粋)

```assembly
// func Dim(x, y float64) float64
TEXT ·Dim(SB),NOSPLIT,$0
    // (+Inf, +Inf) special case
    MOVD    x+0(FP), R2
    MOVD    y+8(FP), R3
    MOVD    $PosInf, R4
    CMPUBNE R4, R2, dim2
    CMPUBEQ R4, R3, bothInf
dim2:   // (-Inf, -Inf) special case
    MOVD    $NegInf, R4
    CMPUBNE R4, R2, dim3
    CMPUBEQ R4, R3, bothInf
dim3:   // (NaN, x) or (x, NaN)
    MOVD    $~(1<<63), R5
    MOVD    $PosInf, R4
    AND     R5, R2 // x = |x|
    CMPUBLT R4, R2, isDimNaN
    AND     R5, R3 // y = |y|
    CMPUBLT R4, R3, isDimNaN

    FMOVD   x+0(FP), F1
    FMOVD   y+8(FP), F2
    FSUB    F2, F1
    FMOVD   $(0.0), F2
    FCMPU   F2, F1
    BGE     +3(PC)
    FMOVD   F1, ret+16(FP)
    RET
    FMOVD   F2, ret+16(FP)
    RET
bothInf: // Dim(-Inf, -Inf) or Dim(+Inf, +Inf)
isDimNaN:
    MOVD    $NaN, R4
    MOVD    R4, ret+16(FP)
    RET
```
-   `TEXT ·Dim(SB),NOSPLIT,$0`: `Dim`関数の開始を宣言します。`SB`は静的ベースポインタ、`NOSPLIT`はスタックフレームを分割しないことを示し、`$0`はローカル変数がないことを示します。
-   `MOVD x+0(FP), R2`: 引数`x`（フレームポインタ`FP`からのオフセット0）をレジスタ`R2`に移動します。`y`も同様に`R3`にロードされます。
-   `$PosInf`, `$NegInf`, `$NaN`: 浮動小数点数の特殊値を定数として定義し、レジスタにロードして比較に使用します。
-   `CMPUBNE`, `CMPUBEQ`, `CMPUBLT`: 符号なし比較命令で、浮動小数点数のビットパターンを直接比較して特殊値を検出します。
-   `AND R5, R2`: `R5`は符号ビット以外の全ビットが1のマスクで、`AND`演算により浮動小数点数の絶対値を取得します。これにより、`NaN`の検出を容易にします。
-   `FMOVD`, `FSUB`, `FCMPU`: `s390x`の浮動小数点命令で、それぞれ浮動小数点レジスタへの移動、減算、比較を行います。
-   `BGE`, `BLT`: 比較結果に基づいて分岐します。
-   `RET`: 関数から戻ります。

このコードは、`x`と`y`が`+Inf`や`-Inf`、`NaN`である場合の特殊な挙動を最初にチェックし、それ以外の場合に通常の減算とゼロとの比較を行います。

### `src/math/sqrt_s390x.s` (抜粋)

```assembly
// func Sqrt(x float64) float64
TEXT ·Sqrt(SB),NOSPLIT,$0
    FMOVD x+0(FP), F1
    FSQRT F1, F1
    FMOVD F1, ret+8(FP)
    RET
```
-   `FMOVD x+0(FP), F1`: 引数`x`を浮動小数点レジスタ`F1`にロードします。
-   `FSQRT F1, F1`: `F1`レジスタの値の平方根を計算し、結果を`F1`に格納します。これは`s390x`のハードウェア命令です。
-   `FMOVD F1, ret+8(FP)`: `F1`レジスタの結果を戻り値としてフレームポインタ`FP`からのオフセット`8`に格納します。
-   `RET`: 関数から戻ります。

この実装は、`s390x`の専用ハードウェア命令を直接利用するため、非常に効率的です。

### `src/math/stubs_s390x.s` (抜粋)

```assembly
TEXT ·Asin(SB),NOSPLIT,$0
    BR ·asin(SB)

TEXT ·Acos(SB),NOSPLIT,$0
    BR ·acos(SB)
// ... (他の関数も同様)
```
-   `TEXT ·Asin(SB),NOSPLIT,$0`: `Asin`関数の開始を宣言します。
-   `BR ·asin(SB)`: `asin`というラベル（通常はCライブラリの`asin`関数へのシンボル）に無条件分岐します。これにより、Goの`Asin`関数が呼び出された際に、システムが提供する`asin`関数が実行されます。

これらのスタブは、Goの関数呼び出しを`s390x`システムが提供するネイティブな数学ライブラリ関数にリダイレクトすることで、Goプログラムがこれらの最適化された実装を利用できるようにします。
