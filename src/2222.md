# [インデックス 2222] ファイルの概要

このコミットは、Go言語の標準ライブラリである`fmt`パッケージにおいて、数値のフォーマット指定子に`#`フラグ（代替形式）のサポートを追加するものです。具体的には、8進数（`%o`）と16進数（`%x`, `%X`）の出力において、それぞれプレフィックス（`0`、`0x`、`0X`）を付加する機能が実装されました。

## 変更の背景

Go言語の`fmt`パッケージは、C言語の`printf`関数に似た書式指定文字列を用いたフォーマット機能を提供します。C言語の`printf`には、数値の代替形式（alternative form）を指定するための`#`フラグが存在します。例えば、8進数には`0`、16進数には`0x`または`0X`のプレフィックスを付加する機能です。

このコミットが行われた2009年5月は、Go言語がまだ一般に公開される前の初期開発段階でした。この時期は、言語の基本的な機能や標準ライブラリの設計が活発に行われており、既存のプログラミング言語（特にC言語）の慣習や期待される機能を取り込む作業が進められていました。

この変更は、`fmt`パッケージが提供するフォーマット機能の網羅性を高め、C言語の`printf`に慣れた開発者にとってより直感的で期待通りの挙動を提供することを目的としています。特に、デバッグ出力や特定のデータ形式の表示において、数値の基数を明示するプレフィックスは非常に有用です。

## 前提知識の解説

### Go言語の`fmt`パッケージ

`fmt`パッケージは、Go言語におけるフォーマットI/O（入出力）を扱うための標準ライブラリです。`Printf`、`Sprintf`、`Fprint`などの関数を提供し、C言語の`printf`ファミリー関数と同様に、書式指定文字列（format string）と引数を用いて整形された文字列を生成したり、出力ストリームに書き込んだりします。

書式指定文字列は、プレーンテキストと「動詞（verb）」と呼ばれる特殊なシーケンスで構成されます。動詞は`%`で始まり、その後に続く文字によって引数の型や表示形式を指定します。

### フォーマット動詞とフラグ

*   **`%o`**: 符号なし整数を8進数で表示します。
*   **`%x`**: 符号なし整数を16進数（小文字）で表示します。
*   **`%X`**: 符号なし整数を16進数（大文字）で表示します。

### `#`フラグ（代替形式）

`#`フラグは、数値のフォーマットにおいて「代替形式（alternate form）」を指定するために使用されます。

*   **`%#o`**: 8進数表示において、非ゼロの数値に`0`プレフィックスを付加します。
*   **`%#x`**: 16進数表示において、非ゼロの数値に`0x`プレフィックスを付加します。
*   **`%#X`**: 16進数表示において、非ゼロの数値に`0X`プレフィックスを付加します。

このフラグは、数値の基数を視覚的に明確にするために利用されます。例えば、`fmt.Printf("%#x", 10)`は`0xa`と出力され、`fmt.Printf("%x", 10)`が`a`と出力されるのと対照的です。

### `OCL`と`CL`

Go言語の初期開発において、`OCL` (Old Change List) と `CL` (Change List) は、Google内部のコードレビューシステム（Perforceベース）における変更セットの識別子でした。Go言語がオープンソース化される前は、Googleの内部インフラストラクチャ上で開発が進められており、これらの番号は特定の変更の履歴を追跡するために使用されていました。このコミットメッセージに含まれる`OCL=28936`と`CL=28936`は、この変更がGoogle内部で28936番目の変更リストとしてレビュー・承認されたことを示しています。

## 技術的詳細

このコミットの主要な変更は、`src/lib/fmt/format.go`内の`integer`関数に、`#`フラグの処理ロジックを追加することです。`integer`関数は、Goの`fmt`パッケージが様々な整数型を文字列に変換する際の中心的なロジックを担っています。

変更の核心は、フォーマット構造体`f`の`sharp`フィールド（`#`フラグが指定されたかどうかを示すブール値）をチェックし、その値に基づいて出力文字列にプレフィックスを追加する点にあります。

### 8進数（`%#o`）の処理

8進数の場合、`#`フラグが指定され、かつ数値が既に`0`で始まっていない（つまり、`0`以外の数値）場合に、出力文字列の先頭に`0`を追加します。これは、`buf`（数値を文字列として格納するバイトスライス）の適切な位置に`'0'`を挿入することで実現されます。

### 16進数（`%#x`, `%#X`）の処理

16進数の場合、`#`フラグが指定されると、出力文字列の先頭に`0x`または`0X`を追加します。`format.go`の`integer`関数では、`digits`引数によって16進数の文字セット（小文字または大文字）が渡されます。この`digits`引数を利用して、適切な`x`または`X`文字を決定し、`0`と共に`buf`の先頭に挿入します。

### テストケースの追加

`src/lib/fmt/fmt_test.go`には、新しい`%#o`、`%#x`、`%#X`フォーマットの挙動を検証するためのテストケースが追加されています。これにより、実装が正しく機能すること、特にプレフィックスが期待通りに付加されることが保証されます。また、幅指定や精度指定などの他のフラグとの組み合わせもテストされており、堅牢性が確認されています。

## コアとなるコードの解説

### `src/lib/fmt/fmt_test.go`の変更点

*   **削除されたテストケース**: `fmtTest{ "% d", -12345, "-12345" }` が削除されています。これはおそらく、`% d`（スペースフラグ）が負の数に対してはスペースを付加しないという仕様に合致しない、または冗長なテストケースであったためと考えられます。
*   **`%#o`のテスト追加**: 8進数に`#`フラグを付けた場合のテストが追加されました。`01234`という8進数リテラルが、フォーマット後も`01234`として出力されることを確認しています。これは、Goの8進数リテラルが`0`で始まるため、`#`フラグが付いても追加の`0`が付かないことを示唆しています。
*   **`%#x`のテスト追加**: 16進数に`#`フラグを付けた場合のテストが追加されました。`0x1234abcd`が`0x1234abcd`として出力されることを確認しており、`0x`プレフィックスが正しく付加されることを示しています。
*   **`%#X`のテスト追加**: 大文字の16進数に`#`フラグを付けた場合のテストが追加されました。`0`という値が`0X0`として出力されることを確認しており、`0X`プレフィックスが正しく付加されることを示しています。
*   **複合フラグのテスト追加**: `%-#20.8x`、`%-#20.8X`、`%-#20.8o`のように、左詰め（`-`）、幅指定、精度指定、そして代替形式（`#`）を組み合わせた場合のテストが追加されています。これにより、これらのフラグが互いに正しく作用することが検証されています。

### `src/lib/fmt/format.go`の変更点

`func (f *Fmt) integer(...) string` 関数は、整数値を文字列に変換する主要なロジックを含んでいます。この関数内に、`#`フラグの処理を追加する新しい`if f.sharp`ブロックが導入されました。

*   **`if f.sharp`ブロック**:
    *   このブロックは、フォーマットフラグ`f`の`sharp`フィールドが`true`（つまり、`#`フラグが指定されている）の場合に実行されます。
    *   内部の`switch base`文で、数値の基数（8進数か16進数か）に応じて異なる処理を行います。

*   **`case 8:`（8進数）の処理**:
    *   `if buf[i+1] != '0'`という条件は、既に数値が`0`で始まっていない場合にのみ、プレフィックスの`0`を追加することを示しています。Goの8進数リテラルは`0`で始まるため、この条件は主に、`0`で始まらない数値（例: `fmt.Printf("%#o", 10)`）に対して`0`を付加するために機能します。
    *   `buf[i] = '0'; i--;` は、現在のバッファ位置`i`に`'0'`を書き込み、ポインタ`i`をデクリメントして次の文字の書き込み位置を調整します。

*   **`case 16:`（16進数）の処理**:
    *   `buf[i] = 'x' + digits[10]-'a'; i--;` は、16進数のプレフィックスの2文字目（`x`または`X`）を書き込みます。`digits[10]`は、`digits`文字列（例: "0123456789abcdef" または "0123456789ABCDEF"）の11番目の文字（インデックス10）を参照します。これは、小文字の`x`または大文字の`X`を決定するために使用されます。例えば、`digits`が小文字の場合、`digits[10]`は`'a'`であり、`'x' + 'a' - 'a'`は`'x'`になります。`digits`が大文字の場合、`digits[10]`は`'A'`であり、`'x' + 'A' - 'a'`は`'X'`になります。
    *   `buf[i] = '0'; i--;` は、16進数のプレフィックスの1文字目（`0`）を書き込みます。
    *   これらの操作により、`0x`または`0X`が数値の前に正しく挿入されます。

この変更により、`fmt`パッケージはC言語の`printf`と同様の`#`フラグの挙動を提供し、数値の基数を明示的に表示する機能が強化されました。
