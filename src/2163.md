# [インデックス 2163] ファイルの概要

このコミットは、Go言語の標準ライブラリである`json`パッケージにおける、JSON Map（Goのマップ型に相当）に対する`Len()`メソッドの定義を追加するものです。これにより、JSONオブジェクトの要素数（キーと値のペアの数）を統一的に取得できるようになります。

## 変更の背景

このコミットが行われた2009年5月は、Go言語がまだ初期段階にあり、標準ライブラリ、特に`json`パッケージが活発に開発・改良されていた時期です。当時の`json`パッケージの`Json`インターフェースには、既にJSON配列（`ArrayKind`）の長さを取得するための`Len()`メソッドが存在していました。しかし、JSONオブジェクト（`MapKind`）の要素数を取得する統一的な手段がありませんでした。

JSONデータは、配列とオブジェクトという2つの主要な構造を持ちます。配列の長さは`len()`で取得できるのが自然であるのと同様に、オブジェクトの要素数（キーの数）も同様のセマンティクスで取得できることが望ましいと判断されました。この変更は、`Json`インターフェースの設計をより一貫性のあるものにし、JSONデータの操作をより直感的にするための改善の一環として行われました。

## 前提知識の解説

*   **Go言語の`json`パッケージ**: Go言語の標準ライブラリの一部で、JSON (JavaScript Object Notation) データのエンコードとデコードを提供します。構造体とJSONデータの間のマッピングを自動的に行ったり、ジェネリックなJSONツリー構造を操作するためのインターフェースを提供したりします。
*   **`Json`インターフェース**: このコミットの時点での`json`パッケージにおける、JSONデータを抽象的に表現するためのインターフェースです。このインターフェースを通じて、JSONの様々な型（文字列、数値、ブール値、配列、マップなど）を統一的に扱うことができました。
*   **`MapKind`と`ArrayKind`**: `Json`インターフェースが扱うJSONデータの種類を示す内部的な定数または概念です。`MapKind`はJSONオブジェクト（キーと値のペアの集合）を、`ArrayKind`はJSON配列（順序付けられた値のリスト）を指します。
*   **`Len()`メソッド**: 一般的に、Go言語において`len()`組み込み関数は、配列、スライス、マップ、文字列、チャネルなどの長さを取得するために使用されます。このコミットでは、`Json`インターフェースの一部として、JSONデータ構造の「長さ」や「要素数」を返すメソッドとして`Len()`が定義されています。
*   **`map[string]Json`**: Go言語でJSONオブジェクトを表現するために内部的に使用されるマップ型です。キーは文字列、値は別の`Json`インターフェース型となります。

## 技術的詳細

このコミットの技術的な核心は、`Json`インターフェースの`Len()`メソッドのセマンティクスを拡張し、具体的な実装として`_Map`型に`Len()`メソッドを追加した点にあります。

1.  **`Json`インターフェースの定義変更**:
    `src/lib/json/generic.go`ファイルにおいて、`Json`インターフェース内の`Len()`メソッドのコメントが変更されました。
    変更前: `Len() int; // length (ArrayKind)`
    変更後: `Len() int; // length (ArrayKind, MapKind)`
    この変更は、`Len()`メソッドがJSON配列だけでなく、JSONマップ（オブジェクト）の長さも返すことを明示的に示しています。これはインターフェースの契約の拡張を意味します。

2.  **`_Map`構造体への`Len()`メソッドの実装追加**:
    `src/lib/json/generic.go`ファイルにおいて、JSONマップを内部的に表現する`_Map`構造体に`Len()`メソッドが追加されました。
    ```go
    type _Map struct { m map[string]Json; _Null }
    func (j *_Map) Kind() int { return MapKind }
    func (j *_Map) Len() int { return len(j.m) } // 追加された行
    func (j *_Map) Get(s string) Json {
    	if j.m == nil {
    		return Null
    	}
    	// ...
    }
    ```
    この実装は非常にシンプルで、`_Map`構造体が内部に持つ`map[string]Json`型のフィールド`m`の長さを、Goの組み込み関数`len()`を使ってそのまま返します。これにより、JSONオブジェクトが持つキーと値のペアの総数が取得できるようになります。

3.  **テストケースの追加**:
    `src/lib/json/generic_test.go`ファイルに、`_Map`型に対する`Len()`メソッドの動作を検証するテストケースが追加されました。
    ```go
    	if cnt := mapv.Len(); cnt != len(jsontests) {
    		t.Errorf("StringToJson(%#q).Len() => %v, want %v", mapstr, cnt,
    		         len(jsontests));
    	}
    ```
    このテストは、JSON文字列からパースされたマップの`Len()`メソッドが、期待される要素数（元のテストデータ`jsontests`の長さ）と一致するかどうかを確認しています。これにより、新しく追加された機能が正しく動作することが保証されます。

この変更により、`Json`インターフェースを介してJSONデータを扱う際に、そのデータが配列であろうとオブジェクトであろうと、統一された`Len()`メソッドでその「サイズ」を取得できるようになったため、コードの記述がより簡潔かつ汎用的になりました。

## コアとなるコードの解説

*   **`src/lib/json/generic.go`**:
    *   `Json`インターフェースの`Len()`メソッドのコメントが更新され、このメソッドが`ArrayKind`（JSON配列）だけでなく`MapKind`（JSONオブジェクト）にも適用されることが明示されました。これは、インターフェースのセマンティクスが拡張されたことを示します。
    *   `_Map`構造体（JSONオブジェクトを表現する内部型）に、`Len() int`メソッドが追加されました。このメソッドは、`_Map`が内部に持つ`map[string]Json`型のフィールド`m`の要素数を、Goの組み込み関数`len()`を使って返します。これにより、JSONオブジェクトのキーと値のペアの数を取得できるようになります。

*   **`src/lib/json/generic_test.go`**:
    *   `TestJsonMap`関数内に、`mapv.Len()`の戻り値が期待される要素数（`jsontests`の長さ）と一致するかどうかを検証するテストコードが追加されました。これは、`_Map`型に新しく追加された`Len()`メソッドが正しく機能することを保証するためのものです。

これらの変更により、`json`パッケージの`Json`インターフェースは、JSON配列とJSONオブジェクトの両方に対して統一的な方法で要素数を取得できる、より汎用的なインターフェースとなりました。
