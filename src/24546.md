# [インデックス 24546] ファイルの概要

このコミットは、Go言語の公式ドキュメントにおけるmacOS (旧称 OS X) の最小要件を更新するものです。具体的には、Goのビルドおよび実行に必要なmacOSのバージョンが、これまでの「OS X 10.6 (Snow Leopard) 以降」から「OS X 10.7 (Lion) 以降」へと引き上げられたことを反映しています。この変更は、Goのインストールドキュメント（ソースからのインストールガイドと一般的なインストールガイド）に適用されています。

## 変更の背景

このコミットの背景には、Go言語のランタイムやツールチェーンがサポートするmacOSの最小バージョンが変更されたことがあります。コミットメッセージにある `Fixes #11995` は、この変更が特定の課題（issue）に対応するものであることを示唆しています。具体的なissueの内容は、Goの古いissueトラッカー（おそらく `code.google.com/p/go`）に存在していた可能性があり、現在のGitHubリポジトリでは直接参照できませんが、一般的にこのような要件の引き上げは、以下のいずれかの理由によるものです。

1.  **新しい機能やAPIの利用**: Goのコンパイラやランタイムが、OS X 10.7以降で導入された新しいシステムコール、ライブラリ、または機能を利用するようになったため、それ以前のバージョンでは正しく動作しなくなった。
2.  **メンテナンスコストの削減**: 古いOSバージョンのサポートを維持することは、テスト、バグ修正、および開発において追加のコストを伴います。開発チームは、より新しいOSバージョンに焦点を当てることで、リソースを効率的に配分し、より良い開発体験を提供することを目指します。
3.  **依存関係の更新**: Goが依存する外部ライブラリやツールが、OS X 10.7以降を最小要件とするようになったため、Go自体もそれに追従する必要が生じた。
4.  **セキュリティと安定性**: 古いOSバージョンはセキュリティパッチやバグ修正が提供されなくなるため、それらをサポートし続けることは、Goアプリケーションのセキュリティや安定性にリスクをもたらす可能性があります。

このコミットは、Goのドキュメントを実際のサポート状況に合わせて更新し、ユーザーがGoをインストールする際に誤った情報に基づいて作業を進めることを防ぐ目的があります。

## 前提知識の解説

### macOSのバージョンとコードネーム

*   **OS X 10.6 Snow Leopard**: 2009年8月にリリースされたmacOSのバージョン。このコミット以前のGoの最小要件でした。
*   **OS X 10.7 Lion**: 2011年7月にリリースされたmacOSのバージョン。このコミットによってGoの新しい最小要件となりました。Lionでは、Launchpad、Mission Control、フルスクリーンアプリケーション、AirDropなど、多くの新機能が導入されました。また、32ビットアプリケーションのサポートが段階的に縮小され始め、64ビット環境への移行が加速しました。

### Goの環境変数 `GOOS` と `GOARCH`

Go言語のクロスコンパイル機能は、`GOOS` と `GOARCH` という環境変数によって制御されます。

*   **`GOOS` (Go Operating System)**: ターゲットとするオペレーティングシステムを指定します。例えば、`darwin` はmacOS (旧称 OS X) を、`linux` はLinuxを、`windows` はWindowsを指します。
*   **`GOARCH` (Go Architecture)**: ターゲットとするCPUアーキテクチャを指定します。例えば、`amd64` は64ビットx86アーキテクチャを、`386` は32ビットx86アーキテクチャを、`arm` はARMアーキテクチャを指します。

これらの変数を設定することで、開発者は現在の環境とは異なるOSやアーキテクチャ向けにGoプログラムをコンパイルできます。このコミットでは、`GOOS=darwin` の場合の最小バージョンが変更されたことをドキュメントに反映しています。

### `doc/install-source.html` と `doc/install.html`

これらはGo言語の公式ウェブサイトに掲載されているインストールドキュメントの一部です。

*   **`doc/install-source.html`**: ソースコードからGoをビルドおよびインストールする方法について説明しています。Goの開発者や、特定の環境でGoをカスタマイズして使用したいユーザー向けです。
*   **`doc/install.html`**: 公式バイナリディストリビューションを使用してGoをインストールする方法について説明しています。ほとんどの一般ユーザーがGoを使い始める際に参照するドキュメントです。

これらのドキュメントは、Goのサポートするプラットフォームとバージョンに関する正確な情報を提供することが非常に重要です。

## 技術的詳細

このコミットは、Goのインストールドキュメント内のmacOSの最小要件に関する記述を修正するものです。具体的な変更は以下の2つのファイルで行われています。

1.  **`doc/install-source.html`**:
    *   このファイルは、`$GOOS` の選択肢を説明する箇所で、`darwin` (Mac OS X) のサポートバージョンを記述しています。
    *   変更前は `darwin (Mac OS X 10.6 and above and iOS)` となっていましたが、変更後は `darwin (Mac OS X 10.7 and above and iOS)` となり、最小要件が10.6から10.7に引き上げられたことを明記しています。

2.  **`doc/install.html`**:
    *   このファイルは、公式バイナリディストリビューションが利用可能なOSと、その最小バージョンを説明しています。
    *   変更前は `Mac OS X (Snow Leopard and above)` および表形式のリストで `Mac OS X 10.6 or later` となっていましたが、変更後はそれぞれ `Mac OS X (10.7 and above)` および `Mac OS X 10.7 or later` に修正されています。
    *   また、`Mac OS X 10.7 or later` の行では、サポートされるアーキテクチャが `amd64, 386` から `amd64` に変更されています。これは、OS X 10.7以降では32ビットの `386` アーキテクチャのサポートがGoの公式バイナリディストリビューションから除外されたことを示唆しています。これは、Appleが32ビットアプリケーションのサポートを段階的に廃止していった流れと一致します。

これらの変更は、Goの実際のサポートポリシーとドキュメントとの間にあった不一致を解消し、ユーザーに正確な情報を提供することを目的としています。

## コアとなるコードの解説

上記の差分は、GoのインストールドキュメントにおけるmacOSの最小要件に関する記述を修正しています。

### `doc/install-source.html` の変更

*   `-<code>darwin</code> (Mac OS X 10.6 and above and iOS), <code>dragonfly</code>, <code>freebsd</code>,`
*   `+<code>darwin</code> (Mac OS X 10.7 and above and iOS), <code>dragonfly</code>, <code>freebsd</code>,`

この変更は、ソースからGoをビルドする際の `GOOS=darwin` の最小サポートバージョンを「OS X 10.6以降」から「OS X 10.7以降」に更新しています。これは、GoのツールチェーンがOS X 10.7で利用可能になった機能やAPIに依存するようになったことを示唆しています。

### `doc/install.html` の変更

*   `-Linux, Mac OS X (Snow Leopard and above), and Windows operating systems and`
*   `+Linux, Mac OS X (10.7 and above), and Windows operating systems and`

この変更は、公式バイナリディストリビューションのmacOSサポートに関する一般的な記述を「Snow Leopard (10.6) 以降」から「10.7 以降」に更新しています。

*   `-<tr><td>Mac OS X 10.6 or later</td> <td>amd64, 386</td> <td>use the gcc<sup>&#8224;</sup> that comes with Xcode<sup>&#8225;</sup></td></tr>`
*   `+<tr><td>Mac OS X 10.7 or later</td> <td>amd64</td> <td>use the gcc<sup>&#8224;</sup> that comes with Xcode<sup>&#8225;</sup></td></tr>`

この表形式の変更は、以下の2つの重要な点を更新しています。

1.  **最小バージョン**: 「Mac OS X 10.6 or later」が「Mac OS X 10.7 or later」に変更され、最小要件がOS X Lionに引き上げられたことを明確に示しています。
2.  **サポートアーキテクチャ**: `amd64, 386` から `amd64` へと変更されています。これは、Goの公式バイナリディストリビューションがOS X 10.7以降では32ビット (386) アーキテクチャのサポートを終了したことを意味します。これは、AppleがOS X Lion以降で32ビットカーネルのサポートを廃止し、64ビット環境への移行を推進したことと整合性が取れています。Goもこの流れに沿って、より新しいOSバージョンと64ビットアーキテクチャに焦点を当てるようになったと考えられます。

これらの変更は、Goのユーザーが自身のmacOS環境がGoの要件を満たしているかを確認する上で非常に重要な情報を提供します。
