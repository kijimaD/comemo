## 元コミット内容

このコミットは、`doc/devel/release.html` ファイルにGo 1.5.3のリリース情報を追加するものです。追加された内容は、Go 1.5.3が `math/big` パッケージのセキュリティ修正を含んでおり、それが `crypto/tls` パッケージに影響を与えることを明記しています。また、Go 1.5.3のマイルストーンとリリースアナウンスへのリンクも提供されています。

## 変更の背景

Go 1.5.3は、2016年1月13日にリリースされたGo言語のマイナーバージョンです。このリリースは、特に重要なセキュリティ脆弱性（CVE-2015-8618）に対処するために行われました。この脆弱性は、Goの標準ライブラリである `math/big` パッケージ内のRSA計算に影響を与え、`crypto/rsa` を介して `crypto/tls` パッケージに波及する可能性がありました。

このコミットの目的は、Go 1.5.3のリリースに伴い、公式のリリースノートドキュメント (`doc/devel/release.html`) を更新し、ユーザーにこの重要なセキュリティ修正について通知することです。これにより、ユーザーはGo 1.5.3へのアップグレードの必要性を認識し、自身のアプリケーションを保護するための適切な措置を講じることができます。

## 前提知識の解説

このコミットの理解には、以下の技術的背景知識が役立ちます。

*   **Go言語のリリースサイクル**: Go言語は定期的に新しいバージョンをリリースしており、メジャーバージョン（例: Go 1.5）と、バグ修正やセキュリティパッチを含むマイナーバージョン（例: Go 1.5.3）があります。
*   **`math/big` パッケージ**: Go言語の標準ライブラリの一部で、任意精度の整数演算をサポートします。暗号化アルゴリズムなど、非常に大きな数値を扱う必要がある場面で利用されます。
*   **`crypto/rsa` パッケージ**: RSA暗号アルゴリズムの実装を提供するGo言語の標準ライブラリです。公開鍵暗号方式の一つであり、データの暗号化、デジタル署名などに広く用いられます。
*   **`crypto/tls` パッケージ**: Transport Layer Security (TLS) プロトコルの実装を提供するGo言語の標準ライブラリです。ウェブサイトのHTTPS通信など、セキュアなネットワーク通信を実現するために使用されます。TLSハンドシェイク中にRSA鍵交換が行われることがあります。
*   **RSA Chinese Remainder Theorem (CRT)**: RSA暗号の復号処理を高速化するために用いられる技術です。中国剰余定理を利用して、大きな数のべき乗剰余計算をより小さな数の計算に分割し、その結果を結合することで効率化を図ります。
*   **サイドチャネル攻撃**: 暗号システムの実装から漏洩する情報（実行時間、消費電力、電磁波など）を利用して、秘密鍵などの機密情報を推測する攻撃手法です。RSA CRTの実装における計算エラーが、このような情報漏洩の経路となることがあります。
*   **CVE (Common Vulnerabilities and Exposures)**: 公開されている情報セキュリティの脆弱性や露出を識別するための標準的な識別子です。CVE-2015-8618はこの脆弱性に対する識別子です。

## 技術的詳細

Go 1.5.3で修正されたセキュリティ脆弱性（CVE-2015-8618）は、`math/big` パッケージにおけるRSA中国剰余定理 (CRT) の実装の誤りに起因していました。この誤りは、特に32ビットシステム上で、RSA計算が誤った結果を生成する可能性がありました。

具体的には、RSA CRTの計算中に誤りが発生すると、秘密鍵を構成する2つの素数（pとq）のうちの1つが漏洩する可能性がありました。この情報漏洩は、TLSサーバーがRSA鍵交換を行う際に、攻撃者が多数の署名操作を観測することで、サーバーのRSA秘密鍵を推測することを可能にするサイドチャネル攻撃に利用される恐れがありました。

*   **32ビットシステムでの影響**: 32ビットシステムでは、このバグは約2^26回に1回の頻度で発生する可能性がありました。これは、約6400万回の署名操作を観測することで、攻撃者が秘密鍵を抽出できる可能性があることを意味します。
*   **64ビットシステムでの影響**: 64ビットシステムでは、バグの発生頻度は2^50回に1回未満と非常に低く、攻撃の成功は極めて困難でした。

この脆弱性は、`crypto/rsa` パッケージを介して `crypto/tls` パッケージに影響を与え、TLSサーバーが32ビットシステム上で稼働している場合に、そのRSA秘密鍵が漏洩するリスクがありました。

Go 1.5.3では、この `math/big` パッケージ内のRSA CRT計算の誤りが修正されました。これにより、誤った計算結果が生成される可能性が排除され、サイドチャネル攻撃による秘密鍵の漏洩リスクが軽減されました。

さらに、Go 1.6では、この種のバグに対するより一般的な対策として、RSA計算を二重チェックするメカニズムが導入されました。これは、計算結果の信頼性を高め、将来的に同様の脆弱性が発見されるリスクを低減するための防御策です。

## コアとなるコードの解説

このコミットによるコードの変更は、`doc/devel/release.html` ファイルへの追記のみです。

具体的には、Go 1.5.2に関する段落の後に、Go 1.5.3に関する新しい段落が追加されています。

追加されたHTMLコードは以下の通りです。

```html
<p>
go1.5.3 (released 2016/01/13) includes a security fix to the <code>math/big</code> package
affecting the <code>crypto/tls</code> package.
See the <a href="https://github.com/golang/go/issues?q=milestone%3AGo1.5.3">Go 1.5.3 milestone on our issue tracker</a>
and the <a href="https://golang.org/s/go153announce">release announcement</a> for details.
</p>
```

この段落は以下の情報を伝えています。

*   **Go 1.5.3のリリース日**: 2016年1月13日。
*   **主要な変更点**: `math/big` パッケージに対するセキュリティ修正が含まれており、これが `crypto/tls` パッケージに影響を与えること。
*   **詳細情報へのリンク**:
    *   Go 1.5.3のマイルストーン（GitHubのIssueトラッカー）へのリンク。これにより、修正された具体的なIssueや関連する議論を確認できます。
    *   リリースアナウンス（`https://golang.org/s/go153announce`）へのリンク。これにより、公式のリリース発表で提供される詳細な情報（脆弱性の内容、影響、推奨される対応など）を確認できます。

この変更は、Go言語のユーザーが最新のリリース情報を把握し、特にセキュリティ関連の重要な更新を見逃さないようにするための、ドキュメント上の重要な更新です。
