## 変更の背景

Go言語の `math/big` パッケージは、標準の `int` や `int64` 型では表現できないような非常に大きな整数（任意精度整数）を扱うために提供されています。しかし、このパッケージの利用方法、特に複数の `big.Int` オブジェクトを組み合わせて複雑な計算を行う具体的な例が不足している場合がありました。

このコミットは、Go issue #11241 に対応するものです。このissueでは、`math/big` パッケージのドキュメントに、より実践的で完全な例を追加することが求められていました。特に、`big.Int` の基本的な操作（初期化、加算、比較、べき乗、素数判定）を組み合わせた例は、ユーザーがこのパッケージの機能を理解し、自身のコードで活用する上で非常に有用です。

追加されたフィボナッチ数の計算と素数判定の例は、`big.Int` がどのようにして通常の整数型ではオーバーフローしてしまうような大きな数値を扱うことができるのかを明確に示しています。これにより、ユーザーは `math/big` パッケージの強力な機能をより容易に理解し、利用できるようになります。

## 前提知識の解説

### Go言語の `math/big` パッケージ

`math/big` パッケージは、Go言語で任意精度算術を可能にするためのものです。これは、標準の `int` や `int64` 型が持つ固定のビット幅（通常64ビット）を超える非常に大きな整数や、高い精度が求められる浮動小数点数を扱う際に必要となります。

*   **`big.Int`**: 任意精度の整数を表す型です。内部的には数値の桁をスライスで管理することで、メモリが許す限り任意の大きさの整数を表現できます。
*   **`big.NewInt(int64)`**: `int64` 型の値を基に新しい `big.Int` オブジェクトを生成し、初期化するための関数です。
*   **`Add(x, y *Int) *Int`**: `x` と `y` の和を計算し、その結果をレシーバ `*Int` に格納して返します。`big.Int` のメソッドは通常、レシーバ自身を変更し、そのレシーバを返すことでメソッドチェーンを可能にします。
*   **`Cmp(y *Int) int`**: レシーバ `*Int` と `y` を比較します。レシーバが `y` より小さい場合は -1、等しい場合は 0、大きい場合は 1 を返します。
*   **`Exp(x, y, m *Int) *Int`**: `x` の `y` 乗を計算し、もし `m` が `nil` でなければ、その結果を `m` で割った余り（モジュロ演算）を計算します。結果はレシーバ `*Int` に格納されます。この例では `m` が `nil` なので、単純なべき乗計算 (`10^99`) に使用されます。
*   **`ProbablyPrime(n int) bool`**: レシーバ `*Int` が素数である可能性を判定します。`n` はミラー-ラビン素数判定法を実行する回数を指定します。`n` が大きいほど、素数である確率は高まりますが、計算コストも増加します。結果は確率的なものであり、`true` が返されても絶対的な素数である保証はありませんが、`n=20` 程度であれば非常に高い確率で正しい結果が得られます。

### フィボナッチ数列

フィボナッチ数列は、最初の2項が0と1（または1と1）で、それ以降の項が直前の2項の和となる数列です。
例: 0, 1, 1, 2, 3, 5, 8, 13, ...
この数列は急速に増加するため、大きな項を計算するには任意精度整数が必要になります。

### ミラー-ラビン素数判定法 (Miller-Rabin Primality Test)

ミラー-ラビン素数判定法は、与えられた数が素数であるかどうかを確率的に判定するアルゴリズムです。決定的な素数判定法（例: 試し割り）に比べて非常に高速であり、特に大きな数の素数判定に適しています。このアルゴリズムは、合成数（素数ではない数）を素数であると誤判定する確率を非常に低く抑えることができます。`ProbablyPrime` メソッドの引数 `n` は、このテストの反復回数を指定し、反復回数を増やすことで誤判定の確率をさらに下げることができます。

### Go言語の `example_test.go` ファイル

Go言語では、`_test.go` で終わるファイルにテストコードを記述します。その中でも、`Example` 関数は特別な意味を持ちます。これらは通常のテスト関数と同様に実行されますが、その目的はパッケージのAPIの使用例を示すことです。`// Output:` コメントを記述することで、その例の実行結果をドキュメントとして表示し、かつその出力が正しいことをテストとして検証することができます。これにより、ドキュメントとコードの乖離を防ぎ、常に最新で正確な使用例を提供できます。

## 技術的詳細

このコミットで追加された `Example_fibonacci` 関数は、`math/big` パッケージの `big.Int` 型を効果的に使用して、以下のタスクを実行します。

1.  **任意精度整数の初期化**: `big.NewInt(0)` と `big.NewInt(1)` を使用して、フィボナッチ数列の最初の2項を `big.Int` 型で初期化します。これにより、通常の `int64` では扱えないような大きな数も計算できるようになります。
2.  **100桁の最小値の定義**: `limit` 変数に10の99乗（10^99）を設定します。これは、100桁の最小の整数です。`limit.Exp(big.NewInt(10), big.NewInt(99), nil)` を使用して計算されます。`Exp` メソッドはべき乗を計算し、第3引数が `nil` の場合はモジュロ演算を行いません。
3.  **フィボナッチ数列の計算**: `for` ループ内で、`fib1.Cmp(&limit) < 0` という条件で `fib1` が `limit` より小さい間、フィボナッチ数列を計算し続けます。
    *   `fib1, fib2 = fib2, fib1.Add(fib1, fib2)` の行は、フィボナッチ数列の次の項を効率的に計算しています。`fib1.Add(fib1, fib2)` は `fib1` と `fib2` の和を計算し、その結果を `fib1` に格納します。その後、`fib1` の古い値が `fib2` に、`fib1` の新しい値が `fib1` にそれぞれ代入されます。この代入は並行して行われるため、一時変数なしで値を交換し、更新することができます。
4.  **素数判定**: 100桁のフィボナッチ数が計算された後、`fib1.ProbablyPrime(20)` を呼び出して、その数が素数である可能性を判定します。引数 `20` は、ミラー-ラビン素数判定法を20回繰り返すことを意味し、これにより非常に高い信頼度で素数性を判定できます。

この例は、`math/big` パッケージが提供する基本的な算術操作と、素数判定のようなより高度な機能の両方を、実用的なシナリオでどのように組み合わせるかを示しています。特に、`big.Int` のメソッドがレシーバ自身を変更し、そのレシーバを返すというGoの慣用的なパターンも示されており、効率的なコード記述に役立ちます。

## コアとなるコードの解説

追加された `Example_fibonacci` 関数は以下のステップで動作します。

1.  **`fib1 := big.NewInt(0)` と `fib2 := big.NewInt(1)`**:
    *   フィボナッチ数列の最初の2つの数 `0` と `1` を `big.Int` 型で初期化します。`big.NewInt` は `int64` から `big.Int` を生成するヘルパー関数です。

2.  **`var limit big.Int` と `limit.Exp(big.NewInt(10), big.NewInt(99), nil)`**:
    *   `limit` という `big.Int` 型の変数を宣言します。
    *   `limit.Exp` メソッドを使って、`10` の `99` 乗を計算し、`limit` に格納します。これは、100桁の最小の整数（1の後に0が99個続く数）を定義しています。第3引数 `nil` はモジュロ演算を行わないことを意味します。

3.  **`for fib1.Cmp(&limit) < 0 { ... }`**:
    *   `for` ループは、現在のフィボナッチ数 `fib1` が `limit`（100桁の最小値）よりも小さい間、繰り返されます。
    *   `fib1.Cmp(&limit)` は `fib1` と `limit` を比較し、`fib1` が `limit` より小さい場合は `-1` を返します。

4.  **`fib1, fib2 = fib2, fib1.Add(fib1, fib2)`**:
    *   この行はフィボナッチ数列の次の項を計算する核心部分です。
    *   `fib1.Add(fib1, fib2)` は、現在の `fib1` と `fib2` の和を計算し、その結果を `fib1` に格納します。`big.Int` のメソッドは通常、レシーバ自身を変更します。
    *   Goの多重代入の機能を利用して、`fib1` の古い値が `fib2` に、`fib1` の新しい値が `fib1` に同時に代入されます。これにより、一時変数なしで数列を更新できます。

5.  **`fmt.Println(fib1)`**:
    *   ループが終了すると、`fib1` には100桁以上の最小のフィボナッチ数が格納されているため、その値を出力します。

6.  **`isPrime := fib1.ProbablyPrime(20)`**:
    *   計算されたフィボナッチ数 `fib1` が素数であるかどうかを確率的に判定します。
    *   `ProbablyPrime(20)` は、ミラー-ラビン素数判定法を20回実行することを意味します。これにより、非常に高い確率で素数性を判定できます。

7.  **`fmt.Println(isPrime)`**:
    *   素数判定の結果 (`true` または `false`) を出力します。この例では、出力コメントから `false` が期待されています。

8.  **`// Output:` コメント**:
    *   `example_test.go` ファイルの特別なコメントで、この例を実行した際の期待される出力を示します。Goのテストツールは、このコメントと実際の出力を比較し、一致しない場合はテスト失敗とします。これにより、ドキュメントとコードの整合性が保たれます。

この例は、`math/big` パッケージの基本的な使い方から、フィボナッチ数列のような数学的な計算、そして素数判定といった応用までを網羅しており、ユーザーがパッケージの機能を理解する上で非常に役立ちます。
