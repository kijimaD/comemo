## 前提知識の解説

このコミットを理解するためには、以下の基本的なプログラミングおよびオペレーティングシステムに関する知識が必要です。

*   **プロセス (Process)**: オペレーティングシステム上で実行されるプログラムのインスタンスです。各プロセスは独自のメモリ空間、ファイルディスクリプタ、およびその他のリソースを持ちます。
*   **コマンドライン引数 (Command-line Arguments)**: プログラムを実行する際に、そのプログラムに渡される追加の情報です。例えば、`go run main.go arg1 arg2` の場合、`arg1` と `arg2` がコマンドライン引数です。プログラムはこれらの引数を解析して、動作をカスタマイズできます。
*   **環境変数 (Environment Variables)**: オペレーティングシステムが提供する、プロセス間で共有されるキーと値のペアの集合です。これらは、プログラムの動作に影響を与える設定情報（例: パス、言語設定など）を渡すために使用されます。
*   **システムコール (System Call)**: プログラムがオペレーティングシステムのカーネルに対して、特定のサービス（例: ファイルの読み書き、プロセスの作成/終了など）を要求するためのインターフェースです。Go言語では、`syscall` パッケージを通じてシステムコールを直接呼び出すことができます。
*   **プログラムの終了 (Program Exit)**: プログラムがその実行を終了することです。通常、プログラムは終了ステータスコード（または終了コード）をオペレーティングシステムに返します。慣例として、0は成功を示し、非ゼロの値はエラーを示します。

## 技術的詳細

このコミットで追加された `src/lib/os/proc.go` ファイルは、Go言語の `os` パッケージの一部として、プロセスに関する基本的な機能を提供します。具体的には、以下の3つの主要な要素を定義しています。

1.  **`Args []string`**: 実行中のプログラムに渡されたコマンドライン引数を保持する文字列スライスです。これはGoランタイムによって提供されるとコメントされています。
2.  **`Envs []string`**: 実行中のプログラムの環境変数を保持する文字列スライスです。これもGoランタイムによって提供されるとコメントされています。
3.  **`Exit(code int)` 関数**: プログラムを終了させるための関数です。引数 `code` は終了ステータスコードを表します。この関数は、`syscall` パッケージの `SYS_EXIT` システムコールを直接呼び出すことで、プログラムの終了をOSに通知します。

このファイルは、GoプログラムがOSと対話するための最も基本的なインターフェースの一つを確立するものであり、Goの標準ライブラリの基盤を形成する上で不可欠な部分です。

## コアとなるコードの変更箇所

このコミットでは、`src/lib/os/proc.go` という新しいファイルが追加されました。その内容は以下の通りです。

```go
// Copyright 2009 The Go Authors. All rights reserved.
// Use of this source code is governed by a BSD-style
// license that can be found in the LICENSE file.

package os

import (
	"os";
	"syscall";
)

var Args []string;	// provided by runtime
var Envs []string;	// provided by runtime

// Exit causes the current program to exit with the given status code.
// Conventionally, code zero indicates success, non-zero an error.
// returning exit status n.
func Exit(code int) {
	syscall.Syscall(syscall.SYS_EXIT, int64(code), 0, 0)
}
```

## コアとなるコードの解説

*   **`// Copyright 2009 The Go Authors. All rights reserved.`**: Go言語のソースコードに共通の著作権表示です。
*   **`package os`**: このファイルが `os` パッケージの一部であることを示します。`os` パッケージは、オペレーティングシステム機能へのプラットフォームに依存しないインターフェースを提供します。
*   **`import (...)`**: 必要なパッケージをインポートしています。
    *   `"os"`: これは自己参照的なインポートのように見えますが、Goの初期のコードベースではこのような記述が見られることがあります。現在のGoでは通常、`os` パッケージ内で再度 `os` をインポートすることはありません。これは、Goのモジュールシステムやパッケージ管理が成熟する前の過渡期のコードである可能性を示唆しています。
    *   `"syscall"`: オペレーティングシステムの低レベルなシステムコールにアクセスするためのパッケージです。
*   **`var Args []string; // provided by runtime`**: `Args` は文字列のスライスとして宣言されており、プログラムのコマンドライン引数を保持します。コメントにあるように、この変数の値はGoランタイムによって設定されます。
*   **`var Envs []string; // provided by runtime`**: `Envs` は文字列のスライスとして宣言されており、プログラムの環境変数を保持します。これもGoランタイムによって設定されます。
*   **`func Exit(code int) { ... }`**:
    *   `Exit` 関数は、整数型の `code` を引数にとります。この `code` はプログラムの終了ステータスを表します。
    *   `syscall.Syscall(syscall.SYS_EXIT, int64(code), 0, 0)`: ここがこの関数の核心です。
        *   `syscall.Syscall` は、指定されたシステムコールを呼び出すためのGoの関数です。
        *   `syscall.SYS_EXIT` は、プログラムを終了させるためのシステムコール番号です。
        *   `int64(code)` は、終了ステータスコードをシステムコールに渡すための引数です。
        *   残りの `0, 0` は、この特定のシステムコールでは使用されない追加の引数です。

このコードは、GoプログラムがOSレベルでどのように引数や環境変数を取得し、どのように自身を終了させるかという、非常に基本的なメカニズムを確立しています。
