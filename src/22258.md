# [インデックス 22258] ファイルの概要

このコミットは、Go言語の`time`パッケージにおける`darwin/arm`（macOSやiOSのARMアーキテクチャ）向けの`zoneinfo`（タイムゾーン情報）サポートを追加しようとした以前のコミットを元に戻す（リバートする）ものです。元の変更がDarwin環境で「壊れていた」ため、その問題を解決するためにリバートされました。

## 元コミット内容

このコミットがリバートした元のコミット（ハッシュ: `54efdc596f7b6c711e5d65d99f1c25a0ca3628f1`）のメッセージは、リバートコミットのメッセージから「time: zoneinfo support on darwin/arm」であったと推測されます。これは、Goの`time`パッケージがDarwinのARMアーキテクチャ上でタイムゾーン情報を適切に扱えるようにするための変更であったと考えられます。

## 変更の背景

Go言語の`time`パッケージは、日付と時刻の操作においてタイムゾーン情報を正確に扱うことが求められます。特に、異なる地域や夏時間（Daylight Saving Time）の適用を考慮するためには、システムが提供するタイムゾーンデータベース（`zoneinfo`または`tzdata`）を参照する必要があります。

元のコミット（`54efdc596f7b6c711e5d65d99f1c25a0ca3628f1`）は、GoがDarwin（macOSやiOS）のARMアーキテクチャ上で`zoneinfo`を適切にサポートするための試みでした。これは、Goアプリケーションがこれらの環境で動作する際に、正確なローカルタイムゾーン情報を取得できるようにすることを目的としていたと考えられます。

しかし、このコミットは「Broken on darwin.」（Darwin上で壊れている）という問題を引き起こしました。具体的な破損の詳細はコミットメッセージからは不明ですが、タイムゾーン情報の読み込みパス、パーミッション、または特定のDarwin/ARM環境での挙動が期待通りでなかった可能性が考えられます。この問題のため、安定性を確保するために元の変更を元に戻すことが決定されました。

## 前提知識の解説

*   **Goの`time`パッケージ**: Go言語の標準ライブラリの一部で、日付、時刻、期間、タイムゾーンなどを扱うための機能を提供します。`time.Now()`で現在時刻を取得したり、`time.Parse()`で文字列から時刻を解析したり、`time.LoadLocation()`で特定のタイムゾーンを読み込んだりする際に使用されます。
*   **タイムゾーン (Time Zone)**: 地球上の特定の地域で共通して使用される標準時を定めたものです。夏時間（Daylight Saving Time, DST）の導入により、年間で時刻が変更される地域もあります。
*   **`zoneinfo` (tzdata)**: タイムゾーンのルールとオフセットに関する情報を含むデータベースです。Unix系オペレーティングシステム（Linux, macOS, BSDなど）で広く利用されており、`/usr/share/zoneinfo`などのパスにファイルとして格納されています。Goの`time`パッケージは、システムの`zoneinfo`ファイルを読み込むことでタイムゾーン情報を解決します。
*   **Darwin**: Appleが開発したオペレーティングシステム（macOS、iOS、watchOS、tvOSなど）の基盤となるUnix系OSカーネルおよびコアサービス群の総称です。
*   **ARMアーキテクチャ**: Advanced RISC Machines社が設計したRISC（Reduced Instruction Set Computer）ベースのプロセッサアーキテクチャです。スマートフォン、タブレット、組み込みシステムなど、低消費電力と高性能が求められるモバイルデバイスで広く採用されています。AppleのMシリーズチップもARMベースです。
*   **Goのビルドタグ (`+build`)**: Goのソースファイルに記述される特殊なコメント行で、そのファイルが特定のビルド条件（オペレーティングシステム、アーキテクチャ、Goのバージョンなど）が満たされた場合にのみコンパイルされるように指定します。例えば、`// +build darwin,arm`は、DarwinかつARMアーキテクチャの場合にのみコンパイルされることを意味します。

## 技術的詳細

このリバートコミットは、Goの`time`パッケージがDarwinのARMアーキテクチャ上でタイムゾーン情報をどのように扱うかという問題に焦点を当てています。

元のコミットでは、`src/time/zoneinfo_darwin_armx.go`というファイルが追加され、DarwinのARM環境に特化した`zoneinfo`の読み込みロジックが実装されたと考えられます。このファイルの内容から、iOSアプリケーションバンドル内の`zoneinfo.zip`というファイルをタイムゾーン情報のソースとして利用しようとしていたことが伺えます。iOSアプリケーションはサンドボックス化されており、通常のシステムパスにある`zoneinfo`ファイルにアクセスできないため、アプリケーションバンドル内に`zoneinfo.zip`を含めるというアプローチは、iOS環境では一般的な手法です。

しかし、この実装が「Broken on darwin.」と判断されたため、以下の変更が行われました。

1.  **`src/time/zoneinfo_darwin_armx.go`の削除**: このファイル全体が削除されました。これにより、DarwinのARMアーキテクチャに特化した`zoneinfo`の読み込みロジックがGoのビルドから完全に除外されました。これは、この特定の実装が機能しなかったか、予期せぬ副作用を引き起こしたことを示唆しています。
2.  **`src/time/zoneinfo_unix.go`のビルドタグの変更**: `zoneinfo_unix.go`は、Unix系システム全般で`zoneinfo`ファイルを読み込むための汎用的なロジックを含んでいます。元のコミットでは、このファイルが`darwin`環境で`arm`および`arm64`アーキテクチャを除外するようにビルドタグが変更されていた可能性があります（`// +build darwin,!arm,!arm64`のような形）。今回のリバートにより、この除外が取り消され、`zoneinfo_unix.go`が再びDarwinのすべてのアーキテクチャ（ARMを含む）に適用されるようになりました（`// +build darwin dragonfly freebsd linux nacl netbsd openbsd solaris`）。これは、Darwin ARM環境が、特化したロジックではなく、汎用的なUnixの`zoneinfo`読み込みロジックにフォールバックすることを意味します。
3.  **`src/time/sleep_test.go`の変更**: `TestIssue5745`というテスト関数から、`darwin`かつ`arm`アーキテクチャの場合にテストをスキップするロジックが削除されました。元のスキップは「issue 10043」に関連するとコメントされていました。このスキップロジックの削除は、`zoneinfo`の変更が`sleep_test.go`に影響を与えていた可能性、または元の`zoneinfo`サポートが原因で発生していた問題がリバートによって解消されたことを示唆しています。ただし、GoのIssue 10043の詳細は現在のGoのIssueトラッカーでは確認できませんでした。

このリバートは、GoがDarwinのARM環境でタイムゾーン情報を扱うことの複雑さを示しています。特にiOSのようなサンドボックス環境では、システムファイルへのアクセスが制限されるため、`zoneinfo`のような外部データへのアクセス方法が課題となります。このコミットは、特定の環境に特化した最適化や機能追加が、予期せぬ互換性問題やバグを引き起こす可能性があることを示しています。

3.  **`src/time/zoneinfo_unix.go`**:

## コアとなるコードの解説

*   **`src/time/sleep_test.go`の変更**:
    `TestIssue5745`はタイマーの削除中にパニックが発生した場合にデッドロックが発生しないことをテストするものです。元のコミットでは、`darwin/arm`環境でこのテストがスキップされるように設定されていました。これは、元の`zoneinfo`サポートの変更が、このテストの動作に影響を与えていたか、または`darwin/arm`環境における`time`パッケージの挙動に何らかの未解決の問題（issue 10043）があったためと考えられます。今回のリバートにより、`zoneinfo`の特化ロジックが削除されたことで、このテストが再び`darwin/arm`環境でも実行されるようになりました。これは、元の`zoneinfo`サポートがこのテストの失敗の原因であったか、少なくとも関連する問題を引き起こしていたことを示唆しています。

*   **`src/time/zoneinfo_darwin_armx.go`の削除**:
    このファイルの削除は、GoがDarwinのARMアーキテクチャ向けに特別に実装していた`zoneinfo`の読み込みメカニズムが破棄されたことを意味します。このファイルには、`syscall.Getwd()`を使ってカレントワーキングディレクトリ（iOSアプリの場合、アプリバンドルのルート）から`zoneinfo.zip`を読み込もうとするロジックが含まれていました。このアプローチが「Broken on darwin.」であったため、Goは一時的にこの特化されたサポートを撤回し、より安定した（しかし、もしかしたら機能が限定されるかもしれない）汎用的なメカニズムに頼ることになりました。

*   **`src/time/zoneinfo_unix.go`のビルドタグの変更**:
    この変更は、`zoneinfo_darwin_armx.go`の削除と密接に関連しています。`zoneinfo_unix.go`は、Unix系システムで標準的な`zoneinfo`ファイルを読み込むためのコードを含んでいます。元のコミットでは、`darwin`環境のうち`arm`と`arm64`アーキテクチャをこのファイルの適用対象から除外していました。これは、`zoneinfo_darwin_armx.go`がこれらのアーキテクチャ向けに独自の`zoneinfo`読み込みを提供していたためです。`zoneinfo_darwin_armx.go`が削除されたことで、`darwin`の`arm`および`arm64`アーキテクチャも再び`zoneinfo_unix.go`の汎用的なロジックを使用するようになりました。これにより、これらの環境では、システム標準の`zoneinfo`パス（例: `/usr/share/zoneinfo`）からタイムゾーン情報を読み込もうとします。iOSのようなサンドボックス環境では、このパスへのアクセスが制限されるため、タイムゾーン情報の取得に問題が生じる可能性があります。

全体として、このリバートは、GoがDarwinのARM環境でタイムゾーン情報を扱う上での課題に直面し、一時的に特化されたサポートを撤回して、より汎用的な（しかし、特定の環境では不完全な）アプローチに戻したことを示しています。
