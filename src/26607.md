## 変更の背景

このコミットの背景には、Go 1.6の正式リリースが間近に迫っていたという状況があります。通常、ソフトウェアのリリース前には、そのリリースに関するドキュメント（リリースノートなど）が「ドラフト（下書き）」として公開され、開発者やコミュニティによるレビューや最終調整が行われます。リリースが近づき、ドキュメントの内容が確定した段階で、これらの「ドラフト」を示す表記が削除されます。

コミットメッセージにある「Go 1.6 is soon (but not yet).」という記述は、リリースが差し迫っているものの、まだ最終的なリリース日ではないことを示しています。この段階でドラフトタグを削除することで、リリースノートが最終版に近い状態であることを示し、正式リリースへの準備を進めていたと考えられます。また、「Fixes #14301」という記述から、GitHub issue #14301がこのドラフトタグの削除に関連するタスクであったことが伺えます。

## 前提知識の解説

*   **Goリリースサイクル**: Go言語は、通常6ヶ月ごとにメジャーリリースを行います。各リリースには、新機能、パフォーマンス改善、バグ修正などが含まれます。リリース前には、ベータ版やリリース候補版が公開され、コミュニティからのフィードバックを募ります。
*   **リリースノート**: リリースノートは、新しいバージョンで導入された変更点、新機能、非互換性、バグ修正などをまとめた公式ドキュメントです。ユーザーが新しいバージョンにアップグレードする際に参照する重要な情報源となります。
*   **ドラフト（DRAFT）**: ドキュメントがまだ最終版ではなく、変更される可能性があることを示すために使用される状態です。正式リリース前には、リリースノートもドラフト状態であることが一般的です。
*   **HTMLコメント `<!-- ... -->`**: HTMLファイル内で、ブラウザには表示されないが、ソースコード内に情報を残すためのコメントです。このコミットでは、HTMLコメント内のタイトル情報も変更されています。
*   **Goのドキュメント管理**: Goプロジェクトでは、公式ドキュメントもバージョン管理システム（Git）で管理されており、コードと同様にコミットを通じて変更が追跡されます。

## コアとなるコードの解説

変更された `doc/go1.6.html` は、Go言語の公式ウェブサイトで公開されるGo 1.6のリリースノートのソースファイルです。このファイルは、HTMLと、ページタイトルなどのメタデータを定義するためのJSONライクなブロックで構成されています。

*   **タイトルメタデータの変更**:
    `"Title"` フィールドは、ウェブページのタイトルとして使用されるだけでなく、検索エンジンの結果やブラウザの履歴などにも影響を与えます。`" DRAFT"` を削除することで、このドキュメントが正式なリリースノートとして扱われるべきであることを明確にしています。

*   **注意書きの削除**:
    削除された`<p>`ブロックは、リリースノートがまだベータ版のものであり、Go 1.6がまだリリースされていないことをユーザーに警告するためのものでした。この注意書きが不要になったということは、Go 1.6のリリースが非常に間近に迫っているか、あるいは既にリリースされたことを意味します（コミットメッセージの日付とGo 1.6の実際のリリース日を考慮すると、リリース直前の最終調整であった可能性が高いです）。特に、コメント `<!-- NOTE: WHEN REMOVING THIS COMMENT FIX THE TITLE AT THE TOP OF THE FILE TOO! -->` は、このブロックを削除する際にタイトルも修正する必要があることを開発者に促すものであり、このコミットでその指示が実行された形になります。

これらの変更は、Go 1.6のリリースプロセスにおける最終段階のドキュメント更新であり、ユーザーに対して最新かつ正確な情報を提供するための重要なステップです。
