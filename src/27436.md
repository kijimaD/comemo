# [インデックス 27436] ファイルの概要

このコミットは、Go言語のコマンドラインツール (`cmd/go`) から、Google Codeに特化したコードを削除するものです。Google Codeが既にシャットダウンしているため、関連するインポートパスの処理、警告メッセージ、およびテストコードが不要となり、これらが削除されました。

## 元コミット内容

このコミットは、Go言語のツールチェーンの一部である `cmd/go` から、Google Codeに関連する全ての特殊な処理を削除することを目的としています。具体的には、Google Codeのインポートパスの認識、シャットダウンに関する警告メッセージ、および関連するテストコードが対象です。Google Codeが既にサービスを終了しているため、これらのコードは不要となり、メンテナンスの負担を減らすために削除されました。

以前のコミット `4ec2fd3e6ac4f869d39348bf48016687b731d910` では、Google Codeのシャットダウン警告を残すべきかという議論がありましたが、Go 1.6からは既に警告が削除されており、Go 1.7のリリース時にはユーザーがGoogle Codeの終了を認識していると判断されたため、完全に削除する運びとなりました。

この変更は、Issue #10193 に関連しています。

## 変更の背景

変更の背景には、主に以下の点があります。

1.  **Google Codeのシャットダウン**: Google Codeは、Googleが提供していたオープンソースプロジェクトのホスティングサービスでしたが、2015年3月に新規プロジェクトの作成を停止し、2016年1月25日に完全にシャットダウンしました。これにより、`code.google.com` ドメインでホストされていたリポジトリはアクセスできなくなりました。
2.  **Goツールの保守性**: Google Codeのサポートコードは、もはや機能しないサービスのためのものであり、Goツールのコードベースを不必要に複雑にしていました。これを削除することで、コードの保守性が向上し、将来的な変更が容易になります。
3.  **ユーザーへの影響の最小化**: Google Codeのシャットダウンから時間が経過し、Go 1.6で既に警告が削除されていたことから、Go 1.7のリリース時にはほとんどのユーザーがこの変更に適応していると判断されました。そのため、関連コードを完全に削除しても大きな混乱は生じないと見込まれました。

## 前提知識の解説

*   **Go Modulesと`go get`**: Go言語では、外部パッケージの依存関係を管理するためにGo Modulesが導入されています。それ以前は、`go get` コマンドが主に外部リポジトリからソースコードを取得し、`GOPATH` に配置する役割を担っていました。`go get` は、インポートパスに基づいて、GitHub、Bitbucket、Google Codeなどの様々なバージョン管理システム (VCS) ホスティングサービスからコードを自動的にダウンロードする機能を持っていました。
*   **バージョン管理システム (VCS)**: Git, Mercurial (hg), Subversion (svn) など、ソフトウェアのソースコードの変更履歴を管理するためのシステムです。Google Codeはこれら複数のVCSをサポートしていました。
*   **Google Code**: かつてGoogleが提供していたオープンソースプロジェクトのホスティングサービス。多くのGoプロジェクトもここでホストされていましたが、GitHubなどの他のサービスへの移行が進み、最終的にシャットダウンしました。
*   **インポートパス**: Go言語において、パッケージを識別し、インポートするために使用される文字列です。例えば、`"github.com/user/project"` のような形式です。`go get` はこのインポートパスを解析して、どのVCSホスティングサービスからどのリポジトリを取得すべきかを判断します。

## 技術的詳細

このコミットは、`cmd/go` ツールがGoogle Codeのインポートパスを特別に扱うためのロジックを完全に削除します。具体的には、以下のファイル群からGoogle Codeに関連する記述が削除されています。

*   `src/cmd/go/alldocs.go` および `src/cmd/go/help.go`: `go doc` や `go help` コマンドで表示されるドキュメントやヘルプメッセージから、Google Codeのインポートパスの例が削除されました。これは、もはや有効ではない情報を提供しないようにするためです。
*   `src/cmd/go/get.go`: `go get` コマンドの主要なロジックが含まれるファイルです。ここから、`code.google.com` で始まるインポートパスに対するシャットダウン警告メッセージの出力ロジックが削除されました。
*   `src/cmd/go/vcs.go`: `go get` が様々なVCSホスティングサービスを認識し、それらのリポジトリからコードを取得するためのロジックが含まれるファイルです。このファイルから、Google Codeのインポートパスを解析するための正規表現 (`vcsPaths` 変数内のエントリ) や、Google CodeのリポジトリからVCSタイプを検出するための `googleCodeVCS` 関数、古いGoogle Codeのパスを処理する `oldGoogleCode` 関数など、Google Codeに特化した全てのコードが削除されました。
*   `src/cmd/go/go_test.go` および `src/cmd/go/vcs_test.go`: Google Codeのインポートパスの処理をテストするためのテストケースが削除されました。サービスがシャットダウンしているため、これらのテストはもはや実行できず、コードベースから削除することが適切です。特に `TestIssue10193` はGoogle Codeへの依存が明示されており、スキップされていましたが、このコミットで完全に削除されました。

これらの変更は、GoツールがGoogle Codeの存在を完全に「忘れる」ことを意味し、コードベースのクリーンアップと簡素化に貢献します。

## コアとなるコードの解説

`src/cmd/go/vcs.go` の変更を例に取ると、`vcsPaths` という変数には、GoのインポートパスがどのVCSホスティングサービスに属するかを識別するための正規表現パターンと関連する処理が定義されていました。このコミットでは、Google Codeに対応する以下のエントリが削除されました。

```go
// Google Code - new syntax
{
	prefix: "code.google.com/",
	re:     `^(?P<root>code\\.google\\.com/p/(?P<project>[a-z0-9\\-]+)(\\.(?P<subrepo>[a-z0-9\\-]+))?)(/[A-Za-z0-9_.\\-]+)*$`,
	repo:   "https://{root}",
	check:  googleCodeVCS,
},

// Google Code - old syntax
{
	re:    `^(?P<project>[a-z0-9_\\-.]+)\\.googlecode\\.com/(git|hg|svn)(?P<path>/.*)?$`,
	check: oldGoogleCode,
},
```

これらのエントリは、`code.google.com/p/project` のような新しい形式のパスと、`project.googlecode.com/git` のような古い形式のパスを識別するために使用されていました。これらが削除されたことで、`go get` はもはやGoogle Codeのインポートパスを特別に処理しようとはしません。

また、`googleCodeVCS` 関数と `oldGoogleCode` 関数も削除されました。`googleCodeVCS` は、Google Codeのプロジェクトの `/source/checkout` ページをスクレイピングしてVCSタイプ（hg, git, svn）を特定する複雑なロジックを持っていました。`oldGoogleCode` は、古い形式のGoogle Codeパスが使用された場合に、新しい形式のパスを使用するように促すエラーメッセージを生成していました。これらの関数が削除されたことで、GoツールはGoogle Codeに関連するネットワークリクエストやエラー処理を行う必要がなくなりました。

`src/cmd/go/get.go` から削除された警告メッセージのロジックは以下のようになります。

```go
// Warn that code.google.com is shutting down. We
// issue the warning here because this is where we
// have the import stack.
if strings.HasPrefix(p.ImportPath, "code.google.com") {
	fmt.Fprintf(os.Stderr, "warning: code.google.com is shutting down; import path %v will stop working\\n", p.ImportPath)
	if len(*stk) > 1 {
		fmt.Fprintf(os.Stderr, "warning: package %v\\n", strings.Join(*stk, "\\n\\timports "))
	}
}
```

このコードは、`code.google.com` で始まるインポートパスが検出された場合に、標準エラー出力に警告メッセージを表示していました。この警告は、Google Codeのシャットダウンが進行中であることをユーザーに知らせるためのものでしたが、サービスが完全に終了したため、もはや不要となりました。
