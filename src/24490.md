## 変更の背景

Go 1.5のリリースでは、Go言語のコンパイラとランタイムがC言語からGo言語自体で完全に書き直されるという、Goの歴史上でも画期的な変更が行われました。この大きな変更に伴い、各プラットフォームへの対応状況も大きく進化しました。

このコミットは、Go 1.5におけるSolarisオペレーティングシステムへのサポート強化を公式ドキュメントに反映させることを目的としています。特に、Solaris環境でのGo開発者にとって重要な機能であるcgo（GoとC言語の相互運用）の完全サポート、およびネットワーク関連機能を提供する`net`パッケージ、暗号化および証明書関連機能を提供する`crypto/x509`パッケージの改善が実現されました。これらの機能強化は、Solaris上でより複雑なGoアプリケーションを開発する上で不可欠であり、その情報をリリースノートに明記することで、ユーザーに最新の対応状況を伝える必要がありました。

コミットメッセージにある `Fixes #11952` は、おそらくGoプロジェクトの内部的な課題追跡システムにおける特定の課題を指しており、その課題がSolarisサポートの改善に関連していたことを示唆しています。

## 前提知識の解説

*   **Go言語 (Golang)**: Googleによって開発されたオープンソースのプログラミング言語。シンプルさ、効率性、並行処理のサポートが特徴です。
*   **Go 1.5**: 2015年8月にリリースされたGo言語のメジャーバージョン。このバージョンでは、GoコンパイラとランタイムがGo自身で書き直され（"self-hosting"）、ガベージコレクタの改善、`GOMAXPROCS`のデフォルト値変更など、多くの重要な変更が導入されました。
*   **Solaris**: Sun Microsystems（現在はOracleが所有）によって開発されたUNIXベースのオペレーティングシステム。特にエンタープライズ環境での高い信頼性とスケーラビリティで知られています。
*   **cgo**: Go言語の機能の一つで、C言語のコードをGoプログラムから呼び出したり、GoのコードをC言語から呼び出したりするためのメカニズムを提供します。これにより、既存のCライブラリをGoプロジェクトで利用したり、パフォーマンスが重要な部分をCで記述したりすることが可能になります。
*   **`net`パッケージ**: Goの標準ライブラリの一部で、TCP/IP、UDP、DNSルックアップなど、ネットワークプログラミングのための基本的な機能を提供します。
*   **`crypto/x509`パッケージ**: Goの標準ライブラリの一部で、X.509証明書とPKIX（Public Key Infrastructure X.509）に関する機能を提供します。これには、証明書の解析、検証、証明書署名要求（CSR）の生成などが含まれます。SSL/TLS通信やセキュアなアプリケーション開発において重要な役割を果たします。
*   **ドキュメンテーション**: ソフトウェアの機能、使用方法、変更点などを記述した文書。特にリリースノートは、新しいバージョンで何が変更されたか、どのような新機能が追加されたか、どのような改善が行われたかをユーザーに伝える上で非常に重要です。

## 技術的詳細

このコミット自体はコードの機能的な変更ではなく、Go 1.5のリリースノートである`doc/go1.5.html`ファイルへの情報追加です。しかし、その背後にある技術的詳細は、Go 1.5におけるSolarisサポートの成熟度を示しています。

Go 1.5以前のSolarisサポートは、cgoや特定の標準ライブラリ（`net`, `crypto/x509`）において完全ではなかった可能性があります。これらのパッケージは、OSのシステムコールやCライブラリと密接に連携する必要があるため、特定のプラットフォームへの移植には多くの作業が伴います。

*   **cgoの完全サポート**: Solaris上でcgoが完全に機能するようになったということは、GoプログラムがSolarisのネイティブCライブラリ（例えば、システムAPIや既存のサードパーティライブラリ）を問題なく利用できるようになったことを意味します。これは、Solaris環境でGoアプリケーションを開発する際の柔軟性と表現力を大幅に向上させます。
*   **`net`パッケージの改善**: `net`パッケージは、ネットワーク通信を行う上でOSのネットワークスタックと深く連携します。Solaris環境での`net`パッケージの改善は、TCP/IPソケットの操作、DNS解決、ネットワークインターフェース情報の取得などが、Solarisの特性に合わせて最適化され、安定して動作するようになったことを示唆しています。Go 1.5では、多くのUnix系システム（Solarisを含む）で`net`パッケージのDNSリゾルバがデフォルトでcgoを必要としなくなったという変更もあり、これはSolaris上でのGoプログラムの実行を簡素化し、OSリソース消費を削減する効果がありました。
*   **`crypto/x509`パッケージの改善**: `crypto/x509`パッケージは、証明書の検証や管理において、OSの証明書ストアや暗号化ライブラリと連携することがあります。Solarisでのこのパッケージの改善は、GoアプリケーションがSolaris環境でセキュアな通信（HTTPSなど）を確立する際に、証明書の検証が正しく行われ、信頼性の高い暗号化機能が利用できるようになったことを意味します。

これらの改善は、Go 1.5の「Go自身によるGoの書き換え」という大きな変更の中で、各プラットフォーム固有の課題が解決され、Goがより多くの環境で「ファーストクラス」の言語として機能するようになった証拠と言えます。

## コアとなるコードの解説

追加されたHTMLスニペットは、Go 1.5のリリースノートにおいて、Solarisユーザー向けの重要な情報を伝達しています。

最初の追加された段落：
```html
<p>
The Solaris port now has full support for cgo and the packages
<a href="/pkg/net/"><code>net</code></a> and
<a href="/pkg/crypto/x509/"><code>crypto/x509</code></a>,
as well as a number of other fixes and improvements.
</p>
```
この部分は、Go 1.5でSolarisへの移植が大幅に進歩したことを明確に述べています。特に、cgo、`net`パッケージ、`crypto/x509`パッケージが「完全なサポート」を得たことが強調されています。これは、Solaris上でGoアプリケーションがこれらの重要な機能（Cライブラリとの連携、ネットワーク通信、セキュリティ関連処理）を完全に、かつ安定して利用できるようになったことを意味します。また、「その他の修正と改善」という記述は、これらの主要な機能以外にも、Solaris固有のバグ修正やパフォーマンス最適化が行われたことを示唆しています。

二番目の追加された段落：
```html
<p>
Solaris now has full cgo support.
</p>
```
この短い段落は、cgoの完全サポートという点を再度強調しています。cgoはGoとCの相互運用性を提供するため、既存のシステムライブラリやパフォーマンスが重要な部分をCで記述したコードとGoを連携させる上で非常に重要です。この機能が完全にサポートされたことは、Solaris上でのGoの適用範囲を大きく広げることになります。この記述は、cgoの重要性を鑑みて、特に独立した段落として再度言及する価値があると判断されたものと考えられます。

これらの変更は、Go 1.5がSolarisプラットフォームにとってより堅牢で機能豊富な選択肢となったことを、公式ドキュメントを通じてユーザーに伝えるためのものです。
