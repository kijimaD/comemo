# [インデックス 27420] ファイルの概要

このコミットは、GoランタイムとCGO（C言語との相互運用機能）において、ARM64アーキテクチャでの浮動小数点（FP）レジスタの保存に関する重要な修正を導入しています。具体的には、CGO呼び出しを行う際に、呼び出された関数（callee）によって保存されるべき浮動小数点レジスタが適切に保存・復元されていなかった問題を解決し、データ破損のリスクを排除します。

## 元コミット内容

`runtime, runtime/cgo: save callee-saved FP registers on arm64`

このコミットは、GoランタイムおよびCGOにおいて、ARM64アーキテクチャでcallee-saved（呼び出し先保存）浮動小数点レジスタを保存するように修正します。これはIssue #14876に対応するものです。

## 変更の背景

この変更は、GoのIssue #14876「runtime/cgo: crosscall2 must save all callee-saved registers (xmm, VFP, etc.)」に対応するために行われました。このIssueは、Goランタイムの`crosscall2`関数（CGO呼び出しに使用される）が、Cコードを呼び出す際に、一部のcallee-savedレジスタ、特にARM64アーキテクチャにおけるVFP（Vector Floating-Point）レジスタを適切に保存していなかったというバグを指摘していました。

この問題が発生すると、CGOを介してC関数が呼び出された際に、C関数がこれらのレジスタの値を変更しても、Goランタイムがその変更を認識せず、Goコードに戻ったときに予期せぬデータ破損や誤動作を引き起こす可能性がありました。特に、浮動小数点演算を多用するCライブラリを使用する場合に顕著な問題となります。このコミットは、この潜在的なデータ破損を防ぎ、GoとCの間の相互運用性の堅牢性を向上させることを目的としています。

## 前提知識の解説

### ARM64アーキテクチャ

ARM64（AArch64）は、ARMv8-A命令セットアーキテクチャに基づく64ビットプロセッサアーキテクチャです。スマートフォン、タブレット、サーバーなど、幅広いデバイスで利用されています。ARM64は、レジスタの数や命令セットが従来のARM32とは異なり、特に浮動小数点演算やSIMD（Single Instruction, Multiple Data）演算を効率的に実行するためのVFP/SIMDレジスタセットを備えています。

### レジスタと呼び出し規約（Calling Convention）

CPUのレジスタは、プログラムがデータを一時的に格納するために使用する高速な記憶領域です。関数呼び出しが行われる際には、これらのレジスタの値をどのように扱うかについて、特定のルール（呼び出し規約、Calling Convention）が定められています。

*   **Caller-saved registers（呼び出し元保存レジスタ）**: 呼び出し元（caller）の関数が、呼び出し先（callee）の関数を呼び出す前に、これらのレジスタの値をスタックに保存する責任があります。呼び出し先関数はこれらのレジスタを自由に変更できます。
*   **Callee-saved registers（呼び出し先保存レジスタ）**: 呼び出し先（callee）の関数が、自身の処理を開始する前にこれらのレジスタの値をスタックに保存し、関数から戻る前に元の値を復元する責任があります。これにより、呼び出し元関数は、これらのレジスタの値が関数呼び出しによって変更されないことを保証できます。

### ARM64の浮動小数点（FP）レジスタとAAPCS64

ARM64アーキテクチャでは、浮動小数点演算やSIMD演算のためにVFP/SIMDレジスタ（`V0`から`V31`）が提供されています。これらのレジスタは、データサイズに応じて`B`（8ビット）、`H`（16ビット）、`S`（32ビット）、`D`（64ビット）、`Q`（128ビット）としてアクセスできます。

ARM64の標準的な呼び出し規約であるAAPCS64（Procedure Call Standard for the ARM 64-bit Architecture）では、`V8`から`V15`（またはGoアセンブリの文脈では`F8`から`F15`）がcallee-saved浮動小数点レジスタとして定義されています。つまり、C関数がこれらのレジスタを使用する場合、そのC関数は呼び出し元（Goランタイム）のためにこれらのレジスタの値を保存し、復元する責任があります。しかし、GoランタイムがCGO呼び出しを行う際には、Go側もこれらのレジスタの保存・復元を適切に行う必要があります。

### GoランタイムとCGO

Go言語は、C言語で書かれたライブラリを呼び出すためのCGO（C Go）というメカニズムを提供しています。CGOを使用すると、Goプログラムから既存のCライブラリの関数を呼び出したり、Cのデータ構造を扱ったりすることができます。Goランタイムは、CGO呼び出しを行う際に、Goの実行コンテキストからCの実行コンテキストへ、そしてCからGoへと安全に切り替えるための複雑な処理を行います。これには、レジスタの保存・復元、スタックの切り替えなどが含まれます。`crosscall2`は、このコンテキスト切り替えの一部を担うGoランタイム内のアセンブリ関数です。

## 技術的詳細

このコミットの核心は、ARM64アーキテクチャにおけるCGO呼び出しの際に、Goランタイムがcallee-saved浮動小数点レジスタ（`F8`から`F15`）を適切に保存・復元していなかったという問題の修正です。

Goランタイムの`crosscall2`関数は、GoからCへの呼び出しを行う際の中間層として機能します。この関数は、Cの呼び出し規約に従って、Goのレジスタ状態を保存し、C関数が安全に実行できるように準備します。しかし、これまでは整数レジスタの一部は保存されていましたが、AAPCS64でcallee-savedとされている浮動小数点レジスタ`F8`から`F15`は保存されていませんでした。

このコミットでは、以下の3つのアセンブリファイルが変更されています。

1.  `src/runtime/cgo/asm_arm64.s`: `crosscall2`関数が定義されているファイルです。ここでは、CGO呼び出しの前後で`F8`から`F15`までの浮動小数点レジスタがスタックに保存され、復元されるように修正されました。これにより、C関数がこれらのレジスタを自由に使用しても、Goランタイムの浮動小数点状態が破損することがなくなります。
2.  `src/runtime/rt0_darwin_arm64.s`: Darwin（macOS/iOS）上のARM64環境におけるGoランタイムの初期化コードです。特に、共有ライブラリとしてビルドされたGoプログラム（`-buildmode=c-shared`）がCから呼び出される際の`_rt0_arm64_darwin_lib`関数において、同様に`F8`から`F15`レジスタの保存・復元が追加されました。
3.  `src/runtime/rt0_linux_arm64.s`: Linux上のARM64環境におけるGoランタイムの初期化コードです。Darwinの場合と同様に、共有ライブラリとしてビルドされたGoプログラムがCから呼び出される際の`_rt0_arm64_linux_lib`関数において、`F8`から`F15`レジスタの保存・復元が追加されました。

これらの変更により、GoランタイムはCGO呼び出しの際に、ARM64の呼び出し規約に完全に準拠し、浮動小数点レジスタの状態を確実に保護するようになりました。

## コアとなるコードの解説

変更の中心は、ARM64アセンブリにおけるレジスタの保存と復元です。

*   **`SUB $(8*24), RSP` / `ADD $(8*24), RSP`**:
    *   `RSP`はスタックポインタレジスタです。
    *   `SUB`命令はスタックポインタの値を減算し、スタックフレームを拡張します。`$(8*24)`は`192`バイトを意味し、これは既存のレジスタ保存領域に加えて、8つの浮動小数点レジスタ（各8バイト）を保存するための領域（`8 * 8 = 64`バイト）が追加されたことを示します。
    *   `ADD`命令はスタックポインタの値を加算し、スタックフレームを解放します。
*   **`FMOVD Fx, (offset)(RSP)`**:
    *   `FMOVD`はARM64アセンブリにおける浮動小数点レジスタの移動命令です。`D`はダブルプレシジョン（64ビット）を意味します。
    *   `Fx`は浮動小数点レジスタ（`F8`から`F15`）を示します。
    *   `(offset)(RSP)`は、スタックポインタ`RSP`からのオフセット位置にあるメモリを指します。
    *   この命令は、指定された浮動小数点レジスタ`Fx`の値を、スタック上の指定されたオフセット位置に保存します。これはCGO呼び出しが行われる前に実行され、Goランタイムの浮動小数点状態を保護します。
*   **`FMOVD (offset)(RSP), Fx`**:
    *   この命令は、スタック上の指定されたオフセット位置に保存されていた値を、浮動小数点レジスタ`Fx`に復元します。これはCGO呼び出しが完了し、Goランタイムに制御が戻る直前に実行されます。

これらの命令の追加により、GoランタイムはCGO呼び出しの前後で、ARM64のcallee-saved浮動小数点レジスタの値を確実に保存・復元するようになり、CGOを介したGoとCの相互作用におけるデータ破損のリスクが解消されました。
