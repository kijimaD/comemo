# [インデックス 23932] ファイルの概要

このコミットは、Go言語の標準ライブラリ `text/scanner` パッケージに、実行可能なサンプルコードを追加するものです。具体的には、`src/text/scanner/example_test.go` という新しいファイルが追加され、`scanner.go` 内にあった基本的な使用方法を示すコメントブロックが削除されました。これにより、パッケージのドキュメントが改善され、ユーザーが `text/scanner` の使い方をより簡単に理解できるようになります。

## コミット

`text/scanner` パッケージに実行可能なサンプル（`Example`関数）を追加し、既存の`scanner.go`ファイルから冗長なコメントによる使用例を削除しました。

## 変更の背景

Go言語のドキュメンテーションシステムでは、`_test.go` ファイル内に `Example` というプレフィックスを持つ関数を記述することで、その関数がパッケージのドキュメントに表示され、かつ `go test` コマンドによって実行・検証される「実行可能なサンプルコード」として扱われます。

このコミット以前は、`text/scanner` パッケージの基本的な使用方法は `scanner.go` ファイル内のコメントブロックとして記述されていました。コメント内のコードは、実際に実行して動作を確認することができず、また、コードの変更によってコメントの内容が古くなるリスクがありました。

この変更の背景には、以下の目的があります。

1.  **ドキュメントの品質向上**: 実行可能なサンプルコードを提供することで、ユーザーは実際にコードを動かしながらパッケージの挙動を理解できるようになります。これは、静的なコメントよりもはるかに効果的な学習方法です。
2.  **コードとドキュメントの一貫性の維持**: `Example` 関数は `go test` によって自動的に実行され、その出力が期待される出力（`// Output:` コメントで指定）と一致するか検証されます。これにより、サンプルコードが常に最新かつ正確であることを保証できます。コメント内のコードではこのような自動検証はできません。
3.  **Goの慣習への準拠**: Goコミュニティでは、パッケージの基本的な使い方を示すために `Example` 関数を使用することが推奨されています。この変更は、その慣習に沿ったものです。

## 前提知識の解説

このコミットを理解するためには、以下のGo言語の概念とパッケージに関する知識が役立ちます。

### 1. `text/scanner` パッケージ

`text/scanner` パッケージは、Go言語の字句解析器（lexer/scanner）を提供します。これは、入力テキストストリームをトークン（単語、数字、記号など）に分割するために使用されます。コンパイラやインタープリタ、構文ハイライターなどのツールで、ソースコードや設定ファイルを解析する際の最初のステップとして利用されます。

*   **`scanner.Scanner`**: 字句解析器の主要な構造体です。`Init` メソッドで入力ソース（`io.Reader`）を設定し、`Scan` メソッドを繰り返し呼び出すことで次のトークンを取得します。
*   **`scanner.TokenText()`**: 現在スキャンされたトークンのテキスト表現を返します。
*   **`scanner.Pos()`**: 現在スキャンされたトークンの開始位置（行番号と列番号）を返します。
*   **`scanner.EOF`**: 入力ストリームの終端を示す特別なトークンです。

### 2. Goのテストとドキュメンテーションにおける `Example` 関数

Go言語では、`_test.go` で終わるファイルに記述された特定の形式の関数が、テストだけでなくドキュメンテーションにも利用されます。

*   **`func Example()`**: パッケージ全体の基本的な使用方法を示すサンプルコードです。
*   **`func Example_suffix()`**: パッケージ内の特定の機能や型に焦点を当てたサンプルコードです。
*   **`func ExampleType()`**: `Type` という名前の型に関するサンプルコードです。
*   **`func ExampleType_Method()`**: `Type` 型の `Method` メソッドに関するサンプルコードです。

これらの `Example` 関数は、`go doc` コマンドで生成されるドキュメントに表示されます。さらに、関数内に `// Output:` というコメント行とその後に続く期待される出力を含めることで、`go test` コマンドがサンプルコードを実行し、実際の出力が期待される出力と一致するかどうかを自動的に検証します。これにより、ドキュメント内のコードが常に正しく動作することが保証されます。

### 3. `strings.NewReader`

`strings.NewReader` は、文字列を `io.Reader` インターフェースを満たすオブジェクトに変換する関数です。`text/scanner` パッケージの `Init` メソッドは `io.Reader` を引数として取るため、この関数を使って文字列リテラルをスキャナーの入力として渡すことができます。

## 技術的詳細

このコミットの技術的詳細は、主にGoのドキュメンテーションとテストの仕組みを効果的に利用することにあります。

`text/scanner` パッケージは、Goのソースコードのような構造化されたテキストを解析するための汎用的なツールです。このパッケージの利用者は、通常、特定の言語の構文解析器を構築する際に、まず字句解析の段階で `text/scanner` を利用します。そのため、その基本的な使い方を明確かつ検証可能な形で示すことは非常に重要です。

追加された `Example` 関数は、以下のステップで `text/scanner` の典型的な使用パターンを示しています。

1.  **入力ソースの準備**: `const src` で解析対象となるGo言語風のコードスニペットを定義します。
2.  **スキャナーの初期化**: `var s scanner.Scanner` でスキャナーのインスタンスを作成し、`s.Init(strings.NewReader(src))` で文字列リテラルを `io.Reader` としてスキャナーに渡します。
3.  **トークンのスキャン**: `for tok != scanner.EOF` ループを使って、`s.Scan()` を繰り返し呼び出し、入力ストリームの終端（`scanner.EOF`）に達するまでトークンを一つずつ取得します。
4.  **トークンの処理**: ループ内で `fmt.Println("At position", s.Pos(), ":", s.TokenText())` を使って、各トークンの位置とテキスト内容を出力します。これにより、スキャナーがどのようにテキストをトークンに分割し、それぞれのトークンがどこにあるかを視覚的に確認できます。
5.  **出力の検証**: `// Output:` コメントブロックに期待される出力を記述することで、`go test` コマンドがこのサンプルコードを実行した際に、実際の出力がこの期待値と一致するかを自動的に検証します。これにより、サンプルコードの正確性が保証されます。

一方、`scanner.go` から削除されたコメントブロックは、同じような使用パターンを示していましたが、これは単なるテキストであり、コンパイルエラーや実行時の問題が発生しても検出されませんでした。`Example` 関数への移行により、この問題が解決され、パッケージのメンテナンス性が向上しました。

```go
package scanner_test

import (
	"fmt"
	"strings"
	"text/scanner"
)

func Example() {
	const src = `
	// This is scanned code.
	if a > 10 {
		someParsable = text
	}`
	var s scanner.Scanner
	s.Init(strings.NewReader(src))
	var tok rune
	for tok != scanner.EOF {
		tok = s.Scan()
		fmt.Println("At position", s.Pos(), ":", s.TokenText())
	}

	// Output:
	// At position 3:4 : if
	// At position 3:6 : a
	// At position 3:8 : >
	// At position 3:11 : 10
	// At position 3:13 : {
	// At position 4:15 : someParsable
	// At position 4:17 : =
	// At position 4:22 : text
	// At position 5:3 : }
	// At position 5:3 : 
}
```

## コアとなるコードの解説

### `src/text/scanner/example_test.go` の解説

*   **`package scanner_test`**: このサンプルコードが `scanner` パッケージの外部にあることを示します。これにより、パッケージの公開APIのみを使用してテストおよびサンプルが記述されていることが保証されます。
*   **`import` ブロック**: `fmt` (出力用)、`strings` (文字列を `io.Reader` に変換するため)、`text/scanner` (対象パッケージ) をインポートしています。
*   **`func Example()`**: Goのドキュメンテーションツールによって認識され、実行されるサンプル関数です。
*   **`const src = ...`**: 字句解析の対象となるGo言語風のコードスニペットを定義しています。これにはコメント、キーワード、識別子、演算子、数値リテラルなどが含まれており、`text/scanner` がこれらをどのようにトークン化するかを示すのに適しています。
*   **`var s scanner.Scanner`**: `scanner.Scanner` 型の変数を宣言し、字句解析器のインスタンスを作成します。
*   **`s.Init(strings.NewReader(src))`**: スキャナーを初期化します。`strings.NewReader(src)` は、定義した文字列 `src` を `io.Reader` インターフェースを満たすオブジェクトに変換し、スキャナーの入力ソースとして設定します。
*   **`for tok != scanner.EOF { ... }`**: ループを使って、入力ストリームの終端（`scanner.EOF`）に達するまでトークンをスキャンし続けます。
*   **`tok = s.Scan()`**: 次のトークンをスキャンし、その種類（`rune` 型）を `tok` に格納します。
*   **`fmt.Println("At position", s.Pos(), ":", s.TokenText())`**: スキャンされた各トークンの詳細を出力します。
    *   `s.Pos()`: 現在のトークンの開始位置（行番号と列番号）を返します。
    *   `s.TokenText()`: 現在のトークンの文字列表現を返します。
*   **`// Output:` コメントブロック**: このコメントブロックは、`go test` コマンドがこの `Example` 関数を実行した際に期待される標準出力の内容を定義します。`go test` は、実際の出力とこのコメントの内容を比較し、一致しない場合はテストを失敗させます。これにより、サンプルコードが常に正しく動作し、ドキュメントが最新の状態に保たれることが保証されます。

### `src/text/scanner/scanner.go` からの削除部分の解説

削除されたコメントブロックは、`text/scanner` パッケージの基本的な使用パターンを説明するものでした。これは、`Example` 関数が追加される前の、パッケージのドキュメントの一部として機能していました。

```go

```

このコメントは、`Example` 関数が提供する実行可能で検証可能なサンプルコードによって置き換えられました。コメントの削除は、冗長な情報の排除と、ドキュメントの品質向上を目的としています。
