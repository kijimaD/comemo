## 変更の背景

このコミットは、Go 1.4のリリースに向けたドキュメントの更新の一環です。Goの標準ライブラリである `fmt` パッケージにおいて、マップ型へのポインタ（例: `*map[string]int`）のデフォルトの出力形式が変更されました。以前は、このようなポインタを `fmt.Print` や `fmt.Printf` で出力すると、単にポインタのアドレス（例: `0x12345678`）が表示されていました。しかし、Go 1.4からは、マップの内容をデリファレンスした形式、つまり `&map[キー:値 キー:値]` のように表示されるようになりました。

この変更は、デバッグ時やログ出力時に、マップへのポインタを直接出力するだけでその内容を確認できるようになり、開発者の利便性を向上させるためのものです。このコミットは、この重要な変更がGo 1.4のリリースノートに明記され、ユーザーが新しい挙動を認識できるようにすることを目的としています。

## 前提知識の解説

### Go言語の`fmt`パッケージ

`fmt`パッケージは、Go言語におけるフォーマットされたI/O（入出力）を実装するための標準ライブラリです。C言語の`printf`や`scanf`に似た機能を提供し、様々なデータ型を文字列として整形して出力したり、文字列からデータを読み取ったりすることができます。

*   **`fmt.Print` / `fmt.Println`**: 引数をデフォルトのフォーマットで出力します。`Println`は改行を追加します。
*   **`fmt.Printf`**: フォーマット指定子（バーブ）を使用して、より詳細なフォーマットで出力します。
    *   **`%v`**: 値のデフォルトのフォーマットで出力します。構造体やマップなどの複合型の場合、その内容が再帰的に表示されます。
    *   **`%p`**: ポインタのアドレスを16進数で出力します。
    *   **`%T`**: 値の型名を出力します。

### ポインタ

Go言語におけるポインタは、変数のメモリアドレスを保持する特殊な変数です。ポインタを使用することで、関数間で大きなデータ構造をコピーすることなく参照渡ししたり、データの共有や変更を効率的に行ったりすることができます。

*   **`&`演算子**: 変数のアドレスを取得します。例: `p := &x` は変数`x`のアドレスを`p`に代入します。
*   **`*`演算子**: ポインタが指すアドレスに格納されている値（デリファレンス）を取得します。例: `v := *p` はポインタ`p`が指すアドレスの値を`v`に代入します。

### マップ

Go言語のマップ（`map`）は、キーと値のペアを格納するハッシュテーブルの実装です。キーは一意であり、値に効率的にアクセスするために使用されます。マップは参照型であり、変数にマップを代入したり関数に渡したりすると、マップのヘッダ（内部データ構造へのポインタ）がコピーされるだけで、基となるデータは共有されます。

*   マップの宣言例: `m := make(map[string]int)`
*   要素の追加/アクセス: `m["key"] = 10`, `value := m["key"]`

### Goのリリースノート (`doc/go1.4.txt`)

Go言語では、各メジャーリリース（例: Go 1.4, Go 1.5）において、そのバージョンで導入された新機能、変更点、非互換性などが詳細に記述されたリリースノートが提供されます。これらのリリースノートは通常、`doc/goX.Y.txt` のようなファイルとしてGoのソースツリー内に存在し、公式ウェブサイトでも公開されます。開発者はこれらのドキュメントを参照することで、新しいバージョンへの移行や、特定の機能の挙動変更を理解することができます。

## 技術的詳細

このコミットが文書化している技術的な変更は、Goの`fmt`パッケージがマップへのポインタをフォーマットする際の挙動の変更です。

Goの`fmt`パッケージは、`fmt.Print`、`fmt.Println`、`fmt.Printf`などの関数を通じて、Goの様々なデータ型を人間が読める形式の文字列に変換します。特に`%v`バーブは、値のデフォルト表現を出力するために広く使用されます。

変更前は、`*map[T]T`（マップへのポインタ）を`%v`で出力すると、Goの他のポインタ型と同様に、そのポインタが指すメモリアドレスが16進数形式で表示されていました。例えば、`var m *map[string]int` があり、`m`が有効なマップを指している場合、`fmt.Println(m)` は `0x123abc` のような出力になることがありました。

しかし、Go 1.4で導入された変更により、`fmt`パッケージはマップへのポインタを特別に扱い、そのポインタが指すマップの**内容**をデリファレンスして表示するようになりました。この新しい挙動では、`&`記号がポインタであることを示し、その後にマップのリテラル表現（`map[キー:値 キー:値]`）が続きます。例えば、`m`が`map[string]int{"a": 1, "b": 2}`を指している場合、`fmt.Println(m)` は `&map[a:1 b:2]` のような出力になります。

この変更は、デバッグの際に非常に有用です。開発者は、マップへのポインタ変数を単にプリントするだけで、そのマップが現在どのような状態にあるのか、どのようなキーと値のペアを持っているのかを即座に確認できるようになります。これにより、コードの挙動を追跡し、問題を特定するプロセスが簡素化されます。

このドキュメントの更新は、`fmt`パッケージの内部的な変更（`CL 154870043`で実装されたとされる）を反映したものであり、Go 1.4にアップグレードするユーザーがこの新しい出力形式に戸惑わないようにするためのものです。

## コアとなるコードの解説

追加された行 `fmt: print type *map[T]T as &map[k:v] (CL 154870043)` は、Go 1.4における`fmt`パッケージの重要な変更点を簡潔に説明しています。

*   `fmt:`: この変更が`fmt`パッケージに関連することを示します。
*   `print type *map[T]T as &map[k:v]`: これが変更の核心です。
    *   `*map[T]T`: これは、任意のキー型`T`と値型`T`を持つマップへのポインタ型を表します。例えば、`*map[string]int`や`*map[int]bool`などです。
    *   `as &map[k:v]`: これは、新しい出力形式を示します。`&`はポインタであることを示し、その後に`map[k:v]`という形式で、ポインタが指すマップのキーと値のペアが列挙されます。これは、マップリテラルのような表現であり、マップの内容が直接視覚化されることを意味します。
*   `(CL 154870043)`: この変更が、Goのコードレビューシステムにおける変更リスト（Change List）のID `154870043` によって導入されたことを示します。このCLが`fmt`パッケージの実際のコード変更を含んでいます。

この一行の追加により、Go 1.4のユーザーは、`fmt`パッケージがマップへのポインタをどのように扱うかについて、明確なガイダンスを得ることができます。これにより、デバッグ出力やログの解析がより直感的になり、開発体験が向上します。
