# [インデックス 2748] ファイルの概要

このコミットは、Go言語の`bignum`パッケージ（後の`math/big`パッケージに相当）内の`RatFromString`関数に、指数表記（例: `1e2`, `1.1e-2`）をサポートする機能を追加するものです。これにより、文字列形式で与えられた有理数を、より柔軟に、科学技術計算などで一般的に用いられる指数形式でパースできるようになります。

## 変更の背景

`RatFromString`関数は、文字列から有理数（Rational Number）を解析するための機能を提供します。しかし、このコミット以前は、`"123.45"`のような通常の小数表記はサポートしていましたが、`"1.23e+2"`や`"4.56E-3"`といった指数表記には対応していませんでした。科学技術計算や金融計算など、非常に大きな数や小さな数を扱う場面では、指数表記は数値の表現として非常に一般的かつ効率的です。

この変更の背景には、`bignum`パッケージが扱う任意精度数値の汎用性を高め、より幅広い数値表現をサポートすることで、ユーザーが文字列から有理数をパースする際の利便性と表現力を向上させる目的があります。指数表記のサポートは、数値解析ライブラリとしての`bignum`パッケージの完全性を高める上で不可欠な機能拡張でした。

## 前提知識の解説

### 有理数 (Rational Number)
有理数とは、二つの整数 $p$ と $q$ を用いて $\frac{p}{q}$ の分数形式で表せる数のことです。ただし、$q$ はゼロであってはなりません。整数、有限小数、循環小数はすべて有理数に含まれます。Go言語の`math/big`パッケージ（このコミット時点では`bignum`パッケージ）では、`Rat`型がこの有理数を任意精度で表現します。これは、通常の`float64`型が持つ浮動小数点数の精度限界を超えて、正確な分数計算を可能にします。

### 指数表記 (Exponential Notation / Scientific Notation)
指数表記は、非常に大きな数や小さな数を簡潔に表現するための方法です。一般的には $a \times 10^b$ の形式で表され、プログラミング言語では `aEb` や `aeb` と記述されることが多いです。
*   `a` は仮数部（mantissa）または有効数字部と呼ばれ、通常は $1 \le |a| < 10$ の範囲の数です。
*   `b` は指数部（exponent）と呼ばれ、整数です。
例えば、`1.23e+2` は $1.23 \times 10^2 = 123$ を意味し、`4.56e-3` は $4.56 \times 10^{-3} = 0.00456$ を意味します。

### Go言語の`bignum`パッケージ (現在の`math/big`)
このコミットが行われた2009年当時、Go言語の任意精度演算ライブラリは`src/pkg/bignum`に存在していました。その後、このパッケージは標準ライブラリの`math/big`として再編成され、現在に至ります。`math/big`パッケージは、`Int`（任意精度整数）、`Rat`（任意精度有理数）、`Float`（任意精度浮動小数点数）の各型を提供し、金融計算、暗号化、科学技術計算など、高い精度が要求される場面で利用されます。

`Rat`型は内部的に分子と分母を`Int`型で保持し、分数の形で数値を表現します。これにより、浮動小数点数演算で発生する可能性のある丸め誤差を回避し、正確な計算が可能です。

## 技術的詳細

このコミットの主要な変更は、`RatFromString`関数が文字列中の指数表記を認識し、それを有理数として正しく解釈するロジックを追加した点にあります。

1.  **指数部の検出**: `RatFromString`はまず、数値の整数部と小数部を通常の形式でパースします。その後、パースされた文字列の末尾に `'e'` または `'E'` の文字があるかをチェックします。これは指数表記の開始を示します。

2.  **指数値のパース**: `'e'` または `'E'` が検出された場合、その直後から文字列の最後までを指数部として扱います。この指数部は、`IntFromString`関数（整数をパースする関数）を使用して整数値として読み取られます。例えば、`"1.23e+2"`の場合、`"+2"`が指数部としてパースされ、整数`2`が得られます。

3.  **指数部の適用**: パースされた指数値`e`に基づいて、元の有理数（仮数部）に $10^e$ を乗算または除算します。
    *   **正の指数**: もし指数`e`が正の場合（例: `1e2`）、元の有理数の分子に $10^e$ を乗算します。これは、`a = a.MulNat(m)`（ここで`m`は $10^e$）という操作に対応します。
    *   **負の指数**: もし指数`e`が負の場合（例: `1e-2`）、元の有理数の分母に $10^{|e|}$ を乗算します。これは、`b = b.Mul(m)`という操作に対応します。負の指数は、数値を小さくするため、分母を大きくすることで実現されます。

4.  **`Nat(10).Pow(uint(e.mant.Value()))`**: ここで`Nat(10)`は、`10`という自然数（非負整数）を表す`Nat`型（`Int`型の一部）のインスタンスを作成します。`.Pow()`メソッドは、この基数（10）を指定された指数で累乗します。`e.mant.Value()`は、パースされた指数整数`e`の絶対値を取得し、それを`uint`型に変換して累乗の指数として使用します。これにより、$10^{|e|}$ が計算されます。

5.  **パース長の調整**: `RatFromString`は、パースした文字列の長さも返します。指数表記をサポートするために、この返される長さ（`alen + blen + elen`）に指数部の長さも加算されるように修正されています。これにより、呼び出し元は文字列のどこまでが有理数として解釈されたかを正確に知ることができます。

この変更により、`RatFromString`は、`"123"`, `"12.3"`, `"1e2"`, `"1.2e-3"`といった多様な形式の文字列から有理数を正確に構築できるようになり、`bignum`パッケージの堅牢性と実用性が大幅に向上しました。

## コアとなるコードの解説

### `src/pkg/bignum/bignum.go` の変更点

`RatFromString`関数は、文字列`s`と基数`base`を受け取り、有理数`*Rational`、実際に使用された基数`uint`、そしてパースされた文字列の長さ`int`を返します。

追加されたコードブロックは、以下のステップで指数表記を処理します。

1.  **`var elen int;`**: 指数部の文字列長を格納するための変数`elen`を宣言します。
2.  **`mlen := alen + blen;`**: 既にパースされた整数部と小数部の合計長を`mlen`に格納します。これは、指数部が始まる可能性のある位置を示します。
3.  **`if mlen < len(s) { ... }`**: 文字列`s`が`mlen`よりも長い場合、つまりまだ読み取るべき文字が残っている場合に指数部のチェックを行います。
4.  **`ch := s[mlen]; if ch == 'e' || ch == 'E' { ... }`**: `mlen`の位置の文字が`'e'`または`'E'`であるかをチェックし、指数表記が開始されているかを確認します。
5.  **`e, base, elen = IntFromString(s[mlen + 1 : len(s)], abase);`**: 指数文字（`'e'`または`'E'`）の次の文字から文字列の最後までを指数部として抽出し、`IntFromString`関数を使って整数`e`としてパースします。`elen`には、この指数部の文字列長が格納されます。
6.  **`elen++;`**: `IntFromString`が返す`elen`は指数値自体の長さなので、指数文字（`'e'`または`'E'`）の分を加えて`elen`をインクリメントします。
7.  **`assert(base == abase);`**: パースされた指数部の基数が、元の数値の基数と一致することを確認します。
8.  **`m := Nat(10).Pow(uint(e.mant.Value()));`**: 基数10を、パースされた指数`e`の絶対値で累乗した値`m`を計算します。`e.mant.Value()`は`Integer`型`e`の絶対値を取得します。
9.  **`if e.sign { b = b.Mul(m); } else { a = a.MulNat(m); }`**:
    *   `e.sign`が`true`の場合、指数`e`は負の数です。この場合、元の有理数の分母`b`に`m`を乗算します。例えば、`1e-2`は`1/100`なので、分母を100倍します。
    *   `e.sign`が`false`の場合、指数`e`は正の数です。この場合、元の有理数の分子`a`に`m`を乗算します。例えば、`1e2`は`100/1`なので、分子を100倍します。
10. **`return MakeRat(a, b), base, alen + blen + elen;`**: 最終的な有理数と、パースされた文字列の合計長（整数部、小数部、指数部の合計）を返します。

### `src/pkg/bignum/bignum_test.go` の変更点

テストファイルには、指数表記を検証するための新しいテストケースが追加されています。

*   `rat_eq(11, ratFromString("1e2", 0, nil), bignum.Rat(100, 1));`
    *   `"1e2"`が`100/1`として正しくパースされることを確認します。
*   `rat_eq(12, ratFromString("1e-2", 0, nil), bignum.Rat(1, 100));`
    *   `"1e-2"`が`1/100`として正しくパースされることを確認します。
*   `rat_eq(13, ratFromString("1.1e2", 0, nil), bignum.Rat(110, 1));`
    *   `"1.1e2"`が`110/1`として正しくパースされることを確認します。
*   `rat_eq(14, ratFromString(".1e2x", 0, &slen), bignum.Rat(10, 1)); test(15, slen == 4);`
    *   `".1e2x"`のように、指数表記の後に余分な文字がある場合でも、指数表記までが正しくパースされ（`.1e2` -> `10/1`）、パース長`slen`が`4`（`.1e2`の長さ）であることを確認します。これは、`RatFromString`が文字列全体ではなく、有効な数値部分のみをパースする挙動をテストしています。

これらのテストケースは、指数表記の様々なパターン（正の指数、負の指数、小数部を含む指数、余分な文字を含む場合）を網羅しており、実装が堅牢であることを保証します。
