# [インデックス 23867] ファイルの概要

このコミットは、Go言語のビルドシステムにおけるクリーンアップスクリプトの修正に関するものです。具体的には、`src/clean.bash`、`src/clean.bat`、`src/clean.rc` の各スクリプトにおいて、`go tool dist clean` コマンドの呼び出し方法を修正し、さらに `go clean -i cmd` を追加することで、ビルド成果物のクリーンアップをより完全に行うように変更しています。また、Windows向けの `clean.bat` では `go tool dist env` コマンドのオプション指定も修正されています。

## 変更の背景

このコミットの背景には、Go言語のビルドシステムにおけるクリーンアップ処理の不完全さがあったと考えられます。特に、`#10734` で報告された問題は、既存のクリーンアップスクリプトが一部のビルド成果物（特にコマンドの実行ファイル）を適切に削除できていなかったことを示唆しています。

Go言語のビルドプロセスでは、コンパイルされたパッケージや実行ファイルが特定の場所にインストールされます。開発者がビルド環境をクリーンな状態に戻したい場合、これらの成果物をすべて削除する必要があります。しかし、以前のスクリプトでは、`go tool dist clean` の呼び出し方が不適切であったり、`go clean -i cmd` のようにコマンドの実行ファイルを削除する処理が欠けていたりしたため、古い実行ファイルが残存し、予期せぬ動作を引き起こす可能性がありました。

このコミットは、これらの問題を解決し、`go clean` コマンドと `go tool dist clean` コマンドを正しく、かつ網羅的に使用することで、ビルド環境をより確実にクリーンアップできるようにすることを目的としています。

## 前提知識の解説

このコミットを理解するためには、以下のGo言語のビルドシステムと関連コマンドに関する知識が必要です。

### 1. Go言語のビルドシステム

Go言語は、ソースコードから実行ファイルを生成するための独自のビルドシステムを持っています。`go build` コマンドはソースコードをコンパイルし、`go install` コマンドはコンパイルされたパッケージやコマンドを実行可能なパスに配置します。これらのプロセス中に、中間ファイルやキャッシュファイルが生成されます。

### 2. `go clean` コマンド

`go clean` コマンドは、Goのビルドシステムによって生成されたオブジェクトファイル、キャッシュファイル、およびインストールされたパッケージや実行ファイルを削除するために使用されます。これにより、クリーンな状態から再ビルドを行うことができます。

*   **`go clean`**: デフォルトでは、現在のディレクトリとそのサブディレクトリにあるオブジェクトファイル（`.a` ファイルなど）を削除します。
*   **`go clean -i`**: インストールされたパッケージアーカイブ（`.a` ファイル）と実行可能ファイル（`$GOBIN` にインストールされたコマンドなど）を削除します。
*   **`go clean -i std`**: 標準ライブラリのインストール済みパッケージを削除します。
*   **`go clean -i cmd`**: インストールされたコマンド（実行可能ファイル）を削除します。これは、`$GOBIN` に配置された実行ファイルを対象とします。

### 3. `go tool dist` コマンド

`go tool dist` は、Goツールチェイン自体のビルドと管理に関連する低レベルなコマンド群です。GoのソースコードからGoコンパイラやその他のツールをビルドする際に使用されます。

*   **`go tool dist clean`**: Goツールチェイン自体のビルドプロセスで生成された中間ファイルや成果物をクリーンアップします。これは、Goのソースコードリポジトリ内で `make clean` のような役割を果たします。
*   **`go tool dist env`**: Goツールチェインのビルド環境で使用される環境変数を表示します。
    *   **`-w`**: 環境変数をファイルに書き出します。
    *   **`-p`**: 環境変数を標準出力に表示します。

### 4. シェルスクリプト (bash, batch, rc)

このコミットで変更されているファイルは、それぞれ異なるシェルスクリプトです。

*   **`clean.bash`**: Bashシェル（Linux, macOSなどで一般的）用のスクリプト。
*   **`clean.bat`**: Windowsのコマンドプロンプト（Batchファイル）用のスクリプト。
*   **`clean.rc`**: Plan 9オペレーティングシステムで使用されるrcシェル用のスクリプト。

これらのスクリプトは、Goのビルド環境をクリーンアップするための自動化された手順を定義しています。

## 技術的詳細

このコミットの技術的な詳細は、主に以下の3点に集約されます。

### 1. `go tool dist clean` の呼び出し方法の統一と修正

以前のスクリプトでは、`$GOTOOLDIR/dist clean` のように、`dist` コマンドを直接実行しようとしていました。しかし、Goのツールチェインでは、`dist` コマンドは `go tool` サブコマンドを通じて実行されるのが一般的かつ推奨される方法です。

このコミットでは、`"$GOBIN/go" tool dist clean` という形式に修正されています。
*   `$GOBIN/go` (または `%GOBIN%\go`): Goの実行可能ファイルへのパスを明示的に指定しています。これにより、環境変数 `PATH` に依存せず、正しい `go` コマンドが実行されることが保証されます。
*   `tool dist clean`: `go tool` サブコマンドを使用して `dist clean` を呼び出すことで、Goツールチェインの内部的なコマンド実行メカニズムに沿った正しい方法でクリーンアップが実行されます。

この変更により、`dist clean` が意図した通りに機能し、Goツールチェインのビルド成果物が適切に削除されるようになります。

### 2. `go clean -i cmd` の追加

以前のクリーンアップスクリプトでは、標準ライブラリのパッケージ (`std`) は `go clean -i std` で削除されていましたが、Goのコマンド（実行ファイル）は明示的に削除されていませんでした。

このコミットでは、`"$GOBIN/go" clean -i cmd` が追加されています。これにより、`go install` によって `$GOBIN` ディレクトリにインストールされたすべてのコマンド（例えば `gofmt` や `vet` などのツール、またはユーザーが `go install` した独自のコマンド）がクリーンアップ時に削除されるようになります。これは、古いバージョンのコマンドが残存することを防ぎ、ビルド環境の一貫性を保つ上で非常に重要です。

### 3. `clean.bat` における `go tool dist env` のオプション修正

Windows向けの `clean.bat` スクリプトでは、`go tool dist env -wp` が `go tool dist env -w -p` に変更されています。
*   `-wp`: これは `-w` と `-p` を結合したショートハンドとして意図されていた可能性がありますが、Goのコマンドラインパーサーでは正しく解釈されない場合があります。
*   `-w -p`: これは `-w` オプションと `-p` オプションを個別に指定する正しい方法です。

この修正により、`go tool dist env` コマンドがWindows環境で意図した通りに動作し、環境変数が正しくファイルに書き出され、かつ表示されるようになります。これは、クリーンアップスクリプトが依存する環境変数を正確に取得するために重要です。

これらの変更は、Goのビルドシステムにおけるクリーンアップ処理の堅牢性と正確性を向上させるためのものであり、開発者がより信頼性の高いビルド環境を維持するのに役立ちます。

## コアとなるコードの解説

### 1. `"$GOBIN/go" tool dist clean` への変更

*   **旧コード**: `$GOTOOLDIR/dist clean`
    *   これは、`$GOTOOLDIR` (Goツールチェインの内部ディレクトリ) 内にある `dist` という実行ファイルを直接呼び出そうとしていました。しかし、Goのツールチェインの設計上、`dist` コマンドは `go tool` サブコマンドを介して実行されるべきです。直接呼び出すと、環境設定やパスの問題により正しく動作しない可能性がありました。
*   **新コード**: `"$GOBIN/go" tool dist clean`
    *   `"$GOBIN/go"` は、Goの実行可能ファイルへの絶対パスを確実に指定します。
    *   `tool dist clean` は、`go` コマンドの `tool` サブコマンドを使って `dist clean` を実行する、Goツールチェインが推奨する正しい方法です。これにより、Goツールチェインのビルド成果物（例えば、Goコンパイラやリンカのビルド時に生成される中間ファイル）が確実にクリーンアップされます。

### 2. `"$GOBIN/go" clean -i cmd` の追加

*   **追加されたコード**: `"$GOBIN/go" clean -i cmd`
    *   この行は、`go clean` コマンドに `-i cmd` オプションを付けて実行することを意味します。
    *   `-i` オプションは、インストールされたパッケージアーカイブと実行可能ファイルを削除するよう指示します。
    *   `cmd` は、特に `$GOBIN` ディレクトリにインストールされたコマンド（実行ファイル）を対象とします。
    *   この追加により、以前のクリーンアップスクリプトでは削除されていなかった可能性のある、Goのコマンドラインツールやユーザーが `go install` でインストールした実行ファイルが確実に削除されるようになります。これにより、古いバージョンの実行ファイルが残存することによる潜在的な問題を回避できます。

### 3. `clean.bat` における `go tool dist env -wp` から `go tool dist env -w -p` への変更

*   **旧コード**: `go tool dist env -wp >env.bat`
    *   `-wp` は、`-w` (write) と `-p` (print) の両方のオプションを同時に指定しようとしたものですが、WindowsのバッチファイルやGoのコマンドラインパーサーによっては、これを単一の不明なオプションとして解釈してしまう可能性がありました。
*   **新コード**: `go tool dist env -w -p >env.bat`
    *   `-w` と `-p` を個別のオプションとして明示的に指定することで、`go tool dist env` コマンドが正しく解釈され、環境変数が `env.bat` ファイルに書き込まれると同時に標準出力にも表示されるようになります。これは、クリーンアップスクリプトがGoのビルド環境を正しく設定するために必要なステップです。

これらの変更は、Goのビルド環境のクリーンアップ処理をより堅牢で正確なものにし、異なるオペレーティングシステム環境（Bash, Batch, rc）での一貫した動作を保証することを目的としています。
