# [インデックス 22251] ファイルの概要

このコミットは、Go言語の標準ライブラリである`math/big`パッケージ内の`Float`型に関する変更です。具体的には、無限大の浮動小数点数値を扱うためのAPIが修正されています。変更されたファイルは以下の2つです。

*   `src/math/big/float.go`: `Float`型の定義と関連するメソッドが含まれる主要なソースファイルです。`NewInf`関数の削除と`SetInf`メソッドの追加が行われました。
*   `src/math/big/float_test.go`: `float.go`で定義された機能のテストコードです。`NewInf`から`SetInf`への変更に伴い、テストコードも更新され、`SetInf`の新しいテストケースが追加されました。

## 変更の背景

このコミットの主な目的は、`math/big`パッケージの`Float`型における無限大値の生成と設定に関するAPIの一貫性を向上させることです。以前は、無限大の`Float`値を生成するために`NewInf`という関数が提供されていました。この関数は新しい`*Float`インスタンスを返していました。しかし、`math/big`パッケージ内の他の多くの`Set`プレフィックスを持つメソッド（例: `SetFloat64`, `SetInt64`, `SetRat`など）は、既存の`Float`レシーバを変更してその結果を返すというGo言語の慣用的なパターンに従っています。`NewInf`が新しいインスタンスを返す一方で、他の`Set`メソッドが既存のインスタンスを変更するという非対称性は、APIの利用者を混乱させる可能性がありました。

このコミットでは、`NewInf`関数を削除し、代わりに`SetInf`というメソッドを`Float`型に追加することで、この不整合を解消しています。`SetInf`は、他の`Set`メソッドと同様に、レシーバである`Float`インスタンス自体を無限大に設定し、そのレシーバを返します。これにより、`Float`型のAPI全体で一貫した操作モデルが提供され、より予測可能で使いやすいインターフェースが実現されます。特に、既存の`Float`変数を再利用して無限大を設定したい場合に、余分なアロケーションなしで操作できるようになります。

## 前提知識の解説

*   **`math/big`パッケージ**: Go言語の標準ライブラリの一部であり、任意精度の数値演算を提供するパッケージです。`int`、`float`、`rat`（有理数）といった型が含まれており、通常の組み込み型では表現できない非常に大きな数値や、高い精度が要求される計算に対応します。金融計算、暗号化、科学技術計算などで利用されます。
*   **`Float`型**: `math/big`パッケージ内で定義されている任意精度浮動小数点数型です。この型は、IEEE 754浮動小数点標準に準拠した通常の`float32`や`float64`とは異なり、ユーザーが指定した任意の精度で計算を行うことができます。内部的には、符号、指数、仮数部で構成されます。
*   **無限大 (`Inf`)**: 浮動小数点数演算における特殊な値の一つで、数値が非常に大きくなり、表現可能な最大値を超えた場合に発生します。正の無限大 (`+Inf`) と負の無限大 (`-Inf`) があります。Go言語の`math`パッケージでも`math.Inf(1)`で`+Inf`、`math.Inf(-1)`で`-Inf`を生成できます。`math/big.Float`も同様に無限大を表現できます。
*   **Go言語のAPI設計における慣用句 (`NewX` vs `SetX`)**:
    *   **`NewX`関数**: 通常、`New`プレフィックスを持つ関数は、新しいインスタンスを生成して初期化し、そのポインタを返します（例: `new(T)`や`make([]T)`のラッパー、または構造体の初期化）。これらの関数は、新しいオブジェクトが必要な場合に利用されます。
    *   **`SetX`メソッド**: 通常、`Set`プレフィックスを持つメソッドは、既存のレシーバ（多くの場合ポインタレシーバ）の値を変更し、そのレシーバ自体を返します。これにより、メソッドチェーンが可能になり、既存のオブジェクトを再利用してメモリ割り当てを避けることができます。`math/big`パッケージでは、多くの演算結果を既存の`Float`インスタンスに格納するためにこのパターンが広く使われています。このコミットは、`NewInf`がこの`SetX`パターンから逸脱していた点を修正し、APIの一貫性を高めるものです。

## 技術的詳細

このコミットの技術的な変更点は、主に`src/math/big/float.go`における`NewInf`関数の削除と`SetInf`メソッドの追加、そしてそれに伴う`src/math/big/float_test.go`のテストコードの修正です。

1.  **`NewInf`関数の削除**:
    *   以前は、`NewInf(sign int) *Float`という関数が存在し、`sign`引数に基づいて`+Inf`または`-Inf`の新しい`Float`インスタンスを生成して返していました。
    *   この関数は、`&Float{neg: sign < 0, exp: infExp}`という形で新しい`Float`構造体を直接初期化していました。
    *   このコミットにより、この関数は完全に削除されました。

2.  **`SetInf`メソッドの追加**:
    *   `func (z *Float) SetInf(sign int) *Float`という新しいメソッドが`Float`型に追加されました。
    *   このメソッドは、レシーバである`z`（既存の`Float`インスタンス）を無限大に設定します。`sign`引数が0以上であれば`+Inf`、負であれば`-Inf`を設定します。
    *   **`z.acc = Exact`**: `Float`型の`acc`フィールドは、数値の精度（`Exact`, `Below`, `Above`）を示します。無限大は正確な値であるため、`Exact`に設定されます。
    *   **`z.neg = sign < 0`**: `neg`フィールドは符号を表します。`sign`が負であれば`true`（負の無限大）、そうでなければ`false`（正の無限大）に設定されます。
    *   **`z.mant = z.mant[:0]`**: `mant`フィールドは仮数部（mantissa）を表すスライスです。無限大は有限の仮数部を持たないため、スライスを空にすることで仮数部をクリアします。
    *   **`z.exp = infExp`**: `exp`フィールドは指数部を表します。`infExp`は`math/big`パッケージ内部で定義されている定数で、無限大を表す特別な指数値です。
    *   メソッドは`z`自身を返すため、`f.SetPrec(10).SetInf(1)`のようにメソッドチェーンで利用できます。

3.  **テストコードの変更 (`src/math/big/float_test.go`)**:
    *   `makeFloat`ヘルパー関数内で、無限大を生成する際に`NewInf`の代わりに`x.SetInf`が使用されるように変更されました。`makeFloat`はテストのために`Float`インスタンスを生成するユーティリティ関数です。
    *   `TestFloatSetInf`という新しいテスト関数が追加されました。このテストは、`SetInf`メソッドが正しく無限大を設定し、`Float`インスタンスの精度が変更されないことを検証します。様々な`sign`値と`prec`（精度）の組み合わせで`SetInf`を呼び出し、結果の文字列表現と精度が期待通りであることを確認しています。

これらの変更により、`Float`型のAPIは、既存のオブジェクトを変更する`Set`メソッドのパターンに統一され、より予測可能で使いやすくなりました。

## コアとなるコードの解説

### `src/math/big/float.go` の変更

*   **`NewInf`関数の削除**:
    ```go
    // NewInf returns a new infinite Float value with value +Inf (sign >= 0),
    // or -Inf (sign < 0).
    func NewInf(sign int) *Float {
    	return &Float{neg: sign < 0, exp: infExp}
    }
    ```
    このコードブロック全体が削除されました。これは、新しい`Float`インスタンスをヒープに割り当てて無限大を初期化するという、Goの`Set`メソッドの慣用句とは異なるパターンでした。

*   **`SetInf`メソッドの追加**:
    ```go
    // SetInf sets z to the infinite Float +Inf for sign >= 0,
    // or -Inf for sign < 0, and returns z. The precision of
    // z is unchanged and the result is always Exact.
    func (z *Float) SetInf(sign int) *Float {
    	z.acc = Exact
    	z.neg = sign < 0
    	z.mant = z.mant[:0]
    	z.exp = infExp
    	return z
    }
    ```
    この新しいメソッドは、`*Float`型のレシーバ`z`に対して動作します。
    *   `z.acc = Exact`: 無限大は正確な値であるため、精度情報を示す`acc`フィールドを`Exact`に設定します。
    *   `z.neg = sign < 0`: `sign`が負の値であれば`z`を負の無限大に、そうでなければ正の無限大に設定します。
    *   `z.mant = z.mant[:0]`: `Float`の内部表現において、仮数部（`mant`）は数値の有効桁を保持するスライスです。無限大は有限の仮数部を持たないため、このスライスを空にすることで仮数部の情報をクリアします。
    *   `z.exp = infExp`: `exp`フィールドは指数部を表します。`infExp`は`math/big`パッケージ内部で定義された特別な定数で、この値が設定されることで`Float`インスタンスが無限大を表すようになります。
    *   `return z`: メソッドチェーンを可能にするために、変更されたレシーバ`z`自身を返します。

これらの変更は、`math/big.Float`のAPIをよりGo言語の慣用的なスタイルに合わせ、一貫性と使いやすさを向上させるためのものです。
