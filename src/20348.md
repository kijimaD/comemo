# [インデックス 20348] ファイルの概要

このコミットは、Go言語の標準ライブラリである`crypto`パッケージの`Hash`列挙型に、SHA-3ハッシュ関数（SHA3-224, SHA3-256, SHA3-384, SHA3-512）を追加するものです。これにより、`go.crypto/sha3`パッケージで提供されるSHA-3の実装が、Goの標準的な暗号インターフェースを通じてより容易に利用できるようになります。

## 変更の背景

SHA-3 (Secure Hash Algorithm 3) は、2012年に米国国立標準技術研究所 (NIST) によって選定された新しい暗号学的ハッシュ関数であり、2015年にはFIPS 202として標準化されました。SHA-1やSHA-2とは異なる「スポンジ構造」を採用しており、将来的な暗号解読技術の進歩に対する耐性向上を目的としています。

Go言語では、既に`golang.org/x/crypto/sha3`という外部パッケージでSHA-3の実装が提供されていました。このコミットの背景には、この新しい標準ハッシュアルゴリズムをGoの標準`crypto`パッケージのインターフェースに統合し、開発者がより簡単に、かつGoの既存のハッシュ関数と同じ抽象化レベルでSHA-3を利用できるようにするという意図があります。これにより、Goアプリケーションが最新の暗号標準に準拠しやすくなり、セキュリティの選択肢が広がります。

コミットメッセージにある「Reverse dependency of https://golang.org/cl/130950043/」は、この変更が別の変更（`golang.org/cl/130950043`）に依存している、またはその変更によって可能になったことを示唆しています。`golang.org/cl/130950043`は`TestStackGrowth`テスト内の競合状態を修正するものであり、直接的なSHA3の実装とは異なりますが、Goのランタイムやテストインフラストラクチャの安定性向上に関連している可能性があります。

## 前提知識の解説

### 暗号学的ハッシュ関数

暗号学的ハッシュ関数は、任意の長さの入力データ（メッセージ）を受け取り、固定長の短い出力（ハッシュ値、メッセージダイジェスト、またはフィンガープリントと呼ばれる）を生成する数学的なアルゴリズムです。主な特性として以下が挙げられます。

*   **一方向性**: ハッシュ値から元のメッセージを効率的に復元することは非常に困難である。
*   **衝突耐性**: 異なる2つのメッセージが同じハッシュ値を生成することは非常に困難である（衝突の発見が計算上不可能である）。
*   **原像計算困難性**: 特定のハッシュ値を持つメッセージを効率的に見つけることは非常に困難である。

これらの特性により、データの整合性検証、デジタル署名、パスワードの保存など、様々なセキュリティ関連の用途で利用されます。

### SHA-3 (Keccak)

SHA-3は、NISTが主催したハッシュ関数コンペティションで選定された、最新の標準ハッシュ関数ファミリーです。ベルギーの研究者チームによって設計されたKeccakアルゴリズムに基づいており、SHA-1やSHA-2とは根本的に異なる「スポンジ構造」を採用しています。この構造は、データを「吸収」し、ハッシュ値を「絞り出す」というプロセスで動作します。

SHA-3ファミリーには、出力サイズが異なるいくつかのバリアントがあります。

*   **SHA3-224**: 224ビットのハッシュ値を生成
*   **SHA3-256**: 256ビットのハッシュ値を生成
*   **SHA3-384**: 384ビットのハッシュ値を生成
*   **SHA3-512**: 512ビットのハッシュ値を生成

また、SHAKE128やSHAKE256といったExtendable Output Functions (XOFs) も含まれており、これらは任意の長さの出力を生成できます。SHA-3は、既存のSHA-2ファミリーとは異なる設計であるため、将来的にSHA-2に脆弱性が見つかった場合の代替手段としても期待されています。

### Go言語の`crypto`パッケージ

Go言語の標準ライブラリに含まれる`crypto`パッケージは、様々な暗号関連の機能を提供します。これには、ハッシュ関数、乱数生成器、公開鍵暗号などが含まれます。このパッケージは、Goアプリケーションで安全な暗号操作を行うための基盤を提供します。

### `crypto.Hash`列挙型

`crypto`パッケージ内には`Hash`という型が定義されており、これはGo言語で利用可能な様々な暗号学的ハッシュアルゴリズムを識別するための列挙型（実際には`uint`型の定数）として機能します。例えば、`crypto.SHA256`はSHA-256アルゴリズムを、`crypto.MD5`はMD5アルゴリズムをそれぞれ表します。

この`Hash`型は、ハッシュアルゴリズムを抽象的に扱うことを可能にし、`New()`（指定されたアルゴリズムの新しいハッシュインターフェースを返す）、`Size()`（ハッシュ値のバイト長を返す）、`Available()`（指定されたハッシュ関数がバイナリにリンクされているか報告する）といったメソッドを提供します。これにより、開発者は具体的なハッシュアルゴリズムの実装を意識することなく、統一されたインターフェースでハッシュ操作を行うことができます。

### `go.crypto/sha3`パッケージ

`golang.org/x/crypto`リポジトリは、Go言語の標準ライブラリには含まれないが、Goチームによって開発・メンテナンスされている実験的または外部の暗号化ライブラリ群です。`go.crypto/sha3`パッケージは、このリポジトリの一部としてSHA-3アルゴリズムのGo言語実装を提供しています。このコミットは、この外部パッケージで提供されているSHA-3の機能を、Goの標準`crypto.Hash`列挙型に組み込むことで、より「標準的」な方法で利用できるようにするものです。

## 技術的詳細

このコミットの技術的な核心は、Go言語の`src/pkg/crypto/crypto.go`ファイルに、SHA-3ハッシュ関数の各バリアントを`crypto.Hash`列挙型と、それらの出力サイズを定義する`digestSizes`マップに追加することです。

1.  **`crypto.Hash`列挙型への追加**:
    `crypto.go`ファイル内の`const`ブロックに、`SHA3_224`, `SHA3_256`, `SHA3_384`, `SHA3_512`という新しい定数が追加されます。これらの定数は、`iota`キーワードによって自動的に一意の整数値が割り当てられ、`crypto.Hash`型の一部として認識されるようになります。これにより、Goのプログラムはこれらの新しい定数を使ってSHA-3ハッシュアルゴリズムを指定できるようになります。

    ```go
    const (
        // ... 既存のハッシュ定数 ...
        SHA3_224                  // import code.google.com/p/go.crypto/sha3
        SHA3_256                  // import code.google.com/p/go.crypto/sha3
        SHA3_384                  // import code.google.com/p/go.crypto/sha3
        SHA3_512                  // import code.google.com/p/go.crypto/sha3
        maxHash
    )
    ```
    コメントにある`import code.google.com/p/go.crypto/sha3`は、これらのハッシュ定数が`go.crypto/sha3`パッケージの実装に対応していることを示しています。

2.  **`digestSizes`マップへの出力サイズの追加**:
    `digestSizes`は、各`crypto.Hash`定数に対応するハッシュ値のバイト長を格納するマップ（またはスライス）です。このコミットでは、新しく追加されたSHA-3ハッシュ関数に対応する出力サイズがこのマップに追加されます。

    ```go
    var digestSizes = []uint8{
        // ... 既存のハッシュサイズ ...
        SHA3_224:  28,
        SHA3_256:  32,
        SHA3_384:  48,
        SHA3_512:  64,
        // ...
    }
    ```
    これにより、`crypto.Hash`型の`Size()`メソッドが、SHA-3ハッシュに対しても正しい出力サイズを返すことができるようになります。例えば、`crypto.SHA3_256.Size()`は32を返します。これは、ハッシュ値を格納するためのバッファを動的に確保する際などに非常に重要です。

これらの変更は、`go.crypto/sha3`パッケージが提供する具体的なSHA-3の実装と、Goの標準`crypto`パッケージが提供する抽象的なハッシュインターフェースとの間の橋渡しをします。これにより、Goの標準ライブラリを利用する開発者は、外部パッケージのインポートを意識することなく、`crypto.Hash`型を通じてSHA-3を利用できるようになります。

## コアとなるコードの解説

このコミットは、`src/pkg/crypto/crypto.go`ファイルに対して行われています。このファイルは、Go言語の標準`crypto`パッケージにおけるハッシュアルゴリズムの定義と、それらに関連するメタデータ（例えば出力サイズ）を管理しています。

変更点は大きく2つのセクションに分かれます。

1.  **`const`ブロックへの追加**:
    元のコードの30行目付近にある`const`ブロックに、以下の4行が追加されています。
    ```go
    +	SHA3_224                  // import code.google.com/p/go.crypto/sha3
    +	SHA3_256                  // import code.google.com/p/go.crypto/sha3
    +	SHA3_384                  // import code.google.com/p/go.crypto/sha3
    +	SHA3_512                  // import code.google.com/p/go.crypto/sha3
    ```
    これらの行は、`crypto.Hash`列挙型に新しい定数としてSHA-3の各バリアント（224ビット、256ビット、384ビット、512ビット）を追加しています。Goの`iota`メカニズムにより、これらの定数には自動的に連続した整数値が割り当てられ、`crypto.Hash`型の一部として認識されるようになります。これにより、開発者は`crypto.SHA3_256`のように記述することで、SHA3-256ハッシュアルゴリズムを識別できるようになります。コメントは、これらの定数が`go.crypto/sha3`パッケージの実装に対応していることを示唆しています。

2.  **`digestSizes`マップへの追加**:
    元のコードの41行目付近にある`digestSizes`という`uint8`型のスライス（またはマップとして機能する配列）に、以下の4行が追加されています。
    ```go
    +	SHA3_224:  28,
    +	SHA3_256:  32,
    +	SHA3_384:  48,
    +	SHA3_512:  64,
    ```
    `digestSizes`は、各ハッシュアルゴリズムが生成するハッシュ値のバイト長を定義しています。ここに追加されたエントリは、それぞれのSHA-3バリアントの標準的な出力サイズを示しています。
    *   `SHA3_224`の出力は28バイト（224ビット / 8ビット/バイト = 28）
    *   `SHA3_256`の出力は32バイト（256ビット / 8ビット/バイト = 32）
    *   `SHA3_384`の出力は48バイト（384ビット / 8ビット/バイト = 48）
    *   `SHA3_512`の出力は64バイト（512ビット / 8ビット/バイト = 64）
    この変更により、`crypto.Hash`型の`Size()`メソッドが、これらの新しいSHA-3ハッシュに対しても正確な出力サイズを返すことが保証されます。これは、ハッシュ結果を格納するためのメモリを適切に割り当てる際に不可欠な情報です。

これらの変更は、Goの標準`crypto`パッケージがSHA-3ハッシュアルゴリズムを「認識」し、そのメタデータ（特にサイズ）を提供できるようにするための基盤を構築します。これにより、`go.crypto/sha3`パッケージの具体的な実装と連携して、Goエコシステム全体でSHA-3の利用が促進されます。
