# [インデックス 20979] ファイルの概要

## コミット

Goの`database/sql`パッケージにおけるテストの安定性向上。`TestDrivers`関数が複数回実行された際にクラッシュしないように修正されました。具体的には、テスト実行前にグローバルなドライバ登録状態をリセットする`unregisterAllDrivers`関数が導入され、テストの独立性と再現性が確保されました。

## 変更の背景

このコミットは、Goの標準ライブラリである`database/sql`パッケージ内のテスト関数`TestDrivers`が、複数回実行されたり、特に`-test.cpu=1,1`のような並列テスト設定で実行されたりした場合にクラッシュする問題を解決するために行われました。

`database/sql`パッケージは、データベースドライバをグローバルなマップに登録するメカニズムを持っています。`TestDrivers`のようなテスト関数がこのグローバルな状態（登録済みドライバのリスト）を変更し、テスト終了後にその状態を適切にクリーンアップしない場合、同じテストが再度実行されたり、他のテストがこの変更されたグローバル状態に依存したりすると、予期せぬ動作やクラッシュを引き起こす可能性があります。

この問題は、テストの独立性と再現性を損なうものであり、テストスイート全体の信頼性を低下させます。そのため、テストが常にクリーンな状態から開始できるように、グローバルなドライバ登録状態をリセットするメカニズムが必要とされました。

## 前提知識の解説

### Goの`database/sql`パッケージ

Goの`database/sql`パッケージは、GoプログラムからSQLデータベースを操作するための標準インターフェースを提供します。このパッケージ自体は特定のデータベースの実装を含まず、データベースドライバは`driver.Driver`インターフェースを実装し、`sql.Register`関数を使ってシステムに登録されます。これにより、アプリケーションは特定のデータベースドライバに依存することなく、汎用的な`database/sql`インターフェースを通じて様々なデータベースと対話できます。

### `sql.Register`関数

`func Register(name string, driver driver.Driver)`は、データベースドライバをGoの`database/sql`パッケージに登録するために使用されます。`name`はドライバを一意に識別する文字列（例: "mysql", "postgres"）で、`driver`はそのドライバの実装です。登録されたドライバは、パッケージ内部のグローバルな`map[string]driver.Driver`に保存されます。これにより、`sql.Open(driverName, dataSourceName)`のようにドライバ名を指定してデータベース接続を開くことができるようになります。

### Goのテストとグローバルステート

Goのテストフレームワーク（`go test`コマンド）は、テスト関数を並列で実行する機能を持っています。これは、テストの実行時間を短縮するのに役立ちますが、テストがグローバルな状態（このコミットで問題となった`database/sql`パッケージのドライバ登録マップなど）を変更する場合、問題を引き起こす可能性があります。

*   **グローバルステートの競合**: 複数のテストが同時に同じグローバルステートを読み書きしようとすると、競合状態が発生し、テストの失敗やクラッシュにつながることがあります。
*   **テストの独立性**: 理想的なテストは、他のテストの実行順序や結果に影響されず、常に同じ結果を返す「独立した」ものであるべきです。グローバルステートへの依存は、この独立性を損ないます。
*   **`-test.cpu`フラグ**: `go test -test.cpu=N`は、テストを並列実行する際に使用するCPUの最大数を指定します。`N=1`は並列実行を無効にしますが、`N=1,1`のように指定すると、テストが複数回実行される環境（例えば、テストスイート全体を複数回実行するCI/CDパイプラインなど）で、グローバルステートの問題が顕在化しやすくなります。

## 技術的詳細

`database/sql`パッケージは、登録されたドライバを`drivers`という`map[string]driver.Driver`型のグローバル変数に保持しています。`TestDrivers`関数は、この`drivers`マップにテスト用のダミードライバ（"test"と"invalid"）を登録し、`Drivers()`関数（登録済みドライバのリストを返す）の結果を検証します。

このコミット以前の`TestDrivers`関数は、テスト実行後に`drivers`マップを元の状態に戻す（クリーンアップする）処理を行っていませんでした。そのため、一度`TestDrivers`が実行されると、"test"や"invalid"といったドライバがグローバルな`drivers`マップに登録されたままになります。

この状態が問題となるのは、以下のようなシナリオです。

1.  **テストの再実行**: `TestDrivers`が再度実行された場合、既に"test"や"invalid"ドライバが登録されているため、`Register`関数が同じ名前で再度呼び出されることになります。`Register`関数は同じ名前のドライバが既に存在する場合、それを上書きしますが、テストの期待値（例えば、特定の数のドライバが登録されていること）と合わなくなり、テストが失敗する可能性があります。
2.  **並列テスト実行**: `-test.cpu`フラグを使用してテストが並列実行される場合、複数のテストが同時に`drivers`マップを操作しようとすると、競合状態が発生し、データ破損やクラッシュにつながる可能性があります。
3.  **テストスイートの不安定性**: `TestDrivers`の実行が他のテストに影響を与え、テストスイート全体が不安定になる原因となります。

このコミットは、`TestDrivers`が実行されるたびに、グローバルな`drivers`マップを完全にリセットすることで、これらの問題を解決しています。これにより、`TestDrivers`は常にクリーンな状態から開始され、他のテストや自身の再実行に影響を与えることなく、独立して動作するようになります。

## コアとなるコードの解説

### `src/database/sql/sql.go`における変更

新しく追加された`unregisterAllDrivers()`関数は以下の通りです。

```go
func unregisterAllDrivers() {
	// For tests.
	drivers = make(map[string]driver.Driver)
}
```

この関数は非常にシンプルですが、その効果は絶大です。`drivers`は`database/sql`パッケージ内でドライバを登録するために使用されるグローバルな`map[string]driver.Driver`変数です。`unregisterAllDrivers()`は、この既存の`drivers`マップを、`make(map[string]driver.Driver)`によって作成された**新しい空のマップで上書き**します。

これにより、以前に`sql.Register`によって登録されていたすべてのドライバがクリアされ、`drivers`マップは初期状態に戻ります。コメント`// For tests.`が示すように、この関数は主にテストのセットアップとティアダウンの目的で導入されました。

### `src/database/sql/fakedb_test.go`における変更

`TestDrivers`関数は以下のように変更されました。

```go
func TestDrivers(t *testing.T) {
	unregisterAllDrivers() // 追加
	Register("test", fdriver) // 追加
	Register("invalid", Dummy{})
	all := Drivers()
	// ... (既存の検証ロジック)
}
```

変更点は`TestDrivers`関数の冒頭に以下の2行が追加されたことです。

1.  `unregisterAllDrivers()`: これにより、`TestDrivers`が実行されるたびに、グローバルなドライバ登録状態が完全にリセットされます。これにより、以前のテスト実行が残した状態が、現在のテスト実行に影響を与えることがなくなります。
2.  `Register("test", fdriver)`: `unregisterAllDrivers()`によってすべてのドライバがクリアされた後、`TestDrivers`が正しく機能するために必要な`"test"`ドライバが再登録されます。これにより、テストは常に期待するドライバが登録された状態で開始されることが保証されます。

これらの変更により、`TestDrivers`はグローバルな状態に依存せず、何度実行されても、あるいは並列で実行されても、常に同じクリーンな環境で動作し、安定した結果を返すようになりました。これは、テストの信頼性と再現性を大幅に向上させる重要な修正です。
