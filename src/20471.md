# [インデックス 20471] ファイルの概要

このコミットは、Goランタイムの内部構造を整理し、コードの保守性と明確性を向上させるためのクリーンアップ作業です。具体的には、`timenow`というアセンブリのサンク（thunk）を専用のファイルに移動し、C言語やアセンブリで実装された汎用サービスのための宣言を`stubs.go`という単一のファイルに集約しています。

## 変更の背景

このコミットは、Goランタイムのコードベースの継続的な整理と構造化の一環として行われました。ランタイムはGoプログラムの実行を支える低レベルな部分であり、そのコードはパフォーマンスと正確性が極めて重要です。そのため、コードの重複を排除し、関連する機能を論理的にグループ化することで、保守性を高め、将来の機能追加や最適化を容易にすることが目的です。

具体的には、`timenow`のような共通のアセンブリルーチンが複数のアーキテクチャ固有のアセンブリファイルに散らばっていたり、C言語やアセンブリで実装された関数のGo側からの宣言が様々なファイルに分散していたりする状況がありました。このような状態は、コードの発見性を低下させ、変更時のエラーを引き起こしやすくします。このコミットは、これらの問題を解決し、ランタイムコードの全体的な品質を向上させることを目指しています。

## 前提知識の解説

*   **Goランタイム (Go Runtime)**: Goプログラムの実行を管理する低レベルな部分です。これには、ゴルーチン（goroutine）のスケジューリング、メモリ管理（ガベージコレクションを含む）、チャネル操作、システムコールとの連携など、Go言語の並行性と効率性を実現するための多くの機能が含まれます。ランタイムのコードは、Go言語だけでなく、C言語やアセンブリ言語でも書かれています。
*   **アセンブリ言語 (`.s` ファイル)**: Goランタイムには、特定のCPUアーキテクチャ（例: x86, ARM）に特化したアセンブリ言語で書かれたファイル（`.s`拡張子）が含まれています。これらのファイルは、Go言語では直接アクセスできないハードウェア機能を利用したり、極めて高いパフォーマンスが要求される処理（例: コンテキストスイッチ、システムコールラッパー）を実装するために使用されます。
*   **サンク (Thunk)**: プログラミングにおいて、サンクは別の関数や計算を呼び出すための小さなコード片です。Goランタイムの文脈では、アセンブリで書かれたサンクは、Go言語の関数とアセンブリ言語の関数との間の呼び出し規約の橋渡しをしたり、特定の処理を遅延させたりするために使われます。例えば、`runtime·timenow`は、Goランタイム内部から標準ライブラリの`time.now`関数を呼び出すためのアダプターとして機能します。
*   **スタブ (Stub) と `stubs.go`**: スタブは、実際の機能が別の場所（この場合はアセンブリやC言語）で実装されている関数の「宣言」または「プレースホルダー」です。`stubs.go`ファイルは、Goランタイム内で、Go言語のコードがアセンブリやC言語で書かれた低レベルなサービスを呼び出すためのインターフェース宣言を集約する役割を担っています。これにより、Goコードはこれらの低レベル関数を型安全な方法で利用できます。

## 技術的詳細

このコミットは、Goランタイムの内部的なコード構成を改善するための2つの主要な変更を含んでいます。

1.  **`timenow`サンクの移動**:
    *   以前は、`runtime·timenow`というアセンブリサンクが、`src/runtime/asm_386.s`、`src/runtime/asm_amd64.s`、`src/runtime/asm_amd64p32.s`、`src/runtime/asm_arm.s`といった複数のアーキテクチャ固有のアセンブリファイルに重複して存在していました。このサンクは、ランタイムが現在の時刻を取得するために`time.now`関数を呼び出すためのものでした。
    *   このコミットでは、`runtime·timenow`の実装を`src/runtime/thunk.s`という新しい（または既存の）専用のアセンブリファイルに移動しました。これにより、この共通のサンクが単一の場所に集約され、コードの重複が解消されました。これは、異なるアーキテクチャ間で共通の低レベルな処理をより効率的に管理するための一般的なパターンです。

2.  **汎用C/アセンブリサービス宣言の`stubs.go`への集約**:
    *   `getgoroot()`、`fastrand1()`、`readgstatus()`といった、C言語やアセンブリで実装されているランタイムサービスのGo側からの宣言が、`src/runtime/extern.go`、`src/runtime/mgc0.go`、`src/runtime/mprof.go`など、複数のファイルに分散していました。
    *   このコミットでは、これらの宣言を`src/runtime/stubs.go`に移動しました。`stubs.go`は、Goランタイムが外部（アセンブリやC）で実装された関数を呼び出すためのインターフェースを定義する場所として機能します。これにより、ランタイムの低レベルなインターフェースが`stubs.go`に一元化され、どの関数が外部実装であるか、そしてそのシグネチャが何であるかを容易に把握できるようになります。これは、コードの構造を明確にし、依存関係を管理しやすくするための重要なステップです。

これらの変更は、機能的な振る舞いを変更するものではなく、純粋にコードの内部的な整理と構造化を目的としています。

## コアとなるコードの変更箇所

このコミットにおけるコアとなるコードの変更は、主に以下のファイルにおけるコードの移動と宣言の追加/削除です。

*   **`src/runtime/asm_386.s`, `src/runtime/asm_amd64.s`, `src/runtime/asm_amd64p32.s`, `src/runtime/asm_arm.s`**:
    *   これらのファイルから、`TEXT runtime·timenow(SB), NOSPLIT, $0-0`で始まる`timenow`サンクのアセンブリ実装が削除されました。
*   **`src/runtime/extern.go`, `src/runtime/mgc0.go`, `src/runtime/mprof.go`**:
    *   `getgoroot() string` (extern.go), `func timenow() (sec int64, nsec int32)` (mgc0.go), `func fastrand1() uint32` および `func readgstatus(*g) uint32` (mprof.go) といった、アセンブリやCで実装された関数のGo側の宣言が削除されました。
*   **`src/runtime/stubs.go`**:
    *   削除された上記の宣言（`func readgstatus(*g) uint32`, `func fastrand1() uint32`, `func timenow() (sec int64, nsec int32)`）がこのファイルに追加されました。これにより、これらの低レベルサービスのGo側からのインターフェースが一元化されました。
*   **`src/runtime/thunk.s`**:
    *   `TEXT runtime·timenow(SB), NOSPLIT, $0-0`で始まる`timenow`サンクのアセンブリ実装がこのファイルに追加されました。これは、他の`asm_*.s`ファイルから移動されたものです。

## コアとなるコードの解説

このコミットの核心は、Goランタイムの低レベルな部分におけるコードの「場所」を最適化することにあります。

`timenow`サンクを`thunk.s`に移動したことは、共通のアセンブリルーチンを専用のファイルに集約するという設計思想を反映しています。これにより、同じコードが複数の場所で維持されることによる冗長性が排除され、将来的に`timenow`のロジックに変更が必要になった場合でも、修正箇所が単一に限定されるため、保守が容易になります。また、`thunk.s`というファイル名自体が、このようなサンクの目的を明確に示しており、コードの意図を理解しやすくなります。

一方、`getgoroot`、`fastrand1`、`readgstatus`といった関数の宣言を`stubs.go`に集約したことは、Goランタイムが外部（アセンブリやC）で実装されたサービスとどのように連携するかを明確にするためのものです。`stubs.go`は、これらの「スタブ」宣言の公式なリポジトリとして機能し、Goコードが低レベルなランタイム機能にアクセスするための統一されたインターフェースを提供します。これにより、ランタイムの内部構造を理解しようとする開発者にとって、どの関数がGoで実装され、どの関数がアセンブリやCで実装されているのかが、より明確になります。

これらの変更は、個々の機能の動作を変更するものではありませんが、Goランタイムのコードベース全体の構造と保守性を大幅に改善するものです。
