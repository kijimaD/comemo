## 前提知識の解説

### `math/big`パッケージと任意精度演算

Go言語の標準ライブラリ`math/big`パッケージは、任意精度の数値演算を提供します。これは、標準の`int`、`int64`、`float64`などの組み込み型では扱えない、非常に大きな整数（`big.Int`）、有理数（`big.Rat`）、または高い精度が要求される浮動小数点数（`big.Float`）を扱うために設計されています。

*   **`big.Float`**: 任意精度の浮動小数点数を表します。精度はビット数で指定でき、必要に応じて動的に調整することも可能です。これにより、計算中に発生する丸め誤差を最小限に抑え、極めて正確な結果を得ることができます。`big.Float`の演算は、通常の浮動小数点数演算よりも計算コストが高くなりますが、その分、精度が保証されます。

### ニュートン法（Newton's Method）

ニュートン法は、関数`f(x) = 0`の根（解）を数値的に見つけるための反復法です。このコミットの例では、数値`a`の平方根を求めるために使用されます。平方根`x = sqrt(a)`は、`x^2 - a = 0`の根であるため、関数`f(x) = x^2 - a`にニュートン法を適用します。

ニュートン法の更新式は以下の通りです。
`x_{n+1} = x_n - f(x_n) / f'(x_n)`

ここで、`f(x) = x^2 - a` であり、その導関数 `f'(x) = 2x` です。
これを代入すると、平方根を求めるためのニュートン法の更新式は次のようになります。
`x_{n+1} = x_n - (x_n^2 - a) / (2x_n)`
`x_{n+1} = x_n - x_n/2 + a/(2x_n)`
`x_{n+1} = x_n/2 + a/(2x_n)`
`x_{n+1} = 1/2 * (x_n + a/x_n)`

この式は、初期推定値`x_0`から始めて、`x_1, x_2, ...`と反復計算を行うことで、真の平方根に収束していきます。ニュートン法は、各反復で有効桁数がほぼ倍になるという非常に速い収束性を持つことが特徴です。

### `math.Log2`

`math.Log2`関数は、Go言語の`math`パッケージに属し、引数の2を底とする対数（二進対数）を計算します。このコミットの例では、ニュートン法の反復回数を決定するために使用されています。ニュートン法が各ステップで有効桁数を約2倍にするという性質を利用し、目標とする精度（`prec`ビット）に到達するために必要な反復回数を`log_2(prec)`で概算しています。

## 技術的詳細

`Example_sqrt2`関数は、`big.Float`を使用して数値2の平方根を200ビットの精度で計算するプロセスを詳細に示しています。

1.  **精度の設定**:
    `const prec = 200`
    計算に使用する精度を200ビットに設定します。これは`big.Float`の仮数部（mantissa）のビット数を指し、この値が大きいほど計算結果の精度が高くなります。

2.  **反復回数の決定**:
    `steps := int(math.Log2(prec))`
    ニュートン法は各反復で有効桁数が約2倍になるため、目標精度`prec`に到達するために必要な反復回数を`log_2(prec)`で概算します。200ビットの精度の場合、`log_2(200)`は約7.64なので、`steps`は8となります。これにより、十分な精度が得られるまで反復が行われます。

3.  **`big.Float`値の初期化**:
    *   `two := new(big.Float).SetPrec(prec).SetInt64(2)`: 計算対象の数値2を`prec`ビットの精度を持つ`big.Float`として初期化します。
    *   `half := new(big.Float).SetPrec(prec).SetFloat64(0.5)`: ニュートン法の更新式で使用する1/2を`prec`ビットの精度を持つ`big.Float`として初期化します。
    *   `x := new(big.Float).SetPrec(prec).SetInt64(1)`: 平方根の初期推定値として1を`prec`ビットの精度を持つ`big.Float`として初期化します。
    *   `t := new(big.Float)`: 一時変数`t`を宣言します。`big.Float`の演算では、結果を格納するレシーバ（この場合は`t`）の精度が設定されていない（0の場合）場合、引数の中で最も大きい精度を自動的に引き継ぐため、ここでは明示的に精度を設定する必要はありません。

4.  **ニュートン法の反復計算**:
    `for i := 0; i <= steps; i++ { ... }`
    `steps`回だけ反復計算を行います。各反復では、以下のニュートン法の更新式が適用されます。
    `x_{n+1} = 1/2 * ( x_n + (2.0 / x_n) )`
    コードでは、この式が3つのステップに分けて実行されます。
    *   `t.Quo(two, x)`: `t = 2.0 / x_n` を計算します。`Quo`は除算メソッドです。
    *   `t.Add(x, t)`: `t = x_n + (2.0 / x_n)` を計算します。`Add`は加算メソッドです。
    *   `x.Mul(half, t)`: `x_{n+1} = 0.5 * t` を計算し、結果を`x`に格納します。`Mul`は乗算メソッドです。

5.  **結果の出力**:
    *   `fmt.Printf("sqrt(2) = %.50f\\n", x)`: 計算された平方根`x`を小数点以下50桁まで表示します。`big.Float`は`fmt.Formatter`インターフェースを実装しているため、通常の`fmt.Printf`の動詞（verb）を使用できます。
    *   `t.Mul(x, x)`: 計算された`x`の二乗を`t`に格納します。
    *   `fmt.Printf("error = %e\\n", t.Sub(two, t))`: `x*x`と元の数値2との誤差を指数表記で表示します。理想的には0に非常に近い値になるはずです。

この例は、`big.Float`の基本的な操作（初期化、精度設定、加算、乗算、除算）と、数値アルゴリズム（ニュートン法）を組み合わせて高い精度の計算を行う方法を明確に示しています。

## コアとなるコードの変更箇所

`src/math/big/example_test.go`ファイルに以下の`Example_sqrt2`関数が追加されました。

```go
// This example shows how to use big.Float to compute the square root of 2 with
// a precision of 200 bits, and how to print the result as a decimal number.
func Example_sqrt2() {
	// We'll do computations with 200 bits of precision in the mantissa.
	const prec = 200

	// Compute the square root of 2 using Newton's Method. We start with
	// an initial estimate for sqrt(2), and then iterate:
	//     x_{n+1} = 1/2 * ( x_n + (2.0 / x_n) )

	// Since Newton's Method doubles the number of correct digits at each
	// iteration, we need at least log_2(prec) steps.
	steps := int(math.Log2(prec))

	// Initialize values we need for the computation.
	two := new(big.Float).SetPrec(prec).SetInt64(2)
	half := new(big.Float).SetPrec(prec).SetFloat64(0.5)

	// Use 1 as the initial estimate.
	x := new(big.Float).SetPrec(prec).SetInt64(1)

	// We use t as a temporary variable. There's no need to set its precision
	// since big.Float values with unset (== 0) precision automatically assume
	// the largest precision of the arguments when used as the result (receiver)
	// of a big.Float operation.
	t := new(big.Float)

	// Iterate.
	for i := 0; i <= steps; i++ {
		t.Quo(two, x)  // t = 2.0 / x_n
		t.Add(x, t)    // t = x_n + (2.0 / x_n)
		x.Mul(half, t) // x_{n+1} = 0.5 * t
	}

	// We can use the usual fmt.Printf verbs since big.Float implements fmt.Formatter
	fmt.Printf("sqrt(2) = %.50f\\n", x)

	// Print the error between 2 and x*x.
	t.Mul(x, x) // t = x*x
	fmt.Printf("error = %e\\n", t.Sub(two, t))

	// Output:
	// sqrt(2) = 1.41421356237309504880168872420969807856967187537695
	// error = 0.000000e+00
}
```

## コアとなるコードの解説

追加された`Example_sqrt2`関数は、`math/big`パッケージの`big.Float`型を用いて、数値2の平方根を高い精度で計算する具体的な手順を示しています。

1.  **`prec`定数の定義**: `const prec = 200` は、計算に使用する浮動小数点数の精度を200ビットに設定しています。`big.Float`は、このビット数で仮数部を表現し、より高い精度を可能にします。

2.  **`steps`変数の計算**: `steps := int(math.Log2(prec))` は、ニュートン法の反復回数を決定します。ニュートン法は各反復で有効桁数がほぼ倍になるため、目標精度`prec`に到達するために必要な最小限の反復回数を`log_2(prec)`で概算しています。これにより、無駄な計算を省きつつ、必要な精度を確保します。

3.  **`big.Float`変数の初期化**:
    *   `two`, `half`, `x`はそれぞれ、計算対象の数値2、ニュートン法の係数0.5、そして平方根の初期推定値1を`big.Float`型で表現しています。`SetPrec(prec)`を呼び出すことで、これらの数値が指定された200ビットの精度で扱われるように設定されます。
    *   `t`は一時的な計算結果を保持するための`big.Float`変数です。`big.Float`のメソッド（`Quo`, `Add`, `Mul`など）は、レシーバ（結果を格納する変数）の精度が設定されていない場合、引数の中で最も高い精度を自動的に採用するため、`t`には明示的な精度設定は不要です。

4.  **ニュートン法の反復ループ**: `for i := 0; i <= steps; i++` ループ内で、ニュートン法の更新式 `x_{n+1} = 1/2 * ( x_n + (2.0 / x_n) )` が実装されています。
    *   `t.Quo(two, x)`: `2.0 / x_n` を計算し、結果を`t`に格納します。
    *   `t.Add(x, t)`: `x_n + (2.0 / x_n)` を計算し、結果を`t`に格納します。
    *   `x.Mul(half, t)`: `0.5 * (x_n + (2.0 / x_n))` を計算し、次の反復のための新しい推定値`x_{n+1}`を`x`に格納します。

5.  **結果の出力と誤差の確認**:
    *   `fmt.Printf("sqrt(2) = %.50f\\n", x)`: 最終的に計算された`x`（数値2の平方根）を小数点以下50桁まで整形して出力します。`big.Float`は`fmt.Formatter`インターフェースを実装しているため、標準の`fmt.Printf`で直接出力できます。
    *   `t.Mul(x, x)`: 計算された平方根`x`の二乗を求めます。
    *   `fmt.Printf("error = %e\\n", t.Sub(two, t))`:`x*x`と元の数値2との差を計算し、誤差を指数表記で出力します。この誤差が非常に小さい（理想的には0）ことで、計算の正確性が確認できます。

このコードは、`big.Float`が提供する高精度演算能力と、ニュートン法のような数値アルゴリズムを組み合わせることで、いかにして高い精度の計算を実現できるかを示す優れた例となっています。
