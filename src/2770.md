## 変更の背景
この変更の背景には、Go言語の公式ドキュメンテーションツールである`godoc`のレンダリング挙動があります。`godoc`はGoのソースコード内のコメントを解析し、HTML形式のドキュメントを生成します。この際、特定の書式規則に従ってコメントを記述することで、より整形された、読みやすいドキュメントが出力されます。

元のコメントでは、リストの項目がハイフン (`-`) の後にタブ文字なしで記述されていました。これは一部のドキュメンテーションツールでは適切にリストとして解釈されないか、あるいは意図しない表示になる可能性があります。このコミットは、`godoc`がリストとして正しく認識し、視覚的に整った形で表示できるように、ハイフンの後にタブ文字 (`\t`) を追加することでインデントを調整しています。これにより、生成されるドキュメントの品質とユーザーエクスペリエンスが向上します。

## 前提知識の解説

### Go言語の`godoc`ツール
`godoc`は、Go言語のソースコードからドキュメンテーションを生成するための公式ツールです。Goの設計思想の一つに「ドキュメンテーションはコードと共に生きるべき」という考え方があり、`godoc`はその思想を具現化しています。
- **機能**: ソースコード内のエクスポートされた型、関数、変数、定数、パッケージなどの宣言に付随するコメントを解析し、HTML形式のドキュメントとして提供します。
- **コメントの書式**: `godoc`は特定のコメント書式を解釈します。例えば、パッケージ宣言の直前のコメントはパッケージの概要となり、エクスポートされた識別子の直前のコメントはその識別子の説明となります。リスト形式の記述もサポートされており、適切にインデントされたハイフンやアスタリスクを使用することで、整形されたリストとしてレンダリングされます。
- **目的**: 開発者がコードを理解しやすくするため、またライブラリやパッケージの利用者がAPIを迅速に把握できるようにするために不可欠なツールです。

### `bignum`パッケージ
`bignum`パッケージは、Go言語で任意精度算術（arbitrary-precision arithmetic）を扱うための初期の実験的なパッケージでした。これは、標準の`int`や`float64`型では表現できない非常に大きな数値や非常に小さな数値を扱う際に使用されます。
- **任意精度算術**: コンピュータのネイティブなデータ型が持つ固定のビット幅に制限されず、必要に応じてメモリを動的に割り当てて、任意の桁数の数値を表現・計算する技術です。
- **提供される型**:
    - `Natural`: 符号なし整数（非負の整数）
    - `Integer`: 符号付き整数
    - `Rational`: 有理数（分数）
- **現在の状況**: `bignum`パッケージは、後に標準ライブラリの`math/big`パッケージに置き換えられ、より堅牢で最適化された任意精度算術機能が提供されています。このコミットが行われた2009年当時は、まだ`bignum`が開発途上にあった時期です。

## 技術的詳細
このコミットの技術的詳細は、`godoc`がコメント内のリストをどのように解釈し、レンダリングするかに集約されます。

`godoc`は、コメントブロック内でハイフン (`-`) やアスタリスク (`*`) で始まる行をリスト項目として認識します。しかし、単にハイフンを置くだけでなく、その後に適切なインデント（通常はタブまたは複数のスペース）が続くことで、より明確なリスト構造として解釈され、HTML出力時に`<ul>`や`<ol>`タグ、`<li>`タグが適切に生成されます。

元のコード:
```go
// - Natural	unsigned integers
// - Integer	signed integers
// - Rational	rational numbers
```
この形式では、`godoc`がこれを単なる箇条書きとして認識する可能性はありますが、より厳密なリスト構造として解釈されない場合や、視覚的なインデントが不足する場合があります。

変更後のコード:
```go
//	- Natural	unsigned integers
//	- Integer	signed integers
//	- Rational	rational numbers
```
変更点を見ると、各行のハイフン (`-`) の前にタブ文字 (`\t`) が追加されています。これにより、`godoc`はこれらの行を明確にインデントされたリスト項目として認識し、生成されるHTMLドキュメントにおいて、より適切な視覚的階層と整形された表示を実現します。これは、ドキュメンテーションのセマンティクスを改善し、最終的な出力の品質を高めるための細かな調整です。

このような変更は、コードの動作には全く影響を与えませんが、ドキュメンテーションの品質を重視するGo言語のエコシステムにおいては重要な改善と見なされます。

## コアとなるコードの解説
この変更は、`bignum`パッケージの概要を説明するコメントブロックにあります。

```go
// A package for arbitrary precision arithmethic.
// It implements the following numeric types:
//
//	- Natural	unsigned integers
//	- Integer	signed integers
//	- Rational	rational numbers
//
package bignum
```

このコメントは、`bignum`パッケージが提供する主要な数値型をリストアップしています。変更前は、各リスト項目のハイフンがコメントスラッシュ`//`の直後に続いていましたが、変更後はハイフンの前にタブ文字が挿入されています。

このタブ文字の追加は、`godoc`がコメントをHTMLに変換する際に、これらの項目を適切にインデントされたリストとしてレンダリングするための指示となります。これにより、生成されるドキュメントでは、これらの型が視覚的に区別され、パッケージの機能がより明確に提示されるようになります。これは、コードの可読性ではなく、生成されるドキュメントの可読性を向上させるための典型的な修正です。
