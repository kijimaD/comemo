## 変更の背景

Go言語の初期開発段階において、文字列操作はプログラミングにおいて不可欠な機能でした。このコミットは、`strings` パッケージに、文字列の大文字・小文字変換と空白文字のトリミングという基本的なユーティリティを追加することを目的としています。

しかし、この時点ではまだGo言語のUnicodeサポートが完全に成熟していなかったため、これらの関数は一時的に「ASCII限定」の実装として導入されました。コード内のコメント `// TODO: full Unicode support` が示すように、開発チームは将来的に完全なUnicode対応を行う意図を持っていました。これは、開発の初期段階でまず必要最低限の機能を提供し、その後徐々に機能を拡張していくという一般的なアプローチを反映しています。

ASCII限定の実装は、マルチバイト文字の処理を考慮する必要がないため、シンプルかつ効率的に実装できるという利点があります。これにより、Go言語のユーザーは、少なくともASCII文字に関しては基本的な文字列操作をすぐに利用できるようになりました。

## 前提知識の解説

### Go言語における文字列 (string)
Go言語の `string` 型は、読み取り専用のバイトスライス (`[]byte`) として実装されており、UTF-8エンコードされたテキストを保持します。これは、文字列が直接文字のシーケンスではなく、バイトのシーケンスであることを意味します。

### ASCIIとUnicode
*   **ASCII (American Standard Code for Information Interchange)**: 英語圏で広く使われる文字コードで、0から127までの数値で英数字、記号、制御文字を表します。各文字は1バイトで表現されます。
*   **Unicode**: 世界中のあらゆる文字を統一的に扱うための文字コードです。ASCIIを含む多くの文字セットを包含し、各文字には一意のコードポイントが割り当てられます。UTF-8はUnicodeのエンコーディング形式の一つで、可変長バイト（1バイトから4バイト）でコードポイントを表現します。ASCII文字はUTF-8でも1バイトで表現されるため、ASCII互換性があります。

### 大文字・小文字変換の課題
ASCII文字の場合、大文字と小文字は特定の数値オフセットで関連付けられています（例: 'a'と'A'）。しかし、Unicodeではこの関係はより複雑で、言語や文脈によって大文字・小文字のルールが異なります。また、1文字が複数バイトで表現されるため、バイト単位での操作では正しく変換できない場合があります。

### 空白文字のトリミングの課題
ASCIIではスペース、タブ、改行などが空白文字として定義されますが、Unicodeにはさらに多くの空白文字（例: 全角スペース、ノーブレークスペースなど）が存在します。

### `strings` パッケージ
Go言語の標準ライブラリの一部であり、文字列を操作するための多くのユーティリティ関数を提供します。例えば、文字列の検索、置換、分割、結合などがあります。

## 技術的詳細

このコミットで追加された `UpperASCII`、`LowerASCII`、`TrimSpaceASCII` 関数は、Go言語の `string` がバイトスライスであるという特性を利用し、バイト単位で処理を行います。

### `UpperASCII` および `LowerASCII`
これらの関数は、入力文字列 `s` の各バイトをループ処理します。
*   `UpperASCII` は、バイト値が `'a'` から `'z'` の範囲にある場合、そのバイト値から `'a' - 'A'` の差分を引くことで、対応する大文字のASCIIバイト値に変換します。
*   `LowerASCII` は、バイト値が `'A'` から `'Z'` の範囲にある場合、そのバイト値に `'a' - 'A'` の差分を足すことで、対応する小文字のASCIIバイト値に変換します。

重要な点として、UTF-8エンコードされたマルチバイト文字は、ASCIIの低位バイト値（0-127）を使用しないため、これらの関数はASCII文字のみを安全にバイト単位で処理できます。非ASCII文字（例: 日本語、アクセント付きのラテン文字など）は変換されず、そのままのバイト値でコピーされます。これは、`// TODO: full Unicode support` コメントが示唆するように、意図的な制限です。

### `isWhitespaceASCII`
このヘルパー関数は、入力バイト `c` がASCIIの空白文字（スペース `' '`、タブ `'\t'`、キャリッジリターン `'\r'`、ラインフィード `'\n'`）のいずれかであるかを判定します。非常に限定的な定義であり、Unicodeの空白文字は考慮されていません。

### `TrimSpaceASCII`
この関数は、`isWhitespaceASCII` を利用して、文字列の先頭と末尾からASCII空白文字を削除します。
1.  `start` と `end` という2つのインデックスを初期化します。`start` は文字列の先頭、`end` は文字列の末尾を指します。
2.  `start` を文字列の先頭から増やしていき、`isWhitespaceASCII` が `false` を返す最初の文字を見つけます。
3.  `end` を文字列の末尾から減らしていき、`isWhitespaceASCII` が `false` を返す最初の文字を見つけます。
4.  最終的に、`s[start:end]` のスライスを返します。これにより、先頭と末尾の空白文字が取り除かれた文字列が得られます。

このアプローチもバイト単位で行われるため、非ASCIIの空白文字には対応していません。

### テストコード (`strings_test.go`)
テストファイルでは、`StringTest` という構造体と `runStringTests` というヘルパー関数が導入されています。
*   `StringTest` は、入力文字列 `in` と期待される出力文字列 `out` を保持します。
*   `runStringTests` は、与えられた文字列操作関数 `f` とテストケースの配列 `testCases` を受け取り、各テストケースに対して関数を実行し、結果が期待値と一致するかを検証します。これにより、複数の文字列操作関数に対してテストロジックを再利用できるようになっています。

`upperASCIITests`、`lowerASCIITests`、`trimSpaceASCIITests` という具体的なテストケースが定義され、それぞれの関数が正しく動作するかを確認しています。

### `src/lib/strings/strings.go`

#### `func UpperASCII(s string) string`
この関数は、入力文字列 `s` のASCII小文字を対応する大文字に変換した新しい文字列を返します。
1.  `b := make([]byte, len(s))`：入力文字列 `s` と同じ長さのバイトスライス `b` を作成します。Goの文字列はイミュータブル（変更不可）なので、新しい文字列を構築するためにバイトスライスを使用します。
2.  `for i := 0; i < len(s); i++`：文字列 `s` の各バイトをループ処理します。
3.  `c := s[i]`：現在のバイトを `c` に格納します。
4.  `if 'a' <= c && c <= 'z'`：現在のバイト `c` がASCII小文字の範囲内にあるかをチェックします。
5.  `c -= 'a' - 'A'`：もしASCII小文字であれば、大文字との差分（例: 'a'と'A'のASCII値の差）を引くことで、対応する大文字のASCII値に変換します。
6.  `b[i] = c`：変換された（または変換されなかった）バイトを新しいバイトスライス `b` に格納します。
7.  `return string(b)`：構築されたバイトスライス `b` を文字列に変換して返します。

#### `func LowerASCII(s string) string`
この関数は、入力文字列 `s` のASCII大文字を対応する小文字に変換した新しい文字列を返します。ロジックは `UpperASCII` と対称的です。
1.  `if 'A' <= c && c <= 'Z'`：現在のバイト `c` がASCII大文字の範囲内にあるかをチェックします。
2.  `c += 'a' - 'A'`：もしASCII大文字であれば、小文字との差分を足すことで、対応する小文字のASCII値に変換します。

#### `func isWhitespaceASCII(c byte) bool`
このヘルパー関数は、与えられたバイト `c` がASCIIの空白文字であるかを判定します。
1.  `switch int(c)`：バイト `c` の整数値に基づいて分岐します。
2.  `case ' ', '\t', '\r', '\n'`：スペース、タブ、キャリッジリターン、ラインフィードのいずれかであれば `true` を返します。
3.  それ以外の場合は `false` を返します。

#### `func TrimSpaceASCII(s string) string`
この関数は、入力文字列 `s` の先頭と末尾からASCII空白文字を削除した新しい文字列スライスを返します。
1.  `start, end := 0, len(s)`：`start` は文字列の開始インデックス、`end` は文字列の終了インデックス（排他的）を初期化します。
2.  `for start < end && isWhitespaceASCII(s[start])`：`start` インデックスを文字列の先頭から増やしていき、`isWhitespaceASCII` が `false` を返す最初の文字（非空白文字）を見つけます。
3.  `for start < end && isWhitespaceASCII(s[end-1])`：`end` インデックスを文字列の末尾から減らしていき、`isWhitespaceASCII` が `false` を返す最初の文字（非空白文字）を見つけます。`s[end-1]` は現在の `end` が指す位置の直前の文字です。
4.  `return s[start:end]`：`start` から `end` までの部分文字列をスライスとして返します。これにより、先頭と末尾の空白文字が取り除かれた文字列が得られます。
