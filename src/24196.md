## 変更の背景

このコミットは、Go言語の `time` パッケージにおける `Format` 関数のドキュメントの明確化を目的としています。具体的には、Issue #10963 で報告された、秒の小数部をフォーマットする方法が分かりにくいという問題に対処しています。

Goの `time.Format` 関数は、特定の参照時刻（`Mon Jan _2 15:04:05 MST 2006`）をテンプレートとして使用し、そのテンプレート内の各要素が実際の時刻値の対応する部分に置き換えられるという独特のフォーマット方法を採用しています。しかし、秒の小数部を表現する方法については、既存のドキュメントでは十分に説明されておらず、ユーザーがどのようにミリ秒やマイクロ秒などを出力すればよいか迷うことがありました。

この変更は、ドキュメントに具体的な例と説明を追加することで、この混乱を解消し、開発者がより直感的に `time.Format` を利用できるようにすることを意図しています。

## 前提知識の解説

### Go言語の `time` パッケージ

Go言語の標準ライブラリに含まれる `time` パッケージは、時刻の表現、操作、フォーマット、パース（解析）のための機能を提供します。

### `time.Time` 型

`time.Time` 型は、特定の時点を表す構造体です。年、月、日、時、分、秒、ナノ秒、タイムゾーン情報などを保持します。

### `time.Format` 関数

`time.Format(layout string) string` 関数は、`time.Time` 型の値を指定されたレイアウト文字列に従ってフォーマットし、文字列として返します。Goの `time.Format` の特徴は、フォーマット文字列が `strftime` や `SimpleDateFormat` のような記号ベースではなく、**参照時刻**（`Mon Jan _2 15:04:05 MST 2006`）の各要素をテンプレートとして使用する点です。

例えば、`2006` は年、`01` は月、`02` は日、`15` は時（24時間形式）、`04` は分、`05` は秒を表します。この参照時刻の各要素を、出力したいフォーマットに合わせて並べ替えることで、任意の時刻フォーマットを作成できます。

### 秒の小数部

時刻の秒の小数部は、ミリ秒（10^-3秒）、マイクロ秒（10^-6秒）、ナノ秒（10^-9秒）などで表現されます。これらを時刻フォーマットに含めることは、ログ記録、データ交換、高精度なタイムスタンプが必要なアプリケーションで非常に重要です。

## コアとなるコードの解説

このコミットは、Goの `time` パッケージの `format.go` ファイル内のドキュメントコメントに、以下の重要な説明を追加しています。

```go
// A fractional second is represented by adding a period and zeros
// to the end of the seconds section of layout string, as in "15:04:05.000"
// to format a time stamp with millisecond precision.
```

この追加されたコメントは、`time.Format` 関数で秒の小数部をフォーマットする際の具体的な方法を明確に示しています。

-   **`"15:04:05"`**: これは、参照時刻 `Mon Jan _2 15:04:05 2006` の「時:分:秒」の部分に対応します。
-   **`.000`**: 秒の参照値 `05` の後にピリオドとゼロを追加することで、小数部の精度を指定します。
    -   `.0` は小数点以下1桁（100ミリ秒）
    -   `.00` は小数点以下2桁（10ミリ秒）
    -   `.000` は小数点以下3桁（ミリ秒）
    -   `.000000` は小数点以下6桁（マイクロ秒）
    -   `.000000000` は小数点以下9桁（ナノ秒）

このように、追加するゼロの数によって、出力される小数部の精度を制御できます。この説明は、これまで暗黙的であった、または他の例から推測する必要があったフォーマットルールを明示的にすることで、ユーザーエクスペリエンスを大幅に向上させます。

また、`time.Format` の実行可能な例（`Example`）への参照が、より目立つように追加され、既存の参照も小文字の `example` に修正されました。これにより、ユーザーは実際のコード例を通じてフォーマットの動作を容易に確認できるようになります。
