# [インデックス 23552] ファイルの概要

このコミットは、GoランタイムにおけるOpenBSD環境でのシグナルハンドリングの挙動を改善するものです。具体的には、OSスレッド（M）が初期化される際に、常に全てのシグナルをアンブロックするのではなく、必要なシグナルのみをアンブロックするように変更し、より適切なシグナルマスクの管理を実現しています。これにより、OpenBSD上でのGoプログラムのシグナル処理がより堅牢かつ予測可能になります。

## 元コミット内容

このコミットは、OpenBSD環境において、GoランタイムがOSスレッド（M）の初期化時にシグナルマスクを管理する方法を変更します。以前は、`minit`関数内で`sigprocmask(_SIG_SETMASK, sigset_none)`を呼び出すことで、OSスレッドのシグナルマスクを空（全てのシグナルをアンブロック）に設定していました。

この変更により、以下の挙動が導入されます。

1.  **シグナルマスクの保存**: `msigsave`関数が、現在のOSスレッドのシグナルマスクを`m.sigmask`に保存するようになりました。
2.  **選択的なシグナルアンブロック**: `minit`関数では、保存された`m.sigmask`を基に、Goランタイムが処理する必要がある特定のシグナル（`_SigUnblock`フラグが設定されているシグナル）のみをアンブロックするように`nmask`を計算し、そのマスクを適用します。これにより、ランタイムにとって重要でないシグナルは、元のマスクの状態に応じてブロックされたままになります。
3.  **シグナルマスクの復元**: `unminit`関数が追加され、OSスレッドがGoランタイムから解放される際に、`msigsave`で保存された元のシグナルマスクを復元するようになりました。

この変更は、OpenBSD上でGoランタイムがシグナルを「常に全てブロックする」のではなく、「常に全てアンブロックする」という以前の挙動を修正し、よりきめ細やかなシグナルマスク管理を行うことを目的としています。

## 変更の背景

この変更の背景には、GoランタイムがOSスレッドのシグナルマスクをどのように管理すべきかという課題があります。Unix系システムでは、各スレッドが独自のシグナルマスクを持ち、どのシグナルを受信するかを制御できます。Goランタイムは、ゴルーチンをOSスレッドに多重化して実行するため、シグナルハンドリングは非常に重要です。

以前のOpenBSD実装では、OSスレッドがGoランタイムによって初期化される際（`minit`）、無条件に全てのシグナルをアンブロックしていました。これは、Goランタイムが特定のシグナルを処理できるようにするための一種の「リセット」操作として機能していた可能性があります。しかし、この「全てアンブロック」というアプローチは、以下のような問題を引き起こす可能性がありました。

1.  **外部ライブラリとの競合**: GoプログラムがCgoを介してCライブラリを呼び出す場合、Cライブラリが特定のシグナルをブロックしていることを期待していることがあります。Goランタイムが勝手に全てのシグナルをアンブロックしてしまうと、Cライブラリの期待するシグナルハンドリングの挙動が壊れる可能性がありました。
2.  **意図しないシグナル受信**: プログラムの他の部分やOSが特定のシグナルをブロックしていることを期待しているにもかかわらず、Goランタイムがそれをアンブロックしてしまうと、意図しないシグナルがスレッドに配信され、予期せぬ動作やクラッシュにつながる可能性がありました。
3.  **一貫性の欠如**: 他のOS（Linuxなど）では、Goランタイムはより洗練されたシグナルマスク管理を行っており、OpenBSDでも同様の堅牢なメカニズムを導入する必要がありました。

このコミットは、これらの問題を解決し、OpenBSD環境でのシグナルハンドリングを他のプラットフォームと同等に、より安全で予測可能なものにすることを目的としています。具体的には、OSスレッドがGoランタイムにアタッチされる前のシグナルマスクを尊重しつつ、Goランタイム自身が必要とするシグナルのみをアンブロックするという、よりバランスの取れたアプローチを採用しています。

## 前提知識の解説

このコミットを理解するためには、以下の概念について知っておく必要があります。

### 1. GoランタイムのM-P-Gモデル

Goランタイムは、ゴルーチン（G）、論理プロセッサ（P）、OSスレッド（M）という3つのエンティティを使用して並行性を管理します。

*   **G (Goroutine)**: Goにおける軽量な実行単位。ユーザーが記述する並行処理のコードです。
*   **P (Processor)**: OSスレッド（M）上でゴルーチン（G）を実行するためのコンテキストを提供します。スケジューラの一部であり、実行可能なゴルーチンのキューを保持します。
*   **M (Machine/OS Thread)**: 実際のOSスレッドです。Pにアタッチされ、そのPが管理するゴルーチンを実行します。Goランタイムは必要に応じてOSスレッドを生成・破棄し、ゴルーチンをM上で実行します。

シグナルはOSスレッド（M）に配信されるため、Mのシグナルマスクがシグナルハンドリングの挙動に直接影響します。

### 2. Unix系システムにおけるシグナルとシグナルマスク

*   **シグナル**: プロセスやスレッドに対して非同期に通知されるイベントです。例えば、`SIGINT`（Ctrl+C）、`SIGSEGV`（セグメンテーション違反）、`SIGTERM`（終了要求）などがあります。
*   **シグナルマスク**: 各スレッドは「シグナルマスク」と呼ばれるビットマスクを持っています。このマスクは、そのスレッドが現在ブロックしているシグナルのセットを定義します。シグナルがブロックされている場合、そのシグナルはスレッドに配信されず、保留状態になります。ブロックが解除されると、保留されていたシグナルが配信されます。
*   **`sigprocmask`システムコール**: シグナルマスクを操作するためのシステムコールです。
    *   `sigprocmask(how, set, oldset)`:
        *   `how`: シグナルマスクの変更方法を指定します。
            *   `_SIG_BLOCK`: `set`で指定されたシグナルを現在のマスクに追加（ブロック）します。
            *   `_SIG_UNBLOCK`: `set`で指定されたシグナルを現在のマスクから削除（アンブロック）します。
            *   `_SIG_SETMASK`: 現在のマスクを`set`で指定されたシグナルセットに置き換えます。
        *   `set`: 新しいシグナルマスクまたは追加/削除するシグナルセットへのポインタ。
        *   `oldset`: 変更前のシグナルマスクを保存するためのポインタ。`NULL`の場合、保存されません。
    *   `sigprocmask(_SIG_BLOCK, 0)`: `set`が`0`（または`NULL`）の場合、現在のシグナルマスクを変更せずに取得します。

### 3. `unsafe.Pointer`とポインタ操作

Goの`unsafe`パッケージは、型安全性をバイパスして低レベルのポインタ操作を可能にします。このコミットでは、`unsafe.Pointer`を使用して`uint32`型のポインタと`m.sigmask`（通常は`sigset`型）の間で型変換を行い、シグナルマスクのビット操作を行っています。これは、`sigset`がOSによって異なる構造を持つ可能性があるため、共通の`uint32`として扱うことで移植性を高める（または特定のOSでの実装詳細に対応する）ためと考えられます。

### 4. `sigtable`と`_SigUnblock`フラグ

Goランタイム内部には、各シグナルの特性を定義する`sigtable`という配列が存在します。このテーブルには、シグナル番号、デフォルトのアクション、そして`_SigUnblock`のようなフラグが含まれています。`_SigUnblock`フラグは、Goランタイムが特定の状況下で、そのシグナルをOSスレッドのシグナルマスクから明示的にアンブロックする必要があることを示します。これには、ランタイムエラー（例: `SIGSEGV`）や、Goのネットワーキングなどが依存するシグナル（例: `SIGIO`）が含まれることがあります。

## 技術的詳細

このコミットの技術的詳細は、`src/runtime/os1_openbsd.go`ファイル内の`msigsave`, `minit`, `unminit`関数の変更に集約されます。

### `msigsave(mp *m)`関数の変更

*   **変更前**: この関数は何もしていませんでした。
*   **変更後**:
    ```go
    smask := (*uint32)(unsafe.Pointer(&mp.sigmask))
    if unsafe.Sizeof(*smask) > unsafe.Sizeof(mp.sigmask) {
        throw("insufficient storage for signal mask")
    }
    *smask = sigprocmask(_SIG_BLOCK, 0)
    ```
    このコードは、現在のOSスレッドのシグナルマスクを取得し、それを`mp.sigmask`に保存します。
    *   `unsafe.Pointer(&mp.sigmask)`: `mp.sigmask`のアドレスを`unsafe.Pointer`に変換します。`mp.sigmask`は`m`構造体の一部で、OSスレッドのシグナルマスクを保持するためのフィールドです。
    *   `(*uint32)(...)`: `unsafe.Pointer`を`*uint32`型にキャストします。これは、シグナルマスクを32ビットの整数として扱うことを意図しています。
    *   `sigprocmask(_SIG_BLOCK, 0)`: このシステムコールは、現在のスレッドのシグナルマスクを変更せずに取得します。`_SIG_BLOCK`は通常、シグナルをブロックするために使われますが、第2引数（`set`）が`0`の場合、現在のマスクを返すという特殊な挙動をします。
    *   `*smask = ...`: 取得した現在のシグナルマスクの値を`mp.sigmask`に書き込みます。

    これにより、GoランタイムがOSスレッドを「借りる」直前のシグナルマスクの状態が保存されることになります。

### `minit()`関数の変更

*   **変更前**:
    ```go
    sigprocmask(_SIG_SETMASK, sigset_none)
    ```
    これは、OSスレッドのシグナルマスクを`sigset_none`（全てのシグナルがアンブロックされた状態）に設定していました。
*   **変更後**:
    ```go
    // restore signal mask from m.sigmask and unblock essential signals
    nmask := *(*uint32)(unsafe.Pointer(&_g_.m.sigmask))
    for i := range sigtable {
        if sigtable[i].flags&_SigUnblock != 0 {
            nmask &^= 1 << (uint32(i) - 1)
        }
    }
    sigprocmask(_SIG_SETMASK, nmask)
    ```
    このコードは、OSスレッドがGoランタイムによって初期化される際に、より洗練されたシグナルマスクを設定します。
    *   `nmask := *(*uint32)(unsafe.Pointer(&_g_.m.sigmask))`: `msigsave`で保存された元のシグナルマスクを`nmask`にロードします。`_g_.m`は現在のゴルーチンが実行されているOSスレッド（M）を指します。
    *   `for i := range sigtable { ... }`: `sigtable`をイテレートし、各シグナルについてチェックします。
    *   `if sigtable[i].flags&_SigUnblock != 0`: もしシグナル`i`に`_SigUnblock`フラグが設定されている場合、そのシグナルはGoランタイムにとって重要であり、アンブロックされるべきであると判断されます。
    *   `nmask &^= 1 << (uint32(i) - 1)`: `nmask`から該当するシグナルのビットをクリアします。これは、そのシグナルをアンブロックする操作に相当します。`uint32(i) - 1`は、シグナル番号が1から始まるため、ビットマスクのインデックスを0ベースに調整しています。
    *   `sigprocmask(_SIG_SETMASK, nmask)`: 最終的に計算された`nmask`をOSスレッドの新しいシグナルマスクとして設定します。

    この変更により、GoランタイムはOSスレッドがGoコードを実行する際に、元のシグナルマスクを尊重しつつ、ランタイムの動作に不可欠なシグナルのみをアンブロックするようになります。

### `unminit()`関数の追加

*   **変更前**: この関数は存在しませんでした。
*   **変更後**:
    ```go
    _g_ := getg()
    smask := *(*uint32)(unsafe.Pointer(&_g_.m.sigmask))
    sigprocmask(_SIG_SETMASK, smask)
    signalstack(nil, 0)
    ```
    この関数は、OSスレッドがGoランタイムから解放される際（例えば、`dropm`関数によってMがPから切り離される際）に呼び出されます。
    *   `smask := *(*uint32)(unsafe.Pointer(&_g_.m.sigmask))`: `msigsave`で保存された元のシグナルマスクを再度取得します。
    *   `sigprocmask(_SIG_SETMASK, smask)`: OSスレッドのシグナルマスクを、Goランタイムがそのスレッドを「借りる」前の状態に完全に復元します。
    *   `signalstack(nil, 0)`: シグナルスタックをリセットします。

    この復元処理は非常に重要です。これにより、GoランタイムがOSスレッドのシグナルマスクを変更した影響が、そのスレッドがGoランタイムの管理下を離れた後も残ってしまう「シグナルマスクのリーク」を防ぎます。これにより、OSスレッドが他の目的（例えばCgoコールバックやOSの他の部分）で使用される際に、予測可能なシグナルハンドリングの挙動が保証されます。

## コアとなるコードの解説

このコミットの核心は、GoランタイムがOSスレッドのシグナルマスクを管理する方法を、**「無条件に全てアンブロックする」** から **「元の状態を保存し、必要なものだけアンブロックして、終了時に復元する」** という、より洗練されたアプローチに変更した点にあります。

1.  **`msigsave`でのシグナルマスクの保存**:
    `msigsave`関数は、OSスレッドがGoランタイムの管理下に入る直前に呼び出されます。ここで`sigprocmask(_SIG_BLOCK, 0)`を使って現在のシグナルマスクを取得し、`mp.sigmask`に保存します。これは、スレッドがGoランタイムに「貸し出される」前の状態を記録するものです。

2.  **`minit`での選択的アンブロック**:
    `minit`関数は、OSスレッドがGoランタイムによって初期化され、ゴルーチンを実行する準備ができたときに呼び出されます。
    *   まず、`msigsave`で保存された`_g_.m.sigmask`を`nmask`としてロードします。
    *   次に、`sigtable`を走査し、`_SigUnblock`フラグが設定されているシグナル（Goランタイムが処理する必要があるシグナル）について、`nmask`からそのシグナルをアンブロックします（ビットをクリアします）。
    *   最後に、この`nmask`を`sigprocmask(_SIG_SETMASK, nmask)`でOSスレッドの新しいシグナルマスクとして設定します。
    このプロセスにより、Goランタイムは、スレッドの元のシグナルマスクを尊重しつつ、ランタイムの正常な動作に必要なシグナルのみがアンブロックされることを保証します。これにより、外部ライブラリがブロックしているシグナルが意図せずアンブロックされることを防ぎます。

3.  **`unminit`でのシグナルマスクの復元**:
    `unminit`関数は、OSスレッドがGoランタイムの管理下を離れる際（例えば、ゴルーチンが終了し、OSスレッドがアイドル状態に戻るか、CgoコールバックのためにGoランタイムから切り離される際）に呼び出されます。
    *   ここで、`_g_.m.sigmask`に保存されていた元のシグナルマスクを再度取得し、`sigprocmask(_SIG_SETMASK, smask)`を使ってOSスレッドのシグナルマスクを元の状態に完全に復元します。
    この復元処理は、Goランタイムがスレッドのシグナルマスクに加えた変更が、そのスレッドがGoランタイムの管理下を離れた後も影響を及ぼさないようにするために不可欠です。これにより、シグナルマスクのリークを防ぎ、システム全体のシグナルハンドリングの一貫性と予測可能性を保ちます。

これらの変更により、OpenBSD上でのGoプログラムは、より堅牢で、他のシステムとの互換性も高いシグナルハンドリングを実現できるようになりました。
