## 変更の背景

Go言語のテストフレームワークでは、`_test.go`で終わるファイルにテストコードを記述します。その中でも、`Example`関数は特別な意味を持ちます。これらは単なるテストとして実行されるだけでなく、`godoc`コマンドによって生成されるパッケージのドキュメントに組み込まれ、実際に実行可能なコード例として表示されます。これにより、ドキュメントが常に最新かつ正確なコード例を提供することが保証されます。

このコミットが行われた背景には、おそらく以下の理由が考えられます。

1.  **ドキュメントの品質向上**: `Example`関数を専用の`example_test.go`ファイルに分離することで、`godoc`がより適切にこれらの例を抽出し、パッケージのドキュメントとして公開しやすくなります。これにより、`mime`パッケージの利用者が`encodedword`機能の使い方をより簡単に理解できるようになります。
2.  **テストコードとExampleコードの分離**: 従来の`encodedword_test.go`ファイルには、ユニットテストとExampleコードが混在していました。これを分離することで、それぞれのファイルの役割が明確になり、コードの可読性と保守性が向上します。ユニットテストは機能の検証に集中し、Exampleコードは使用方法のデモンストレーションに集中できます。
3.  **`go test -examples`の活用**: `go test -examples`コマンドは、`Example`関数のみを実行し、その出力が期待される出力と一致するかを検証します。Exampleコードを専用ファイルに移動することで、この機能がより効果的に利用され、Exampleコード自体の正確性が保証されます。
4.  **Go issue #11257の修正**: コミットメッセージにある`Fixes #11257`は、この変更が特定の課題を解決したことを示唆しています。具体的な課題内容は不明ですが、上記の理由のいずれか、またはそれらの組み合わせが、Exampleコードの移動を必要としたと考えられます。

## 前提知識の解説

### Go言語のテストとExample関数

Go言語には、標準で強力なテストフレームワークが組み込まれています。
*   **`_test.go`ファイル**: Goのパッケージ内で、ファイル名が`_test.go`で終わるファイルはテストファイルとして扱われます。これらのファイルには、`TestXxx`という形式のテスト関数、`BenchmarkXxx`という形式のベンチマーク関数、そして`ExampleXxx`という形式のExample関数を記述できます。
*   **`Example`関数**:
    *   `func ExampleF()`: 関数`F`のExample。
    *   `func ExamplePackage()`: パッケージ全体のExample。
    *   `func ExampleType_Method()`: 型`Type`のメソッド`Method`のExample。
    `Example`関数は、その関数の標準出力が`// Output:`コメントに続く内容と一致するかどうかを`go test`実行時に検証します。これにより、Exampleコードが常に動作し、ドキュメントと実際の挙動が乖離しないように保たれます。
    また、`godoc`コマンドで生成されるドキュメントに自動的に組み込まれ、パッケージの利用者にコードの具体的な使用例を提供します。
*   **`example_test.go`ファイル**: `Example`関数を記述するための慣習的なファイル名です。このファイルは、テスト対象のパッケージとは異なるパッケージ名（例: `package mime_test`）を持つことが一般的です。これにより、Exampleコードがパッケージの外部からどのように利用されるかをシミュレートし、公開APIのみを使用していることを保証できます。

### MIME "Encoded-Word" Syntax (RFC 2047)

MIME (Multipurpose Internet Mail Extensions) は、電子メールでASCII以外の文字やマルチメディアコンテンツを扱うための標準です。RFC 2047は、MIMEヘッダフィールド（例: Subject, From, To）内で非ASCII文字を安全に表現するための「Encoded-Word」構文を定義しています。

Encoded-Wordの一般的な形式は以下の通りです。
`=?charset?encoding?encoded-text?=`

*   **`charset`**: 元のテキストの文字セット（例: `utf-8`, `iso-8859-1`）。
*   **`encoding`**: エンコード方式。`Q`はQ-encoding（Quoted-Printableに似た形式）、`B`はBase64エンコーディングを意味します。
*   **`encoded-text`**: 指定された`charset`と`encoding`でエンコードされたテキスト。

例えば、`¡Hola, señor!`という文字列をUTF-8でQ-encodingすると、`=?utf-8?q?=C2=A1Hola,_se=C3=B1or!?=`のようになります。

### Goの`mime`パッケージ

Go標準ライブラリの`mime`パッケージは、MIMEエンティティの解析と生成をサポートします。このパッケージには、RFC 2047で定義されているEncoded-Wordのエンコードとデコードを行うための`WordEncoder`と`WordDecoder`型が含まれています。

*   `mime.QEncoding.Encode(charset, s string)`: Q-encodingを使用して文字列`s`をエンコードします。
*   `mime.BEncoding.Encode(charset, s string)`: Base64エンコーディングを使用して文字列`s`をエンコードします。
*   `mime.WordDecoder`: Encoded-Wordをデコードするための型で、`Decode`メソッド（単一のEncoded-Wordをデコード）と`DecodeHeader`メソッド（複数のEncoded-Wordを含むヘッダ文字列をデコード）を提供します。

## 技術的詳細

このコミットの技術的な核心は、GoのテストフレームワークにおけるExample関数のベストプラクティスへの準拠です。

1.  **`_test.go`から`example_test.go`への移動**:
    *   元の`src/mime/encodedword_test.go`は、`package mime`に属していました。これは、テスト対象のパッケージと同じパッケージ名を持つ通常のテストファイルです。
    *   新しく作成された`src/mime/example_test.go`は、`package mime_test`に属しています。この命名規則は、Exampleコードがテスト対象のパッケージの外部にあるかのように振る舞うことを意味します。これにより、Exampleコードはパッケージの公開されたAPIのみを使用することが強制され、内部実装に依存しない、より堅牢な使用例を提供できます。
    *   `mime_test`パッケージから`mime`パッケージの機能を利用するには、`mime.QEncoding.Encode`のように、パッケージ名を明示的に指定する必要があります。これは、`example_test.go`内のコードが`mime`パッケージのインポートを必要とすることからも明らかです。

2.  **`Example`関数の役割の強化**:
    *   `ExampleWordEncoder_Encode()`、`ExampleWordDecoder_Decode()`、`ExampleWordDecoder_DecodeHeader()`といった関数は、`mime`パッケージの`WordEncoder`と`WordDecoder`の基本的な使い方をデモンストレーションしています。
    *   これらの関数には`// Output:`コメントが含まれており、`go test`実行時に実際の出力と期待される出力が比較されます。これにより、Exampleコードが常に正しく動作することが保証されます。
    *   特に`ExampleWordDecoder_Decode()`と`ExampleWordDecoder_DecodeHeader()`では、`CharsetReader`フィールドをカスタム関数で設定することで、未知の文字セット（例: `x-case`）を処理する方法も示されており、`mime`パッケージの柔軟性が強調されています。これは、実際のアプリケーションで様々な文字セットを扱う際に役立つ高度な使用例です。

この変更により、`mime`パッケージのドキュメントはよりリッチで信頼性の高いものとなり、開発者が`encodedword`機能を効果的に利用するための手助けとなります。

## コアとなるコードの解説

新しく作成された`src/mime/example_test.go`ファイルは、`mime`パッケージの`encodedword`機能の利用方法を具体的に示すExample関数を含んでいます。

```go
package mime_test // パッケージ名を `mime_test` とすることで、外部からの利用をシミュレート

import (
	"bytes"
	"fmt"
	"io"
	"io/ioutil"
	"mime" // mimeパッケージをインポート
)

// ExampleWordEncoder_Encode は mime.WordEncoder の Encode メソッドの使用例を示します。
// 異なる文字セットとエンコーディング（Q-encoding, Base64-encoding）で文字列をエンコードする方法をデモンストレーションします。
func ExampleWordEncoder_Encode() {
	fmt.Println(mime.QEncoding.Encode("utf-8", "¡Hola, señor!"))
	fmt.Println(mime.QEncoding.Encode("utf-8", "Hello!"))
	fmt.Println(mime.BEncoding.Encode("UTF-8", "¡Hola, señor!"))
	fmt.Println(mime.QEncoding.Encode("ISO-8859-1", "Caf\\xE9"))
	// Output:
	// =?utf-8?q?=C2=A1Hola,_se=C3=B1or!?=
	// Hello!
	// =?UTF-8?b?wqFIb2xhLCBzZcOxb3Ih?=
	// =?ISO-8859-1?q?Caf=E9?=
}

// ExampleWordDecoder_Decode は mime.WordDecoder の Decode メソッドの使用例を示します。
// 単一の Encoded-Word をデコードする方法と、カスタム CharsetReader を設定して未知の文字セットを扱う方法をデモンストレーションします。
func ExampleWordDecoder_Decode() {
	dec := new(mime.WordDecoder)
	header, err := dec.Decode("=?utf-8?q?=C2=A1Hola,_se=C3=B1or!?=")
	if err != nil {
		panic(err)
	}
	fmt.Println(header)

	// カスタム CharsetReader の設定例
	dec.CharsetReader = func(charset string, input io.Reader) (io.Reader, error) {
		switch charset {
		case "x-case":
			// 例のための偽の文字セット。実際には go-charset などのパッケージと統合される。
			content, err := ioutil.ReadAll(input)
			if err != nil {
				return nil, err
			}
			return bytes.NewReader(bytes.ToUpper(content)), nil // 大文字に変換する例
		default:
			return nil, fmt.Errorf("unhandled charset %q", charset)
		}
	}
	header, err = dec.Decode("=?x-case?q?hello!?=")
	if err != nil {
		panic(err)
	}
	fmt.Println(header)
	// Output:
	// ¡Hola, señor!
	// HELLO!
}

// ExampleWordDecoder_DecodeHeader は mime.WordDecoder の DecodeHeader メソッドの使用例を示します。
// 複数の Encoded-Word を含むヘッダ文字列をデコードする方法と、カスタム CharsetReader を使用する例をデモンストレーションします。
func ExampleWordDecoder_DecodeHeader() {
	dec := new(mime.WordDecoder)
	header, err := dec.DecodeHeader("=?utf-8?q?=C3=89ric?= <eric@example.org>, =?utf-8?q?Ana=C3=AFs?= <anais@example.org>")
	if err != nil {
		panic(err)
	}
	fmt.Println(header)

	header, err = dec.DecodeHeader("=?utf-8?q?=C2=A1Hola,?= =?utf-8?q?_se=C3=B1or!?=")
	if err != nil {
		panic(err)
	}
	fmt.Println(header)

	// ExampleWordDecoder_Decode と同様にカスタム CharsetReader を使用
	dec.CharsetReader = func(charset string, input io.Reader) (io.Reader, error) {
		switch charset {
		case "x-case":
			content, err := ioutil.ReadAll(input)
			if err != nil {
				return nil, err
			}
			return bytes.NewReader(bytes.ToUpper(content)), nil
		default:
			return nil, fmt.Errorf("unhandled charset %q", charset)
		}
	}
	header, err = dec.DecodeHeader("=?x-case?q?hello_?= =?x-case?q?world!?=")
	if err != nil {
		panic(err)
	}
	fmt.Println(header)
	// Output:
	// Éric <eric@example.org>, Anaïs <anais@example.org>
	// ¡Hola, señor!
	// HELLO WORLD!
}
```

このコードは、`mime`パッケージの`encodedword`機能の主要なAPIである`WordEncoder`と`WordDecoder`の具体的な使用例を提供します。特に、`mime_test`パッケージとして定義されているため、`mime`パッケージの公開APIのみが使用されていることが保証され、実際のアプリケーションでの利用方法を正確に反映しています。`// Output:`コメントにより、これらの例が`go test`によって検証可能であり、`godoc`によってドキュメントとして生成されることが期待されます。
