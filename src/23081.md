## 変更の背景

このコミットの主な背景は、Go言語の公式FAQドキュメントに記載されている情報が古くなり、非推奨となったツールへの参照が含まれていたことです。具体的には、Goパッケージのベンダーリング（vendoring）を支援するツールとして`github.com/kr/goven`が紹介されていましたが、このツール自体が非推奨（deprecated）とされていました。

Goプロジェクトの目的は、ユーザーに最新かつ推奨されるプラクティスとツールを提供することです。そのため、非推奨のツールへの参照を削除し、代わりにGoの標準ツールチェインの一部である`golang.org/x/tools/cmd/gomvpkg`のような、より適切で公式にサポートされているツールを推奨することが望ましいと判断されました。これにより、ユーザーはGoのパッケージ管理に関する正確で最新の情報を得られるようになります。

## 前提知識の解説

### Goのパッケージ管理とベンダーリング

Go言語では、コードは「パッケージ」という単位で整理されます。他の開発者が作成したパッケージ（外部依存）を利用する場合、通常は`go get`コマンドを使用してそれらをダウンロードし、プロジェクトのビルドパスに含めます。

しかし、外部依存のバージョン管理や、ビルドの再現性を確保するために、「ベンダーリング（Vendoring）」という手法が用いられることがあります。ベンダーリングとは、プロジェクトが依存する外部パッケージのソースコードを、プロジェクト自身のレポジトリ内の特定のディレクトリ（通常は`vendor/`）にコピーして管理することです。これにより、外部パッケージの変更がプロジェクトのビルドに予期せぬ影響を与えることを防ぎ、特定のバージョンの依存関係を固定できます。

Go 1.5以降、Goツールチェインは公式にベンダーリングをサポートするようになりました。それ以前は、`goven`のようなサードパーティツールがベンダーリングのプロセスを自動化するために利用されていました。

### Goツールチェインと`golang.org/x/tools`

Go言語には、`go build`、`go test`、`go run`などの基本的なコマンドを提供する強力な「Goツールチェイン」が組み込まれています。これらはGo開発の基盤となります。

さらに、Goチームは`golang.org/x/`配下に、Goの標準ライブラリには含まれないが、Goエコシステムにとって有用な実験的または補助的なツールやライブラリを公開しています。`golang.org/x/tools`はその一つで、Goコードの解析、変換、リファクタリング、その他の開発支援を行うための様々なツールが含まれています。`gomvpkg`もこの`golang.org/x/tools`の一部として提供されています。

## 技術的詳細

### `goven`と`gomvpkg`の役割

*   **`github.com/kr/goven`**: このツールは、Go 1.5で公式にベンダーリングがサポートされる以前の時代に、Goプロジェクトにおける外部依存のベンダーリングを支援するために開発されました。具体的には、依存パッケージを`vendor/`ディレクトリにコピーするプロセスを自動化する役割を担っていました。しかし、Goツールチェイン自体がベンダーリング機能を内蔵するようになり、また、より洗練されたモジュール管理システム（Go Modules）が登場したことで、その役割は薄れ、非推奨となりました。コミットメッセージにあるように、開発者自身が非推奨であることを示していました。

*   **`golang.org/x/tools/cmd/gomvpkg`**: `gomvpkg`は、Goパッケージを移動し、それに伴うインポートパスの変更をGoソースファイル全体で自動的に更新するためのコマンドラインツールです。これは、大規模なGoプロジェクトのリファクタリングにおいて非常に有用です。
    *   **機能**:
        *   指定されたGoパッケージをあるインポートパスから別のインポートパスへ移動します。
        *   移動先のパスが既存のパッケージと競合しないか分析し、競合がある場合はエラーを報告します。
        *   プロジェクト内のすべてのGoソースファイルをスキャンし、移動されたパッケージへのインポートパスを自動的に更新します。
        *   オプションで、バージョン管理システム（VCS）と連携し、`git mv`のようなコマンドを実行して、ファイルシステムの移動をVCSにも反映させることができます（`-vcs_mv_cmd`フラグ）。
    *   **標準ツールとしての位置づけ**: `gomvpkg`は`golang.org/x/tools`の一部として提供されており、Goチームによってメンテナンスされています。これは、Go開発者が安心して利用できる「標準的な」ツールであることを意味します。
    *   **`gopls`との関連**: 近年では、`gomvpkg`が提供するようなパッケージ移動とインポートパス更新の機能は、Go言語サーバーである`gopls`（Go Language Server）に統合されています。`gopls`はIDEやエディタと連携し、リアルタイムでコード補完、定義へのジャンプ、リファクタリングなどの機能を提供しており、`gomvpkg`の機能もその一部として利用可能です。

このコミットは、GoのFAQドキュメントが、Goエコシステムの進化とツールの推奨状況の変化に合わせて更新されたことを示しています。

## コアとなるコードの解説

変更は`doc/go_faq.html`ファイル内の1箇所のみです。

*   **削除された行**:
    ```html
    -Keith Rarick\'s <a href=\"https://github.com/kr/goven\">goven</a> is one tool to help automate this process.
    ```
    この行は、`goven`というツールへの言及と、そのGitHubリポジトリへのリンクを含んでいました。

*   **追加された行**:
    ```html
    +<a href=\"https://godoc.org/golang.org/x/tools/cmd/gomvpkg\">gomvpkg</a> is one tool to help automate this process.
    ```
    この行は、`gomvpkg`というツールへの言及と、その`godoc.org`上のドキュメントへのリンクに置き換えられています。
