## 変更の背景

Go言語の`net`パッケージは、ネットワークインターフェースの情報（IPアドレス、ネットマスクなど）を取得するためのクロスプラットフォームなAPIを提供します。しかし、オペレーティングシステム（特にWindows）によっては、これらの情報が正確に取得できない、あるいはOSのネイティブツールが返す情報と一致しないといった問題が発生することがあります。

このコミットの背景には、Goの`net`パッケージがWindows上で返すネットワークインターフェースのアドレスとネットマスクの正確性を検証する必要性がありました。特に、Issue #12811で報告されているような、`net`パッケージが返す情報に不整合がある可能性が指摘されており、その問題を修正した後に、その修正が正しく機能していることを確認するための堅牢なテストが必要とされていました。

`netsh`コマンドはWindows環境でネットワーク設定を管理・表示するための標準的なツールであり、その出力は信頼できる情報源と見なされます。このコミットは、`netsh`の出力を「真実の源」として利用し、Goの`net`パッケージの出力と比較することで、Goパッケージの正確性を保証するためのテストメカニズムを導入しています。

## 前提知識の解説

### Go言語の `net` パッケージ

Go言語の標準ライブラリである`net`パッケージは、ネットワークI/Oのプリミティブな機能を提供します。これには、TCP/IP、UDP、ドメイン名解決、HTTPクライアント/サーバーなどが含まれます。特に、`net.Interface`構造体と`net.Interface.Addrs()`メソッドは、システム上のネットワークインターフェースに関する情報（名前、MACアドレス、IPアドレス、ネットマスクなど）を取得するために使用されます。

### Windowsの `netsh` コマンド

`netsh`（Network Shell）は、Windowsオペレーティングシステムに組み込まれているコマンドラインスクリプトユーティリティです。これを使用すると、ローカルまたはリモートのコンピューターのネットワーク構成を表示したり、変更したりできます。ネットワークインターフェース、IPアドレス、ルーティングテーブル、ファイアウォール設定など、多岐にわたるネットワーク関連の情報を操作できます。

このコミットでは、特に以下の`netsh`コマンドが利用されています。
*   `netsh interface ip show config`: すべてのネットワークインターフェースのIP構成情報を表示します。
*   `netsh interface ipv4 show address name="<interface_name>"`: 指定されたインターフェースのIPv4アドレス情報を表示します。
*   `netsh interface ipv6 show address interface="<interface_name>"`: 指定されたインターフェースのIPv6アドレス情報を表示します。

### Issue #12811

GoのIssue #12811は、「`net.InterfaceAddrs` returns incorrect netmask on Windows」というタイトルで、Windows環境において`net`パッケージの`InterfaceAddrs`関数が誤ったネットマスクを返す可能性があるというバグを報告しています。このバグは、特に複数のIPアドレスが割り当てられているインターフェースや、特定のネットワーク構成で顕著になる可能性があります。このコミットで追加されたテストは、このIssueが修正されたことを検証するために設計されています。

### PowerShell

`netsh`コマンドの実行には、WindowsのPowerShellが利用されています。PowerShellは、コマンドラインシェルとスクリプト言語を組み合わせたもので、システム管理タスクの自動化に広く使用されます。このコミットでは、`Out-File`コマンドレットを使用して`netsh`の出力を一時ファイルにリダイレクトし、UTF8エンコーディングで保存しています。これは、`netsh`の出力が特定の文字コードで提供される場合があるため、Goプログラムで確実に読み取れるようにするための工夫です。

## コアとなるコードの解説

### `runNetsh` 関数

```go
func runNetsh(args ...string) ([]byte, error) {
	removeUTF8BOM := func(b []byte) []byte {
		if len(b) >= 3 && b[0] == 0xEF && b[1] == 0xBB && b[2] == 0xBF {
			return b[3:]
		}
		return b
	}
	f, err := ioutil.TempFile("", "go-netsh-test")
	if err != nil {
		return nil, err
	}
	f.Close()
	defer os.Remove(f.Name())
	cmd := fmt.Sprintf(`%s | Out-File "%s" -encoding UTF8`, strings.Join(args, " "), f.Name())
	out, err := exec.Command("powershell", "-Command", cmd).CombinedOutput()
	if err != nil {
		if len(out) != 0 {
			return nil, fmt.Errorf("%s: %s", err, out)
		}
		return nil, err
	}
	out, err = ioutil.ReadFile(f.Name())
	if err != nil {
		return nil, err
	}
	return removeUTF8BOM(out), nil
}
```
この関数は、`netsh`コマンドをPowerShell経由で実行し、その出力を取得するための汎用的なヘルパーです。
1.  `removeUTF8BOM`という内部関数は、UTF-8 BOMが付加されている可能性のあるバイトスライスからBOMを除去します。これは、PowerShellの`Out-File -encoding UTF8`がBOMを付加することがあるためです。
2.  `ioutil.TempFile`で一時ファイルを作成し、`netsh`コマンドの出力をこのファイルにリダイレクトします。
3.  `fmt.Sprintf`でPowerShellコマンド文字列を構築します。`strings.Join(args, " ")`で`netsh`コマンドとその引数を結合し、`| Out-File "%s" -encoding UTF8`で一時ファイルにUTF8エンコーディングで出力するように指定します。
4.  `exec.Command("powershell", "-Command", cmd).CombinedOutput()`でPowerShellコマンドを実行し、標準出力と標準エラーを結合した結果を取得します。
5.  一時ファイルから内容を読み込み、`removeUTF8BOM`でBOMを除去した結果を返します。

### `netshInterfaceIPv4ShowAddress` 関数

```go
func netshInterfaceIPv4ShowAddress(name string) ([]string, error) {
	out, err := runNetsh("netsh", "interface", "ipv4", "show", "address", "name=\""+name+"\"")
	if err != nil {
		return nil, err
	}
	// adress information is listed like:
	//    IP Address:                           10.0.0.2
	//    Subnet Prefix:                        10.0.0.0/24 (mask 255.255.255.0)
	//    IP Address:                           10.0.0.3
	//    Subnet Prefix:                        10.0.0.0/24 (mask 255.255.255.0)
	addrs := make([]string, 0)
	var addr, subnetprefix string
	lines := bytes.Split(out, []byte{'\r', '\n'})
	for _, line := range lines {
		if bytes.Contains(line, []byte("Subnet Prefix:")) {
			f := bytes.Split(line, []byte{':'})
			if len(f) == 2 {
				f = bytes.Split(f[1], []byte{'('})
				if len(f) == 2 {
					f = bytes.Split(f[0], []byte{'/'})
					if len(f) == 2 {
						subnetprefix = string(bytes.TrimSpace(f[1]))
						if addr != "" && subnetprefix != "" {
							addrs = append(addrs, addr+"/"+subnetprefix)
						}
					}
				}
			}
		}
		addr = ""
		if bytes.Contains(line, []byte("IP Address:")) {
			f := bytes.Split(line, []byte{':'})
			if len(f) == 2 {
				addr = string(bytes.TrimSpace(f[1]))
			}
		}
	}
	return addrs, nil
}
```
この関数は、指定されたインターフェースのIPv4アドレスとネットマスクを`netsh`コマンドから取得し、`IPアドレス/CIDR`形式の文字列スライスとして返します。
1.  `runNetsh`を呼び出して`netsh interface ipv4 show address name="<interface_name>"`を実行します。
2.  `netsh`の出力を行ごとに分割し、各行を解析します。
3.  "Subnet Prefix:"を含む行からCIDR形式のネットマスクを抽出し、"IP Address:"を含む行からIPアドレスを抽出します。
4.  抽出したIPアドレスとネットマスクを結合し、`10.0.0.2/24`のような形式で`addrs`スライスに追加します。

```go
					have = append(have, addr.IP.String())
				}
			case *IPAddr:
				if addr.IP.To4() != nil {
					have = append(have, addr.String())
				}
				if addr.IP.To16() != nil && addr.IP.To4() == nil {
					// netsh does not output netmask for ipv6, so ignore ipv6 mask
					have = append(have, addr.IP.String())
				}
			}
		}
		sort.Strings(have)

		want, err := netshInterfaceIPv4ShowAddress(ifi.Name)
		if err != nil {
			t.Fatal(err)
		}
		wantIPv6, err := netshInterfaceIPv6ShowAddress(ifi.Name)
		if err != nil {
			t.Fatal(err)
		}
		want = append(want, wantIPv6...)
		sort.Strings(want)

		if strings.Join(want, "/") != strings.Join(have, "/") {
			t.Errorf("%s: unexpected addresses list %q, want %q", ifi.Name, have, want)
		}
	}
}
```
このテスト関数は、Goの`net`パッケージが返すネットワークインターフェースのアドレスが、`netsh`コマンドが返す情報と一致するかを検証します。
1.  `t.Skip`により、Issue #12811が修正されるまでテストがスキップされます。
2.  `net.Interfaces()`を呼び出して、システム上のすべてのネットワークインターフェースを取得します。
3.  各インターフェースについて、以下の処理を行います。
    *   `ifi.Addrs()`を呼び出して、Goが返すIPアドレスとネットマスクのリスト（`have`）を取得します。IPv6アドレスの場合、`netsh`がネットマスクを出力しないため、比較のためにIPv6アドレスのネットマスクは無視されます。
    *   `netshInterfaceIPv4ShowAddress`と`netshInterfaceIPv6ShowAddress`を呼び出して、`netsh`コマンドが返すIPアドレスとネットマスクのリスト（`want`）を取得します。
    *   `have`と`want`のリストをソートし、`strings.Join`で結合して比較します。
    *   もし両者が一致しない場合、`t.Errorf`でエラーを報告します。
