## 変更の背景

Go言語の仕様書は、言語の正確な挙動を定義する最も重要なドキュメントです。この仕様書は、開発者がGo言語の機能や構文を理解するための主要な情報源となります。このコミットの背景には、仕様書の可読性とナビゲーションを向上させるという目的があります。

Go言語では、文字列リテラルとルーンリテラルの両方で、バックスラッシュ (`\`) を用いたエスケープシーケンスが共通して使用されます。例えば、改行文字 (`\n`) やタブ文字 (`\t`)、Unicodeコードポイント (`\uXXXX`) などです。仕様書では、これらのエスケープシーケンスの規則がルーンリテラルのセクションで詳細に説明されています。

しかし、文字列リテラルのセクションでエスケープシーケンスについて言及する際、読者がルーンリテラルのセクションに移動して詳細を確認する必要があるにもかかわらず、直接的なリンクが提供されていませんでした。このため、読者は関連情報を探すために手動でスクロールしたり、目次を検索したりする必要がありました。

このコミットは、文字列リテラルのエスケープシーケンスに関する記述から、ルーンリテラルのセクションへのHTMLリンクを追加することで、このナビゲーションの不便さを解消し、読者が関連する情報に迅速にアクセスできるようにすることを目的としています。これにより、仕様書全体の整合性とユーザーエクスペリエンスが向上します。

## 前提知識の解説

このコミットの変更内容を理解するためには、以下のGo言語の基本的な概念と仕様書に関する知識が必要です。

### 1. Go言語の文字列リテラル (String Literals)

Go言語には2種類の文字列リテラルがあります。

*   **解釈済み文字列リテラル (Interpreted String Literals)**:
    *   ダブルクォーテーション (`"`) で囲まれます。例: `"Hello, world!"`
    *   バックスラッシュ (`\`) を含むエスケープシーケンスが解釈されます。例えば、`"\n"` は改行文字として扱われます。
    *   このコミットが関連するのは、このタイプの文字列リテラルです。
*   **Raw文字列リテラル (Raw String Literals)**:
    *   バッククォーテーション (`` ` ``) で囲まれます。例: `` `Hello,\nworld!` ``
    *   バックスラッシュを含むエスケープシーケンスは解釈されず、文字通りに扱われます。

### 2. Go言語のルーンリテラル (Rune Literals)

*   シングルクォーテーション (`'`) で囲まれます。例: `'a'`, `'世'`
*   単一のUnicodeコードポイントを表します。Go言語において「ルーン (rune)」はUnicodeコードポイントのエイリアスです。
*   ルーンリテラルも、文字列リテラルと同様にバックスラッシュを用いたエスケープシーケンスをサポートします。例えば、`'\n'` は改行文字のルーンを表します。

### 3. エスケープシーケンス (Escape Sequences)

エスケープシーケンスは、文字列やルーンリテラル内で特殊な意味を持つ文字や、直接入力できない文字（例: 改行、タブ、特定のUnicode文字）を表現するために使用されます。Go言語で一般的に使用されるエスケープシーケンスには以下のようなものがあります。

*   `\n`: 改行 (newline)
*   `\t`: タブ (tab)
*   `\\`: バックスラッシュ (backslash)
*   `\"`: ダブルクォーテーション (double quote) - 解釈済み文字列リテラル内で使用
*   `\'`: シングルクォーテーション (single quote) - ルーンリテラル内で使用
*   `\xNN`: 16進数で指定されたバイト値 (NNは2桁の16進数)
*   `\uNNNN`: 16進数で指定されたUnicodeコードポイント (NNNNは4桁の16進数)
*   `\UNNNNNNNN`: 16進数で指定されたUnicodeコードポイント (NNNNNNNNは8桁の16進数)
*   `\ooo`: 8進数で指定されたバイト値 (oooは3桁の8進数)

重要な点として、文字列リテラルとルーンリテラルでは、ほとんどのエスケープシーケンスの解釈規則が共通しています。ただし、文字列リテラル内では `\'` が不正であり、`\"` が合法であるのに対し、ルーンリテラル内では `\"` が不正であり、`\'` が合法であるという違いがあります。これは、リテラルを囲むクォーテーション文字をエスケープする必要があるためです。

### 4. Go言語仕様書 (The Go Programming Language Specification)

Go言語仕様書は、Go言語の構文、セマンティクス、および標準ライブラリの動作を正式に記述したドキュメントです。これはGo言語の「真実の源」であり、コンパイラの実装や言語の挙動に関する議論の最終的な権威となります。このドキュメントはHTML形式で提供されており、内部リンク（アンカーリンク）を使用して関連セクション間を移動できるようになっています。

## 技術的詳細

このコミットは、Go言語仕様書の一部である `doc/go_spec.html` ファイルを修正するものです。技術的な変更は、HTMLドキュメント内のテキストにハイパーリンクを追加するという非常にシンプルなものです。

具体的には、文字列リテラルに関するセクションで、エスケープシーケンスの解釈がルーンリテラルと同様であると説明している箇所に、ルーンリテラルのセクションへのHTMLアンカーリンク (`<a href="#Rune_literals">...</a>`) を挿入しています。

HTMLのアンカーリンクは、`<a>` タグと `href` 属性を使用して作成されます。`href` 属性の値が `#` で始まる場合、それは現在のドキュメント内の特定のIDを持つ要素へのリンク（アンカーリンク）を意味します。この場合、`#Rune_literals` は、HTMLドキュメント内の `id="Rune_literals"` を持つ要素（通常は見出しタグなど）へのリンクとなります。

この変更により、仕様書を読むユーザーは、文字列リテラルのエスケープシーケンスについて読んでいる際に、ルーンリテラルのエスケープシーケンスに関する詳細な説明が必要になった場合、クリック一つで関連するセクションに直接ジャンプできるようになります。これは、ドキュメントのユーザビリティと相互参照性を高めるための標準的なウェブ開発の手法です。

この変更は、Go言語のコンパイラやランタイムの動作には一切影響を与えません。純粋にドキュメントの改善であり、言語の定義そのものを変更するものではありません。
