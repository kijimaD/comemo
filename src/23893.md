## 変更の背景

Go言語の標準ライブラリは、その堅牢なドキュメンテーションと使いやすさで知られています。`html` パッケージは、HTMLエンティティのエンコード/デコード機能を提供し、ウェブアプリケーション開発においてクロスサイトスクリプティング (XSS) 攻撃などのセキュリティ脆弱性を防ぐ上で非常に重要です。

このコミットが行われた2015年当時、`html` パッケージの `EscapeString` および `UnescapeString` 関数には、公式な使用例が提供されていませんでした。Goの `Example` 関数は、単なるテストケースとしてだけでなく、`go doc` コマンドで表示されるドキュメントに自動的に組み込まれるため、関数の利用方法を開発者に示すための非常に効果的な手段です。

この変更の背景には、これらの重要な関数の利用促進と、開発者がより安全なウェブアプリケーションを構築できるよう、明確なガイドラインを提供したいという意図があります。具体的な使用例があることで、開発者は関数の挙動を直感的に理解し、誤用を防ぐことができます。

## 前提知識の解説

### 1. Go言語の `Example` 関数

Go言語には、通常のユニットテスト (`TestXxx`) とは別に、`ExampleXxx` という形式の関数を記述する慣習があります。これらの `Example` 関数は以下の特徴を持ちます。

*   **ドキュメンテーション:** `go doc` コマンドを実行すると、対応する関数やパッケージのドキュメントに `Example` 関数のコードスニペットと出力が自動的に表示されます。これにより、開発者は実際のコード例を通じて関数の使い方を学ぶことができます。
*   **テスト:** `Example` 関数は `go test` コマンドによって実行されます。関数内のコメント `// Output: ...` と実際の実行結果が一致するかどうかが検証されます。これにより、ドキュメントの例が常に最新かつ正確であることが保証されます。
*   **ファイル名:** 通常、`_test.go` で終わるファイルに記述されます。

### 2. HTMLエスケープとアンエスケープ

ウェブアプリケーションにおいて、ユーザーからの入力や外部データをHTMLとして表示する際には、セキュリティ上の注意が必要です。悪意のあるユーザーが `<script>` タグなどのHTML要素を挿入し、他のユーザーのブラウザで実行させる「クロスサイトスクリプティング (XSS)」攻撃を防ぐため、HTMLエスケープが不可欠です。

*   **HTMLエスケープ (HTML Escaping):**
    *   HTMLの特殊文字（`<`, `>`, `&`, `"`, `'` など）を、それに対応するHTMLエンティティ（`&lt;`, `&gt;`, `&amp;`, `&quot;`, `&#39;` など）に変換する処理です。
    *   これにより、特殊文字がHTMLタグや属性として解釈されるのを防ぎ、単なるテキストとして表示されるようにします。
    *   例: `<script>alert('XSS')</script>` は `&lt;script&gt;alert(&#39;XSS&#39;)&lt;/script&gt;` に変換されます。

*   **HTMLアンエスケープ (HTML Unescaping):**
    *   HTMLエンティティを、それに対応する元の特殊文字に変換する処理です。
    *   エスケープされた文字列を元の形式に戻す必要がある場合（例: データベースに保存されたエスケープ済みテキストを編集画面で表示する前など）に使用されます。
    *   例: `&lt;` は `<` に、`&amp;` は `&` に変換されます。

### 3. `html` パッケージの `EscapeString` と `UnescapeString`

Goの `html` パッケージは、これらのエスケープ/アンエスケープ機能を提供します。

*   `html.EscapeString(s string) string`: 指定された文字列 `s` 内のHTML特殊文字をHTMLエンティティにエスケープします。
*   `html.UnescapeString(s string) string`: 指定された文字列 `s` 内のHTMLエンティティを元の特殊文字にアンエスケープします。

## 技術的詳細

このコミットは、`src/html/example_test.go` という新しいファイルを追加することで、`html` パッケージの `EscapeString` と `UnescapeString` 関数の具体的な使用例を提供しています。

`ExampleEscapeString` 関数では、以下の文字列が使用されています。
```go
const s = `\"Fran & Freddie\'s Diner\" <tasty@example.com>`
```
この文字列には、HTMLで特殊な意味を持つ可能性のある文字（`"`, `&`, `'`, `<`, `>`）が含まれています。`html.EscapeString` を適用すると、これらの文字が対応するHTMLエンティティに変換され、出力は以下のようになります。
```
&#34;Fran &amp; Freddie&#39;s Diner&#34; &lt;tasty@example.com&gt;
```
ここで、`"` は `&#34;` に、`&` は `&amp;` に、`'` は `&#39;` に、`<` は `&lt;` に変換されていることがわかります。

一方、`ExampleUnescapeString` 関数では、エスケープされた文字列が入力として与えられています。
```go
const s = `&quot;Fran &amp; Freddie&#39;s Diner&quot; &lt;tasty@example.com&gt;`
```
この文字列に `html.UnescapeString` を適用すると、HTMLエンティティが元の特殊文字に戻され、出力は以下のようになります。
```
"Fran & Freddie's Diner" <tasty@example.com>
```
これにより、`&quot;` は `"` に、`&amp;` は `&` に、`&#39;` は `'` に、`&lt;` は `<` に変換されていることが確認できます。

これらの例は、Goの `Example` 関数の慣習に従い、`// Output: ...` コメントによって期待される出力が明示されています。これにより、`go test` 実行時に実際の出力と期待される出力が比較され、関数の動作が正しく維持されていることが保証されます。また、`go doc html` コマンドを実行した際に、これらの例がドキュメントとして表示され、開発者にとって非常に有用な情報源となります。
