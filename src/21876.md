## 変更の背景

`math/big`パッケージは、任意精度（arbitrary-precision）の数値演算を提供するGo言語の標準ライブラリです。浮動小数点数型である`Float`は、金融計算や科学技術計算など、高い精度が求められる場面で利用されます。

このコミットが行われた背景には、`Float`型の機能不足と既存関数の挙動の不整合があったと考えられます。

1.  **標準数学関数との互換性**: `Frexp`や`Ldexp`といった関数は、浮動小数点数を仮数部と指数部に分解・再構成するために広く使われる基本的な操作です。これらが`math/big.Float`に存在しないことは、任意精度浮動小数点数を用いた複雑な計算を行う上で不便でした。これらの関数を導入することで、標準の`math`パッケージとの互換性を高め、より柔軟な数値操作を可能にします。
2.  **`Set`と`Copy`の役割の明確化**: 以前の`Set`関数は、値の代入と精度の設定の両方の役割を担っていました。しかし、これは関数の責務が曖昧であり、特に精度の扱いにおいて混乱を招く可能性がありました。このコミットでは、`Copy`を導入して純粋な値の代入（精度と丸めモードもコピー）を行い、`Set`は既存の`Float`変数の精度と丸めモードを尊重しつつ値を設定するように変更することで、それぞれの関数の役割を明確化し、APIの整合性を向上させています。
3.  **`Cmp`関数の無限大対応**: 浮動小数点数の比較において、無限大（`+Inf`, `-Inf`）は特殊な値であり、その比較ルールはIEEE 754標準で定義されています。以前の`Cmp`関数が無限大を適切に扱えなかったことは、任意精度浮動小数点数を用いた比較演算の正確性を損なう可能性がありました。この修正により、`Float`型の比較演算がより堅牢になります。
4.  **堅牢性の向上**: 新機能の追加や既存機能の改善に伴い、関連するテストケースを拡充することで、コードの品質と信頼性を向上させる狙いがあります。

これらの変更は、`math/big.Float`がより強力で使いやすい任意精度浮動小数点数型となるための重要なステップと言えます。

## 前提知識の解説

このコミットを理解するためには、以下の概念が役立ちます。

1.  **任意精度浮動小数点数 (Arbitrary-Precision Floating-Point Numbers)**:
    通常の`float32`や`float64`といった浮動小数点数は、表現できる桁数（精度）が固定されています。これに対し、任意精度浮動小数点数は、必要に応じて精度を動的に調整できるため、非常に高い精度が要求される計算（例: 金融、物理シミュレーション）に適しています。Go言語の`math/big`パッケージがこれを提供します。

2.  **IEEE 754 浮動小数点数標準**:
    ほとんどの現代のコンピュータシステムで採用されている浮動小数点数の表現と演算に関する国際標準です。この標準は、有限の数値だけでなく、無限大（`+Inf`, `-Inf`）や非数（`NaN`）といった特殊な値の表現と、それらの値を含む演算の挙動も定義しています。`math/big`パッケージは、この標準に準拠した挙動を目指しています。

3.  **仮数部と指数部 (Mantissa/Significand and Exponent)**:
    浮動小数点数は通常、`符号 × 仮数部 × 基数^指数部`という形式で表現されます。
    *   **仮数部 (Mantissa / Significand)**: 数値の有効数字部分を表します。通常、正規化された形式（例: 1.0 <= 仮数部 < 2.0）で表現されます。
    *   **指数部 (Exponent)**: 基数（通常は2）を何乗するかを示し、数値のスケール（桁）を決定します。

4.  **`Frexp`関数**:
    `Frexp(x)`は、浮動小数点数`x`を仮数部`mant`と指数部`exp`に分解する関数です。結果は`x = mant × 2^exp`を満たし、`0.5 <= |mant| < 1.0`の範囲に正規化された`mant`と、整数`exp`を返します。これは、数値の内部表現を分析したり、特定の範囲に正規化したりする際に便利です。

5.  **`Ldexp`関数**:
    `Ldexp(mant, exp)`は、`Frexp`の逆操作を行う関数です。仮数部`mant`と指数部`exp`を受け取り、`mant × 2^exp`の計算結果を返します。これは、仮数部と指数部から浮動小数点数を再構成する際に使用されます。

6.  **`Set`と`Copy`のセマンティクス**:
    オブジェクト指向プログラミングにおいて、オブジェクトの代入やコピーは重要な概念です。
    *   **`Set`**: 既存のオブジェクトに別のオブジェクトの値を設定する操作。この際、既存オブジェクトのプロパティ（例: 精度、丸めモード）を尊重しつつ、値のみを更新することがあります。
    *   **`Copy`**: 別のオブジェクトの値を完全に複製し、新しいオブジェクトとして、または既存のオブジェクトにその全てのプロパティ（値、精度、丸めモードなど）を上書きする操作。

7.  **`Cmp`関数 (Compare)**:
    二つの数値を比較し、その大小関係を示す整数（例: -1, 0, 1）を返す関数です。浮動小数点数の比較では、通常の数値だけでなく、無限大や非数といった特殊な値の比較ルールも考慮する必要があります。

## 技術的詳細

このコミットでは、`math/big.Float`型の内部構造と操作に深く関わる変更が加えられています。

1.  **`Frexp` (`MantExp`) と `Ldexp` (`SetMantExp`) の実装**:
    *   `Float.MantExp()`: `Float`型の値を仮数部と指数部に分解します。`x.exp`が無限大を示す`infExp`でない限り、仮数部の指数を0に設定し、元の`x.exp`を整数`exp`として返します。これにより、仮数部は`0.5 <= |mant| < 1.0`の範囲に正規化されます。無限大やゼロの場合の特殊な挙動も定義されています。
    *   `Float.SetMantExp()`: `MantExp`の逆操作で、与えられた仮数部と指数部から`Float`型の値を構築します。無限大やゼロの場合の特殊な挙動、および指数部の大きさが`MaxExp`を超える場合の無限大への変換が考慮されています。

2.  **`IsInt`関数の実装**:
    `Float.IsInt()`は、`Float`型の値が整数であるかどうかを報告します。
    *   ゼロ（`x == 0`）は整数と見なされます。
    *   `0 < |x| <= 0.5`の範囲の非ゼロの数値は整数ではありません。
    *   `x.exp`が`x.prec`（精度）以上の場合、小数部を持つには十分な精度がないため、整数と見なされます。
    *   それ以外の場合、内部の仮数部（`x.mant`）の末尾のゼロビットを考慮し、必要な最小精度（`minPrec`）を計算します。`x.exp`が`minPrec`以上であれば整数と判断されます。無限大は整数とは見なされません。

3.  **`Set`と`Copy`のセマンティクス変更**:
    *   `Float.Set(x *Float)`: `z`の精度が0の場合、`x`の精度に設定されます。その後、`x`の符号、指数、仮数部を`z`にコピーします。`z`の精度が`x`の精度より小さい場合、丸め処理（`z.round(0)`）が行われます。これにより、`Set`は既存の`Float`変数の精度設定を尊重しつつ値を設定する「設定」操作となります。
    *   `Float.Copy(x *Float)`: `z`に`x`の全てのプロパティ（符号、指数、仮数部、精度、丸めモード）を完全にコピーします。これは「真の代入」操作であり、`x`の全ての状態を`z`に反映させます。以前の`Set`が担っていた役割をより明確な名前で提供します。

4.  **`Cmp`関数の無限大対応とロジック改善**:
    *   以前の`Cmp`関数は無限大の比較を適切に処理していませんでした。
    *   新しい`Cmp`関数は、まず`mag()`ヘルパー関数を使用して、両方の`Float`値の「大きさ」（符号付きの絶対値のようなもの）を比較します。`mag()`は、`-Inf`を-2、負の有限数を-1、ゼロを0、正の有限数を+1、`+Inf`を+2として返します。
    *   この`mag()`の結果に基づいて、無限大を含む比較が効率的に行われます。
    *   `mag()`が等しい（つまり、両方とも有限数で同じ符号を持つか、両方ともゼロである）場合にのみ、従来の`ucmp`（符号なし比較）ロジックが適用されます。これにより、無限大の比較が正確かつ効率的に行われるようになりました。

これらの変更は、`math/big.Float`のAPIの整合性を高め、より正確で堅牢な任意精度浮動小数点数演算を可能にしています。

## コアとなるコードの解説

### `src/math/big/float.go`

#### `func (x *Float) MantExp() (mant *Float, exp int)`

```go
// MantExp breaks x into its mantissa and exponent components.
// It returns mant and exp satisfying x == mant × 2**exp, with
// the absolute value of mant satisfying 0.5 <= |mant| < 1.0.
// mant has the same precision and rounding mode as x.
//
// Special cases are:
//
//	(  ±0).MantExp() =   ±0, 0
//	(±Inf).MantExp() = ±Inf, 0
//
// MantExp does not modify x; the result mant is a new Float.
func (x *Float) MantExp() (mant *Float, exp int) {
	mant = new(Float).Copy(x) // xのコピーをmantとして作成
	if x.exp != infExp {      // xが無限大でない場合
		mant.exp = 0          // mantの指数を0に設定
		exp = int(x.exp)      // xの指数を結果のexpとして返す
	}
	return
}
```
この関数は、浮動小数点数`x`を仮数部`mant`と指数部`exp`に分解します。`mant`は`x`のコピーとして初期化され、`x`が無限大でない限り、`mant`の指数は0に設定され、`x`の元の指数が`exp`として返されます。これにより、`mant`は`0.5 <= |mant| < 1.0`の範囲に正規化されます。

#### `func (z *Float) SetMantExp(mant *Float, exp int) *Float`

```go
// SetMantExp is the inverse of MantExp. It sets z to mant × 2**exp and
// and returns z. The result z has the same precision and rounding mode
// as mant.
//
// Special cases are:
//
//	z.SetMantExp(  ±0, exp) =   ±0
//	z.SetMantExp(±Inf, exp) = ±Inf
//
// The result is ±Inf if the magnitude of exp is > MaxExp.
func (z *Float) SetMantExp(mant *Float, exp int) *Float {
	z.Copy(mant) // mantの値をzにコピー
	if len(z.mant) == 0 || z.exp == infExp { // zがゼロまたは無限大の場合
		return z // そのまま返す
	}
	z.setExp(int64(exp)) // zの指数を設定
	return z
}
```
`MantExp`の逆操作です。与えられた仮数部`mant`と指数部`exp`から`Float`型の値`z`を構築します。`z`はまず`mant`のコピーとして初期化され、その後、`exp`に基づいて指数が設定されます。ゼロや無限大の特殊ケース、および指数が`MaxExp`を超える場合の無限大への変換が考慮されています。

#### `func (x *Float) IsInt() bool`

```go
// IsInt reports whether x is an integer.
// ±Inf are not considered integers.
func (x *Float) IsInt() bool {
	// pick off easy cases
	if len(x.mant) == 0 {
		return x.exp != infExp // x == 0
	}
	// x != 0
	if x.exp <= 0 {
		return false // 0 < |x| <= 0.5
	}
	// x.exp > 0
	if uint(x.exp) >= x.prec {
		return true // not enough precision for fractional mantissa
	}
	if debugFloat {
		x.validate()
	}
	// x.mant[len(x.mant)-1] != 0
	// determine minimum required precision for x
	minPrec := uint(len(x.mant))*_W - x.mant.trailingZeroBits()
	return uint(x.exp) >= minPrec
}
```
`Float`型の値が整数であるかを判定します。ゼロは整数、`0 < |x| <= 0.5`の範囲の非ゼロは整数ではないと即座に判断されます。`x.exp`が`x.prec`以上の場合、小数部を持つには精度が足りないため整数と見なされます。それ以外の場合、仮数部の末尾のゼロビットを考慮して最小限必要な精度を計算し、`x.exp`がその精度以上であれば整数と判断します。

#### `func (z *Float) Set(x *Float) *Float`

```go
// Set sets z to the (possibly rounded) value of x and returns z.
// If z's precision is 0, it is changed to the precision of x
// before setting z (and rounding will have no effect).
// Rounding is performed according to z's precision and rounding
// mode; and z's accuracy reports the result error relative to the
// exact (not rounded) result.
func (z *Float) Set(x *Float) *Float {
	if z != x {
		if z.prec == 0 { // zの精度が0の場合、xの精度に合わせる
			z.prec = x.prec
		}
		z.acc = Exact
		z.neg = x.neg
		z.exp = x.exp
		z.mant = z.mant.set(x.mant)
		if z.prec < x.prec { // zの精度がxの精度より小さい場合、丸め処理を行う
			z.round(0)
		}
	}
	return z
}
```
`z`に`x`の値を設定します。`z`の精度が0の場合は`x`の精度に設定され、それ以外の場合は`z`の既存の精度が尊重されます。`x`の符号、指数、仮数部がコピーされ、もし`z`の精度が`x`の精度より小さい場合は、丸め処理が適用されます。

#### `func (z *Float) Copy(x *Float) *Float`

```go
// Copy sets z to x, with the same precision and rounding mode as x,
// and returns z.
func (z *Float) Copy(x *Float) *Float {
	if z != x {
		z.acc = Exact
		z.neg = x.neg
		z.exp = x.exp
		z.mant = z.mant.set(x.mant)
		z.prec = x.prec // xの精度をそのままコピー
		z.mode = x.mode // xの丸めモードをそのままコピー
	}
	return z
}
```
`z`に`x`の全てのプロパティ（値、精度、丸めモード）を完全にコピーします。これは、`x`の完全な複製を作成する「真の代入」操作です。

#### `func (x *Float) Cmp(y *Float) int`

```go
// Cmp compares x and y and returns:
//   -1 if x <  y
//    0 if x == y (incl. -0 == 0)
//   +1 if x >  y
//
func (x *Float) Cmp(y *Float) int {
	if debugFloat {
		x.validate()
		y.validate()
	}

	mx := x.mag() // xの「大きさ」を取得
	my := y.mag() // yの「大きさ」を取得

	switch {
	case mx < my: // xの大きさがyより小さい場合
		return -1
	case mx > my: // xの大きさがyより大きい場合
		return +1
	}
	// mx == my (大きさが等しい場合)

	// only if |mx| == 1 we have to compare the mantissae
	switch mx {
	case -1: // 両方とも負の有限数
		return -x.ucmp(y) // 符号なし比較の結果を反転
	case +1: // 両方とも正の有限数
		return +x.ucmp(y) // 符号なし比較の結果をそのまま使用
	}

	return 0 // 両方ともゼロ、または両方とも無限大で同じ符号
}
```
`x`と`y`を比較し、その大小関係を返します。まず、`mag()`ヘルパー関数を使って両者の「大きさ」を比較し、無限大を含む比較を効率的に処理します。大きさが等しい場合（両方とも有限数で同じ符号を持つか、両方ともゼロである場合）にのみ、仮数部を比較する`ucmp`関数が呼び出されます。

#### `func (x *Float) mag() int`

```go
// mag returns:
//
//	-2 if x == -Inf
//	-1 if x < 0
//	 0 if x == -0 or x == +0
//	+1 if x > 0
//	+2 if x == +Inf
//
// mag is a helper function for Cmp.
func (x *Float) mag() int {
	m := 1
	if len(x.mant) == 0 { // 仮数部が空の場合（ゼロまたは無限大）
		m = 0
		if x.exp == infExp { // 無限大の場合
			m = 2
		}
	}
	if x.neg { // 負の数の場合
		m = -m
	}
	return m
}
```
`Cmp`関数で使用されるヘルパー関数で、`Float`値の「大きさ」を整数で返します。これにより、無限大を含む比較が簡潔に記述できるようになります。

テストケースで`Float`値を文字列から簡単に生成するためのユーティリティ関数です。無限大の文字列表現も処理します。

#### `func feq(x, y *Float) bool`

```go
// feq(x, y) is like x.Cmp(y) == 0 but it also considers the sign of 0 (0 != -0).
func feq(x, y *Float) bool {
	return x.Cmp(y) == 0 && x.neg == y.neg
}
```
`x.Cmp(y) == 0`に加えて、ゼロの符号（`+0`と`-0`）も考慮して浮動小数点数が等しいかを判定するヘルパー関数です。

これらの変更により、`math/big.Float`はより機能的で堅牢な任意精度浮動小数点数型となりました。
