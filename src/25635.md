## 変更の背景

Goランタイムは、プログラムの実行中に発生する様々なシグナル（ソフトウェア割り込み）を適切に処理するために、`setsig`関数を通じてシグナルハンドラを設定します。この設定には、Linuxシステムコールである`rt_sigaction`が使用されます。

問題は、特定の環境、特にQemuのようなシステムエミュレータ上でGoプログラムを実行した場合に発生しました。Qemuは、ホストシステム上でゲストシステムをエミュレートする際に、一部のシステムコールの振る舞いを変更したり、完全にサポートしなかったりすることがあります。このコミットの背景にある問題は、Qemuが`SIGRTMAX`（リアルタイムシグナルの最大値）に対して`rt_sigaction`システムコールを処理する際に、エラーを返すことがあったという点です。

Goランタイムは通常、`rt_sigaction`がエラーを返すと、致命的なエラーとして`throw("rt_sigaction failure")`を呼び出し、プログラムをクラッシュさせます。しかし、Qemuの特定の振る舞いにより、`SIGRTMAX`に対する`rt_sigaction`のエラーは、Goプログラムの実行を妨げるべきではない、無視できるエラーであると判断されました。このコミットは、この特定のケースでのクラッシュを防ぎ、GoプログラムがQemu環境でより堅牢に動作するようにするために導入されました。これは、以前に提案された変更が何らかの理由で取り込まれなかったため、再導入されたものです。

## 前提知識の解説

### シグナル (Signals)

LinuxやUnix系OSにおいて、シグナルはプロセスに対して非同期的にイベントを通知するメカニズムです。例えば、Ctrl+Cを押すと`SIGINT`が、不正なメモリアクセスがあると`SIGSEGV`がプロセスに送られます。シグナルには標準シグナルとリアルタイムシグナルがあります。

-   **標準シグナル**: `SIGINT`, `SIGTERM`, `SIGKILL`など、番号が固定されており、信頼性が低い（シグナルが複数回発生しても1回しか通知されない可能性がある）。
-   **リアルタイムシグナル (Real-time Signals)**: `SIGRTMIN`から`SIGRTMAX`までの範囲のシグナル。これらは信頼性が高く、キューイングされるため、複数回発生したシグナルもすべて通知されます。Goランタイムは、スケジューラやガベージコレクタの動作のためにリアルタイムシグナルを内部的に利用することがあります。`SIGRTMAX`は、システムがサポートするリアルタイムシグナルの最大番号を示します。

### `rt_sigaction` システムコール

`sigaction`は、特定のシグナルがプロセスに送信されたときに実行されるアクション（シグナルハンドラ）を設定するためのシステムコールです。`rt_sigaction`は、リアルタイムシグナルをサポートするために拡張されたバージョンです。このシステムコールは、シグナルハンドラの設定、シグナルマスクの変更、シグナル処理フラグの指定などを行います。

`rt_sigaction`の呼び出しが成功すると0を返し、失敗すると-1を返して`errno`にエラーコードを設定します。Goランタイムは、この戻り値をチェックしてシグナルハンドラの設定が成功したかを確認します。

### Qemu

Qemu (Quick EMUlator) は、オープンソースの汎用プロセッサエミュレータおよび仮想化ソフトウェアです。Qemuは、異なるアーキテクチャのCPUをエミュレートしたり、完全なシステム仮想化を提供したり、ユーザーモードエミュレーション（ホストOS上で異なるアーキテクチャのバイナリを実行）を行ったりすることができます。

このコミットの文脈では、Qemuのユーザーモードエミュレーションが関係している可能性が高いです。ユーザーモードエミュレーションでは、Qemuはゲストバイナリのシステムコールをインターセプトし、ホストOSのシステムコールに変換して実行します。この変換プロセスや、Qemuがエミュレートする環境の特性により、特定のシステムコールが期待通りに動作しない、あるいはエラーを返すことがあります。

## 技術的詳細

Goランタイムの`src/runtime/os1_linux.go`ファイルには、Linux環境でのシグナルハンドリングに関するコードが含まれています。`setsig`関数は、特定のシグナル番号`i`に対してシグナルハンドラ`fn`を設定する役割を担っています。

この関数内で、Goランタイムは`rt_sigaction`システムコールを呼び出してシグナルハンドラを設定します。

```go
func setsig(i int32, fn uintptr, restart bool) {
	// ... (シグナルハンドラの設定準備) ...
	sa.sa_handler = fn
	if rt_sigaction(uintptr(i), &sa, nil, unsafe.Sizeof(sa.sa_mask)) != 0 {
		throw("rt_sigaction failure")

変更前のコードでは、`rt_sigaction`が0以外の値を返した場合（つまりエラーが発生した場合）、無条件に`throw("rt_sigaction failure")`を呼び出し、Goプログラムを強制終了させていました。

このコミットは、この特定のシナリオを検出し、`SIGRTMAX`に対する`rt_sigaction`のエラーを特別に無視することで、Goランタイムの堅牢性を高めています。
