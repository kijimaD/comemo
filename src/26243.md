## 変更の背景

Go言語の公式ドキュメントには、Go Playgroundで実行可能な様々なサンプルコードが含まれています。`doc/play/pi.go` は、Goの並行処理機能（ゴルーチンとチャネル）を用いて円周率を計算するデモンストレーションコードです。このコードのコメントには、その背景や詳細を説明する外部記事へのリンク `http://goo.gl/ZuTZM` が含まれていました。

しかし、この参照リンクが時間の経過とともにリンク切れとなり、ユーザーがサンプルコードの意図や技術的な詳細を深く理解するための情報源にアクセスできなくなっていました。この問題はGitHub Issue #13345 として報告され、その解決のために、リンク切れとなったURLをInternet Archive (archive.org) に保存されている同コンテンツのバージョンへの新しい短縮URL `https://goo.gl/la6Kli` に更新する必要が生じました。

## 前提知識の解説

### Go言語の並行処理 (Concurrency in Go)
Go言語は、軽量なスレッドである「ゴルーチン (goroutine)」と、ゴルーチン間の安全な通信を可能にする「チャネル (channel)」というプリミティブを提供することで、並行処理を強力にサポートしています。
*   **ゴルーチン**: `go` キーワードを使って関数呼び出しの前に記述するだけで、その関数を新しいゴルーチンとして実行できます。OSのスレッドよりもはるかに軽量で、数千、数万のゴルーチンを同時に実行することが可能です。
*   **チャネル**: ゴルーチン間で値を送受信するための通信メカニズムです。チャネルは型付けされており、データの送受信は同期的に行われるため、競合状態 (race condition) を防ぎ、安全な並行プログラミングを促進します。

`doc/play/pi.go` のようなサンプルコードは、これらのGoの並行処理の強力な機能を具体的に示すために利用されます。

### Go Playground
Go Playgroundは、Go言語のコードをブラウザ上で記述、実行、共有できるオンラインツールです。Go言語の公式ウェブサイト (go.dev) に統合されており、Go言語の学習や簡単なコードのテストに広く利用されています。`doc/play` ディレクトリ内のファイルは、このGo Playgroundで実行可能なサンプルコードとして提供されています。

### URL短縮サービス (goo.gl)
`goo.gl` は、Googleが提供していたURL短縮サービスです。長いURLを短くすることで、共有しやすくしたり、文字数制限のある環境で利用しやすくしたりする目的で使われていました。しかし、Googleは2018年にこのサービスを終了し、既存の短縮URLも最終的には機能しなくなりました。このコミットが行われた2016年時点ではまだ稼働していましたが、リンク切れは発生しうる状況でした。

### Internet Archive (archive.org)
Internet Archiveは、ウェブサイト、ソフトウェア、音楽、映画、書籍などのデジタルデータを収集・保存している非営利団体です。特に「Wayback Machine」と呼ばれるサービスは、過去のウェブサイトのアーカイブを閲覧することを可能にします。これにより、オリジナルのURLがリンク切れになった場合でも、過去のコンテンツにアクセスできる貴重な手段となります。

## 技術的詳細

このコミットの技術的な変更は非常にシンプルですが、その背景にはウェブコンテンツの永続性という重要な課題が潜んでいます。

`doc/play/pi.go` ファイルは、Go Playgroundで実行されるサンプルコードであり、そのコメントはコードの理解を助けるための補助情報を提供します。元のコメント `// See http://goo.gl/ZuTZM.` は、円周率の並行計算に関する詳細な説明が書かれた外部記事へのリンクでした。

リンク切れが発生した場合、ユーザーはサンプルコードの動作原理や実装の意図を深く探求する機会を失います。これは、特に学習目的でGo Playgroundを利用するユーザーにとって大きな不利益となります。

このコミットでは、リンク切れの問題を解決するために、Internet ArchiveのWayback Machineを利用しました。元の記事がアーカイブされていることを確認し、そのアーカイブされたページへのURLを `goo.gl` で再度短縮し、`https://goo.gl/la6Kli` という新しい短縮URLを生成しました。この新しいURLは、元のコンテンツのアーカイブ版を指すため、リンク切れの問題を回避し、将来的なリンク切れのリスクも低減します（Internet Archive自体が非常に安定したサービスであるため）。

変更自体は、単一のコメント行のURL文字列の置換であり、Goプログラムの実行ロジックや機能には一切影響を与えません。これは、ドキュメントの正確性とユーザー体験の向上を目的とした、保守的な変更です。

## コアとなるコードの解説

変更は `doc/play/pi.go` ファイルのわずか1行に限定されています。

*   `- // See http://goo.gl/ZuTZM.`
    *   これは削除された行で、以前のリンク切れのURL `http://goo.gl/ZuTZM` を含むコメントです。
*   `+ // See https://goo.gl/la6Kli.`
    *   これは追加された行で、新しいURL `https://goo.gl/la6Kli` を含むコメントです。この新しいURLは、Internet Archiveに保存された元のコンテンツを指しています。

この変更により、`pi.go` のサンプルコードを閲覧するユーザーは、コメントに記載されたリンクをクリックすることで、円周率の並行計算に関する詳細な説明記事に引き続きアクセスできるようになりました。コードの機能自体には変更がなく、ドキュメンテーションの正確性と可用性を維持するための修正です。
