# [インデックス 21776] ファイルの概要

このコミットは、Go言語の `math/big` パッケージにおいて、`big.Float` 型の浮動小数点数を10進数表記に正確に変換するためのコア機能の実装を追加します。具体的には、多倍長10進数表現を扱う `decimal` 型とその関連メソッドが導入され、特にバイナリから10進数への正確な変換と丸め処理に特化しています。

## 変更の背景

浮動小数点数の表現は、コンピュータ内部では通常2進数で行われます。しかし、0.1のような単純な10進数も2進数では無限小数となり、正確に表現できないという問題があります。このため、2進数で表現された浮動小数点数を10進数に変換する際に、精度を失わずに正確な表現を得ることは非常に重要です。特に、`math/big` パッケージのような多倍長精度を扱うライブラリでは、この正確性が求められます。

このコミットは、`big.Float` 型の値を文字列として出力する際（例えば `Float.Text()` メソッドを通じて）に、その内部の2進数表現から正確な10進数表現を生成するための基盤を提供します。この `decimal` 型は、一般的な10進数演算のためではなく、あくまで `big.Float` から10進数への変換と丸め処理に特化して設計されています。

Go言語の標準ライブラリには、一般的な用途の多倍長10進数型（例: `math/big.Decimal`）は存在しません。過去にはそのような型の追加が議論されましたが（Go Issue #12127など）、標準ライブラリには採用されませんでした。そのため、金融計算など厳密な10進数演算が必要な場合は、通常 `github.com/shopspring/decimal` のような外部ライブラリが利用されます。このコミットで導入される `decimal` 型は、そのような汎用的な10進数型とは異なり、`big.Float` の内部処理を支えるためのものです。

## 前提知識の解説

*   **`math/big` パッケージ**: Go言語の標準ライブラリの一部で、任意精度（多倍長精度）の整数 (`big.Int`)、有理数 (`big.Rat`)、浮動小数点数 (`big.Float`) を扱うための機能を提供します。通常の `float64` や `int` が表現できる範囲や精度を超える計算が必要な場合に使用されます。
*   **`big.Float`**: `math/big` パッケージで提供される任意精度の浮動小数点数型です。内部的には2進数で値を保持しますが、その精度はユーザーが指定できます。
*   **浮動小数点数の2進数表現と10進数表現の不一致**: 多くのプログラミング言語で使われるIEEE 754浮動小数点数標準は2進数に基づいています。このため、0.1のような10進数の有限小数は、2進数では無限小数となり、コンピュータのメモリに正確に格納できません。結果として、浮動小数点数の計算では丸め誤差が生じることがあります。
*   **正確な2進数から10進数への変換**: 2進数で表現された数を10進数に正確に変換するためには、特別なアルゴリズムが必要です。このコミットのコメントにもある「2が10を割り切る（2 divides 10）」という重要な観察は、2進数の右シフト（除算）が10進数表現で正確に行えることを意味します。例えば、2進数で `x / 2^n` は、10進数で `x * (1/2)^n = x * (5/10)^n = x * 5^n / 10^n` となり、10進数の桁をシフトする操作に変換できます。
*   **仮数部 (Mantissa) と指数部 (Exponent)**: 浮動小数点数は通常、`仮数部 × 基数^指数部` の形式で表現されます。例えば、1.23 × 10^4 の場合、1.23が仮数部、10が基数、4が指数部です。このコミットで導入される `decimal` 型も、`x.mant * 10 ** x.exp` の形式で10進数を表現します。

## 技術的詳細

このコミットで導入される `decimal` 型は、`big.Float` の内部表現（2進数の仮数部と指数部）を、10進数の仮数部と指数部に変換するためのものです。

`decimal` 構造体は以下のフィールドを持ちます。
*   `mant []byte`: 仮数部のASCII数字をビッグエンディアンで格納します。例えば、123.45であれば `[]byte{'1', '2', '3', '4', '5'}` のようになります。
*   `exp int`: 指数部です。`x.mant * 10 ** x.exp` の関係で、`0.5 <= x.mant < 1` となるように正規化されます。

主要なメソッドは以下の通りです。

1.  **`init(m nat, shift int)`**:
    *   `m`: `big.Float` の内部的な2進数仮数部（`nat`型は多倍長自然数）。
    *   `shift`: 2進数でのシフト量。
    *   このメソッドは、`m << shift` または `m >> -shift` の値を10進数表現の `decimal` 型に初期化します。
    *   **最適化**: 右シフトが必要な場合、まず `m` から末尾のゼロビットを除去し、10進数でのシフト量を減らします。これは、10進数でのシフトが2進数よりも遅い可能性があるためです。
    *   **シフト処理の分担**: 左シフト（`shift > 0`）は2進数表現のまま `nat.shl` を使って行われます。これは2進数での左シフトが高速かつ正確であるためです。
    *   **10進数への変換**: `m.decimalString()` を使って2進数の仮数部を10進数の文字列に変換し、それを `x.mant` に格納します。
    *   **10進数での右シフト**: 残りの右シフト（`shift < 0`）は、10進数表現に変換された後、`x.shr` メソッドを使って行われます。`maxShift` 定数（`_W - 4`、`_W` は `Word` のビット数）は、一度に処理できる最大シフト量を定義し、オーバーフローを防ぎます。

2.  **`shr(s uint)`**:
    *   `s`: シフト量（`s <= maxShift`）。
    *   このメソッドは、`x >> s` を10進数表現で実行します。これは「シフト・アンド・サブトラクト（shift-and-subtract）」アルゴリズムを用いて、10進数の仮数部を `2^s` で除算する操作に相当します。
    *   具体的には、仮数部の各桁を読み込み、`2^s` で除算し、結果の桁を書き込みます。余りは次の桁の計算に持ち越されます。
    *   この処理は、2進数の右シフトを10進数の桁操作に変換する複雑なロジックを含んでいます。

3.  **`String()`**:
    *   `decimal` 型の値を人間が読める10進数文字列に変換します。指数部 `x.exp` と仮数部 `x.mant` の長さに基づいて、`0.00ddd`、`dd.ddd`、`ddd00` のいずれかの形式で出力します。

このコミットは、`big.Float` の正確な文字列変換という、浮動小数点数演算において非常に重要な側面を支える基盤技術を導入しています。

## コアとなるコードの変更箇所

`src/math/big/decimal.go` が新規追加されています。

```go
// Copyright 2015 The Go Authors. All rights reserved.
// Use of this source code is governed by a BSD-style
// license that can be found in the LICENSE file.

// This file implements multi-precision decimal numbers.
// The implementation is for float to decimal conversion only;
// not general purpose use.
// The only operations are precise conversion from binary to
// decimal and rounding.
//
// The key observation and some code (shr) is borrowed from
// strconv/decimal.go: conversion of binary fractional values can be done
// precisely in multi-precision decimal because 2 divides 10 (required for
// >> of mantissa); but conversion of decimal floating-point values cannot
// be done precisely in binary representation.
//
// In contrast to strconv/decimal.go, only right shift is implemented in
// decimal format - left shift can be done precisely in binary format.

package big

// A decimal represents a floating-point number in decimal representation.
// The value of a decimal x is x.mant * 10 ** x.exp with 0.5 <= x.mant < 1,
// with the most-significant mantissa digit at index 0.
type decimal struct {
	mant []byte // mantissa ASCII digits, big-endian
	exp  int    // exponent, valid if len(mant) > 0
}

// Maximum shift amount that can be done in one pass without overflow.
// A Word has _W bits and (1<<maxShift - 1)*10 + 9 must fit into Word.
const maxShift = _W - 4

// Init initializes x to the decimal representation of m << shift (for
// shift >= 0), or m >> -shift (for shift < 0).
func (x *decimal) init(m nat, shift int) {
	// special case 0
	if len(m) == 0 {
		x.mant = x.mant[:0]
		return
	}

	// Optimization: If we need to shift right, first remove any trailing
	// zero bits from m to reduce shift amount that needs to be done in
	// decimal format (since that is likely slower).
	if shift < 0 {
		ntz := m.trailingZeroBits()
		s := uint(-shift)
		if s >= ntz {
			s = ntz // shift at most ntz bits
		}
		m = nat(nil).shr(m, s)
		shift += int(s)
	}

	// Do any shift left in binary representation.
	if shift > 0 {
		m = nat(nil).shl(m, uint(shift))
		shift = 0
	}

	// Convert mantissa into decimal representation.
	s := m.decimalString() // TODO(gri) avoid string conversion here
	n := len(s)
	x.exp = n
	// Trim trailing zeros; instead the exponent is tracking
	// the decimal point independent of the number of digits.
	for n > 0 && s[n-1] == 0 {
		n--
	}
	x.mant = make([]byte, n)
	copy(x.mant, s)

	// Do any (remaining) shift right in decimal representation.
	if shift < 0 {
		for shift < -maxShift {
			x.shr(maxShift)
			shift += maxShift
		}
		x.shr(uint(-shift))
	}
}

// shr implements x >> s, for s <= maxShift.
func (x *decimal) shr(s uint) {
	// Division by 1<<s using shift-and-subtract algorithm.

	// pick up enough leading digits to cover first shift
	r := 0 // read index
	var n Word
	for n>>s == 0 && r < len(x.mant) {
		ch := Word(x.mant[r])
		r++
		n = n*10 + ch - '0'
	}
	if n == 0 {
		// x == 0; shouldn't get here, but handle anyway
		x.mant = x.mant[:0]
		return
	}
	for n>>s == 0 {
		r++
		n *= 10
	}
	x.exp += 1 - r

	// read a digit, write a digit
	w := 0 // write index
	for r < len(x.mant) {
		ch := Word(x.mant[r])
		r++
		d := n >> s
		n -= d << s
		x.mant[w] = byte(d + '0')
		w++
		n = n*10 + ch - '0'
	}

	// write extra digits that still fit
	for n > 0 && w < len(x.mant) {
		d := n >> s
		n -= d << s
		x.mant[w] = byte(d + '0')
		w++
		n = n * 10
	}
	x.mant = x.mant[:w] // the number may be shorter (e.g. 1024 >> 10)

	// append additional digits that didn't fit
	for n > 0 {
		d := n >> s
		n -= d << s
		x.mant = append(x.mant, byte(d+'0'))
		n = n * 10
	}

	// remove trailing zeros
	w = len(x.mant)
	for w > 0 && x.mant[w-1] == '0' {
		w--
	}
	x.mant = x.mant[:w]
}

func (x *decimal) String() string {
	if len(x.mant) == 0 {
		return "0"
	}

	var buf []byte
	switch {
	case x.exp <= 0:
		// 0.00ddd
		buf = append(buf, "0."...)
		buf = appendZeros(buf, -x.exp)
		buf = append(buf, x.mant...)

	case /* 0 < */ x.exp < len(x.mant):
		// dd.ddd
		buf = append(buf, x.mant[:x.exp]...)
		buf = append(buf, '.')
		buf = append(buf, x.mant[x.exp:]...)

	default: // len(x.mant) <= x.exp
		// ddd00
		buf = append(buf, x.mant...)
		buf = appendZeros(buf, x.exp-len(x.mant))
	}

	return string(buf)
}

// appendZeros appends n 0 digits to buf and returns buf.
func appendZeros(buf []byte, n int) []byte {
	for ; n > 0; n-- {
		buf = append(buf, '0')
	}
	return buf
}
```

## コアとなるコードの解説

### `decimal` 構造体

```go
type decimal struct {
	mant []byte // mantissa ASCII digits, big-endian
	exp  int    // exponent, valid if len(mant) > 0
}
```
`decimal` 型は、10進数浮動小数点数を表現するための構造体です。
*   `mant`: 仮数部をバイトスライス（ASCII数字）として保持します。例えば、数値 `123` は `[]byte{'1', '2', '3'}` となります。ビッグエンディアン（最上位桁が先頭）で格納されます。
*   `exp`: 指数部です。`x.mant * 10 ** x.exp` の形式で数値を表します。例えば、`mant` が `{'1', '2', '3'}` で `exp` が `3` なら `123 * 10^3 = 123000` を意味します。

このメソッドは、2進数の多倍長自然数 `m` を `shift` 量だけシフトした結果を、`decimal` 型の `x` に初期化します。
*   **右シフトの最適化**: `shift` が負の場合（右シフト）、まず `m` の末尾のゼロビットを数え (`ntz`)、その分だけ2進数で右シフトします。これにより、後続の10進数での右シフト量を減らし、パフォーマンスを向上させます。
*   **2進数での左シフト**: `shift` が正の場合（左シフト）、`nat.shl` を使って2進数表現のまま左シフトを行います。2進数での左シフトは効率的です。
*   **10進数への変換**: シフト処理の後、`m.decimalString()` を呼び出して `m` を10進数の文字列に変換し、それを `x.mant` にコピーします。この際、末尾のゼロはトリムされ、指数部 `x.exp` で桁数を調整します。
*   **10進数での右シフト**: 2進数でのシフトで処理しきれなかった残りの右シフト（`shift < 0`）は、`x.shr` メソッドを使って10進数表現で行われます。`maxShift` を超える大きなシフトは、`maxShift` ずつ複数回に分けて実行されます。

### `shr(s uint)` メソッド

```go

```
このメソッドは、`decimal` 型の `x` を `2^s` で除算する（右に `s` ビットシフトする）処理を10進数表現で行います。これは「シフト・アンド・サブトラクト」アルゴリズムに基づいています。
*   **先行桁の読み込み**: まず、`n >> s` がゼロでなくなるまで、`x.mant` の先行桁を読み込み、`n` に蓄積します。これは、シフト操作に必要なだけの桁数を確保するためです。
*   **桁ごとの処理**: `x.mant` の各桁を順に読み込み、`n` に追加し、`n` を `2^s` で除算した結果の桁 `d` を計算します。この `d` を `x.mant` の書き込み位置に格納し、`n` から `d << s` を減算して余りを更新します。このプロセスを繰り返すことで、10進数での除算を実現します。
*   **残りの桁と末尾のゼロの処理**: 仮数部の残りの桁や、除算によって新たに生成される桁を処理し、最後に末尾のゼロを削除して正規化します。

### `String()` メソッド

```go

		return "0"

```
`decimal` 型の値を、一般的な10進数表記の文字列に変換します。
*   `x.exp` の値に基づいて、小数点以下の桁数、整数部の桁数、または末尾のゼロの数を調整し、適切な形式の文字列を生成します。
    *   `x.exp <= 0`: "0.00ddd" の形式（例: `mant={'1','2','3'}, exp=-2` -> "0.00123"）
    *   `0 < x.exp < len(x.mant)`: "dd.ddd" の形式（例: `mant={'1','2','3','4','5'}, exp=3` -> "123.45"）
    *   `len(x.mant) <= x.exp`: "ddd00" の形式（例: `mant={'1','2','3'}, exp=5` -> "12300"）
