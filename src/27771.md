## 元コミット内容

`cmd/pprof: pass the event to pprof_toggle_asm for the weblist command`

このコミットは、`pprof`の`weblist`コマンドが生成するWebインターフェースにおいて、アセンブリ表示の切り替えを行うJavaScript関数`pprof_toggle_asm`に、クリックイベントオブジェクトを渡すように修正するものです。これにより、イベントハンドラがイベントに関する詳細情報にアクセスできるようになります。

## 変更の背景

この変更は、Issue #15225 に対応するものです。元の実装では、`pprof_toggle_asm()`という形でJavaScript関数が呼び出されており、クリックイベントに関する情報（例えば、どの要素がクリックされたか、マウスの位置など）に直接アクセスすることができませんでした。WebUIのインタラクティブ性を高めたり、より洗練された動作を実装したりするためには、イベントハンドラがイベントオブジェクトにアクセスできることが不可欠です。

具体的には、`weblist`コマンドはプロファイルデータをHTML形式で表示し、ユーザーが関数名などをクリックすることで、その関数の詳細な情報（アセンブリコードなど）を表示・非表示する機能を提供しています。この表示切り替えの際に、イベントオブジェクトを渡すことで、将来的にはクリックされた要素に基づいて異なる動作をさせたり、イベントの伝播を制御したりといった高度なインタラクションを実装する基盤が整えられます。

## 前提知識の解説

### Go言語の`pprof`ツール

`pprof`は、Goプログラムのパフォーマンスプロファイルデータを視覚化・分析するためのツールです。CPU使用率、メモリ割り当て、ゴルーチン、ブロックプロファイルなど、様々な種類のプロファイルデータを収集し、テキスト、グラフィック、Webインターフェースなど多様な形式でレポートを生成できます。

### `pprof weblist`コマンド

`pprof`のサブコマンドの一つである`weblist`は、プロファイルデータをHTML形式のWebページとして出力し、ブラウザでインタラクティブに表示する機能を提供します。このWebページでは、関数ごとのパフォーマンス情報が一覧表示され、特定の関数をクリックすることで、その関数のソースコードやアセンブリコードを詳細に確認できます。

### HTMLの`onClick`イベントハンドラとJavaScriptのイベントオブジェクト

HTML要素には、ユーザーのアクション（クリック、マウスオーバーなど）に応答するためのイベントハンドラ属性があります。`onClick`はその一つで、要素がクリックされたときに実行されるJavaScriptコードを指定します。

JavaScriptのイベントハンドラ関数が呼び出される際、通常はイベントに関する詳細情報を含む`Event`オブジェクトが引数として渡されます。この`Event`オブジェクトには、イベントの種類、ターゲット要素、マウスの位置、キーボードの状態など、様々なプロパティが含まれています。

例えば、`onClick="myFunction()"`と記述した場合、`myFunction`には引数が渡されません。しかし、`onClick="myFunction(event)"`と記述することで、ブラウザは自動的にクリックイベントの`Event`オブジェクトを`myFunction`の引数として渡します。これにより、`myFunction`内で`event.target`（クリックされた要素）や`event.preventDefault()`（デフォルトのイベント動作をキャンセル）などの操作が可能になります。

## 技術的詳細

このコミットの技術的な変更は非常にシンプルですが、その影響は重要です。

変更前:
```html
<pre onClick="pprof_toggle_asm()">
```

変更後:
```html
<pre onClick="pprof_toggle_asm(event)">
```

この変更により、`pprof_toggle_asm`というJavaScript関数が呼び出される際に、ブラウザによって自動的に生成されるクリックイベントオブジェクトが引数として渡されるようになります。

`pprof_toggle_asm`関数は、`pprof weblist`が生成するHTMLレポート内で、アセンブリコードの表示・非表示を切り替える役割を担っていると推測されます。イベントオブジェクトを受け取ることで、この関数は以下のようなことが可能になります。

1.  **イベントターゲットの特定**: `event.target`プロパティを使用して、実際にクリックされたHTML要素を特定できます。これにより、例えば、クリックされた要素の親要素や隣接要素を操作するといった、よりコンテキストに応じた動作を実装できます。
2.  **イベントの伝播制御**: `event.stopPropagation()`メソッドを使用して、イベントがDOMツリーを遡って親要素に伝播するのを防ぐことができます。これは、ネストされた要素にそれぞれイベントハンドラが設定されている場合に、意図しない動作を防ぐために重要です。
3.  **デフォルト動作の抑制**: `event.preventDefault()`メソッドを使用して、リンクのクリックによるページ遷移など、ブラウザのデフォルトのイベント動作を抑制できます。
4.  **将来的な拡張性**: イベントオブジェクトにアクセスできることで、将来的にアセンブリ表示の切り替え機能に、例えばShiftキーを押しながらクリックした場合に別の動作をする、といった修飾キーとの組み合わせによる機能を追加する際の基盤となります。

この修正は、`pprof`のWebUIの堅牢性と拡張性を向上させるための、小さなしかし重要な一歩と言えます。

## コアとなるコードの解説

`src/cmd/internal/pprof/report/source.go`ファイルは、`pprof weblist`コマンドが生成するHTMLレポートのソースコード部分を担当しています。

`printFunctionHeader`関数は、`weblist`レポート内で個々の関数のヘッダー部分（関数名、ファイルパス、プロファイルデータなど）をHTMLとして出力する役割を担っています。この関数内で、`<pre>`タグが生成されており、このタグがクリックされたときに`pprof_toggle_asm`というJavaScript関数が実行されるように設定されています。

変更前は、`onClick="pprof_toggle_asm()"`となっており、`pprof_toggle_asm`関数は引数なしで呼び出されていました。
変更後は、`onClick="pprof_toggle_asm(event)"`となり、HTMLのイベントハンドラが自動的に提供する`event`オブジェクトが明示的に`pprof_toggle_asm`関数に渡されるようになりました。

この変更は、GoのコードがHTML文字列を生成する部分で行われています。Goのコード自体がJavaScriptのロジックを変更しているわけではなく、生成されるHTMLの属性値を変更することで、ブラウザ上でのJavaScript関数の呼び出し方法を修正しています。
