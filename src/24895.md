# [インデックス 24895] ファイルの概要

このコミットは、Go言語の `strconv` パッケージに `QuoteToGraphic` および関連する関数を追加するものです。これにより、文字列を引用符で囲む際に、Unicodeの「グラフィック文字」として扱われる特定のスペース文字（`Zs`カテゴリ）がエスケープされずにそのまま出力されるようになります。これは、従来の `Quote` 関数が `IsPrint` の定義に基づいて非表示文字をエスケープしていたのに対し、より柔軟な引用符付けの要件に対応するための変更です。

## 元コミット内容

`strconv: add QuoteToGraphic and friends`

この引用符付けのバージョンでは、表意文字スペース文字のような `Zs` カテゴリのルーンがエスケープされずにそのまま通過することを許可します。

まだやるべきこと（おそらく）：`Printf` からこれにアクセスする方法。

`#11511` を更新。

## 変更の背景

Go言語の `strconv` パッケージは、文字列と数値の変換、および文字列のリテラル表現の生成（引用符付け）を提供します。既存の `Quote` 関数群は、Goの文字列リテラル規則に従い、制御文字や `IsPrint` 関数で定義される「表示可能でない」文字をエスケープしていました。しかし、特定のユースケースでは、Unicodeの `Zs` (Separator, Space) カテゴリに属する文字（例: ノーブレークスペース `U+00A0`、表意文字スペース `U+3000` など）を、視覚的にはスペースとして機能するにもかかわらず、エスケープせずにそのまま出力したいという要望がありました。

従来の `IsPrint` 関数は、これらのスペース文字を「表示可能でない」と判断し、`\uXXXX` 形式でエスケープしていました。しかし、これらの文字は多くの文脈で「グラフィック文字」（つまり、視覚的に存在する文字）として扱われるべきです。このコミットは、このようなニーズに応えるため、`unicode` パッケージの `IsGraphic` の概念を `strconv` パッケージの引用符付け機能に導入し、より柔軟な文字列の引用符付けメカニズムを提供することを目的としています。

関連するIssue `#11511` は、この問題提起の背景となっています。

## 前提知識の解説

### Go言語の `strconv` パッケージ

`strconv` パッケージは、Goの標準ライブラリの一部で、基本的なデータ型（整数、浮動小数点数、ブール値）と文字列との間の変換機能を提供します。また、文字列をGoのソースコードリテラルとして引用符で囲むための関数（`Quote`, `QuoteToASCII` など）も含まれています。これらの引用符付け関数は、文字列内の特殊文字や非表示文字をエスケープシーケンスに変換し、文字列がGoの構文規則に準拠するようにします。

### Unicodeの文字カテゴリ

Unicodeは、世界中の文字を統一的に扱うための文字コード標準です。各文字には、その性質を示す「カテゴリ」が割り当てられています。このコミットで特に重要なのは以下のカテゴリです。

*   **`Zs` (Separator, Space)**: スペース文字。例えば、通常のスペース `U+0020`、ノーブレークスペース `U+00A0`、表意文字スペース `U+3000` などが含まれます。これらは視覚的には空白ですが、文字としては存在します。
*   **`L` (Letter)**: 文字（アルファベット、漢字など）。
*   **`M` (Mark)**: 結合文字（アクセント記号など）。
*   **`N` (Number)**: 数字。
*   **`P` (Punctuation)**: 句読点。
*   **`S` (Symbol)**: 記号。

### `unicode.IsPrint` と `unicode.IsGraphic`

Go言語の `unicode` パッケージは、Unicode文字に関する情報や操作を提供します。

*   **`unicode.IsPrint(r rune) bool`**: ルーン `r` が「表示可能」であるかどうかを報告します。表示可能とは、`L` (Letter), `M` (Mark), `N` (Number), `P` (Punctuation), `S` (Symbol) のいずれかのカテゴリに属する文字、またはスペース `U+0020` を指します。`Zs` カテゴリの他のスペース文字（例: ノーブレークスペース、表意文字スペース）は `IsPrint` では `false` となります。これは、これらの文字が通常のテキストフローで「空白」として扱われるため、明示的にエスケープされるべきであるという考えに基づいています。

*   **`unicode.IsGraphic(r rune) bool`**: ルーン `r` が「グラフィック文字」であるかどうかを報告します。グラフィック文字とは、`L`, `M`, `N`, `P`, `S` のいずれかのカテゴリに属する文字、および `Zs` (Separator, Space) カテゴリに属する文字を指します。つまり、`IsPrint` が `true` を返す文字に加えて、`Zs` カテゴリのすべてのスペース文字も `IsGraphic` では `true` を返します。これは、これらのスペース文字も視覚的に「存在する」文字として扱われるべきであるという考えに基づいています。

このコミットの核心は、`strconv` の引用符付けにおいて、`IsPrint` の基準ではなく `IsGraphic` の基準を適用する新しいオプションを提供することにあります。

## 技術的詳細

このコミットは、`strconv` パッケージの文字列引用符付けロジックを拡張し、Unicodeの `IsGraphic` の概念を導入します。

1.  **`isGraphic` リストの追加**:
    `src/strconv/isprint.go` に `isGraphic` という `[]uint16` 型の新しいグローバル変数が追加されました。このリストには、`unicode.IsPrint` では `false` となるが `unicode.IsGraphic` では `true` となるルーン（主に `Zs` カテゴリのスペース文字）が格納されます。このリストは、`makeisprint.go` によって生成されます。

2.  **`makeisprint.go` の更新**:
    `src/strconv/makeisprint.go` は、`isprint.go` 内の `isNotPrint` や `isGraphic` といったルーンのリストを生成するためのツールです。このコミットでは、`isGraphic` リストを生成するロジックが追加されました。具体的には、`unicode.IsPrint(r) != unicode.IsGraphic(r)` かつ `unicode.IsGraphic(r)` であるルーンを抽出し、`isGraphic` リストに追加します。これにより、`isGraphic` リストは `IsPrint` では表示可能でないが `IsGraphic` では表示可能であるルーンの集合となります。

3.  **`IsGraphic` 関数の追加**:
    `src/strconv/quote.go` に `IsGraphic(r rune) bool` 関数が追加されました。この関数は、`unicode.IsGraphic` と同じロジックを `strconv` パッケージ内で効率的に実装します。まず `IsPrint(r)` をチェックし、それが `true` であれば `true` を返します。そうでなければ、新しく追加された `isInGraphicList(r)` を呼び出して、`isGraphic` リストにルーンが含まれているかをチェックします。

4.  **`isInGraphicList` 関数の追加**:
    `src/strconv/quote.go` に `isInGraphicList(r rune) bool` 関数が追加されました。これは `isGraphic` リストに対して二分探索を行い、ルーン `r` がリストに含まれているかを効率的に判断します。`IsGraphic` 関数が `IsPrint` のチェック後にこの関数を呼び出すことで、冗長な処理を避けています。

5.  **`quoteWith` 関数の変更**:
    `strconv` パッケージの内部関数である `quoteWith` は、文字列を引用符で囲む主要なロジックを担っています。この関数に `graphicOnly bool` という新しい引数が追加されました。
    *   `graphicOnly` が `true` の場合、引用符付けのロジックは `IsPrint(r)` ではなく `IsPrint(r) || graphicOnly && isInGraphicList(r)` を使用するようになります。これにより、`IsPrint` ではエスケープされる `Zs` カテゴリのスペース文字が、`graphicOnly` が `true` の場合はエスケープされずにそのまま出力されるようになります。

6.  **新しい引用符付け関数の追加**:
    `quoteWith` の変更に伴い、`QuoteToGraphic` および `QuoteRuneToGraphic` 関数が追加されました。
    *   `func QuoteToGraphic(s string) string`: 文字列 `s` を二重引用符で囲み、`IsGraphic` の定義に基づいて非表示文字をエスケープします。
    *   `func AppendQuoteToGraphic(dst []byte, s string) []byte`: `QuoteToGraphic` と同様の処理を行い、結果を既存のバイトスライス `dst` に追加します。
    *   `func QuoteRuneToGraphic(r rune) string`: ルーン `r` を一重引用符で囲み、`IsGraphic` の定義に基づいて非表示文字をエスケープします。
    *   `func AppendQuoteRuneToGraphic(dst []byte, r rune) []byte`: `QuoteRuneToGraphic` と同様の処理を行い、結果を既存のバイトスライス `dst` に追加します。

7.  **既存関数の更新**:
    既存の `Quote`, `QuoteToASCII`, `QuoteRune`, `QuoteRuneToASCII` 関数は、`quoteWith` を呼び出す際に `graphicOnly` 引数に `false` を渡すように変更されました。これにより、これらの関数の既存の動作は維持されます。

8.  **テストの追加と更新**:
    `src/strconv/quote_test.go` に、新しく追加された `IsGraphic` 関数と `QuoteToGraphic` 関数群の動作を検証するためのテストケースが追加されました。特に、`Zs` カテゴリのスペース文字が `QuoteToGraphic` でエスケープされないことを確認するテストが含まれています。

これらの変更により、開発者は文字列を引用符で囲む際に、どの文字をエスケープし、どの文字をそのまま出力するかについて、よりきめ細やかな制御が可能になります。特に、視覚的にはスペースとして機能するが `IsPrint` ではエスケープされる文字を、エスケープせずに扱いたい場合に `QuoteToGraphic` が有用です。

```go
	// The list of graphic but not "printable" runes is short. Just make one easy table.
	fmt.Fprintf(&buf, "// isGraphic lists the graphic runes not matched by IsPrint.\n")
	fmt.Fprintf(&buf, "var isGraphic = []uint16{\n")
	for r := rune(0); r <= unicode.MaxRune; r++ {
		if unicode.IsPrint(r) != unicode.IsGraphic(r) {
			// Sanity check.
			if !unicode.IsGraphic(r) {
				log.Fatalf("%U is printable but not graphic\n", r)
			}
			if r > 0xFFFF { // We expect only 16-bit values.
				log.Fatalf("%U too big for isGraphic\n", r)
			}
			fmt.Fprintf(&buf, "\t%#04x,\n", r)
		}
	}
	fmt.Fprintf(&buf, "}\n")
```

```go
// The returned string uses Go escape sequences (\t, \n, \xFF, \u0100) for
// non-ASCII characters and non-printable characters as defined by IsGraphic.
func QuoteToGraphic(s string) string {

}

// AppendQuoteToGraphic appends a double-quoted Go string literal representing s,
// as generated by QuoteToGraphic, to dst and returns the extended buffer.
func AppendQuoteToGraphic(dst []byte, s string) []byte {

// ... (QuoteRuneToGraphic, AppendQuoteRuneToGraphic も同様に追加)

// IsGraphic reports whether the rune is defined as a Graphic by Unicode. Such
// characters include letters, marks, numbers, punctuation, symbols, and
// spaces, from categories L, M, N, P, S, and Zs.
func IsGraphic(r rune) bool {
	if IsPrint(r) {
		return true
	}
	return isInGraphicList(r)
}

// isInGraphicList reports whether the rune is in the isGraphic list. This separation
// from IsGraphic allows quoteWith to avoid two calls to IsPrint.
// Should be called only if IsPrint fails.
func isInGraphicList(r rune) bool {
	// We know r must fit in 16 bits - see makeisprint.go.
	if r > 0xFFFF {
		return false
	}
	rr := uint16(r)
	i := bsearch16(isGraphic, rr)
	return i < len(isGraphic) && rr == isGraphic[i]
}
```

## コアとなるコードの解説

このコミットの核心は、`strconv` パッケージにおける文字列の引用符付けの挙動を、Unicodeの「表示可能 (Printable)」という概念から「グラフィック (Graphic)」という概念へと拡張した点にあります。

1.  **`isGraphic` リストと `isInGraphicList` 関数**:
    `isGraphic` リストは、`unicode.IsPrint` では `false` となるが `unicode.IsGraphic` では `true` となる特定のルーン（主に `Zs` カテゴリのスペース文字）を効率的に識別するために導入されました。`isInGraphicList` 関数は、このリストに対して高速な二分探索を行い、ルーンがこの特殊なグラフィック文字の集合に含まれるかを判定します。これにより、`IsGraphic` 関数が `IsPrint` のチェック後に、追加のグラフィック文字を効率的に識別できるようになります。

2.  **`IsGraphic` 関数の実装**:
    `strconv.IsGraphic` は、まず `strconv.IsPrint` を呼び出します。これは、`IsPrint` が `true` を返す文字は必ず `IsGraphic` も `true` を返すため、共通のケースを効率的に処理するためです。`IsPrint` が `false` を返した場合にのみ、`isInGraphicList` を呼び出して、`Zs` カテゴリのスペース文字のような、`IsPrint` では非表示だが `IsGraphic` ではグラフィック文字として扱われるルーンであるかを判断します。この二段階のチェックにより、効率性と正確性を両立しています。

3.  **`quoteWith` 関数の `graphicOnly` 引数**:
    `quoteWith` は `strconv` パッケージ内で文字列を引用符で囲む中心的なロジックを持つ関数です。この関数に `graphicOnly` というブール型の引数が追加されたことが、この変更の最も重要な部分です。
    *   `graphicOnly` が `false` の場合（従来の `Quote` や `QuoteToASCII` など）、引用符付けのロジックは `IsPrint(r)` に基づいて文字をエスケープするかどうかを決定します。
    *   `graphicOnly` が `true` の場合（新しい `QuoteToGraphic` など）、ロジックは `IsPrint(r) || graphicOnly && isInGraphicList(r)`、実質的には `IsGraphic(r)` に基づいて文字をエスケープするかどうかを決定します。これにより、`Zs` カテゴリのスペース文字がエスケープされずにそのまま出力されるようになります。

4.  **`QuoteToGraphic` および関連関数の導入**:
    `QuoteToGraphic`、`AppendQuoteToGraphic`、`QuoteRuneToGraphic`、`AppendQuoteRuneToGraphic` は、`quoteWith` 関数を `graphicOnly` に `true` を設定して呼び出すことで、新しい引用符付けの挙動を外部に公開します。これにより、開発者は、従来の `Quote` 関数ではエスケープされていた特定のスペース文字を、エスケープせずに文字列リテラルとして表現できるようになります。

この一連の変更は、Go言語がUnicodeの複雑な文字特性をより細かく、かつ効率的に扱うための進化を示しています。特に、国際化されたアプリケーションや、特定のUnicodeスペース文字の視覚的表現が重要な場面で、この新しい引用符付け機能は有用です。
