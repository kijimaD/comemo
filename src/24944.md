このコミットは、Go言語の `math/big` パッケージにおける `RoundingMode` の使用例を追加するものです。`math/big` パッケージは、任意精度（arbitrary-precision）の数値演算を提供し、特に浮動小数点数 `big.Float` において、様々な丸めモードがどのように動作するかを具体的に示すためのテストコードが追加されました。

## 変更の背景

Go言語の `math/big` パッケージは、標準の `float64` や `float32` では表現できない高精度な浮動小数点数演算を必要とするアプリケーションのために設計されています。このような高精度演算では、数値の丸め処理が結果に大きな影響を与えるため、様々な丸めモードが提供されています。しかし、これらの `RoundingMode` が具体的にどのように動作し、どのような結果をもたらすのかを理解することは、特に浮動小数点演算に不慣れな開発者にとっては難しい場合があります。

このコミットは、おそらくIssue #11241（コミットメッセージに記載されているが、公開されているGoのIssueトラッカーでは直接的な関連が見つからなかったため、内部的な議論や非常に古いIssueである可能性が高い）で指摘された、`RoundingMode` の使用例の不足に対応するために行われました。具体的な例を提供することで、開発者が各丸めモードの挙動を視覚的に確認し、自身のアプリケーションで適切に利用できるようになることが目的です。

## 前提知識の解説

### 任意精度演算 (Arbitrary-Precision Arithmetic)
通常の `float64` や `float32` は、IEEE 754標準に基づいており、固定されたビット数で数値を表現します。これにより、表現できる数値の範囲と精度には限界があります。任意精度演算は、必要に応じてメモリを動的に割り当てることで、事実上無限の精度で数値を表現・計算できる手法です。Goの `math/big` パッケージは、この任意精度演算を `Int` (整数)、`Rat` (有理数)、`Float` (浮動小数点数) の各型で提供します。

### `math/big.Float`
`math/big.Float` は、任意精度の浮動小数点数を表す型です。通常の浮動小数点数と同様に、仮数部と指数部を持ちますが、そのビット幅はユーザーが設定できます。これにより、非常に大きな数や非常に小さな数を高い精度で扱うことが可能になります。

### 丸めモード (RoundingMode)
浮動小数点数演算では、計算結果が表現可能な精度を超えた場合、その結果を最も近い表現可能な値に「丸める」必要があります。この丸め方にはいくつかの規則があり、これらを丸めモードと呼びます。`math/big` パッケージでは、以下の主要な丸めモードが提供されています。

*   **`ToNearestEven` (最近接偶数への丸め)**: 最も近い表現可能な値に丸めます。もし2つの表現可能な値が等距離にある場合（例: 2.5を整数に丸める場合、2と3が等距離）、偶数の方に丸めます。これはIEEE 754標準で推奨されるデフォルトの丸めモードであり、統計的なバイアスが少ないとされています。
*   **`ToNearestAway` (最近接ゼロから遠い方への丸め)**: 最も近い表現可能な値に丸めます。もし2つの表現可能な値が等距離にある場合、ゼロから遠い方（絶対値が大きい方）に丸めます。例: 2.5は3に、-2.5は-3に丸められます。
*   **`ToZero` (ゼロへの丸め、切り捨て)**: ゼロに近い方へ丸めます。正の数は切り捨てられ、負の数は切り上げられます。例: 2.6は2に、-2.6は-2に丸められます。
*   **`AwayFromZero` (ゼロから遠い方への丸め、切り上げ)**: ゼロから遠い方へ丸めます。正の数は切り上げられ、負の数は切り捨てられます。例: 2.1は3に、-2.1は-3に丸められます。
*   **`ToNegativeInf` (負の無限大への丸め、切り下げ)**: 常に負の無限大方向へ丸めます。例: 2.6は2に、-2.1は-3に丸められます。
*   **`ToPositiveInf` (正の無限大への丸め、切り上げ)**: 常に正の無限大方向へ丸めます。例: 2.1は3に、-2.6は-2に丸められます。

これらの丸めモードは、金融計算、科学技術計算、統計処理など、特定の丸め規則が厳密に要求される場面で非常に重要となります。

## 技術的詳細

このコミットで追加された `ExampleRoundingMode` 関数は、`math/big` パッケージの `big.Float` 型と `RoundingMode` 列挙型を組み合わせて、様々な浮動小数点数が異なる丸めモードでどのように処理されるかを実演します。

例では、`operands` という `float64` のスライスに、正負の様々な小数値（2.6, 2.5, 2.1, -2.1, -2.5, -2.6）が用意されています。これらの値は、丸めモードの違いが明確に現れるように選ばれています。

各オペランドに対して、`big.ToNearestEven` から `big.ToPositiveInf` までの全ての `RoundingMode` をループで適用します。
重要なのは、`new(big.Float).SetPrec(2)` の部分です。`SetPrec(2)` は、`big.Float` の精度を2ビットに設定することを意味します。`big.Float` の精度は、仮数部のビット数を指定します。この例では、整数値への丸めを実演するために、意図的に低い精度（2ビット）を設定しています。これにより、`big.Float` は実質的に整数部分のみを保持しようとし、小数部分が丸めの対象となります。

`SetMode(mode)` で現在のループの丸めモードを設定し、`SetFloat64(f64)` で `float64` の値を `big.Float` に変換して丸め処理を実行します。
結果は `fmt.Printf` を使って整形され、各オペランドが各丸めモードでどのように丸められるかが表形式で出力されます。これにより、各丸めモードの挙動の違いが一目でわかるようになっています。

出力されるコメントブロックは、この例を実行した際の期待される結果を示しており、テストフレームワークがこの例の出力を検証するために使用されます。

## コアとなるコードの解説

追加された `ExampleRoundingMode` 関数は、`go test` コマンドで実行されるテストスイートの一部として認識され、その出力がコメントブロック `// Output:` と比較されます。これにより、`RoundingMode` の動作が期待通りであることを保証しつつ、同時にその使用方法と結果をドキュメントとして提供します。

1.  **`operands` の定義**:
    `operands := []float64{2.6, 2.5, 2.1, -2.1, -2.5, -2.6}`
    丸めモードの違いを明確にするために、境界値や中間値を含む様々な浮動小数点数が用意されています。

2.  **ヘッダーの出力**:
    `fmt.Printf("x   ")`
    `for mode := big.ToNearestEven; mode <= big.ToPositiveInf; mode++ { fmt.Printf(" %s", mode) }`
    `fmt.Println()`
    出力される表のヘッダー行を生成します。最初の列は元の数値 `x`、その後に各 `RoundingMode` の名前が続きます。`mode.String()` は `RoundingMode` の列挙値を文字列に変換します（例: "ToNearestEven"）。

3.  **各オペランドとモードでの丸め処理**:
    `for _, f64 := range operands { ... }`
    `fmt.Printf("%4g", f64)`
    `for mode := big.ToNearestEven; mode <= big.ToPositiveInf; mode++ { ... }`
    外側のループは各オペランド `f64` を処理し、内側のループは各 `RoundingMode` を適用します。

    `f := new(big.Float).SetPrec(2).SetMode(mode).SetFloat64(f64)`
    -   `new(big.Float)`: 新しい `big.Float` オブジェクトを初期化します。
    -   `SetPrec(2)`: 精度を2ビットに設定します。これは、`big.Float` が数値を表現する際に使用する仮数部のビット数です。この例では、整数への丸めをシミュレートするために意図的に低い精度を設定しています。例えば、`2.5` を2ビット精度で表現しようとすると、丸めが必要になります。
    -   `SetMode(mode)`: 現在のループで指定された丸めモードを設定します。
    -   `SetFloat64(f64)`: `float64` の値を `big.Float` に変換し、設定された精度と丸めモードに従って丸め処理を行います。

    `format := fmt.Sprintf(" %%%dg", len(mode.String()))`
    `fmt.Printf(format, f)`
    各丸め結果 `f` を、対応する丸めモード名の長さに合わせて整形して出力します。これにより、表形式の出力が整列されます。

4.  **期待される出力 (Outputコメント)**:
    `// Output:` で始まるコメントブロックは、この例を実行した際に標準出力に表示されるべき内容を定義しています。Goのテストフレームワークは、このコメントブロックと実際のプログラム出力を比較し、一致しない場合はテスト失敗とします。これにより、例が常に正しい結果を示すことが保証されます。

このコードは、`math/big.Float` の柔軟性と `RoundingMode` の多様な挙動を、簡潔かつ効果的に示す優れた例となっています。
