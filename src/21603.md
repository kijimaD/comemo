# [インデックス 21603] ファイルの概要

このコミットは、Go言語のビルドシステムにおいて、ホストOSとホストアーキテクチャ（`GOHOSTOS`および`GOHOSTARCH`）の情報をC言語プログラムから利用できるようにするための変更です。これにより、C言語で書かれたGoの内部ツールが、実行環境のGoツールパスを正確に特定できるようになります。

## 元コミット内容

`[dev.cc] cmd/dist, lib9: make GOHOSTARCH, GOHOSTOS available to C programs`

このコミットは、Goの内部ツールである`cmd/dist`と`lib9`において、C言語プログラムから`GOHOSTARCH`（ホストアーキテクチャ）と`GOHOSTOS`（ホストOS）の環境変数にアクセスできるようにするものです。これは、Cコード内でGoのサブプロセスを呼び出す際に、Goツールが配置されているパス（`$GOROOT/pkg/tool/$GOHOSTARCH_$GOHOSTOS`）を正確に特定するために必要とされます。

## 変更の背景

Go言語のビルドシステムは、Go自身をビルドするためにC言語で書かれた一部のツール（特に初期のブートストラッププロセス）に依存しています。これらのC言語ツールが、Goのコンパイラやリンカなどの他のGoツールを呼び出す必要がある場合、それらのツールの正確なパスを知る必要があります。

Goのツールは、`$GOROOT/pkg/tool/$GOHOSTARCH_$GOHOSTOS`というパスに配置されます。ここで`$GOHOSTARCH`と`$GOHOSTOS`は、Goツールチェインが実行されているホストシステムのアーキテクチャとOSを示します。

このコミット以前は、C言語で書かれた内部ツールがこれらのホスト情報を直接取得する標準的な方法がありませんでした。そのため、CコードからGoサブプロセスを正確に呼び出すことが困難でした。この変更は、Cコードがこれらのホスト情報を取得できるようにすることで、Goツールチェインの内部的な連携を強化し、ビルドプロセスの堅牢性を向上させることを目的としています。

## 前提知識の解説

*   **`cmd/dist`**:
    `cmd/dist`は、Go言語のディストリビューションをビルド、テスト、およびブートストラップするための内部コマンドラインユーティリティです。これはGoプロジェクトの開発およびリリースサイクルにおいて非常に重要な役割を果たしますが、一般的なGo開発者が自身のアプリケーションをビルドするために直接使用するものではありません。`go tool dist`コマンドを通じて、ブートストラップ、クリーン、環境設定、インストール、テストなどの特定の操作を実行するために利用されます。

*   **`lib9`**:
    `lib9`は、Goプロジェクトの内部で利用されるユーティリティ関数のコレクションを指すことが多いです。Go言語は、Bell LabsのPlan 9オペレーティングシステムにルーツを持つ開発者によって設計されたため、Plan 9由来の概念やツールとの歴史的なつながりがあります。`lib9`は、Goのランタイムやツールチェインの低レベルな部分で、ファイル操作やシステムインタラクションなど、特定のプラットフォームに依存する処理や共通のユーティリティ機能を提供するために使用されていると考えられます。

*   **`GOHOSTARCH` と `GOHOSTOS`**:
    これらはGoの環境変数であり、Goツールチェインが実行されている**ホスト**システムのアーキテクチャとオペレーティングシステムをそれぞれ定義します。
    *   `GOHOSTOS`: Goツールチェインが動作しているOS（例: `linux`, `windows`, `darwin`）。
    *   `GOHOSTARCH`: Goツールチェインが動作しているCPUアーキテクチャ（例: `amd64`, `arm`, `386`）。
    これらは、Goプログラムがコンパイルされる**ターゲット**システムを示す`GOOS`および`GOARCH`とは異なります。通常、`GOHOSTOS`と`GOHOSTARCH`は自動的に検出され設定されるため、ユーザーが手動で変更する必要はほとんどありません。クロスコンパイルを行う際には、`GOOS`と`GOARCH`を設定しますが、`GOHOSTOS`と`GOHOSTARCH`は変更しません。

*   **Goツールチェインの構造**:
    Goのコンパイラ（`go tool compile`）、リンカ（`go tool link`）、アセンブラ（`go tool asm`）などの主要なツールは、Goのインストールディレクトリ（`$GOROOT`）内の特定のパスに配置されます。具体的には、`$GOROOT/pkg/tool/$GOHOSTARCH_$GOHOSTOS`というディレクトリに、ホストシステムに特化したバイナリが格納されています。例えば、Linux AMD64システムでは`$GOROOT/pkg/tool/linux_amd64`となります。

## 技術的詳細

このコミットの技術的な核心は、Goのビルドプロセスにおいて、C言語コンパイラに`GOHOSTOS`と`GOHOSTARCH`の値をCプリプロセッサマクロとして渡す点と、それらのマクロ値をC言語関数を通じて取得できるようにする点にあります。

1.  **`cmd/dist`によるマクロ定義**:
    `src/cmd/dist/build.go`の変更により、`cmd/dist`がC言語のソースコードをコンパイルする際に、`GOHOSTOS`と`GOHOSTARCH`の現在の値を`-D`オプションを使ってCプリプロセッサマクロとして定義するようになりました。例えば、`GOHOSTOS`が`linux`であれば、コンパイルコマンドに`-DGOHOSTOS="linux"`のような引数が追加されます。これにより、Cソースコード内で`GOHOSTOS`というマクロが定義され、その値が文字列リテラルとして利用可能になります。

2.  **`lib9`でのC関数による公開**:
    `src/lib9/goos.c`には、GoのOS関連の情報を取得するためのC言語関数群が含まれています。このコミットでは、新たに`getgohostos()`と`getgohostarch()`という2つのC関数が追加されました。これらの関数は、`cmd/dist`によって定義された`GOHOSTOS`および`GOHOSTARCH`マクロの値を単に返します。

3.  **ヘッダファイルでの宣言**:
    `include/libc.h`は、Goの内部Cコードで広く利用される共通のヘッダファイルです。このファイルに`getgohostos()`と`getgohostarch()`の関数プロトタイプが追加されたことで、Goの他のC言語ソースファイルからこれらの関数を呼び出して、ホストOSとホストアーキテクチャの情報を取得できるようになりました。

この一連の変更により、C言語で書かれたGoの内部ツールは、実行時に`getgohostos()`や`getgohostarch()`を呼び出すことで、自身の実行環境のOSとアーキテクチャをプログラム的に知ることができ、それに基づいてGoツールチェインのパスを動的に構築することが可能になります。

## コアとなるコードの解説

### `include/libc.h` の変更

```c
 extern	char*\tgetgohostos(void);\n+extern	char*\tgetgohostarch(void);\n
```
この変更は、`getgohostos`と`getgohostarch`という2つの新しいC言語関数のプロトタイプ宣言を`libc.h`に追加しています。これにより、Goの内部Cコードの他の部分がこれらの関数を呼び出して、ホストOSとホストアーキテクチャの情報を取得できるようになります。これは、C言語における関数の前方宣言であり、コンパイラに対してこれらの関数が存在し、どのように呼び出されるかを伝えます。

### `src/cmd/dist/build.go` の変更

```go
+\t\t\t\t\t\"-D\", fmt.Sprintf(\"GOHOSTOS=%q\", gohostos),\n+\t\t\t\t\t\"-D\", fmt.Sprintf(\"GOHOSTARCH=%q\", gohostarch),\n```
`cmd/dist`のビルドスクリプトである`build.go`に、Cコンパイラに渡す引数を追加する変更が加えられています。具体的には、`fmt.Sprintf`を使用して`GOHOSTOS`と`GOHOSTARCH`の値をCプリプロセッサの`-D`オプションとして追加しています。
例えば、`gohostos`変数が`"linux"`であれば、`-DGOHOSTOS="linux"`という引数がCコンパイラに渡されます。これにより、Cソースコード内で`GOHOSTOS`というマクロが定義され、その値が文字列リテラルとして利用可能になります。これは、GoのビルドプロセスがCコードにホスト環境の情報を「注入」するメカニズムです。

### `src/lib9/goos.c` の変更

```c
+char*\n+getgohostarch(void)\n+{\n+\treturn GOHOSTARCH;\n+}\n+\n+char*\n+getgohostos(void)\n+{\n+\treturn GOHOSTOS;\n+}\n```
この変更は、`src/lib9/goos.c`ファイルに`getgohostarch()`と`getgohostos()`という2つの新しいC言語関数を実装しています。これらの関数は、それぞれ`GOHOSTARCH`と`GOHOSTOS`というマクロの値を返します。
これらのマクロは、前述の`src/cmd/dist/build.go`によってCコンパイラに`-D`オプションで渡され、コンパイル時に定義されます。したがって、これらの関数は、Goのビルドプロセスによって設定されたホストOSとホストアーキテクチャの情報を、C言語プログラムが実行時に取得するためのシンプルなインターフェースを提供します。
