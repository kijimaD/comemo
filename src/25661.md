## 変更の背景

このコミットの背景には、Go言語がサポートするハードウェアアーキテクチャの範囲を拡大するというGo開発チームの継続的な取り組みがあります。特に、MIPS 64-bitアーキテクチャ（`mips64`および`mips64le`）は、組み込みシステム、ネットワーク機器、スーパーコンピューティングなど、特定の分野で広く利用されています。Go 1.6のリリースに向けて、これらのアーキテクチャに対する公式サポートが追加されたため、その事実をユーザーに伝えるために公式ドキュメントを更新する必要がありました。

Go言語は、その強力なクロスコンパイル機能により、様々なプラットフォームで動作するバイナリを生成できることが大きな特徴です。新しいアーキテクチャのサポートは、Goの適用範囲を広げ、より多様な環境での開発を可能にします。このドキュメント更新は、Go 1.6でMIPS 64-bitが正式にサポートされることをユーザーに周知し、これらのプラットフォームでGoを使用するための情報を提供するためのものです。

## 前提知識の解説

### Go言語のクロスコンパイルと環境変数 `GOOS` および `GOARCH`

Go言語は、異なるオペレーティングシステム（OS）やCPUアーキテクチャ向けにプログラムをコンパイルする「クロスコンパイル」機能を強力にサポートしています。これは、開発者が自身の開発環境とは異なるターゲット環境で動作するバイナリを簡単に生成できることを意味します。

*   **`GOOS`**: ターゲットとなるオペレーティングシステムを指定する環境変数です。例えば、`linux`、`windows`、`darwin`（macOS）などがあります。
*   **`GOARCH`**: ターゲットとなるCPUアーキテクチャを指定する環境変数です。例えば、`amd64`（64-bit x86）、`386`（32-bit x86）、`arm`（32-bit ARM）、`arm64`（64-bit ARM）などがあります。

開発者は、`GOOS`と`GOARCH`を適切に設定してから`go build`コマンドを実行することで、目的のプラットフォーム向けにバイナリを生成できます。このコミットは、`GOARCH`の選択肢に`mips64`と`mips64le`を追加するものです。

### MIPSアーキテクチャ

MIPS（Microprocessor without Interlocked Pipeline Stages）は、RISC（Reduced Instruction Set Computer）アーキテクチャの一種で、主に組み込みシステム、ルーター、セットトップボックス、ゲーム機などで広く使用されてきました。

*   **MIPS 64-bit**: 64ビットのレジスタとデータパスを持つMIPSプロセッサです。より大きなメモリ空間を扱え、高性能な処理が可能です。
*   **ビッグエンディアン（Big-endian）とリトルエンディアン（Little-endian）**: これらは、マルチバイトデータをメモリに格納する際のバイト順序を指します。
    *   **ビッグエンディアン**: データの最上位バイト（最も significant なバイト）が最も小さいアドレスに格納されます。人間が数字を読む順序に似ています。
    *   **リトルエンディアン**: データの最下位バイト（最も significant でないバイト）が最も小さいアドレスに格納されます。
    *   `mips64`は通常ビッグエンディアンを指し、`mips64le`はリトルエンディアンを指します。同じMIPSアーキテクチャでも、エンディアンの違いによりバイナリの互換性がなくなるため、Goではこれらを区別してサポートします。

### Go 1.6のリリースサイクルと新機能追加

Go言語は、約半年ごとにメジャーバージョンをリリースするサイクルを持っています。Go 1.6は2016年2月にリリースされました。このようなメジャーリリースでは、言語の新機能、標準ライブラリの改善、パフォーマンスの向上、そして新しいプラットフォームのサポートなどが含まれます。このコミットは、Go 1.6でMIPS 64-bitアーキテクチャがサポートされることになったことを反映したドキュメントの更新です。

### ブートストラップ

Goコンパイラ自体はGo言語で書かれています。新しいアーキテクチャをGoでサポートする場合、そのアーキテクチャ上で動作するGoコンパイラを最初に構築する必要があります。このプロセスを「ブートストラップ」と呼びます。通常、既存のGoコンパイラ（例えばGo 1.4）を使って新しいGoコンパイラ（例えばGo 1.5）をコンパイルし、その新しいコンパイラを使ってさらに新しいGoコンパイラ（例えばGo 1.6）をコンパイルするという手順を踏みます。

`doc/install-source.html`の変更箇所には、`bootstrap.bash`スクリプトや`gccgo 5`を使ったブートストラップに関する言及があり、これはGo 1.5がサポートしていないシステム（例: `linux/ppc64`や`linux/mips64le`）でGo 1.5をインストールする際の代替手段を示しています。これは、新しいアーキテクチャのサポートが段階的に導入される過程で必要となる手順です。

## 技術的詳細

このコミットは、Goの公式インストールガイドである`doc/install-source.html`を更新し、Go 1.6で導入されるMIPS 64-bitアーキテクチャのサポートを反映しています。具体的には、以下の点が技術的な詳細として挙げられます。

1.  **新しい`GOARCH`値の追加**: `mips64`（64-bit MIPSビッグエンディアン）と`mips64le`（64-bit MIPSリトルエンディアン）が、Goがサポートする`GOARCH`のリストに正式に追加されました。これにより、開発者はこれらの値を`GOARCH`環境変数に設定することで、MIPS 64-bitシステム向けのGoバイナリをクロスコンパイルできるようになります。
2.  **Linuxバイナリのサポート**: ドキュメントには、`mips64`と`mips64le`がLinuxバイナリをサポートすることが明記されています。これは、GoがこれらのMIPS 64-bitプロセッサ上で動作するLinuxディストリビューションをターゲットとしていることを示します。
3.  **Go 1.6での新規サポート**: `New in 1.6`という記述は、これらのアーキテクチャのサポートがGo 1.6で初めて導入されたことを明確に示しています。また、`not as well excercised as other ports`という注意書きは、他の成熟したポート（例: `amd64`）と比較して、これらの新しいポートはまだテストや実運用での実績が少ない可能性があることを示唆しています。これは、新しいプラットフォームサポートの初期段階では一般的な注意喚起です。
4.  **ブートストラップに関する記述の更新**: Go 1.5がサポートしていないシステム（`linux/ppc64`など）でGo 1.5をインストールする際のブートストラップに関する説明に、新たに`linux/mips64le`が追加されました。これは、Go 1.5の時点では`mips64le`が直接サポートされていなかったため、Go 1.5をこれらのシステムに導入するには特別なブートストラップ手順が必要であったことを示しています。Go 1.6で正式サポートされることで、この状況は改善されます。
5.  **`$GOOS`と`$GOARCH`の有効な組み合わせの更新**: ドキュメントの後半にある、`$GOOS`と`$GOARCH`の有効な組み合わせを示すテーブルに、`linux/mips64`と`linux/mips64le`のエントリが追加されました。これにより、ユーザーはこれらの組み合わせが公式にサポートされていることを一目で確認できます。

これらの変更は、Go言語がより広範なハードウェアプラットフォームに対応し、そのエコシステムを拡大していく上で重要な一歩となります。

## コアとなるコードの解説

このコミットによる`doc/install-source.html`への変更は、Go言語のMIPS 64-bitアーキテクチャサポートに関する情報をユーザーに提供するためのものです。

1.  **新しいアーキテクチャの説明の追加**:
    ```html
    <dt>
    	<code>mips64, mips64le</code> (64-bit MIPS big- and little-endian)
    </dt>
    <dd>
    	Supports Linux binaries. New in 1.6 and not as well excercised as other ports.
    </dd>
    ```
    このセクションは、Goがサポートするアーキテクチャのリストに`mips64`と`mips64le`を追加しています。`dt`（definition term）タグでアーキテクチャ名とその説明（64-bit MIPS big- and little-endian）を提供し、`dd`（definition description）タグでその詳細を記述しています。特に、「Supports Linux binaries. New in 1.6 and not as well excercised as other ports.」という記述は、これらのアーキテクチャがGo 1.6で新しくLinuxバイナリをサポートすること、そして他のより成熟したポートと比較してまだ利用実績が少ない可能性があることを明確に伝えています。

2.  **Go 1.5のブートストラップに関する記述の更新**:
    ```diff
    -as <code>linux/ppc64</code>) you can either use
    +as <code>linux/ppc64</code> and <code>linux/mips64le</code>) you can either use
    ```
    Go 1.5を、Go 1.4ではサポートされていないシステム（例: `linux/ppc64`）にインストールする際のブートストラップ手順に関する説明文に、新たに`linux/mips64le`が追加されました。これは、Go 1.5の時点では`mips64le`が直接サポートされていなかったため、Go 1.5をこれらのシステムに導入するには特別なブートストラップ手順が必要であったことを示唆しています。Go 1.6で正式サポートされることで、この状況は改善されますが、Go 1.5のインストールに関する過去の文脈を正確に保つための変更です。

3.  **`$GOARCH`の選択肢リストの更新**:
    ```diff
    -<code>ppc64le</code> (PowerPC 64-bit, little-endian), and <code>ppc64</code> (PowerPC 64-bit, big-endian).\n
    +<code>ppc64le</code> (PowerPC 64-bit, little-endian), <code>ppc64</code> (PowerPC 64-bit, big-endian),\n
    +<code>mips64le</code> (MIPS 64-bit, little-endian), and <code>mips64</code> (MIPS 64-bit, big-endian).\n
    ```
    `$GOARCH`環境変数に設定できる値のリストに、`mips64le`と`mips64`が追加されました。これにより、ユーザーはGoがこれらのMIPS 64-bitアーキテクチャをターゲットとして認識し、コンパイルできることを確認できます。

4.  **`$GOOS`と`$GOARCH`の有効な組み合わせテーブルの更新**:
    ```html
    <tr>
    <td></td><td><code>linux</code></td> <td><code>mips64</code></td>
    </tr>
    <tr>
    <td></td><td><code>linux</code></td> <td><code>mips64le</code></td>
    </tr>
    ```
    サポートされる`$GOOS`と`$GOARCH`の有効な組み合わせを示すHTMLテーブルに、`linux/mips64`と`linux/mips64le`の行が追加されました。これは、GoがLinuxオペレーティングシステム上でMIPS 64-bitアーキテクチャを公式にサポートしていることを明確に示し、ユーザーがこれらの組み合わせでGoアプリケーションを開発・デプロイできることを保証します。

これらの変更は、Go言語のプラットフォームサポートの拡大を公式に文書化し、開発者が新しいターゲットアーキテクチャでGoを利用する際の障壁を低減することを目的としています。
