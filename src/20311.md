# [インデックス 20311] ファイルの概要

このコミットは、Go言語の標準ライブラリである `net/http` パッケージに、HTTP Basic認証の資格情報（ユーザー名とパスワード）をリクエストから抽出するための `BasicAuth` メソッドを `*http.Request` 型に追加するものです。これにより、サーバーサイドで受信したリクエストのBasic認証ヘッダーを簡単に解析できるようになります。

`net/http`: `*http.Request` に `BasicAuth` メソッドを追加

`net/http` パッケージは、RFC 2617 で定義されている Basic認証スキームを使用して HTTP Authorization ヘッダーを設定する機能はサポートしていますが、Basic認証スキームを使用する認証済みリクエストからユーザー名とパスワードを抽出する機能は提供していませんでした。

Basic認証スキームを使用する認証済みリクエストからユーザー名とパスワードを返す `BasicAuth` メソッドを `*http.Request` に追加します。

## 変更の背景

Goの `net/http` パッケージは、クライアント側でHTTPリクエストにBasic認証ヘッダーを付与するための `SetBasicAuth` メソッドを既に提供していました。しかし、サーバー側で受信したリクエストの `Authorization` ヘッダーからBasic認証の資格情報（ユーザー名とパスワード）を安全かつ簡単に抽出する標準的なメカニズムが欠けていました。

この機能の欠如は、Basic認証を必要とするAPIエンドポイントやWebサービスをGoで実装する際に、開発者が手動で `Authorization` ヘッダーを解析し、Base64デコードを行い、さらにユーザー名とパスワードを区切る処理を記述する必要があることを意味していました。これは冗長であり、エラーの温床となる可能性がありました。

このコミットは、このギャップを埋め、サーバーサイドでのBasic認証の処理を簡素化し、より堅牢にするために `BasicAuth` メソッドを導入しました。これにより、開発者は認証ロジックの実装に集中でき、ヘッダー解析の詳細に煩わされることがなくなります。

## 前提知識の解説

### HTTP Basic認証 (RFC 2617)

HTTP Basic認証は、HTTPプロトコルにおける最も基本的な認証スキームの一つです。RFC 2617「HTTP Authentication: Basic and Digest Access Authentication」で定義されています。

1.  **動作原理**:
    *   クライアントが保護されたリソースにアクセスしようとすると、サーバーは `WWW-Authenticate` ヘッダー（例: `WWW-Authenticate: Basic realm="Restricted Area"`）を含む `401 Unauthorized` ステータスコードを返します。
    *   クライアントは、ユーザー名とパスワードをコロン（`:`）で結合し、その文字列をBase64エンコードします（例: `username:password` -> `dXNlcm5hbWU6cGFzc3dvcmQ=`）。
    *   エンコードされた文字列の前に "Basic " というプレフィックスを付けて、`Authorization` ヘッダーに含めてリクエストを再送信します（例: `Authorization: Basic dXNlcm5hbWU6cGFzc3dvcmQ=`）。
    *   サーバーは受信した `Authorization` ヘッダーを解析し、Base64デコードしてユーザー名とパスワードを抽出し、それらを検証します。

2.  **セキュリティ上の注意点**:
    *   Basic認証は、資格情報をBase64エンコードするだけであり、暗号化は行いません。Base64はエンコードであり、暗号化ではないため、簡単にデコードされてしまいます。
    *   そのため、Basic認証は必ずHTTPS（SSL/TLS）と組み合わせて使用する必要があります。HTTPSを使用しない場合、ネットワーク上の盗聴者によってユーザー名とパスワードが平文で傍受される危険性があります。

### `net/http` パッケージ

`net/http` はGo言語の標準ライブラリであり、HTTPクライアントとサーバーの実装を提供します。WebアプリケーションやAPIサーバーを構築する上で中心的な役割を果たします。

*   `http.Request`: 受信したHTTPリクエストまたは送信するHTTPリクエストを表す構造体です。リクエストメソッド、URL、ヘッダー、ボディなどの情報を含みます。
*   `http.Response`: 受信したHTTPレスポンスまたは送信するHTTPレスポンスを表す構造体です。ステータスコード、ヘッダー、ボディなどの情報を含みます。
*   `http.Handler`: HTTPリクエストを処理するためのインターフェースです。`ServeHTTP(ResponseWriter, *Request)` メソッドを実装することで、カスタムのHTTPハンドラを作成できます。

## 技術的詳細

このコミットは、`*http.Request` 型に `BasicAuth()` メソッドを追加し、その内部で利用されるヘルパー関数 `parseBasicAuth()` を導入しています。

### `BasicAuth()` メソッドのロジック

1.  `r.Header.Get("Authorization")` を呼び出して、リクエストの `Authorization` ヘッダーの値を取得します。
2.  `Authorization` ヘッダーが空文字列 (`""`) の場合、Basic認証情報が存在しないため、空のユーザー名、パスワード、および `ok=false` を返します。
3.  `Authorization` ヘッダーが存在する場合、取得した値を `parseBasicAuth()` ヘルパー関数に渡します。
4.  `parseBasicAuth()` から返されたユーザー名、パスワード、および `ok` の値をそのまま返します。

### `parseBasicAuth()` ヘルパー関数のロジック

この関数は、`Authorization` ヘッダーの文字列を受け取り、Basic認証の仕様に従ってユーザー名とパスワードを抽出します。

1.  **プレフィックスの確認**:
    *   入力された `auth` 文字列が `"Basic "` で始まっているかを確認します。Basic認証ヘッダーは必ずこのプレフィックスで始まります。
    *   もし始まっていない場合、有効なBasic認証ヘッダーではないため、空のユーザー名、パスワード、および `ok=false` を返します。
2.  **Base64デコード**:
    *   `strings.TrimPrefix(auth, "Basic ")` を使用して `"Basic "` プレフィックスを取り除き、残りの文字列（Base64エンコードされた資格情報）を取得します。
    *   `base64.StdEncoding.DecodeString()` を使用して、このBase64文字列をデコードし、バイトスライス `c` を取得します。
    *   デコード中にエラーが発生した場合（例: 無効なBase64文字列）、空のユーザー名、パスワード、および `ok=false` を返します。
3.  **ユーザー名とパスワードの分離**:
    *   デコードされたバイトスライス `c` を文字列 `cs` に変換します。
    *   `strings.IndexByte(cs, ':')` を使用して、文字列 `cs` 内の最初のコロン（`:`）のインデックス `s` を見つけます。Basic認証の仕様では、ユーザー名とパスワードはコロンで区切られています。
    *   コロンが見つからない場合（`s < 0`）、形式が不正であるため、空のユーザー名、パスワード、および `ok=false` を返します。
4.  **結果の返却**:
    *   コロンのインデックス `s` を使用して、`cs[:s]` でユーザー名を、`cs[s+1:]` でパスワードを抽出します。
    *   抽出したユーザー名、パスワード、および `ok=true` を返します。

この実装により、`net/http` パッケージは、Basic認証のサーバーサイド処理を標準化し、開発者がより安全で効率的なコードを書けるように貢献しています。

+// BasicAuth returns the username and password provided in the request's
+// Authorization header, if the request uses HTTP Basic Authentication.
+// See RFC 2617, Section 2.
+func (r *Request) BasicAuth() (username, password string, ok bool) {
+	auth := r.Header.Get("Authorization")
+	if auth == "" {
+		return
+	}
+	return parseBasicAuth(auth)
+}
+
+// parseBasicAuth parses an HTTP Basic Authentication string.
+// "Basic QWxhZGRpbjpvcGVuIHNlc2FtZQ==" returns ("Aladdin", "open sesame", true).
+func parseBasicAuth(auth string) (username, password string, ok bool) {
+	if !strings.HasPrefix(auth, "Basic ") {
+		return
+	}
+	c, err := base64.StdEncoding.DecodeString(strings.TrimPrefix(auth, "Basic "))
+	if err != nil {
+		return
+	}
+	cs := string(c)
+	s := strings.IndexByte(cs, ':')
+	if s < 0 {
+		return
+	}
+	return cs[:s], cs[s+1:], true
+}

## コアとなるコードの解説

### `src/pkg/net/http/request.go`

*   **`import "encoding/base64"` の追加**: Base64エンコードされた認証情報をデコードするために、`encoding/base64` パッケージがインポートされています。
*   **`func (r *Request) BasicAuth() (username, password string, ok bool)`**:
    *   このメソッドは `*http.Request` 型のレシーバーを持ち、HTTPリクエストオブジェクトに対して呼び出されます。
    *   `r.Header.Get("Authorization")` で `Authorization` ヘッダーの値を取得します。
    *   ヘッダーが存在しない場合は、`ok` を `false` としてすぐに返します。
    *   ヘッダーが存在する場合は、内部ヘルパー関数である `parseBasicAuth` に処理を委譲します。
*   **`func parseBasicAuth(auth string) (username, password string, ok bool)`**:
    *   この関数は、`Authorization` ヘッダーの生の値（例: `"Basic QWxhZGRpbjpvcGVuIHNlc2FtZQ=="`）を引数として受け取ります。
    *   まず、`strings.HasPrefix(auth, "Basic ")` で文字列が `"Basic "` で始まることを確認し、Basic認証スキームであることを検証します。そうでなければ `ok=false` を返します。
    *   `strings.TrimPrefix(auth, "Basic ")` で `"Basic "` プレフィックスを取り除き、残りのBase64エンコードされた文字列を取得します。
    *   `base64.StdEncoding.DecodeString()` を使用して、このBase64文字列をバイトスライスにデコードします。デコードに失敗した場合も `ok=false` を返します。
    *   デコードされたバイトスライスを文字列に変換し、`strings.IndexByte(cs, ':')` でユーザー名とパスワードを区切るコロンの位置を探します。コロンが見つからない場合も `ok=false` を返します。
    *   コロンの位置に基づいて、ユーザー名 (`cs[:s]`) とパスワード (`cs[s+1:]`) を抽出し、`ok=true` とともに返します。

### `src/pkg/net/http/request_test.go`

*   **`import "encoding/base64"` の追加**: テストケースでBase64エンコードされた文字列を生成するためにインポートされています。
