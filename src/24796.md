## 元コミット内容

このコミットは、`src/fmt/doc.go`ファイル内の`%e`および`%E`フォーマット動詞に関するドキュメントの記述を修正しています。

変更前:
```
		%e	scientific notation, e.g. -1234.456e+78
		%E	scientific notation, e.g. -1234.456E+78
```

変更後:
```
		%e	scientific notation, e.g. -1.234456e+78
		%E	scientific notation, e.g. -1.234456E+78
```

## 変更の背景

この変更は、Goの`fmt`パッケージにおける浮動小数点数の科学的記法（`%e`および`%E`）の実際の出力形式と、ドキュメントに記載されている例との間に不一致があったために行われました。具体的には、Goの`fmt`パッケージは、科学的記法で数値をフォーマットする際に、小数点より前に1桁の非ゼロの数字が来るように正規化します。しかし、以前のドキュメントの例では、小数点より前に複数の数字がある形式（例: `-1234.456e+78`）が示されており、これは実際の挙動とは異なっていました。

この不一致は、GoのIssue #12340で報告され、ユーザーがドキュメントを読んだ際に誤解を招く可能性がありました。このコミットは、ドキュメントの正確性を向上させ、ユーザーが`fmt`パッケージの挙動を正しく理解できるようにするために実施されました。

## 前提知識の解説

### `fmt`パッケージ

`fmt`パッケージは、Go言語の標準ライブラリの一部であり、フォーマットされたI/O（入力/出力）を実装します。C言語の`printf`や`scanf`に似た機能を提供し、様々なデータ型を文字列として整形したり、文字列からデータを解析したりするために使用されます。

### フォーマット動詞

`fmt`パッケージでは、`Printf`や`Sprintf`などの関数で、出力する値の型や表示形式を指定するために「フォーマット動詞（format verb）」を使用します。フォーマット動詞は`%`記号で始まり、その後に文字が続きます（例: `%d`は整数、`%s`は文字列）。

### 浮動小数点数のフォーマット動詞

浮動小数点数（`float32`, `float64`）をフォーマットするための主な動詞には以下のようなものがあります。

*   **`%f`**: 小数点形式（例: `123.456`）。
*   **`%e`**: 科学的記法（小文字の`e`を使用、例: `1.234e+03`）。
*   **`%E`**: 科学的記法（大文字の`E`を使用、例: `1.234E+03`）。
*   **`%g`**: 値に応じて`%e`または`%f`のいずれか短い方を選択します。
*   **`%G`**: 値に応じて`%E`または`%f`のいずれか短い方を選択します。
*   **`%b`**: 指数部が2のべき乗である、小数点なしの科学的記法（例: `-123456p-78`）。これは`strconv.FormatFloat`の`'b'`フォーマットに似ています。

### 科学的記法（Scientific Notation）

科学的記法は、非常に大きい数や非常に小さい数を簡潔に表現する方法です。一般的に、`a × 10^b`の形式で表されます。ここで`a`は仮数（mantissa）または有効数字（significand）と呼ばれ、`b`は指数（exponent）と呼ばれます。

Goの`fmt`パッケージにおける`%e`および`%E`フォーマット動詞は、この科学的記法で浮動小数点数を出力します。標準的な科学的記法では、仮数`a`は通常、`1 <= |a| < 10`となるように正規化されます。つまり、小数点より前に1桁の非ゼロの数字が来ます。例えば、`1234.56`は`1.23456e+03`と表現されます。

## 技術的詳細

このコミットの技術的詳細は、Goの`fmt`パッケージが浮動小数点数を科学的記法でフォーマットする際の内部的な挙動と、そのドキュメントの整合性に関するものです。

Goの`fmt`パッケージは、浮動小数点数を`%e`または`%E`でフォーマットする際、`strconv.FormatFloat`関数を内部的に利用しています。`strconv.FormatFloat`は、指定されたフォーマット（ここでは`'e'`または`'E'`）に従って浮動小数点数を文字列に変換します。この関数は、IEEE 754浮動小数点標準に準拠しており、科学的記法で出力する際には、小数点より前に1桁の非ゼロの数字が来るように正規化された形式を採用します。

例えば、`fmt.Sprintf("%e", 1234.456)`を実行すると、出力は`1.234456e+03`となります。これは、数値`1234.456`が`1.234456 × 10^3`として表現されるためです。

以前のドキュメントの例では、`-1234.456e+78`という形式が示されていました。これは、小数点より前に複数の数字がある形式であり、一般的な科学的記法の正規化された形式とは異なります。このような形式は、一部のプログラミング言語やシステムで採用されることもありますが、Goの`fmt`パッケージのデフォルトの挙動ではありません。

このコミットは、ドキュメントの例を実際のGoの挙動に合わせて`-1.234456e+78`に変更することで、この不一致を解消しました。この修正により、Goの`fmt`パッケージのドキュメントはより正確になり、開発者が期待する出力形式を正しく理解できるようになります。

この変更は、コードの動作自体を変更するものではなく、あくまでドキュメントの記述を修正するものです。しかし、ドキュメントの正確性は、ライブラリの使いやすさや開発者の生産性に直結するため、非常に重要な修正と言えます。

## コアとなるコードの解説

この変更は、`src/fmt/doc.go`内のコメント行を修正するものです。`doc.go`ファイルは、Goのパッケージドキュメントを生成するための特別なファイルであり、パッケージの概要や主要な機能、使用例などが記述されています。

具体的には、`%e`と`%E`というフォーマット動詞の説明部分にある`e.g.`（例）が修正されています。

*   **`%e`**: 浮動小数点数を科学的記法で出力します。指数部には小文字の`e`が使用されます。
    *   変更前: `-1234.456e+78`
    *   変更後: `-1.234456e+78`
*   **`%E`**: 浮動小数点数を科学的記法で出力します。指数部には大文字の`E`が使用されます。
    *   変更前: `-1234.456E+78`
    *   変更後: `-1.234456E+78`

この修正のポイントは、小数点より前の桁数が1桁になるように例が変更された点です。これは、Goの`fmt`パッケージが浮動小数点数を科学的記法でフォーマットする際の標準的な挙動（正規化された形式）を正確に反映しています。例えば、`1234.456`という数値は、`%e`でフォーマットすると`1.234456e+03`となり、小数点より前には`1`という1桁の数字が来ます。元の例の`-1234.456e+78`は、この正規化された形式とは異なっていました。

この修正により、`fmt`パッケージのドキュメントは、実際のコードの挙動と完全に一致するようになり、開発者がドキュメントを参照する際に混乱することがなくなります。これは、ドキュメントの品質とユーザーエクスペリエンスの向上に貢献する、小さながらも重要な修正です。
