## 変更の背景

このコミットは、Windows環境における `os.Getwd()` 関数の無限再帰バグを修正するために導入されました。既存の `os.Getwd()` の実装では、内部で `os.Stat(".")` を呼び出していました。しかし、Windows環境において `os.Stat` 関数が、何らかの形で現在の作業ディレクトリを取得する処理（あるいはそれに依存する処理）を内部的に行っていたため、結果として `os.Getwd()` が `os.Stat` を呼び出し、その `os.Stat` が再び `os.Getwd()` を呼び出すという無限再帰が発生していました。これにより、プログラムがクラッシュするか、スタックオーバーフローを引き起こす可能性がありました。

## 前提知識の解説

*   **`os.Getwd()`**: Go言語の標準ライブラリ `os` パッケージが提供する関数で、現在のプロセスが実行されている作業ディレクトリの絶対パスを文字列として返します。
*   **`syscall.Getwd()`**: `syscall` パッケージは、オペレーティングシステムが提供する低レベルなシステムコールへのインターフェースを提供します。`syscall.Getwd()` は、OS固有のAPI（Windowsの場合は `GetCurrentDirectory` など）を直接呼び出して現在の作業ディレクトリを取得します。これは `os` パッケージの `Getwd()` が内部で利用する可能性のある、よりプリミティブな関数です。
*   **`os.Stat()`**: 指定されたファイルまたはディレクトリのファイル情報（サイズ、パーミッション、更新日時など）を取得する関数です。引数に `"."` を渡すと、現在の作業ディレクトリの情報を取得しようとします。
*   **無限再帰 (Infinite Recursion)**: 関数が自身を呼び出し続け、その呼び出しが終了条件に到達しない状態を指します。これにより、コールスタックが際限なく積まれ、最終的にスタックオーバーフローエラーが発生し、プログラムが異常終了します。
*   **`runtime.GOOS`**: Go言語の組み込み変数で、プログラムがビルドされるターゲットオペレーティングシステムの名前（例: "linux", "windows", "darwin"）を文字列で保持します。クロスプラットフォーム対応のコードを書く際に、OS固有の処理を分岐させるために使用されます。

## 技術的詳細

問題の根源は、Goの `os` パッケージが提供する高レベルな `Getwd()` 関数が、内部で `os.Stat(".")` を呼び出していた点にありました。通常、`os.Stat` はファイルシステムのメタデータを取得する独立した操作であるべきですが、Windowsの特定の条件下、またはその内部実装において、現在の作業ディレクトリの情報を取得する際に、間接的に `Getwd()` と同じようなロジック、あるいは `Getwd()` が依存する低レベルなAPIを呼び出していたと考えられます。

この依存関係が循環的であったため、`os.Getwd() -> os.Stat(".") -> (内部で) os.Getwd()` という呼び出しパスが形成され、無限ループに陥りました。

この問題を解決するために、コミットではWindows環境に特化した対応が導入されました。具体的には、`runtime.GOOS == "windows"` の場合に限り、`os.Getwd()` は直接 `syscall.Getwd()` を呼び出すように変更されました。`syscall.Getwd()` は、OSのネイティブAPIを直接叩くため、`os.Stat` を介した間接的な呼び出しパスを回避できます。これにより、無限再帰の連鎖が断ち切られ、Windows上での `os.Getwd()` が正常に機能するようになりました。

この変更は、Goの標準ライブラリが特定のOSの挙動に起因する問題を、そのOSに特化した低レベルなシステムコールを利用して解決する典型的な例と言えます。

## コアとなるコードの解説

変更は `src/pkg/os/getwd.go` ファイルの `Getwd()` 関数内で行われました。

1.  **`import "runtime"` の追加**:
    `runtime` パッケージが新しくインポートされました。これは `runtime.GOOS` を使用するために必要です。

2.  **Windows固有の処理の追加**:
    `Getwd()` 関数の冒頭に以下の条件分岐が追加されました。

    ```go
    	if runtime.GOOS == "windows" {
    		return syscall.Getwd()
    	}
    ```
    このコードブロックは、現在の実行環境がWindowsであるかどうかを `runtime.GOOS` で判定します。もしWindowsであれば、`os.Getwd()` はそれ以降の汎用的なロジック（`os.Stat(".")` を含む部分）を実行せず、直接 `syscall.Getwd()` を呼び出してその結果を返します。

    これにより、Windows環境でのみ発生していた `os.Stat(".")` を介した無限再帰のパスが完全に回避され、`syscall` パッケージが提供する低レベルで直接的な作業ディレクトリ取得メカニズムが利用されるようになりました。他のOS（Linux, macOSなど）では、この条件分岐はスキップされ、既存の汎用的な `Getwd()` のロジックが引き続き適用されます。
