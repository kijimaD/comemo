## 変更の背景

このコミットの主な目的は、`math/big` パッケージの `Float` 型に `Int()` メソッドを実装することです。これは、多倍長浮動小数点数から整数部分を切り捨てる（truncation）機能を提供します。以前は、この機能は `BUG(gri) Int is not yet implemented` というコメントと共に未実装の状態でした。浮動小数点数から整数部分を抽出する操作は、数値計算やデータ変換において基本的な要件であり、`math/big` パッケージの完全性を高めるために必要とされました。特に、`Float`型が表現できる非常に大きな、あるいは非常に小さな数値に対しても正確に整数部分を扱うことが求められます。

## 前提知識の解説

### `math/big` パッケージ

`math/big` パッケージは、Go言語で任意精度（多倍長）の数値演算を可能にするためのパッケージです。標準の `int` や `float64` 型では表現できない、非常に大きな整数、有理数、浮動小数点数を扱うことができます。これにより、金融計算、暗号化、科学技術計算など、高い精度が要求されるアプリケーションで利用されます。

### `Float` 型の表現

`math/big.Float` 型は、以下の形式で浮動小数点数を表現します。

`sign × mantissa × 2^exponent`

ここで：
- `sign`：数値の符号（正または負）。
- `mantissa`（仮数）：0.5 以上 1.0 未満の範囲に正規化された数値。
- `exponent`（指数）：2のべき乗の指数。

この表現は、IEEE 754 浮動小数点標準に似ていますが、`math/big.Float` は固定されたビット幅ではなく、必要に応じて精度を拡張できる点が異なります。`0` や `Inf`（無限大）のような特殊な値は、特別な仮数と指数で表現されます。

### 浮動小数点数の丸めと切り捨て (Truncation)

浮動小数点数を整数に変換する際には、いくつかの丸めモードがあります。
- **丸め (Rounding)**: 最も近い整数に丸める。例えば、2.5 は 3 に、-2.5 は -3 に丸められる（または偶数丸めなど、特定の規則に従う）。
- **切り捨て (Truncation)**: 小数点以下を単純に切り捨てる。これは「ゼロ方向への丸め」とも呼ばれ、正の数では床関数 (floor) と同じ、負の数では天井関数 (ceil) と同じ結果になります。
    - 例: `trunc(2.7) = 2`, `trunc(2.1) = 2`
    - 例: `trunc(-2.7) = -2`, `trunc(-2.1) = -2`

このコミットで実装される `Float.Int()` は、この「切り捨て」の動作を提供します。

### `Accuracy` 型

`math/big` パッケージでは、演算結果の精度を示すために `Accuracy` 型が使用されます。
- `Exact`: 結果が正確であることを示します。
- `Below`: 結果が真の値よりも小さいことを示します（正の数の切り捨てなど）。
- `Above`: 結果が真の値よりも大きいことを示します（負の数の切り捨てなど）。

`Float.Int()` メソッドでは、浮動小数点数が元々整数であった場合は `Exact` を返し、そうでない場合は切り捨ての方向に応じて `Below` または `Above` を返します。

## 技術的詳細

このコミットの主要な変更は、`Float` 型に `Int()` メソッドを追加し、それに伴い `IsInt()` メソッドのロジックを改善した点です。

### `Float.Int()` メソッドの実装

`Float.Int()` メソッドは、`Float` 型の数値 `x` の整数部分を `*big.Int` 型で返します。`x` が無限大 (`±Inf`) の場合は `nil` を返します。

1.  **精度 (Accuracy) の初期設定**:
    *   結果が不正確な場合の `Accuracy` は、デフォルトで `Below` に設定されます。
    *   もし `x` が負の数であれば、切り捨ては真の値よりも大きくなるため、`Accuracy` は `Above` に設定されます。

2.  **エッジケースの処理**:
    *   `x.exp <= 0` の場合: これは `|x| < 1` または `|x| == Inf` のケースをカバーします。
        *   `x.exp == infExp` であれば、`x` は無限大なので `nil` と適切な `Accuracy` (`Below` または `Above`) を返します。
        *   `x` が `0` であれば (`len(x.mant) == 0`)、`Accuracy` は `Exact` に設定されます。
        *   それ以外の場合（`0 < |x| < 1`）、整数部分は `0` なので、新しい `*big.Int` (値は0) と適切な `Accuracy` を返します。
    *   `x.exp > 0` の場合: これは `|x| >= 1` のケースです。

3.  **整数部分の抽出ロジック**:
    *   `Float` の内部表現は `mantissa × 2^exponent` です。整数部分を抽出するには、仮数部を指数部に基づいて適切にシフトする必要があります。
    *   `allBits` は仮数部 `x.mant` が持つビットの総数です。
    *   `minPrec` は `x` の有効な仮数部が持つ最小限の精度（末尾のゼロビットを除いたビット数）です。
    *   `exp` は `x.exp` を `uint` にキャストしたものです。
    *   `exp >= minPrec` の場合、`x` は完全に整数であり、`Accuracy` は `Exact` に設定されます。
    *   仮数部 `x.mant` を `big.Int` の絶対値として扱い、`exp` の値に応じて左シフト (`shl`) または右シフト (`shr`) します。
        *   `exp > allBits`: 仮数部を `exp - allBits` ビットだけ左シフトします。これは、非常に大きな整数を表す場合に発生します。
        *   `exp < allBits`: 仮数部を `allBits - exp` ビットだけ右シフトします。これは、仮数部に小数部分が含まれる場合に、その小数部分を切り捨てるために行われます。
        *   `exp == allBits`: シフトは不要で、仮数部をそのまま使用します。

4.  **結果の返却**:
    *   計算された絶対値 `res.abs` と符号 `res.neg` を持つ `*big.Int` オブジェクトを返します。

### `IsInt()` メソッドの改善

`IsInt()` メソッドは、`Float` 型の数値が厳密に整数であるかどうかを報告します。このコミットでは、`IsInt()` のロジックがより堅牢になるように修正されています。

*   以前のバージョンでは `x.exp <= 0` の場合に `return false` となっていましたが、これは `|x| < 1` のケースで `0` が整数であるという事実を考慮していませんでした。
*   新しいロジックでは、`x.exp <= 0` の場合、`len(x.mant) == 0 && x.exp != infExp` (つまり `x == 0`) であれば `true` を返すように修正されました。これにより、`0` が正しく整数として認識されます。
*   `x.exp > 0` の場合、`uint(x.exp) >= x.prec` であれば `true` を返します。これは、指数が仮数部の精度よりも大きい場合、小数部分が存在しないことを意味します。
*   最終的なチェックとして、`minPrec` を計算し、`exp >= minPrec` であれば整数であると判断します。これは、仮数部の末尾のゼロビットを考慮して、実際に有効なビット数と指数を比較することで、より正確な整数判定を行います。

### `setExp()` メソッドの変更

`setExp()` メソッドは、`Float` の指数を設定します。このコミットでは、`len(z.mant) == 0` (つまり `z` が `0` である) の場合に、指数 `e` を `0` に設定するロジックが追加されました。これは、`0` の表現を一貫させるための修正です。`0` は常に指数 `0` を持つべきです。

## コアとなるコードの変更箇所

### `src/math/big/float.go`

```go
// IsInt reports whether x is an integer.
// ±Inf are not considered integers.
func (x *Float) IsInt() bool {
	if debugFloat {
		x.validate()
	}
	// pick off easy cases
	if x.exp <= 0 {
		// |x| < 1 || |x| == Inf
		return len(x.mant) == 0 && x.exp != infExp
	}
	// x.exp > 0
	if uint(x.exp) >= x.prec {
		return true // not enough precision for fractional mantissa
	}
	// x.mant[len(x.mant)-1] != 0
	// determine minimum required precision for x
	minPrec := uint(len(x.mant))*_W - x.mant.trailingZeroBits()
	return uint(x.exp) >= minPrec
}

// If the exponent's magnitude is too large, z becomes ±Inf.
func (z *Float) setExp(e int64) {
	if -MaxExp <= e && e <= MaxExp {
		if len(z.mant) == 0 {
			e = 0
		}
		z.exp = int32(e)
		return
	}
	// ... (rest of the function remains unchanged)
}

// Int returns the result of truncating x towards zero; or nil
// if x is an infinity. The result is Exact if x.IsInt();
// otherwise it is Below for x > 0, and Above for x < 0.
func (x *Float) Int() (res *Int, acc Accuracy) {
	if debugFloat {
		x.validate()
	}
	// accuracy for inexact results
	acc = Below // truncation
	if x.neg {
		acc = Above
	}
	// pick off easy cases
	if x.exp <= 0 {
		// |x| < 1 || |x| == Inf
		if x.exp == infExp {
			return nil, acc // ±Inf
		}
		if len(x.mant) == 0 {
			acc = Exact // ±0
		}
		return new(Int), acc // ±0.xxx
	}
	// x.exp > 0
	// x.mant[len(x.mant)-1] != 0
	// determine minimum required precision for x
	allBits := uint(len(x.mant)) * _W
	minPrec := allBits - x.mant.trailingZeroBits()
	exp := uint(x.exp)
	if exp >= minPrec {
		acc = Exact
	}
	// shift mantissa as needed
	res = &Int{neg: x.neg}
	// TODO(gri) should have a shift that takes positive and negative shift counts
	switch {
	case exp > allBits:
		res.abs = res.abs.shl(x.mant, exp-allBits)
	default:
		res.abs = res.abs.set(x.mant)
	case exp < allBits:
		res.abs = res.abs.shr(x.mant, allBits-exp)
	}
	return
}
```

## コアとなるコードの解説

### `Float.Int()` メソッド

このメソッドは、`Float` 型の数値 `x` の整数部分を `*big.Int` として計算し、返します。

-   **`acc = Below` / `if x.neg { acc = Above }`**:
    *   これは、切り捨て（truncation）の性質を反映しています。正の数を切り捨てると、結果は元の値より小さくなるか等しくなります（例: 1.23 -> 1）。そのため `Below`。
    *   負の数を切り捨てると、結果は元の値より大きくなるか等しくなります（例: -1.23 -> -1）。そのため `Above`。
    *   `x.IsInt()` の場合は `Exact` に上書きされます。

-   **`if x.exp <= 0 { ... }`**:
    *   指数が0以下の場合、数値の絶対値は1未満であるか、無限大です。
    *   `x.exp == infExp` は無限大を表し、この場合 `nil` を返します。
    *   `len(x.mant) == 0` は `0` を表し、この場合 `acc = Exact` となります。
    *   それ以外（例: `0.123`, `-0.456`）は、整数部分が `0` となるため、`new(Int)` (値が0の `big.Int`) を返します。

-   **`allBits := uint(len(x.mant)) * _W`**:
    *   `_W` は `big.Word` 型のビット幅（通常は32または64）です。
    *   `len(x.mant)` は仮数部を構成する `big.Word` の数です。
    *   これにより、仮数部が全体で何ビットを占めているかが計算されます。

-   **`minPrec := allBits - x.mant.trailingZeroBits()`**:
    *   `trailingZeroBits()` は、仮数部の末尾にあるゼロビットの数を返します。
    *   `minPrec` は、仮数部の有効な（非ゼロの）ビット数を表します。これは、数値の真の精度を決定するために重要です。

-   **`if exp >= minPrec { acc = Exact }`**:
    *   もし指数 `exp` が `minPrec` 以上であれば、仮数部の有効なビットがすべて小数点の左側にあることを意味します。つまり、元の `Float` は厳密に整数であったため、`Accuracy` は `Exact` に設定されます。

-   **`switch { ... }` ブロック**:
    *   これは、仮数部を適切な `big.Int` に変換するためのシフトロジックです。
    *   `exp > allBits`: 指数が仮数部の全ビット数よりも大きい場合、仮数部を左にシフトして、不足している `exp - allBits` ビットを補います。これは、非常に大きな整数（例: `1e+100`）を扱う場合に発生します。
    *   `exp < allBits`: 指数が仮数部の全ビット数よりも小さい場合、仮数部を右にシフトして、`allBits - exp` ビットを切り捨てます。これにより、小数部分が除去され、整数部分のみが残ります。
    *   `default` (`exp == allBits`): シフトは不要で、仮数部をそのまま `big.Int` に設定します。

### `IsInt()` メソッド

このメソッドは、`Float` が厳密に整数であるかを判定します。

-   **`if x.exp <= 0 { return len(x.mant) == 0 && x.exp != infExp }`**:
    *   指数が0以下の場合、`0` のみが整数として扱われます。`len(x.mant) == 0` は `0` を意味し、`x.exp != infExp` は無限大ではないことを確認します。これにより、`0` が正しく整数と判定されます。

-   **`if uint(x.exp) >= x.prec { return true }`**:
    *   `x.prec` は `Float` の設定された精度です。
    *   もし指数が設定された精度以上であれば、仮数部のすべてのビットが小数点の左側にあると見なされ、数値は整数であると判断されます。

-   **`minPrec := uint(len(x.mant))*_W - x.mant.trailingZeroBits()`**:
    *   `Float.Int()` と同様に、仮数部の有効なビット数を計算します。

-   **`return uint(x.exp) >= minPrec`**:
    *   最終的に、指数が仮数部の有効なビット数以上であれば、その `Float` は整数であると判断されます。

### `setExp()` メソッド

このメソッドは、`Float` の指数を設定する際に、`0` の特殊なケースを処理します。

-   **`if len(z.mant) == 0 { e = 0 }`**:
    *   もし仮数部が空（つまり `z` が `0`）であれば、指数 `e` を強制的に `0` に設定します。これは、`0` の表現が一意であることを保証するためです。
