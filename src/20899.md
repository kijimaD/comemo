# [インデックス 20899] ファイルの概要

このコミットは、Go言語のWindowsインストーラーに関連するURLの修正と改善を目的としています。具体的には、インストーラーが「プログラムの追加と削除」（Add or Remove Programs: ARP）リストに表示するヘルプ、README、および情報提供のURLを更新し、それらが正しく機能し、クリック可能なリンクとして表示されるようにしています。

## 変更の背景

Go言語のWindowsインストーラーにおいて、「プログラムの追加と削除」リストに表示されるヘルプURL (`ARPHELPLINK`) が404エラー（ページが見つかりません）を返していました。これは、ユーザーがインストーラーを通じてGoに関するヘルプ情報を参照しようとした際に、正しい情報にアクセスできないという問題を引き起こしていました。

また、`ARPREADME` と `ARPURLINFOABOUT` のURLについても、HTTPスキーム（`http://` または `https://`）が欠落していたため、「プログラムの追加と削除」リスト内でクリック可能なリンクとして認識されず、ユーザーが直接アクセスできないというユーザビリティ上の問題がありました。

これらの問題を解決し、ユーザーエクスペリエンスを向上させるために、関連するURLの更新と修正が行われました。

## 前提知識の解説

このコミットを理解するためには、以下の前提知識が役立ちます。

*   **Windows Installer XML (WiX) Toolset**: WiXは、Windowsインストーラー（.msiファイル）を作成するためのオープンソースのツールセットです。XMLベースの言語を使用してインストーラーの動作を定義します。Go言語のWindowsインストーラーもWiXを使用して構築されています。
*   **MSIプロパティ**: Windowsインストーラーは、インストールプロセスやインストールされたアプリケーションの情報を制御するために、さまざまなプロパティを使用します。これらのプロパティは、インストーラーの動作をカスタマイズしたり、システムに特定の情報を登録したりするために利用されます。
*   **ARP (Add or Remove Programs) プロパティ**: WiXにおいて、`ARP`で始まるプロパティは、Windowsの「プログラムの追加と削除」（Windows 10以降では「アプリと機能」）コントロールパネルに表示されるアプリケーションの情報をカスタマイズするために使用されます。
    *   **`ARPHELPLINK`**: インストールされた製品に関する技術サポートのインターネットアドレス（URL）を指定します。プログラムが「プログラムの追加と削除」リストで選択された際に、「サポート情報」セクションに表示されます。
    *   **`ARPREADME`**: インストールされたアプリケーションに関連付けられたREADMEファイルのフルパスを指定します。
    *   **`ARPURLINFOABOUT`**: 製品に関する一般的な情報を提供するURL、または発行元のホームページへのリンクを定義します。これも「プログラムの追加と削除」インターフェースに表示されます。
*   **URLスキーム**: URL（Uniform Resource Locator）は、インターネット上のリソースのアドレスを指定するための標準的な方法です。URLの先頭には、リソースにアクセスするためのプロトコルを示す「スキーム」（例: `http://`, `https://`, `ftp://`）が含まれます。ブラウザやオペレーティングシステムがURLを正しく認識し、クリック可能なリンクとして扱うためには、このスキームが不可欠です。

## 技術的詳細

このコミットは、WiXインストーラー定義ファイルである `installer.wxs` を変更しています。このファイルは、Go言語のWindowsインストーラーの構造と動作を記述しています。

変更の核心は、以下の3つのWiXプロパティの値の更新です。

1.  **`ARPHELPLINK`**: 以前は `golang.org/doc/community.html` という相対的なURLが設定されていましたが、これが404エラーを引き起こしていました。新しい値は `https://golang.org/help/` となり、Go言語の公式ヘルプページを指す絶対URLに修正されました。これにより、ユーザーは常に最新かつ正しいヘルプ情報にアクセスできるようになります。
2.  **`ARPREADME`**: 以前は `golang.org` と設定されていましたが、HTTPスキームが欠落していました。新しい値は `https://golang.org` となり、`https://` スキームが追加されました。これにより、「プログラムの追加と削除」リスト内でこのURLがクリック可能なリンクとして認識され、ユーザーがGo言語の公式サイトに直接アクセスできるようになります。
3.  **`ARPURLINFOABOUT`**: `ARPREADME` と同様に、以前は `golang.org` と設定されていましたが、HTTPスキームが欠落していました。新しい値は `https://golang.org` となり、`https://` スキームが追加されました。これにより、このURLもクリック可能なリンクとなり、ユーザーがGo言語に関する情報ページに容易にアクセスできるようになります。

これらの変更は、インストーラーがWindowsシステムに登録するメタデータを直接修正するものであり、Go言語のインストール後のユーザーエクスペリエンス、特に情報アクセス性において重要な改善をもたらします。

## コアとなるコードの解説

このコードスニペットは、WiXのXML定義の一部であり、Windowsインストーラーのプロパティを定義しています。

*   `<Property Id="..." Value="..." />` タグは、特定のMSIプロパティとその値を設定するために使用されます。
*   変更前は、`ARPHELPLINK` が `golang.org/doc/community.html` を指しており、これは当時存在しないか、移動したURLでした。
*   `ARPREADME` と `ARPURLINFOABOUT` は `golang.org` を指していましたが、`http://` または `https://` のスキームが欠落していました。Windowsの「プログラムの追加と削除」インターフェースは、スキームがないURLを自動的にクリック可能なリンクとして認識しない場合があります。
*   変更後、`ARPHELPLINK` は `https://golang.org/help/` という新しい絶対URLに更新されました。
*   `ARPREADME` と `ARPURLINFOABOUT` は、それぞれ `https://golang.org` に更新され、明示的に `https://` スキームが追加されました。これにより、これらのURLがWindowsのUIで正しくハイパーリンクとして機能するようになります。

この修正は、インストーラーの機能そのものには影響を与えませんが、インストールされたアプリケーションのメタデータ表示とユーザーの情報アクセス性を大幅に改善します。
