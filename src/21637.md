# [インデックス 21637] ファイルの概要

このコミットは、Go言語のアセンブラ（`cmd/asm`）内部で使用されるアドレス表現のための新しいパッケージ `addr` を追加するものです。具体的には、アセンブラ命令のアドレスを構造体 `Addr` として定義し、そのアドレスがどのような要素（レジスタ、オフセット、シンボルなど）を持つかを判定するためのヘルパーメソッドを提供します。

## 変更の背景

このコミットは、Go言語のアセンブラ（`cmd/asm`）の内部構造を改善し、アセンブラが扱うアドレスの表現をより明確かつ構造化された方法で行うために導入されました。アセンブラは、ソースコード（`.s`ファイル）から機械語命令を生成する過程で、様々な形式のアドレス（即値、レジスタ、メモリ参照、シンボルなど）を解析し、操作する必要があります。

以前は、これらのアドレス情報が散在していたり、アドホックな方法で処理されていた可能性があります。`Addr` 型を導入することで、アセンブラのコードベース全体でアドレスの概念を一貫して扱い、解析、検証、およびコード生成のロジックを簡素化し、保守性を向上させることが目的と考えられます。特に、アセンブラが複雑なアドレッシングモード（例: `(R1*8)` のようなインデックス付きアドレス）を正確に処理するためには、アドレスの各構成要素を明確に分離して表現できるデータ構造が不可欠です。

この変更は、Goコンパイラツールチェーンの進化の一環であり、アセンブラの堅牢性と機能性を高めるための基盤整備と位置づけられます。

## 前提知識の解説

このコミットを理解するためには、以下の前提知識が役立ちます。

1.  **Go言語のアセンブラ (`cmd/asm`)**:
    Go言語は、一部のパフォーマンスクリティカルな部分や、特定のハードウェア機能にアクセスするために、Goアセンブラ（`cmd/asm`）を使用します。これは、一般的なアセンブラとは異なり、Goのリンケージ規約や型システムと密接に連携するように設計されています。Goのアセンブラコードは`.s`拡張子を持ち、Goの関数として呼び出せるようにコンパイルされます。アセンブラは、これらの`.s`ファイルを解析し、機械語に変換する役割を担います。

2.  **アセンブラにおけるアドレス**:
    アセンブラの文脈における「アドレス」は、単なるメモリ番地を指すだけでなく、命令のオペランドとして使用される様々な値を指します。これには以下のような種類があります。
    *   **即値 (Immediate Value)**: 命令に直接埋め込まれる定数（例: `$3`）。
    *   **レジスタ (Register)**: CPUのレジスタ（例: `R1`）。
    *   **メモリ参照 (Memory Reference)**: メモリ上の位置を指す。これは、ベースレジスタ、インデックスレジスタ、スケール、オフセット、シンボルなど、複数の要素の組み合わせで表現されることが多い（例: `8(R1)`, `(R1*8)`, `main·main(SB)`）。
    *   **シンボル (Symbol)**: 関数名やグローバル変数名など、プログラム内の特定の場所を指す名前（例: `main·main(SB)`）。

3.  **Goのツールチェーン**:
    Go言語のビルドプロセスは、`go build` コマンドによって統合されていますが、その内部ではコンパイラ（`cmd/compile`）、アセンブラ（`cmd/asm`）、リンカ（`cmd/link`）などの複数のツールが連携して動作します。`cmd/asm` は、Goのアセンブラソースコードをオブジェクトファイルに変換する役割を担います。

4.  **Goのパッケージ構造**:
    Goのソースコードはパッケージに分割され、依存関係が管理されます。`src/cmd/asm/internal/addr` というパスは、`cmd/asm` ツール内部でのみ使用される（`internal` ディレクトリのため外部からはインポートできない）`addr` パッケージであることを示しています。これは、ツール内部の特定の機能に特化したコードをカプセル化するための標準的なGoのプラクティスです。

## 技術的詳細

このコミットによって追加された `addr` パッケージは、Goアセンブラが扱うアドレスの複雑な構造を `Addr` 型としてカプセル化します。`Addr` 構造体は、アセンブラのアドレスが持ちうる様々な構成要素をフィールドとして持ちます。

*   **`Addr` 構造体のフィールド**:
    *   `IsStatic`: シンボルが静的かどうか（例: `symbol<>`）。
    *   `IsImmediateConstant`: 即値定数かどうか（例: `$3`）。
    *   `IsImmediateAddress`: 即値アドレスかどうか（例: `$main·main(SB)`）。
    *   `IsIndirect`: 間接参照かどうか（例: `(R1)`）。
    *   `HasRegister`, `HasRegister2`, `HasFloat`, `HasOffset`, `HasString`: それぞれレジスタ、2つ目のレジスタ、浮動小数点数、オフセット、文字列定数を持つかどうかを示すブールフラグ。
    *   `Symbol`: シンボル名（例: `"main·main"`）。
    *   `Register`, `Register2`: レジスタ番号（`int16`）。
    *   `Offset`: オフセット値（`int64`）。
    *   `Float`: 浮動小数点定数（`float64`）。
    *   `String`: 文字列定数。
    *   `Index`: インデックスレジスタ番号（`int16`）。
    *   `Scale`: スケール値（`int8`、例: `(R1*8)` の `8`）。

*   **定数**:
    `ImmediateConstant`, `ImmediateAddress`, `Indirect`, `Symbol`, `Register`, `Register2`, `Offset`, `Float`, `String`, `Index`, `Scale` といった定数が定義されています。これらはビットマスクとして使用され、`Has` および `Is` メソッドでアドレスのプロパティを効率的にチェックするために利用されます。

*   **`Has` メソッド**:
    `func (a *Addr) Has(mask int) bool` は、`Addr` インスタンスが指定されたマスク内のいずれかの要素を持っているかどうかを報告します。このメソッドは、間接参照や即値のプロパティはチェックしません。例えば、`a.Has(Register | Offset)` は、アドレスがレジスタまたはオフセットのいずれかを持っている場合に `true` を返します。

*   **`Is` メソッド**:
    `func (a *Addr) Is(mask int) bool` は、`Addr` インスタンスが指定されたマスク内の要素を「正確に」持っているかどうかを報告します。このメソッドは、間接参照や即値のプロパティもチェックします。例えば、`a.Is(Register | Offset)` は、アドレスがレジスタとオフセットを両方持ち、かつそれ以外の要素を持たない場合に `true` を返します。これは、特定のアドレッシングモードを厳密に識別する際に有用です。

この新しい `addr` パッケージは、アセンブラのパーサーがアセンブリコードを解析する際に、オペランドとして現れるアドレスをこの `Addr` 型のインスタンスに変換するために使用されます。これにより、アセンブラのバックエンドが、解析されたアドレスの構造に基づいて適切な機械語命令を生成する際のロジックが大幅に簡素化されます。

## コアとなるコードの変更箇所

このコミットは、`src/cmd/asm/internal/addr/addr.go` という新しいファイルを追加しています。このファイルがこのコミットの唯一の変更点であり、その内容は以下の通りです。

```go
// Copyright 2015 The Go Authors. All rights reserved.
// Use of this source code is governed by a BSD-style
// license that can be found in the LICENSE file.

// Package addr holds the definition of an instruction address.
package addr

// Addr represents a parsed address.
type Addr struct {
	IsStatic            bool    // symbol<>
	IsImmediateConstant bool    // $3
	IsImmediateAddress  bool    // $main·main(SB)
	IsIndirect          bool    // (R1)
	HasRegister         bool    // register is set
	HasRegister2        bool    // register2 is set
	HasFloat            bool    // float is set
	HasOffset           bool    // offset is set
	HasString           bool    // string is set
	Symbol              string  // "main·main"
	Register            int16   // R1
	Register2           int16   // R1 in R0:R1
	Offset              int64   // 3
	Float               float64 // 1.0e2 (floating constant)
	String              string  // "hi" (string constant)
	Index               int16   // R1 in (R1*8)
	Scale               int8    // 8 in (R1*8)
}

const (
	// IsStatic does not appear here; Is and Has methods ignore it.
	ImmediateConstant = 1 << iota
	ImmediateAddress
	Indirect
	Symbol
	Register
	Register2
	Offset
	Float
	String
	Index
	Scale
)

// Has reports whether the address has any of the specified elements.
// Indirect and immediate are not checked.
func (a *Addr) Has(mask int) bool {
	if mask&Symbol != 0 && a.Symbol != "" {
		return true
	}
	if mask&Register != 0 && a.HasRegister {
		return true
	}
	if mask&Register2 != 0 && a.HasRegister2 {
		return true
	}
	if mask&Offset != 0 && a.HasOffset {
		return true
	}
	if mask&Float != 0 && a.HasFloat {
		return true
	}
	if mask&String != 0 && a.HasString {
		return true
	}
	if mask&Index != 0 && a.Index != 0 {
		return true
	}
	if mask&Scale != 0 && a.Scale != 0 {
		return true
	}
	return false
}

// Is reports whether the address has exactly the specified elements.
// Indirect and immediate are checked.
func (a *Addr) Is(mask int) bool {
	if (mask&ImmediateConstant == 0) != !a.IsImmediateConstant {
		return false
	}
	if (mask&ImmediateAddress == 0) != !a.IsImmediateAddress {
		return false
	}
	if (mask&Indirect == 0) != !a.IsIndirect {
		return false
	}
	if (mask&Symbol == 0) != (a.Symbol == "") {
		return false
	}
	if (mask&Register == 0) != !a.HasRegister {
		return false
	}
	if (mask&Register2 == 0) != !a.HasRegister2 {
		return false
	}
	if (mask&Offset == 0) != !a.HasOffset {
		// $0 has the immediate bit but value 0.
		return false
	}
	if (mask&Float == 0) != !a.HasFloat {
		return false
	}
	if (mask&String == 0) != !a.HasString {
		return false
	}
	if (mask&Index == 0) != (a.Index == 0) {
		return false
	}
	if (mask&Scale == 0) != (a.Scale == 0) {
		return false
	}
	return true
}
```

## コアとなるコードの解説

追加された `addr.go` ファイルは、Goアセンブラの内部でアドレスを表現するための中心的なデータ構造と、その操作のためのメソッドを提供します。

1.  **`Addr` 構造体**:
    この構造体は、アセンブラが解析する様々な種類のアドレス（例: `R1`, `8(R1)`, `$3`, `main·main(SB)`, `(R1*8)` など）を統一的に表現するためのものです。各フィールドは、アドレスが持ちうる特定の要素（レジスタ、オフセット、シンボル、即値など）に対応しています。ブール型のフラグ（`IsStatic`, `IsImmediateConstant`, `HasRegister` など）は、そのアドレスが特定のプロパティを持つかどうかを迅速に判定するために使用されます。これにより、アセンブラのパーサーは、入力されたアセンブリコードのアドレス部分を解析し、この `Addr` 構造体のインスタンスにマッピングすることができます。

2.  **定数群**:
    `ImmediateConstant`, `Symbol`, `Register` などの定数は、`1 << iota` を使用してビットフラグとして定義されています。これらは、`Has` および `Is` メソッドに渡されるマスクとして機能し、アドレスのプロパティを効率的にチェックすることを可能にします。例えば、`Register | Offset` のように複数の定数をOR結合することで、複数のプロパティを同時に指定できます。

3.  **`Has` メソッド**:
    このメソッドは、`Addr` インスタンスが、引数で指定されたマスク内の「いずれかの」要素を持っている場合に `true` を返します。これは、アドレスが特定のカテゴリに属するかどうかを大まかに判定する際に便利です。例えば、`addr.Has(addr.Register | addr.Symbol)` は、アドレスがレジスタまたはシンボルのいずれかを含んでいれば `true` を返します。

4.  **`Is` メソッド**:
    このメソッドは、`Addr` インスタンスが、引数で指定されたマスク内の要素を「正確に」持っている場合に `true` を返します。つまり、マスクで指定された要素はすべて存在し、マスクで指定されていない要素はすべて存在しない場合にのみ `true` を返します。これは、特定のアドレッシングモード（例: 「レジスタとオフセットのみを持つアドレス」）を厳密に識別する際に非常に重要です。例えば、`addr.Is(addr.Register | addr.Offset)` は、アドレスがレジスタとオフセットを両方持ち、かつそれ以外の要素（シンボル、即値など）を持たない場合にのみ `true` を返します。

この `addr` パッケージの導入により、Goアセンブラのコードは、アドレスの解析と処理において、より構造化され、エラーを起こしにくく、保守しやすいものになります。アセンブラのフロントエンドはアセンブリコードを `Addr` 型に変換し、バックエンドは `Addr` 型のインスタンスを検査して適切な機械語命令を生成する、という明確な役割分担が可能になります。
