## 元コミット内容

このコミットの目的は、`README.md` ファイルを更新し、Goプロジェクトのイシュートラッカーの適切な使用方法を明確にすることです。具体的には、イシュートラッカーがバグ報告と提案のみを目的としていることを強調し、質問のための直接リンクを削除しています。代わりに、質問があるユーザーを `golang-nuts` メーリングリストと新しいフォーラムに誘導する文言が追加されました。これは、イシュートラッカーが質問のために誤用される頻度が高かったため、その負担を軽減し、本来の目的のために効率的に機能させるための変更です。

## 変更の背景

Goプロジェクトのイシュートラッカーは、本来、バグの報告や新機能の提案といった、プロジェクトの改善に直接関わる議論のために設計されています。しかし、多くのユーザーがプログラミングに関する一般的な質問や使用方法に関する疑問をイシュートラッカーに投稿していました。これにより、イシュートラッカーが本来の目的から逸脱し、開発者やメンテナが重要なバグや提案を見落とす可能性が高まり、管理が困難になるという問題が発生していました。

このコミットは、このようなイシュートラッカーの誤用を減らし、コミュニティの適切なコミュニケーションチャネルへの誘導を強化することを目的としています。直接的なリンクを削除することで、安易な質問投稿を防ぎ、本当に報告すべき問題がある場合にのみイシュートラッカーが利用されるように促しています。また、質問のための適切な場所として `golang-nuts` と新しいフォーラムを明示することで、ユーザーがより早く、より適切な場所で回答を得られるように配慮されています。

## 前提知識の解説

*   **README.md**: ソフトウェアプロジェクトのルートディレクトリに配置される慣習的なファイルで、プロジェクトの概要、インストール方法、使用方法、貢献方法、ライセンス情報など、プロジェクトに関する基本的な情報を提供します。GitHubなどのプラットフォームでは、リポジトリのトップページに自動的に表示されます。
*   **イシュートラッカー (Issue Tracker)**: ソフトウェア開発において、バグ、機能リクエスト、タスクなどを追跡・管理するためのシステムです。Goプロジェクトでは、主にバグ報告と公式な提案（プロポーザル）の議論のために使用されます。
*   **golang-nuts**: Goプログラミング言語に関する一般的な議論、質問、情報交換が行われる公式のGoogleグループ（メーリングリスト）です。Goコミュニティの主要なコミュニケーションチャネルの一つであり、幅広いトピックが扱われます。
*   **forum.golangbridge.org**: Goコミュニティによって運営されているフォーラムで、`golang-nuts` と同様にGoに関する質問や議論が行われます。より現代的なフォーラム形式を提供し、`golang-nuts` と並んでGoユーザーのサポートチャネルとして機能しています。
*   **プルリクエスト (Pull Request)**: Gitベースのバージョン管理システム（GitHubなど）において、コードの変更を提案し、プロジェクトのメインブランチにマージしてもらうための仕組みです。Goプロジェクトでは、独自のコードレビューシステム（GerritベースのGo-Review）を使用しており、GitHubのプルリクエストは直接受け付けていません。この点も `README.md` で明記されています。

## 技術的詳細

このコミットは、`README.md` ファイルの内容を直接変更することで、ユーザーへの情報提供の仕方を改善しています。具体的な変更点は以下の通りです。

1.  **イシュートラッカーへの直接リンクの削除**: 以前は `Please report issues here: https://golang.org/issue/new` という形でイシュートラッカーへの直接リンクが提供されていました。このリンクを削除することで、ユーザーが安易にイシュートラッカーにアクセスして質問を投稿するのを防ぎます。
2.  **イシュートラッカーの目的の明確化**: `##### Please note that we do not use pull requests.` という既存の文言が `##### Note that we do not accept pull requests and that we use the issue tracker for bug reports and proposals only.` と変更されました。これにより、イシュートラッカーが「バグ報告と提案のみ」に使用されるべきであることが明確に強調されます。
3.  **質問のための適切なチャネルの提示**: 上記の変更された文言に続けて、`Please ask questions on https://forum.golangbridge.org or https://groups.google.com/forum/#!forum/golang-nuts.` という一文が追加されました。これにより、質問があるユーザーは `forum.golangbridge.org` または `golang-nuts` メーリングリストを利用するよう明確に誘導されます。

これらの変更は、ドキュメントの記述を修正するだけであり、Go言語のランタイムやコンパイラなどのコードベース自体には影響を与えません。しかし、プロジェクトの運用とコミュニティ管理の観点からは非常に重要な変更です。
