## 変更の背景

このコミットの背景は、Go 1.4の正式リリースに伴う公式ドキュメントの更新です。Go言語は定期的に新しいバージョンをリリースしており、それぞれのリリースには言語仕様の変更、ランタイムの改善、ツールの追加、プラットフォームサポートの拡充などが含まれます。ユーザーが最新のGoバージョンに関する情報を容易に参照できるように、リリースノートへのリンクを含む形で `release.html` ファイルを更新する必要がありました。

Go 1.4は2014年12月10日にリリースされたGo言語の5番目の主要な安定版リリースであり、Go 1.3から6ヶ月後に登場しました。このリリースは主に実装作業に焦点を当て、ガベージコレクタの改善や、将来のリリースでの完全な並行ガベージコレクタの準備を進めました。

## 前提知識の解説

このコミットを理解するためには、以下の前提知識が役立ちます。

*   **Go言語のリリースサイクル**: Go言語は通常、半年に一度のペースで主要なリリースを行います。各リリースでは、言語の安定性と後方互換性を維持しつつ、新機能の追加やパフォーマンスの改善が行われます。
*   **Goのドキュメント構造**: Goプロジェクトのドキュメントは、`doc` ディレクトリ以下に配置されており、HTML形式で提供されることが多いです。`release.html` のようなファイルは、過去のリリースに関する概要やリンクをまとめる役割を担っています。
*   **Go 1.4の主要な変更点**:
    *   **言語の変更**: `for-range` ループのマイナーな変更（値、ループインデックス、マップキーを割り当てずにイテレートできるようになった）。ポインタへのポインタに対するメソッド呼び出しが言語仕様に従って許可されなくなった（後方互換性のない変更）。
    *   **ランタイムの改善**: スタックが連続的になり、必要に応じて再割り当てされるようになったことで、「ホットスタックスプリット」問題が解消されました。ガベージコレクタも改善されました。
    *   **新しいツール**: `go` コマンドがビルド時のソースコード生成をサポートするようになり、コンパイル前にツール実行を自動化するための新しい `go generate` サブコマンドが追加されました。
    *   **プラットフォームサポート**: Android上のARMプロセッサが正式にサポートされ、Goコードを使用したシンプルなAndroidアプリケーションの作成が可能になりました。Native Client (NaCl) のサポートもARMに拡張され、Plan 9のAMD64サポートも追加されました。
    *   **互換性**: 以前のリリースと同様に、Go 1.4も互換性の約束を維持しており、ほとんどの既存プログラムは変更なしでコンパイルおよび実行できると予想されました。
    *   **パフォーマンス**: ほとんどのプログラムはGo 1.3と比較して同等かわずかに高速に実行されると予想されましたが、広範な変更のため一部でわずかな速度低下が発生する可能性がありました。
    *   `runtime/race` パッケージがFreeBSDをサポートし、`go command` の `-race` フラグがFreeBSDで利用可能になりました。
    *   `sync/atomic` パッケージに、任意の型の効率的なアトミックロードとストアのための新しい `Value` 型が導入されました。

## 技術的詳細

このコミット自体は、Go言語のランタイムやコンパイラに直接的な技術的変更を加えるものではなく、純粋にドキュメントの更新です。しかし、その背景にあるGo 1.4のリリースは、Go言語の進化において重要なマイルストーンでした。

`doc/devel/release.html` ファイルは、Goの各バージョンのリリース情報を時系列でまとめる役割を担っています。このコミットでは、既存のGo 1.3のセクションの上に、Go 1.4の新しいセクションが追加されました。追加されたHTMLスニペットは以下の通りです。

```html
<h2 id="go1.4">go1.4 (released 2014/12/10)</h2>

<p>
Go 1.4 is a major release of Go.
Read the <a href="/doc/go1.4">Go 1.4 Release Notes</a> for more information.
</p>
```

この変更により、ユーザーは `release.html` を閲覧するだけで、Go 1.4がリリースされたこと、それが主要なリリースであること、そして詳細なリリースノートへの直接リンクがあることを知ることができます。これは、Goプロジェクトにおける情報提供の標準的なプラクティスに従ったものです。

## コアとなるコードの解説

追加されたコードは標準的なHTMLマークアップです。

*   `<h2 id="go1.4">go1.4 (released 2014/12/10)</h2>`: これは、Go 1.4リリースに関するセクションの見出しを定義しています。`id="go1.4"` は、ページ内の特定のセクションへのアンカーリンクを可能にします。リリース日も明記されています。
*   `<p>Go 1.4 is a major release of Go. Read the <a href="/doc/go1.4">Go 1.4 Release Notes</a> for more information.</p>`: これは段落を定義しており、Go 1.4が主要なリリースであること、そして `/doc/go1.4` へのハイパーリンクを通じてGo 1.4のリリースノートを参照するよう促しています。このリンクは、Goの公式ウェブサイト上でGo 1.4のリリースノートページに直接誘導します。

この変更は、Goのドキュメントが常に最新のリリース情報を反映していることを保証するための、シンプルかつ効果的な方法です。
