# [インデックス 27128] ファイルの概要

このコミットは、Goコンパイラ (`cmd/compile`) における組み込み関数 (builtin functions) の型ノードの処理に関する最適化とリファクタリングを目的としています。具体的には、型のコピー処理を効率化し、関連する二つの関数 `deep` と `substAny` を統合することで、コードの簡素化とパフォーマンスの向上を図っています。

## 変更の背景

Goコンパイラは、プログラムの型情報を内部的に表現するために「型ノード (type nodes)」を使用します。組み込み関数（例: `make`, `new`, `len`, `cap` など）は、その引数の型に応じて異なる具体的な型を持つことがあります。例えば、`make([]int, 10)` と `make(map[string]int)` では、`make` 関数自体は同じですが、その結果の型は異なります。

以前の実装では、これらの組み込み関数の型を処理する際に、不必要に多くの型ノードがコピーされていた可能性があります。特に、`substAny` 関数は、ジェネリックな型プレースホルダー（`TANY`）を具体的な型に置き換える役割を担っていましたが、このプロセスで型の構造全体を深くコピーする `deep` 関数が常に呼び出されていました。

この「常に深くコピーする」というアプローチは、変更がない部分まで含めてコピーするため、メモリ使用量の増加やコンパイル時間のオーバーヘッドを引き起こす可能性がありました。このコミットの目的は、この非効率性を解消し、必要な部分のみをコピーすることで、コンパイラのパフォーマンスを向上させることにあります。また、`deep` と `substAny` の機能が密接に関連しているため、これらを統合することでコードの重複を排除し、保守性を高めることも意図されています。

## 前提知識の解説

このコミットを理解するためには、以下のGoコンパイラの内部構造と概念に関する知識が必要です。

1.  **型ノード (Type Nodes)**: Goコンパイラは、プログラム内のすべての型（プリミティブ型、構造体、配列、マップ、関数など）を抽象構文木 (AST) の一部として表現します。これらの表現が「型ノード」です。各型ノードは、その型の種類 (`Etype`) や、それが参照する他の型（例: ポインタの指す型、配列の要素型、マップのキー型と値型、関数の引数型と戻り値型）へのポインタを持ちます。

2.  **`Etype` (Element Type)**: 型ノードがどのような種類の型を表すかを示す列挙型です。例えば、`TANY` は任意の型を表すプレースホルダー、`TPTR32`/`TPTR64` はポインタ型、`TCHAN` はチャネル型、`TARRAY` は配列型、`TMAP` はマップ型、`TFUNC` は関数型、`TSTRUCT` は構造体型などを表します。

3.  **`TANY` 型**: Goコンパイラの内部で、ジェネリックな操作や型推論の過程で使用されるプレースホルダー型です。組み込み関数のように、引数の型によって結果の型が変わるようなケースで、一時的に「任意の型」として扱われます。その後、具体的な型情報が判明した際に、この `TANY` が実際の型に置き換えられます。

4.  **型情報のコピー**: コンパイラが型情報を操作する際、元の型構造を破壊しないように、そのコピーを作成することがよくあります。特に、型推論や型変換の過程で、元の型定義を変更せずに新しい型を生成する必要がある場合に重要です。

5.  **`substAny` 関数**: この関数は、型構造を走査し、`TANY` 型のプレースホルダーを、引数として渡された具体的な型に置き換える役割を担っていました。これは、組み込み関数が具体的な型でインスタンス化される際に必要となる処理です。

6.  **`deep` 関数**: この関数は、与えられた型ノードのディープコピー（深層コピー）を作成する役割を担っていました。つまり、型ノードだけでなく、それが参照するすべてのサブタイプ（例: ポインタの指す型、配列の要素型など）も再帰的にコピーします。

7.  **`Type.Copyany` フィールド**: 以前の `Type` 構造体にあったフィールドで、`TANY` 型がコピー可能であるかどうかを示すフラグとして使用されていた可能性があります。このコミットで不要と判断され削除されました。

## 技術的詳細

このコミットの核心は、Goコンパイラの型システムにおける効率的な型置換とコピーのメカニズムにあります。

以前の `substAny` 関数は、`TANY` 型を具体的な型に置き換える際に、常に `deep` 関数を呼び出して型構造全体のディープコピーを作成していました。これは、型構造の一部しか変更されない場合でも、すべてのサブタイプを再帰的にコピーするという非効率なアプローチでした。

新しい実装では、`substAny` 関数が `deep` 関数の機能を吸収し、単一の関数として動作します。この新しい `substAny` は、型構造を走査しながら、実際に変更が必要な部分（`TANY` 型の置換や、サブタイプが変更された場合）のみをコピーするように最適化されています。

具体的には、`substAny` は引数として `*Type` (型ノードへのポインタ) と `*[]*Type` (置換に使用する型スライスのポインタ) を受け取ります。そして、再帰的に型構造を走査し、以下のロジックで処理を行います。

-   **`TANY` 型の場合**: `types` スライスから次の型を取り出し、現在の `TANY` 型をその型に置き換えます。この際、新しい型ノードが返されます。
-   **ポインタ、チャネル、配列型 (`TPTR32`, `TPTR64`, `TCHAN`, `TARRAY`)**: これらの型は単一のサブタイプ (`t.Type`) を持ちます。`substAny` を再帰的に呼び出してサブタイプを処理し、もしサブタイプが変更された場合のみ、現在の型ノードをコピーし、その `Type` フィールドを更新します。変更がなければ、元の型ノードをそのまま返します。
-   **マップ型 (`TMAP`)**: キー型 (`t.Down`) と値型 (`t.Type`) の二つのサブタイプを持ちます。それぞれを `substAny` で処理し、どちらか一方でも変更があれば、現在の型ノードをコピーして `Down` と `Type` フィールドを更新します。
-   **関数型 (`TFUNC`)**: レシーバ型 (`t.Recvs()`)、引数型 (`t.Params()`)、戻り値型 (`t.Results()`) の複数のサブタイプを持ちます。それぞれを `substAny` で処理し、いずれか一つでも変更があれば、現在の関数型ノードをコピーし、対応するフィールドを更新します。特に、`Recvs()` や `Results()` が変更されていない場合でも、`Copy()` を呼び出して新しいスライスを作成し、元のスライスへの参照を断ち切ることで、意図しない副作用を防いでいます。
-   **構造体型 (`TSTRUCT`)**: 構造体の各フィールド (`t.FieldSlice()`) を走査し、それぞれのフィールド型を `substAny` で処理します。いずれかのフィールド型が変更された場合、構造体型ノードをコピーし、変更されたフィールドを持つ新しいフィールドスライスを設定します。この際、変更されていないフィールドも `Copy()` して新しいインスタンスを作成することで、元のフィールドへの参照を断ち切ります。
-   **その他の型**: 変更の必要がないため、元の型ノードをそのまま返します。

この「変更があった場合のみコピーする」という戦略は、コンパイラのメモリフットプリントを削減し、型操作のパフォーマンスを向上させます。また、`Type.Copyany` フィールドは、`TANY` 型のコピー動作を制御するために使用されていた可能性がありますが、新しい `substAny` のロジックでは不要になったため削除されました。

## コアとなるコードの解説

### `substAny` 関数の新しい実装 (`src/cmd/compile/internal/gc/subr.go`)

```go
// substAny walks t, replacing instances of "any" with successive
// elements removed from types.  It returns the substituted type.
func substAny(t *Type, types *[]*Type) *Type {
	if t == nil {
		return nil
	}

	switch t.Etype {
	default:
		// Leave the type unchanged.

	case TANY:
		if len(*types) == 0 {
			Fatalf("substArgTypes: not enough argument types")
		}
		t = (*types)[0] // TANYを具体的な型に置き換え
		*types = (*types)[1:]

	case TPTR32, TPTR64, TCHAN, TARRAY, TFIELD:
		elem := substAny(t.Type, types) // サブタイプを再帰的に処理
		if elem != t.Type { // サブタイプが変更された場合のみ
			t = t.Copy() // 現在の型ノードをコピー
			t.Type = elem // コピーした型ノードのサブタイプを更新
		}

	case TMAP:
		key := substAny(t.Down, types)
		val := substAny(t.Type, types)
		if key != t.Down || val != t.Type { // キー型または値型が変更された場合のみ
			t = t.Copy()
			t.Down = key
			t.Type = val
		}

	case TFUNC:
		// レシーバ、引数、戻り値の各リストを処理
		// いずれか変更があれば、関数型ノードをコピーし、リストを更新
		recvList := t.Recvs()
		paramList := t.Params()
		resultList := t.Results()

		newRecvList := substAny(recvList, types)
		newParamList := substAny(paramList, types)
		newResultList := substAny(resultList, types)

		if newRecvList != recvList || newParamList != paramList || newResultList != resultList {
			// Note that this code has to be aware of the
			// representation underlying Recvs/Results/Params.
			if newRecvList == recvList {
				newRecvList = newRecvList.Copy() // 変更がなくても新しいスライスを作成
			}
			if newResultList == resultList {
				newResultList = newResultList.Copy() // 変更がなくても新しいスライスを作成
			}
			t = t.Copy()
			*t.RecvsP() = newRecvList
			*t.ResultsP() = newResultList
			*t.ParamsP() = newParamList
		}

	case TSTRUCT:
		// 構造体のフィールドを処理
		fields := t.FieldSlice()
		changed := false
		var newFields [8]*Type // 組み込み関数用に十分なサイズ
		for i, f := range fields {
			nf := substAny(f, types) // フィールド型を再帰的に処理
			if nf != f { // フィールド型が変更された場合
				if !changed {
					// 最初の変更の場合、それまでのフィールドをコピー
					for j := 0; j < i; j++ {
						newFields[j] = fields[j].Copy()
					}
				}
				changed = true
			} else if changed {
				// 既に変更があった場合、変更されていないフィールドもコピー
				nf = f.Copy()
			}
			newFields[i] = nf
		}
		if changed { // いずれかのフィールドが変更された場合
			t = t.Copy()
			t.SetFields(newFields[:len(fields)]) // 新しいフィールドスライスを設定
		}
	}

	return t // 変更された、または元の型ノードを返す
}
```

この新しい `substAny` 関数は、`deep` 関数の役割を統合し、型構造を再帰的に走査しながら、実際に変更が必要な部分（`TANY` の置換やサブタイプの変更）のみを効率的にコピーします。これにより、不必要なメモリ割り当てとコピー処理が削減され、コンパイラのパフォーマンスが向上します。

5.  **`substAny` 関数**: この関数は、型構造を走査し、`TANY` 型のプレースホルダーを、引数として渡された具体的な型に置き換える役割を担っていました。これは、組み込み関数が具体的な型でインスタンス化される際に必要となる処理です。

6.  **`deep` 関数**: この関数は、与えられた型ノードのディープコピー（深層コピー）を作成する役割を担っていました。つまり、型ノードだけでなく、それが参照するすべてのサブタイプ（例: ポインタの指す型、配列の要素型など）も再帰的にコピーします。

7.  **`Type.Copyany` フィールド**: 以前の `Type` 構造体にあったフィールドで、`TANY` 型がコピー可能であるかどうかを示すフラグとして使用されていた可能性があります。このコミットで不要と判断され削除されました。

## 技術的詳細

このコミットの核心は、Goコンパイラの型システムにおける効率的な型置換とコピーのメカニズムにあります。

以前の `substAny` 関数は、`TANY` 型を具体的な型に置き換える際に、常に `deep` 関数を呼び出して型構造全体のディープコピーを作成していました。これは、型構造の一部しか変更されない場合でも、すべてのサブタイプを再帰的にコピーするという非効率なアプローチでした。

新しい実装では、`substAny` 関数が `deep` 関数の機能を吸収し、単一の関数として動作します。この新しい `substAny` は、型構造を走査しながら、実際に変更が必要な部分（`TANY` 型の置換や、サブタイプが変更された場合）のみをコピーするように最適化されています。

具体的には、`substAny` は引数として `*Type` (型ノードへのポインタ) と `*[]*Type` (置換に使用する型スライスのポインタ) を受け取ります。そして、再帰的に型構造を走査し、以下のロジックで処理を行います。

-   **`TANY` 型の場合**: `types` スライスから次の型を取り出し、現在の `TANY` 型をその型に置き換えます。この際、新しい型ノードが返されます。
-   **ポインタ、チャネル、配列型 (`TPTR32`, `TPTR64`, `TCHAN`, `TARRAY`)**: これらの型は単一のサブタイプ (`t.Type`) を持ちます。`substAny` を再帰的に呼び出してサブタイプを処理し、もしサブタイプが変更された場合のみ、現在の型ノードをコピーし、その `Type` フィールドを更新します。変更がなければ、元の型ノードをそのまま返します。
-   **マップ型 (`TMAP`)**: キー型 (`t.Down`) と値型 (`t.Type`) の二つのサブタイプを持ちます。それぞれを `substAny` で処理し、どちらか一方でも変更があれば、現在の型ノードをコピーして `Down` と `Type` フィールドを更新します。
-   **関数型 (`TFUNC`)**: レシーバ型 (`t.Recvs()`)、引数型 (`t.Params()`)、戻り値型 (`t.Results()`) の複数のサブタイプを持ちます。それぞれを `substAny` で処理し、いずれか一つでも変更があれば、現在の関数型ノードをコピーし、対応するフィールドを更新します。特に、`Recvs()` や `Results()` が変更されていない場合でも、`Copy()` を呼び出して新しいスライスを作成し、元のスライスへの参照を断ち切ることで、意図しない副作用を防いでいます。
-   **構造体型 (`TSTRUCT`)**: 構造体の各フィールド (`t.FieldSlice()`) を走査し、それぞれのフィールド型を `substAny` で処理します。いずれかのフィールド型が変更された場合、構造体型ノードをコピーし、変更されたフィールドを持つ新しいフィールドスライスを設定します。この際、変更されていないフィールドも `Copy()` して新しいインスタンスを作成することで、元のフィールドへの参照を断ち切ります。
-   **その他の型**: 変更の必要がないため、元の型ノードをそのまま返します。

この「変更があった場合のみコピーする」という戦略は、コンパイラのメモリフットプリントを削減し、型操作のパフォーマンスを向上させます。また、`Type.Copyany` フィールドは、`TANY` 型のコピー動作を制御するために使用されていた可能性がありますが、新しい `substAny` のロジックでは不要になったため削除されました。

## コアとなるコードの解説

### `substAny` 関数の新しい実装 (`src/cmd/compile/internal/gc/subr.go`)

```go
// substAny walks t, replacing instances of "any" with successive
// elements removed from types.  It returns the substituted type.
func substAny(t *Type, types *[]*Type) *Type {
	if t == nil {
		return nil
	}

	switch t.Etype {
	default:
		// Leave the type unchanged.

	case TANY:
		if len(*types) == 0 {
			Fatalf("substArgTypes: not enough argument types")
		}
		t = (*types)[0] // TANYを具体的な型に置き換え
		*types = (*types)[1:]

	case TPTR32, TPTR64, TCHAN, TARRAY, TFIELD:
		elem := substAny(t.Type, types) // サブタイプを再帰的に処理
		if elem != t.Type { // サブタイプが変更された場合のみ
			t = t.Copy() // 現在の型ノードをコピー
			t.Type = elem // コピーした型ノードのサブタイプを更新
		}

	case TMAP:
		key := substAny(t.Down, types)
		val := substAny(t.Type, types)
		if key != t.Down || val != t.Type { // キー型または値型が変更された場合のみ
			t = t.Copy()
			t.Down = key
			t.Type = val
		}

	case TFUNC:
		// レシーバ、引数、戻り値の各リストを処理
		// いずれか変更があれば、関数型ノードをコピーし、リストを更新
		recvList := t.Recvs()
		paramList := t.Params()
		resultList := t.Results()

		newRecvList := substAny(recvList, types)
		newParamList := substAny(paramList, types)
		newResultList := substAny(resultList, types)

		if newRecvList != recvList || newParamList != paramList || newResultList != resultList {
			// Note that this code has to be aware of the
			// representation underlying Recvs/Results/Params.
			if newRecvList == recvList {
				newRecvList = newRecvList.Copy() // 変更がなくても新しいスライスを作成
			}
			if newResultList == resultList {
				newResultList = newResultList.Copy() // 変更がなくても新しいスライスを作成
			}
			t = t.Copy()
			*t.RecvsP() = newRecvList
			*t.ResultsP() = newResultList
			*t.ParamsP() = newParamList
		}

	case TSTRUCT:
		// 構造体のフィールドを処理
		fields := t.FieldSlice()
		changed := false
		var newFields [8]*Type // 組み込み関数用に十分なサイズ
		for i, f := range fields {
			nf := substAny(f, types) // フィールド型を再帰的に処理
			if nf != f { // フィールド型が変更された場合
				if !changed {
					// 最初の変更の場合、それまでのフィールドをコピー
					for j := 0; j < i; j++ {
						newFields[j] = fields[j].Copy()
					}
				}
				changed = true
			} else if changed {
				// 既に変更があった場合、変更されていないフィールドもコピー
				nf = f.Copy()
			}
			newFields[i] = nf
		}
		if changed { // いずれかのフィールドが変更された場合
			t = t.Copy()
			t.SetFields(newFields[:len(fields)]) // 新しいフィールドスライスを設定
		}
	}

	return t // 変更された、または元の型ノードを返す
}
```

この新しい `substAny` 関数は、`deep` 関数の役割を統合し、型構造を再帰的に走査しながら、実際に変更が必要な部分（`TANY` の置換やサブタイプの変更）のみを効率的にコピーします。これにより、不必要なメモリ割り当てとコピー処理が削減され、コンパイラのパフォーマンスが向上します。
