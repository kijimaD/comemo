## 変更の背景

Go言語は、後方互換性を非常に重視しています。新しいリリースでAPIを追加する際、既存のコードが壊れないように細心の注意が払われます。`api/next.txt` ファイルは、この互換性ポリシーを維持するための重要なメカニズムの一部です。このファイルには、次のメジャーリリースで公開される予定のすべての新しいAPI要素がリストアップされます。これにより、開発者は将来の変更を事前に確認し、ツールやリンターなどが新しいAPIに対応できるよう準備する機会が与えられます。

このコミットは、Go開発チームが次期リリースに向けて様々な機能強化や改善を進める中で、それらの変更に伴って公開されるAPIを正式に記録するプロセスの一環として行われました。特に、`go/exact` や `go/types` といったコンパイラやツール関連のパッケージに多くのAPIが追加されていることから、Goのツールチェインの機能強化が活発に行われていた時期であることが伺えます。また、`crypto` や `math/big` といったパッケージの拡張は、より高度な暗号化機能や数値計算機能への需要に応えるものです。

## 前提知識の解説

### Go言語のAPI互換性ポリシー

Go言語は「Go 1 compatibility guarantee」という強力な互換性保証を持っています。これは、Go 1.xのリリース間で、既存のGoプログラムが新しいGoバージョンでコンパイルされ、実行されることを保証するものです。この保証は、Goの標準ライブラリの公開APIにも適用されます。新しいAPIの追加は許可されますが、既存のAPIの変更や削除は原則として行われません。`api/next.txt` は、この互換性保証を維持しつつ、新しいAPIを計画的に導入するための文書化プロセスの一部です。

### `api/next.txt` と `api/go1.txt`

*   **`api/go1.txt`**: Go 1.xの各リリースで安定していると見なされる公開APIのリストです。このファイルに記載されているAPIは、Go 1の互換性保証の対象となります。
*   **`api/next.txt`**: 次のメジャーリリース（例: Go 1.xからGo 1.(x+1)）で導入される予定の新しいAPIのリストです。このファイルに記載されたAPIは、まだ安定版とは見なされず、変更される可能性がありますが、開発者やツール作成者はこれを見て将来の変更に備えることができます。

### Goの標準ライブラリの構造

Goの標準ライブラリは、様々な機能を提供する多数のパッケージで構成されています。これらのパッケージは、ファイルシステム操作、ネットワーク通信、暗号化、データ構造、テキスト処理など、幅広いタスクをカバーします。各パッケージは、公開された型（`type`）、関数（`func`）、メソッド（`method`）、定数（`const`）、変数（`var`）を通じて機能を提供します。

### DWARF (Debugging With Arbitrary Record Formats)

`debug/dwarf` パッケージは、DWARFデバッグ情報フォーマットを解析するためのGoのライブラリです。DWARFは、コンパイルされたプログラムのソースコードレベルでのデバッグを可能にするためのメタデータ（変数名、型情報、行番号とアドレスのマッピングなど）を記述するための標準フォーマットです。このコミットで追加された `LineReader` 関連のAPIは、実行可能ファイル内のコードアドレスとソースコードの行番号のマッピングを効率的に読み取るための機能を提供します。

### Goの抽象構文木 (AST) と型情報

`go/ast` パッケージはGoプログラムの抽象構文木（AST）を表現するための型を提供します。`go/types` パッケージは、Goプログラムの型チェックとセマンティック分析を行うための機能を提供します。これらは、Goのコンパイラ、リンター、IDEなどのツールがGoコードを理解し、分析するために不可欠なパッケージです。このコミットでこれらのパッケージに多数のAPIが追加されていることは、Goのツールエコシステムの進化を示唆しています。

### 暗号化とTLS

`crypto` パッケージとそのサブパッケージ（`crypto/rsa`, `crypto/tls` など）は、Go言語で暗号化操作やTLS/SSL通信を行うための機能を提供します。このコミットでは、新しい暗号化モードやTLSスイートのサポートが追加されており、セキュリティ機能の強化が図られています。

### 任意精度演算 (`math/big`)

`math/big` パッケージは、任意精度の整数、有理数、浮動小数点数を扱うための機能を提供します。これは、標準のGoの数値型では表現できない非常に大きな数値や、高い精度が要求される計算を行う場合に利用されます。このコミットで `Float` 型に多くのメソッドが追加されていることは、浮動小数点数演算の機能が強化されたことを示しています。

## 技術的詳細

このコミットは、Goの標準ライブラリに以下の主要なAPI変更を導入しています。

### `archive/zip`

*   `method (*Writer) SetOffset(int64)`: ZIPアーカイブの書き込み時に、次のファイルエントリのオフセットを明示的に設定する機能。これは、ZIP64形式など、特定の高度なZIPアーカイブ操作で必要となる場合があります。

### `bufio`

*   `method (*Reader) Discard(int) (int, error)`: `bufio.Reader` から指定されたバイト数を読み飛ばす（破棄する）機能。これにより、不要なデータを効率的にスキップできます。
*   `method (ReadWriter) Discard(int) (int, error)`: `bufio.ReadWriter` も同様に `Discard` メソッドをサポートします。

### `bytes`

*   `method (*Buffer) Cap() int`: `bytes.Buffer` の現在の容量（メモリ割り当てサイズ）を返す機能。
*   `method (*Reader) Size() int64`: `bytes.Reader` が読み取る元のバイトスライスの全長を返す機能。

### `crypto`

*   `type Decrypter interface { Decrypt, Public }`: 復号化操作を行うための新しいインターフェース。
    *   `Decrypt(io.Reader, []uint8, DecrypterOpts) ([]uint8, error)`: データを復号化するメソッド。
    *   `Public() PublicKey`: 対応する公開鍵を返すメソッド。
*   `type DecrypterOpts interface {}`: 復号化オプションを渡すための空のインターフェース。

### `crypto/elliptic`

*   `type CurveParams struct, Name string`: 楕円曲線パラメータ構造体に `Name` フィールドが追加され、曲線の名前を識別できるようになります。

### `crypto/rsa`

*   `method (*PrivateKey) Decrypt(io.Reader, []uint8, crypto.DecrypterOpts) ([]uint8, error)`: RSA秘密鍵による復号化メソッドが、新しい `crypto.DecrypterOpts` インターフェースを受け入れるように変更されました。これにより、PKCS#1 v1.5やOAEPなどの異なるパディングスキームに対応するためのオプションを柔軟に渡せるようになります。
*   `type OAEPOptions struct`: OAEP (Optimal Asymmetric Encryption Padding) パディングのためのオプション構造体。
    *   `Hash crypto.Hash`: 使用するハッシュ関数。
    *   `Label []uint8`: OAEPラベル。
*   `type PKCS1v15DecryptOptions struct`: PKCS#1 v1.5パディングのためのオプション構造体。
    *   `SessionKeyLen int`: セッション鍵の長さ。

### `crypto/tls`

*   `const TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384 = 49196`: 新しいTLS暗号スイートの定数。ECDHE-ECDSA鍵交換、AES-256-GCM暗号化、SHA384ハッシュを使用。
*   `const TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384 = 49200`: 新しいTLS暗号スイートの定数。ECDHE-RSA鍵交換、AES-256-GCM暗号化、SHA384ハッシュを使用。
これらの追加は、より強力で現代的な暗号化アルゴリズムのサポートを強化し、TLS通信のセキュリティを向上させます。

### `crypto/x509/pkix`

*   `type Name struct, ExtraNames []AttributeTypeAndValue`: X.509証明書の識別名構造体に `ExtraNames` フィールドが追加され、追加の属性を格納できるようになります。

## コアとなるコードの解説

このコミットは、Goの標準ライブラリのAPI定義ファイルである `api/next.txt` に、新しいAPI要素の行を追加するものです。このファイルは、GoのビルドシステムによってGoの公開APIの変更を追跡するために使用されます。

追加された各行は、以下のフォーマットに従っています。

`pkg <パッケージパス>, <要素の種類> <要素名> [追加情報]`

例:
*   `pkg archive/zip, method (*Writer) SetOffset(int64)`: `archive/zip` パッケージの `*Writer` 型に `SetOffset` メソッドが追加されたことを示します。
*   `pkg crypto, type Decrypter interface { Decrypt, Public }`: `crypto` パッケージに `Decrypter` というインターフェースが追加され、そのインターフェースが `Decrypt` と `Public` というメソッドを持つことを示します。
*   `pkg go/types, const Bool = 1`: `go/types` パッケージに `Bool` という定数が追加され、その値が `1` であることを示します。

このファイルへの追加は、対応するGoのソースコードファイルに実際にこれらのAPIが実装された後に、APIの公開を正式に宣言するために行われます。したがって、このコミット自体は機能的な変更をもたらすものではなく、GoのAPI進化の記録と互換性保証の維持のための文書化ステップです。
