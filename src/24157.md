# [インデックス 24157] ファイルの概要

このコミットは、Go言語のパッケージ管理ツールである `go get` コマンドにおいて、`code.google.com` からパッケージを取得しようとした際に、そのサービスが閉鎖されることを警告する機能を追加するものです。これにより、ユーザーは将来的に発生する可能性のあるパッケージ取得の失敗に事前に気づき、適切な対応を取ることを促されます。

## 変更の背景

この変更の背景には、Googleが提供していたオープンソースプロジェクトホスティングサービスである `code.google.com` の閉鎖があります。

*   **2015年3月:** Googleは `code.google.com` の閉鎖を発表しました。これは、GitHubなどのよりモダンなプラットフォームへの移行を促すものでした。
*   **2015年8月24日:** `code.google.com` は新しいプロジェクトの更新を受け付けなくなりました。
*   **2016年1月:** サービスは完全に閉鎖されました。

Go言語の初期の段階では、多くのGoパッケージが `code.google.com` 上でホストされており、`go get` コマンドもこれらのリポジトリから直接パッケージを取得する機能を持っていました。サービス閉鎖の発表後、`go get` を利用して `code.google.com` 上のパッケージを取得しようとするユーザーは、将来的にエラーに直面することが確実でした。

このコミットは、`code.google.com` の閉鎖が完全に実施される前に、ユーザーに対して早期に警告を発することで、影響を受けるプロジェクトの移行を促し、混乱を最小限に抑えることを目的としています。コミットの日付（2015年7月11日）は、閉鎖の発表後、かつ更新停止の前に位置しており、この警告機能が非常にタイムリーに追加されたことを示しています。

## 前提知識の解説

### `go get` コマンド

`go get` はGo言語の公式なパッケージ管理コマンドの一つです。主に以下の機能を提供します。

*   **リモートリポジトリからのパッケージ取得:** 指定されたインポートパスに基づいて、GitHub、Bitbucket、Google Code（当時は）、またはカスタムドメインなどのリモートリポジトリからソースコードをダウンロードします。
*   **依存関係の解決:** 取得したパッケージが依存する他のパッケージも自動的にダウンロードします。
*   **ビルドとインストール:** ダウンロードしたパッケージを `$GOPATH/src` に配置し、実行可能なコマンドであれば `$GOPATH/bin` にインストールします。

`go get` は、Goのモジュールシステムが導入される前のGo 1.11以前のバージョンでは、Goプロジェクトの依存関係管理の中心的なツールでした。

### `code.google.com` とGoエコシステム

`code.google.com` は、Googleが提供していた無料のオープンソースプロジェクトホスティングサービスで、Subversion、Git、Mercurialなどのバージョン管理システムをサポートしていました。Go言語の初期には、多くのGoプロジェクトやライブラリがここにホストされており、Goエコシステムにおいて重要な役割を担っていました。Goの標準ライブラリの一部も、`code.google.com/p/go` のようなパスで参照されることがありました。

### Goのインポートパス

Go言語では、パッケージはインポートパスによって識別されます。インポートパスは、パッケージのソースコードがどこにあるかを示す文字列です。例えば、`"fmt"` は標準ライブラリのフォーマットパッケージを指し、`"github.com/user/repo/package"` はGitHub上の特定のリポジトリ内のパッケージを指します。`go get` コマンドは、このインポートパスを解析して、対応するリモートリポジトリからソースコードを取得します。

## 技術的詳細

このコミットで追加された警告機能は、`go get` コマンドのパッケージダウンロード処理に組み込まれています。

1.  **インポートパスのチェック**: `go get` がパッケージのインポートパスを処理する際に、そのパスが `"code.google.com"` で始まるかどうかを `strings.HasPrefix` 関数を用いて確認します。
2.  **警告メッセージの生成**: インポートパスが `"code.google.com"` で始まる場合、`fmt.Fprintf` を使用して標準エラー出力 (`os.Stderr`) に警告メッセージを出力します。このメッセージは、`code.google.com` が閉鎖されること、および現在のインポートパスが将来的に機能しなくなることをユーザーに伝えます。
3.  **インポートスタックの表示**: 警告メッセージに加えて、現在のパッケージがどのような依存関係を経て `code.google.com` 上のパッケージに到達したかを示す「インポートスタック」も表示されます。これは、`len(*stk) > 1` の条件で判断され、`strings.Join(*stk, "\n\timports ")` を使って整形されます。これにより、ユーザーはどのプロジェクトが `code.google.com` の依存関係を持っているかを特定しやすくなります。
4.  **テストケースの追加**: この警告機能が正しく動作することを確認するために、新しいテストケース `TestIssue10193` が追加されました。このテストは、`go get` が `code.google.com` 上の存在しないリポジトリに対して実行されたときに、期待される警告メッセージが標準エラー出力に表示されることを検証します。

この実装は、`go get` の通常の動作を妨げることなく、ユーザーへの情報提供を目的とした非破壊的な変更です。

## コアとなるコードの解説

### `src/cmd/go/get.go` の変更

`download` 関数は、`go get` コマンドが実際にパッケージをダウンロードする際の中心的なロジックを担っています。この関数内で、パッケージのインポートパス `p.ImportPath` が `code.google.com` で始まるかどうかをチェックする条件分岐が追加されました。

```go
		// Warn that code.google.com is shutting down.  We
		// issue the warning here because this is where we
		// have the import stack.
		if strings.HasPrefix(p.ImportPath, "code.google.com") {
			fmt.Fprintf(os.Stderr, "warning: code.google.com is shutting down; import path %v will stop working\n", p.ImportPath)
			if len(*stk) > 1 {
				fmt.Fprintf(os.Stderr, "warning: package %v\n", strings.Join(*stk, "\n\timports "))
			}
		}
```

*   `strings.HasPrefix(p.ImportPath, "code.google.com")`: 現在処理しているパッケージのインポートパスが `"code.google.com"` で始まるかを判定します。
*   `fmt.Fprintf(os.Stderr, ...)`: 条件が真の場合、標準エラー出力に警告メッセージを出力します。`os.Stderr` を使用することで、通常のプログラム出力とは別に警告が表示され、ユーザーの注意を引きやすくなります。
    *   警告メッセージは「`warning: code.google.com is shutting down; import path %v will stop working`」という形式で、`%v` には該当するインポートパスが入ります。
*   `if len(*stk) > 1`: `stk` はインポートスタック（現在のパッケージがどのパッケージからインポートされたかの履歴）を表します。スタックの長さが1より大きい場合（つまり、現在のパッケージが直接 `go get` で指定されたものではなく、他のパッケージの依存関係としてインポートされた場合）、そのインポートスタックも表示します。
*   `strings.Join(*stk, "\n\timports ")`: インポートスタックを整形して表示します。例えば、「`package A\n\timports B\n\timports C`」のように、依存関係の連鎖を分かりやすく示します。これにより、ユーザーはどのルートで `code.google.com` のパッケージが依存関係として持ち込まれているかを把握できます。

### `src/cmd/go/go_test.go` の変更

`TestIssue10193` テスト関数は、この警告機能が期待通りに動作することを検証します。

```go
func TestIssue10193(t *testing.T) {
	testenv.MustHaveExternalNetwork(t)

	tg := testgo(t)
	defer tg.cleanup()
	tg.parallel()
	tg.tempDir("src")
	tg.setenv("GOPATH", tg.path("."))
	tg.runFail("get", "code.google.com/p/rsc-svn")
	tg.grepStderr("is shutting down", "missed warning about code.google.com")
}
```

*   `testenv.MustHaveExternalNetwork(t)`: このテストが外部ネットワーク接続を必要とすることを示します。`go get` はリモートリポジトリにアクセスするため、ネットワーク接続が必須です。
*   `tg := testgo(t)`: テストヘルパー `testgo` のインスタンスを作成します。これにより、`go` コマンドの実行や環境設定を簡単に行えます。
*   `tg.runFail("get", "code.google.com/p/rsc-svn")`: `go get` コマンドを `code.google.com/p/rsc-svn` というインポートパスで実行します。このリポジトリは存在しないか、アクセスできないことを想定しており、`runFail` はコマンドが失敗することを期待します。重要なのは、失敗する前に警告が出力されることです。
*   `tg.grepStderr("is shutting down", "missed warning about code.google.com")`: `go get` コマンドの標準エラー出力に `"is shutting down"` という文字列が含まれていることを検証します。この文字列は、`code.google.com` 閉鎖に関する警告メッセージの一部です。このチェックにより、警告機能が正しく実装されていることが確認されます。
