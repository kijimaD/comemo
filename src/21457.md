## 変更の背景

このコミットの直接的な背景は、Go 1.5リリースに向けて、新しく追加された`bufio.Reader.Discard`メソッドを公式のリリースノートに含めることです。`bufio.Reader.Discard`メソッド自体は、Goの`bufio`パッケージにおいて、バッファリングされた入力ストリームから指定されたバイト数を効率的にスキップするための機能として導入されました。

従来のGoのI/O操作では、入力ストリームから特定のバイト数を読み飛ばす場合、そのデータを一時的に読み込むためのバッファを確保し、実際に読み込み操作を行う必要がありました。これは、不要なデータであってもメモリの割り当てとコピーが発生し、特に大量のデータをスキップする場合や、パフォーマンスが重視される場面ではオーバーヘッドとなっていました。

`Discard`メソッドは、このような非効率性を解消するために設計されました。このメソッドは、内部バッファのポインタを直接操作することで、実際にデータをメモリにコピーすることなく、指定されたバイト数だけ読み込み位置を進めることができます。これにより、不要なメモリ割り当てやデータコピーのコストを削減し、I/O処理の効率を向上させることが可能になります。

このコミットは、この重要なAPIの追加をGo 1.5のユーザーに周知し、新しい機能の利用を促すためのドキュメンテーション作業の一環です。

## 前提知識の解説

### `bufio`パッケージ

`bufio`パッケージは、Go言語の標準ライブラリ`io`パッケージの上に構築されており、バッファリングされたI/O操作を提供します。これにより、ディスクやネットワークなどの低速なI/Oデバイスとのやり取りにおいて、システムコールの回数を減らし、アプリケーションのパフォーマンスを大幅に向上させることができます。

*   **バッファリングの原理**: `bufio`パッケージの`Reader`型は、内部に一定サイズのメモリバッファを保持します。`Read`メソッドが呼び出されると、一度に多くのデータを基となる`io.Reader`からバッファに読み込み、そのバッファからユーザーにデータを返します。これにより、小さな読み込み要求が頻繁に発生しても、実際のシステムコールはバッファが空になったときにまとめて行われるため、効率が良くなります。

### `bufio.Reader.Discard`メソッドの必要性

`bufio.Reader.Discard(n int)`メソッドは、`bufio.Reader`の内部バッファから`n`バイトを読み飛ばすことを目的としています。このメソッドが導入される前は、以下のような方法でデータをスキップしていました。

1.  **`io.ReadFull`や`io.CopyN`の使用**:
    ```go
    // 不要なデータを読み捨てる例 (Discard導入前)
    buffer := make([]byte, n)
    _, err := io.ReadFull(reader, buffer) // nバイトを読み込み、bufferに格納
    // bufferの内容は不要だが、メモリを消費し、コピーが発生する
    ```
    この方法は、`n`バイト分のバッファを確保し、実際にデータをそのバッファにコピーするため、メモリ割り当てとデータコピーのオーバーヘッドが発生します。特に、スキップするデータ量が大きい場合や、頻繁にスキップ操作を行う場合には、パフォーマンス上のボトルネックとなる可能性がありました。

`Discard`メソッドは、このようなオーバーヘッドを回避し、より効率的にデータをスキップするための手段として導入されました。これは、プロトコルのヘッダーや、特定の区切り文字までの不要なデータを読み飛ばすといったシナリオで特に有用です。

### Go 1.5

このコミットが`go1.5.txt`に追加されていることから、`bufio.Reader.Discard`はGo 1.5のリリースで導入された新機能の一つであることがわかります。Go 1.5は、Go言語の歴史において重要なリリースであり、コンパイラのGo言語での再実装（self-hosting）、ガベージコレクタの改善、並行処理モデルの最適化など、多くの重要な変更と改善が含まれていました。`bufio.Reader.Discard`のようなAPIの追加も、標準ライブラリの機能強化の一環として行われました。

## 技術的詳細

このコミット自体は、Go言語のランタイムやライブラリのコードベースに機能的な変更を加えるものではなく、Go 1.5のリリースノートである`doc/go1.5.txt`に一行を追加するドキュメントの更新です。しかし、このドキュメント更新が指し示す`bufio.Reader.Discard`メソッドの導入は、`bufio`パッケージの効率性を高める上で重要な技術的改善です。

`bufio.Reader.Discard(n int)`メソッドの内部的な動作は、`bufio.Reader`が持つ内部バッファの管理に依存します。`bufio.Reader`は、`Peek`や`ReadByte`などの操作のために、読み込まれたがまだ消費されていないデータをバッファ内に保持しています。`Discard`メソッドが呼び出されると、`n`バイト分だけ、このバッファ内の「読み込み済みだが未消費」データの範囲を前方に移動させます。これにより、実際にデータを読み込んだり、新しいバッファにコピーしたりすることなく、論理的にデータをスキップした状態を作り出します。

もし`n`が現在のバッファ内の利用可能なデータ量よりも大きい場合、`Discard`は基となる`io.Reader`からさらにデータを読み込み、バッファを埋めながら指定されたバイト数をスキップしようとします。この際も、可能な限りバッファの再利用やポインタ操作に留め、不要なメモリ割り当てやコピーを避けるように設計されています。

この最適化は、特にネットワークプロトコル解析やファイルフォーマット解析など、固定長または可変長のヘッダーや不要なフィールドを頻繁にスキップする必要があるアプリケーションにおいて、CPUサイクルとメモリ帯域幅の節約に貢献します。
