## 元コミット内容

Goの`net`パッケージにSolaris向けのCGOサポートを追加します。

## 変更の背景

Go言語はクロスプラットフォーム対応を重視しており、様々なオペレーティングシステム上で動作します。しかし、特定のOSでは、ネットワーク操作などの低レベルな機能を実現するために、そのOS固有のCライブラリやシステムコールを利用する必要がある場合があります。

このコミット以前は、Goの`net`パッケージがSolaris上でCGO（GoとC言語の相互運用機能）を介してネットワーク関連のCライブラリを適切に利用するための設定が不足していた可能性があります。これにより、Solaris環境でのGoプログラムのネットワーク機能が制限されたり、非効率であったりする問題があったと考えられます。

この変更は、Solaris環境におけるGoのネットワーク機能の完全性とパフォーマンスを向上させることを目的としています。特に、ホスト名解決（DNSルックアップなど）において、C言語の`getaddrinfo`関数をSolaris固有の設定で利用できるようにすることで、より堅牢でOSに最適化された動作を実現します。

## 前提知識の解説

### Goの`net`パッケージ

Go言語の標準ライブラリの一部であり、TCP/IP、UDP、DNSルックアップなど、ネットワークプログラミングの基本的な機能を提供します。多くのOSで共通のインターフェースを提供しつつ、内部的にはOS固有の実装を抽象化しています。

### CGO

GoプログラムからC言語のコードを呼び出したり、C言語のライブラリをリンクしたりするためのGoの機能です。Go言語自体が提供しない低レベルなOS機能や、既存のCライブラリを利用する際に不可欠です。CGOを使用するには、Goのソースファイル内に特別なコメントブロック（`import "C"`の直前）でCのコードやリンカフラグを記述します。

### Solaris

Sun Microsystems（現在はOracleが所有）によって開発されたUNIX系オペレーティングシステムです。特にエンタープライズ環境で利用されてきました。他のUNIX系OS（Linux, FreeBSDなど）と同様に、ネットワーク関連のシステムコールやライブラリ（例: `socket`, `nsl`）を提供しますが、その実装やリンカの要件は異なる場合があります。

### `+build`タグ

Goのビルド制約（build constraints）の一つで、Goソースファイルの先頭に記述されます。これにより、特定の環境（OS、アーキテクチャ、Goのバージョンなど）でのみそのファイルをコンパイルするように指定できます。例えば、`+build solaris`はSolaris環境でのみこのファイルをビルドすることを意味します。`+build cgo,!netgo`は、CGOが有効で、かつ`netgo`タグが無効な場合にビルドされることを意味します。`netgo`タグは、Goのネットワークスタックのみを使用し、CGOを使用しない場合に用いられます。

### `LDFLAGS`

リンカフラグ（Linker Flags）の略で、CGOのコンテキストでは、GoプログラムがCライブラリとリンクする際にリンカに渡すオプションを指定します。`-lsocket`はソケットAPIを提供するライブラリ（`libsocket`）をリンクし、`-lnsl`はネットワークサービスライブラリ（`libnsl`、通常はNIS/YPやネームサービス関連の機能を提供）をリンクすることを指示します。Solarisではこれらのライブラリがネットワーク機能に必要です。

### `netdb.h`

C言語の標準ライブラリの一部で、ネットワークデータベース操作（ホスト名とアドレスの変換など）に関連する関数やデータ構造（例: `addrinfo`, `getaddrinfo`）の宣言が含まれるヘッダファイルです。

### `getaddrinfo`関数と関連フラグ

`getaddrinfo`は、ホスト名とサービス名（ポート番号など）から、ネットワークアドレス情報（IPアドレス、ポート、ソケットタイプなど）を取得するためのC言語の関数です。この関数は、`hints`構造体を通じて様々なフラグを受け取り、アドレス解決の挙動を制御します。

*   **`AI_CANONNAME`**: このフラグが設定されている場合、`getaddrinfo`は指定されたホスト名の正規名（canonical name）を解決しようとします。結果として返される`addrinfo`構造体には、この正規名が含まれます。
*   **`AI_V4MAPPED`**: 主にIPv6アドレスを要求する際に使用されます。このフラグが設定されていると、IPv6アドレスが見つからない場合に、IPv4アドレスをIPv4-mapped IPv6アドレス（IPv6形式で表現されたIPv4アドレス）として返すことを許可します。
*   **`AI_ALL`**: `AI_V4MAPPED`と組み合わせて使用されることが多いフラグです。`AI_V4MAPPED`と共に設定されている場合、`getaddrinfo`はIPv6アドレスとIPv4-mapped IPv6アドレスの両方を返します。これにより、IPv6とIPv4の両方に対応するアドレス情報を網羅的に取得できます。

これらのフラグは、Goの`net`パッケージがSolaris上でホスト名解決を行う際に、C言語の`getaddrinfo`関数をどのように呼び出すかを決定するために使用されます。

## 技術的詳細

このコミットの主要な目的は、Goの`net`パッケージがSolaris環境でCGOを介してC言語のネットワーク関連関数を適切に利用できるようにすることです。

1.  **`src/net/cgo_solaris.go`の新規追加**:
    *   このファイルはSolaris固有のCGO設定をカプセル化するために作成されました。
    *   ファイルの先頭には`// +build cgo,!netgo`というビルドタグがあり、CGOが有効で、かつGo独自のネットワークスタック（`netgo`）が使用されていない場合にのみ、このファイルがコンパイルされることを保証します。
    *   CGOコメントブロック内で、Solarisのネットワーク機能に必要なCライブラリ（`libsocket`と`libnsl`）をリンクするための`LDFLAGS`が指定されています。
    *   また、`netdb.h`ヘッダファイルがインクルードされており、これにより`getaddrinfo`関数や関連する定数（`AI_CANONNAME`など）がGoコードから利用可能になります。
    *   `const cgoAddrInfoFlags = C.AI_CANONNAME | C.AI_V4MAPPED | C.AI_ALL`という行は、Solaris環境で`getaddrinfo`関数を呼び出す際に使用するフラグの組み合わせを定義しています。これにより、ホスト名解決時に正規名、IPv4-mapped IPv6アドレス、およびすべての利用可能なアドレスタイプが考慮されるようになります。

2.  **`src/net/cgo_unix.go`の変更**:
    *   既存の`cgo_unix.go`ファイルは、様々なUNIX系OS向けのCGO設定をまとめたものです。
    *   このファイルのビルドタグ`// +build darwin dragonfly freebsd linux netbsd openbsd`に`solaris`が追加されました。
    *   これにより、`cgo_unix.go`で定義されている共通のCGOベースのネットワーク機能が、Solaris環境でも有効になるように拡張されました。

これらの変更により、Goの`net`パッケージはSolaris上で、CGOを介してOSネイティブのネットワーク解決メカニズムをより効果的に利用できるようになり、GoプログラムのSolaris対応が強化されます。

## コアとなるコードの解説

### `src/net/cgo_solaris.go` (新規ファイル)

*   **`// Copyright 2015 The Go Authors. All rights reserved.`**: Goプロジェクトの標準的な著作権表示です。
*   **`// Use of this source code is governed by a BSD-style // license that can be found in the LICENSE file.`**: BSDスタイルのライセンスに従うことを示します。
*   **`// +build cgo,!netgo`**: このビルドタグは、このファイルが以下の条件でコンパイルされることを指定します。
    *   `cgo`: CGOが有効であること。
    *   `!netgo`: Go独自のネットワークスタック（`netgo`）が使用されていないこと。つまり、CGOを介したOSネイティブのネットワーク機能が期待されている場合です。
*   **`package net`**: このファイルが`net`パッケージの一部であることを宣言します。
*   **`/* ... */ import "C"`**: CGOの特別な構文です。`import "C"`の直前のコメントブロック内にC言語のコードやリンカフラグを記述します。
    *   **`#cgo LDFLAGS: -lsocket -lnsl`**: Solaris環境でGoプログラムがC言語のネットワーク関連関数を使用するために必要なリンカフラグです。`libsocket`と`libnsl`という2つのライブラリをリンクするようにリンカに指示します。
    *   **`#include <netdb.h>`**: C言語の`netdb.h`ヘッダファイルをインクルードします。これにより、`getaddrinfo`関数や`AI_CANONNAME`などの関連定数がGoコードから利用可能になります。
*   **`const cgoAddrInfoFlags = C.AI_CANONNAME | C.AI_V4MAPPED | C.AI_ALL`**: `getaddrinfo`関数に渡すフラグの組み合わせを定義しています。
    *   `C.AI_CANONNAME`: ホストの正規名を解決するよう指示します。
    *   `C.AI_V4MAPPED`: IPv4アドレスをIPv4-mapped IPv6アドレスとして返すことを許可します。
    *   `C.AI_ALL`: IPv6アドレスとIPv4-mapped IPv6アドレスの両方を返すよう指示します。
    これらのフラグを組み合わせることで、Solaris上でのホスト名解決がより包括的かつ堅牢になります。

### `src/net/cgo_unix.go` (変更箇所)

*   **`- // +build darwin dragonfly freebsd linux netbsd openbsd`**: 変更前のビルドタグです。Solarisが含まれていませんでした。
*   **`+ // +build darwin dragonfly freebsd linux netbsd openbsd solaris`**: 変更後のビルドタグです。既存のUNIX系OSのリストに`solaris`が追加されました。これにより、このファイルで定義されているCGOベースの共通ネットワーク機能がSolaris環境でもコンパイルされ、利用されるようになります。
