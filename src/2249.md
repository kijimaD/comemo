## 変更の背景

ブロック暗号（例: AES）は、固定長のデータブロック（通常は64ビットまたは128ビット）を暗号化・復号するように設計されています。しかし、実際のアプリケーションでは、ファイル全体やネットワークストリームのような、任意の長さのデータを暗号化する必要が頻繁に生じます。このような場合、ブロック暗号を直接適用するのではなく、「暗号利用モード（Modes of Operation）」と呼ばれる手法を用いて、ブロック暗号をストリーム暗号のように機能させることが一般的です。

このコミットは、Go言語の暗号ライブラリに、特に重要な2つのストリーム暗号利用モードであるOFB (Output Feedback) とCTR (Counter) を追加することを目的としています。これらのモードは、ブロック暗号の出力を擬似乱数ストリームとして利用し、平文とXOR演算を行うことで暗号化・復号を実現します。これにより、Goの暗号ライブラリは、より多様な暗号化要件に対応できるようになり、特にストリームデータの効率的な処理が可能になります。また、OFBとCTRモードは、暗号化と復号が同じ操作であるという特性を持ち、実装の簡素化と効率化に貢献します。

## 前提知識の解説

### ブロック暗号 (Block Cipher)
AES (Advanced Encryption Standard) のように、固定長のデータブロック（例: 128ビット）を入力として受け取り、同じ長さの暗号化されたブロックを出力する対称鍵暗号アルゴリズムです。鍵を用いて暗号化・復号を行います。

### ストリーム暗号 (Stream Cipher)
データをビットまたはバイト単位で逐次的に暗号化・復号する対称鍵暗号アルゴリズムです。通常、鍵と初期値（IV: Initialization Vector）から「鍵ストリーム」と呼ばれる擬似乱数ストリームを生成し、この鍵ストリームと平文をXOR（排他的論理和）することで暗号文を生成します。復号も同じ鍵ストリームを用いて暗号文とXORすることで行われます。

### 暗号利用モード (Modes of Operation)
ブロック暗号を、ブロック長よりも長いメッセージやストリームデータに適用するための標準的な方法です。これにより、ブロック暗号のセキュリティ特性を維持しつつ、様々なアプリケーション要件に対応できます。代表的なモードには、ECB (Electronic Codebook)、CBC (Cipher Block Chaining)、OFB (Output Feedback)、CTR (Counter) などがあります。

### OFB (Output Feedback) モード
ブロック暗号をストリーム暗号として機能させるモードの一つです。
1.  初期ベクトル (IV) をブロック暗号で暗号化し、その出力を鍵ストリームの一部として使用します。
2.  同時に、そのブロック暗号の出力を次のブロックの入力としてフィードバックします。
3.  このプロセスを繰り返すことで、連続的な鍵ストリームを生成します。
4.  生成された鍵ストリームを平文とXORすることで暗号化を行います。復号も同じ鍵ストリームを用いて暗号文とXORすることで行われます。
OFBモードの鍵ストリームは平文とは独立して生成されるため、事前に生成しておくことが可能です。また、暗号化と復号が同じ操作であるという特徴があります。

### CTR (Counter) モード
ブロック暗号をストリーム暗号として機能させる、もう一つの重要なモードです。
1.  初期ベクトル (IV) とカウンターを組み合わせた値をブロック暗号で暗号化します。
2.  そのブロック暗号の出力を鍵ストリームの一部として使用します。
3.  各ブロックごとにカウンターをインクリメントし、この新しいカウンター値を次のブロックの入力として使用します。
4.  生成された鍵ストリームを平文とXORすることで暗号化を行います。復号も同じ鍵ストリームを用いて暗号文とXORすることで行われます。
CTRモードは、OFBモードと同様に鍵ストリームが平文とは独立して生成され、暗号化と復号が同じ操作です。さらに、各ブロックの鍵ストリーム生成が独立しているため、並列処理が容易であり、高速な暗号化・復号が可能です。

### NIST SP 800-38A
米国国立標準技術研究所 (NIST) が発行している「Recommendation for Block Cipher Modes of Operation」という文書です。ブロック暗号の様々な利用モード（ECB, CBC, OFB, CTRなど）の標準的な定義、実装ガイドライン、セキュリティに関する考慮事項が詳細に記述されています。このコミットで実装されたOFBおよびCTRモードは、このNISTの推奨事項に基づいています。

## 技術的詳細

このコミットは、Go言語の`src/lib/crypto/block`パッケージに、OFBおよびCTRモードのストリーム暗号機能を追加します。実装は、汎用的なXORベースのストリーム処理メカニズムの上に構築されており、`io.Reader`および`io.Writer`インターフェースを通じて利用可能です。

主要な技術的ポイントは以下の通りです。

1.  **汎用XORストリーム処理 (`xor.go`):**
    *   `DataStream`インターフェースが定義されており、`Next() []byte`メソッドを通じて擬似乱数ストリームのブロックを生成する役割を担います。
    *   `xorReader`と`xorWriter`構造体が実装されており、`DataStream`から取得した鍵ストリームと入力データをXOR演算することで、透過的な暗号化/復号機能を提供します。これらはそれぞれ`io.Reader`と`io.Writer`インターフェースを実装しています。
    *   この汎用的なXOR処理層により、OFBやCTRといった異なる鍵ストリーム生成ロジックを持つモードを、共通のフレームワーク上で効率的に実装できるようになります。

2.  **CTRモードの実装 (`ctr.go`):**
    *   `ctrStream`構造体が定義されており、基盤となるブロック暗号 (`Cipher`) と、インクリメントされるカウンター (`ctr`) を保持します。
    *   `ctrStream`は`DataStream`インターフェースを実装しており、`Next()`メソッド内で現在のカウンター値をブロック暗号で暗号化し、その結果を鍵ストリームとして返します。その後、カウンターは次のブロックのためにインクリメントされます。
    *   `NewCTRReader`と`NewCTRWriter`関数は、指定されたブロック暗号と初期ベクトル (IV) を用いて`ctrStream`を初期化し、`NewXorReader`または`NewXorWriter`を介して`io.Reader`または`io.Writer`を返します。

3.  **OFBモードの実装 (`ofb.go`):**
    *   `ofbStream`構造体が定義されており、基盤となるブロック暗号 (`Cipher`) と、フィードバックされる初期ベクトル (`iv`) を保持します。
    *   `ofbStream`は`DataStream`インターフェースを実装しており、`Next()`メソッド内で現在のIVをブロック暗号で暗号化し、その結果を鍵ストリームとして返します。同時に、この結果が次のIVとして`iv`フィールドに格納され、フィードバックループを形成します。
    *   `NewOFBReader`と`NewOFBWriter`関数は、指定されたブロック暗号と初期ベクトル (IV) を用いて`ofbStream`を初期化し、`NewXorReader`または`NewXorWriter`を介して`io.Reader`または`io.Writer`を返します。

4.  **テストカバレッジ (`ctr_aes_test.go`, `ofb_aes_test.go`, `xor_test.go`):**
    *   各モードの実装には、対応するテストファイルが追加されています。
    *   `ctr_aes_test.go`と`ofb_aes_test.go`では、AESブロック暗号を用いたNIST SP 800-38Aで定義されている標準的なテストベクトルが使用されており、実装の正確性が検証されています。
    *   `xor_test.go`では、`XorReader`と`XorWriter`の汎用的なXOR処理が、様々なI/Oサイズやフラグメンテーションのシナリオで正しく機能することが確認されています。

この変更により、Go言語の暗号ライブラリは、ストリーム暗号の利用モードをサポートし、ファイル暗号化、ネットワーク通信の暗号化など、幅広いユースケースに対応できるようになりました。

## コアとなるコードの解説

### `src/lib/crypto/block/xor.go`

このファイルは、OFBやCTRといったストリーム暗号モードの基盤となる汎用的なXOR処理を提供します。

*   **`DataStream` インターフェース:**
    ```go
    type DataStream interface {
        Next() []byte
    }
    ```
    これは、擬似乱数ストリームのブロックを生成するオブジェクトが実装すべきインターフェースです。`Next()`メソッドが呼び出されるたびに、次の鍵ストリームのブロック（`[]byte`）を返します。

*   **`xorReader` 構造体と `NewXorReader` 関数:**
    `io.Reader`インターフェースを実装し、基盤となる`io.Reader`からデータを読み込み、`DataStream`から取得した鍵ストリームとXOR演算を行うことで、復号（または暗号化）されたデータを提供します。

*   **`xorWriter` 構造体と `NewXorWriter` 関数:**
    `io.Writer`インターフェースを実装し、書き込まれたデータを`DataStream`から取得した鍵ストリームとXOR演算し、その結果を基盤となる`io.Writer`に書き込みます。これにより、暗号化（または復号）されたデータが書き込まれます。

この`xor.go`の汎用的な実装により、鍵ストリームの生成ロジック（`DataStream`の実装）と、そのストリームを用いたXOR処理（`xorReader`/`xorWriter`）が分離され、コードの再利用性とモジュール性が高められています。

### `src/lib/crypto/block/ctr.go`

CTRモードの鍵ストリーム生成ロジックと、それを利用した`io.Reader`/`io.Writer`を提供します。

*   **`ctrStream` 構造体:**
    ```go
    type ctrStream struct {
        c   Cipher
        ctr []byte
        out []byte
    }
    ```
    `c`は基盤となるブロック暗号、`ctr`はインクリメントされるカウンター、`out`はブロック暗号の出力（鍵ストリームブロック）を一時的に保持するバッファです。

*   **`newCTRStream` 関数:**
    `ctrStream`を初期化します。`ctr`（カウンター）は初期ベクトル (IV) からコピーされます。

*   **`(x *ctrStream) Next() []byte` メソッド:**
    `DataStream`インターフェースの`Next()`メソッドの実装です。
    1.  現在の`x.ctr`（カウンター）を`x.c.Encrypt`で暗号化し、結果を`x.out`に格納します。これが鍵ストリームのブロックとなります。
    2.  `x.ctr`の値をインクリメントします。これは、次のブロックの鍵ストリームを生成するために使用されます。
    3.  `x.out`を返します。

*   **`NewCTRReader` と `NewCTRWriter` 関数:**
    `ctrStream`を`NewXorReader`または`NewXorWriter`に渡し、CTRモードで動作する`io.Reader`または`io.Writer`を生成します。

### `src/lib/crypto/block/ofb.go`

OFBモードの鍵ストリーム生成ロジックと、それを利用した`io.Reader`/`io.Writer`を提供します。

*   **`ofbStream` 構造体:**
    ```go
    type ofbStream struct {
        c  Cipher
        iv []byte
    }
    ```
    `c`は基盤となるブロック暗号、`iv`はフィードバックされる初期ベクトル（または前回のブロック暗号出力）です。

*   **`newOFBStream` 関数:**
    `ofbStream`を初期化します。`iv`は初期ベクトルからコピーされ、ブロック暗号のブロックサイズと一致するかどうかがチェックされます。

*   **`(x *ofbStream) Next() []byte` メソッド:**
    `DataStream`インターフェースの`Next()`メソッドの実装です。
    1.  現在の`x.iv`を`x.c.Encrypt`で暗号化し、その結果を再び`x.iv`に格納します。これが鍵ストリームのブロックとなり、同時に次のブロックの入力としてフィードバックされます。
    2.  `x.iv`を返します。

*   **`NewOFBReader` と `NewOFBWriter` 関数:**
    `ofbStream`を`NewXorReader`または`NewXorWriter`に渡し、OFBモードで動作する`io.Reader`または`io.Writer`を生成します。

これらの実装により、Go言語の`crypto/block`パッケージは、ブロック暗号をストリーム暗号として利用するための堅牢で効率的なメカニズムを獲得しました。
