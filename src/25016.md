## 変更の背景

Go 1.6リリースにおいて、標準ライブラリの `math/rand` パッケージに `Read` 関数が追加されました。この関数は、`io.Reader` インターフェースを実装し、擬似乱数ジェネレータからバイト列を読み出す機能を提供します。新しいAPIが追加された際には、その変更をユーザーに周知するためにリリースノートに記載することが慣例となっています。このコミットは、その慣例に従い、`math/rand.Read` の追加を `doc/go1.6.txt` に記録することを目的としています。

この変更の背景には、`io.Reader` インターフェースを通じて乱数バイト列を取得したいというニーズがあったと考えられます。特に、既存のAPIが `io.Reader` を期待している場合に、`math/rand` からの乱数を簡単に供給できるようにするためです。ただし、`math/rand` は暗号学的に安全ではない擬似乱数を提供するパッケージであるため、その `Read` 関数も同様に暗号学的に安全ではないという重要な注意点があります。

## 前提知識の解説

### 1. Go言語の `math/rand` パッケージ

`math/rand` パッケージは、Go言語で擬似乱数（Pseudo-Random Number, PRN）を生成するための機能を提供します。擬似乱数は、特定の初期値（シード）から決定論的なアルゴリズムによって生成される数値のシーケンスであり、統計的にはランダムに見えますが、完全に予測可能です。そのため、シミュレーション、ゲーム、テストデータ生成など、セキュリティが要求されない場面で利用されます。

*   **シード (Seed)**: 擬似乱数ジェネレータの初期状態を決定する値です。同じシードを使用すると、常に同じ乱数シーケンスが生成されます。通常、`rand.Seed()` 関数でシードを設定します。シードを設定しない場合、デフォルトで1が使用されます。
*   **乱数生成器 (Generator)**: `rand.Source` インターフェースを実装する型が乱数生成器として機能します。`math/rand` パッケージのトップレベル関数（例: `rand.Intn`, `rand.Float64`）は、デフォルトのグローバルな乱数生成器を使用します。

### 2. `io.Reader` インターフェース

Go言語の `io` パッケージは、I/Oプリミティブを定義する基本的なインターフェースを提供します。`io.Reader` はその中でも最も基本的なインターフェースの一つで、データを読み出すための単一のメソッド `Read` を定義しています。

```go
type Reader interface {
    Read(p []byte) (n int, err error)
}
```

`Read` メソッドは、`p` スライスに最大 `len(p)` バイトのデータを読み込み、読み込んだバイト数 `n` とエラー `err` を返します。`io.Reader` は、ファイル、ネットワーク接続、メモリバッファなど、様々なデータソースからデータを読み出すための統一された方法を提供します。

### 3. 擬似乱数と暗号学的に安全な乱数

乱数には大きく分けて「擬似乱数」と「暗号学的に安全な乱数（Cryptographically Secure Pseudo-Random Number, CSPRN）」の2種類があります。

*   **擬似乱数 (PRN)**: `math/rand` パッケージが提供するものです。シードが分かれば、次に生成される乱数を予測できます。セキュリティが重要でない場面で、高速な乱数生成が必要な場合に使用されます。
*   **暗号学的に安全な乱数 (CSPRNG)**: `crypto/rand` パッケージが提供するものです。予測不可能性が非常に高く、シードが分かっても次に生成される乱数を予測することが極めて困難です。パスワード生成、鍵生成、セッションID生成など、セキュリティが要求される場面で必須となります。

`math/rand.Read` は `math/rand` パッケージの一部であるため、生成する乱数は擬似乱数であり、暗号学的に安全ではありません。この区別は、乱数を使用するアプリケーションのセキュリティ要件を考慮する上で非常に重要です。

## 技術的詳細

Go 1.6で `math/rand` パッケージに追加された `Read` 関数は、`io.Reader` インターフェースを実装しています。そのシグネチャは以下の通りです。

```go
func (r *Rand) Read(p []byte) (n int, err error)
```

または、グローバルな乱数生成器を使用するパッケージレベルの関数として:

```go
func Read(p []byte) (n int, err error)
```

この `Read` 関数は、引数として渡されたバイトスライス `p` を、`math/rand` パッケージの擬似乱数ジェネレータから生成されたランダムなバイトで埋めます。`n` は実際に書き込まれたバイト数を示し、`len(p)` と等しくなります。エラーは常に `nil` を返します。

内部的には、`Read` 関数は `math/rand` の `Int63()` メソッドなどを利用して64ビットの擬似乱数を生成し、それをバイト列に変換して `p` に書き込んでいきます。このプロセスは、`p` スライスが完全に埋まるまで繰り返されます。

重要な点は、この `Read` 関数が `crypto/rand` パッケージの `Read` 関数と名前は同じですが、その性質が全く異なることです。`math/rand.Read` は高速ですが予測可能であり、セキュリティ目的で使用してはなりません。一方、`crypto/rand.Read` は低速ですが暗号学的に安全であり、セキュリティが要求される場面で使用すべきです。

このコミットは、この新しい `math/rand.Read` 関数がGo 1.6で利用可能になったことを、リリースノートの「API additions and behavior changes」セクションに明記することで、開発者にその存在を知らせる役割を果たしています。
