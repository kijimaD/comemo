# [インデックス 21981] ファイルの概要

このコミットは、Go言語の標準ライブラリ `image` パッケージにおける `Rectangle` 型の `Overlaps` および `Union` メソッドが、空の矩形（Empty Rectangle）を適切に処理していなかったバグを修正するものです。具体的には、空の矩形が関与する場合のこれらのメソッドの挙動を修正し、関連するテストケースを追加しています。

## コミット

`image` パッケージ内の `Rectangle.Overlaps` および `Rectangle.Union` メソッドにおける、空の矩形に関するバグ修正。

## 変更の背景

この変更は、Go言語の `image` パッケージにおける `Rectangle` 型の `Overlaps` および `Union` メソッドが、空の矩形（Empty Rectangle）を正しく扱わないというバグ（Issue #9895）を修正するために行われました。

Goの `image` パッケージでは、画像処理における領域を `Rectangle` 型で表現します。`Rectangle` は `Min` と `Max` という2つの `Point` で定義され、それぞれ矩形の左上と右下の座標を示します。矩形が「空」であるとは、その幅または高さがゼロ以下である状態を指します。例えば、`Min.X >= Max.X` または `Min.Y >= Max.Y` の場合に矩形は空と見なされます。

`Overlaps` メソッドは2つの矩形が重なり合うかどうかを判定し、`Union` メソッドは2つの矩形を包含する最小の矩形を返します。これらのメソッドが空の矩形を適切に処理しない場合、予期せぬ結果やバグを引き起こす可能性があります。例えば、空の矩形と非空の矩形が重なり合うと誤って判定されたり、空の矩形を含む `Union` 演算が不正な結果を返したりする可能性がありました。

この修正は、これらのメソッドが数学的・幾何学的に正しい挙動を示すようにし、ライブラリの堅牢性を向上させることを目的としています。

## 前提知識の解説

### Go言語の `image` パッケージ

Go言語の標準ライブラリ `image` パッケージは、画像データの表現と基本的な画像処理機能を提供します。このパッケージは、様々な画像フォーマット（JPEG, PNGなど）のデコード・エンコード、画像データの操作、色空間の変換など、幅広い機能を含んでいます。

### `image.Point` と `image.Rectangle`

*   **`image.Point`**: 2次元空間における点を表す構造体です。`X` と `Y` という2つの整数フィールドを持ちます。
    ```go
    type Point struct {
        X, Y int
    }
    ```
*   **`image.Rectangle`**: 2次元空間における矩形領域を表す構造体です。`Min` と `Max` という2つの `Point` フィールドを持ちます。`Min` は矩形の左上隅（最小のX座標とY座標）を、`Max` は矩形の右下隅（最大のX座標とY座標）を表します。ただし、`Max` の座標は排他的であり、`Max.X` は矩形に含まれるピクセルの最大のX座標の1つ右の座標、`Max.Y` は最大のY座標の1つ下の座標を示します。
    ```go
    type Rectangle struct {
        Min, Max Point
    }
    ```

### 空の矩形 (Empty Rectangle)

`Rectangle` が空であるとは、その幅または高さがゼロ以下である状態を指します。これは以下の条件のいずれかが満たされる場合に発生します。
*   `r.Min.X >= r.Max.X`
*   `r.Min.Y >= r.Max.Y`

`image.Rectangle` には `Empty()` メソッドがあり、矩形が空であるかどうかを判定します。

### `Rectangle.Overlaps` メソッド

`func (r Rectangle) Overlaps(s Rectangle) bool`
このメソッドは、レシーバ `r` と引数 `s` の2つの矩形が非空の共通部分（重なり）を持つ場合に `true` を返します。重なりがない場合や、どちらかの矩形が空である場合は `false` を返すことが期待されます。

### `Rectangle.Union` メソッド

`func (r Rectangle) Union(s Rectangle) Rectangle`
このメソッドは、レシーバ `r` と引数 `s` の両方の矩形を完全に包含する最小の矩形を返します。これは、2つの矩形の和集合（Union）を計算する操作に相当します。空の矩形が関与する場合、その挙動は特に重要です。例えば、非空の矩形と空の矩形のUnionは、非空の矩形そのものであるべきです。

## 技術的詳細

このコミットの技術的詳細は、`Rectangle` 型の `Overlaps` と `Union` メソッドが、空の矩形をどのように扱うべきかという幾何学的な定義に焦点を当てています。

### `Rectangle.Union` の修正

元の `Union` メソッドは、2つの矩形 `r` と `s` のそれぞれの `Min` と `Max` 座標を比較し、それらの最小値と最大値を取ることで、両方を包含する矩形を計算していました。しかし、このロジックは、どちらかの矩形が空である場合に問題を引き起こす可能性がありました。

例えば、`r` が空の矩形である場合、`r.Min.X` や `r.Max.X` の値は意味をなさず、`s` との比較によって誤った `Min` や `Max` が選ばれてしまう可能性がありました。

修正後の `Union` メソッドは、まず引数 `r` または `s` のいずれかが `Empty()` であるかをチェックします。
*   もし `r` が空であれば、`s` をそのまま返します。
*   もし `s` が空であれば、`r` をそのまま返します。

これにより、空の矩形とのUnion演算は、非空の矩形を返すという直感的な挙動が保証されます。両方が非空の場合にのみ、従来の座標比較ロジックが適用されます。

### `Rectangle.Overlaps` の修正

元の `Overlaps` メソッドは、2つの矩形 `r` と `s` が重なり合うかどうかを判定するために、以下の条件式を使用していました。
`r.Min.X < s.Max.X && s.Min.X < r.Max.X && r.Min.Y < s.Max.Y && s.Min.Y < r.Max.Y`

この条件式は、非空の矩形同士の重なりを判定する上では正しいですが、どちらかの矩形が空である場合には問題がありました。幾何学的な定義では、空の矩形は他のいかなる矩形とも「非空の共通部分」を持つことはありません。しかし、上記の条件式は、空の矩形であっても特定の座標関係によっては `true` を返してしまう可能性がありました。

修正後の `Overlaps` メソッドは、まず `!r.Empty() && !s.Empty()` という条件を追加しました。これは、`r` と `s` の両方が非空である場合にのみ、重なり判定のロジックを実行するというものです。これにより、どちらか一方でも空の矩形が存在する場合、`Overlaps` は常に `false` を返すようになり、幾何学的な定義に合致するようになりました。

### テストケースの追加

このコミットでは、`src/image/geom_test.go` に新しいテストファイルが追加され、`TestRectangle` という包括的なテスト関数が導入されました。このテストは、`Intersect`、`Union`、`Overlaps` メソッドの挙動を検証するために、様々な矩形の組み合わせ（空の矩形を含む）を使用しています。

特に、`Union` と `Overlaps` の修正された挙動を検証するためのテストが強化されています。例えば、`a.Empty() == r.Overlaps(s)` のようなアサーションは、`Intersect` の結果が空であることと `Overlaps` が `false` を返すことが同等であることを確認しています。また、`Union` の結果が、元の矩形をすべて包含する最小の矩形であることを確認するためのロジックも含まれています。

### `src/image/geom_test.go`

新しいテストファイルが追加され、`TestRectangle` 関数が定義されています。この関数は、`Intersect`, `Union`, `Overlaps` メソッドの様々なケース（空の矩形を含む）を網羅的にテストしています。

```diff
--- /dev/null
+++ b/src/image/geom_test.go
@@ -0,0 +1,103 @@
+// Copyright 2015 The Go Authors. All rights reserved.
+// Use of this source code is governed by a BSD-style
+// license that can be found in the LICENSE file.
+
+package image
+
+import (
+	"fmt"
+	"testing"
+)
+
+func TestRectangle(t *testing.T) {
+	// in checks that every point in f is in g.
+	in := func(f, g Rectangle) error {
+		if !f.In(g) {
+			return fmt.Errorf("f=%s, f.In(%s): got false, want true", f, g)
+		}
+		for y := f.Min.Y; y < f.Max.Y; y++ {
+			for x := f.Min.X; x < f.Max.X; x++ {
+				p := Point{x, y}
+				if !p.In(g) {
+					return fmt.Errorf("p=%s, p.In(%s): got false, want true", p, g)
+				}
+			}
+		}
+		return nil
+	}
+
+	rects := []Rectangle{
+		Rect(0, 0, 10, 10),
+		Rect(1, 2, 3, 4),
+		Rect(4, 6, 10, 10),
+		Rect(2, 3, 12, 5),
+		Rect(-1, -2, 0, 0),
+		Rect(-1, -2, 4, 6),
+		Rect(-10, -20, 30, 40),
+		Rect(8, 8, 8, 8), // Empty rectangle
+		Rect(88, 88, 88, 88), // Empty rectangle
+		Rect(6, 5, 4, 3), // Empty rectangle (Min.X > Max.X)
+	}
+
+	// The intersection should be the largest rectangle a such that every point
+	// in a is both in r and in s.
+	for _, r := range rects {
+		for _, s := range rects {
+			a := r.Intersect(s)
+			if err := in(a, r); err != nil {
+				t.Errorf("Intersect: r=%s, s=%s, a=%s, a not in r: %v", r, s, a, err)
+			}
+			if err := in(a, s); err != nil {
+				t.Errorf("Intersect: r=%s, s=%s, a=%s, a not in s: %v", r, s, a, err)
+			}
+			if a.Empty() == r.Overlaps(s) {
+				t.Errorf("Intersect: r=%s, s=%s, a=%s: empty=%t same as overlaps=%t",
+					r, s, a, a.Empty(), r.Overlaps(s))
+			}
+			largerThanA := [4]Rectangle{a, a, a, a}
+			largerThanA[0].Min.X--
+			largerThanA[1].Min.Y--
+			largerThanA[2].Max.X++
+			largerThanA[3].Max.Y++
+			for i, b := range largerThanA {
+				if b.Empty() {
+					// b isn't actually larger than a.
+					continue
+				}
+				if in(b, r) == nil && in(b, s) == nil {
+					t.Errorf("Intersect: r=%s, s=%s, a=%s, b=%s, i=%d: intersection could be larger",
+						r, s, a, b, i)
+				}
+			}
+		}
+	}
+
+	// The union should be the smallest rectangle a such that every point in r
+	// is in a and every point in s is in a.
+	for _, r := range rects {
+		for _, s := range rects {
+			a := r.Union(s)
+			if err := in(r, a); err != nil {
+				t.Errorf("Union: r=%s, s=%s, a=%s, r not in a: %v", r, s, a, err)
+			}
+			if err := in(s, a); err != nil {
+				t.Errorf("Union: r=%s, s=%s, a=%s, s not in a: %v", r, s, a, err)
+			}
+			if a.Empty() {
+				// You can't get any smaller than a.
+				continue
+			}
+			smallerThanA := [4]Rectangle{a, a, a, a}
+			smallerThanA[0].Min.X++
+			smallerThanA[1].Min.Y++
+			smallerThanA[2].Max.X--
+			smallerThanA[3].Max.Y--
+			for i, b := range smallerThanA {
+				if in(r, b) == nil && in(s, b) == nil {
+					t.Errorf("Union: r=%s, s=%s, a=%s, b=%s, i=%d: union could be smaller",
+						r, s, a, b, i)
+				}
+			}
+		}
+	}
```

## コアとなるコードの解説

### `Union` メソッドの修正

追加された以下のコードは、`Union` メソッドの冒頭で、引数として渡された矩形 `r` または `s` のいずれかが空であるかどうかをチェックします。

```go
	if r.Empty() {
		return s
	}
	if s.Empty() {
		return r
	}
```

*   `r.Empty()`: レシーバの矩形 `r` が空であるかを判定します。
*   `s.Empty()`: 引数の矩形 `s` が空であるかを判定します。

もし `r` が空であれば、`r` と `s` の和集合は `s` そのものになります。同様に、もし `s` が空であれば、和集合は `r` そのものになります。この修正により、空の矩形とのUnion演算が常に正しい結果（非空の矩形とのUnionであれば非空の矩形、両方空であれば空の矩形）を返すことが保証されます。これにより、後続の座標比較ロジックが、非空の矩形同士のUnion演算にのみ適用されるようになります。

### `Overlaps` メソッドの修正

`Overlaps` メソッドの変更は、重なり判定の条件式に `!r.Empty() && !s.Empty()` を追加した点です。

```go
	return !r.Empty() && !s.Empty() &&
		r.Min.X < s.Max.X && s.Min.X < r.Max.X &&
		r.Min.Y < s.Max.Y && s.Min.Y < r.Max.Y
```

*   `!r.Empty()`: 矩形 `r` が空でないことを確認します。
*   `!s.Empty()`: 矩形 `s` が空でないことを確認します。

この変更により、`Overlaps` メソッドは、重なりを判定する前に、両方の矩形が非空であることを厳密にチェックするようになりました。幾何学的に、空の矩形は他のいかなる矩形とも「非空の共通部分」を持つことはありません。したがって、どちらか一方でも空の矩形が存在する場合、`Overlaps` は直ちに `false` を返すようになります。これにより、以前のバグ（空の矩形が誤って重なりを持つと判定される可能性）が解消されました。

### `geom_test.go` の追加

`geom_test.go` に追加された `TestRectangle` 関数は、`image` パッケージの矩形操作の堅牢性を大幅に向上させます。
*   `in` ヘルパー関数: ある矩形 `f` の全ての点が別の矩形 `g` の内部にあることを検証します。これは、`Union` や `Intersect` の結果が期待される範囲内にあることを確認するために使用されます。
*   `rects` スライス: 様々な種類の矩形（通常の矩形、負の座標を持つ矩形、そして特に重要な空の矩形）のテストケースを定義しています。
*   `Intersect` のテスト: `Intersect` メソッドの結果が、元の2つの矩形の両方に含まれる最大の矩形であることを検証します。また、`a.Empty() == r.Overlaps(s)` というアサーションを通じて、交差が空であることと重なりがないことが同義であることを確認しています。
*   `Union` のテスト: `Union` メソッドの結果が、元の2つの矩形を包含する最小の矩形であることを検証します。特に、空の矩形が関与する場合の挙動が正しく処理されることを確認します。

これらのテストは、修正された `Union` と `Overlaps` メソッドが、空の矩形を含むあらゆる入力に対して、期待される幾何学的な挙動を正確に再現することを確認するための重要な検証手段となります。
