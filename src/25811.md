# [インデックス 25811] ファイルの概要

このコミットは、Goプロジェクトに「Go Community Code of Conduct」（行動規範）を導入するものです。具体的には、Goコミュニティにおける行動の期待値、歓迎されない行動、問題報告プロセス、およびモデレーションに関するガイドラインを定義した新しいHTMLドキュメント `doc/conduct.html` を追加しています。また、既存のドキュメント (`doc/contrib.html` と `doc/help.html`) にこの新しい行動規範へのリンクを追加し、コミュニティメンバーが容易にアクセスできるようにしています。この変更は、技術的な機能追加やバグ修正ではなく、コミュニティの健全性と包摂性を高めるためのガバナンスに関する重要な更新です。

## 変更の背景

このコミットの主な背景は、Goコミュニティが多様なバックグラウンドを持つ人々にとって、より友好的で安全かつ歓迎される環境を提供することにあります。オープンソースプロジェクトでは、世界中の様々な文化、経験、コミュニケーションスタイルを持つ人々が協力します。このような多様性の中で、誤解や衝突が生じる可能性があり、それがコミュニティの成長や参加を阻害することがあります。

コミットメッセージに `Fixes #13073` とあるように、この変更はIssue #13073に対応するものです。このIssueは、Goコミュニティにおける行動規範の必要性に関する議論や要望を反映していると考えられます。行動規範を明確にすることで、以下のような目的が達成されます。

1.  **行動の標準化**: 異なる社会的価値観やコミュニケーションスタイルを持つ人々が、効果的、生産的、かつ敬意を持ってGoについて議論できるような、行動の基本的な基準を定めること。
2.  **紛争解決メカニズムの提供**: コミュニティ内で紛争が発生した場合に、それを解決するための明確なメカニズムを提供すること。
3.  **多様性の促進**: コミュニティを多様なバックグラウンドを持つ人々にとって歓迎される場所にすること。Goプロジェクトの成功には、あらゆるバックグラウンドからの貢献者とユーザーが不可欠であるという認識に基づいています。

この行動規範は、意見の相違や議論を許容しつつも、建設的でない行動やハラスメントを明確に禁止することで、健全なコミュニティの発展を目指しています。

## 前提知識の解説

### オープンソースプロジェクトにおける行動規範 (Code of Conduct)

行動規範（Code of Conduct, CoC）は、オープンソースプロジェクトやコミュニティにおいて、参加者がどのように行動すべきかを定めた一連のルールとガイドラインです。その主な目的は以下の通りです。

*   **安全で歓迎される環境の構築**: あらゆる参加者（年齢、性別、性的指向、障害、人種、民族、宗教、国籍、身体的特徴、経験レベルなどに関わらず）が安心して参加し、貢献できるような環境を保証します。
*   **期待される行動の明確化**: コミュニティ内で許容される行動と許容されない行動を明確にすることで、参加者間の誤解や衝突を減らします。
*   **紛争解決の枠組み**: 問題が発生した場合に、それを報告し、解決するための明確なプロセスを提供します。これにより、ハラスメントや不適切な行動が放置されることを防ぎます。
*   **多様性と包摂性の促進**: 多様な視点や才能がプロジェクトに集まることを奨励し、コミュニティ全体の健全性と革新性を高めます。

多くの主要なオープンソースプロジェクト（Linux Foundation, Python Software Foundation, Contributor Covenantなど）が行動規範を採用しており、これは現代のオープンソース開発におけるベストプラクティスの一つとされています。

### Goコミュニティと「Gopher」

Goコミュニティは、Go言語の開発者、ユーザー、貢献者からなる活発なエコシステムです。Go言語のマスコットである「Gopher」（ゴーファー）は、コミュニティメンバー自身を指す愛称としても使われます。Goコミュニティは、その実用性、パフォーマンス、並行処理の容易さといったGo言語の特性と同様に、シンプルさ、効率性、そして協力的な精神を重視する傾向があります。

このコミットで導入された行動規範は、Goコミュニティが「Gopher values」として掲げる特定の価値観（友好的で歓迎的であること、忍耐力、思慮深さ、敬意、寛大さ、破壊的な行動の回避など）を明文化し、それらをコミュニティ全体で共有・遵守することを促しています。

## 技術的詳細

このコミットは、Goプロジェクトのドキュメント構造に新しいHTMLファイルを追加し、既存のドキュメントからそのファイルへのリンクを確立するという、比較的シンプルな技術的変更を含んでいます。

1.  **`doc/conduct.html` の新規作成**:
    *   このファイルは、Goコミュニティの行動規範の全文を記述したHTMLドキュメントです。
    *   ファイルの冒頭には、Goドキュメントシステムがタイトルとパスを認識するためのメタデータコメント `<!--{ "Title": "Go Community Code of Conduct", "Path": "/conduct", "Template": true }-->` が含まれています。`"Template": true` は、Goのドキュメントレンダリングシステムがこのファイルをテンプレートとして処理することを示唆しています。
    *   CSSスタイルブロック `<style>` が含まれており、リスト要素 (`<ul>`) の最大幅を800pxに制限し、ネストされたリストの余白を調整しています。これは、ドキュメントの可読性を高めるためのプレゼンテーション層の調整です。
    *   HTMLコンテンツは、行動規範の目的、適用範囲、Gopher values、歓迎されない行動、モデレーション、問題報告プロセス、および要約といった主要なセクションに分かれています。
    *   特に、問題報告プロセスでは、`conduct@golang.org` へのメール送信、匿名報告フォーム (`https://golang.org/s/conduct-report`)、および行動規範ワーキンググループのメンバーリストが明記されています。
    *   他のGoプロジェクトのドキュメントと同様に、`<a>` タグを用いた内部リンクや外部リンクが適切に配置されています（例: `https://blog.golang.org/open-source`）。

2.  **`doc/contrib.html` の変更**:
    *   このファイルは、Goプロジェクトへの貢献方法に関するドキュメントです。
    *   既存のセキュリティ問題報告に関するセクションの下に、コミュニティ関連の問題報告に関する新しい段落が追加されました。
    *   追加された段落は、「Community-related issues should be reported to `conduct@golang.org`. See the <a href=\"/conduct\">Code of Conduct</a> for more details.」という内容で、行動規範への直接的なリンクを提供しています。

3.  **`doc/help.html` の変更**:
    *   このファイルは、Goに関するヘルプやリソースに関するドキュメントです。
    *   新しいセクション `<h3 id=\"conduct\"><a href=\"/conduct\">Code of Conduct</a></h3>` が追加されました。
    *   このセクションには、「Guidelines for participating in Go community spaces and a reporting process for handling issues.」という説明が付随しており、行動規範の目的を簡潔に示し、`doc/conduct.html` へのリンクを提供しています。

これらの変更により、Goコミュニティの行動規範が公式ドキュメントの一部として組み込まれ、貢献者やユーザーが容易に参照できるようになりました。

## コアとなるコードの解説

### `doc/conduct.html` (新規追加)

このファイルは、Goコミュニティの行動規範の「本体」です。その内容は以下の主要なセクションで構成されています。

*   **About the Code of Conduct**:
    *   **Why have a Code of Conduct?**: 行動規範を設ける理由を説明しています。多様なバックグラウンドを持つ人々が友好的で安全な環境で協力できるようにすること、行動の基準を定めること、紛争解決のメカニズムを提供すること、そして多様性を促進することの3つの主要な目標を挙げています。
    *   **Where does the Code of Conduct apply?**: 行動規範が適用される範囲を定義しています。公式のGitHubプロジェクト、コードレビュー、メーリングリスト（golang-nuts, golang-dev）、IRCチャンネル（#go-nuts）、/r/golang subredditといった「Go spaces」が明示されています。

*   **Gopher values**: Goコミュニティのメンバー（Gophers）が目指すべき価値観を列挙しています。
    *   友好的で歓迎的であること (Be friendly and welcoming)
    *   忍耐力を持つこと (Be patient) - 異なるコミュニケーションスタイルや非母国語話者への配慮を含む。
    *   思慮深くあること (Be thoughtful) - 言葉がどう解釈されるかを考慮し、時にはコメントを控えることも含む。
    *   敬意を払うこと (Be respectful) - 特に意見の相違に対して。
    *   寛大であること (Be charitable) - 他者の議論を善意に解釈し、同意できない場合でも理解しようと努める。
    *   破壊的な行動を避けること (Avoid destructive behavior) - 話題の脱線、非建設的な批判、皮肉、攻撃的またはデリケートな問題の議論、マイクロアグレッションなどを具体的に挙げています。
    これらの価値観は、誤解が生じた際に防御的になったり非難したりせず、疑わしきは罰せずの精神で、すべての関係者が紛争を沈静化する責任があることを強調しています。

*   **Unwelcome behavior**: Go spacesで明示的に禁止されている行動をリストアップしています。
    *   侮辱的、品位を傷つける、憎悪に満ちた、または脅迫的な発言。
    *   年齢、障害、性別、国籍、人種、宗教、性的指向などに基づく差別。
    *   いじめや組織的なハラスメント。
    *   不適切な性的誘い。
    *   これらのいずれかの扇動。

*   **Moderation**: モデレーションの役割とプロセスについて説明しています。
    *   Go spacesは自由な言論の場ではなく、Goに関する議論のための場であること。
    *   モデレーターの目標は、Goに関する建設的な議論を促進すること。
    *   行動規範に違反した場合、警告され、停止を求められること。従わない場合は一時的なコミュニティからの追放、繰り返しの違反は永久追放につながること。
    *   モデレーターは他のコミュニティメンバーよりも高い基準が求められること。
    *   モデレーターの行動に関する苦情は、後述の報告プロセスを通じて処理されること。

*   **Reporting issues**: 問題報告のプロセスと行動規範ワーキンググループについて詳述しています。
    *   行動規範ワーキンググループは、Goコミュニティを代表し、行動関連の問題を処理する責任があること。紛争を沈静化し、すべての関係者が満足する形で問題を解決することを目的としています。
    *   ワーキンググループのメンバーリストが明記されています。
    *   問題に遭遇した場合、`conduct@golang.org` にメールするか、匿名報告フォームを提出すること。問題を公にしたり、特定の個人やグループに対して感情を煽ったりしないよう警告しています。
    *   報告はワーキンググループ内で機密に扱われること。
    *   報告者への対応、ワーキンググループによるインシデントのレビュー、決定（何もしない、謝罪の要求、警告、一時的な活動停止、永久追放など）、および決定の通知プロセスが説明されています。
    *   行動規範とワーキンググループの目標は、可能な限り調和的な方法で紛争を解決することであり、追放などの強制措置は最終手段としてのみ用いられることが強調されています。
    *   行動規範の変更は、提案プロセスを通じて行われること。

*   **Summary**: 行動規範の主要なポイントを簡潔にまとめています。
    *   すべての人を尊重し、親切に扱うこと。
    *   コミュニケーションにおいて思慮深くあること。
    *   破壊的または扇動的でないこと。
    *   問題に遭遇した場合は `conduct@golang.org` にメールすること。

*   **Acknowledgements**: このドキュメントがDjango、FreeBSD、Rustプロジェクトの行動規範から派生したものであることを認めています。

### `doc/contrib.html` および `doc/help.html` の変更

これらのファイルへの変更は、新規作成された `doc/conduct.html` へのリンクを追加することに限定されています。

*   `doc/contrib.html` では、セキュリティ問題の報告に関する既存のセクションに続いて、コミュニティ関連の問題報告に関する新しい段落が追加され、`conduct@golang.org` へのメールアドレスと行動規範へのリンクが提供されています。これにより、貢献者がコミュニティ関連の問題をどこに報告すべきか、そしてその詳細を行動規範で確認できることが明確になります。
*   `doc/help.html` では、Goコミュニティの章の後に、行動規範への新しいセクションが追加されています。ここでも、行動規範の目的を簡潔に説明し、`doc/conduct.html` への直接リンクを提供しています。これにより、Goに関するヘルプを探しているユーザーが、コミュニティ参加のガイドラインにも容易にアクセスできるようになります。

これらのリンクの追加は、行動規範がGoプロジェクトの公式ドキュメント構造に適切に統合され、コミュニティメンバーにとって発見しやすく、参照しやすい状態にすることを保証します。
