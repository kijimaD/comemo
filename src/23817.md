## 変更の背景

Go言語は、その設計当初からクロスプラットフォーム対応を重視しており、様々なオペレーティングシステムとCPUアーキテクチャで動作するように設計されています。Go 1.5のリリースでは、特にサーバーや組み込みシステム分野で需要が高まっていた64ビットARM (`arm64` / `AArch64`) や、IBMのPowerPC (`ppc64` / `ppc64le`) アーキテクチャへのサポートが追加されました。

このコミットは、これらの新しいアーキテクチャサポートを公式ドキュメントに反映させることを目的としています。ドキュメントが最新の状態に保たれることで、ユーザーはGoをこれらの新しい環境にインストールする際の手順や、サポート状況について正確な情報を得ることができます。特に、`install-source.html` はソースコードからGoをビルド・インストールする際のガイドであるため、サポートされるアーキテクチャのリストを正確にすることは非常に重要です。

## 前提知識の解説

### Goのクロスコンパイルとビルドシステム

Go言語の大きな特徴の一つは、その強力なクロスコンパイル機能です。開発者は、あるOS/アーキテクチャの環境（例: macOS上のamd64）で、別のOS/アーキテクチャ（例: Linux上のarm64）向けのバイナリを簡単にビルドできます。これは、`GOOS` と `GOARCH` という環境変数を設定することで実現されます。

### `GOOS` と `GOARCH`

*   **`GOOS`**: ターゲットとなるオペレーティングシステムを指定します。例えば、`linux`, `darwin` (macOS), `windows`, `freebsd` などがあります。
*   **`GOARCH`**: ターゲットとなるCPUアーキテクチャを指定します。例えば、`amd64`, `386`, `arm`, `arm64`, `ppc64`, `ppc64le` などがあります。

Goのビルドツールは、これらの環境変数の組み合わせに基づいて、適切なコンパイラとリンカを選択し、ターゲットプラットフォーム向けの実行可能ファイルを生成します。

### CPUアーキテクチャの種類

*   **`amd64` (x86-64)**: 現在最も広く普及している64ビットのx86アーキテクチャ。デスクトップPCやサーバーで主流です。
*   **`386` (x86, x86-32)**: 32ビットのx86アーキテクチャ。古いシステムや一部の組み込みシステムで使用されます。
*   **`arm` (ARM)**: 32ビットのARMアーキテクチャ。Raspberry Piなどのシングルボードコンピュータや、古いモバイルデバイスで広く使われています。
*   **`arm64` (AArch64)**: 64ビットのARMアーキテクチャ。Apple Silicon Mac、最新のスマートフォン、クラウドサーバー（AWS Gravitonなど）で採用が進んでいます。高い電力効率が特徴です。
*   **`ppc64` (PowerPC 64-bit, big-endian)**: IBMが開発したPowerPCアーキテクチャの64ビット版で、ビッグエンディアン形式。一部の高性能サーバーやスーパーコンピュータで使用されます。
*   **`ppc64le` (PowerPC 64-bit, little-endian)**: `ppc64` のリトルエンディアン版。Linux環境で広く採用されており、特にIBM Power Systemsなどで利用されます。

### Goコンパイラのバックエンド

Goの初期のバージョンでは、各アーキテクチャに対応するコンパイラが `6g` (amd64), `8g` (386), `5g` (arm) のように命名されていました。Go 1.5以降では、これらのコンパイラは `go tool compile` コマンドに統合され、`GOARCH` 環境変数に基づいて適切なバックエンドが選択されるようになりました。このコミットの変更箇所には古いコンパイラ名も記載されていますが、これは当時のドキュメントの記述に合わせたものです。

## 技術的詳細

このコミットは、Goのソースコード自体ではなく、Goプロジェクトのドキュメントファイル `doc/install-source.html` の内容を更新しています。このHTMLファイルは、Goのソースコードからビルド・インストールする手順を説明する公式ガイドの一部です。

具体的な変更点は以下の通りです。

1.  **サポートアーキテクチャ数の更新**:
    *   「The Go compilers support three instruction sets.」という記述が「The Go compilers support five instruction sets.」に変更され、Goがサポートするアーキテクチャが3種類から5種類に増えたことが明示されました。

2.  **新しいアーキテクチャの詳細な追加**:
    *   `arm64` (AArch64) が新しい `<dt>` (定義語) と `<dd>` (定義説明) のペアとして追加されました。サポートOSとしてLinuxとDarwin (macOS) が挙げられ、「New in 1.5 and not as well excercised as other ports.」と、Go 1.5で新しく、他のポートほどテストされていないことが注記されています。
    *   `ppc64, ppc64le` (64-bit PowerPC big- and little-endian) も同様に新しい `<dt>` と `<dd>` のペアとして追加されました。サポートOSはLinuxで、こちらも `arm64` と同様の成熟度に関する注記があります。

3.  **`GOOS` と `GOARCH` の選択肢の更新**:
    *   `GOOS` の選択肢に `iOS` が追加され、`darwin` が Mac OS X 10.6以上 *および* iOS をサポートすることが明記されました。
    *   `GOARCH` の選択肢に `arm64`, `ppc64le`, `ppc64` が追加され、Goがサポートするアーキテクチャの全リストが最新化されました。

4.  **`GOOS` と `GOARCH` の有効な組み合わせテーブルの更新**:
    *   `darwin` と `arm` の組み合わせが追加されました。
    *   `darwin` と `arm64` の組み合わせが追加されました。
    *   `linux` と `arm64` の組み合わせが追加されました。
    *   `linux` と `ppc64` の組み合わせが追加されました。
    *   `linux` と `ppc64le` の組み合わせが追加されました。
    *   `openbsd` と `arm` の組み合わせが追加されました。

これらの変更により、Go 1.5で導入された新しいプラットフォームサポートがドキュメントに完全に反映され、ユーザーはGoのビルドと実行に関する最新の情報を参照できるようになりました。特に、`arm64` や `ppc64` のような新しいアーキテクチャが「New in 1.5 and not as well excercised as other ports」と明記されている点は、ユーザーがこれらのプラットフォームでGoを使用する際の期待値を適切に設定する上で重要です。

## コアとなるコードの解説

このコミットは、GoのインストールガイドHTMLファイル `doc/install-source.html` を直接編集しています。

1.  **アーキテクチャリストの更新**:
    *   `<p>` タグ内のテキストが「The Go compilers support three instruction sets.」から「The Go compilers support five instruction sets.」に変更され、GoがサポートするCPUアーキテクチャの総数が増加したことを示しています。
    *   `<dl>` (定義リスト) 内に、`arm64` と `ppc64, ppc64le` の新しい `<dt>` (定義語) と `<dd>` (定義説明) のペアが追加されました。これにより、これらの新しいアーキテクチャに関する説明（サポートOS、Go 1.5で追加されたこと、成熟度）がドキュメントに組み込まれました。
    *   既存の `arm` アーキテクチャの説明も更新され、サポートOSに `Darwin` (macOS) が追加されました。

2.  **`GOOS` と `GOARCH` 環境変数の説明の更新**:
    *   `GOOS` の選択肢を列挙する箇所で、`darwin` の説明に `and iOS` が追加され、iOSもターゲットOSとしてサポートされることが明記されました。
    *   `GOARCH` の選択肢を列挙する箇所で、`arm64`, `ppc64le`, `ppc64` が追加され、利用可能なアーキテクチャのリストが完全になりました。

3.  **`GOOS` と `GOARCH` の有効な組み合わせテーブルの更新**:
    *   HTMLテーブル (`<table>`) 内に、新しい `GOOS`/`GOARCH` の組み合わせを示す `<tr>` (テーブル行) と `<td>` (テーブルデータ) が多数追加されました。これには、`darwin/arm`, `darwin/arm64`, `linux/arm64`, `linux/ppc64`, `linux/ppc64le`, `openbsd/arm` などが含まれます。このテーブルは、ユーザーがGoをビルドする際にどの `GOOS` と `GOARCH` の組み合わせが有効であるかを一目で確認できるようにするためのものです。

これらの変更は、Go 1.5で導入された新しいプラットフォームサポートをユーザーに正確に伝えるためのドキュメント更新であり、Go言語のクロスプラットフォーム対応の進化を反映しています。
