## 変更の背景

Go言語の標準ライブラリでは、各パッケージの利用方法を明確にするために、`Example` 関数を `_test.go` ファイル内に記述することが推奨されています。これは、以下の複数のメリットをもたらします。

1.  **ドキュメントの充実**: `go doc` コマンドや Go の公式ドキュメントサイト (pkg.go.dev) でパッケージのドキュメントを表示する際に、`Example` 関数のコードと期待される出力が自動的に表示されます。これにより、ユーザーはコードの動作をすぐに理解し、自身のプロジェクトで利用する際の参考とすることができます。
2.  **テストとしての機能**: `Example` 関数は `go test` コマンドによって実行され、その出力が `// Output:` コメントに記述された内容と一致するかどうかが検証されます。これにより、コード例が常に最新かつ正確であることを保証し、パッケージの変更によって例が壊れることを防ぎます。これは、単なるコメントや静的なドキュメントでは得られない大きな利点です。
3.  **学習コストの削減**: 特に `net/mail` のように、RFC に基づく複雑なデータ構造（メールアドレスやメッセージヘッダなど）を扱うパッケージでは、具体的なコード例があることで、ユーザーはどのようにデータをパースし、アクセスすればよいかを直感的に理解できます。

このコミットは、`net/mail` パッケージの使いやすさと堅牢性を向上させるために、これらの `Example` 関数を追加することを目的としています。

## 前提知識の解説

### Go言語の `net/mail` パッケージ

`net/mail` パッケージは、Go言語で電子メールメッセージを解析するための機能を提供します。主に以下の構造体と関数が重要です。

*   **`mail.Message`**: 電子メールメッセージ全体を表す構造体です。ヘッダ (`Header`) とボディ (`Body`) を持ちます。
*   **`mail.Header`**: メッセージヘッダを表す `map[string][]string` 型のエイリアスです。`Get` メソッドを使って特定のヘッダフィールドの値を取得できます。
*   **`mail.Address`**: 電子メールアドレスを表す構造体で、名前 (`Name`) とアドレス (`Address`) のフィールドを持ちます。
*   **`mail.ParseAddress(string) (*Address, error)`**: 単一のメールアドレス文字列を解析し、`mail.Address` 構造体に変換します。
*   **`mail.ParseAddressList(string) ([]*Address, error)`**: 複数のメールアドレスを含む文字列（例: "Alice <a@example.com>, Bob <b@example.com>"）を解析し、`mail.Address` のスライスを返します。
*   **`mail.ReadMessage(io.Reader) (*Message, error)`**: `io.Reader` からメールメッセージを読み込み、`mail.Message` 構造体を返します。

### Go言語の `Example` 関数とテスト

Go言語では、`_test.go` で終わるファイルにテストコードを記述します。このファイルには、通常のテスト関数 (`TestXxx`) の他に、`Example` 関数を記述することができます。

*   **`ExampleXxx()`**: パッケージの利用例を示す関数です。関数名の後に `_` を付けて特定の関数や型に関連付けることもできます（例: `ExampleParseAddressList`）。
*   **`// Output:` コメント**: `Example` 関数の直後に `// Output:` で始まるコメントを記述することで、その例を実行した際の標準出力の期待値を指定できます。`go test` コマンドは、`Example` 関数を実行し、実際の出力とこのコメントの内容を比較して、一致しない場合はテスト失敗とします。これにより、コード例が常に正しく動作することを保証します。

### 電子メールの基本構造 (RFC 5322)

電子メールメッセージは、大きく分けて「ヘッダ」と「ボディ」の2つの部分から構成されます。

*   **ヘッダ**: メッセージに関するメタデータ（送信者、受信者、件名、日付など）を含みます。各ヘッダフィールドは「フィールド名: フィールド値」の形式で記述されます。
*   **ボディ**: メッセージの本文を含みます。

`net/mail` パッケージは、これらの構造をGoのデータ型にマッピングし、簡単にアクセスできるようにします。

## 技術的詳細

このコミットで追加された `src/net/mail/example_test.go` ファイルは、`net/mail` パッケージの主要な機能の具体的な使用方法を、Goの `Example` 関数として実装しています。

1.  **`ExampleParseAddressList()`**:
    *   複数のメールアドレスを含む文字列 `list` を定義します。
    *   `mail.ParseAddressList` 関数を使用して、この文字列を `mail.Address` 型のスライスに解析します。
    *   解析された各アドレスの名前とアドレス部分を標準出力に出力します。
    *   `// Output:` コメントにより、期待される出力が定義されており、`go test` 実行時にこの出力が検証されます。

2.  **`ExampleParseAddress()`**:
    *   単一のメールアドレスを含む文字列を定義します。
    *   `mail.ParseAddress` 関数を使用して、この文字列を `mail.Address` 型のポインタに解析します。
    *   解析されたアドレスの名前とアドレス部分を標準出力に出力します。
    *   `// Output:` コメントにより、期待される出力が定義されています。

3.  **`ExampleReadMessage()`**:
    *   完全なメールメッセージ（ヘッダとボディを含む）を表す複数行文字列 `msg` を定義します。
    *   `strings.NewReader(msg)` を使用して、この文字列を `io.Reader` インターフェースを満たすオブジェクトに変換します。
    *   `mail.ReadMessage` 関数を使用して、`io.Reader` からメールメッセージを読み込み、`mail.Message` 構造体を取得します。
    *   `m.Header.Get()` メソッドを使って、`Date`、`From`、`To`、`Subject` といった特定のヘッダフィールドの値を取得し、出力します。
    *   `ioutil.ReadAll(m.Body)` を使用してメッセージボディの内容を読み込み、出力します。
    *   `// Output:` コメントにより、期待される出力が定義されており、ヘッダとボディの両方が正しくパースされ、アクセスできることを示しています。

これらの `Example` 関数は、`go test` コマンドを実行する際に自動的に検出され、実行されます。各関数の実行結果の標準出力は、対応する `// Output:` コメントの内容と比較され、一致しない場合はテストエラーとして報告されます。これにより、`net/mail` パッケージのAPIが意図した通りに動作し続けることが保証されます。

+import (

+	"io/ioutil"
+	"log"
+	"net/mail"
+	"strings"

+func ExampleParseAddressList() {
+	const list = "Alice <alice@example.com>, Bob <bob@example.com>, Eve <eve@example.com>"
+	emails, err := mail.ParseAddressList(list)
+	if err != nil {
+		log.Fatal(err)
+	}

+	for _, v := range emails {
+		fmt.Println(v.Name, v.Address)
+	}

+	// Alice alice@example.com
+	// Bob bob@example.com
+	// Eve eve@example.com
+}
+
+func ExampleParseAddress() {
+	e, err := mail.ParseAddress("Alice <alice@example.com>")
+	if err != nil {
+		log.Fatal(err)
+	}
+
+	fmt.Println(e.Name, e.Address)
+
+	// Output:
+	// Alice alice@example.com
+}
+
+func ExampleReadMessage() {
+	msg := `Date: Mon, 23 Jun 2015 11:40:36 -0400
+From: Gopher <from@example.com>
+To: Another Gopher <to@example.com>
+Subject: Gophers at Gophercon
+
+Message body
+`
+
+	r := strings.NewReader(msg)
+	m, err := mail.ReadMessage(r)
+	if err != nil {
+		log.Fatal(err)
+	}
+
+	header := m.Header
+	fmt.Println("Date:", header.Get("Date"))
+	fmt.Println("From:", header.Get("From"))
+	fmt.Println("To:", header.Get("To"))
+	fmt.Println("Subject:", header.Get("Subject"))
+
+	body, err := ioutil.ReadAll(m.Body)
+	if err != nil {
+		log.Fatal(err)
+	}
+	fmt.Printf("%s", body)
+

+	// Date: Mon, 23 Jun 2015 11:40:36 -0400
+	// From: Gopher <from@example.com>
+	// To: Another Gopher <to@example.com>
+	// Subject: Gophers at Gophercon
+	// Message body

## コアとなるコードの解説

追加された `example_test.go` ファイルは、`mail_test` パッケージに属しており、これは `net/mail` パッケージのテストコードであることを示します。

1.  **パッケージ宣言とインポート**:
    *   `package mail_test`: `net/mail` パッケージのテストパッケージであることを示します。これにより、`net/mail` パッケージ内のエクスポートされた識別子にアクセスできます。
    *   `import (...)`: `fmt` (出力用)、`io/ioutil` (ボディ読み込み用)、`log` (エラーハンドリング用)、`net/mail` (対象パッケージ)、`strings` (文字列リーダー作成用) がインポートされています。

2.  **`ExampleParseAddressList()` 関数**:
    *   `const list = "Alice <alice@example.com>, Bob <bob@example.com>, Eve <eve@example.com>"`: 複数のメールアドレスを含む文字列を定義しています。
    *   `emails, err := mail.ParseAddressList(list)`: `mail.ParseAddressList` を呼び出して、アドレスリストを解析します。
    *   エラーハンドリング: `if err != nil { log.Fatal(err) }` は、解析中にエラーが発生した場合にプログラムを終了させます。
    *   `for _, v := range emails { fmt.Println(v.Name, v.Address) }`: 解析された各 `mail.Address` オブジェクトから `Name` と `Address` フィールドを取り出し、標準出力に出力します。
    *   `// Output:` コメント: 期待される出力が正確に記述されており、`go test` がこれを検証します。

3.  **`ExampleParseAddress()` 関数**:
    *   `e, err := mail.ParseAddress("Alice <alice@example.com>")`: 単一のメールアドレス文字列を `mail.ParseAddress` で解析します。
    *   エラーハンドリング: 同様にエラーを処理します。
    *   `fmt.Println(e.Name, e.Address)`: 解析された `mail.Address` オブジェクトの名前とアドレスを出力します。
    *   `// Output:` コメント: 期待される出力が記述されています。

4.  **`ExampleReadMessage()` 関数**:
    *   `msg := `...``: バッククォート文字列リテラルを使用して、完全なメールメッセージの生データを定義しています。これには `Date`, `From`, `To`, `Subject` ヘッダとメッセージボディが含まれます。
    *   `r := strings.NewReader(msg)`: `mail.ReadMessage` が `io.Reader` を引数として取るため、文字列 `msg` を `strings.NewReader` で `io.Reader` に変換します。
    *   `m, err := mail.ReadMessage(r)`: `mail.ReadMessage` を呼び出して、メッセージ全体を解析し、`mail.Message` オブジェクトを取得します。
    *   エラーハンドリング: エラーを処理します。
    *   `header := m.Header`: `mail.Message` からヘッダ部分を取得します。
    *   `fmt.Println("Date:", header.Get("Date"))`: `header.Get()` メソッドを使用して、特定のヘッダフィールドの値を取得し、出力します。`Get` メソッドは、指定されたヘッダフィールドの最初の値を返します。
    *   `body, err := ioutil.ReadAll(m.Body)`: `m.Body` は `io.Reader` なので、`ioutil.ReadAll` を使ってメッセージボディの全内容をバイトスライスとして読み込みます。
    *   エラーハンドリング: ボディ読み込み中のエラーを処理します。
    *   `fmt.Printf("%s", body)`: 読み込んだボディの内容を文字列として出力します。
    *   `// Output:` コメント: 期待される出力が記述されており、ヘッダとボディが正しく抽出されることを示しています。
