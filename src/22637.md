## 元コミット内容

`crypto/x509: skip SHA2 system verify test if not supported.`

このコミットは、Go言語の`crypto/x509`パッケージにおいて、SHA2ハッシュアルゴリズムのシステムサポートが利用できない場合に、関連するテストをスキップするように変更します。これは、Windows XP SP2およびWindows Server 2003がSHA2をサポートしていないという既知の問題に対応するためのものです。

## 変更の背景

Go言語のテストスイートは、様々なオペレーティングシステム上で実行されます。Windows環境において、`crypto/x509`パッケージの証明書検証テストの一部が、SHA2ハッシュアルゴリズムを使用する証明書を検証しようとします。しかし、Windows XP Service Pack 2 (SP2) および Windows Server 2003 といった古いバージョンのWindowsでは、システムレベルでSHA2ハッシュアルゴリズムのサポートが組み込まれていませんでした。

このサポートの欠如により、これらの古いWindows環境でGoのテストを実行すると、SHA2関連の証明書検証テストが失敗するという問題が発生していました。テストの信頼性を確保し、これらの環境でのCI/CDパイプラインの健全性を維持するためには、SHA2がサポートされていない環境では該当するテストをスキップする必要がありました。このコミットは、その問題を解決するために導入されました。

## 前提知識の解説

*   **SHA2 (Secure Hash Algorithm 2)**:
    SHA2は、米国国家安全保障局（NSA）によって設計された暗号学的ハッシュ関数のファミリーです。SHA-256、SHA-384、SHA-512などのバリアントがあり、データの完全性を検証するために広く使用されています。特に、デジタル署名やSSL/TLS証明書において、データの改ざんを検出するために不可欠な要素です。SHA1の後継として、より高いセキュリティレベルを提供します。

*   **X.509 証明書**:
    X.509は、公開鍵証明書の標準フォーマットです。WebサイトのSSL/TLS通信、コード署名、電子メールの暗号化など、様々なセキュリティプロトコルで使用されます。X.509証明書は、公開鍵と、その公開鍵が特定のエンティティ（個人、サーバーなど）に属していることを証明する情報を含んでいます。これらの証明書は、通常、信頼された認証局（CA）によって署名されます。

*   **システムルート証明書**:
    オペレーティングシステム（Windows、macOS、Linuxなど）には、信頼できる認証局（CA）の公開鍵証明書が事前にインストールされています。これらは「システムルート証明書」と呼ばれ、OSがデジタル証明書の信頼性を検証する際の出発点となります。Go言語の`crypto/x509`パッケージは、証明書の検証を行う際に、これらのシステムルート証明書を利用して証明書チェーンの信頼性を確立しようとします。

*   **Windows API `GetVersion`**:
    `GetVersion`は、Windowsオペレーティングシステムのバージョン情報を取得するためのAPI関数です。この関数は、OSのメジャーバージョンとマイナーバージョンをエンコードした32ビットの値を返します。このコミットでは、このAPIを使用して、実行中のWindowsのバージョンがSHA2をサポートしているかどうかを判断します。Windows Vista (メジャーバージョン6) 以降のバージョンではSHA2がネイティブにサポートされています。

## 技術的詳細

このコミットは、Goの`crypto/x509`パッケージがWindows環境でSHA2のシステムサポートを動的に検出し、それに基づいてテストの挙動を調整するメカニズムを導入します。

1.  **Windowsバージョン検出の追加**:
    *   `src/internal/syscall/windows/syscall_windows.go`と`src/internal/syscall/windows/zsyscall_windows.go`に、Windows APIの`GetVersion`を呼び出すためのGoラッパー関数が追加されました。
    *   `syscall_windows.go`には`GetVersion()`という関数が追加され、これは`GetVersion` APIの戻り値からメジャーバージョンとマイナーバージョンを抽出します。
    *   `zsyscall_windows.go`には、`GetVersion` APIを呼び出すための低レベルなシステムコールラッパーが定義されています。

2.  **SHA2サポートフラグの導入**:
    *   `src/crypto/x509/verify_test.go`に、グローバル変数`supportSHA2`が導入されました。この変数は、デフォルトで`true`に初期化されます。
    *   `src/crypto/x509/sha2_windows_test.go`という新しいファイルが追加され、その中の`init()`関数でWindowsのバージョンチェックが行われます。
    *   `init()`関数は、`windows.GetVersion()`を呼び出し、メジャーバージョンが6未満（つまり、Windows Vistaより古いバージョン、例えばWindows XP SP2やWindows Server 2003）である場合、`supportSHA2`フラグを`false`に設定します。これにより、SHA2がシステムでサポートされていないことがGoランタイムに通知されます。

3.  **テストの条件付きスキップ**:
    *   `src/crypto/x509/verify_test.go`の`testVerify`関数内で、テストケースを反復処理するループに新しい条件が追加されました。
    *   この条件は、`useSystemRoots`が`true`（システムルート証明書を使用する場合）であり、かつ`supportSHA2`が`false`（システムがSHA2をサポートしていない場合）であり、かつ現在のテストケースが`sha2: true`（SHA2関連のテストである場合）である場合に、そのテストケースを`continue`（スキップ）します。
    *   これにより、SHA2をサポートしない古いWindows環境では、SHA2関連のシステム検証テストが実行されなくなり、テストの失敗が回避されます。

この変更により、Goのテストスイートは、古いWindows環境でも適切に動作し、SHA2サポートの有無に関わらず、テスト結果の信頼性が向上します。

1.  **`src/crypto/x509/sha2_windows_test.go` (新規ファイル)**:

## コアとなるコードの解説

### `src/crypto/x509/sha2_windows_test.go` (新規ファイル)

```go
// Copyright 2015 The Go Authors. All rights reserved.
// Use of this source code is governed by a BSD-style
// license that can be found in the LICENSE file.

package x509

import "internal/syscall/windows"

func init() {
	if major, _ := windows.GetVersion(); major < 6 {
		// Windows XP SP2 and Windows 2003 do not support SHA2.
		// http://blogs.technet.com/b/pki/archive/2010/09/30/sha2-and-windows.aspx
		supportSHA2 = false
	}
}
```
このファイルは、Windows環境でのSHA2サポートを検出するためのロジックを含んでいます。`init()`関数は、パッケージが初期化される際に自動的に実行されます。
`windows.GetVersion()`を呼び出してWindowsのメジャーバージョンを取得し、それが6未満（Windows Vistaより古いバージョン）であれば、グローバル変数`supportSHA2`を`false`に設定します。これにより、古いWindowsシステムではSHA2がサポートされていないことをGoランタイムが認識します。

### `src/internal/syscall/windows/zsyscall_windows.go`

```go
// ... (既存のvar宣言) ...

var (
	// ... (既存のproc宣言) ...
	procGetAdaptersAddresses = modiphlpapi.NewProc("GetAdaptersAddresses")
	procGetComputerNameExW   = modkernel32.NewProc("GetComputerNameExW")
	procGetVersion           = modkernel32.NewProc("GetVersion") // GetVersion APIのプロシージャ
)

// ... (既存の関数定義) ...

func getVersion() (v uint32) {
	r0, _, _ := syscall.Syscall(procGetVersion.Addr(), 0, 0, 0, 0)
	v = uint32(r0)
	return
}
```
このファイルは、Windows APIの`GetVersion`をGoから呼び出すための実際のシステムコールラッパーを定義しています。`procGetVersion`は`kernel32.dll`から`GetVersion`関数へのポインタを取得し、`getVersion()`関数は`syscall.Syscall`を使用してこのAPIを呼び出し、その戻り値（OSバージョン情報）を`uint32`として返します。
