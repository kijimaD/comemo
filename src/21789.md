## 変更の背景

このコミットの背景には、Go言語の標準ライブラリである`net`パッケージのスコープと、より実験的または専門的なネットワーク機能の管理に関する設計思想があります。

元々`src/net/net.go`ファイルには、`// TODO(rsc): support for raw ethernet sockets`というコメントが存在していました。これは、将来的にGoの標準`net`パッケージで生イーサネットソケットのサポートを検討していることを示すものでした。

しかし、Goプロジェクトでは、標準ライブラリの肥大化を防ぎ、安定性と保守性を維持するために、特定の機能や実験的な機能は`golang.org/x/`配下のサブプロジェクトとして開発される方針が取られています。生イーサネットソケットのような低レベルなネットワーク機能は、一般的なアプリケーション開発で頻繁に使用されるものではなく、OS依存性やセキュリティ上の考慮事項も多いため、標準ライブラリに含めるには慎重な検討が必要です。

コミットメッセージにあるように、関連する課題であるIssue #8432が`golang.org/x/net`に移管されたため、標準ライブラリ内の`TODO`コメントは不要となり削除されました。これは、生イーサネットソケットのサポートが、標準ライブラリのコア機能ではなく、`golang.org/x/net`というより専門的な領域で開発・提供されるべきであるというGoチームの決定を反映しています。

## 前提知識の解説

### Go言語の`net`パッケージ

Go言語の`net`パッケージは、Goの標準ライブラリの一部であり、ネットワークI/Oのプリミティブ機能を提供します。このパッケージは、TCP/IP、UDP、Unixドメインソケットなど、様々なネットワークプロトコルを扱うための基本的なインターフェースと実装を含んでいます。開発者はこのパッケージを利用して、クライアントアプリケーションやサーバーアプリケーションを容易に構築できます。例えば、`net.Dial`関数で接続を確立したり、`net.Listen`関数でリッスンを開始したりします。

### `golang.org/x/net`

`golang.org/x/net`は、Go言語の公式エクステンションリポジトリである`golang.org/x/`配下にあるネットワーク関連のパッケージ群です。標準ライブラリには含まれないが、Goチームによって開発・メンテナンスされている追加の機能や、より実験的な機能、特定のユースケースに特化した機能が含まれています。

`golang.org/x/`リポジトリの目的は以下の通りです。
*   **標準ライブラリの安定性維持**: 新しい機能や実験的な機能を標準ライブラリに直接追加する前に、ここで十分にテストし、成熟させることができます。
*   **標準ライブラリの肥大化防止**: 全てのネットワーク関連機能を標準ライブラリに含めると、ライブラリが大きくなりすぎ、保守が困難になる可能性があります。
*   **迅速なイテレーション**: 標準ライブラリのリリースサイクルとは独立して、新しい機能の開発や改善をより迅速に行うことができます。

`golang.org/x/net`には、HTTP/2、WebSocket、DNS、OAuth2など、多岐にわたるネットワークプロトコルやユーティリティが含まれています。

### Raw Ethernet Sockets（生イーサネットソケット）

Raw Ethernet Sockets（生イーサネットソケット）は、OSI参照モデルのデータリンク層（レイヤー2）で動作するソケットの一種です。通常のアプリケーションが使用するTCP/IPソケット（レイヤー3以上のプロトコルを扱う）とは異なり、IPヘッダやTCP/UDPヘッダといった上位層のプロトコル処理をOSに任せず、アプリケーションが直接イーサネットフレーム全体を操作することを可能にします。

**特徴と用途:**
*   **低レベルなアクセス**: イーサネットフレームのヘッダやペイロードを直接読み書きできます。
*   **プロトコルに依存しない**: 特定のプロトコル（TCP, UDP, IPなど）に縛られず、任意のプロトコルを実装できます。
*   **用途**:
    *   ネットワーク診断ツール（例: `tcpdump`、`Wireshark`のようなパケットアナライザ）
    *   カスタムネットワークプロトコルの実装
    *   ブリッジやルーターのようなネットワークデバイスのエミュレーション
    *   特定のハードウェアやネットワークインターフェースとの直接的なやり取り
*   **セキュリティと特権**: 生ソケットの操作は、ネットワークスタックの低レベルにアクセスするため、通常はOSの特権（例: Linuxの`CAP_NET_RAW`ケーパビリティやroot権限）が必要です。誤用するとネットワークに深刻な影響を与える可能性があるため、セキュリティリスクが高いとされています。

### TODOコメント

`TODO`コメントは、ソースコード内に記述される特別なコメントで、開発者が将来的に対応すべきタスクや改善点、未実装の機能などをマークするために使用されます。通常、IDEやコードエディタは`TODO`コメントをハイライト表示したり、タスクリストとして抽出する機能を提供しています。これにより、開発者はコードベース全体で未完了の作業を追跡しやすくなります。

## 技術的詳細

このコミットの技術的詳細は、コードの変更そのものよりも、Go言語の標準ライブラリの設計原則と、特定の機能のスコープに関する決定に集約されます。

変更内容は、`src/net/net.go`ファイルから以下の3行のコメントを削除するだけです。

```go
// TODO(rsc):
//	support for raw ethernet sockets
```

このコメントは、Goの初期開発者の一人であるRuss Cox (`rsc`) によって追加されたもので、将来的に標準`net`パッケージで生イーサネットソケットのサポートを検討するという意図を示していました。

しかし、Goチームは、標準ライブラリを軽量かつ安定に保つことを重視しています。生イーサネットソケットのような機能は、以下のような理由から標準ライブラリのコア部分には適さないと判断されたと考えられます。

1.  **複雑性**: 生ソケットの操作は、OSのシステムコールに深く依存し、プラットフォームごとの差異が大きい。これを標準ライブラリで抽象化し、クロスプラットフォームで安定して提供するのは大きな労力を要します。
2.  **専門性**: ほとんどのGoアプリケーションは、TCPやUDPといった上位層のプロトコルを使用し、生ソケットを直接操作する必要はありません。特定の専門的な用途に限定される機能です。
3.  **セキュリティ**: 生ソケットは低レベルなアクセスを可能にするため、誤用された場合のセキュリティリスクが高いです。

これらの理由から、生イーサネットソケットのサポートは、より専門的で実験的な機能を集約する`golang.org/x/net`リポジトリに移管されることになりました。Issue #8432がその移管の具体的なタスクとして設定され、このコミットはその移管が完了したことを受けて、標準ライブラリ内の古い`TODO`コメントをクリーンアップするものです。

したがって、このコミットは、コードベースのクリーンアップと、Go標準ライブラリの設計方針（コア機能と拡張機能の分離）を明確にするという点で技術的な意味を持ちます。

## コアとなるコードの解説

このコミットでは、`src/net/net.go`ファイルの38行目から40行目にかけて存在していた以下のコメントが削除されました。

```go
// TODO(rsc):
//	support for raw ethernet sockets
```

このコメントは、Goの`net`パッケージの初期段階で、将来的に生イーサネットソケットのサポートを検討するという意図を示すものでした。`TODO`コメントは、コードベースの特定の箇所に未完了の作業や将来の改善点があることを開発者に知らせるための一般的なプラクティスです。

このコメントの削除は、生イーサネットソケットのサポートに関する作業が完全に放棄されたことを意味するものではありません。むしろ、コミットメッセージが示すように、関連する課題（Issue #8432）が`golang.org/x/net`リポジトリに移管されたため、標準ライブラリのこの場所で`TODO`として残しておく必要がなくなったことを意味します。

つまり、この変更は、Goの標準ライブラリのコードベースを整理し、特定の機能の責任範囲を明確にするためのクリーンアップ作業の一環です。生イーサネットソケットのサポートは、より適切な場所である`golang.org/x/net`で継続して開発されることになりました。
