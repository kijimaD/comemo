# [インデックス 19915] ファイルの概要

このコミットは、Go言語のビルドシステムにおいて、新たに`power64`および`power64le`という2つのアーキテクチャをサポート対象として追加するものです。これにより、GoプログラムがIBM Power SystemsなどのPowerPC 64ビットアーキテクチャ上でネイティブにコンパイル・実行できるようになります。具体的には、Goのビルドツール（`cmd/dist`）とビルドパッケージ（`go/build`）がこれらの新しいアーキテクチャを認識し、適切に処理できるように変更が加えられています。

## 変更の背景

Go言語は、その設計思想の一つとして、多様なプラットフォームへの対応を重視しています。このコミットは、その方針の一環として、IBMが開発したPowerPC 64ビットアーキテクチャへのサポートを拡張するために行われました。

`power64`および`power64le`は、それぞれPowerPC 64ビットのビッグエンディアン（Big-Endian）およびリトルエンディアン（Little-Endian）のバリアントを指します。これらのアーキテクチャは、主にサーバー、スーパーコンピュータ、組み込みシステムなどで利用されており、Goがこれらの環境で動作できるようにすることで、Goの適用範囲と利用可能性を広げることが目的です。

Goのビルドシステムに新しいアーキテクチャを追加することは、単にコンパイラがそのアーキテクチャのコードを生成できるだけでなく、Goのツールチェイン全体がそのアーキテクチャを認識し、ビルドプロセスを適切に管理できることを意味します。これにより、開発者はPowerPC 64ビット環境向けにGoアプリケーションを容易に開発・デプロイできるようになります。

## 前提知識の解説

### GOARCH

`GOARCH`は、Go言語の環境変数の一つで、ターゲットとするCPUアーキテクチャを指定するために使用されます。例えば、`amd64`はIntel/AMDの64ビットアーキテクチャ、`386`は32ビットアーキテクチャ、`arm`はARMアーキテクチャを指します。Goのビルドツールは、この`GOARCH`の値に基づいて、適切なアーキテクチャ固有のコードを生成し、ライブラリを選択します。

### cmd/dist

`cmd/dist`は、Go言語のソースコードからGoツールチェイン自体をビルドするためのコマンドです。これはGoのブートストラッププロセスにおいて重要な役割を果たし、コンパイラ、リンカ、その他のツールを構築します。`cmd/dist`は、Goがサポートするアーキテクチャのリストを内部的に持っており、どのアーキテクチャ向けにビルドが可能かを決定します。

### go/buildパッケージ

`go/build`パッケージは、Goのソースコードを解析し、ビルドプロセスを管理するための機能を提供します。これには、Goのソースファイル内のビルドタグ（例: `// +build linux,amd64`）を解釈する機能や、特定の`GOOS`（オペレーティングシステム）および`GOARCH`の組み合わせに基づいてファイルをインクルードまたは除外する機能が含まれます。また、`ArchChar`関数のように、`GOARCH`の文字列表現を内部的な単一文字表現にマッピングする役割も担っています。

### power64とpower64le

*   **PowerPC (Power Architecture)**: IBMが開発したRISC（Reduced Instruction Set Computer）ベースのマイクロプロセッサアーキテクチャです。高性能計算、サーバー、組み込みシステムなど、幅広い分野で利用されています。
*   **64ビット**: 64ビットのレジスタとメモリアドレス空間を持つアーキテクチャを指します。これにより、より大きなメモリ空間を扱え、より複雑な計算を効率的に実行できます。
*   **エンディアンネス (Endianness)**: メモリ上で複数バイトのデータをどのように並べるかを示すバイト順序の規則です。
    *   **ビッグエンディアン (Big-Endian, BE)**: データの最上位バイト（最も重要なバイト）が最も小さいアドレスに格納されます。人間が数字を読む順序に似ています。
    *   **リトルエンディアン (Little-Endian, LE)**: データの最下位バイト（最も重要でないバイト）が最も小さいアドレスに格納されます。Intel x86アーキテクチャなどで広く使われています。
*   **`power64`**: 通常、PowerPC 64ビットのビッグエンディアン（BE）バリアントを指します。
*   **`power64le`**: PowerPC 64ビットのリトルエンディアン（LE）バリアントを指します。近年、LinuxなどのOSがPowerPC上でリトルエンディアンモードで動作することが増えており、互換性のために重要です。

## 技術的詳細

このコミットでは、Goのビルドシステムが`power64`と`power64le`を認識し、適切に処理できるように、以下の3つのファイルが変更されています。

1.  **`src/cmd/dist/build.c`**:
    *   このC言語のファイルは、Goツールチェインのビルドプロセスを管理する`cmd/dist`の一部です。
    *   `gochars`という静的変数に、新しいアーキテクチャに対応する文字（`9`）が追加されています。この文字は、特定の`GOARCH`を内部的に表現するために使用されます。
    *   `okgoarch`という文字列配列に、`"power64"`と`"power64le"`が追加されています。これは、`cmd/dist`が認識する有効な`GOARCH`のリストです。

2.  **`src/pkg/go/build/build.go`**:
    *   このGo言語のファイルは、`go/build`パッケージの一部であり、Goのソースコードのビルドに関するロジックを含んでいます。
    *   `ArchChar`関数に、`"power64"`と`"power64le"`が渡された場合に、対応する文字`"9"`を返すケースが追加されています。この関数は、`GOARCH`の文字列表現を、ビルドタグなどで使用される単一文字表現に変換するために使用されます。

3.  **`src/pkg/go/build/syslist.go`**:
    *   このGo言語のファイルは、`go/build`パッケージの一部であり、Goがサポートするオペレーティングシステム（`goosList`）とアーキテクチャ（`goarchList`）のリストを定数として定義しています。
    *   `goarchList`定数に、`"power64"`と`"power64le"`が追加されています。これにより、`go/build`パッケージを使用する他のツールやライブラリが、これらの新しいアーキテクチャをサポート対象として認識できるようになります。

これらの変更により、Goのビルドシステム全体が`power64`および`power64le`アーキテクチャを公式にサポートするようになり、クロスコンパイルやネイティブビルドが可能になります。

## コアとなるコードの解説

### `src/cmd/dist/build.c` の変更

*   `static char *gochars = "5668";` から `static char *gochars = "566899";` への変更:
    *   `gochars`は、Goの各アーキテクチャに対応する内部的な文字コードを定義しています。既存の`5`（ARM）、`6`（AMD64/x86-64）、`8`（386/x86）に加えて、`power64`および`power64le`のために新しい文字`9`が追加されました。これにより、`cmd/dist`がこれらのアーキテクチャを内部的に識別できるようになります。
*   `static char *okgoarch[] = { ... };` への `"power64"` と `"power64le"` の追加:
    *   `okgoarch`は、`cmd/dist`がビルド可能なターゲットアーキテクチャのリストを保持しています。このリストに`"power64"`と`"power64le"`が追加されることで、`cmd/dist`はこれらのアーキテクチャを有効なビルドターゲットとして認識し、それら向けのツールチェインを構築できるようになります。

### `src/pkg/go/build/build.go` の変更

*   `func ArchChar(goarch string) (string, error)` 関数への `case "power64", "power64le": return "9", nil` の追加:
    *   `ArchChar`関数は、`GOARCH`の文字列値（例: `"amd64"`）を受け取り、それに対応する単一文字の識別子（例: `"6"`）を返します。この識別子は、Goのビルドタグ（例: `// +build amd64`）などで使用されます。
    *   この変更により、`"power64"`または`"power64le"`が`goarch`引数として渡された場合、関数は`"9"`を返します。これは、`cmd/dist/build.c`で`gochars`に追加された`9`と対応しており、Goのビルドシステム全体で一貫したアーキテクチャ識別子を使用できるようにします。

### `src/pkg/go/build/syslist.go` の変更

*   `const goarchList = "386 amd64 amd64p32 arm "` から `const goarchList = "386 amd64 amd64p32 arm power64 power64le "` への変更:
    *   `goarchList`は、Goが公式にサポートするすべての`GOARCH`の文字列リストを定義する定数です。
    *   このリストに`"power64"`と`"power64le"`が追加されることで、`go/build`パッケージを利用する他のGoツール（例: `go env`、`go list`、`go vet`など）が、これらの新しいアーキテクチャを認識し、それらに関連する操作を正しく実行できるようになります。これは、Goエコシステム全体でPowerPC 64ビットアーキテクチャのサポートを統合するための重要なステップです。

これらの変更は、Goのビルドシステムにおけるアーキテクチャ認識の基盤を拡張し、PowerPC 64ビット環境でのGo開発を可能にするためのものです。
