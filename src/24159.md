## 元コミット内容

`crypto: add SHA-512/224 and SHA-512/256 as described in FIPS 180-4`

このコミットは、FIPS 180-4で規定されているSHA-512/224およびSHA-512/256ハッシュアルゴリズムをGo言語の`crypto`パッケージに追加するものです。

## 変更の背景

FIPS 180-4 (Secure Hash Standard) は、2012年に米国国立標準技術研究所 (NIST) によって発行された、セキュアハッシュアルゴリズムの標準規格です。この規格は、SHA-224、SHA-256、SHA-384、SHA-512といった既存のハッシュ関数に加え、新たにSHA-512/224とSHA-512/256を導入しました。

これらの新しいハッシュ関数が導入された主な背景には、64ビットアーキテクチャにおけるパフォーマンスの最適化と、セキュリティ特性の向上が挙げられます。従来のSHA-224やSHA-256は32ビットワードで動作するように設計されていましたが、64ビットシステムではSHA-512ベースのアルゴリズムの方が効率的に処理できるため、より高速なハッシュ計算が期待されます。また、SHA-512/224とSHA-512/256は「ワイドパイプ構造」と呼ばれる特性を持ち、内部状態のサイズが出力ハッシュ値のサイズよりも大きいため、Jouxの多重衝突攻撃やハーディング攻撃、長いメッセージに対する第二原像攻撃といった一般的な攻撃に対する耐性が向上します。

このコミットは、Go言語の`crypto`パッケージがこれらの新しい標準に準拠し、ユーザーが最新かつ高性能なハッシュアルゴリズムを利用できるようにするために行われました。

## 前提知識の解説

*   **ハッシュ関数 (Hash Function)**: 任意の長さのデータを入力として受け取り、固定長のデータ（ハッシュ値、メッセージダイジェスト）を出力する関数です。暗号学的ハッシュ関数は、入力データが少しでも変わると出力が大きく変化する（雪崩効果）、元の入力データをハッシュ値から推測するのが困難である（原像計算困難性）、同じハッシュ値を持つ異なる入力データを見つけるのが困難である（衝突耐性）といった特性を持ち、データの完全性検証やデジタル署名などに利用されます。
*   **FIPS 180-4 (Federal Information Processing Standards Publication 180-4)**: 米国政府が定めるセキュアハッシュアルゴリズムの標準規格です。SHA-1、SHA-224、SHA-256、SHA-384、SHA-512、SHA-512/224、SHA-512/256などが含まれます。
*   **SHA-2 (Secure Hash Algorithm 2)**: NISTによって開発された暗号学的ハッシュ関数のファミリーです。SHA-256、SHA-512、SHA-224、SHA-384、SHA-512/224、SHA-512/256などが含まれます。
*   **SHA-512**: 512ビットのハッシュ値を出力するSHA-2ファミリーのハッシュ関数です。内部演算に64ビットワードを使用します。
*   **SHA-512/224 および SHA-512/256**: これらはSHA-512の「切り詰められた (truncated)」バージョンです。SHA-512と同じコア圧縮関数とメッセージスケジューラを使用しますが、以下の点が異なります。
    *   **初期ハッシュ値 (Initial Hash Values, IVs)**: SHA-512とは異なる、FIPS 180-4で特別に定義された初期ハッシュ値を使用します。これにより、SHA-512とは異なるハッシュ値が生成されます。
    *   **出力の切り詰め**: SHA-512/224は最終的な512ビットのハッシュ値のうち上位224ビットを、SHA-512/256は上位256ビットをそれぞれ出力として使用します。
*   **ワイドパイプ構造 (Wide-pipe construction)**: ハッシュ関数の内部状態（チェイニング変数）のサイズが、最終的な出力ハッシュ値のサイズよりも大きい構造を指します。これにより、ハッシュ値のサイズが同じであっても、内部状態が大きいため、特定の攻撃（例：多重衝突攻撃）に対する耐性が向上します。SHA-512/224とSHA-512/256は、SHA-512の512ビットの内部状態を維持しつつ、224ビットまたは256ビットのハッシュ値を出力するため、このワイドパイプ構造の恩恵を受けます。

## 技術的詳細

このコミットは、Go言語の`crypto`パッケージ内の`sha512`サブパッケージに、SHA-512/224とSHA-512/256の実装を追加します。

1.  **`crypto/crypto.go`の変更**:
    *   `Hash`型の定数に`SHA512_224`と`SHA512_256`が追加されます。これにより、これらの新しいハッシュ関数がGoの標準的なハッシュアルゴリズムとして認識されるようになります。
    *   `digestSizes`マップに、`SHA512_224`の出力サイズ28バイトと`SHA512_256`の出力サイズ32バイトが追加されます。
2.  **`src/crypto/sha512/sha512.go`の変更**:
    *   パッケージのコメントがFIPS 180-2からFIPS 180-4に更新され、SHA-512/224とSHA-512/256が実装されることが明記されます。
    *   `init()`関数内で、`crypto.RegisterHash`を用いて`SHA512_224`と`SHA512_256`がそれぞれ`New512_224`と`New512_256`コンストラクタ関数に登録されます。
    *   新しい定数`Size224` (28バイト) と`Size256` (32バイト) が追加され、それぞれのハッシュ出力サイズを定義します。
    *   SHA-512/224とSHA-512/256の初期ハッシュ値 (IVs) である`init0_224`から`init7_224`、および`init0_256`から`init7_256`が追加されます。これらの値はFIPS 180-4で規定されたものです。
    *   `digest`構造体に`is384`フィールドの代わりに`function crypto.Hash`フィールドが追加されます。これにより、単にSHA-384であるか否かだけでなく、どのSHA-512派生関数であるかを識別できるようになります。
    *   `Reset()`メソッドが変更され、`d.function`の値に基づいて適切な初期ハッシュ値が設定されるようになります。これにより、SHA-512、SHA-384、SHA-512/224、SHA-512/256のそれぞれで正しいIVが適用されます。
    *   `New512_224()`と`New512_256()`という新しいコンストラクタ関数が追加され、それぞれ対応するハッシュオブジェクトを初期化します。
    *   `Size()`メソッドが変更され、`d.function`の値に基づいて正しい出力サイズ（`Size`、`Size384`、`Size224`、`Size256`）を返すようになります。
    *   `Sum()`メソッドが変更され、`d.function`の値に基づいて最終的なハッシュ値が適切に切り詰められるようになります。
    *   `Sum512_224()`と`Sum512_256()`という新しいヘルパー関数が追加され、入力データに対するワンショットのハッシュ計算を提供します。
3.  **`src/crypto/sha512/sha512_test.go`の変更**:
    *   テストファイルがFIPS 180-2からFIPS 180-4を参照するように更新されます。
    *   `sha512Test`構造体が拡張され、`out224`、`out256`、`out384`、`out512`フィールドを持つようになります。これにより、単一のテストケースで異なるSHA-512派生ハッシュ関数の出力を検証できるようになります。
    *   `golden`テストデータが更新され、SHA-512/224とSHA-512/256の期待されるハッシュ値が含まれるようになります。
    *   `testHash`という新しいヘルパー関数が導入され、各ハッシュ関数（SHA-512/224、SHA-512/256、SHA-384、SHA-512）に対して、ワンショット計算とストリーミング計算の両方でテストを実行します。これにより、新しいハッシュ関数の正確性が検証されます。

## コアとなるコードの解説

このコミットの核心は、`src/crypto/sha512/sha512.go`における`digest`構造体の変更と、それに関連するメソッドの更新です。

1.  **`digest`構造体の変更**:
    *   以前は`is384 bool`というフィールドでSHA-384であるか否かを区別していましたが、これを`function crypto.Hash`というより汎用的なフィールドに置き換えました。これにより、SHA-512、SHA-384、SHA-512/224、SHA-512/256といった複数のSHA-512派生ハッシュ関数を同じ`digest`構造体で管理できるようになります。これは、これらのハッシュ関数が内部的に同じ圧縮関数を使用するという特性を活かした設計です。
2.  **`Reset()`メソッドの更新**:
    *   `Reset()`メソッドは、ハッシュ計算を開始する際に内部状態を初期化する役割を担います。変更前は`is384`の値に基づいてSHA-512またはSHA-384の初期ハッシュ値を選択していましたが、変更後は`d.function`の値を`switch`文で評価し、`crypto.SHA384`、`crypto.SHA512_224`、`crypto.SHA512_256`、またはデフォルトの`crypto.SHA512`に対応する適切な初期ハッシュ値（`init0_384`〜`init7_384`、`init0_224`〜`init7_224`、`init0_256`〜`init7_256`、`init0`〜`init7`）を設定するように変更されました。これにより、各ハッシュ関数がFIPS 180-4で規定された正しい初期状態から計算を開始することが保証されます。
3.  **`New512_224()`と`New512_256()`関数の追加**:
    *   これらの新しいコンストラクタ関数は、それぞれ`crypto.SHA512_224`と`crypto.SHA512_256`の`function`フィールドを持つ`digest`オブジェクトを生成し、`Reset()`を呼び出して初期化します。これにより、ユーザーはこれらの新しいハッシュ関数を簡単にインスタンス化できるようになります。
4.  **`Size()`メソッドの更新**:
    *   `Size()`メソッドは、ハッシュ関数の出力サイズをバイト単位で返します。変更後は`d.function`の値に基づいて、`Size224` (28バイト)、`Size256` (32バイト)、`Size384` (48バイト)、または`Size` (64バイト) のいずれかを返すように拡張されました。
5.  **`Sum()`メソッドの更新**:
    *   `Sum()`メソッドは、現在のハッシュ状態から最終的なハッシュ値を計算し、指定されたバイトスライスに追加して返します。変更後は`d.function`の値に基づいて、`hash[:Size384]`、`hash[:Size224]`、`hash[:Size256]`、または`hash[:]`（SHA-512の場合）のように、適切な長さにハッシュ値を切り詰めて返すように変更されました。これにより、各ハッシュ関数がFIPS 180-4で規定された正しい長さのハッシュ値を出力することが保証されます。
6.  **`Sum512_224()`と`Sum512_256()`関数の追加**:
    *   これらの関数は、入力データ全体を一度にハッシュ計算し、結果をバイトスライスとして返す便利なワンショット関数です。内部的には、対応する`digest`オブジェクトを初期化し、`Write()`でデータを書き込み、`checkSum()`でハッシュ値を計算し、適切な長さに切り詰めて返します。

これらの変更により、Goの`crypto/sha512`パッケージは、FIPS 180-4で定義されたSHA-512/224とSHA-512/256を完全にサポートし、既存のSHA-512およびSHA-384の実装と統合された形で提供されることになります。
