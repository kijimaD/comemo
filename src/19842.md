# [インデックス 19842] ファイルの概要

## 変更の背景

このコミットの主な背景は、Go 1.4リリースに向けて行われた`syscall`パッケージの「凍結（freeze）」です。

Go言語の`syscall`パッケージは、オペレーティングシステム（OS）のシステムコールをGoプログラムから直接呼び出すための低レベルなインターフェースを提供していました。しかし、このパッケージは以下のような課題を抱えていました。

1.  **肥大化**: 多数のOS、アーキテクチャに対応するため、非常に多くのシステムコールや定数を含み、パッケージが肥大化していました。
2.  **テストと管理の困難さ**: 多様なプラットフォームでのテストが困難であり、継続的な変更の管理が大きな負担となっていました。
3.  **ドキュメントの不整合**: OSによって動作が異なるため、ドキュメントの一貫性を保つことが難しい状況でした。
4.  **Go 1互換性保証との兼ね合い**: `syscall`パッケージはOSの挙動やカーネル定数に依存するため、Go 1の互換性保証を厳密に維持することが困難でした。OS側の変更がGoのリリースサイクルとは独立して行われるため、予期せぬ互換性の問題が発生する可能性がありました。

これらの課題に対処するため、GoチームはGo 1.4以降、標準ライブラリ内の`syscall`パッケージを凍結し、新しいシステムコールやプラットフォーム固有の機能の追加を停止することを決定しました。その代わりに、より柔軟な更新が可能な外部リポジトリである`golang.org/x/sys`パッケージへの移行が推奨されるようになりました。

このコミット（d7566da188daf71e2b4e8129c0d33d112864ef3e）は、この`syscall`パッケージ凍結の準備の一環として行われました。以前追加されたDarwin向けのソース固有マルチキャストソケットオプションは、凍結される`syscall`パッケージのスコープには含まれないと判断され、削除されることになりました。これにより、`syscall`パッケージはよりスリムになり、凍結後のメンテナンスが容易になります。

## 前提知識の解説

このコミットの変更内容を理解するためには、以下の技術的な概念を把握しておく必要があります。

*   **Go言語の`syscall`パッケージ**:
    Go言語の標準ライブラリの一部であり、OSが提供するシステムコールをGoプログラムから直接呼び出すための機能を提供します。ファイル操作、ネットワーク通信、プロセス管理など、OSレベルの低レベルな操作を行う際に使用されます。しかし、前述の通り、Go 1.4以降は凍結され、新しい機能追加は`golang.org/x/sys`パッケージで行われるようになりました。

*   **マルチキャスト通信**:
    ネットワーク通信の一種で、1対多の通信モデルです。特定のマルチキャストグループに属する複数の受信者に対して、単一の送信元からデータを効率的に送信することができます。ビデオストリーミングやオンラインゲームなど、複数のクライアントに同じデータを同時に配信する必要がある場合に利用されます。

*   **ソース固有マルチキャスト (Source-Specific Multicast, SSM)**:
    マルチキャスト通信の高度な形式です。通常のマルチキャストでは、グループアドレスを指定するだけでそのグループ宛のトラフィックを受信しますが、SSMではさらに「特定の送信元からのマルチキャストトラフィックのみを受信する」というフィルタリングが可能です。これにより、受信者は関心のある送信元からのデータのみを受け取り、不要なトラフィックを排除できます。SSMは主にIGMPv3 (IPv4) や MLDv2 (IPv6) といったプロトコルによってサポートされます。

*   **ソケットオプション**:
    ソケットの動作を細かく制御するための設定項目です。`setsockopt`や`getsockopt`といったシステムコールを通じて設定・取得されます。マルチキャスト通信においては、マルチキャストグループへの参加/脱退、TTL（Time To Live）の設定、ループバックの有効/無効、そしてSSMにおける送信元フィルタリングなどの設定にソケットオプションが使用されます。

*   **Darwin (macOS)**:
    Apple社が開発するオペレーティングシステムで、macOSの基盤となっています。Unix系のOSですが、その内部実装、特にシステムコールやネットワークスタックの挙動には、Linuxなどの他のUnix系OSとは異なる独自の側面があります。そのため、Goの`syscall`パッケージでは、Darwin固有の型定義や定数が必要とされます。

*   **`RawSockaddrStorage`**:
    C言語の`struct sockaddr_storage`に対応するGoの型定義です。これは、IPv4、IPv6、Unixドメインソケットなど、様々な種類のソケットアドレスを格納できる汎用的な構造体です。ソケットアドレスの具体的な種類に関わらず、同じメモリ領域で扱うことができるため、柔軟なプログラミングを可能にします。

*   **`GroupReq` および `GroupSourceReq`**:
    マルチキャストグループへの参加や、SSMにおける送信元フィルタリングを設定するために使用される構造体です。
    *   `GroupReq` (`struct group_req`): 特定のマルチキャストグループに参加する際に使用され、グループアドレスを指定します。
    *   `GroupSourceReq` (`struct group_source_req`): ソース固有マルチキャストにおいて、特定の送信元からのマルチキャストトラフィックを受信するために使用され、グループアドレスと送信元アドレスの両方を指定します。

*   **`MCAST_*` 定数**:
    マルチキャストに関連するソケットオプションやフラグを表す定数です。例えば、`MCAST_JOIN_GROUP`はマルチキャストグループへの参加、`MCAST_BLOCK_SOURCE`は特定の送信元からのトラフィックをブロックする、といった操作に対応します。

## 技術的詳細

このコミットは、Goの`syscall`パッケージからDarwin環境におけるソース固有マルチキャストソケットオプションのサポートを**削除（元に戻す）**するものです。具体的には、以下のGo言語の型定義と定数が削除されました。

1.  **`src/pkg/syscall/types_darwin.go` からの削除**:
    *   `type RawSockaddrStorage C.struct_sockaddr_storage`
    *   `type GroupReq C.struct_group_req`
    *   `type GroupSourceReq C.struct_group_source_req`
    *   これらの型に対応する`Sizeof`定数（`SizeofSockaddrStorage`, `SizeofGroupReq`, `SizeofGroupSourceReq`）

2.  **`src/pkg/syscall/zerrors_darwin_386.go` および `src/pkg/syscall/zerrors_darwin_amd64.go` からの削除**:
    *   `MCAST_BLOCK_SOURCE`
    *   `MCAST_EXCLUDE`
    *   `MCAST_INCLUDE`
    *   `MCAST_JOIN_GROUP`
    *   `MCAST_JOIN_SOURCE_GROUP`
    *   `MCAST_LEAVE_GROUP`
    *   `MCAST_LEAVE_SOURCE_GROUP`
    *   `MCAST_UNBLOCK_SOURCE`
    *   `MCAST_UNDEFINED`
    これらの`MCAST_*`定数は、ソース固有マルチキャストを含むマルチキャストソケットオプションの操作に使用されるフラグでした。

3.  **`src/pkg/syscall/ztypes_darwin_386.go` および `src/pkg/syscall/ztypes_darwin_amd64.go` からの削除**:
    *   `type RawSockaddrStorage struct { ... }`
    *   `type GroupReq struct { ... }`
    *   `type GroupSourceReq struct { ... }`
    *   これらの型に対応する`Sizeof`定数（`SizeofSockaddrStorage`, `SizeofGroupReq`, `SizeofGroupSourceReq`）

これらのファイルは、Darwin固有のシステムコールに関連する型、エラーコード、および定数を定義しており、32ビット（`386`）と64ビット（`amd64`）の両方のアーキテクチャに対応しています。特に`zerrors_darwin_*.go`と`ztypes_darwin_*.go`は、C言語のヘッダファイルから自動生成される部分が多く含まれています。

この変更は、Go 1.4での`syscall`パッケージの凍結という大きな方針転換に直接関連しています。以前のCL 101460043で追加されたDarwin固有のソース固有マルチキャスト機能は、`syscall`パッケージの将来の方向性、特に凍結後のメンテナンスの観点から、標準ライブラリに含めるにはニッチすぎる、あるいは複雑すぎると判断された可能性があります。

これらの定義を削除することで、Go標準ライブラリの`syscall`パッケージはより簡素化され、凍結後の管理が容易になります。プラットフォーム固有の高度なネットワーク機能は、今後`golang.org/x/sys`のような外部パッケージでより柔軟に開発・保守されるべきであるというGoチームの意向が反映されています。これにより、標準ライブラリはより安定し、コアな機能に集中できるようになります。

## コアとなるコードの解説

削除されたコードは、Goの`syscall`パッケージにおけるDarwin環境向けのソース固有マルチキャストソケットオプションのGo言語側バインディング（定義）でした。

*   **`RawSockaddrStorage`**: これは、様々なソケットアドレス（IPv4、IPv6など）を格納するための汎用的な構造体です。この型が削除されたことは、この構造体を利用していた特定のマルチキャスト関連構造体も同時に削除されることを意味します。

*   **`GroupReq` および `GroupSourceReq`**: これらの構造体は、マルチキャストグループへの参加や、特にソース固有マルチキャストにおける送信元フィルタリングを設定するために使用されていました。`GroupReq`はグループアドレスのみを指定し、`GroupSourceReq`はグループアドレスと特定の送信元アドレスの両方を指定します。これらの削除により、Goの`syscall`パッケージは、Darwin上でこれらの高度なマルチキャスト操作を直接サポートしなくなります。

*   **`MCAST_*` 定数**: これらの定数は、上記のソケットオプションと共に使用されるフラグでした。対応する機能が削除されたため、これらの定数も不要となり削除されました。

`zerrors_darwin_*.go`と`ztypes_darwin_*.go`ファイルは、C言語のシステムヘッダファイルからGoの定義を自動生成するプロセスの一部です。これらのファイルから定義が削除されたということは、Goの標準ライブラリが、これらの低レベルなC言語の構造体や定数への直接的なGoバインディングを提供しないという方針転換を示しています。これにより、Goの`syscall`パッケージは、より汎用的な機能に限定され、プラットフォーム固有の複雑な機能は外部パッケージに委ねられることになります。
