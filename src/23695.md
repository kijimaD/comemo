# [インデックス 23695] ファイルの概要

このコミットは、Go言語のプロファイリングツールである `pprof` において、SVGグラフのパン（移動）とズーム機能を提供する `SVGPan` ライブラリの取り扱い方法を変更するものです。具体的には、これまで外部のURLから `SVGPan.js` を参照していたのをやめ、ライブラリのJavaScriptコードを `pprof` の内部に直接埋め込むように修正しています。これにより、外部依存性を排除し、オフライン環境での利用やセキュリティ面での安定性向上を図っています。

## 変更の背景

この変更の背景には、主に以下の点が挙げられます。

1.  **外部依存性の排除と安定性の向上**: 以前の `pprof` は、SVGグラフのインタラクティブ機能（パンとズーム）を実現するために、`SVGPan.js` というJavaScriptライブラリを外部のURL（`https://www.cyberz.org/projects/SVGPan/SVGPan.js`）から動的に読み込んでいました。しかし、外部リソースへの依存は、そのリソースが利用できなくなった場合（サーバーダウン、URL変更など）や、インターネット接続がない環境での `pprof` の利用を妨げる可能性があります。また、外部リソースの内容が変更された場合に予期せぬ動作を引き起こすリスクも存在します。
2.  **セキュリティの強化**: 外部のJavaScriptファイルを直接読み込むことは、そのファイルが悪意のあるコードに置き換えられた場合に、`pprof` を利用するユーザーのシステムに影響を与える潜在的なセキュリティリスクを伴います。ライブラリを内部にコピーすることで、コードの完全性を `pprof` 自身が管理できるようになります。
3.  **Issue #10375 の解決**: このコミットメッセージに明記されているように、この変更は `Issue #10375` を解決するために行われました。このIssueは、外部の `SVGPan.js` への依存が引き起こす問題（おそらくは上記のような安定性やオフライン利用に関する問題）を指摘していたと考えられます。

## 前提知識の解説

### Go言語の `pprof` ツール

`pprof` は、Goプログラムのパフォーマンスプロファイリングを行うための強力なツールです。CPU使用率、メモリ割り当て、ゴルーチンブロック、ミューテックス競合などのプロファイルデータを収集し、それを視覚的に分析するための様々な形式（テキスト、グラフ、Webインターフェースなど）で出力できます。特に、SVG形式でコールグラフやフレームグラフを出力する機能は、パフォーマンスのボトルネックを視覚的に特定するのに役立ちます。

### SVG (Scalable Vector Graphics)

SVGは、XMLベースの2次元ベクターグラフィックス記述言語です。画像が拡大・縮小されても品質が劣化しないという特徴があります。Webブラウザで直接表示でき、JavaScriptと組み合わせることでインタラクティブな操作（パン、ズームなど）を実装できます。

### SVGPan ライブラリ

`SVGPan` は、SVG画像に対してマウス操作によるパン（移動）とズーム機能を追加するためのJavaScriptライブラリです。SVG要素にイベントリスナーを設定し、マウスのドラッグで画像を移動させたり、マウスホイールで拡大・縮小したりする機能を提供します。これにより、複雑なSVGグラフでも詳細な部分を容易に確認できるようになります。

### `xlink:href` と `CDATA` セクション

*   **`xlink:href`**: SVGやXML文書において、外部リソースへのリンクを指定するために使用される属性です。このコミット以前は、`<script xlink:href="https://www.cyberz.org/projects/SVGPan/SVGPan.js"/>` のように記述され、外部のJavaScriptファイルを読み込んでいました。
*   **`CDATA` セクション**: XML文書内で、マークアップとして解釈されたくないテキストブロックを記述するために使用されます。`<script type="text/ecmascript"><![CDATA[...JavaScriptコード...]]></script>` のように記述することで、JavaScriptコード内の特殊文字（`<` や `&` など）がXMLパーサーによって誤って解釈されるのを防ぎ、コードをそのまま埋め込むことができます。

## 技術的詳細

このコミットの技術的な変更点は、`pprof` が生成するSVG出力に `SVGPan` ライブラリを組み込む方法を根本的に変えたことです。

1.  **`SVGPan.js` の内部化**: `SVGPan.js` のJavaScriptコード全体が、`src/cmd/pprof/internal/svg/svgpan.go` という新しいGoファイル内の `svgPanJS` というGoの文字列定数として取り込まれました。これにより、`SVGPan` ライブラリは `pprof` バイナリの一部となり、外部へのネットワークアクセスなしで利用可能になります。
2.  **動的URL参照の削除**:
    *   `src/cmd/pprof/internal/driver/driver.go` から、`--svgpan` コマンドラインフラグと、それに対応する `flagSVGPan` フィールドが削除されました。これにより、ユーザーが `SVGPan` ライブラリのURLをカスタマイズするオプションがなくなりました。
    *   `src/cmd/pprof/internal/commands/commands.go` の `PProf` 関数および `saveSVGToFile` 関数から、`svgpan` パラメータが削除されました。これは、`SVGPan` のソースが固定されたため、動的に渡す必要がなくなったことを意味します。
3.  **SVG出力へのJavaScript埋め込み方法の変更**:
    *   `src/cmd/pprof/internal/svg/svg.go` の `Massage` 関数が変更されました。以前は、`svgPan` パラメータで渡されたURLを `xlink:href` 属性に設定して外部JavaScriptファイルをリンクしていましたが、この変更により `svgPanJS` 定数に格納されたJavaScriptコードを直接SVG内に埋め込むようになりました。
    *   埋め込みには、`<script type="text/ecmascript"><![CDATA[` と `]]></script>` で囲む `CDATA` セクションが使用されています。これは、JavaScriptコード内の特殊文字がXMLとして解釈されるのを防ぐための標準的な手法です。
    *   また、`Massage` 関数内の `svgPan == ""` のチェックが削除されました。これは、`svgPan` パラメータ自体がなくなったため不要になったためです。
4.  **SVGの初期スケール調整**: `Massage` 関数内で、`graphId.FindStringIndex(svg)` で見つけた位置に `<g id="viewport" transform="scale(0.5,0.5) translate(0,0)">` という要素が追加されています。これは、SVGPanが適用されるビューポートの初期変換を設定するもので、グラフの表示サイズを調整し、全体を見やすくするためのものです。

これらの変更により、`pprof` が生成するSVGファイルは自己完結型となり、Webブラウザで開くだけでパンとズーム機能が利用できるようになります。

function setupHandlers(root){
	setAttributes(root, {
		"onmouseup" : "handleMouseUp(evt)",
		"onmousedown" : "handleMouseDown(evt)",
		"onmousemove" : "handleMouseMove(evt)",

/**
 * Retrieves the root element for SVG manipulation. The element is then cached into the svgRoot global variable.
 */
function getRoot(root) {
	if(typeof(svgRoot) == "undefined") {
		var g = null;

		g = root.getElementById("viewport");

		if(g == null)
			g = root.getElementsByTagName('g')[0];

		if(g == null)
			alert('Unable to obtain SVG root element');

		setCTM(g, g.getCTM());

		g.removeAttribute("viewBox");

		svgRoot = g;
	}

	return svgRoot;
}

/**
 * Instance an SVGPoint object with given event coordinates.
 */
function getEventPoint(evt) {
	var p = root.createSVGPoint();

	p.x = evt.clientX;
	p.y = evt.clientY;

	return p;
}

/**
 * Sets the current transform matrix of an element.
 */

	var s = "matrix(" + matrix.a + "," + matrix.b + "," + matrix.c + "," + matrix.d + "," + matrix.e + "," + matrix.f + ")";

	element.setAttribute("transform", s);
}

 * Dumps a matrix to a string (useful for debug).
 */

	var s = "[ " + matrix.a + ", " + matrix.c + ", " + matrix.e + "\n  " + matrix.b + ", " + matrix.d + ", " + matrix.f + "\n  0, 0, 1 ]";

	return s;
}

	for (var i in attributes)
		element.setAttributeNS(null, i, attributes[i]);

/**
 * Handle mouse wheel event.
 */
function handleMouseWheel(evt) {
	if(!enableZoom)
		return;

	if(evt.preventDefault)
		evt.preventDefault();

	evt.returnValue = false;

	var svgDoc = evt.target.ownerDocument;

	var delta;

	if(evt.wheelDelta)
		delta = evt.wheelDelta / 3600; // Chrome/Safari
	else
		delta = evt.detail / -90; // Mozilla

	var z = 1 + delta; // Zoom factor: 0.9/1.1

	var g = getRoot(svgDoc);
	
	var p = getEventPoint(evt);

	p = p.matrixTransform(g.getCTM().inverse());

	// Compute new scale matrix in current mouse position
	var k = root.createSVGMatrix().translate(p.x, p.y).scale(z).translate(-p.x, -p.y);

        setCTM(g, g.getCTM().multiply(k));

	if(typeof(stateTf) == "undefined")
		stateTf = g.getCTM().inverse();

	stateTf = stateTf.multiply(k.inverse());
}

/**
 * Handle mouse move event.
 */
function handleMouseMove(evt) {
	if(evt.preventDefault)
		evt.preventDefault();

	evt.returnValue = false;

	var svgDoc = evt.target.ownerDocument;

	var g = getRoot(svgDoc);

	if(state == 'pan' && enablePan) {
		// Pan mode
		var p = getEventPoint(evt).matrixTransform(stateTf);

		setCTM(g, stateTf.inverse().translate(p.x - stateOrigin.x, p.y - stateOrigin.y));
	} else if(state == 'drag' && enableDrag) {
		// Drag mode
		var p = getEventPoint(evt).matrixTransform(g.getCTM().inverse());

		setCTM(stateTarget, root.createSVGMatrix().translate(p.x - stateOrigin.x, p.y - stateOrigin.y).multiply(g.getCTM().inverse()).multiply(stateTarget.getCTM()));

		stateOrigin = p;
	}
}

/**
 * Handle click event.
 */
function handleMouseDown(evt) {
	if(evt.preventDefault)
		evt.preventDefault();

	evt.returnValue = false;

	var svgDoc = evt.target.ownerDocument;

	var g = getRoot(svgDoc);

	if(
		evt.target.tagName == "svg" 
		|| !enableDrag // Pan anyway when drag is disabled and the user clicked on an element 
	) {
		// Pan mode
		state = 'pan';

		stateTf = g.getCTM().inverse();

		stateOrigin = getEventPoint(evt).matrixTransform(stateTf);
	} else {
		// Drag mode
		state = 'drag';

		stateTarget = evt.target;

		stateTf = g.getCTM().inverse();

		stateOrigin = getEventPoint(evt).matrixTransform(stateTf);
	}
}

/**
 * Handle mouse button release event.
 */
function handleMouseUp(evt) {
	if(evt.preventDefault)
		evt.preventDefault();

	evt.returnValue = false;

	var svgDoc = evt.target.ownerDocument;

	if(state == 'pan' || state == 'drag') {
		// Quit pan mode
		state = '';
	}
}

    *   変更前は、`svgPan` という文字列パラメータ（外部URL）を受け取り、`<script xlink:href="` + `svgPan` + `"/>` のように外部ファイルをリンクしていました。
    *   変更後は、`svgPan` パラメータが削除され、代わりに `svgPanJS` 定数に格納されたJavaScriptコードを直接埋め込むようになりました。埋め込み形式は `<script type="text/ecmascript"><![CDATA[` + `svgPanJS` + `]]></script>` です。
    *   これにより、生成されるSVGファイルは、`SVGPan` の機能に必要なJavaScriptコードをすべて内包する自己完結型となります。
    *   また、`<g id="viewport" transform="scale(0.5,0.5) translate(0,0)">` という要素が追加され、SVGの初期表示スケールが調整されています。これは、大きなグラフでも最初に全体像を把握しやすくするためのUX改善と考えられます。

3.  **`commands.go` と `driver.go` の変更**:
    *   これらのファイルでは、`SVGPan` のURLを動的に設定するための `svgpan` パラメータや `flagSVGPan` フラグが削除されています。これは、`SVGPan` ライブラリが内部化され、そのソースが固定されたため、外部からの設定が不要になったことを反映しています。

これらの変更により、`pprof` のSVG出力は、インターネット接続の有無や外部サイトの可用性に依存することなく、常にインタラクティブなパン・ズーム機能を提供できるようになりました。
