# [インデックス 27811] ファイルの概要

このコミットは、Go言語の標準ライブラリである`fmt`パッケージのドキュメントファイル`src/fmt/doc.go`に対する変更です。`fmt`パッケージは、GoプログラムにおけるフォーマットI/O（入出力）を実装しており、C言語の`printf`や`scanf`に似た機能を提供します。`doc.go`ファイルは、このパッケージの全体的な機能、特にフォーマット動詞（verb）やフラグ、精度などの書式設定ルールに関する詳細な説明を含んでいます。この変更は、浮動小数点数のフォーマット動詞である`%g`の「精度」の解釈について、より明確な説明を加えることを目的としています。

## コミット

このコミットは、`fmt`パッケージのドキュメントにおいて、浮動小数点数フォーマット動詞`%g`の「精度」が「小数点以下の桁数」ではなく「有効数字の総数」を決定することを明確にするためのものです。これはドキュメントの変更のみであり、コードの動作には影響を与えません。

## 変更の背景

Goの`fmt`パッケージにおける浮動小数点数のフォーマットは、`%f`（固定小数点）、`%e`（科学表記）、`%g`（状況に応じて`%f`または`%e`を選択）などの動詞を使用します。これらの動詞において「精度」（precision）という概念が使われますが、その解釈は動詞によって異なります。

特に`%f`や`%e`の場合、精度は「小数点以下の桁数」を意味します。しかし、`%g`の場合、精度は「有効数字の総数」を意味します。この違いがドキュメント内で十分に明確に説明されていなかったため、ユーザーが`%g`の挙動を誤解する可能性がありました。

このコミットは、Issue #15178で報告されたこの曖昧さを解消するために行われました。ユーザーが`%g`の精度指定を`%f`や`%e`と同じように「小数点以下の桁数」と誤解しないよう、ドキュメントを修正し、より正確な例を提示することで、混乱を防ぐことが目的です。

## 前提知識の解説

### Go言語の`fmt`パッケージ

`fmt`パッケージは、Go言語で最も基本的なテキストフォーマット機能を提供します。`fmt.Printf`や`fmt.Sprintf`などの関数を通じて、様々なデータ型を整形された文字列として出力することができます。フォーマットは「フォーマット動詞」（format verb）と呼ばれる特殊な文字（例: `%d`、`%s`、`%f`）と、それに付随するフラグや幅、精度指定子によって制御されます。

### 浮動小数点数フォーマット動詞

*   **`%f` (Fixed-point notation)**: 固定小数点表記で数値をフォーマットします。精度を指定した場合、小数点以下の桁数を決定します。
    *   例: `fmt.Sprintf("%.2f", 123.456)` は `"123.46"` となります（小数点以下2桁）。
*   **`%e` (Scientific notation)**: 科学表記（指数表記）で数値をフォーマットします。精度を指定した場合、小数点以下の桁数を決定します。
    *   例: `fmt.Sprintf("%.2e", 123.456)` は `"1.23e+02"` となります（小数点以下2桁）。
*   **`%g` (General notation)**: 一般表記で数値をフォーマットします。数値の大きさに基づいて、`%e`または`%f`のどちらか短い方を選択します。**この動詞における精度は、小数点以下の桁数ではなく、有効数字の総数を決定します。**

### 精度（Precision）の概念

プログラミングにおける数値のフォーマットにおいて、「精度」という言葉は文脈によって異なる意味を持つことがあります。

*   **小数点以下の桁数 (Digits after decimal point)**: 小数点より右側に表示される桁数。`%f`や`%e`の精度指定はこの意味で使われます。
*   **有効数字の総数 (Total number of significant digits)**: 数値の先頭のゼロでない数字から始まる、すべての数字の総数。`%g`の精度指定はこの意味で使われます。

例えば、`123.456`という数値に対して：
*   小数点以下2桁 (`.2f`) は `123.46`
*   有効数字3桁 (`.3g`) は `123` または `1.23e+02` のように、全体の桁数が3になるように調整されます。

この違いが、`%g`の挙動を理解する上で非常に重要となります。

## 技術的詳細

このコミットの技術的詳細は、`fmt`パッケージのドキュメントが`%g`フォーマット動詞の「精度」の定義をどのように明確化したかにあります。

変更前は、`%g`の精度について「it sets the total number of digits」と記述されていました。これは「総桁数」を意味しますが、具体的な例が`%.4g prints 123.5`（元の値は`123.45`）となっており、この例では有効数字が4桁になるように丸められていることが示されていました。しかし、`%f`や`%e`の精度が小数点以下の桁数を指すという説明の直後にこの記述があったため、読者が`%g`の精度も小数点以下の桁数を指すと誤解する可能性がありました。

変更後は、「except that for %g/%G precision sets the total number of significant digits.」と明確に「有効数字の総数」を指すように修正されました。さらに、例も`given 12.345 the format %6.3f prints 12.345 while %.3g prints 12.3`に変更され、`%.3g`が`12.345`を有効数字3桁の`12.3`としてフォーマットすることを示しています。この新しい例は、`%f`と`%g`の精度の違いをより直感的に理解しやすくしています。

また、`%g`のデフォルトの精度については、「it is the smallest number of digits necessary to identify the value uniquely.」と記述されており、これは値が持つ情報を失わない最小限の桁数で表現されることを意味します。この部分は変更されていませんが、変更された説明と合わせて読むことで、`%g`の柔軟性と目的がより明確になります。

このドキュメントの修正は、`fmt`パッケージのユーザーが浮動小数点数のフォーマットをより正確に制御し、期待通りの出力を得るための理解を深める上で非常に重要です。特に、数値の丸めや表示形式に関するバグや誤解を防ぐのに役立ちます。

## コアとなるコードの解説

変更は`src/fmt/doc.go`ファイル内の95行目から104行目にかけてのドキュメントコメントにあります。

**変更前:**
```go
	For floating-point values, width sets the minimum width of the field and
	precision sets the number of places after the decimal, if appropriate,
	except that for %g/%G it sets the total number of digits. For example,
	given 123.45 the format %6.2f prints 123.45 while %.4g prints 123.5.
	The default precision for %e and %f is 6; for %g it is the smallest
	number of digits necessary to identify the value uniquely.
```
この記述では、`%g/%G`の精度が「総桁数（total number of digits）」を決定すると説明されていました。例として`given 123.45 the format %6.2f prints 123.45 while %.4g prints 123.5.`が挙げられていましたが、`123.45`を`%.4g`でフォーマットすると`123.5`になるという例は、有効数字4桁で丸められていることを示唆しつつも、「総桁数」という表現が曖昧さを残していました。

**変更後:**
```go
	For floating-point values, width sets the minimum width of the field and
	precision sets the number of places after the decimal, if appropriate,
	except that for %g/%G precision sets the total number of significant
	digits. For example, given 12.345 the format %6.3f prints 12.345 while
	%.3g prints 12.3. The default precision for %e and %f is 6; for %g it
	is the smallest number of digits necessary to identify the value uniquely.
```
変更点として、`except that for %g/%G it sets the total number of digits.`が`except that for %g/%G precision sets the total number of significant digits.`に修正されました。これにより、`%g`の精度が「有効数字の総数（total number of significant digits）」を決定することが明確に示されました。

また、例も`given 123.45 the format %6.2f prints 123.45 while %.4g prints 123.5.`から`given 12.345 the format %6.3f prints 12.345 while %.3g prints 12.3.`に変更されました。新しい例では、`12.345`という数値に対して、`%6.3f`が`12.345`と出力するのに対し、`%.3g`は有効数字3桁で`12.3`と出力することが示されており、`%f`と`%g`の精度の解釈の違いがより明確に、かつ直感的に理解できるようになっています。

この修正は、ドキュメントの正確性を向上させ、ユーザーが`fmt`パッケージの浮動小数点数フォーマット機能をより適切に利用できるようにするための重要な改善です。
