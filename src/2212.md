## 変更の背景

このコミットが行われた2009年5月は、Go言語がまだ一般に公開される前の開発初期段階にあたります。Go言語はシステムプログラミングを意識して設計されており、オペレーティングシステムとのインタラクションは重要な要素です。`Getuid`, `Getgid`, `Geteuid`, `Getegid`といった関数は、Unix系システムにおいてプロセスがどのユーザー権限で実行されているか、あるいはどのグループに属しているかを知るための基本的なシステムコールです。

これらの関数が`os`パッケージに追加された背景には、Goプログラムがファイルシステムへのアクセス権限の確認、特定のユーザーに紐づくリソースの管理、あるいはセキュリティ関連の処理を行う際に、実行ユーザーの識別情報が必要となるケースが想定されたためと考えられます。初期のGo言語開発において、OSとの連携を強化し、より実用的なシステムツールやアプリケーションを構築するための基盤を整備する一環として、これらの基本的な機能が導入されました。

## 前提知識の解説

### ユーザーID (UID) とグループID (GID)

Unix系オペレーティングシステムでは、システム上のすべてのユーザーとグループは一意の数値識別子を持っています。

*   **UID (User ID)**: ユーザーを一意に識別するための数値です。例えば、`root`ユーザーは通常UID 0を持ちます。
*   **GID (Group ID)**: グループを一意に識別するための数値です。ユーザーは一つ以上のグループに所属できます。

### 実ユーザーID (Real UID) と実効ユーザーID (Effective UID)

Unix系システムでは、プロセスのユーザーIDには「実ユーザーID」と「実効ユーザーID」の概念があります。

*   **実ユーザーID (Real UID)**: プロセスを起動したユーザーのUIDです。これはプロセスの所有者を識別し、通常は変更されません。
*   **実効ユーザーID (Effective UID)**: プロセスがファイルやその他のシステムリソースにアクセスする際に使用されるUIDです。通常は実ユーザーIDと同じですが、`setuid`ビットが設定されたプログラムを実行した場合など、一時的に異なるUID（例えばrootのUID）になることがあります。これにより、一般ユーザーが特定の特権操作を実行できるようになります。

同様に、グループIDにも**実グループID (Real GID)**と**実効グループID (Effective GID)**が存在し、それぞれ実ユーザーIDと実効ユーザーIDに対応する役割を果たします。

### システムコール (Syscall)

システムコールは、ユーザー空間のプログラムがオペレーティングシステムカーネルのサービスを要求するためのインターフェースです。ファイルI/O、プロセス管理、メモリ管理など、OSが提供するほとんどの機能はシステムコールを通じて利用されます。Go言語の`syscall`パッケージは、これらの低レベルなシステムコールをGoプログラムから直接呼び出すための機能を提供します。

このコミットでは、`syscall.SYS_GETUID`, `syscall.SYS_GETEUID`, `syscall.SYS_GETGID`, `syscall.SYS_GETEGID`といった定数を使用して、対応するシステムコールを呼び出しています。

## 技術的詳細

このコミットの主要な変更点は、`src/lib/os/user.go`という新しいファイルが追加され、その中で以下の4つの関数が定義されていることです。

*   `func Getuid() (uid int, err Error)`: プロセスの実ユーザーIDを返します。
*   `func Geteuid() (uid int, err Error)`: プロセスの実効ユーザーIDを返します。
*   `func Getgid() (uid int, err Error)`: プロセスの実グループIDを返します。
*   `func Getegid() (uid int, err Error)`: プロセスの実効グループIDを返します。

これらの関数は、内部的にGoの`syscall`パッケージを利用して、対応するUnixシステムコールを呼び出しています。

例えば、`Getuid()`関数の実装は以下のようになっています。

```go
func Getuid() (uid int, err Error) {
	u, _, e := syscall.Syscall(syscall.SYS_GETUID, 0, 0, 0);
	if e != 0 {
		return -1, ErrnoToError(e)
	}
	return int(u), nil
}
```

ここで注目すべき点は以下の通りです。

1.  **`syscall.Syscall`の利用**: `syscall.Syscall`は、指定されたシステムコール番号（例: `syscall.SYS_GETUID`）と最大3つの引数を受け取り、システムコールを実行します。戻り値は3つの`uintptr`型で、最初の2つはシステムコールの戻り値、3つ目はエラーコード（errno）を表します。
2.  **エラーハンドリング**: システムコールがエラーを返した場合（`e != 0`）、`ErrnoToError(e)`を呼び出してGoの`Error`型に変換し、それを返しています。これはGoのエラーハンドリングの慣習に従ったものです。
3.  **型変換**: システムコールの戻り値は`uintptr`型ですが、ユーザーIDやグループIDは整数として扱われるため、`int(u)`のように型変換を行っています。

また、`src/lib/os/Makefile`が更新され、新しく追加された`user.go`ファイルがビルドプロセスに含まれるように変更されています。これは、`gobuild`ツールによって自動生成されるMakefileの定義に`user.go`が追加されたことを示しています。具体的には、`gobuild`コマンドの引数に`user.go`が追加され、生成されるオブジェクトファイルリスト`O2`に`user.$O`が、そしてアーカイブコマンドに`user.$O`が追加されています。

## コアとなるコードの解説

### `src/lib/os/Makefile`の変更

この変更は、`user.go`がGoの`os`パッケージの一部として正しくビルドされるようにするためのものです。

*   `gobuild`コマンドの引数に`user.go`が追加されました。これは、`gobuild`が`os`パッケージをビルドする際に`user.go`もコンパイル対象に含めることを指示しています。
*   `O2`変数（オブジェクトファイルリスト）に`user.$O`が追加されました。`$O`はコンパイルされたオブジェクトファイルの拡張子（例: `.5` for 5g, `.6` for 6g）を表します。これにより、`user.go`から生成されたオブジェクトファイルがリンク対象に含まれるようになります。
*   `a2`ターゲットの`$(AR)`コマンド（アーカイブコマンド）の引数にも`user.$O`が追加されました。これは、`os`パッケージのアーカイブファイル（`_obj$D/os.a`）に`user.go`のオブジェクトファイルが含められることを意味します。

これらの変更により、`Getuid`などの関数が`os`パッケージの一部として利用可能になります。

### `src/lib/os/user.go`の新規追加

このファイルは、Goプログラムが現在のプロセスのユーザーおよびグループIDを取得するための主要なロジックを含んでいます。

*   **パッケージ宣言**: `package os`により、このファイルがGoの標準ライブラリ`os`パッケージの一部であることが示されます。
*   **インポート**: `syscall`パッケージと`os`パッケージをインポートしています。`syscall`は低レベルなシステムコールへのアクセスを提供し、`os`はエラー型`Error`（当時のGoのエラーハンドリング）を提供するためにインポートされています。
*   **`Getuid()`関数**:
    *   `syscall.Syscall(syscall.SYS_GETUID, 0, 0, 0)`を呼び出し、Unixの`getuid()`システムコールを実行します。
    *   戻り値`u`はUID、`e`はエラーコード（errno）です。
    *   エラーが発生した場合（`e != 0`）、`ErrnoToError(e)`でGoのエラー型に変換して返します。
    *   成功した場合、`u`を`int`型にキャストしてUIDとして返します。
*   **`Geteuid()`関数**:
    *   `syscall.Syscall(syscall.SYS_GETEUID, 0, 0, 0)`を呼び出し、Unixの`geteuid()`システムコールを実行します。
    *   ロジックは`Getuid()`と同様で、実効ユーザーIDを返します。
*   **`Getgid()`関数**:
    *   `syscall.Syscall(syscall.SYS_GETGID, 0, 0, 0)`を呼び出し、Unixの`getgid()`システムコールを実行します。
    *   ロジックは`Getuid()`と同様で、実グループIDを返します。
*   **`Getegid()`関数**:
    *   `syscall.Syscall(syscall.SYS_GETEGID, 0, 0, 0)`を呼び出し、Unixの`getegid()`システムコールを実行します。
    *   ロジックは`Getuid()`と同様で、実効グループIDを返します。

これらの関数は、Goプログラムが実行されている環境のユーザーおよびグループ情報を取得するための基本的なAPIを提供し、より高度な権限管理やセキュリティ関連の機能の実装の基礎となります。
