## 元コミット内容

このコミットは、`bytes`パッケージに`ContainsAny`関数を追加し、関連するテストコードも移植するものです。これは、`strings`パッケージに既に存在する同名の関数との一貫性を保つことを目的としています。

## 変更の背景

Go言語の標準ライブラリには、文字列操作を行う`strings`パッケージと、バイトスライス操作を行う`bytes`パッケージがあります。これら二つのパッケージは、しばしば類似の機能を提供し、APIの一貫性が重視されています。

`strings`パッケージには、特定の文字列内に指定された文字セットのいずれかの文字が含まれているかを判定する`ContainsAny`関数が既に存在していました。しかし、`bytes`パッケージにはこれに対応する関数がありませんでした。この非対称性は、開発者がバイトスライスを扱う際に不便を感じる可能性があり、APIの一貫性というGo言語の設計原則にも反していました。

このコミットは、Issue #15140で報告されたこのギャップを埋めるために行われました。`bytes`パッケージに`ContainsAny`を追加することで、`strings`パッケージとの機能的な一貫性を確保し、開発者がより直感的に両パッケージを利用できるようになります。

## 前提知識の解説

*   **Go言語の`bytes`パッケージと`strings`パッケージ**:
    *   `strings`パッケージは、UTF-8でエンコードされた文字列（`string`型）を操作するためのユーティリティ関数を提供します。
    *   `bytes`パッケージは、バイトスライス（`[]byte`型）を操作するためのユーティリティ関数を提供します。Go言語では、文字列は不変のバイトスライスとして内部的に表現され、UTF-8エンコーディングが標準です。`bytes`パッケージは、より低レベルなバイト操作や、バイナリデータの処理によく使用されます。
*   **`ContainsAny`関数**:
    *   一般的に、`ContainsAny(s, chars)`のような関数は、文字列`s`またはバイトスライス`s`が、`chars`で指定された文字セットのいずれかの文字を含んでいる場合に`true`を返します。
*   **`IndexAny`関数**:
    *   `IndexAny(s, chars)`関数は、文字列`s`またはバイトスライス`s`内で、`chars`で指定された文字セットのいずれかの文字が最初に出現するインデックスを返します。もしどの文字も含まれていない場合は`-1`を返します。`ContainsAny`は、この`IndexAny`の結果が`-1`でないかどうかをチェックすることで実装されることが多いです。
*   **UTF-8エンコーディング**:
    *   Go言語の文字列はすべてUTF-8でエンコードされています。`bytes.ContainsAny`も、`chars`引数として渡される文字列がUTF-8エンコードされたUnicodeコードポイントとして扱われることを明示しています。これにより、マルチバイト文字（例: 日本語の文字や絵文字）も正しく処理されます。

## 技術的詳細

このコミットで追加された`bytes.ContainsAny`関数は、`bytes.IndexAny`関数を内部的に呼び出すことで実装されています。具体的には、`bytes.ContainsAny(b []byte, chars string) bool`は、`bytes.IndexAny(b, chars) >= 0`という非常に簡潔なロジックで定義されています。

この実装は、以下の理由から効率的かつ適切です。

1.  **既存の効率的なロジックの再利用**: `bytes.IndexAny`は、バイトスライス`b`内で`chars`に含まれる任意のUnicodeコードポイントを検索する最適化されたロジックを既に持っています。`ContainsAny`を`IndexAny`の上に構築することで、コードの重複を避け、`IndexAny`の持つパフォーマンス上の利点をそのまま享受できます。
2.  **意味論的な整合性**: `ContainsAny`が「含まれているか」を問うのに対し、`IndexAny`は「どこに含まれているか」を問います。もし含まれていればインデックスが返され、含まれていなければ`-1`が返されるという`IndexAny`のセマンティクスは、`ContainsAny`のブール値の結果を導出するのに完全に適合します。
3.  **UTF-8の扱い**: `bytes.IndexAny`は、`chars`引数をUTF-8エンコードされたUnicodeコードポイントとして解釈し、バイトスライス`b`内の対応するコードポイントを検索します。これにより、`ContainsAny`も自動的にUTF-8対応となり、マルチバイト文字を含む`chars`引数に対しても正しく機能します。

テストコードも`strings`パッケージから移植されており、空のバイトスライス、単一文字、複数文字、マルチバイト文字、特殊文字（正規表現のメタ文字など）を含む多様なケースで`ContainsAny`が期待通りに動作することを確認しています。これにより、関数の堅牢性が保証されます。

## コアとなるコードの解説

### `src/bytes/bytes.go` の `ContainsAny` 関数

```go
// ContainsAny reports whether any of the UTF-8-encoded Unicode code points in chars are within b.
func ContainsAny(b []byte, chars string) bool {
	return IndexAny(b, chars) >= 0
}
```

*   **関数シグネチャ**: `func ContainsAny(b []byte, chars string) bool`
    *   `b []byte`: 検索対象となるバイトスライスです。
    *   `chars string`: 検索する文字セットを含む文字列です。この文字列はUTF-8エンコードされたUnicodeコードポイントとして扱われます。
    *   `bool`: `b`内に`chars`のいずれかの文字が含まれていれば`true`、そうでなければ`false`を返します。
*   **実装**: `return IndexAny(b, chars) >= 0`
    *   この実装は非常にシンプルで、`bytes.IndexAny`関数を呼び出しています。
    *   `bytes.IndexAny(b, chars)`は、`b`内で`chars`に含まれる任意の文字が最初に出現するインデックスを返します。もしどの文字も`b`内に見つからなければ`-1`を返します。
    *   したがって、`IndexAny`の結果が`0`以上であれば（つまり、文字が見つかれば）、`ContainsAny`は`true`を返します。`-1`であれば`false`を返します。

### `src/bytes/bytes_test.go` のテストケース

追加されたテストコードは、`ContainsAnyTests`という構造体のスライスを定義し、様々な入力パターンと期待される結果を網羅しています。

```go
var ContainsAnyTests = []struct {
	b        []byte
	substr   string
	expected bool
}{
	{[]byte(""), "", false},         // 空のバイトスライスと空の検索文字
	{[]byte(""), "a", false},        // 空のバイトスライスと単一文字
	{[]byte(""), "abc", false},       // 空のバイトスライスと複数文字
	{[]byte("a"), "", false},        // 単一文字のバイトスライスと空の検索文字
	{[]byte("a"), "a", true},        // 単一文字の一致
	{[]byte("aaa"), "a", true},      // 複数回出現する単一文字
	{[]byte("abc"), "xyz", false},    // 一致しない文字セット
	{[]byte("abc"), "xcz", true},     // 一致する文字が混在
	{[]byte("a☺b☻c☹d"), "uvw☻xyz", true}, // マルチバイト文字を含むケース
	{[]byte("aRegExp*"), ".(|)*+?^$[]", true}, // 正規表現の特殊文字を含むケース
	{[]byte(dots + dots + dots), " ", false}, // 多数のドットとスペースの不一致
}

func TestContainsAny(t *testing.T) {
	for _, ct := range ContainsAnyTests {
		if ContainsAny(ct.b, ct.substr) != ct.expected {
			t.Errorf("ContainsAny(%s, %s) = %v, want %v",
				ct.b, ct.substr, !ct.expected, ct.expected)
		}
	}
}
```

*   **`ContainsAnyTests`**: このスライスは、テスト対象のバイトスライス`b`、検索文字セット`substr`、そして期待されるブール値`expected`の組み合わせを定義しています。
*   **`TestContainsAny`関数**:
    *   `for`ループで`ContainsAnyTests`の各テストケースを反復処理します。
    *   `ContainsAny(ct.b, ct.substr)`を呼び出し、その結果が`ct.expected`と一致するかどうかをチェックします。
    *   もし一致しない場合は、`t.Errorf`を使ってエラーメッセージを出力し、テスト失敗を報告します。
    *   特に注目すべきは、マルチバイト文字（`☺`, `☻`, `☹`）や正規表現の特殊文字を含むテストケースが含まれている点です。これにより、`ContainsAny`がUTF-8エンコーディングと特殊文字を正しく処理できることが確認されます。
