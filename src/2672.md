## 変更の背景

このコミットの主な背景は、Go言語の仕様書 `doc/go_spec.html` 内の冗長な定義を削除し、同時に識別子のエクスポートルールに関する記述をより正確にすることにあります。

初期のGo言語の仕様策定段階では、様々な用語や概念が定義されていましたが、その中には最終的に使用されなかったものも存在しました。`capital_letter` という用語もその一つで、仕様書内で定義されていながら、実際のルール記述には使われていませんでした。このような未使用の定義は、ドキュメントの肥大化や読者の混乱を招く可能性があるため、削除されました。

また、Go言語の重要な特徴の一つである「識別子のエクスポートルール」に関する記述も、より厳密な表現に修正されました。これにより、仕様の曖昧さを排除し、言語の動作に関する誤解を防ぐことが目的です。

## 前提知識の解説

### Go言語の識別子のエクスポートルール

Go言語では、パッケージの外部からアクセスできる識別子（変数、関数、型など）は、その名前の最初の文字が大文字である必要があります。これはGo言語の設計思想の一つであり、コードの可読性とパッケージ間の依存関係の明確化に貢献しています。例えば、`MyFunction` はエクスポートされますが、`myFunction` はエクスポートされません。

### Unicode文字クラス

Unicodeは、世界中の文字を統一的に扱うための文字コード標準です。Unicodeの各文字には、その文字の特性を示す「文字クラス（Character Class）」が割り当てられています。例えば、`Letter` は文字全般を指し、`Digit` は数字を指します。
このコミットで特に言及されている `Letter, uppercase` は、UnicodeのGeneral Categoryプロパティにおける `Lu` (Letter, Uppercase) に相当します。これは、大文字のアルファベットやその他の大文字として扱われる文字を厳密に定義するものです。

### Go言語の仕様書 (`doc/go_spec.html`)

`doc/go_spec.html` は、Go言語の公式な言語仕様を記述したHTMLドキュメントです。Go言語の構文、セマンティクス、組み込み型、パッケージ、実行モデルなど、言語のあらゆる側面が詳細に定義されています。このドキュメントは、Goコンパイラやツールの実装者、およびGo言語の深い理解を求める開発者にとって最も重要な情報源の一つです。

## 技術的詳細

このコミットは、Go言語の仕様書の内容を改善するものであり、Goコンパイラやランタイムの動作に直接的な変更を加えるものではありません。しかし、仕様書の正確性と明確性を高めるという点で、言語の健全な発展に寄与しています。

1.  **`capital_letter` 定義の削除**:
    *   以前の仕様書には、`capital_letter = /* a Unicode code point classified as "Letter, uppercase" */ .` という定義が存在しました。
    *   この定義は、`unicode_letter` や `unicode_digit` と同様に、特定のUnicode文字クラスを指すものとして導入された可能性があります。
    *   しかし、実際のGo言語の識別子のエクスポートルールを記述する箇所では、この `capital_letter` という用語は使われず、直接 `Unicode upper case letter` という表現が用いられていました。
    *   そのため、この定義は冗長であり、削除されました。これにより、仕様書がより簡潔になりました。

2.  **識別子のエクスポートルール記述の明確化**:
    *   識別子のエクスポートルールを説明する箇所で、以前は `the first character of the identifier's name is a Unicode upper case letter;` と記述されていました。
    *   この記述は、`the first character of the identifier's name is a Unicode upper case letter (Unicode class "Lu");` に変更されました。
    *   `(Unicode class "Lu")` という追記は、`Unicode upper case letter` が具体的にUnicodeのGeneral Categoryプロパティにおける `Lu` (Letter, Uppercase) を指すことを明示しています。
    *   これにより、大文字の定義に関する曖昧さが完全に排除され、Go言語の識別子ルールが国際的な文字セットであるUnicodeのどのカテゴリに厳密に準拠しているかが明確になりました。これは、多言語対応や将来的なUnicodeバージョンの変更に対する堅牢性を高める上で重要です。

## コアとなるコードの解説

上記の差分は、`doc/go_spec.html` 内の2つの主要な変更点を示しています。

1.  **`-capital_letter = /* a Unicode code point classified as "Letter, uppercase" */ .`**:
    この行は、Go言語の仕様書内で定義されていた `capital_letter` という用語の定義を削除しています。この定義は、仕様書の他の部分で実際に使用されていなかったため、冗長と判断され削除されました。これにより、仕様書はより簡潔になり、読者が不要な情報を処理する必要がなくなります。

2.  **`<li>the first character of the identifier\'s name is a Unicode upper case letter;` から `<li>the first character of the identifier\'s name is a Unicode upper case letter (Unicode class "Lu");` への変更**:
    この変更は、Go言語の識別子のエクスポートルールに関する記述を修正しています。以前の記述は「識別子の最初の文字がUnicodeの大文字であること」というものでしたが、これに `(Unicode class "Lu")` という補足が追加されました。
    この `(Unicode class "Lu")` は、UnicodeのGeneral Categoryプロパティにおける「Letter, Uppercase」を明示的に指します。これにより、「大文字」という言葉がUnicodeのどの厳密な定義に基づくものなのかが明確になり、仕様の解釈における曖昧さが排除されます。これは、Go言語の仕様が国際的な文字セットをどのように扱うかについて、より正確な情報を提供するものです。
