## 変更の背景

このコミットの背景には、主に以下の2点があります。

1.  **Gerritプロジェクトの公式URLの変更または明確化**: 以前はGerritプロジェクトの参照として `https://code.google.com/p/gerrit/` が使用されていましたが、これはGoogle Codeのプロジェクトホスティングサービスが終了したか、Gerritの公式ウェブサイトが `https://www.gerritcodereview.com/` に移行したことによるものと考えられます。ドキュメントは常に最新かつ正確な情報を提供する必要があるため、このURLの更新は必須でした。
2.  **GoプロジェクトのGerrit利用方法の明確化**: Goプロジェクトは、GitHubのプルリクエストではなく、独自のGerritインスタンス (`https://go-review.googlesource.com/`) を使用してコードレビューを行っています。`CONTRIBUTING.md` は新規貢献者にとって最初の入り口となるため、この重要な情報を明確に伝えることで、貢献プロセスにおける混乱を避ける目的があります。特に「We do not accept GitHub pull requests」という強いメッセージの後に、GoがGerritをどのように利用しているかを具体的に示すことで、貢献者が正しいワークフローを理解しやすくなります。

`Fixes #14662` との記載がありますが、Goの公式イシュートラッカーでは該当するイシューは見つかりませんでした。これは、当時の内部的なトラッキングシステムや、現在とは異なるイシュー管理方法に起因する可能性があります。しかし、変更内容から判断すると、ドキュメントの正確性と貢献プロセスの明確化が主な動機であることは明らかです。

## 前提知識の解説

### Gerrit (コードレビューシステム)

Gerritは、Gitリポジトリ上で動作するオープンソースのコードレビューシステムです。Googleによって開発され、多くのオープンソースプロジェクト（Android、Chromium、Goなど）で採用されています。Gerritの主な特徴は以下の通りです。

*   **変更セットベースのレビュー**: Gerritは、コミット単位ではなく「変更セット（Change-Id）」という単位でコードレビューを行います。これにより、複数のコミットをまとめてレビューしたり、レビューコメントに基づいてコミットを修正・更新したりするプロセスが効率化されます。
*   **ワークフローの強制**: Gerritは、コードがマージされる前に必ずレビューを通過することを強制するワークフローを提供します。これにより、コード品質の維持とプロジェクトの整合性が保たれます。
*   **Gitとの統合**: Gitのフックやプロトコルと深く統合されており、`git push` コマンドを通じて直接レビューを提出できます。
*   **Webインターフェース**: レビューコメントの追加、変更の比較、承認・拒否などの操作をWebブラウザ上で行える直感的なインターフェースを提供します。

Goプロジェクトでは、GitHubのプルリクエストモデルではなく、このGerritを主要なコードレビューツールとして採用しています。これは、Goプロジェクトの規模、貢献者の数、および厳格なコード品質基準を維持するために、Gerritの提供する詳細なレビュー機能とワークフロー管理が適しているためです。

### Goの貢献プロセス

Goプロジェクトへの貢献は、一般的なGitHubのプルリクエストとは異なる独自のワークフローに従います。

1.  **Go開発環境のセットアップ**: Goのソースコードを取得し、開発環境をセットアップします。
2.  **変更の実装**: 提案する変更を実装し、ローカルのGitリポジトリにコミットします。この際、Gerritが変更セットを識別するために必要な `Change-Id` をコミットメッセージに含める必要があります。これは通常、`git-codereview` ツールによって自動的に生成されます。
3.  **Gerritへのプッシュ**: `git push` コマンドの代わりに、`git-codereview` ツールを使用して変更をGoのGerritインスタンス (`go-review.googlesource.com`) にプッシュします。
4.  **コードレビュー**: Gerrit上で変更が公開され、Goチームのメンバーや他の貢献者によってレビューされます。コメントや提案に基づいて、必要に応じて変更を修正し、再度Gerritにプッシュします。
5.  **承認とマージ**: 変更が承認されると、GoチームのコミッターによってメインのGoリポジトリにマージされます。

このプロセスは、Goプロジェクトの品質と一貫性を保つために非常に重要です。

## 技術的詳細

このコミットは、Goプロジェクトのドキュメントファイルである `CONTRIBUTING.md` (Markdown形式) と `doc/contribute.html` (HTML形式) の2つのファイルを変更しています。変更の核心は、Gerritコードレビューシステムへの参照方法の更新と明確化です。

具体的には、以下の点が変更されています。

1.  **Gerritの公式ウェブサイトURLの更新**:
    *   古いURL: `https://code.google.com/p/gerrit/`
    *   新しいURL: `https://www.gerritcodereview.com/`
    この変更は、Gerritプロジェクト自体の公式ウェブサイトの変更に対応するものです。
2.  **Goプロジェクトが使用するGerritインスタンスの明記**:
    *   `CONTRIBUTING.md` において、「(we use [Gerrit](https://code.google.com/p/gerrit/) instead for code review).」という記述が、「(we use [an instance](https://go-review.googlesource.com/) of the [Gerrit](https://www.gerritcodereview.com/) code review system instead).」に変更されました。
    *   これにより、GoプロジェクトがGerritという一般的なシステムを使用しているだけでなく、具体的に `https://go-review.googlesource.com/` という独自のインスタンスを利用していることが明確に示されます。これは、貢献者が正しいプラットフォームにアクセスするために非常に重要な情報です。
3.  **HTMLドキュメント内のGerritリンクの修正**:
    *   `doc/contribute.html` 内のGerritへのリンクも、同様に `https://code.google.com/p/gerrit/` から `https://www.gerritcodereview.com/` へと更新されています。ただし、HTMLのリンク構文の修正も含まれており、`<a>` タグの `href` 属性が正しく設定されるように変更されています（`https://www.gerritcodereview.com/"` のように末尾に余分な引用符があったものを修正）。

これらの変更は、Goプロジェクトへの貢献を検討している開発者に対して、最新かつ正確な情報を提供し、貢献プロセスをよりスムーズにするためのものです。

## コアとなるコードの解説

### `CONTRIBUTING.md` の変更

この変更では、GoプロジェクトがGitHubプルリクエストを受け付けない理由を説明する箇所が更新されています。

*   **削除行**: `-(we use [Gerrit](https://code.google.com/p/gerrit/) instead for code review).`
    *   ここでは、古いGerritプロジェクトのURL (`https://code.google.com/p/gerrit/`) が参照されていました。
*   **追加行**: `+(we use [an instance](https://go-review.googlesource.com/) of the\n+[Gerrit](https://www.gerritcodereview.com/) code review system instead).`
    *   新しい行では、まずGoがGerritの「インスタンス」を使用していることを明記し、そのインスタンスのURL (`https://go-review.googlesource.com/`) を提供しています。
    *   さらに、Gerrit自体の新しい公式ウェブサイトURL (`https://www.gerritcodereview.com/`) も参照しています。
    *   これにより、Goプロジェクトの貢献者は、Goが使用する具体的なGerritインスタンスと、Gerritシステム全般についての情報源の両方にアクセスできるようになります。

### `doc/contribute.html` の変更

この変更は、HTML形式の貢献ガイドライン内のGerritへのリンクを更新しています。

*   **削除行**: `-system called <a href=\"https://code.google.com/p/gerrit/\">Gerrit</a>.`
    *   ここでも、古いGerritプロジェクトのURLが使用されていました。
*   **追加行**: `+system called <a https://www.gerritcodereview.com/\">Gerrit</a>.`
    *   新しい行では、Gerritの公式ウェブサイトURLを `https://www.gerritcodereview.com/` に更新しています。
    *   注目すべきは、元のHTMLコードの `href` 属性の記述ミス（`href=` の後に `"` が欠落）が修正され、正しいHTML構文 `href="https://www.gerritcodereview.com/"` になっている点です。これにより、リンクが正しく機能するようになります。

これらの変更は、Goプロジェクトのドキュメントの正確性を向上させ、貢献者がGoのコードレビュープロセスをより容易に理解し、参加できるようにするための重要な更新です。
