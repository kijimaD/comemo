## 変更の背景

この変更は、Go言語の `encoding/base64` パッケージのドキュメントに関する課題 #13011 に対応するものです。この課題では、`encoding/base64` パッケージのドキュメントが分かりにくい、または一部が未記述であるという指摘がありました。特に、`encodeStd` のような定数や関連する部分の記述順序が混乱を招くという意見がありました。

Go言語では、`Example` 関数を記述することで、パッケージや関数の使用例をドキュメントに自動的に含めることができます。これにより、ユーザーは実際のコードを通じて機能の動作を理解しやすくなります。このコミットは、`encoding/base64` パッケージ全体の基本的なエンコードとデコードのフローを示すパッケージレベルの `Example` を追加することで、ドキュメントの明確性を向上させ、ユーザーがパッケージをより簡単に使い始められるようにすることを目的としています。

## 前提知識の解説

### Base64エンコーディング

Base64は、バイナリデータをASCII文字列の形式に変換するエンコーディング方式です。主に、テキストベースのプロトコル（例: 電子メール、HTTP）でバイナリデータを安全に転送するために使用されます。Base64は、64種類の文字（A-Z, a-z, 0-9, +, /）とパディング文字（=）を使用してデータを表現します。3バイトのバイナリデータを4文字のBase64文字列に変換するのが基本原理です。

### Go言語の `encoding/base64` パッケージ

Go言語の標準ライブラリには、Base64エンコーディングとデコーディングを扱うための `encoding/base64` パッケージが用意されています。このパッケージは、標準のBase64エンコーディング（`StdEncoding`）とURLおよびファイル名セーフなBase64エンコーディング（`URLEncoding`）を提供します。主な機能としては、バイトスライスをBase64文字列にエンコードする `EncodeToString` や、Base64文字列をバイトスライスにデコードする `DecodeString` などがあります。

### Go言語の `Example` 関数

Go言語のテストフレームワークには、`Example` 関数という特別な機能があります。`Example` 関数は、`_test.go` ファイル内に `func Example()`, `func ExampleF()` (関数 `F` の例), `func ExampleT()` (型 `T` の例), `func ExampleT_M()` (型 `T` のメソッド `M` の例) の形式で記述されます。

これらの関数は、通常のテスト関数と同様に `go test` コマンドで実行されますが、その目的はコードの動作を検証することだけではありません。`Example` 関数の出力は、`// Output:` コメントで指定された期待される出力と比較されます。この比較が成功すると、`Example` 関数はテストに合格したとみなされます。

さらに重要なのは、`Example` 関数は `go doc` コマンドで生成されるドキュメントに自動的に組み込まれる点です。これにより、ユーザーはパッケージや関数のドキュメントを読む際に、実際の使用例とその出力を見ることができます。これは、ライブラリのAPIを理解し、適切に使用するための非常に強力なツールとなります。

このコミットで追加された `Example()` 関数は、`encoding/base64` パッケージの基本的な使用方法をデモンストレーションするために設計されています。

1.  **パッケージレベルのExample**: `func Example()` という名前は、この例が特定の関数や型ではなく、`encoding/base64` パッケージ全体の基本的な使い方を示すものであることを意味します。
2.  **エンコードとデコードのフロー**:
    *   `msg := "Hello, 世界"`: エンコードする元の文字列を定義します。日本語の「世界」が含まれているのは、UTF-8エンコーディングが正しく処理されることを示す良い例です。
    *   `encoded := base64.StdEncoding.EncodeToString([]byte(msg))`: `base64.StdEncoding` を使用して、元の文字列（バイトスライスに変換したもの）をBase64文字列にエンコードします。`StdEncoding` は標準のBase64エンコーディングです。

この `Example` 関数は、`encoding/base64` パッケージの最も一般的なユースケースである「文字列のエンコードとデコード」を簡潔かつ明確に示しており、ドキュメントの可読性と実用性を大幅に向上させます。

## コアとなるコードの解説

変更は `src/encoding/base64/example_test.go` ファイルに集中しており、`Example()` という新しい関数が追加されています。

```go
func Example() {
	msg := "Hello, 世界"
	encoded := base64.StdEncoding.EncodeToString([]byte(msg))
	fmt.Println(encoded)
	decoded, err := base64.StdEncoding.DecodeString(encoded)
	if err != nil {
		fmt.Println("decode error:", err)
		return
	}
	fmt.Println(string(decoded))
	// Output:
	// SGVsbG8sIOS4lueVjA==
	// Hello, 世界
}
```

このコードスニペットは、`encoding/base64` パッケージの基本的な使い方をエンドツーエンドで示しています。

1.  `msg := "Hello, 世界"`: エンコード対象の文字列を定義しています。この文字列にはマルチバイト文字（日本語）が含まれており、Base64エンコーディングがUTF-8文字列を正しく処理できることを示しています。
2.  `encoded := base64.StdEncoding.EncodeToString([]byte(msg))`: `base64.StdEncoding` を使用して、`msg` をバイトスライスに変換し、それをBase64形式の文字列にエンコードしています。`StdEncoding` はRFC 4648で定義されている標準のBase64アルファベットを使用します。
3.  `fmt.Println(encoded)`: エンコードされたBase64文字列を標準出力に出力します。この例では `SGVsbG8sIOS4lueVjA==` となります。
4.  `decoded, err := base64.StdEncoding.DecodeString(encoded)`: エンコードされた文字列 `encoded` を元のバイトスライスにデコードします。`DecodeString` は、入力が有効なBase64文字列でない場合にエラーを返す可能性があります。
5.  `if err != nil { ... }`: デコード処理でエラーが発生した場合の基本的なエラーハンドリングを示しています。実際のアプリケーションでは、より堅牢なエラー処理が必要になります。
6.  `fmt.Println(string(decoded))`: デコードされたバイトスライスを再度文字列に変換し、標準出力に出力します。これにより、元の文字列 `Hello, 世界` が正しく復元されたことを確認できます。
7.  `// Output:` コメント: この特別なコメントは、`go test` コマンドがこの `Example` 関数を実行した際に期待される標準出力の内容を指定します。`go test` は、実際の出力とこのコメントの内容を比較し、一致すればテストが成功したと判断します。この機能により、ドキュメントに表示される例が常に最新かつ正確であることが保証されます。

この `Example` 関数は、`encoding/base64` パッケージの最も一般的で重要な機能であるエンコードとデコードのプロセスを、簡潔かつ実行可能な形で提供することで、ユーザーがパッケージの利用方法を迅速に理解するのに役立ちます。
