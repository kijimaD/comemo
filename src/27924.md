## 元コミット内容

`math/big: implement GobDecode/Encode for big.Float`

`big.Float`型に対して`GobEncode`および`GobDecode`メソッドを実装し、それらのテストを追加しました。

これにより、Issue #14593 が修正されます。

## 変更の背景

Go言語の`math/big`パッケージは、任意精度の数値演算を提供します。特に`big.Float`は、標準の`float32`や`float64`では表現できない高い精度が求められる科学技術計算や金融計算などで利用されます。

`gob`パッケージは、Goのプログラム間でGoのデータ構造をエンコード/デコードするためのメカニズムを提供します。これは、ネットワーク経由でのデータ転送や、ファイルへの永続化など、Goネイティブな環境でのデータ交換に非常に便利です。

このコミット以前は、`big.Float`型は`gob`パッケージによる直接的なシリアライズ/デシリアライズをサポートしていませんでした。これは、`big.Float`の値を`gob`形式で保存したり、ネットワーク経由で送信したりする必要がある開発者にとって不便でした。Issue #14593 は、この機能の欠如を指摘し、`big.Float`が`gob`エンコーディングをサポートするよう求めるものでした。

この変更の背景には、`big.Float`の利用者が、その値を他のGoプログラムやストレージシステムと効率的かつ安全に交換できるようにするというニーズがありました。`GobEncode`と`GobDecode`を実装することで、`big.Float`はGoの標準的なシリアライズメカニズムに統合され、より使いやすくなりました。

## 前提知識の解説

### `math/big`パッケージと`big.Float`

`math/big`パッケージは、Go言語で任意精度の数値演算を行うための型を提供します。
*   **`big.Int`**: 任意精度の整数。
*   **`big.Rat`**: 任意精度の有理数（分数）。
*   **`big.Float`**: 任意精度の浮動小数点数。

`big.Float`は、`float32`や`float64`のような固定小数点数では精度が足りない場合に用いられます。例えば、非常に大きな数や非常に小さな数を扱う場合、あるいは計算過程で発生する丸め誤差を最小限に抑えたい場合に有効です。`big.Float`は、仮数部（mantissa）と指数部（exponent）を持ち、その精度（`prec`）を動的に設定できます。また、丸めモード（`RoundingMode`）や計算結果の正確性（`Accuracy`）も管理します。

### `encoding/gob`パッケージ

`encoding/gob`パッケージは、Goのデータ構造をバイナリ形式でエンコードおよびデコードするためのGo固有のメカニズムです。
*   **自己記述的**: `gob`ストリームは、データ型に関する情報を含んでいるため、受信側は事前に型を知らなくてもデータをデコードできます。
*   **効率性**: JSONやXMLと比較して、よりコンパクトなバイナリ形式でデータを表現します。
*   **Go固有**: Goの型システムと密接に連携しており、構造体、スライス、マップなどのGoのデータ型を自然に扱えます。
*   **`GobEncoder`と`GobDecoder`インターフェース**: 型がこれらのインターフェースを実装している場合、`gob`パッケージはデフォルトのエンコーディングではなく、これらのカスタムメソッドを使用してエンコード/デコードを行います。これにより、開発者は特定の型のシリアライズ方法を細かく制御できます。

### シリアライズとデシリアライズ

*   **シリアライズ（Serialization）**: オブジェクトやデータ構造を、ストレージに保存したり、ネットワーク経由で転送したりできる形式（通常はバイトストリーム）に変換するプロセスです。
*   **デシリアライズ（Deserialization）**: シリアライズされたデータストリームを、元のオブジェクトやデータ構造に再構築するプロセスです。

このコミットは、`big.Float`型が`gob`形式でシリアライズおよびデシリアライズされるための具体的な実装を提供します。

## 技術的詳細

このコミットでは、`big.Float`型が`encoding/gob`パッケージと連携できるように、`GobEncode`と`GobDecode`という2つのメソッドが`*Float`レシーバに対して追加されています。

### `GobEncode`メソッド

`GobEncode`メソッドは、`big.Float`の内部状態をバイトスライスに変換します。このバイトスライスは、`gob`エンコーダによって書き込まれます。

1.  **バージョン管理**: `floatGobVersion`という定数（`byte = 1`）を導入し、エンコーディングのバージョンを管理します。これにより、将来の変更に対して後方互換性を保つことができます。
2.  **内部状態のエンコード**: `big.Float`の以下の内部状態を効率的にバイトにパックします。
    *   `mode` (丸めモード)
    *   `acc` (正確性)
    *   `form` (数値の形式: 有限数、NaN、Inf)
    *   `neg` (符号: 負数かどうか)
    *   `prec` (精度)
    *   `exp` (指数部) - 有限数の場合のみ
    *   `mant` (仮数部) - 有限数の場合のみ
3.  **バイト配列の構築**:
    *   最初のバイトは`floatGobVersion`。
    *   2番目のバイトは、`mode`, `acc`, `form`, `neg`の各情報をビットフィールドとして結合したもの。これにより、これらの小さな情報を1バイトに効率的に格納します。
    *   `prec`と`exp`は`binary.BigEndian.PutUint32`を使用して4バイトのビッグエンディアン形式で格納されます。
    *   `mant`（仮数部）は`x.mant.bytes()`メソッドを使ってバイトスライスに変換され、格納されます。`_W`や`_S`といった定数は、`big.Float`の内部表現（ワードサイズなど）に関連するものです。

### `GobDecode`メソッド

`GobDecode`メソッドは、`gob`デコーダから受け取ったバイトスライスを解析し、`big.Float`の内部状態を再構築します。

1.  **nil値のハンドリング**: 受信したバイトスライスが空の場合（送信側が`nil`またはデフォルト値を送った場合）、`big.Float`をゼロ値にリセットします。
2.  **バージョンチェック**: バイトスライスの最初のバイトをチェックし、エンコーディングバージョンがサポートされているかを確認します。異なるバージョンの場合はエラーを返します。
3.  **内部状態のデコード**: `GobEncode`でパックされたバイトを逆順に解析し、`mode`, `acc`, `form`, `neg`, `prec`, `exp`, `mant`の各値を復元します。
    *   2番目のバイトからビットシフトとマスク操作を使って`mode`, `acc`, `form`, `neg`を抽出します。
    *   `binary.BigEndian.Uint32`を使って`prec`と`exp`を復元します。
    *   `z.mant.setBytes()`メソッドを使って仮数部をバイトスライスから再構築します。
4.  **精度の設定**: デコードされた`prec`を`z.prec`に設定します。もし元の`Float`が既に精度を持っていた場合（`oldPrec != 0`）、`SetPrec`を呼び出して、デコードされた値がその精度に合うように調整します。これは、デコード後に`big.Float`が正しい精度で動作することを保証するために重要です。

### テストの追加

`floatmarsh_test.go`には、`TestFloatGobEncoding`と`TestFloatCorruptGob`という2つの新しいテスト関数が追加されています。

*   **`TestFloatGobEncoding`**:
    *   `floatVals`（様々な浮動小数点数の文字列表現）、符号（`+`, `-`, なし）、および様々な精度（`0`, `1`, `2`, `10`, `53`, `64`, `100`, `1000`）の組み合わせを網羅的にテストします。
    *   各テストケースで`big.Float`を作成し、`gob.NewEncoder`でエンコードし、`gob.NewDecoder`でデコードします。
    *   エンコード前後の`big.Float`の値が`Cmp`メソッドで比較され、一致することを確認します。
    *   `Mode()`も比較され、正しく伝送されたことを確認します。
*   **`TestFloatCorruptGob`**:
    *   意図的に破損した`gob`データ（例えば、バイトスライスを途中で切り詰める、バージョンバイトを改ざんするなど）をデコードしようとした場合に、適切なエラー（`io.ErrUnexpectedEOF`やバージョンエラー）が返されることを確認します。これにより、堅牢性が保証されます。

これらのテストは、`GobEncode`と`GobDecode`の実装が正しく機能し、様々なエッジケースやエラーシナリオにも対応できることを保証します。

## コアとなるコードの変更箇所

### `src/math/big/floatmarsh.go`

```go
 // Gob codec version. Permits backward-compatible changes to the encoding.
 const floatGobVersion byte = 1
 
 // GobEncode implements the gob.GobEncoder interface.
 func (x *Float) GobEncode() ([]byte, error) {
 	if x == nil {
 		return nil, nil
 	}
 	sz := 1 + 1 + 4 // version + mode|acc|form|neg (3+2+2+1bit) + prec
 	if x.form == finite {
 		sz += 4 + int((x.prec+(_W-1))/_W)*_S // exp + mant
 	}
 	buf := make([]byte, sz)
 
 	buf[0] = floatGobVersion
 	b := byte(x.mode&7)<<5 | byte((x.acc+1)&3)<<3 | byte(x.form&3)<<1
 	if x.neg {
 		b |= 1
 	}
 	buf[1] = b
 	binary.BigEndian.PutUint32(buf[2:], x.prec)
 	if x.form == finite {
 		binary.BigEndian.PutUint32(buf[6:], uint32(x.exp))
 		x.mant.bytes(buf[10:])
 	}
 	return buf, nil
 }
 
 // GobDecode implements the gob.GobDecoder interface.
 func (z *Float) GobDecode(buf []byte) error {
 	if len(buf) == 0 {
 		// Other side sent a nil or default value.
 		*z = Float{}
 		return nil
 	}
 
 	if buf[0] != floatGobVersion {
 		return fmt.Errorf("Float.GobDecode: encoding version %d not supported", buf[0])
 	}
 
 	b := buf[1]
 	z.mode = RoundingMode((b >> 5) & 7)
 	z.acc = Accuracy((b>>3)&3) - 1
 	z.form = form((b >> 1) & 3)
 	z.neg = b&1 != 0
 
 	oldPrec := uint(z.prec)
 	z.prec = binary.BigEndian.Uint32(buf[2:])
 
 	if z.form == finite {
 		z.exp = int32(binary.BigEndian.Uint32(buf[6:]))
 		z.mant = z.mant.setBytes(buf[10:])
 	}
 
 	if oldPrec != 0 {
 		z.SetPrec(oldPrec)
 	}
 	return nil
 }
```

```go
 func TestFloatGobEncoding(t *testing.T) {
 	var medium bytes.Buffer
 	for _, test := range floatVals {
 		for _, sign := range []string{"", "+", "-"} {
 			for _, prec := range []uint{0, 1, 2, 10, 53, 64, 100, 1000} {
 				medium.Reset() // empty buffer for each test case (in case of failures)
 				enc := gob.NewEncoder(&medium)
 				dec := gob.NewDecoder(&medium)
 				x := sign + test
 				var tx Float
 				_, _, err := tx.SetPrec(prec).Parse(x, 0)
 				if err != nil {
 					t.Errorf("parsing of %s (prec = %d) failed (invalid test case): %v", x, prec, err)
 					continue
 				}
 				tx.SetMode(ToPositiveInf)
 				if err := enc.Encode(&tx); err != nil {
 					t.Errorf("encoding of %v (prec = %d) failed: %v", &tx, prec, err)
 					continue
 				}
 
 				var rx Float
 				if err := dec.Decode(&rx); err != nil {
 					t.Errorf("decoding of %v (prec = %d) failed: %v", &tx, prec, err)
 					continue
 				}
 
 				if rx.Cmp(&tx) != 0 {
 					t.Errorf("transmission of %s failed: got %s want %s", x, rx.String(), tx.String())
 					continue
 				}
 
 				if rx.Mode() != ToPositiveInf {
 					t.Errorf("transmission of %s's mode failed: got %s want %s", x, rx.Mode(), ToPositiveInf)
 				}
 			}
 		}
 	}
 }
 func TestFloatCorruptGob(t *testing.T) {
 	var buf bytes.Buffer
 	tx := NewFloat(4 / 3).SetPrec(1000).SetMode(ToPositiveInf)
 	if err := gob.NewEncoder(&buf).Encode(tx); err != nil {
 		t.Fatal(err)
 	}
 	b := buf.Bytes()
 	var rx Float
 	if err := gob.NewDecoder(bytes.NewReader(b)).Decode(&rx); err != nil {
 		t.Fatal(err)
 	}
 	var rx2 Float
 	if err := gob.NewDecoder(bytes.NewReader(b[:10])).Decode(&rx2); err != io.ErrUnexpectedEOF {
 		t.Errorf("expected io.ErrUnexpectedEOF, got %v", err)
 	}
 	b[1] = 0
 	if err := gob.NewDecoder(bytes.NewReader(b)).Decode(&rx); err == nil {
 		t.Fatal("expected a version error, got nil")
 	}
 
 }
```

## コアとなるコードの解説

### `floatmarsh.go`

このファイルは、`big.Float`型のマーシャリング（シリアライズ）とアンマーシャリング（デシリアライズ）に関連するコードを含んでいます。今回のコミットでは、`gob`形式でのマーシャリング/アンマーシャリング機能が追加されました。

*   **`floatGobVersion`**: `gob`エンコーディングのバージョンを示すバイト定数です。これにより、将来エンコーディング形式が変更された場合でも、古い形式のデータを正しくデコードできるようになります。
*   **`(*Float).GobEncode()`**:
    *   `x == nil`の場合のハンドリング: `nil`の`*Float`がエンコードされた場合は`nil`バイトスライスを返します。
    *   `sz`の計算: エンコードされるデータのサイズを事前に計算します。バージョンバイト、フラグバイト（`mode`, `acc`, `form`, `neg`をまとめたもの）、精度（`prec`）の4バイトは常に含まれます。有限数（`finite`）の場合のみ、指数部（`exp`）の4バイトと仮数部（`mant`）のバイト数が追加されます。仮数部のサイズは`x.prec`と内部ワードサイズ`_W`、バイトあたりのワード数`_S`に基づいて計算されます。
    *   `buf`の作成: 計算されたサイズでバイトスライス`buf`を作成します。
    *   `buf[0] = floatGobVersion`: 最初のバイトにバージョンを書き込みます。
    *   `b := byte(...)`: `mode`, `acc`, `form`, `neg`の各情報をビットフィールドとして1バイトにパックします。
        *   `x.mode&7)<<5`: `mode`は3ビットで表現され、上位3ビットに配置されます。
        *   `((x.acc+1)&3)<<3`: `acc`は2ビットで表現され、その次に配置されます。`+1`しているのは、`Accuracy`のゼロ値が`Exact`であり、`gob`エンコーディングで`0`と区別するためかもしれません。
        *   `(x.form&3)<<1`: `form`は2ビットで表現され、その次に配置されます。
        *   `x.neg`: `neg`は1ビットで表現され、最下位ビットに配置されます。
    *   `binary.BigEndian.PutUint32(buf[2:], x.prec)`: 精度をビッグエンディアンの4バイト整数として書き込みます。
    *   有限数の場合:
        *   `binary.BigEndian.PutUint32(buf[6:], uint32(x.exp))`: 指数部をビッグエンディアンの4バイト整数として書き込みます。
        *   `x.mant.bytes(buf[10:])`: 仮数部をバイトスライスとして書き込みます。
*   **`(*Float).GobDecode()`**:
    *   `len(buf) == 0`のハンドリング: 空のバイトスライスが渡された場合、`*z`をゼロ値の`Float`にリセットします。
    *   `buf[0] != floatGobVersion`: バージョンチェックを行い、互換性のないバージョンであればエラーを返します。
    *   `b := buf[1]`: フラグバイトを読み込みます。
    *   `z.mode = RoundingMode((b >> 5) & 7)`: フラグバイトから`mode`を抽出します。
    *   `z.acc = Accuracy((b>>3)&3) - 1`: フラグバイトから`acc`を抽出し、エンコード時に`+1`した分を`-1`して元に戻します。
    *   `z.form = form((b >> 1) & 3)`: フラグバイトから`form`を抽出します。
    *   `z.neg = b&1 != 0`: フラグバイトから`neg`を抽出します。
    *   `oldPrec := uint(z.prec)`: デコード前の`z.prec`を保存します。これは、`SetPrec`を呼び出す際に必要になる可能性があります。
    *   `z.prec = binary.BigEndian.Uint32(buf[2:])`: 精度をビッグエンディアンの4バイト整数として読み込みます。
    *   有限数の場合:
        *   `z.exp = int32(binary.BigEndian.Uint32(buf[6:]))`: 指数部をビッグエンディアンの4バイト整数として読み込みます。
        *   `z.mant = z.mant.setBytes(buf[10:])`: 仮数部をバイトスライスから再構築します。
    *   `if oldPrec != 0 { z.SetPrec(oldPrec) }`: もしデコード前の`Float`が既に精度を持っていた場合、その精度を`SetPrec`で再設定します。これは、デコードされた`Float`が元の精度設定を尊重し、必要に応じて内部状態を調整するために重要です。

### `floatmarsh_test.go`

このファイルは、`big.Float`のマーシャリング機能のテストを含んでいます。

*   **`TestFloatGobEncoding`**:
    *   `bytes.Buffer`を`gob.Encoder`と`gob.Decoder`のI/Oとして使用し、メモリ内でエンコード/デコードを行います。
    *   `floatVals`、符号、様々な精度を組み合わせたループで、広範なテストケースを生成します。
    *   `tx.SetPrec(prec).Parse(x, 0)`: テスト文字列`x`と精度`prec`から`big.Float` `tx`を初期化します。
    *   `tx.SetMode(ToPositiveInf)`: 丸めモードを`ToPositiveInf`に設定し、モードも正しく伝送されることを確認します。
    *   `enc.Encode(&tx)`: `tx`を`gob`形式でエンコードします。
    *   `dec.Decode(&rx)`: エンコードされたデータを`rx`にデコードします。
    *   `rx.Cmp(&tx) != 0`: エンコード前後の`big.Float`の値が等しいことを`Cmp`メソッドで確認します。
    *   `rx.Mode() != ToPositiveInf`: 丸めモードも正しく伝送されたことを確認します。
*   **`TestFloatCorruptGob`**:
    *   `gob`エンコードされたバイトスライスを意図的に破損させ、デコード時に適切なエラーが返されることを確認します。
    *   `b[:10]`: バイトスライスを途中で切り詰めて、`io.ErrUnexpectedEOF`エラーが発生することを確認します。
    *   `b[1] = 0`: バージョンバイトを改ざんして、バージョンエラーが発生することを確認します。

これらのテストは、`big.Float`の`gob`エンコーディング/デコーディングが、正常なケースだけでなく、異常なケース（データ破損など）においても期待通りに動作することを保証します。
