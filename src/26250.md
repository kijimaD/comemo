# [インデックス 26250] ファイルの概要

このコミットは、Go言語のインストールに関するドキュメント `doc/install-source.html` に、Linux上のPowerPC 64-bit (ppc64) 環境におけるカーネルバージョンの要件を追加するものです。具体的には、GoをビルドするためにLinuxカーネル2.6.37以降が必要であること、そしてこの要件によりCentOS 6がサポートされないことを明記しています。

## 元コミット内容

このコミットは、Goのソースコードからビルドする際のインストール手順に関するドキュメント `doc/install-source.html` を更新し、Linux/ppc64環境における特定のカーネル要件を追記しています。具体的には、PowerPC 64-bitアーキテクチャ上でGoを動作させるためには、Linuxカーネルバージョン2.6.37以降が必要であるという情報が追加されました。この結果、CentOS 6のような古いカーネルバージョン（通常2.6.32系）を使用しているシステムではGoがサポートされないことが明記されています。これは、Goのランタイムが利用する特定のシステムコールやカーネル機能が、2.6.37以降のカーネルで導入されたか、あるいは安定化したためと考えられます。

## 変更の背景

この変更の背景には、Go言語がサポートする多様なアーキテクチャ、特にPowerPC 64-bit (ppc64) 環境における互換性の問題があったと考えられます。Goはクロスプラットフォーム対応を重視しており、様々なCPUアーキテクチャやOSで動作するように設計されています。しかし、特定のアーキテクチャとOSの組み合わせにおいては、Goランタイムが依存する低レベルのシステム機能が、古いカーネルバージョンでは利用できない、あるいは期待通りに動作しない場合があります。

このコミットは、Goのユーザーがppc64環境でGoをビルドまたは実行しようとした際に、予期せぬ問題に遭遇するのを防ぐために、明確なシステム要件をドキュメントに記載することを目的としています。特に、CentOS 6のような広く使われているが比較的古いOSディストリビューションが、この要件を満たさないことを明示することで、ユーザーの混乱を避ける意図があります。`Fixes #13269` という記述から、この問題が以前からGoコミュニティ内で認識されており、ユーザーからの報告や議論があったことが伺えます。

## 前提知識の解説

*   **PowerPC 64-bit (ppc64)**: IBMが開発したRISCアーキテクチャの一種で、高性能コンピューティングや組み込みシステムなどで利用されます。Go言語は、このppc64アーキテクチャのビッグエンディアン版 (`ppc64`) とリトルエンディアン版 (`ppc64le`) の両方をサポートしています。
*   **Linuxカーネル**: Linuxオペレーティングシステムの中心部分であり、ハードウェアとソフトウェア間の仲介役を務めます。カーネルは、プロセス管理、メモリ管理、デバイスドライバ、システムコールなどの基本的な機能を提供します。
*   **カーネルバージョン**: Linuxカーネルは継続的に開発されており、新しいバージョンがリリースされるたびに、新しい機能の追加、パフォーマンスの改善、セキュリティの強化、バグ修正などが行われます。Goのような低レベルのランタイムは、特定のカーネル機能やシステムコールに依存することがあり、そのために特定のカーネルバージョン以降が必要となることがあります。
*   **システムコール**: アプリケーションがオペレーティングシステム（カーネル）のサービスを要求するためのインターフェースです。Goランタイムは、メモリ割り当て、スレッド管理、ネットワーク通信などのために多数のシステムコールを利用します。
*   **CentOS 6**: Red Hat Enterprise Linux (RHEL) 6のクローンとして広く利用されたLinuxディストリビューションです。CentOS 6は、そのリリース時期から、比較的に古いLinuxカーネルバージョン（主に2.6.32系）をベースとしていました。このため、新しいソフトウェアが要求するカーネル機能が不足している場合があります。
*   **Goのクロスコンパイル**: Go言語は、あるプラットフォームで別のプラットフォーム向けのバイナリを生成するクロスコンパイルを強力にサポートしています。しかし、ターゲットシステムで実行されるためには、そのシステムのOSやカーネルがGoランタイムの要件を満たしている必要があります。

## 技術的詳細

GoランタイムがLinux/ppc64環境でカーネル2.6.37以降を要求する具体的な技術的理由は、通常、以下のいずれかまたは複数の要因に起因します。

1.  **特定のシステムコールの可用性**: Goランタイムは、効率的なメモリ管理（例: `mmap`の特定のフラグ）、スレッドスケジューリング（例: `futex`の高度な利用）、ネットワークI/O（例: `epoll`の特定の機能拡張）などのために、特定のシステムコールやそのオプションに依存することがあります。これらのシステムコールがカーネル2.6.37で導入されたか、あるいはそのバージョンで安定した動作が保証されるようになった可能性があります。
2.  **メモリモデルの変更または最適化**: PowerPCアーキテクチャは、そのメモリモデルにおいてx86とは異なる特性を持つことがあります。Goランタイムがppc64上で効率的に動作するために、特定のカーネル機能を利用してメモリバリアやキャッシュコヒーレンシを管理している可能性があります。これらの機能が2.6.37以降で改善されたか、Goランタイムがそれらの新しいインターフェースを利用するように設計された可能性があります。
3.  **アトミック操作のサポート**: Goの並行処理モデルは、アトミック操作に大きく依存しています。これらの操作がppc64アーキテクチャ上で効率的かつ正しく動作するためには、カーネルレベルでのサポートが必要な場合があります。2.6.37以降のカーネルで、ppc64向けのアトミック操作のサポートが強化された可能性も考えられます。
4.  **ツールチェインとの連携**: Goのコンパイラやリンカは、ターゲットシステムのABI (Application Binary Interface) やシステムコールインターフェースに密接に連携しています。カーネルのバージョンアップに伴い、これらのインターフェースに微細な変更があった場合、Goランタイムが新しいカーネルバージョンに依存するように調整されることがあります。

このコミットは、Goのドキュメントにこの要件を追加することで、ユーザーがGoをビルドまたは実行する前に、自身のシステムがこの技術的要件を満たしているかを確認できるようにしています。特に、CentOS 6がこの要件を満たさないことを明記することで、古いシステムでのGoの利用に関する一般的な問題を事前に解決しようとしています。CentOS 6の標準カーネルは2.6.32系であり、2.6.37の要件を満たしていません。

## コアとなるコードの解説

追加されたHTMLスニペットは、Goのソースからのインストールに関するドキュメントに、PowerPC 64-bit Linux環境における特定の制約を明確に記述しています。

1.  `<p>See the main installation page for the <a href=\"/doc/install#requirements\">overall system requirements</a>. The following additional constraints apply to systems that can be built only from source:</p>`
    *   この段落は、ユーザーを一般的なシステム要件のページに誘導しつつ、ソースからビルドする場合にのみ適用される追加の制約があることを示しています。これは、Goの公式バイナリディストリビューションを使用する場合はこれらの制約が緩和される可能性があることを示唆しているかもしれません（ただし、ppc64向けの公式バイナリが常に提供されているとは限りません）。
2.  `<ul><li>For Linux on PowerPC 64-bit, the minimum supported kernel version is 2.6.37, meaning that Go does not support CentOS 6 on these systems.</li></ul>`
    *   このリスト項目が、このコミットの核心となる情報です。
    *   「For Linux on PowerPC 64-bit」：対象となるプラットフォームを明確に指定しています。
    *   「the minimum supported kernel version is 2.6.37」：Goを動作させるために必要なLinuxカーネルの最小バージョンを具体的に示しています。
    *   「meaning that Go does not support CentOS 6 on these systems.」：このカーネル要件の結果として、CentOS 6がサポート対象外となることを明示しています。これは、CentOS 6が通常2.6.32系のカーネルを使用しているため、2.6.37の要件を満たさないことを意味します。

この変更により、Goをppc64 Linux環境で利用しようとする開発者は、事前に自身のシステムがGoの要件を満たしているかを確認できるようになり、互換性によるビルドや実行時の問題を回避できるようになります。
