# [インデックス 26727] ファイルの概要

このコミットは、GoツールチェーンにFortran言語のサポートを追加するものです。具体的には、`go`コマンドがFortranソースファイル（`.f`, `.F`, `.for`, `.f90`）を認識し、Cgoメカニズムを通じてGoプログラムとリンクできるようにします。これにより、Goから既存のFortranライブラリを利用したり、FortranコードをGoプロジェクトに組み込んだりすることが可能になります。

## コミット

```
cmd/go, go/build: add support for Fortran

This change adds support for Fortran files (.f, .F, .for, .f90) to the
go tool, in a similar fashion to Objective-C/C++. Only gfortran is
supported out of the box so far but leaves other Fortran compiler
toolchains the ability to pass the correct link options via CGO_LDFLAGS.
A simple test (misc/cgo/fortran) has been added and plugged into the
general test infrastructure. This test is only enabled when the $FC
environment variable is defined (or if 'gfortran' was found in $PATH.)

## 変更の背景

Go言語は、そのシンプルさ、並行処理の容易さ、そして高いパフォーマンスから、システムプログラミングやWebサービス開発において広く採用されています。しかし、科学技術計算や数値解析の分野では、長年にわたりFortranがデファクトスタンダードとして利用されてきました。多くの高性能な数値計算ライブラリや既存のコードベースがFortranで書かれており、これらをGoから利用したいというニーズが存在します。

このコミットの背景には、GoプログラムがCgoを介してCやC++のコードと連携できるのと同様に、Fortranコードとも連携できるようにすることで、Go言語の適用範囲を広げ、特に科学技術計算コミュニティにおけるGoの採用を促進するという目的があります。これにより、開発者はGoの現代的な機能とFortranの確立された数値計算能力を組み合わせることが可能になります。

コミットメッセージにある「Derived from CL 4114」は、この変更が以前の作業や提案（Change List 4114）に基づいていることを示唆していますが、その詳細はこのコミット情報からは特定できません。しかし、Go言語が他の言語との相互運用性を重視していることの表れと言えます。

## 前提知識の解説

### Go言語とCgo

Go言語は、C言語との相互運用を可能にする`cgo`というメカニズムを提供しています。`cgo`を使用すると、GoコードからC関数を呼び出したり、CコードからGo関数を呼び出したりすることができます。これは、既存のCライブラリをGoプロジェクトで再利用する際に非常に有用です。

`cgo`の基本的な仕組みは以下の通りです。
1.  Goソースファイル内で`import "C"`という特別なインポート文を使用します。
2.  `import "C"`の直前のコメントブロックにCのコード（ヘッダファイルのインクルード、関数宣言など）を記述します。
3.  `go build`コマンドが`cgo`ツールを呼び出し、GoコードとCコードをそれぞれコンパイルし、最終的にリンクします。
4.  Cコンパイラやリンカに渡すフラグは、`#cgo CFLAGS: ...`や`#cgo LDFLAGS: ...`といったディレクティブを使って指定できます。

### Fortran言語とC言語との相互運用性

Fortranは、科学技術計算に特化したプログラミング言語であり、特に数値計算の分野で高い性能を発揮します。現代のFortran（Fortran 90以降）には、C言語との相互運用性を高めるための機能が導入されています。

*   **`ISO_C_BINDING`モジュール**: Fortran 2003で導入された`ISO_C_BINDING`モジュールは、C言語との相互運用を標準化するための機能を提供します。これには、C言語のデータ型に対応するFortranのデータ型（例: `C_INT`）や、C言語の呼び出し規約に準拠した関数を定義するための`BIND(C)`属性などが含まれます。
*   **`BIND(C)`属性**: Fortranのサブルーチンや関数に`BIND(C)`属性を付与することで、そのルーチンがC言語から呼び出し可能（またはC言語のルーチンを呼び出し可能）な形式でコンパイルされることを保証します。これにより、C言語のリンカがFortranのルーチンを認識し、GoのCgoメカニズムを通じてGoプログラムからFortran関数を呼び出すことが可能になります。

### コンパイラとリンカ

*   **gfortran**: GNU Fortranコンパイラであり、Fortranコードをコンパイルするための一般的なツールです。CgoがFortranをサポートする上で、デフォルトのFortranコンパイラとして想定されています。
*   **リンカオプション (`-lgfortran`)**: FortranコードをCgo経由でGoプログラムにリンクする際、Fortranランタイムライブラリ（`libgfortran`など）が必要になる場合があります。これは、Fortranプログラムが実行時に必要とする特定の関数やデータ構造を提供するためです。`-lgfortran`のようなリンカオプションは、これらのライブラリをリンクするようにリンカに指示します。

## 技術的詳細

このコミットは、GoツールチェーンがFortranソースファイルを認識し、Cgoのビルドプロセスに統合するための複数の変更を導入しています。

1.  **Fortranファイルの認識**:
    *   `go/build`パッケージ（`src/go/build/build.go`）が、`.f`, `.F`, `.for`, `.f90`といった拡張子を持つファイルをFortranソースファイルとして識別し、`Package`構造体の新しいフィールド`FFiles`に格納するように変更されました。
    *   `cmd/go/pkg.go`の`Package`構造体にも`FFiles`フィールドが追加され、`go list`コマンドなどでFortranファイルの情報が表示されるようになります。

2.  **Cgoビルドプロセスへの統合**:
    *   `src/cmd/go/build.go`内の`builder.cgo`関数が、Fortranファイルを処理するように拡張されました。
    *   Fortranファイルが存在する場合、`cgo`ツールは`gfortran`（または`FC`環境変数で指定されたコンパイラ）を使用してこれらのファイルをオブジェクトファイルにコンパイルします。
    *   Fortranコンパイラに渡すフラグとして、新しい`#cgo FFLAGS: ...`ディレクティブが導入されました。これにより、Cgoのコメントブロック内でFortranコンパイラ固有のオプションを指定できます。
    *   リンカオプションに`-lgfortran`が自動的に追加されるようになりました。これは、`gfortran`が使用される場合にFortranランタイムライブラリをリンクするために必要です。他のFortranコンパイラを使用する場合は、`CGO_LDFLAGS`環境変数を通じて適切なリンカオプションを手動で指定できます。

3.  **ビルド制約の追加**:
    *   Fortranファイルを含むパッケージがCgoまたはSWIGを使用していない場合、ビルドエラーとなるように`src/cmd/go/build.go`にチェックが追加されました。これは、FortranコードのコンパイルとリンクにはCgoまたはSWIGのメカニズムが必要であるためです。

4.  **テストインフラストラクチャの更新**:
    *   `src/cmd/dist/test.go`が更新され、FortranサポートのテストがGoのテストインフラストラクチャに組み込まれました。
    *   `misc/cgo/fortran`ディレクトリに、GoとFortranを連携させるシンプルなテストケースが追加されました。このテストは、`$FC`環境変数が定義されているか、`gfortran`が`$PATH`にある場合にのみ実行されます。

5.  **ドキュメントの更新**:
    *   `src/cmd/cgo/doc.go`が更新され、`FFLAGS`ディレクティブとFortranファイルのサポートに関する情報が追加されました。

*   **`answer.f90`**:

    ```
    このGoファイルは、`import "C"`を使用してCgoを有効にしています。コメントブロック内の`// int the_answer();`は、Fortranで定義された`the_answer`関数（CgoからはC関数として見える）のシグネチャをCgoに伝えます。`TheAnswer` Go関数は、`C.the_answer()`を呼び出し、その結果をGoの`int`型に変換して返します。

これらの変更により、GoツールチェーンはFortranコードをGoプロジェクトにシームレスに統合できるようになり、Go言語の適用範囲が大きく広がりました。
