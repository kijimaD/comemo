# [インデックス 22790] ファイルの概要

このコミットは、Go言語のリンカ (`cmd/internal/ld`) において、Mach-O実行ファイル（macOSなどで使用される形式）が `.init_array` セクションを正しく出力できるようにするための変更です。これにより、GoプログラムがmacOS上で起動する際に、必要な初期化関数が適切に実行されるようになります。

## 変更の背景

プログラムが実行を開始する前に、特定の初期化処理が必要となる場合があります。例えば、C++のグローバルオブジェクトのコンストラクタや、ランタイムが提供する初期化ルーチンなどがこれに該当します。macOSなどのApple製OSで使われるMach-O実行ファイルフォーマットでは、これらの初期化関数へのポインタは通常 `.init_array` と呼ばれるセクションに格納されます。

Goプログラムも、そのランタイムの初期化や、Cgoを介してリンクされるC/C++ライブラリの初期化など、起動時に特定の処理を実行する必要があります。このコミット以前は、GoのリンカがMach-O形式の実行ファイルを生成する際に、この `.init_array` セクションをMach-Oの仕様に沿って適切にマークしていませんでした。その結果、macOSのダイナミックリンカ (`dyld`) がGoプログラムの初期化関数を正しく認識・実行できない可能性がありました。

この変更は、Goのリンカが `.init_array` セクションをMach-Oの標準的な初期化関数ポインタセクション (`__mod_init_func`) として正しく識別し、適切なフラグ (`S_MOD_INIT_FUNC_POINTERS`) を設定することで、GoプログラムがmacOS上でより堅牢に、かつ期待通りに起動できるようにするために導入されました。

## 前提知識の解説

### Mach-O (Mach Object) ファイルフォーマット

Mach-Oは、macOS、iOS、watchOS、tvOSなどのApple製オペレーティングシステムで使用される実行可能ファイル、オブジェクトファイル、共有ライブラリのフォーマットです。Mach-Oファイルは、ヘッダ、ロードコマンド、セグメント、セクションで構成されます。

*   **ヘッダ**: ファイルの基本的な情報（CPUタイプ、ファイルタイプなど）を含みます。
*   **ロードコマンド**: リンカやローダがファイルをどのように処理すべきかを指示するコマンドのリストです。これには、セグメントの定義、シンボルテーブルの場所などが含まれます。
*   **セグメント**: 実行可能ファイルの論理的な領域を定義します。各セグメントは、コード、データ、スタックなどの特定の種類の情報を保持します。セグメントはさらに複数のセクションに分割されます。
*   **セクション**: セグメント内のより細かい論理的な区分です。例えば、コードセグメントにはテキストセクション（実行可能な命令）が含まれ、データセグメントには初期化されたデータや初期化されていないデータのためのセクションが含まれます。

### `.init_array` セクション

`.init_array` は、プログラムの `main()` 関数が実行される前に、特定の初期化関数へのポインタを格納するために使用されるセクションです。C++では、グローバルオブジェクトのコンストラクタがこのセクションに登録されることがよくあります。また、一部のシステムでは、ランタイムライブラリや動的にロードされるモジュールの初期化ルーチンもここに配置されます。

リンカは、このセクションに登録された関数ポインタを収集し、実行可能ファイルに含めます。プログラムがロードされると、システムのダイナミックリンカ（macOSでは `dyld`）がこのセクションを見つけ、含まれる関数を `main()` の前に順番に呼び出します。

### `__DATA,__mod_init_func`

Mach-Oフォーマットにおいて、初期化関数へのポインタを格納するセクションは、通常 `__DATA` セグメント内の `__mod_init_func` という名前のセクションとして表現されます。これは、他のOSにおける `.init_array` に相当するMach-O固有の命名規則です。

### `S_MOD_INIT_FUNC_POINTERS`

これはMach-Oのセクションタイプフラグの一つで、値は `9` です。このフラグは、そのセクションがモジュール初期化関数へのポインタを含んでいることを示します。ダイナミックリンカ (`dyld`) は、このフラグを持つセクションを特別に扱い、その中の関数ポインタをプログラムの起動時に実行します。このフラグが正しく設定されていないと、初期化関数が呼び出されない可能性があります。

### Go リンカ (`cmd/internal/ld`)

Go言語のビルドプロセスにおいて、`cmd/internal/ld` はGoプログラムをコンパイルした後に、オブジェクトファイルを結合して最終的な実行可能ファイルを生成する役割を担うリンカです。このリンカは、ターゲットとなるOSやアーキテクチャに応じて、ELF（Linux）、PE（Windows）、Mach-O（macOS）などの異なる実行ファイルフォーマットを生成する能力を持っています。このコミットは、特にMach-Oフォーマットの生成ロジックに焦点を当てています。

## 技術的詳細

このコミットは、GoのリンカがMach-O形式の実行ファイルを生成する際のセクション処理ロジックを拡張します。具体的には、`src/cmd/internal/ld/macho.go` ファイル内の `machoshbits` 関数に修正が加えられています。

`machoshbits` 関数は、Goのリンカが内部的に管理するセクション情報 (`sect`) を、Mach-Oのセクション構造 (`msect`) に変換する際に、Mach-O固有の属性（セクション名やフラグなど）を設定する役割を担っています。

今回の変更では、リンカが処理しているセクションの名前が `.init_array` であるかどうかをチェックする条件分岐が追加されました。もしセクション名が `.init_array` であった場合、以下の2つの重要な属性が `msect` に設定されます。

1.  **`msect.name = "__mod_init_func"`**: Mach-Oの標準的な初期化関数ポインタセクション名である `__mod_init_func` が設定されます。これにより、macOSのダイナミックリンカがこのセクションを正しく識別できるようになります。
2.  **`msect.flag = 9 // S_MOD_INIT_FUNC_POINTERS`**: セクションのフラグが `9` に設定されます。この `9` は `S_MOD_INIT_FUNC_POINTERS` というMach-Oのセクションタイプフラグに対応しており、このセクションが初期化関数へのポインタを含んでいることを `dyld` に明示的に伝えます。

この変更により、Goのリンカは、GoランタイムやCgoによって必要とされる初期化関数が、Mach-O実行ファイル内で `dyld` によって適切に発見され、`main()` 関数が呼び出される前に実行されることを保証します。これは、GoプログラムがmacOS環境で安定して動作するために不可欠な修正です。

## コアとなるコードの解説

変更は `src/cmd/internal/ld/macho.go` ファイル内の `machoshbits` 関数に集中しています。この関数は、Goリンカが内部的に表現するセクション (`sect`) を、Mach-Oのセクション構造 (`msect`) に変換する際に、Mach-O固有のメタデータを設定する役割を担っています。

追加されたコードブロックは以下の通りです。

```go
	if sect.Name == ".init_array" {
		msect.name = "__mod_init_func"
		msect.flag = 9 // S_MOD_INIT_FUNC_POINTERS
	}
```

1.  **`if sect.Name == ".init_array"`**:
    この条件文は、現在処理しているリンカのセクション (`sect`) の名前が、初期化関数ポインタを格納する標準的なセクション名である `".init_array"` と一致するかどうかをチェックします。Goのリンカは、内部的にこの名前で初期化セクションを管理しています。

2.  **`msect.name = "__mod_init_func"`**:
    もしセクション名が `".init_array"` であった場合、対応するMach-Oセクション (`msect`) の名前を `__mod_init_func` に設定します。これは、Mach-Oフォーマットにおける初期化関数ポインタセクションの標準的な名前です。この設定により、macOSのダイナミックリンカ (`dyld`) がこのセクションを正しく認識できるようになります。

3.  **`msect.flag = 9 // S_MOD_INIT_FUNC_POINTERS`**:
    さらに、Mach-Oセクションのフラグを `9` に設定します。コメントにもあるように、この `9` は `S_MOD_INIT_FUNC_POINTERS` という定数に対応する値です。このフラグは、セクションがモジュール初期化関数へのポインタを含んでいることを `dyld` に明示的に伝えます。`dyld` はこのフラグを読み取り、セクション内の関数ポインタをプログラムの `main()` 関数が実行される前に呼び出します。

このわずか5行の追加コードにより、GoのリンカはMach-O実行ファイルにおける初期化セクションの取り扱いをMach-Oの仕様に完全に準拠させ、GoプログラムがmacOS環境で期待通りに初期化されることを保証しています。
