## 変更の背景

このコミットは、Go言語の標準ライブラリである`net/http`パッケージにおいて、RFC 6585で定義された新しいHTTPステータスコードを外部に公開（エクスポート）することを目的としています。

RFC 6585は2012年4月に公開され、いくつかの新しいHTTPステータスコードを導入しました。これらのコードは、HTTP通信におけるより具体的なエラーや状態を示すために提案されました。Go言語へのこれらのコードの追加は、コミットの約2年7ヶ月前（2013年3月頃）に[https://codereview.appspot.com/7678043/](https://codereview.appspot.com/7678043/)で一度提案されていましたが、その時点ではGoの公開APIには含まれていませんでした。

コミットメッセージによると、RFC 6585の仕様は3年以上前に提案され、その後も更新や撤回がなかったため、これらのコードをGoのエクスポートされたAPIに含める時期が来たと判断されました。特に、HTTP/2プロトコルがステータスコード431 (Request Header Fields Too Large) を使用していることが指摘されており、これはこれらのコードをエクスポートする緊急性を高める要因の一つと考えられます。

この変更により、Goの`net/http`パッケージを利用する開発者は、これらの新しいHTTPステータスコードを直接利用できるようになり、より正確なHTTPエラーハンドリングやレスポンス生成が可能になります。

## 前提知識の解説

### HTTPステータスコード

HTTPステータスコードは、Webサーバーがクライアントからのリクエストを処理した結果を示す3桁の数値です。1xx（情報）、2xx（成功）、3xx（リダイレクト）、4xx（クライアントエラー）、5xx（サーバーエラー）の5つのカテゴリに分類されます。これらはHTTPプロトコルの中核をなす要素であり、クライアントとサーバー間の通信状態を理解するために不可欠です。

### RFC 6585: Additional HTTP Status Codes

RFC 6585は、2012年4月にIETF (Internet Engineering Task Force) によって公開された「Additional HTTP Status Codes」という文書です。このRFCは、既存のHTTPステータスコードでは十分に表現できなかった特定のシナリオに対応するため、以下の4つの新しいステータスコードを導入しました。

*   **428 Precondition Required**: オリジンサーバーがリクエストに条件付きヘッダー（例: `If-Match`、`If-Unmodified-Since`）を要求することを示します。これは「失われた更新問題」（複数のクライアントが同時にリソースを更新しようとした際に、古い情報に基づいて更新が行われる問題）を防ぐために使用されます。
*   **429 Too Many Requests**: ユーザーが指定された時間内にあまりにも多くのリクエストを送信したことを示します。これはAPIのレート制限などで頻繁に使用され、クライアントにリクエストを再試行する前に待機するよう促します。
*   **431 Request Header Fields Too Large**: サーバーが、個々のヘッダーフィールドまたはすべてのヘッダーフィールドの合計サイズが大きすぎるため、リクエストの処理を拒否することを示します。クライアントはヘッダーサイズを減らしてからリクエストを再送信する必要があります。
*   **511 Network Authentication Required**: クライアントがネットワークアクセスを得るために認証を行う必要があることを示します。これは通常、キャプティブポータル（公衆Wi-Fiなどでインターネットに接続する前に認証が必要なページ）によって使用されます。

### Go言語の `net/http` パッケージ

`net/http`はGo言語の標準ライブラリの一部であり、HTTPクライアントとサーバーの実装を提供します。このパッケージには、HTTPリクエストの送信、レスポンスの受信、HTTPサーバーの構築、ルーティング、ミドルウェアの処理など、HTTP通信に必要なすべての機能が含まれています。HTTPステータスコードは、このパッケージ内の定数として定義され、`http.StatusOK` (200), `http.StatusNotFound` (404) のように利用されます。

### Go言語におけるエクスポートされた識別子とエクスポートされていない識別子

Go言語では、識別子（変数、関数、型、定数など）の可視性は、その名前の最初の文字が大文字か小文字かによって決まります。

*   **大文字で始まる識別子**: パッケージの外部からアクセス可能です。これらは「エクスポートされた」識別子と呼ばれます。
*   **小文字で始まる識別子**: その識別子が定義されているパッケージ内でのみアクセス可能です。これらは「エクスポートされていない」識別子と呼ばれます。

このコミットでは、以前は小文字で始まっていたRFC 6585のステータスコード定数（例: `statusPreconditionRequired`）を、大文字で始まる名前に変更（例: `StatusPreconditionRequired`）することで、パッケージ外部から利用できるようにしています。

### HTTP/2とステータスコード431

HTTP/2は、HTTP/1.1の後継となる主要な改訂版プロトコルです。パフォーマンスの向上、多重化、ヘッダー圧縮などの機能が導入されています。コミットメッセージで言及されているように、HTTP/2は特にヘッダーの処理において効率化を図っていますが、それでもヘッダーフィールドが大きすぎる場合には問題が発生する可能性があります。ステータスコード431 (Request Header Fields Too Large) は、このような状況をクライアントに明確に伝えるためにHTTP/2環境でも重要となります。

## 技術的詳細

このコミットの技術的な核心は、Goの`net/http`パッケージ内の`src/net/http/status.go`ファイルにおいて、RFC 6585で定義されたHTTPステータスコードをエクスポートすることです。具体的には、以下の変更が行われました。

1.  **定数の可視性変更**: 以前はパッケージ内部でのみ使用可能だった小文字始まりの定数（例: `statusPreconditionRequired`）が、大文字始まりの定数（例: `StatusPreconditionRequired`）に変更され、外部パッケージからアクセス可能になりました。これにより、Goアプリケーション開発者はこれらの新しいステータスコードを直接参照し、利用できるようになります。
2.  **`statusText` マップの更新**: `statusText`は、HTTPステータスコードに対応する人間が読めるテキストメッセージを格納するマップです。エクスポートされた新しい定数とその対応するテキストメッセージがこのマップに追加されました。これにより、`http.StatusText()`関数を呼び出すことで、これらの新しいステータスコードに対する標準的な説明文を取得できるようになります。
3.  **コードの再編成**: 以前はコメントアウトされたセクションに「Go 1.1ではまだエクスポートされていない」という注釈とともに定義されていたこれらの定数が、既存の他のステータスコード定数と並んで正式にエクスポートされた定数リストに統合されました。また、`StatusNetworkAuthenticationRequired` (511) も、以前は5xxエラーのグループとは別に定義されていましたが、このコミットで5xxエラーのグループに移動され、エクスポートされました。

この変更は、Goの`net/http`パッケージが最新のHTTP標準に準拠し、開発者がより表現力豊かなHTTP通信を構築できるようにするための重要なステップです。特に、レート制限 (`429 Too Many Requests`) やセキュリティ関連の認証 (`511 Network Authentication Required`) など、現代のWebアプリケーションで頻繁に遭遇するシナリオに対応するための基盤を提供します。

## コアとなるコードの解説

このコミットでは、`src/net/http/status.go`ファイル内の`const`ブロックと`statusText`マップが変更されています。

1.  **`const`ブロックの変更**:
    *   以前はコメントアウトされたセクションに小文字で定義されていた`statusPreconditionRequired` (428), `statusTooManyRequests` (429), `statusRequestHeaderFieldsTooLarge` (431) が、既存の4xxステータスコードのグループに大文字で始まる`StatusPreconditionRequired`, `StatusTooManyRequests`, `StatusRequestHeaderFieldsTooLarge`として追加されました。これにより、これらの定数がパッケージ外部からアクセス可能になります。
    *   `statusNetworkAuthenticationRequired` (511) も同様に、以前はコメントアウトされたセクションに小文字で定義されていましたが、5xxステータスコードのグループに`StatusNetworkAuthenticationRequired`として追加され、エクスポートされました。
    *   これにより、Goの`net/http`パッケージのユーザーは、`http.StatusTooManyRequests`のようにこれらの新しいステータスコードを直接参照できるようになります。

2.  **`statusText`マップの変更**:
    *   `statusText`マップは、HTTPステータスコード（整数）をそのテキスト表現（文字列）にマッピングします。
    *   新しいエクスポートされた定数`StatusPreconditionRequired`, `StatusTooManyRequests`, `StatusRequestHeaderFieldsTooLarge`, `StatusNetworkAuthenticationRequired`が、それぞれのテキスト表現とともにこのマップに追加されました。
    *   これにより、`http.StatusText(http.StatusTooManyRequests)`のような呼び出しで、対応するテキスト「Too Many Requests」を取得できるようになります。

これらの変更は、GoのHTTPライブラリがRFC 6585で導入された新しいステータスコードを完全にサポートし、開発者がこれらのコードをGoアプリケーションで簡単に利用できるようにするためのものです。
