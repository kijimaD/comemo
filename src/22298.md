## 変更の背景

`math/big`パッケージの`Float`型は、任意精度浮動小数点数を扱います。浮動小数点数のシフト操作は、その内部表現（仮数部と指数部）を操作することで実現できます。このコミットの背景には、`Float.Lsh`と`Float.Rsh`という専用のシフトメソッドが、既存の`Float.MantExp`と`Float.SetMantExp`というより汎用的なメソッドの組み合わせで容易に代替可能であるという認識があります。

冗長なメソッドを削除することで、APIのシンプルさを保ち、メンテナンスコストを削減することが目的と考えられます。特に、コミットメッセージには「Shifts are trivially implemented by combining Float.MantExp and Float.SetMantExp.」と明記されており、既存の機能で十分であるという判断が示されています。また、削除されるメソッドには「BUG(gri) Lsh is not tested and may not work correctly.」というコメントも付されており、テストが不十分であったり、正しく動作しない可能性があったことも削除の理由の一つかもしれません。

## 前提知識の解説

このコミットを理解するためには、以下の概念についての知識が必要です。

*   **浮動小数点数表現**: 多くのプログラミング言語やハードウェアでは、浮動小数点数は通常、IEEE 754標準に基づいて表現されます。これは、数値を「符号部」「仮数部（または有効数字部）」「指数部」の3つの要素に分解して表現するものです。
    *   **仮数部 (Mantissa/Significand)**: 数値の有効数字を表します。
    *   **指数部 (Exponent)**: 仮数部をどれだけシフトするか（2の何乗を掛けるか）を表します。
    *   **符号部 (Sign)**: 数値が正か負かを表します。
    浮動小数点数の値は、`符号 × 仮数部 × 基数^指数部` の形式で計算されます。Goの`math/big.Float`では、基数は2です。

*   **`math/big`パッケージ**: Go言語の標準ライブラリの一部で、任意精度の数値演算を提供します。`int`や`float64`などの組み込み型では表現できない非常に大きな整数や、高い精度が要求される浮動小数点数計算に使用されます。`Float`型は、このパッケージで任意精度浮動小数点数を扱うための型です。

*   **`Float.MantExp`メソッド**:
    `func (x *Float) MantExp(mant *Float) (exp int)`
    このメソッドは、浮動小数点数`x`を正規化された仮数部と指数部に分解します。具体的には、`x = mant * 2**exp`となるように、`mant`（仮数部）と`exp`（指数部）を返します。`mant`は通常、`0.5 <= |mant| < 1.0`の範囲に正規化されます。

*   **`Float.SetMantExp`メソッド**:
    `func (z *Float) SetMantExp(mant *Float, exp int) *Float`
    このメソッドは、与えられた仮数部`mant`と指数部`exp`から新しい浮動小数点数`z`を構築します。つまり、`z`の値を`mant * 2**exp`に設定します。

*   **ビットシフト操作**:
    *   **左シフト (Left Shift, `Lsh`)**: 数値を左に`s`ビットシフトすることは、その数値を`2^s`倍することと同じです。浮動小数点数においては、指数部を`s`だけ増やすことに相当します。
    *   **右シフト (Right Shift, `Rsh`)**: 数値を右に`s`ビットシフトすることは、その数値を`2^s`で割ることと同じです。浮動小数点数においては、指数部を`s`だけ減らすことに相当します。

## 技術的詳細

このコミットの核心は、浮動小数点数のビットシフトが、その指数部を直接操作することで実現できるという点です。

`Float.MantExp`は、浮動小数点数`x`を仮数部`mant`と指数部`exp`に分解します。
`x = mant * 2^exp`

ここで、`x`を`2^s`倍（左シフト）したい場合、新しい値`x'`は次のようになります。
`x' = x * 2^s = (mant * 2^exp) * 2^s = mant * 2^(exp + s)`

同様に、`x`を`2^s`で割る（右シフト）したい場合、新しい値`x''`は次のようになります。
`x'' = x / 2^s = (mant * 2^exp) / 2^s = mant * 2^(exp - s)`

このことから、浮動小数点数のシフト操作は、`Float.MantExp`で現在の指数部を取得し、それにシフト量`s`を加算（左シフト）または減算（右シフト）し、その新しい指数部と元の仮数部を`Float.SetMantExp`に渡すことで実現できることがわかります。

コミットメッセージにあるように、これは「trivially implemented」（自明に実装できる）操作であり、専用の`Lsh`や`Rsh`メソッドは不要であると判断されました。これにより、APIの重複が解消され、`math/big.Float`の設計がより簡潔になります。

また、`SetMantExp`メソッドのコメントが更新され、「`z`と`mant`は同じであってもよい」という注意書きが追加されています。これは、`z.SetMantExp(&z, z.MantExp(nil)+s)`のように、レシーバと引数で同じ`Float`インスタンスを使用できることを明示しており、インプレースでのシフト操作を可能にしています。

package big_test

import (
	"fmt"
	"math/big"
)

func Example_Shift() {
	// Implementing Float "shift" by modifying the (binary) exponents directly.
	var x big.Float
	for s := -5; s <= 5; s++ {
		x.SetFloat64(0.5)
		x.SetMantExp(&x, x.MantExp(nil)+s) // shift x by s
		fmt.Println(&x)
	}
	// Output:
	// 0.015625
	// 0.03125
	// 0.0625
	// 0.125
	// 0.25
	// 0.5
	// 1
	// 2
	// 4
	// 8
	// 16
}
```
この新しいテスト例`Example_Shift`は、`Float.MantExp`と`Float.SetMantExp`を組み合わせて浮動小数点数のシフト操作を行う具体的な方法を示しています。

`x.SetFloat64(0.5)`: `x`を初期値0.5に設定します。
`x.SetMantExp(&x, x.MantExp(nil)+s)`: ここがシフト操作の核心です。
1.  `x.MantExp(nil)`: `x`の現在の指数部を取得します。`nil`を渡すことで、仮数部を新しい`Float`インスタンスにコピーする必要がないことを示します（この例では仮数部は不要なため）。
2.  `+s`: 取得した指数部にシフト量`s`を加算します。`s`が正の場合は左シフト（乗算）、負の場合は右シフト（除算）に相当します。
3.  `x.SetMantExp(&x, ...)`: `x`の仮数部（`&x`で`x`自身を仮数部として再利用）と、計算された新しい指数部を使って、`x`の値を更新します。

この例は、`Lsh`や`Rsh`がなくても、既存のAPIで簡単にシフト操作が実現できることを明確に示しており、削除されたメソッドの代替手段として機能します。

### `src/math/big/floatexample_test.go` の新規追加部分

```go
// Copyright 2015 The Go Authors. All rights reserved.
// Use of this source code is governed by a BSD-style
// license can be found in the LICENSE file.

package big_test

import (
	"fmt"
	"math/big"
)

func Example_Shift() {
	// Implementing Float "shift" by modifying the (binary) exponents directly.
	var x big.Float
	for s := -5; s <= 5; s++ {
		x.SetFloat64(0.5)
		x.SetMantExp(&x, x.MantExp(nil)+s) // shift x by s
		fmt.Println(&x)
	}
	// Output:
	// 0.015625
	// 0.03125
	// 0.0625
	// 0.125
	// 0.25
	// 0.5
	// 1
	// 2
	// 4
	// 8
	// 16
}
```
この新しいテスト例`Example_Shift`は、`Float.MantExp`と`Float.SetMantExp`を組み合わせて浮動小数点数のシフト操作を行う具体的な方法を示しています。

`x.SetFloat64(0.5)`: `x`を初期値0.5に設定します。
`x.SetMantExp(&x, x.MantExp(nil)+s)`: ここがシフト操作の核心です。
1.  `x.MantExp(nil)`: `x`の現在の指数部を取得します。`nil`を渡すことで、仮数部を新しい`Float`インスタンスにコピーする必要がないことを示します（この例では仮数部は不要なため）。
2.  `+s`: 取得した指数部にシフト量`s`を加算します。`s`が正の場合は左シフト（乗算）、負の場合は右シフト（除算）に相当します。
3.  `x.SetMantExp(&x, ...)`: `x`の仮数部（`&x`で`x`自身を仮数部として再利用）と、計算された新しい指数部を使って、`x`の値を更新します。

この例は、`Lsh`や`Rsh`がなくても、既存のAPIで簡単にシフト操作が実現できることを明確に示しており、削除されたメソッドの代替手段として機能します。
