# [インデックス 27317] ファイルの概要

このコミットは、Go言語のビルドツールである `cmd/dist` において、`s390x` アーキテクチャ上での共有ライブラリ（`-buildmode=shared`）および外部リンケージ（`-ldflags="-linkmode=external"`）を用いたテストを有効にするための変更です。具体的には、`src/cmd/dist/test.go` ファイル内の `supportedBuildmode` 関数と `cgoTest` 関数に `linux-s390x` を追加することで、これらのビルドモードとリンケージモードが `s390x` 環境でサポートされていることを `dist` ツールに認識させ、関連するテストが実行されるようにしています。

## 変更の背景

Go言語は様々なアーキテクチャとオペレーティングシステムをサポートしています。`s390x` はIBMのメインフレームコンピュータで使用される64ビットの命令セットアーキテクチャであり、Linuxディストリビューションもこのアーキテクチャ上で動作します。Goコンパイラとランタイムは `s390x` をサポートしていますが、特定の高度なビルドモード（共有ライブラリの生成や外部リンカの使用）に関するテストが、`cmd/dist` ツールによって `s390x` 環境で適切に実行されていませんでした。

このコミットの背景には、`s390x` 環境におけるGoの共有ライブラリ機能（`-buildmode=shared`）と外部リンケージ機能（`-linkmode=external`）の安定性と正確性を保証する必要がありました。これらの機能は、GoプログラムをC/C++などの他の言語で書かれたライブラリと連携させたり、より複雑なシステムに組み込んだりする際に重要です。テストスイートがこれらのモードを `s390x` で実行しない場合、潜在的なバグや互換性の問題が見過ごされる可能性があります。このコミットは、`s390x` プラットフォームにおけるGoの堅牢性を向上させることを目的としています。

## 前提知識の解説

### `cmd/dist`

`cmd/dist` はGoプロジェクトのビルドシステムの中核をなすツールです。Goのソースコードからコンパイラ、リンカ、標準ライブラリ、その他のツールをビルドし、テストを実行する役割を担っています。Goのビルドプロセスは非常に複雑であり、`cmd/dist` は異なるプラットフォームやアーキテクチャに対応するためのロジックを含んでいます。特に、特定のビルドモードやリンケージモードが特定のOS/アーキテクチャの組み合わせでサポートされているかを判断するロジックが含まれています。

### `s390x`

`s390x` は、IBM System zメインフレームコンピュータで使用される64ビットの命令セットアーキテクチャです。これらのシステムは、高い信頼性、可用性、保守性（RAS）を要求されるエンタープライズ環境で広く利用されています。Go言語が `s390x` をサポートすることで、開発者はメインフレーム上で高性能なGoアプリケーションを開発・デプロイできるようになります。

### `-buildmode=shared`

Goコンパイラのビルドモードの一つで、Goパッケージを共有ライブラリ（`.so` ファイルなど）としてコンパイルすることを可能にします。これにより、複数のGoプログラムが同じ共有ライブラリをリンクしたり、C/C++プログラムからGoの機能を呼び出したりすることが可能になります。これは、大規模なアプリケーションやプラグインアーキテクチャを持つシステムで特に有用です。

### `-ldflags="-linkmode=external"`

Goコンパイラは通常、独自のリンカを使用して実行可能ファイルを生成します（内部リンケージ）。しかし、`-ldflags="-linkmode=external"` オプションを使用すると、Goコンパイラはシステムにインストールされている外部リンカ（例: `gcc`）を使用して最終的な実行可能ファイルをリンクするようになります。これは、Cgo（GoとCの相互運用機能）を使用する場合や、特定のシステムライブラリに依存する場合など、より複雑なリンケージ要件がある場合に必要となることがあります。外部リンカを使用することで、GoプログラムがCライブラリとより密接に連携できるようになります。

### `pair` 変数

`src/cmd/dist/test.go` 内の `pair` 変数は、オペレーティングシステムとアーキテクチャの組み合わせ（例: `linux-amd64`, `linux-s390x`）を表す文字列です。`cmd/dist` ツールは、この `pair` を用いて、特定の機能が現在のビルド環境でサポートされているかどうかを判断します。

    この関数は、指定されたビルドモード（例: `shared`）が現在のOS/アーキテクチャの組み合わせ（`pair`）でサポートされているかどうかを判断します。
    変更前は、`"shared"` モードがサポートされる `pair` のリストに `"linux-s390x"` が含まれていませんでした。

    ```diff

    +		case "linux-386", "linux-amd64", "linux-arm", "linux-arm64", "linux-ppc64le", "linux-s390x":
     			return true
     		}
     	return false
    ```

2.  **`cgoTest(dt *distTest) error` 関数**:
    この関数は、Cgoに関連するテスト、特に外部リンケージを使用するテストの実行ロジックを含んでいます。
    変更前は、外部リンケージテストが実行される `pair` のリストに `"linux-s390x"` が含まれていませんでした。
    変更後、`case` ステートメントに `"linux-s390x"` が追加されました。これにより、`s390x` 環境でも `go test -ldflags="-linkmode=external"` を使用したCgoテストが実行されるようになります。

    ```diff
    --- a/src/cmd/dist/test.go

    @@ -725,7 +725,7 @@ func (t *tester) cgoTest(dt *distTest) error {

     		"dragonfly-386", "dragonfly-amd64",
     		"freebsd-386", "freebsd-amd64", "freebsd-arm",
    -		"linux-386", "linux-amd64", "linux-arm",
    +		"linux-386", "linux-amd64", "linux-arm", "linux-s390x",
     		"netbsd-386", "netbsd-amd64":

     		cmd := t.addCmd(dt, "misc/cgo/test", "go", "test", "-ldflags", "-linkmode=external")
    ```

これらの変更は、`s390x` プラットフォームがGoの共有ライブラリと外部リンケージの機能を完全にサポートしていることを `cmd/dist` に明示的に伝えるものです。これにより、Goのテストスイートが `s390x` 上でこれらの重要な機能のテストを網羅的に実行し、プラットフォーム固有の潜在的な問題を早期に発見できるようになります。
