## 変更の背景

Goプロジェクトでは、コードの変更をレビューし、プロジェクトに統合するためにGerritというコードレビューシステムを使用しています。GerritとGitを連携させるためのカスタムコマンドとして、以前はドキュメント内で `git-review` という名称が使われていました。しかし、Goプロジェクトが公式に提供し、推奨しているツールは `golang.org/x/review/git-codereview` であり、そのコマンド名は `git-codereview` です。

このコミットの背景には、ドキュメントと実際のツールの名称の不一致を解消し、コントリビューターが正しいツール名と使用方法を理解できるようにするという目的があります。`git-review` という名称は、Gerritと連携する他のプロジェクトでも使われる一般的な名称であるため、Goプロジェクト固有のツールであることを明確にするためにも `git-codereview` という名称が適切と判断されたと考えられます。これにより、新規コントリビューターが混乱することなく、Goプロジェクトの貢献プロセスにスムーズに参加できるようになります。

## 前提知識の解説

### Gitとコードレビュー

Gitは分散型バージョン管理システムであり、ソフトウェア開発におけるコードの変更履歴を管理するために広く使用されています。コードレビューは、他の開発者が書いたコードを検査し、品質、正確性、効率性、セキュリティなどを評価するプロセスです。これにより、バグの早期発見、コード品質の向上、知識共有が促進されます。

### Gerrit

Gerritは、Gitリポジトリ上でコードレビューとプロジェクト管理を行うためのオープンソースのウェブベースツールです。Googleによって開発され、大規模なオープンソースプロジェクト（Android、Goなど）で広く採用されています。Gerritは、コミットがメインブランチにマージされる前に、変更がレビューされ、承認されることを保証します。

### `git-review` と `git-codereview`

これらは、GitとGerritの連携を容易にするためのカスタムGitコマンドです。
- **`git-review`**: 一般的にGerritと連携するためのツールとして知られていますが、Goプロジェクトでは `git-codereview` が公式のツールです。
- **`git-codereview`**: `golang.org/x/review` リポジトリに含まれるGoプロジェクト専用のツールです。このツールは、ローカルのGitリポジトリで「変更ブランチ」を管理し、Gerritサーバーへのコードアップロード、レビューの追跡、変更の同期など、Goのコードレビュープロセスを効率化するために設計されています。

### `go get` コマンド

`go get` はGo言語のツールチェーンの一部であり、Goパッケージやコマンドをリモートリポジトリからダウンロードし、インストールするために使用されます。このコミットでは、`go get -u golang.org/x/review/git-codereview` というコマンドが示されており、これは `git-codereview` ツールをダウンロードしてインストールする方法を説明しています。`-u` フラグは、依存関係も含めてパッケージを最新バージョンに更新することを意味します。

## 技術的詳細

このコミットは、`doc/contribute.html` ファイル内の文字列置換に焦点を当てています。具体的には、ドキュメント全体で `git-review` という文字列が出現する箇所を `git-codereview` に変更しています。

変更のポイントは以下の通りです。

1.  **コマンド名の統一**: Goプロジェクトのコントリビューションガイドにおいて、Gerritとの連携に使用するカスタムGitコマンドの名称を `git-review` から `git-codereview` に統一しています。これにより、ドキュメントの正確性が向上し、コントリビューターが正しいツール名を認識できるようになります。
2.  **インストールコマンドの更新**: `go get` を用いたツールのインストールコマンドも `go get -u golang.org/x/review/git-review` から `go get -u golang.org/x/review/git-codereview` に変更されています。これは、ツールのパスが `git-codereview` に変更されたことを反映しています。
3.  **エイリアスの更新**: `git` コマンドのエイリアス設定例においても、`review` ではなく `codereview` を使用するように変更されています。例えば、`change = review change` が `change = codereview change` になっています。また、`submit = codereview submit` という新しいエイリアスも追加されています。これは、`git-codereview` が提供するサブコマンドをより直接的に呼び出すためのものです。
4.  **ドキュメントリンクの更新**: `git-review` のコマンドドキュメントへのリンクも `https://godoc.org/golang.org/x/review/git-review` から `https://godoc.org/golang.org/x/review/git-codereview` に更新されています。

これらの変更は、Goプロジェクトのコントリビューションプロセスにおけるツールの名称と使用方法を明確にし、コントリビューターの利便性を高めることを目的としています。

## コアとなるコードの解説

このコミットは、`doc/contribute.html` ファイル内のテキストコンテンツを更新することで、Goプロジェクトのコントリビューションガイドの正確性を高めています。

-   **`git-review` から `git-codereview` への置換**: ドキュメント全体で、カスタムGitコマンドの参照が `git-review` から `git-codereview` に変更されています。これは、GoプロジェクトがGerritとの連携に推奨するツールの正式名称が `git-codereview` であることを明確にするためです。
-   **`go get` コマンドのパス更新**: `go get -u golang.org/x/review/git-review` が `go get -u golang.org/x/review/git-codereview` に変更され、ツールのインストールパスが修正されました。これにより、コントリビューターは正しいコマンドでツールをインストールできます。
-   **Gitエイリアスの更新と追加**: Gitエイリアスの設定例において、`review` サブコマンドが `codereview` サブコマンドに置き換えられています。例えば、`change = review change` は `change = codereview change` になりました。さらに、`submit = codereview submit` という新しいエイリアスが追加されており、これは `git-codereview` ツールが提供する `submit` 機能（Gerritへの変更の提出）を直接呼び出すためのものです。
-   **ドキュメントリンクの更新**: `godoc.org` 上のツールのドキュメントへのリンクも、新しいツール名に合わせて更新されています。

これらの変更は、Goプロジェクトへの貢献を考えている開発者にとって、より明確で正確な情報を提供し、ツールの誤用を防ぐことを目的としています。
