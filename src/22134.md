## 変更の背景

Go言語の `math/big` パッケージは、任意精度（arbitrary-precision）の数値演算を提供します。これには、整数（`Int`）、有理数（`Rat`）、浮動小数点数（`Float`）の型が含まれます。コミット前の `Float` 型には、その値を正確な有理数（分数）として取得するための `Rat` メソッドが未実装でした。

浮動小数点数は、コンピュータ上での表現の都合上、多くの場合で正確な値を表現できません。例えば、`0.1` は二進数では無限小数となり、有限のビット数では近似値としてしか表現できません。しかし、有理数（分数）は、分子と分母の整数によって正確に表現できます。

この `Float.Rat` メソッドの実装は、`Float` 型で計算された結果を、可能な限り精度を失わずに有理数として表現したいというニーズに応えるものです。特に、金融計算、科学技術計算、あるいは正確な比率を扱う必要がある場面で、この変換機能は非常に重要となります。以前は `panic("unimplemented")` となっていたことから、この機能は以前から計画されており、今回その実装が完了したことを示しています。

## 前提知識の解説

### `math/big` パッケージ

`math/big` パッケージは、Go言語で任意精度の数値演算を行うためのパッケージです。標準の `int` や `float64` 型では表現できない非常に大きな数値や、高い精度が要求される計算に対応するために使用されます。

*   **`Int`**: 任意精度の整数を扱います。
*   **`Rat`**: 任意精度の有理数（分数）を扱います。分子と分母は `Int` 型で表現されます。これにより、循環小数や無限小数となる浮動小数点数を正確に表現できます。
*   **`Float`**: 任意精度の浮動小数点数を扱います。IEEE 754浮動小数点数標準に準拠しており、仮数部と指数部によって数値を表現します。精度はユーザーが設定できます。

### 浮動小数点数の内部表現

`Float` 型は、内部的に符号、仮数（mantissa）、指数（exponent）によって数値を表現します。これは一般的な浮動小数点数表現と同様です。

*   **符号 (sign)**: 数値が正か負かを示します。
*   **仮数 (mantissa)**: 数値の有効数字部分です。`Float` 型では、この仮数部が `big.Int` 型のスライス（`x.mant`）で表現され、任意精度を可能にしています。
*   **指数 (exponent)**: 仮数部をどれだけシフトするかを示します。`Float` 型では、この指数部が `int64` 型（`x.exp`）で表現されます。

例えば、`1.25` という数値は、二進数で `1.01 * 2^0` と表現できます。この場合、仮数は `1.01`（二進数）、指数は `0` となります。

### 有理数（分数）の表現

`Rat` 型は、分子と分母の2つの `big.Int` 型の数値によって有理数を表現します。例えば、`1.25` は `5/4` と表現され、分子は `5`、分母は `4` となります。この表現は、浮動小数点数では近似値となるような数値（例: `1/3`）でも正確に扱うことができます。

## 技術的詳細

`Float.Rat` メソッドの主な目的は、`Float` 型の `x` を `Rat` 型に変換することです。この変換は、`Float` の内部表現である仮数（`x.mant`）と指数（`x.exp`）を利用して行われます。

基本的な考え方は、浮動小数点数 `F` が `M * 2^E` の形式で表現される場合、これを分数 `N/D` に変換することです。ここで `M` は仮数、`E` は指数です。

1.  **特殊なケースのハンドリング**:
    *   `±Inf` (無限大) の場合、`Rat` 型では表現できないため `nil` を返します。
    *   `0` の場合、`0/1` を返します。

2.  **仮数と指数からの変換**:
    *   `Float` の内部表現では、仮数 `x.mant` は `big.Word` のスライスとして格納されており、これは実質的に大きな整数です。
    *   `x.exp` は指数です。
    *   `allBits` は、仮数部が保持できるビットの総数を示します。これは `len(x.mant) * _W` で計算されます。ここで `_W` は `big.Word` のビット幅（通常は32または64）です。

3.  **分子と分母の構築**:
    *   **`x.exp > allBits` の場合**:
        これは、数値が非常に大きく、仮数部だけでは表現しきれないほど指数が大きいケースです。この場合、仮数 `x.mant` を `x.exp - allBits` ビットだけ左シフト（乗算）することで分子を構築します。分母は `1` となります。
        例: `M * 2^E` で `E` が非常に大きい場合、`M * 2^(E - allBits) / 1` のように表現されます。
    *   **`x.exp < allBits` の場合**:
        これは、数値が非常に小さく、仮数部だけでは表現しきれないほど指数が小さいケースです。この場合、仮数 `x.mant` が分子となり、分母は `2^(allBits - x.exp)` となります。
        例: `M * 2^E` で `E` が非常に小さい場合、`M / 2^(allBits - E)` のように表現されます。
    *   **それ以外の場合（`x.exp == allBits`）**:
        このケースは、仮数部がちょうど `allBits` のビット幅で表現される場合です。分子は `x.mant` そのものとなり、分母は `1` となります。

4.  **正規化**:
    変換された `Rat` は、`z.norm()` メソッドを呼び出すことで正規化されます。正規化とは、分子と分母の最大公約数で両方を割り、分母が正になるように調整する処理です。これにより、`2/4` のような分数が `1/2` のように最も簡単な形式に変換されます。

5.  **結果の格納**:
    `Rat` メソッドは、オプションで `*Rat` 型の引数 `z` を受け取ります。`z` が `nil` でない場合、結果はこの `z` に格納され、`z` が返されます。これにより、メモリ割り当てを削減し、パフォーマンスを向上させることができます。

## コアとなるコードの解説

### `src/math/big/float.go` の変更点

`Float.Rat` メソッドは、`Float` 型の `x` を `Rat` 型に変換するロジックをカプセル化しています。

1.  **関数シグネチャ**:
    ```go
    func (x *Float) Rat(z *Rat) *Rat
    ```
    このシグネチャは、`Float` 型のレシーバ `x` に対して `Rat` メソッドが定義されていることを示します。引数 `z` は、結果を格納するためのオプションの `*Rat` ポインタです。これにより、呼び出し元が既存の `Rat` オブジェクトを再利用してメモリ割り当てを避けることができます。

2.  **特殊値のハンドリング**:
    ```go
    switch x.ord() {
    case -2, +2:
        return nil // ±Inf
    case 0:
        if z == nil {
            return new(Rat)
        }
        return z.SetInt64(0)
    }
    ```
    `x.ord()` は `Float` の順序を返します。`-2` と `+2` はそれぞれ負の無限大と正の無限大を表します。無限大は有理数で表現できないため `nil` を返します。`0` の場合は、`0/1` を表す `Rat` オブジェクトを返します。`z` が指定されていればそれを再利用します。

3.  **仮数と指数に基づく変換ロジック**:
    ```go
    allBits := int32(len(x.mant)) * _W
    // build up numerator and denominator
    if z == nil {
        z = new(Rat)
    }
    z.a.neg = x.neg // 分子の符号を設定
    switch {
    case x.exp > allBits:
        // 指数が仮数部のビット幅より大きい場合
        // 分子を左シフト（乗算）して構築
        z.a.abs = z.a.abs.shl(x.mant, uint(x.exp-allBits))
        z.b.abs = z.b.abs[:0] // 分母は1
        return z              // already in normal form
    default: // x.exp == allBits の場合
        // 仮数部がちょうどビット幅に収まる場合
        // 分子は仮数そのまま
        z.a.abs = z.a.abs.set(x.mant)
        z.b.abs = z.b.abs[:0] // 分母は1
        return z              // already in normal form
    case x.exp < allBits:
        // 指数が仮数部のビット幅より小さい場合
        // 分子は仮数そのまま
        z.a.abs = z.a.abs.set(x.mant)
        t := z.b.abs.setUint64(1)
        // 分母を左シフト（乗算）して構築
        z.b.abs = t.shl(t, uint(allBits-x.exp))
        return z.norm() // 正規化して返す
    }
    ```
    この `switch` ステートメントは、`Float` の指数 `x.exp` と仮数部の総ビット幅 `allBits` の関係に基づいて、分子 `z.a.abs` と分母 `z.b.abs` を構築します。
    *   `shl(x.mant, n)`: `x.mant` を `n` ビット左シフトします。これは `x.mant * 2^n` に相当します。
    *   `set(x.mant)`: `x.mant` の値を設定します。
    *   `setUint64(1)`: `big.Int` を `1` に設定します。
    *   `z.norm()`: 構築された `Rat` を正規化します。

このコミットは、`math/big` パッケージの `Float` 型に `Rat` メソッドを実装したことを示しています。

## 変更の背景

Go言語の `math/big` パッケージは、任意精度（arbitrary-precision）の数値演算を提供します。これには、整数（`Int`）、有理数（`Rat`）、浮動小数点数（`Float`）の型が含まれます。コミット前の `Float` 型には、その値を正確な有理数（分数）として取得するための `Rat` メソッドが未実装でした。

浮動小数点数は、コンピュータ上での表現の都合上、多くの場合で正確な値を表現できません。例えば、`0.1` は二進数では無限小数となり、有限のビット数では近似値としてしか表現できません。しかし、有理数（分数）は、分子と分母の整数によって正確に表現できます。

この `Float.Rat` メソッドの実装は、`Float` 型で計算された結果を、可能な限り精度を失わずに有理数として表現したいというニーズに応えるものです。特に、金融計算、科学技術計算、あるいは正確な比率を扱う必要がある場面で、この変換機能は非常に重要となります。以前は `panic("unimplemented")` となっていたことから、この機能は以前から計画されており、今回その実装が完了したことを示しています。

## 前提知識の解説

### `math/big` パッケージ

`math/big` パッケージは、Go言語で任意精度の数値演算を行うためのパッケージです。標準の `int` や `float64` 型では表現できない非常に大きな数値や、高い精度が要求される計算に対応するために使用されます。

*   **`Int`**: 任意精度の整数を扱います。
*   **`Rat`**: 任意精度の有理数（分数）を扱います。分子と分母は `Int` 型で表現されます。これにより、循環小数や無限小数となる浮動小数点数を正確に表現できます。
*   **`Float`**: 任意精度の浮動小数点数を扱います。IEEE 754浮動小数点数標準に準拠しており、仮数部と指数部によって数値を表現します。精度はユーザーが設定できます。

### 浮動小数点数の内部表現

`Float` 型は、内部的に符号、仮数（mantissa）、指数（exponent）によって数値を表現します。これは一般的な浮動小数点数表現と同様です。

*   **符号 (sign)**: 数値が正か負かを示します。
*   **仮数 (mantissa)**: 数値の有効数字部分です。`Float` 型では、この仮数部が `big.Int` 型のスライス（`x.mant`）で表現され、任意精度を可能にしています。
*   **指数 (exponent)**: 仮数部をどれだけシフトするかを示します。`Float` 型では、この指数部が `int64` 型（`x.exp`）で表現されます。

例えば、`1.25` という数値は、二進数で `1.01 * 2^0` と表現できます。この場合、仮数は `1.01`（二進数）、指数は `0` となります。

### 有理数（分数）の表現

`Rat` 型は、分子と分母の2つの `big.Int` 型の数値によって有理数を表現します。例えば、`1.25` は `5/4` と表現され、分子は `5`、分母は `4` となります。この表現は、浮動小数点数では近似値となるような数値（例: `1/3`）でも正確に扱うことができます。

## 技術的詳細

`Float.Rat` メソッドの主な目的は、`Float` 型の `x` を `Rat` 型に変換することです。この変換は、`Float` の内部表現である仮数（`x.mant`）と指数（`x.exp`）を利用して行われます。

基本的な考え方は、浮動小数点数 `F` が `M * 2^E` の形式で表現される場合、これを分数 `N/D` に変換することです。ここで `M` は仮数、`E` は指数です。

1.  **特殊なケースのハンドリング**:
    *   `±Inf` (無限大) の場合、`Rat` 型では表現できないため `nil` を返します。
    *   `0` の場合、`0/1` を返します。

2.  **仮数と指数からの変換**:
    *   `Float` の内部表現では、仮数 `x.mant` は `big.Word` のスライスとして格納されており、これは実質的に大きな整数です。
    *   `x.exp` は指数です。
    *   `allBits` は、仮数部が保持できるビットの総数を示します。これは `len(x.mant) * _W` で計算されます。ここで `_W` は `big.Word` のビット幅（通常は32または64）です。

3.  **分子と分母の構築**:
    *   **`x.exp > allBits` の場合**:
        これは、数値が非常に大きく、仮数部だけでは表現しきれないほど指数が大きいケースです。この場合、仮数 `x.mant` を `x.exp - allBits` ビットだけ左シフト（乗算）することで分子を構築します。分母は `1` となります。
        例: `M * 2^E` で `E` が非常に大きい場合、`M * 2^(E - allBits) / 1` のように表現されます。
    *   **`x.exp < allBits` の場合**:
        これは、数値が非常に小さく、仮数部だけでは表現しきれないほど指数が小さいケースです。この場合、仮数 `x.mant` が分子となり、分母は `2^(allBits - x.exp)` となります。
        例: `M * 2^E` で `E` が非常に小さい場合、`M / 2^(allBits - E)` のように表現されます。
    *   **それ以外の場合（`x.exp == allBits`）**:
        このケースは、仮数部がちょうど `allBits` のビット幅で表現される場合です。分子は `x.mant` そのものとなり、分母は `1` となります。

4.  **正規化**:
    変換された `Rat` は、`z.norm()` メソッドを呼び出すことで正規化されます。正規化とは、分子と分母の最大公約数で両方を割り、分母が正になるように調整する処理です。これにより、`2/4` のような分数が `1/2` のように最も簡単な形式に変換されます。

5.  **結果の格納**:
    `Rat` メソッドは、オプションで `*Rat` 型の引数 `z` を受け取ります。`z` が `nil` でない場合、結果はこの `z` に格納され、`z` が返されます。これにより、メモリ割り当てを削減し、パフォーマンスを向上させることができます。

## コアとなるコードの解説

### `src/math/big/float.go` の変更点

`Float.Rat` メソッドは、`Float` 型の `x` を `Rat` 型に変換するロジックをカプセル化しています。

1.  **関数シグネチャ**:
    ```go
    func (x *Float) Rat(z *Rat) *Rat
    ```
    このシグネチャは、`Float` 型のレシーバ `x` に対して `Rat` メソッドが定義されていることを示します。引数 `z` は、結果を格納するためのオプションの `*Rat` ポインタです。これにより、呼び出し元が既存の `Rat` オブジェクトを再利用してメモリ割り当てを避けることができます。

2.  **特殊値のハンドリング**:
    ```go
    switch x.ord() {
    case -2, +2:
        return nil // ±Inf
    case 0:
        if z == nil {
            return new(Rat)
        }
        return z.SetInt64(0)
    }
    ```
    `x.ord()` は `Float` の順序を返します。`-2` と `+2` はそれぞれ負の無限大と正の無限大を表します。無限大は有理数で表現できないため `nil` を返します。`0` の場合は、`0/1` を表す `Rat` オブジェクトを返します。`z` が指定されていればそれを再利用します。

3.  **仮数と指数に基づく変換ロジック**:
    ```go
    allBits := int32(len(x.mant)) * _W
    // build up numerator and denominator
    if z == nil {
        z = new(Rat)
    }
    z.a.neg = x.neg // 分子の符号を設定
    switch {
    case x.exp > allBits:
        // 指数が仮数部のビット幅より大きい場合
        // 分子を左シフト（乗算）して構築
        z.a.abs = z.a.abs.shl(x.mant, uint(x.exp-allBits))
        z.b.abs = z.b.abs[:0] // 分母は1
        return z              // already in normal form
    default: // x.exp == allBits の場合
        // 仮数部がちょうどビット幅に収まる場合
        // 分子は仮数そのまま
        z.a.abs = z.a.abs.set(x.mant)
        z.b.abs = z.b.abs[:0] // 分母は1
        return z              // already in normal form
    case x.exp < allBits:
        // 指数が仮数部のビット幅より小さい場合
        // 分子は仮数そのまま
        z.a.abs = z.a.abs.set(x.mant)
        t := z.b.abs.setUint64(1)
        // 分母を左シフト（乗算）して構築
        z.b.abs = t.shl(t, uint(allBits-x.exp))
        return z.norm() // 正規化して返す
    }
    ```
    この `switch` ステートメントは、`Float` の指数 `x.exp` と仮数部の総ビット幅 `allBits` の関係に基づいて、分子 `z.a.abs` と分母 `z.b.abs` を構築します。
    *   `shl(x.mant, n)`: `x.mant` を `n` ビット左シフトします。これは `x.mant * 2^n` に相当します。
    *   `set(x.mant)`: `x.mant` の値を設定します。
    *   `setUint64(1)`: `big.Int` を `1` に設定します。
    *   `z.norm()`: 構築された `Rat` を正規化します。

`TestFloatRat` 関数は、`Float.Rat` メソッドの正確性を検証するための包括的なテストスイートです。

    ```go
