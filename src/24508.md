## 変更の背景

Go言語の新しいバージョンであるGo 1.5がリリースされたことに伴い、ソースコードからGoをインストールする際の手順が更新される必要がありました。以前のドキュメントでは、`git checkout`コマンドで`go1.4`タグを指定するように指示されていましたが、Go 1.5のリリースにより、この指示は古くなっていました。このコミットは、この古い情報を修正し、ユーザーが最新のGo 1.5を正しくインストールできるようにすることを目的としています。コミットメッセージにある「Fixes #11983」は、このドキュメントの不正確さを報告する内部イシューに対応するものであることを示唆しています。

## 前提知識の解説

*   **Go言語のインストール（ソースから）:** Go言語は、公式のバイナリ配布だけでなく、ソースコードからビルドしてインストールすることも可能です。これは、特定の開発環境の要件を満たすためや、最新の開発版を試す場合などに利用されます。ソースからのインストールは、通常、GitリポジトリからGoのソースコードをクローンし、特定のバージョンタグをチェックアウトしてから、ビルドコマンドを実行する手順で行われます。
*   **Gitとバージョン管理:** Gitは、ソフトウェア開発で広く使用されている分散型バージョン管理システムです。GoプロジェクトのソースコードもGitで管理されています。
    *   `git clone`: リモートのGitリポジトリから、プロジェクトの完全なコピーをローカルマシンにダウンロードするコマンドです。
    *   `git checkout`: 作業ディレクトリを特定のブランチ、コミット、またはタグの状態に切り替えるために使用されるコマンドです。Goのインストール手順では、安定版リリースに対応するタグ（例: `go1.4`, `go1.5`）をチェックアウトすることが推奨されます。
*   **Goのバージョンタグ:** Goプロジェクトでは、各公式リリースバージョンに対して、`go1.x`のような形式のタグが付けられます。これにより、開発者は特定のバージョンのソースコードを正確に参照し、ビルドすることができます。
*   **`GOROOT`と`GOPATH`:** Go開発において重要な環境変数です。
    *   `GOROOT`: Goのインストールディレクトリを指します。Goの標準ライブラリやツールチェーンがここに配置されます。ソースからGoをビルドした場合、通常、ビルドされたGoの環境がこのパスに設定されます。
    *   `GOPATH`: Goのワークスペースディレクトリを指します。Goのソースコード、パッケージ、および実行可能ファイルが配置される場所です。現代のGoモジュールシステムではその重要性は薄れていますが、古いプロジェクトや特定のビルドシナリオでは依然として関連性があります。

## 技術的詳細

このコミットは、Goの公式ドキュメントの一部である`doc/install-source.html`ファイルを修正しています。このHTMLファイルは、Goをソースコードからビルドしてインストールする手順を説明するものです。

Go 1.5のリリースに伴い、ドキュメント内の2つの主要な箇所でバージョン参照が更新されました。

1.  **`git checkout`コマンドのバージョン指定:**
    ソースからのインストール手順では、ユーザーがGoリポジトリをクローンした後、特定の安定版リリースをチェックアウトするように指示されます。以前は`go1.4`タグが推奨されていましたが、Go 1.5が新しい安定版としてリリースされたため、この指示は`go1.5`に更新されました。これにより、ユーザーは最新の安定版Goをインストールするための正しいコマンドを実行できます。

2.  **リリースバージョンの例示:**
    ドキュメントの別のセクションでは、新しいリリースが`golang-announce`メーリングリストで発表される際に、最新のリリースタグの例として`go1.4`が挙げられていました。この例も`go1.5`に更新され、ドキュメント全体で一貫した最新のバージョン情報が提供されるようになりました。

これらの変更は、ドキュメントの正確性を維持し、ユーザーが常に最新かつ推奨されるGoバージョンをインストールできるようにするための、標準的なドキュメントメンテナンス作業の一環です。

## コアとなるコードの解説

このコミットの核心は、`doc/install-source.html`ファイル内の2つの変更点にあります。

1.  **`git checkout`コマンドの更新 (行 170):**
    変更前: `$ git checkout go1.4`
    変更後: `$ git checkout go1.5`
    この変更は、Goのソースコードをクローンした後に、どのバージョンのソースコードをチェックアウトすべきかという指示を更新しています。Go 1.5がリリースされたため、ユーザーは最新の安定版である`go1.5`タグをチェックアウトすることが推奨されます。これにより、ユーザーはGo 1.5の機能と修正を含むバージョンをビルドできます。

2.  **リリースバージョンの言及の更新 (行 349):**
    変更前: `<code>go1.4</code>`
    変更後: `<code>go1.5</code>`
    この変更は、Goの新しいリリースが発表される際に言及されるリリースタグの例を更新しています。以前は`go1.4`が例として挙げられていましたが、Go 1.5のリリースに伴い、この例も`go1.5`に更新されました。これは、ドキュメント全体でバージョン情報の一貫性を保つための修正です。

これらの変更は、Goのインストール手順が常に最新の安定版リリースを反映するようにするための、シンプルながらも重要なドキュメントの更新です。
