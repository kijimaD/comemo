Go言語のドキュメンテーションシステム（`go doc`コマンドや`godoc`ツールによって生成されるもの）は、特定の命名規則に従ってExample関数を認識し、パッケージのドキュメントに含めます。Example関数は、`Example<FunctionName>`または`Example<Type>_<Method>`の形式で命名される必要があります。

このコミットは、Example関数の名前をGoのドキュメンテーション規則に準拠させることで、これらのExampleがドキュメントに正しく表示され、ユーザーがより簡単に`mime`パッケージの機能と使用方法を理解できるようにすることを目的としています。特に、`WordDecoder`の`CharsetReader`フィールドは、非標準の文字セットを扱う際に非常に重要であり、その使用例が追加されたことで、より実用的なドキュメントが提供されることになりました。

## 前提知識の解説

### Go言語のExample関数とドキュメンテーション

Go言語には、コードの動作例をテストとして記述し、同時にドキュメントとして利用できる「Example関数」というユニークな機能があります。
*   **命名規則**: Example関数は`func Example<FunctionName>()`、`func Example<Type>()`、または`func Example<Type>_<Method>()`という形式で命名されます。
*   **出力検証**: Example関数内で`fmt.Println`などを用いて標準出力に出力された内容は、関数のコメントに`// Output:`または`// Unordered output:`として記述された期待される出力と比較されます。これにより、Exampleが常に正しい出力を生成することを保証するテストとしても機能します。
*   **ドキュメントへの表示**: `go doc`コマンドや`godoc`ツールは、これらの命名規則に従って記述されたExample関数を自動的に検出し、生成されるパッケージドキュメントに含めます。これにより、ユーザーはコードの具体的な使用例をドキュメントから直接確認できます。

### MIME Encoded-Word (RFC 2047)

MIME (Multipurpose Internet Mail Extensions) は、電子メールでASCII以外の文字（日本語、絵文字など）やバイナリデータ（画像、音声など）を扱うための標準です。MIME Encoded-Wordは、特にメールヘッダー（Subject, From, Toなど）でASCII以外の文字を使用するためのメカニズムを定義しています (RFC 2047)。

*   **形式**: `=?charset?encoding?encoded-text?=`
    *   `charset`: 使用される文字セット（例: `utf-8`, `iso-2022-jp`）。
    *   `encoding`: エンコーディング方式。`Q` (Quoted-Printable) または `B` (Base64) のいずれか。
    *   `encoded-text`: `charset`と`encoding`でエンコードされた元のテキスト。
*   **例**: `Subject: =?utf-8?Q?=E3=83=86=E3=82=B9=E3=83=88?=` (「テスト」のUTF-8 Quoted-Printableエンコード)

### `mime`パッケージの`WordDecoder`と`CharsetReader`

Goの`mime`パッケージは、MIME Encoded-Wordのエンコードとデコードを扱う機能を提供します。
*   `WordDecoder`構造体は、Encoded-Wordをデコードするための設定を保持します。
*   `CharsetReader`フィールドは、`WordDecoder`の重要なカスタマイズポイントです。これは、特定の文字セットでエンコードされたデータを読み取るためのカスタムリーダー関数を設定するために使用されます。デフォルトでは、`mime`パッケージは一般的な文字セット（UTF-8など）を処理できますが、非標準の文字セットや、Goの標準ライブラリが直接サポートしていない文字セットをデコードする必要がある場合、この`CharsetReader`を設定することで対応できます。このフィールドは、`func(charset string, input io.Reader) (io.Reader, error)`というシグネチャを持つ関数を受け取ります。この関数は、指定された`charset`とエンコードされたデータを含む`input`リーダーを受け取り、デコードされたバイト列を読み取る新しい`io.Reader`を返します。

## 技術的詳細

このコミットの技術的変更は、主にGoのExample関数の命名規則への準拠と、`WordDecoder`の`CharsetReader`フィールドの具体的な使用例の追加に集約されます。

1.  **Example関数のリネーム**:
    *   `ExampleEncodeWord`は`ExampleWordEncoder_Encode`にリネームされました。これは、`Encode`メソッドが`WordEncoder`型に属していることを明確にし、ドキュメンテーションツールがこれを正しく関連付けることを可能にします。
    *   `ExampleDecodeWord`は`ExampleWordDecoder_Decode`にリネームされました。同様に、`Decode`メソッドが`WordDecoder`型に属していることを示します。
    *   `ExampleDecodeHeader`は`ExampleWordDecoder_DecodeHeader`にリネームされました。これは、`DecodeHeader`メソッドが`WordDecoder`型に属していることを示します。

2.  **`CharsetReader`の使用例の追加**:
    `ExampleWordDecoder_Decode`と`ExampleWordDecoder_DecodeHeader`の両方に、`WordDecoder`の`CharsetReader`フィールドを設定するコードが追加されました。
    *   この例では、`"x-case"`という架空の文字セットを定義しています。
    *   `CharsetReader`関数は、`"x-case"`文字セットが指定された場合、入力ストリームから読み取った内容をすべて大文字に変換する`io.Reader`を返します。これは、カスタム文字セット処理の概念をデモンストレーションするためのものです。
    *   このカスタム`CharsetReader`を設定した後、`=?x-case?q?hello!?=`や`=?x-case?q?hello_?= =?x-case?q?world!?=`のようなEncoded-Wordをデコードし、期待される出力（`HELLO!`、`HELLO WORLD!`）が生成されることを示しています。
    *   この追加により、開発者は`mime`パッケージが標準でサポートしていない文字セットをどのように扱うべきか、具体的なコード例を通じて理解できるようになります。

これらの変更は、`go doc`ツールがExampleを正しく認識し、生成されるドキュメントの品質と実用性を向上させるために不可欠でした。

## コアとなるコードの解説

このコミットでは、`src/mime/encodedword_test.go`ファイル内の3つのExample関数の名前が変更されました。

1.  **`ExampleEncodeWord`から`ExampleWordEncoder_Encode`への変更**:
    *   元の`ExampleEncodeWord`は、`QEncoding.Encode`や`BEncoding.Encode`といった`WordEncoder`型のメソッドの使用例を示していました。Goのドキュメンテーション規則では、特定の型のメソッドのExampleは`Example<Type>_<Method>`の形式で命名されるべきです。この変更により、`go doc mime WordEncoder.Encode`のようなコマンドでこのExampleが正しく表示されるようになります。

2.  **`ExampleDecodeWord`から`ExampleWordDecoder_Decode`への変更**:
    *   同様に、`ExampleDecodeWord`は`WordDecoder`型の`Decode`メソッドの使用例を示していました。この変更により、`go doc mime WordDecoder.Decode`でExampleが表示されます。
    *   このExampleには、`WordDecoder`の`CharsetReader`フィールドを設定する新しいコードブロックが追加されました。これは、カスタム文字セット（この場合は`"x-case"`という架空の文字セット）を処理する方法を示しています。`CharsetReader`は、`io.Reader`を受け取り、デコードされたコンテンツを返す別の`io.Reader`を生成する関数です。この例では、入力されたバイト列をすべて大文字に変換する処理を実装しています。これにより、非標準の文字セットを扱う際の柔軟性が示されています。

3.  **`ExampleDecodeHeader`から`ExampleWordDecoder_DecodeHeader`への変更**:
    *   `ExampleDecodeHeader`もまた、`WordDecoder`型の`DecodeHeader`メソッドの使用例でした。この変更により、`go doc mime WordDecoder.DecodeHeader`でExampleが表示されます。
    *   `ExampleWordDecoder_Decode`と同様に、このExampleにも`CharsetReader`を設定してカスタム文字セットを処理するコードが追加されました。これにより、複数のEncoded-Wordを含むヘッダー文字列が、カスタム`CharsetReader`によってどのように処理されるかを示しています。

これらの変更は、Goのドキュメンテーションの品質を向上させ、開発者が`mime`パッケージの機能をより効果的に利用できるようにするためのものです。特に`CharsetReader`の例は、国際化されたアプリケーションでMIME Encoded-Wordを扱う際の重要なガイダンスとなります。
