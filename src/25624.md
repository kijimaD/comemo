# [インデックス 25624] ファイルの概要

このコミットは、Goプロジェクトの`misc/sortac`ディレクトリに新しいユーティリティツール`sortac`を追加するものです。このツールは、`AUTHORS`ファイルと`CONTRIBUTORS`ファイルの内容をソートするために設計されており、これらのファイルを自動的に更新する他のツールの一部として使用されることを想定しています。

## 元コミット内容

`misc/sortac: AUTHORSおよびCONTRIBUTORSファイルをソートするツールを追加`

このユーティリティは、`AUTHORS`ファイルと`CONTRIBUTORS`ファイルを自動更新する他のツールの一部として使用されるもので、これまで紛失しがちだった。これをリポジトリにチェックインすることで、紛失を防ぎ、他の開発者も利用できるようにする。

Issue #12042を更新。

## 変更の背景

コミットメッセージによると、この`sortac`ユーティリティは、Goプロジェクトの`AUTHORS`ファイルと`CONTRIBUTORS`ファイルを自動的に更新するプロセスの一部として、Brad Fitzpatrick氏によって個人的に利用されていました。しかし、このツールが頻繁に紛失してしまうという問題があったため、リポジトリに正式に追加することで、以下の目的を達成しようとしています。

1.  **ツールの永続化**: 開発者が個人的に管理していたユーティリティをプロジェクトのリポジトリに含めることで、紛失のリスクをなくし、将来にわたって利用可能にする。
2.  **共有と再利用**: 他のGo開発者もこのツールを利用できるようにし、同様のファイル管理タスクを効率化できるようにする。
3.  **標準化**: `AUTHORS`および`CONTRIBUTORS`ファイルのソート順を標準化し、一貫性を保つ。

また、この変更はIssue #12042に関連しており、おそらくこれらのファイルの管理に関する課題を解決するための一環として導入されました。

## 前提知識の解説

### AUTHORSおよびCONTRIBUTORSファイル

多くのオープンソースプロジェクトでは、プロジェクトに貢献した人々を記録するために`AUTHORS`や`CONTRIBUTORS`といったテキストファイルを使用します。これらのファイルには、通常、貢献者の名前やメールアドレスが一覧形式で記載されており、プロジェクトへの貢献を公式に認識する役割を果たします。これらのファイルは、プロジェクトの歴史やコミュニティの成長を示す重要なドキュメントであり、通常はアルファベット順にソートされていることが期待されます。

### Go言語のツール開発

Go言語は、その強力な標準ライブラリとシンプルな構文により、コマンドラインツールの開発に非常に適しています。`go install`コマンドで簡単にバイナリを生成し、パスの通った場所に配置できるため、ユーティリティツールの配布も容易です。この`sortac`もGo言語で書かれた典型的なCLIツールです。

### `golang.org/x/text/collate`パッケージ

Goの標準ライブラリには基本的な文字列ソート機能（`sort.Strings`）がありますが、これはバイト値に基づいたソートであり、多言語環境や特定の言語の慣習に合わせた「人間が期待する」ソート順とは異なる場合があります。例えば、アクセント記号付きの文字や特定の文字の並び順は、言語によって異なります。

`golang.org/x/text/collate`パッケージは、このような言語固有のソート（照合順序、collation）を扱うためのパッケージです。Unicode Collation Algorithm (UCA) に基づいており、`language`パッケージと組み合わせて使用することで、特定の言語やロケールに合わせた正確な文字列ソートを提供します。

*   `collate.New(language.Und, collate.Loose)`: `collate.New`は新しい照合器（collator）を作成します。
    *   `language.Und`: "Undefined"の略で、特定の言語に依存しないデフォルトの照合順序を使用することを示します。これは、一般的なアルファベット順ソートに適しています。
    *   `collate.Loose`: 照合の厳密さを指定します。`Loose`は、アクセント記号や大文字・小文字の違いを無視するなど、より緩やかな比較を行います。これにより、例えば "apple" と "Apple" が同じと見なされ、より自然なソート結果が得られます。

### `bufio.Scanner`

`bufio.Scanner`は、`io.Reader`からデータを読み込み、行単位や単語単位で簡単に処理するためのGoの標準ライブラリです。大きなファイルを効率的に読み込む際にメモリ使用量を抑え、エラーハンドリングも容易にします。

### `io/ioutil.WriteFile`

`io/ioutil`パッケージは、ファイル操作に関する便利なユーティリティ関数を提供します。`ioutil.WriteFile`は、指定されたパスにバイトスライスを書き込み、ファイルが存在しない場合は作成し、存在する場合は上書きします。ファイルのパーミッションも指定できます。

## 技術的詳細

`sortac`ツールは、`AUTHORS`や`CONTRIBUTORS`のようなテキストファイルを、言語に依存しない（`language.Und`）が緩やかな（`collate.Loose`）照合順序でソートすることを目的としています。

### 動作モード

1.  **ファイル引数がある場合**: コマンドライン引数としてファイルパスが与えられた場合、`sortac`はそれらのファイルを読み込み、ソートした内容で元のファイルを上書きします（インプレースソート）。
2.  **ファイル引数がない場合**: コマンドライン引数が与えられない場合、`sortac`は標準入力からデータを読み込み、ソートした結果を標準出力に出力します。

### ヘッダー行の保持

`AUTHORS`や`CONTRIBUTORS`ファイルには、しばしば「`# Please keep the list sorted.`」のようなコメント行が含まれています。このツールは、この特定のヘッダー行を認識し、ソート対象のリストとは別に保持し、ソート後にファイルの先頭に再配置することで、コメントが失われないようにします。これは、ファイルの構造を維持するための重要な機能です。

### ソートアルゴリズム

ソートには、`golang.org/x/text/collate`パッケージが使用されます。これにより、単なるバイト比較ではなく、言語学的に適切なソート順が保証されます。`language.Und`と`collate.Loose`の組み合わせは、一般的な英語圏のアルファベット順ソートに適しており、大文字・小文字や一部の記号の違いを吸収して、より「人間にとって自然な」順序を提供します。

## コアとなるコードの変更箇所

このコミットでは、`misc/sortac/sortac.go`という新しいファイルが追加されています。

```go
// Copyright 2015 The Go Authors. All rights reserved.
// Use of this source code is governed by a BSD-style
// license that can be found in the LICENSE file.

// Sortac sorts the AUTHORS and CONTRIBUTORS files.
//
// Usage:
//
//    sortac [file...]
//
// Sortac sorts the named files in place.
// If given no arguments, it sorts standard input to standard output.
package main

import (
	"bufio"
	"bytes"
	"flag"
	"fmt"
	"io"
	"io/ioutil"
	"log"
	"os"

	"golang.org/x/text/collate"
	"golang.org/x/text/language"
)

func main() {
	log.SetFlags(0)
	log.SetPrefix("sortac: ")
	flag.Parse()

	args := flag.Args()
	if len(args) == 0 {
		os.Stdout.Write(sortAC(os.Stdin))
	} else {
		for _, arg := range args {
			f, err := os.Open(arg)
			if err != nil {
				log.Fatal(err)
			}
			sorted := sortAC(f)
			f.Close()
			if err := ioutil.WriteFile(arg, sorted, 0644); err != nil {
				log.Fatal(err)
			}
		}
	}
}

func sortAC(r io.Reader) []byte {
	bs := bufio.NewScanner(r)
	var header []string
	var lines []string
	for bs.Scan() {
		t := bs.Text()
		lines = append(lines, t)
		if t == "# Please keep the list sorted." {
			header = lines
			lines = nil
			continue
		}
	}
	if err := bs.Err(); err != nil {
		log.Fatal(err)
	}

	var out bytes.Buffer
	c := collate.New(language.Und, collate.Loose)
	c.SortStrings(lines)
	for _, l := range header {
		fmt.Fprintln(&out, l)
	}
	for _, l := range lines {
		fmt.Fprintln(&out, l)
	}
	return out.Bytes()
}
```

## コアとなるコードの解説

### `main`関数

*   `log.SetFlags(0)`と`log.SetPrefix("sortac: ")`: ログ出力のフォーマットを設定しています。タイムスタンプなどを省略し、すべてのログメッセージの前に"sortac: "というプレフィックスを付けます。
*   `flag.Parse()`: コマンドライン引数をパースします。このツールではフラグは定義されていませんが、`flag.Args()`でフラグ以外の引数（ファイルパス）を取得するために呼び出されます。
*   `args := flag.Args()`: コマンドライン引数からファイルパスのリストを取得します。
*   `if len(args) == 0`: 引数がない場合、標準入力（`os.Stdin`）から読み込み、ソート結果を標準出力（`os.Stdout`）に書き出します。
*   `else`: 引数がある場合、各ファイルパスに対して以下の処理を繰り返します。
    *   `os.Open(arg)`: ファイルを開きます。エラーが発生した場合は`log.Fatal`でプログラムを終了します。
    *   `sorted := sortAC(f)`: 開いたファイルの内容を`sortAC`関数に渡し、ソートされたバイトスライスを取得します。
    *   `f.Close()`: ファイルを閉じます。
    *   `ioutil.WriteFile(arg, sorted, 0644)`: ソートされた内容で元のファイルを上書きします。パーミッションは`0644`（所有者は読み書き可能、グループとその他は読み取りのみ可能）に設定されます。エラーが発生した場合は`log.Fatal`でプログラムを終了します。

### `sortAC`関数

この関数は、`io.Reader`からテキストを読み込み、ソートしてバイトスライスとして返します。

*   `bs := bufio.NewScanner(r)`: `io.Reader`（ファイルまたは標準入力）を行単位で読み込むための`bufio.Scanner`を作成します。
*   `var header []string`と`var lines []string`: ヘッダー行とソート対象の行を格納するためのスライスを宣言します。
*   `for bs.Scan()`: スキャナーが行を読み込める限りループします。
    *   `t := bs.Text()`: 現在の行のテキストを取得します。
    *   `lines = append(lines, t)`: 現在の行を`lines`スライスに追加します。
    *   `if t == "# Please keep the list sorted."`: もし現在の行が特定のヘッダーコメントと一致した場合、
        *   `header = lines`: それまでの行（ヘッダーコメントを含む）を`header`スライスにコピーします。
        *   `lines = nil`: `lines`スライスをリセットし、ヘッダーコメント以降の行のみがソート対象となるようにします。
        *   `continue`: 次の行の処理に進みます。
*   `if err := bs.Err(); err != nil`: スキャン中にエラーが発生した場合、`log.Fatal`でプログラムを終了します。
*   `var out bytes.Buffer`: ソートされた結果を構築するための`bytes.Buffer`を作成します。
*   `c := collate.New(language.Und, collate.Loose)`: 言語に依存しない緩やかな照合順序を持つ新しい照合器を作成します。
*   `c.SortStrings(lines)`: `lines`スライス内の文字列を、作成した照合器`c`のルールに従ってソートします。
*   `for _, l := range header`: 保持しておいたヘッダー行を`out`バッファに書き込みます。
*   `for _, l := range lines`: ソートされた行を`out`バッファに書き込みます。
*   `return out.Bytes()`: 構築されたバイトスライスを返します。
