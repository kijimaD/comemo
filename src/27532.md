## 前提知識の解説

### Go言語の `sync.Mutex`

`sync.Mutex` は、Go言語の標準ライブラリ `sync` パッケージで提供される相互排他ロック（ミューテックス）です。並行処理において、複数のGoroutineが共有リソースに同時にアクセスする際に発生する競合状態（Race Condition）を防ぐために使用されます。

-   **`Lock()` メソッド**: ミューテックスをロックします。既にロックされている場合、ロックが解放されるまで呼び出し元のGoroutineはブロックされます。
-   **`Unlock()` メソッド**: ミューテックスをアンロックします。ロックを保持しているGoroutineのみがアンロックできます。

`sync.Mutex` を使用する際の一般的なパターンは、共有リソースへのアクセス前後に `Lock()` と `Unlock()` を呼び出すことです。特に、`defer` ステートメントと組み合わせて `defer mu.Unlock()` とすることで、関数の終了時に確実にロックが解放されるようにすることが推奨されます。

### Go言語の命名規則と慣習

Go言語には、公式のスタイルガイド（Effective GoやGo Code Review Comments）があり、変数名、関数名、構造体名などの命名に関する慣習が定められています。これらの慣習に従うことで、Goコードの可読性と一貫性が向上し、異なる開発者間でのコラボレーションが容易になります。

`sync.Mutex` のインスタンス名として `mu` を使用する慣習は、以下の理由から広く採用されています。

1.  **簡潔性**: `mu` は "mutex" の短縮形であり、簡潔でタイプしやすいです。
2.  **一貫性**: 多くのGoプロジェクトや標準ライブラリでこの命名が採用されており、Go開発者にとって自然なものとなっています。
3.  **明確性**: `mu` という名前を見るだけで、それが相互排他ロックであることをすぐに理解できます。

このコミットは、このようなGoコミュニティで確立された命名慣習に、既存のコードを適合させるためのものです。
