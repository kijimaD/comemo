# [インデックス 15488] ファイルの概要

このコミットは、Go言語のmacOSインストーラーパッケージが、既存のGoのインストールを検出し、それを削除してから新しいバージョンをインストールする機能を追加するものです。これにより、ユーザーは以前のインストールを手動で削除することなく、スムーズにアップグレードできるようになります。

## 変更の背景

この変更の背景には、Go言語のmacOSインストーラーが、既にシステムにGoがインストールされている場合に、その既存のインストールを適切に処理できないという問題がありました。具体的には、以前のバージョンが`/usr/local/go`に存在する場合、インストーラーがそれを上書きするのではなく、競合を引き起こしたり、ユーザーが手動で削除する必要があったりする可能性がありました。

コミットメッセージにある「Fixes #4293」は、この問題がGoのイシュートラッカーで報告されていたことを示唆しています。既存のインストールを検出して削除する機能を追加することで、ユーザーエクスペリエンスが向上し、Goのアップグレードプロセスがよりスムーズになることが期待されます。これにより、ユーザーは古いGoのバージョンをアンインストールする手間を省き、インストーラーが自動的にクリーンな状態を準備できるようになります。

## 前提知識の解説

このコミットを理解するためには、macOSのインストーラーパッケージ（`.pkg`ファイル）の構造と、その中で使用されるスクリプトの役割について理解しておく必要があります。

### macOSインストーラーパッケージ（.pkg）

macOSのインストーラーパッケージは、アプリケーションやシステムコンポーネントをインストールするための標準的な形式です。これらは通常、GUIベースのインストーラーアプリケーションによって実行されます。`.pkg`ファイルは、実際には複数のファイルやディレクトリを含むバンドルであり、その中にはインストールされるペイロード（実際のファイル）と、インストールプロセスを制御するためのスクリプトが含まれています。

### `Distribution`ファイル

`Distribution`ファイルは、macOSインストーラーパッケージの重要なXMLファイルです。このファイルは、インストーラーの動作、表示されるUI、インストール条件、および実行されるスクリプトのロジックを定義します。JavaScriptコードを埋め込むことができ、これによりインストールの前後にカスタムロジックを実行したり、ユーザーにメッセージを表示したり、特定の条件に基づいてインストールを許可または拒否したりすることができます。

このコミットでは、`Distribution`ファイル内の`installCheck()`関数が変更されています。この関数は、インストールの続行を許可する前に、特定の条件をチェックするためにインストーラーによって呼び出されます。

### `preinstall`スクリプト

`preinstall`スクリプトは、macOSインストーラーパッケージ内で定義される特別なシェルスクリプトです。このスクリプトは、インストーラーがペイロード（実際のアプリケーションファイル）をターゲットシステムにコピーする**前**に実行されます。

`preinstall`スクリプトの主な目的は以下の通りです。
*   **前提条件の確認**: システムがインストール要件を満たしているかを確認します。
*   **クリーンアップ/削除**: 以前のバージョンや競合するファイルを削除して、クリーンなインストール環境を準備します。
*   **システム準備**: インストールに必要なディレクトリの作成やパーミッションの変更など、システムレベルの調整を行います。

このスクリプトは通常、root権限で実行されるため、システム全体に影響を与える操作を実行できます。スクリプトが正常に終了するには、終了コード`0`を返す必要があります。非ゼロの終了コードは、インストールの失敗を意味します。

このコミットでは、`preinstall`スクリプトが新規に作成され、既存のGoインストールを削除する役割を担っています。

## 技術的詳細

このコミットは、Go言語のmacOSインストーラーが以前のGoインストールを検出して削除するための2つの主要な変更を導入しています。

1.  **`misc/dist/darwin/Distribution`ファイルの変更**:
    *   このファイルは、macOSインストーラーの動作を定義するXMLベースのファイルであり、JavaScriptコードを埋め込むことができます。
    *   `installCheck()`というJavaScript関数が修正されました。この関数は、インストールの続行を許可する前にインストーラーによって呼び出されます。
    *   変更後、`installCheck()`はまず、`/usr/local/go/bin/go`というパスにGoの実行ファイルが存在するかどうかを`system.files.fileExistsAtPath()`関数を使ってチェックします。
    *   もしファイルが存在する場合、つまり以前のGoインストールが検出された場合、インストーラーはユーザーに警告メッセージを表示します。この警告は、`my.result.title`、`my.result.message`、`my.result.type`プロパティを設定することで行われます。
        *   `my.result.title`は「Previous Installation Detected」となります。
        *   `my.result.message`は「A previous installation of Go exists at /usr/local/go. This installer will remove the previous installation prior to installing. Please back up any data before proceeding.」となり、以前のインストールが削除されることと、続行する前にデータをバックアップするよう促します。
        *   `my.result.type`は「Warning」となり、警告として表示されます。
    *   この警告が表示された場合、`installCheck()`は`false`を返します。これにより、インストーラーはすぐにインストールを続行せず、ユーザーに警告を確認させ、続行するかキャンセルするかを選択させます。ユーザーが続行を選択した場合にのみ、インストールプロセスが進行します。

2.  **`misc/dist/darwin/scripts/preinstall`スクリプトの新規作成**:
    *   このファイルは、インストーラーが実際のファイルをインストールする前に実行されるシェルスクリプトです。
    *   スクリプトはBashスクリプトとして記述されており、`#!/bin/bash`で始まります。
    *   `GOROOT`変数を`/usr/local/go`に設定します。これはGoの標準的なインストールパスです。
    *   `echo "Removing previous installation"`というメッセージを出力し、削除処理が開始されることを示します。
    *   `if [ -d $GOROOT ]; then rm -r $GOROOT; fi`という条件文が含まれています。
        *   `[ -d $GOROOT ]`は、`$GOROOT`で指定されたパスがディレクトリとして存在するかどうかをチェックします。
        *   もしディレクトリが存在する場合、`rm -r $GOROOT`コマンドが実行され、`/usr/local/go`ディレクトリとその内容が再帰的に削除されます。これにより、以前のGoインストールが完全に削除され、新しいインストールがクリーンな環境で行われることが保証されます。

これらの変更により、GoのmacOSインストーラーは、既存のインストールをインテリジェントに検出し、ユーザーに警告し、ユーザーの同意を得てから、新しいバージョンをインストールする前に古いバージョンを自動的に削除するようになります。

## コアとなるコードの解説

### `misc/dist/darwin/Distribution` の変更点

このファイルは、macOSインストーラーの動作を制御するXMLとJavaScriptの組み合わせです。変更は`installCheck()` JavaScript関数内で行われています。

```javascript
 function installCheck() {
         // ... 既存のコード ...
         my.result.type = 'Fatal';
         return false;
     }
-    return true; // 変更前: 無条件にtrueを返していた
+    // 変更後: 以前のGoインストールを検出するロジックを追加
+    if(system.files.fileExistsAtPath('/usr/local/go/bin/go')) {
+	    my.result.title = 'Previous Installation Detected'; // 警告のタイトルを設定
+	    my.result.message = 'A previous installation of Go exists at /usr/local/go. This installer will remove the previous installation prior to installing. Please back up any data before proceeding.'; // 警告メッセージを設定
+	    my.result.type = 'Warning'; // 警告の種類を「Warning」に設定
+	    return false; // インストールを一時停止し、ユーザーに警告を表示させる
+	}
+    return true; // 以前のインストールがなければ、インストールを続行
 }
```

*   **`if(system.files.fileExistsAtPath('/usr/local/go/bin/go'))`**:
    *   `system.files.fileExistsAtPath()`は、指定されたパスにファイルまたはディレクトリが存在するかどうかをチェックするインストーラーの組み込みJavaScript関数です。
    *   ここでは、Goの実行ファイルが通常インストールされるパスである`/usr/local/go/bin/go`が存在するかどうかを確認しています。これにより、システムにGoの以前のインストールがあるかどうかを判断します。
*   **`my.result.title = 'Previous Installation Detected';`**:
    *   インストーラーのUIに表示される警告ダイアログのタイトルを設定します。
*   **`my.result.message = 'A previous installation of Go exists at /usr/local/go. This installer will remove the previous installation prior to installing. Please back up any data before proceeding.';`**:
    *   インストーラーのUIに表示される警告ダイアログの本文メッセージを設定します。ユーザーに、以前のインストールが削除されることと、続行する前にデータをバックアップするよう促しています。
*   **`my.result.type = 'Warning';`**:
    *   表示されるメッセージの種類を「Warning」（警告）に設定します。これにより、インストーラーは警告アイコンと共にメッセージを表示します。
*   **`return false;`**:
    *   この行が実行されると、`installCheck()`関数は`false`を返します。これはインストーラーに対して、すぐにインストールを続行するのではなく、ユーザーに設定された警告メッセージを表示し、ユーザーが「続行」または「キャンセル」を選択するのを待つように指示します。ユーザーが「続行」を選択した場合にのみ、インストールプロセスが進行します。

### `misc/dist/darwin/scripts/preinstall` の新規作成

このファイルは、インストーラーが実際のファイルをコピーする前に実行される新しいシェルスクリプトです。

```bash
#!/bin/bash

GOROOT=/usr/local/go

echo "Removing previous installation"
if [ -d $GOROOT ]; then
	rm -r $GOROOT
fi
```

*   **`#!/bin/bash`**:
    *   この行は「シバン」と呼ばれ、このスクリプトがBashシェルで実行されることを指定します。
*   **`GOROOT=/usr/local/go`**:
    *   `GOROOT`という環境変数を定義し、Goの標準的なインストールディレクトリである`/usr/local/go`に設定しています。
*   **`echo "Removing previous installation"`**:
    *   スクリプトが実行されていることを示すために、コンソールにメッセージを出力します。
*   **`if [ -d $GOROOT ]; then`**:
    *   `[ -d $GOROOT ]`は条件式です。` -d`は、指定されたパス（ここでは`$GOROOT`の値）がディレクトリとして存在するかどうかをチェックします。
    *   もし`/usr/local/go`ディレクトリが存在すれば、`then`以下のコマンドが実行されます。
*   **`rm -r $GOROOT`**:
    *   `rm`コマンドはファイルを削除するために使用されます。
    *   `-r`オプションは「recursive」（再帰的）を意味し、ディレクトリとその中のすべてのファイルおよびサブディレクトリを削除します。
    *   したがって、このコマンドは`/usr/local/go`ディレクトリとその内容をすべて削除します。
*   **`fi`**:
    *   `if`文の終わりを示します。

これらの変更を組み合わせることで、インストーラーはまず既存のGoインストールを検出し、ユーザーに警告します。ユーザーが続行を選択すると、`preinstall`スクリプトが実行され、古いGoインストールが削除されてから、新しいGoバージョンがクリーンな状態でインストールされるようになります。
