## 変更の背景

Go言語の標準ライブラリは、その使いやすさと堅牢性で知られています。しかし、APIリファレンスだけでは、特定のパッケージをどのように使用すれば良いか、特に初心者にとっては直感的に理解しにくい場合があります。`encoding/csv` パッケージはCSV（Comma Separated Values）形式のデータを読み書きするための重要なツールですが、その利用方法を具体的に示すコード例が不足していました。

このコミットの背景には、ユーザーが `encoding/csv` パッケージをより簡単に、かつ正確に利用できるようにするという目的があります。Goのドキュメンテーションシステムは、`Example` 関数として定義されたコードを自動的に抽出し、パッケージのドキュメントに表示する機能を持っています。これにより、開発者は実際のコードスニペットを通じて、関数の使い方や期待される出力を一目で確認できるようになります。このコミットは、このGoのドキュメンテーションのベストプラクティスに則り、`encoding/csv` パッケージの利便性を向上させるために行われました。

## 前提知識の解説

### CSV (Comma Separated Values)
CSVは、データをカンマで区切って並べたテキストファイル形式です。表形式のデータを保存する際によく用いられ、異なるアプリケーション間でのデータ交換に広く利用されています。各行がレコードを表し、各レコード内の値がフィールドを表します。フィールドは通常カンマで区切られますが、セミコロンやタブなどの他の区切り文字が使用されることもあります。フィールド内にカンマや改行が含まれる場合は、通常ダブルクォーテーションで囲まれます。

### Go言語の `encoding/csv` パッケージ
Go言語の標準ライブラリ `encoding/csv` は、CSV形式のデータを読み書きするための機能を提供します。
*   **`csv.Reader`**: CSVデータを読み込むための構造体です。入力ソース（`io.Reader` インターフェースを満たすもの、例: `os.File`, `strings.Reader`）からCSVデータを解析し、レコード（文字列のスライス）として返します。区切り文字 (`Comma`) やコメント文字 (`Comment`) などのオプションを設定できます。
*   **`csv.Writer`**: CSVデータを書き込むための構造体です。出力先（`io.Writer` インターフェースを満たすもの、例: `os.Stdout`, `bytes.Buffer`）にCSV形式でデータを書き込みます。
*   **`Example` 関数**: Goのテストファイル (`_test.go`) 内に `ExampleXxx` という命名規則で定義された関数は、Goのドキュメンテーションツールによって特別な意味を持ちます。これらの関数はテストとして実行されるだけでなく、その出力が期待される出力 (`// Output:`) と一致するかどうかも検証されます。そして、`pkg.go.dev` などのドキュメントサイトで、そのパッケージの具体的な使用例として表示されます。これにより、ユーザーはコードの動作を視覚的に理解しやすくなります。

### `io.EOF`
`io.EOF` は、`io` パッケージで定義されているエラー変数で、入力の終わりに達したことを示します。`csv.Reader` の `Read()` メソッドがこれと等しいエラーを返した場合、それ以上読み込むデータがないことを意味します。

## 技術的詳細

このコミットは、`src/encoding/csv/example_test.go` という新しいファイルを追加することで、`encoding/csv` パッケージの利用例を提供しています。追加された例は以下の通りです。

1.  **`ExampleReader()`**:
    *   基本的な `csv.Reader` の使い方を示します。
    *   `strings.NewReader` を使ってインメモリの文字列からCSVデータを読み込みます。
    *   `r.Read()` をループで呼び出し、1行ずつレコードを読み込み、`fmt.Println` で出力します。
    *   `io.EOF` エラーをチェックして、入力の終わりに達したときにループを終了します。
    *   期待される出力 (`// Output:`) も記述されており、実行結果が明確に示されています。

2.  **`ExampleReader_options()`**:
    *   `csv.Reader` の設定オプションの使用方法を示します。
    *   `r.Comma = ';'` で区切り文字をセミコロンに変更しています。
    *   `r.Comment = '#'` で `#` で始まる行をコメント行として無視するように設定しています。
    *   `r.ReadAll()` を使用して、すべてのレコードを一度に読み込みます。
    *   この例は、非標準的なCSV形式（例: セミコロン区切り、コメント行を含む）を扱う際に `csv.Reader` をいかに柔軟に設定できるかを示しています。

3.  **`ExampleReader_ReadAll()`**:
    *   `csv.Reader` の `ReadAll()` メソッドの基本的な使い方を示します。
    *   `ExampleReader()` と同様にインメモリの文字列からCSVデータを読み込みますが、`ReadAll()` を使用することで、すべてのレコードを `[][]string` 型のスライスとして一度に取得します。
    *   これは、比較的小さなCSVファイルを一度に処理する場合に便利です。

4.  **`ExampleWriter()`**:
    *   基本的な `csv.Writer` の使い方を示します。
    *   `csv.NewWriter(os.Stdout)` を使って標準出力にCSVデータを書き込みます。
    *   `w.Write(record)` をループで呼び出し、1レコードずつ書き込みます。
    *   `w.Flush()` を呼び出して、バッファリングされたデータを強制的に出力先に書き出します。
    *   `w.Error()` をチェックして、書き込み中に発生したエラーを確認します。

5.  **`ExampleWriter_WriteAll()`**:
    *   `csv.Writer` の `WriteAll()` メソッドの基本的な使い方を示します。
    *   `WriteAll()` は `[][]string` 型のスライスを受け取り、すべてのレコードを一度に書き込みます。
    *   `WriteAll()` は内部で `Flush()` を呼び出すため、明示的な `Flush()` の呼び出しは不要です。
    *   `w.Error()` をチェックして、書き込み中に発生したエラーを確認します。

これらの例は、`encoding/csv` パッケージの主要な機能である読み込みと書き込みの両方をカバーしており、異なるシナリオ（行ごとの処理、一括処理、カスタムオプション）に対応しています。

## コアとなるコードの変更箇所

追加されたファイルは `src/encoding/csv/example_test.go` です。このファイル全体が新規追加されており、以下の内容を含みます。

```go
// Copyright 2015 The Go Authors. All rights reserved.
// Use of this source code is governed by a BSD-style
// license that can be found in the LICENSE file.

package csv_test

import (
	"encoding/csv"
	"fmt"
	"io"
	"log"
	"os"
	"strings"
)

func ExampleReader() {
	in := `first_name,last_name,username
"Rob","Pike",rob
Ken,Thompson,ken
"Robert","Griesemer","gri"
`
	r := csv.NewReader(strings.NewReader(in))

	for {
		record, err := r.Read()
		if err == io.EOF {
			break
		}
		if err != nil {
			log.Fatal(err)
		}

		fmt.Println(record)
	}
	// Output:
	// [first_name last_name username]
	// [Rob Pike rob]
	// [Ken Thompson ken]
	// [Robert Griesemer gri]
}

// This example shows how csv.Reader can be configured to handle other
// types of CSV files.
func ExampleReader_options() {
	in := `first_name;last_name;username
"Rob";"Pike";rob
# lines beginning with a # character are ignored
Ken;Thompson;ken
"Robert";"Griesemer";"gri"
`
	r := csv.NewReader(strings.NewReader(in))
	r.Comma = ';'
	r.Comment = '#'

	records, err := r.ReadAll()
	if err != nil {
		log.Fatal(err)
	}

	fmt.Print(records)
	// Output:
	// [[first_name last_name username] [Rob Pike rob] [Ken Thompson ken] [Robert Griesemer gri]]
}

func ExampleReader_ReadAll() {
	in := `first_name,last_name,username
"Rob","Pike",rob
Ken,Thompson,ken
"Robert","Griesemer","gri"
`
	r := csv.NewReader(strings.NewReader(in))

	records, err := r.ReadAll()
	if err != nil {
		log.Fatal(err)
	}

	fmt.Print(records)
	// Output:
	// [[first_name last_name username] [Rob Pike rob] [Ken Thompson ken] [Robert Griesemer gri]]
}

func ExampleWriter() {
	records := [][]string{
		{"first_name", "last_name", "username"},
		{"Rob", "Pike", "rob"},
		{"Ken", "Thompson", "ken"},
		{"Robert", "Griesemer", "gri"},
	}

	w := csv.NewWriter(os.Stdout)

	for _, record := range records {
		if err := w.Write(record); err != nil {
			log.Fatalln("error writing record to csv:", err)
		}
	}

	// Write any buffered data to the underlying writer (standard output).
	w.Flush()

	if err := w.Error(); err != nil {
		log.Fatal(err)
	}
	// Output:
	// first_name,last_name,username
	// Rob,Pike,rob
	// Ken,Thompson,ken
	// Robert,Griesemer,gri
}

func ExampleWriter_WriteAll() {
	records := [][]string{
		{"first_name", "last_name", "username"},
		{"Rob", "Pike", "rob"},
		{"Ken", "Thompson", "ken"},
		{"Robert", "Griesemer", "gri"},
	}

	w := csv.NewWriter(os.Stdout)
	w.WriteAll(records) // calls Flush internally

	if err := w.Error(); err != nil {
		log.Fatalln("error writing csv:", err)
	}
	// Output:
	// first_name,last_name,username
	// Rob,Pike,rob
	// Ken,Thompson,ken
	// Robert,Griesemer,gri
}
```

## コアとなるコードの解説

このコミットで追加されたコードは、`encoding/csv` パッケージの主要なAPIである `Reader` と `Writer` の具体的な使用例を網羅しています。

*   **`package csv_test`**: このファイルが `csv` パッケージのテストパッケージであることを示します。`_test` サフィックスは、テストコードがメインパッケージとは別のパッケージとしてコンパイルされることを意味し、テスト対象のパッケージの内部実装に依存しない形でテストや例を書くことを可能にします。
*   **`import` 文**: `encoding/csv` パッケージ自体はもちろんのこと、入力ソースとして `strings` (インメモリ文字列用)、出力先として `os` (標準出力用)、エラーハンドリングに `log`、そして一般的なI/O操作に `io` と `fmt` がインポートされています。
*   **`ExampleReader()`**:
    *   `in` 変数に複数行のCSVデータをバッククォート文字列リテラルで定義しています。これにより、改行を含む文字列を簡単に表現できます。
    *   `strings.NewReader(in)` は、この文字列を `io.Reader` インターフェースを満たすオブジェクトに変換し、`csv.NewReader` に渡せるようにします。
    *   `for` ループ内で `r.Read()` を呼び出すことで、CSVデータを1レコードずつ読み込みます。`Read()` は `[]string` 型のレコードと `error` を返します。
    *   `if err == io.EOF` は、ファイル（または入力ストリーム）の終わりに達したことを検出し、ループを終了します。これは、ストリームからの読み込み処理における標準的なパターンです。
    *   `if err != nil` は、`io.EOF` 以外のエラーが発生した場合に `log.Fatal(err)` を呼び出してプログラムを終了させます。これは、例がシンプルであるため、より詳細なエラーハンドリングを省略している典型的なパターンです。
    *   `fmt.Println(record)` は、読み込んだレコード（文字列のスライス）を標準出力に出力します。
    *   `// Output:` コメントは、この `Example` 関数を実行した際に期待される標準出力の内容を示します。Goのテストツールは、このコメントと実際の出力を比較し、一致しない場合はテスト失敗とします。
*   **`ExampleReader_options()`**:
    *   この例では、CSVデータがセミコロン区切りであり、`#` で始まる行がコメントであることを想定しています。
    *   `r.Comma = ';'` と `r.Comment = '#'` を設定することで、`csv.Reader` のデフォルトの挙動を上書きし、非標準的なCSV形式に対応させています。
    *   `r.ReadAll()` は、残りのすべてのレコードを一度に読み込み、`[][]string` 型のスライスとして返します。これは、ファイル全体をメモリに読み込んで処理する場合に便利です。
*   **`ExampleWriter()`**:
    *   `records` 変数に書き込むCSVデータを `[][]string` 型のスライスとして定義しています。
    *   `csv.NewWriter(os.Stdout)` は、標準出力に書き込む `csv.Writer` を作成します。
    *   `for` ループ内で `w.Write(record)` を呼び出すことで、1レコードずつCSV形式で標準出力に書き込みます。
    *   `w.Flush()` は、`csv.Writer` の内部バッファに溜まっているデータを強制的に基になる `io.Writer` (この場合は `os.Stdout`) に書き出します。`Write` メソッドは必ずしも即座に書き込みを行うわけではないため、処理の最後に `Flush` を呼び出すことが重要です。
    *   `w.Error()` は、`Flush` や `Write` の実行中に発生したエラーを返します。
*   **`ExampleWriter_WriteAll()`**:
    *   `w.WriteAll(records)` は、`records` スライス内のすべてのデータを一度にCSV形式で書き込みます。
    *   このメソッドは内部で `Flush()` を呼び出すため、明示的に `w.Flush()` を呼び出す必要はありません。

これらの例は、`encoding/csv` パッケージのAPIを効果的に利用するための明確で実行可能なガイドラインを提供し、Goのドキュメンテーションの品質向上に貢献しています。
