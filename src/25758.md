# [インデックス 25758] ファイルの概要

## コミット

このコミットは、Goプロジェクトのビルドシステムの一部である `src/cmd/dist/mkdeps.bash` スクリプトを、macOS (OS X) 環境でより広範なBashバージョンに対応させるために書き換えるものです。具体的には、古いBashバージョンでサポートされていない `declare -A` (連想配列) の使用を排除し、代わりに標準的なシェルコマンドと `awk` を組み合わせて同等の機能を実現しています。

## 変更の背景

この変更の主な背景は、Go開発環境におけるクロスプラットフォーム互換性の問題です。コミットメッセージに「My version of bash doesn't know what 'declare -A' means.」と明記されている通り、コミットの作者であるRuss Cox氏の環境（おそらくmacOS）で利用されていたBashのバージョンが、連想配列を宣言するための `declare -A` コマンドをサポートしていなかったことが原因です。

当時、macOSはデフォルトでBash 3.2を搭載しており、これは2007年にリリースされたバージョンでした。`declare -A` はBash 4.0で導入された機能であるため、macOSのデフォルトBashでは利用できませんでした。Goプロジェクトは様々なプラットフォームでビルドされる必要があり、ビルドスクリプトが特定のBashバージョンに依存することは、開発者やCI/CD環境での問題を引き起こします。このコミットは、このような環境差異によるビルドエラーを解消し、より幅広い環境でGoのビルドシステムが機能するようにするための対応でした。

## 前提知識の解説

### `mkdeps.bash` スクリプトの役割

`mkdeps.bash` は、Goプロジェクトの `cmd/dist` ディレクトリに存在するシェルスクリプトで、Goのビルドプロセスにおいて重要な役割を担っています。このスクリプトの主な目的は、Goの標準ライブラリやツールチェーン内のパッケージ間の依存関係を抽出し、それをGoのソースコード (`deps.go`) として生成することです。

Goのビルドシステムは、どのパッケージがどのパッケージに依存しているかを知る必要があります。`mkdeps.bash` は `go list` コマンドを利用してこの情報を収集し、`deps.go` というファイルに `map[string][]string` の形式で依存関係マップを書き出します。この `deps.go` ファイルは、Goのビルドツール自体が依存関係を解決するために利用されます。

### `declare -A` と Bash の連想配列

`declare -A` は、Bashシェルにおいて連想配列（associative array）を宣言するためのコマンドです。連想配列は、数値インデックスではなく、文字列をキーとして値にアクセスできるデータ構造です。他のプログラミング言語におけるハッシュマップ、辞書、またはオブジェクトに相当します。

**例:**
```bash
declare -A my_array
my_array["key1"]="value1"
my_array["key2"]="value2"
echo ${my_array["key1"]} # 出力: value1
```

この機能はBash 4.0で導入されました。それ以前のBashバージョン（特にmacOSで長らくデフォルトだったBash 3.2など）では `declare -A` は認識されず、スクリプトの実行時にエラーとなります。

### Goのビルド環境変数 `GOOS` と `GOARCH`

Goのビルドシステムは、ターゲットとするオペレーティングシステム (`GOOS`) とアーキテクチャ (`GOARCH`) を指定するための環境変数を使用します。`mkdeps.bash` スクリプトは、これらの環境変数を様々に組み合わせて `go list` コマンドを実行することで、異なるプラットフォーム向けの依存関係を網羅的に収集します。これにより、クロスコンパイルの際に必要なすべての依存関係が `deps.go` に含まれることが保証されます。

### `go list` コマンド

`go list` は、Goパッケージに関する情報を表示するためのコマンドです。このスクリプトでは、特に以下のオプションが使用されています。

*   `-tags cmd_go_bootstrap`: ビルドタグ `cmd_go_bootstrap` が指定された場合にのみビルドされるコードを含めて情報を取得します。これはGoのブートストラッププロセス（Goコンパイラ自体をビルドするプロセス）に関連する特別なタグです。
*   `-f '{{join .Deps "\\n"}}'`: 出力フォーマットを指定します。`.Deps` はパッケージが直接依存するパッケージのインポートパスのリストです。`join .Deps "\\n"` は、これらの依存パスを改行で結合して出力します。
*   `-f '{{range .Deps}}{{if not (eq . "unsafe")}}{{print .}} {{end}}{{end}}'`: 各依存パッケージについて、それが `unsafe` パッケージでなければそのインポートパスを出力します。`unsafe` パッケージは特殊な性質を持つため、依存関係リストから除外されることがあります。
*   `-f '{{range .Deps}}{{$.ImportPath}} {{.}}\n{{end}}'`: これは変更後のスクリプトで使われているフォーマットで、現在のパッケージのインポートパス (`$.ImportPath`) とその依存パッケージのインポートパス (`.`) をスペース区切りで出力し、各依存ペアを改行で区切ります。これにより、「親パッケージ 子パッケージ」の形式で依存関係のペアが得られます。

## 技術的詳細

このコミットの技術的な核心は、Bashの連想配列 (`declare -A`) を使用せずに、同等の依存関係マッピング機能を実現する点にあります。

**変更前のアプローチ:**
変更前のスクリプトでは、`declare -A alldeps` で連想配列を宣言し、`alldeps[$dep]="..."` のようにして、各パッケージ (`$dep`) の依存関係をその連想配列の要素として直接格納していました。これはメモリ上で効率的に依存関係を管理できる方法ですが、Bashのバージョン互換性の問題がありました。

**変更後のアプローチ:**
新しいアプローチでは、以下のステップで連想配列の機能をエミュレートしています。

1.  **`deps_of` 関数の導入:**
    `deps_of` というシェル関数が導入されました。この関数は、引数として与えられたGoパッケージのリストについて、様々な `GOOS`/`GOARCH` の組み合わせで `go list` を実行し、そのパッケージが依存するすべてのパッケージを抽出します。
    出力形式は `'{{$.ImportPath}} {{.}}\n'` で、これは「親パッケージ 子パッケージ」という形式のペアを生成します。
    `| sort -u | grep . | grep -v ' unsafe$'` により、重複を排除し、空行や `unsafe` パッケージへの依存を除外します。

2.  **中間ファイル `tmp.all.deps` の生成:**
    まず、`cmd/go` パッケージとその直接的・間接的なすべての依存パッケージのリストを `all` 変数に格納します。
    次に、`deps_of $all >tmp.all.deps` コマンドを実行し、`all` に含まれるすべてのパッケージについて、その依存関係のペアを `tmp.all.deps` という一時ファイルに書き出します。このファイルは、`親パッケージ 子パッケージ` の形式の行が多数含まれるテキストファイルとなります。

3.  **`awk` を用いた依存関係の抽出と `deps.go` の生成:**
    `deps.go` ファイルを生成するループ内で、各パッケージ (`pkg`) について、`tmp.all.deps` ファイルからそのパッケージの依存関係を抽出するために `awk` コマンドが使用されます。
    `awk -v pkg=$pkg '$1==pkg {print $2}' tmp.all.deps`
    この `awk` コマンドは、`tmp.all.deps` の各行を読み込み、最初のフィールド (`$1`、つまり親パッケージ) が現在の `$pkg` と一致する場合に、2番目のフィールド (`$2`、つまり子パッケージ) を出力します。これにより、連想配列のキー検索と値の取得に相当する処理が、ファイル操作とテキスト処理によって実現されます。

4.  **一時ファイルのクリーンアップ:**
    スクリプトの最後に `rm -f tmp.all.deps` が追加され、生成された一時ファイルが適切に削除されます。

この変更により、スクリプトはBashの特定のバージョンに依存することなく、標準的なUnixコマンド (`awk`, `sort`, `grep`) の組み合わせで機能するようになり、macOSを含むより多くの環境での互換性が確保されました。

## コアとなるコードの解説

### 変更前のコード (`-` で始まる行)

*   `declare -A alldeps`: 連想配列 `alldeps` を宣言しています。これがmacOSの古いBashバージョンで問題となる箇所でした。
*   `for goos in $gooslist; do ... done`: 複数の `GOOS`/`GOARCH` の組み合わせでループし、`go list` を実行して依存関係を収集しています。
*   `alldeps[$dep]="..."`: 収集した依存関係を `alldeps` 連想配列に格納しています。キーはパッケージ名、値はそのパッケージの依存リストです。
*   `for dep in $(for dep in ${!alldeps[@]}; do echo $dep; done | grep -v '^cmd/go$' | sort) cmd/go; do ... done`: `alldeps` 連想配列のすべてのキー（パッケージ名）を取得し、ソートしてループしています。
*   `for subdep in ${alldeps[$dep]}; do ... done`: 各パッケージの依存リストを `alldeps` から取得し、`deps.go` ファイルに書き出しています。

### 変更後のコード (`+` で始まる行)

*   `echo NOTE: errors about loading internal/syscall/windows are ok`: Windows固有のシステムコールに関するエラーは無視できる旨の注意書きが追加されました。
*   `deps_of() { ... }`: 新しく導入されたシェル関数です。
    *   この関数は、`gooslist` と `goarchlist` のすべての組み合わせでループします。
    *   `GOOS=$goos GOARCH=$goarch go list -tags cmd_go_bootstrap -f '{{range .Deps}}{{$.ImportPath}} {{.}}\n{{end}}' $*`: 引数として渡されたパッケージについて `go list` を実行し、「親パッケージ 子パッケージ」の形式で依存関係のペアを出力します。
    *   `| sort -u | grep . | grep -v ' unsafe$'`: 出力をパイプで渡し、重複行を削除し (`sort -u`)、空行を除外し (`grep .`)、`unsafe` パッケージへの依存を除外します (`grep -v ' unsafe$'`)。
*   `all="$(deps_of cmd/go | awk '{print $2}') cmd/go"`: `cmd/go` パッケージのすべての依存関係（直接的および間接的）を `deps_of` 関数で取得し、`awk` で子パッケージのみを抽出し、さらに `cmd/go` 自体を追加して `all` 変数に格納します。これは、`deps.go` に含める必要のあるすべてのパッケージのリストになります。
*   `deps_of $all >tmp.all.deps`: `all` に含まれるすべてのパッケージについて `deps_of` 関数を実行し、その結果（すべての依存関係ペア）を `tmp.all.deps` という一時ファイルにリダイレクトして保存します。
*   `for pkg in $all; do ... done`: `all` 変数に格納された各パッケージについてループします。
*   `echo -n "\"$pkg\": {"`: `deps.go` ファイルに、現在のパッケージ名とマップの開始ブレースを書き込みます。
*   `for dep in $(awk -v pkg=$pkg '$1==pkg {print $2}' tmp.all.deps); do ... done`: ここが連想配列をエミュレートする核心部分です。
    *   `awk -v pkg=$pkg '$1==pkg {print $2}' tmp.all.deps`: `tmp.all.deps` ファイルを読み込み、最初のフィールド（親パッケージ）が現在の `$pkg` と一致する行を見つけ、その行の2番目のフィールド（子パッケージ）を出力します。これにより、`$pkg` のすべての依存パッケージが抽出されます。
    *   抽出された各依存パッケージ (`dep`) は、`deps.go` ファイルに `"\"$dep\","` の形式で書き込まれます。
*   `echo '},'`: 各パッケージの依存リストの終わりにブレースとカンマを書き込みます。
*   `rm -f tmp.all.deps`: スクリプトの最後に、生成された一時ファイル `tmp.all.deps` を削除します。

この変更により、Bashの連想配列に依存しない、より移植性の高いスクリプトが実現されました。
