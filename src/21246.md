# [インデックス 21246] ファイルの概要

このコミットは、Go言語のドキュメントファイル内の`code.google.com`への参照を`golang.org`や`github.com`への参照に更新するものです。具体的には、以下の7つのファイルが変更されています。

- `doc/code.html`
- `doc/contrib.html`
- `doc/devel/release.html`
- `doc/devel/weekly.html`
- `doc/go1.3.html`
- `doc/go_faq.html`
- `doc/help.html`

これらのファイルでは、Go Wiki、Go issue tracker、ソースコード、godocのリンクなどが更新されています。

## 元コミット内容

`[release-branch.go1.4] doc: scrub references to code.google.com`

このコミットは、Go 1.4リリースブランチにおいて、ドキュメント内の`code.google.com`への参照を削除（scrub）することを目的としています。現在のGoユーザーに影響を与える参照が対象であり、古いリリースノート内の参照はそのまま残されています。

## 変更の背景

この変更の背景には、Googleが提供していたオープンソースプロジェクトホスティングサービスである**Google Codeの閉鎖**があります。Google Codeは2015年3月に新規プロジェクトの作成を停止し、2016年1月には完全にシャットダウンされました。

Go言語のプロジェクトは、その初期からGoogle Code上でホストされており、ソースコード管理（Mercurial）、課題追跡（Issue Tracker）、Wikiなどが`code.google.com/p/go`以下で運用されていました。Google Codeの閉鎖に伴い、Goプロジェクトは公式にGitHub（`github.com/golang/go`）と`golang.org`ドメインに移行する必要がありました。

このコミットは、Go 1.4のリリースに向けて、ドキュメント内の古いリンクを新しい公式な場所へ更新し、ユーザーが正しい情報源にアクセスできるようにするための重要な作業の一環です。

## 前提知識の解説

### Google Code

Google Codeは、Googleが提供していた無料のオープンソースプロジェクトホスティングサービスです。バージョン管理システムとしてSubversion、Git、Mercurialをサポートし、課題追跡システム、Wiki、ダウンロード機能などを提供していました。多くのオープンソースプロジェクトが利用していましたが、GitHubなどの新しいプラットフォームの台頭や、Googleの戦略変更により、2015年に閉鎖が発表されました。

### Go言語のプロジェクト管理

Go言語はGoogleによって開発されたプログラミング言語であり、そのプロジェクト管理も初期はGoogle Code上で行われていました。具体的には、ソースコードはMercurialリポジトリとして`code.google.com/p/go`に、課題はIssue Trackerとして同じドメインに存在していました。

### `golang.org`と`github.com/golang`

Google Codeの閉鎖に伴い、Goプロジェクトは公式なウェブサイトとして`golang.org`を、そして主要なソースコードリポジトリと課題追跡システムとしてGitHubの`github.com/golang`組織を利用するようになりました。これにより、Go言語に関するすべての公式情報と開発活動はこれらの新しいドメインに集約されました。

## 技術的詳細

このコミットの技術的な詳細は、主にドキュメント内のURL文字列の置換にあります。

- **`code.google.com/p/go-wiki/wiki/Projects` → `golang.org/wiki/Projects`**: Go Wikiへのリンクの更新。
- **`code.google.com/p/go/issues/list` → `golang.org/issue`**: Goの課題追跡システムへのリンクの更新。
- **`code.google.com/p/go/issues/entry` → `golang.org/issue/new`**: 新しい課題を報告するためのリンクの更新。
- **`code.google.com/p/go/source` → `golang.org/change`**: ソースコードの変更ログへのリンクの更新。
- **`code.google.com/p/go.tools/cmd/godoc` → `golang.org/x/tools/cmd/godoc`**: `godoc`ツールのドキュメントリンクの更新。これは、`go.tools`リポジトリが`golang.org/x/tools`に移行したことを反映しています。
- **`code.google.com/p/go.tools/cmd/benchcmp` → `golang.org/x/tools/cmd/benchcmp`**: `benchcmp`ツールのドキュメントリンクの更新。
- **`code.google.com/p/vitess`**: このリンクは変更されていませんが、これは`Vitess`プロジェクト自体がGoプロジェクトとは独立してGoogle Codeから移行したため、Goのドキュメント側でリンクを更新する必要がなかったか、あるいはこの時点ではまだ移行先が確定していなかったためと考えられます。ただし、このコミットの意図はGoプロジェクト自身の参照を更新することにあります。
- **`code.google.com/p/go-wiki/wiki` → `golang.org/wiki`**: Go Wikiのトップページへのリンクの更新。
- **`https://github.com/golang/go/issues?q=is%3Aopen+is%3Aissue+label%3Ahelpwanted`**: `HelpWanted`ラベルの付いた課題へのリンクが、Google CodeのIssue TrackerからGitHubのIssue Trackerに直接変更されています。これは、Goプロジェクトの課題管理がGitHubに完全に移行したことを示しています。

これらの変更は、ユーザーがGo言語に関する最新かつ正確な情報にアクセスできるようにするために不可欠でした。

## コアとなるコードの解説

このコミットにおける「コアとなるコード」は、Go言語のドキュメントを構成するHTMLファイル群です。これらのファイルは、Go言語のユーザーがGoプロジェクトの様々なリソース（Wiki、Issue Tracker、ソースコードなど）にアクセスするためのリンクを提供しています。

変更の核心は、これらのHTMLファイル内の`<a>`タグの`href`属性値の更新です。具体的には、`code.google.com`をベースとするURLが、`golang.org`または`github.com/golang/go`をベースとするURLに置換されています。

例えば、`doc/code.html`では、Go Wikiへのリンクが以下のように変更されています。

```diff
--- a/doc/code.html
+++ b/doc/code.html
@@ -578,7 +578,7 @@ import "github.com/golang/example/stringutil"
 <p>
 This convention is the easiest way to make your Go packages available for
 others to use.
-The <a href="//code.google.com/p/go-wiki/wiki/Projects">Go Wiki</a>
+The <a href="//golang.org/wiki/Projects">Go Wiki</a>
 and <a href="//godoc.org/">godoc.org</a>
 provide lists of external Go projects.
 </p>
```

また、課題追跡システムへのリンクは、Google CodeからGitHubへ直接変更されています。

```diff
--- a/doc/contrib.html
+++ b/doc/contrib.html
@@ -101,8 +101,8 @@ To get started, read these <a href="/doc/contribute.html">contribution
 guidelines</a> for information on design, testing, and our code review process.
 </p>
 <p>
-Check <a href="https://code.google.com/p/go/issues">the tracker</a> for 
+Check <a href="//golang.org/issue">the tracker</a> for 
 open issues that interest you. Those labeled
-<a href="https://code.google.com/p/go/issues/list?q=status=HelpWanted">HelpWanted</a>
+<a href="https://github.com/golang/go/issues?q=is%3Aopen+is%3Aissue+label%3Ahelpwanted">helpwanted</a>
 are particularly in need of outside help.
 </p>
```

これらの変更は、単なる文字列置換以上の意味を持ちます。これは、GoプロジェクトのインフラストラクチャがGoogle Codeから新しいプラットフォームへと完全に移行したことをドキュメントレベルで反映するものであり、ユーザーが常に最新かつ正確な情報源に誘導されるようにするための重要なメンテナンス作業です。
