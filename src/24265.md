## 変更の背景

Go 1.5リリースでは、標準ライブラリの`crypto/sha512`パッケージに、SHA-512/224とSHA-512/256という新しいハッシュアルゴリズムのサポートが追加されました。これらの機能は、特定のセキュリティ要件やパフォーマンス要件を持つアプリケーションにとって有用なものでした。このコミットの目的は、これらの重要な機能追加がGo 1.5の公式リリースノートに適切に記載され、Goユーザーが新しい暗号機能の存在を認識し、活用できるようにすることです。ドキュメントの更新は、新機能の採用を促進し、開発者が最新のGoバージョンで利用可能なツールを最大限に活用するために不可欠です。

## 前提知識の解説

*   **Go 1.5**: Go言語の歴史において非常に重要なリリースの一つです。このバージョンでGoコンパイラ自体がGo言語で書かれるようになり（セルフホスティング）、ガベージコレクタのレイテンシが大幅に改善されるなど、多くの重要な変更と改善が導入されました。
*   **SHA-512**: Secure Hash Algorithm 512-bitの略で、NIST（アメリカ国立標準技術研究所）によって開発された暗号学的ハッシュ関数の一種です。入力データから固定長の512ビット（64バイト）のハッシュ値（メッセージダイジェスト）を生成します。データの完全性検証やデジタル署名などに利用されます。
*   **SHA-512/224 および SHA-512/256**: これらはSHA-512の「切り詰めバージョン（truncated versions）」です。SHA-512アルゴリズム自体は512ビットのハッシュ値を生成しますが、SHA-512/224は最初の224ビットを、SHA-512/256は最初の256ビットを最終的なハッシュ値として出力します。これにより、より短いハッシュ値が必要な場合や、特定のプロトコルで要求されるハッシュ長に合わせる場合に利用されます。切り詰めバージョンは、元のSHA-512と同じ内部構造と初期値を使用しますが、出力長が異なります。
*   **`crypto/sha512`パッケージ**: Go言語の標準ライブラリに含まれるパッケージで、SHA-512ハッシュアルゴリズムの実装を提供します。このパッケージを利用することで、Goプログラム内で簡単にSHA-512ハッシュ値を計算できます。

## 技術的詳細

このコミットは、Go 1.5のリリースノートである`doc/go1.5.html`ファイルに対する純粋なドキュメントの変更です。コードの機能的な変更やバグ修正ではなく、既存の機能追加をユーザーに伝えるための情報追加が目的です。

具体的には、`doc/go1.5.html`ファイルの既存のリスト項目（`<li>`タグ）の中に、`crypto/sha512`パッケージがSHA-512/224とSHA-512/256のサポートを追加したことを説明する新しいリスト項目が挿入されています。これにより、Go 1.5のリリースノートを読む開発者は、これらの新しいハッシュ関数が利用可能になったことを容易に発見できるようになります。

HTMLの変更は以下の通りです。

```html
<li>

</li>
```

この変更は、Goのドキュメンテーションプロセスの一部であり、新機能がリリースされる際に、その機能が適切に文書化され、ユーザーがアクセスできる情報源に反映されることを保証します。
