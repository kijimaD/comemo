# [インデックス 26117] ファイルの概要

このコミットは、Go言語の`net`パッケージにおけるWindows環境でのネットワークインターフェーステスト`TestInterfacesWithNetsh`を改善するものです。具体的には、`netsh`コマンドの出力からIPv4とIPv6の両方のインターフェース情報を取得し、それらを統合してテストに含めるように変更されました。また、ネットワークインターフェースの「アップ」または「ダウン」の状態もテスト対象に追加されています。さらに、`netsh`コマンドの出力解析の信頼性を高めるため、OSが英語環境であるかどうかのチェックが導入され、英語以外の環境ではテストがスキップされるようになりました。

## 変更の背景

Go言語の`net`パッケージは、様々なオペレーティングシステム上でネットワークインターフェースに関する情報を提供する役割を担っています。Windows環境において、この情報が正確に取得されているかを検証するために、`netsh`コマンドの出力と比較するテストが実装されていました。しかし、既存のテストでは以下の点が不十分でした。

1.  **IPv4とIPv6の網羅性不足**: ネットワーク環境はIPv4からIPv6への移行が進んでおり、両方のプロトコルスタックが共存するケースが一般的です。しかし、従来のテストではIPv4またはIPv6のいずれか一方の`netsh`出力しか考慮されていなかった可能性があり、両方の設定が正しくGoの`net`パッケージに反映されているかを確認できませんでした。
2.  **インターフェース状態の未検証**: ネットワークインターフェースが「接続済み（up）」か「切断済み（down）」かという状態は、ネットワークアプリケーションの動作に直接影響を与える重要な情報です。しかし、この状態がGoの`net`パッケージによって正しく報告されているかどうかの検証が不足していました。
3.  **`netsh`出力の地域依存性**: `netsh`コマンドの出力は、OSの言語設定によって異なる場合があります。特に、出力される文字列（例：「State : connected」）が英語以外の言語で表示される場合、テストが期待する文字列と一致せず、誤ってテストが失敗する可能性がありました。

これらの問題に対処するため、Issue #13606が提起され、このコミットによってテストの堅牢性と網羅性が向上されました。

## 前提知識の解説

### Go言語の`net`パッケージ

Go言語の標準ライブラリである`net`パッケージは、ネットワークI/Oプリミティブを提供します。これには、TCP/IP、UDP、IP、Unixドメインソケットなどのネットワークプロトコルを扱う機能が含まれます。特に、`net.Interfaces()`関数は、システム上のすべてのネットワークインターフェースのリストとその詳細情報（名前、MACアドレス、IPアドレス、フラグなど）を返します。

### `netsh`コマンド

`netsh`（Network Shell）は、Windowsオペレーティングシステムに搭載されているコマンドラインスクリプトユーティリティです。ローカルまたはリモートのコンピューターのネットワーク構成を表示、変更、診断するために使用されます。ネットワークインターフェース、IPアドレス、ルーティング、ファイアウォールなど、多岐にわたるネットワーク設定を管理できます。このコミットでは、`netsh interface ip show interface`や`netsh interface ipv6 show interface`といったコマンドが使用され、ネットワークインターフェースの詳細情報を取得しています。

### IPv4とIPv6

*   **IPv4 (Internet Protocol version 4)**: 現在広く使用されているインターネットプロトコルのバージョンです。32ビットのアドレス空間を持ち、約43億個のユニークなIPアドレスを割り当てることができます。アドレス枯渇の問題が深刻化しています。
*   **IPv6 (Internet Protocol version 6)**: IPv4の後継として開発されたインターネットプロトコルのバージョンです。128ビットのアドレス空間を持ち、事実上無限のIPアドレスを提供します。IPv4との互換性はありませんが、共存（デュアルスタック）環境が一般的です。

### ネットワークインターフェースの状態 (Up/Down)

ネットワークインターフェースの状態は、そのインターフェースが現在アクティブに使用可能であるか（「Up」または「Connected」）、それとも非アクティブであるか（「Down」または「Disconnected」）を示します。例えば、イーサネットケーブルが接続されているか、Wi-Fiに接続されているか、といった物理的な接続状態や、OSレベルでの有効/無効設定によって決まります。

### Windows APIと`syscall`パッケージ

Go言語の`syscall`パッケージは、低レベルのオペレーティングシステムプリミティブへのアクセスを提供します。Windows環境では、`syscall.NewLazyDLL`と`syscall.NewProc`を使用して、`kernel32.dll`のようなシステムライブラリ内の関数（例: `GetACP`）を呼び出すことができます。
*   **`kernel32.dll`**: Windowsのコアシステムライブラリの一つで、メモリ管理、プロセスとスレッド管理、ファイルI/Oなど、基本的なOS機能を提供します。
*   **`GetACP`**: アクティブなコードページ（Active Code Page）を取得するWindows API関数です。コードページは、特定の言語や地域で使用される文字セットとエンコーディングを定義します。これにより、OSの言語設定を間接的に判断できます。`windows_1252`は、西ヨーロッパ言語（英語を含む）で一般的に使用されるANSIコードページです。

## 技術的詳細

このコミットは、`src/net/net_windows_test.go`ファイルに大幅な変更を加えています。

1.  **`isEnglishOS`関数の追加**:
    *   `modkernel32 = syscall.NewLazyDLL("kernel32.dll")`と`procGetACP = modkernel32.NewProc("GetACP")`を用いて、`kernel32.dll`から`GetACP`関数への参照を取得します。
    *   `isEnglishOS`関数は、`syscall.Syscall(procGetACP.Addr(), 0, 0, 0, 0)`を呼び出して現在のシステムのアクティブなコードページを取得します。
    *   取得したコードページが`windows_1252`（ANSI Latin 1; Western European (Windows)）と一致するかどうかをチェックし、英語OSであるかを判断します。これにより、`netsh`コマンドの出力が英語であることを前提としたテストの安定性を確保します。英語以外のOSでは、`TestInterfacesWithNetsh`などのテストがスキップされるようになります。

2.  **`netshInterfaceIPShowConfig`の廃止と`netshInterfaceIPShowInterface`の導入**:
    *   以前の`netshInterfaceIPShowConfig`関数は削除され、より汎用的な`netshInterfaceIPShowInterface(ipver string, ifaces map[string]bool)`関数が導入されました。
    *   この新しい関数は、引数`ipver`（"ipv4"または"ipv6"）に基づいて`netsh interface <ipver> show interface level=verbose`コマンドを実行します。`level=verbose`オプションにより、より詳細なインターフェース情報（特に「State」）が取得されます。
    *   コマンドの出力は行ごとに解析され、「Interface ... Parameters」で始まる行からインターフェース名を抽出し、「State : connected」または「State : disconnected」の行からインターフェースの状態（`isup`）を判断します。
    *   抽出されたインターフェース名と状態は、引数として渡された`ifaces`マップに格納されます。このマップは、複数の`ipver`からの情報を統合するために使用されます。
    *   もし、同じインターフェースに対してIPv4とIPv6の両方で異なる状態が報告された場合、`fmt.Errorf`でエラーを返し、データの不整合を検出します。

3.  **`TestInterfacesWithNetsh`のロジック変更**:
    *   テストの冒頭で`isWindowsXP(t)`と`isEnglishOS(t)`をチェックし、条件を満たさない場合はテストをスキップします。
    *   Goの`net.Interfaces()`関数を呼び出し、システム上のネットワークインターフェース情報を取得します。
    *   取得した各インターフェースについて、その名前と`Flags&FlagUp != 0`（インターフェースが「アップ」状態か）を組み合わせて、`"name:up"`または`"name:down"`形式の文字列リスト`have`を生成します。
    *   `ifaces := make(map[string]bool)`を初期化し、`netshInterfaceIPShowInterface("ipv6", ifaces)`と`netshInterfaceIPShowInterface("ipv4", ifaces)`を順に呼び出して、IPv6とIPv4両方のインターフェース情報を`ifaces`マップに統合します。
    *   `ifaces`マップから、同様に`"name:up"`または`"name:down"`形式の文字列リスト`want`を生成します。
    *   `have`と`want`の両方のリストを`sort.Strings`でソートします。
    *   最後に、`strings.Join(want, "/") != strings.Join(have, "/")`で両方のリストを比較し、Goの`net`パッケージが報告するインターフェース情報と`netsh`コマンドが報告する情報が完全に一致するかを検証します。

4.  **他のテスト関数への`isEnglishOS`チェックの追加**:
    *   `TestInterfaceAddrsWithNetsh`と`TestInterfaceHardwareAddrWithGetmac`にも、同様に`isEnglishOS(t)`チェックが追加され、英語以外のOSではテストがスキップされるようになりました。これにより、`netsh`や`getmac`コマンドの出力解析に起因する地域依存のテスト失敗を防ぎます。

これらの変更により、Windows環境におけるGoの`net`パッケージのネットワークインターフェース情報取得機能が、IPv4/IPv6のデュアルスタック環境やインターフェースの状態変化に対して、より正確かつ堅牢にテストされるようになりました。

## コアとなるコードの解説

### `isEnglishOS`関数

```go
var (
	modkernel32 = syscall.NewLazyDLL("kernel32.dll")
	procGetACP  = modkernel32.NewProc("GetACP")
)

func isEnglishOS(t *testing.T) bool {
	const windows_1252 = 1252 // ANSI Latin 1; Western European (Windows)
	r0, _, _ := syscall.Syscall(procGetACP.Addr(), 0, 0, 0, 0)
	acp := uint32(r0)
	return acp == windows_1252
}
```
この関数は、Windows APIの`GetACP`を呼び出して、現在のシステムのアクティブなコードページを取得します。`windows_1252`は英語環境で一般的なコードページであり、これと一致するかどうかでOSが英語環境であるかを判断します。これにより、`netsh`コマンドの出力が英語であることを前提としたテストの安定性を確保します。

### `netshInterfaceIPShowInterface`関数

```go
func netshInterfaceIPShowInterface(ipver string, ifaces map[string]bool) error {
	out, err := runCmd("netsh", "interface", ipver, "show", "interface", "level=verbose")
	if err != nil {
		return err
	}
	// interface information is listed like:
	//
	//Interface Local Area Connection Parameters
	//----------------------------------------------
	//IfLuid                             : ethernet_6
	//IfIndex                            : 11
	//State                              : connected
	//Metric                             : 10
	//...
	var name string
	lines := bytes.Split(out, []byte{'\r', '\n'})
	for _, line := range lines {
		if bytes.HasPrefix(line, []byte("Interface ")) && bytes.HasSuffix(line, []byte(" Parameters")) {
			f := line[len("Interface "):]
			f = f[:len(f)-len(" Parameters")]
			name = string(f)
			continue
		}
		var isup bool
		switch string(line) {
		case "State                              : connected":
			isup = true
		case "State                              : disconnected":
			isup = false
		default:
			continue
		}
		if name != "" {
			if v, ok := ifaces[name]; ok && v != isup {
				return fmt.Errorf("%s:%s isup=%v: ipv4 and ipv6 report different interface state", ipver, name, isup)
			}
			ifaces[name] = isup
			name = ""
		}
	}
	return nil
}
```
この関数は、指定されたIPバージョン（`"ipv4"`または`"ipv6"`）で`netsh interface <ipver> show interface level=verbose`コマンドを実行し、その出力からインターフェース名と状態を抽出します。抽出された情報は`ifaces`マップに格納され、IPv4とIPv6の両方からの情報を統合します。同じインターフェースで異なる状態が報告された場合はエラーを返します。

### `TestInterfacesWithNetsh`テスト関数（主要な変更部分）

```go
func TestInterfacesWithNetsh(t *testing.T) {
	if isWindowsXP(t) {
		t.Skip("Windows XP netsh command does not provide required functionality")
	}
	if !isEnglishOS(t) {
		t.Skip("English version of OS required for this test")
	}

	toString := func(name string, isup bool) string {
		if isup {
			return name + ":up"
		}
		return name + ":down"
	}

	ift, err := Interfaces()
	if err != nil {
		t.Fatal(err)
	}
	have := make([]string, 0)
	for _, ifi := range ift {
		have = append(have, toString(ifi.Name, ifi.Flags&FlagUp != 0))
	}
	sort.Strings(have)

	ifaces := make(map[string]bool)
	err = netshInterfaceIPShowInterface("ipv6", ifaces)
	if err != nil {
		t.Fatal(err)
	}
	err = netshInterfaceIPShowInterface("ipv4", ifaces)
	if err != nil {
		t.Fatal(err)
	}
	want := make([]string, 0)
	for name, isup := range ifaces {
		want = append(want, toString(name, isup))
	}
	sort.Strings(want)

	if strings.Join(want, "/") != strings.Join(have, "/") {
		t.Errorf("Interfaces mismatch:\nwant: %v\nhave: %v", want, have)
	}
}
```
このテスト関数は、Goの`net.Interfaces()`から取得したインターフェース情報（名前と状態）と、`netsh`コマンドから取得したインターフェース情報（IPv4とIPv6を統合したもの）を比較します。両方の情報源から得られたリストをソートし、文字列として結合して比較することで、Goの`net`パッケージがWindows環境で正確なインターフェース情報を提供していることを検証します。
