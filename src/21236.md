# [インデックス 21236] ファイルの概要

このコミットは、Go言語のリリースの準備を行うためのツールである `misc/makerelease/makerelease.go` ファイルに対する変更です。具体的には、Goのサブモジュール（特に `golang.org/x/` 配下のリポジトリ）の取り扱いに関する改善と、MercurialからGitへの移行期における特別な対応が加えられています。

## 変更の背景

このコミットは、Go 1.4リリースに向けた準備の一環として行われました。当時のGoプロジェクトは、バージョン管理システムをMercurial (hg) からGitへ移行している最中でした。特に、`golang.org/x/` 配下のサブモジュール（例: `golang.org/x/tools`, `golang.org/x/net` など）は、Goのコアリポジトリとは別に管理されており、これらのリポジトリもMercurialからGitへの移行が進められていました。

`makerelease` ツールは、Goのリリースバイナリを構築する際に、これらのサブモジュールも適切に取得・管理する必要があります。しかし、移行期においては、`go get` コマンドがMercurialリポジトリを正しく扱えない、あるいは意図しない動作をする可能性がありました。

このコミットの主な目的は以下の2点です。

1.  **Gitサブモジュールの適切なハンドリング**: 将来的なGitベースのサブモジュール管理に対応するため。
2.  **Go 1.4リリースにおけるMercurialサブモジュールの特別対応**: 移行期であるGo 1.4リリースにおいては、`golang.org/x/` 配下のMercurialリポジトリを `go get` を介さずに、直接 `hg clone` コマンドで取得するように変更することで、リリースの安定性を確保しました。これは一時的な措置であり、コミットメッセージにも「DO NOT import this special case into the git tree.」と明記されています。

## 前提知識の解説

*   **`misc/makerelease/makerelease.go`**: Go言語の公式リリースバイナリを構築するための内部ツールです。Goのソースコード、ツール、ドキュメントなど、リリースに必要なすべてのコンポーネントを収集し、パッケージ化する役割を担っています。
*   **`go get`**: Go言語のパッケージ管理コマンドの一つで、指定されたGoパッケージのソースコードをダウンロードし、依存関係を解決してビルド・インストールします。通常、リモートリポジトリからコードを取得する際に使用されます。
*   **`golang.org/x/` リポジトリ**: Go言語の標準ライブラリには含まれないが、Goチームによって公式にメンテナンスされている追加のパッケージ群です。これらは独立したリポジトリとして管理されており、`go get golang.org/x/tools/...` のようにして取得できます。
*   **Mercurial (hg)**: Gitと同様の分散型バージョン管理システムです。Goプロジェクトは初期にはMercurialを使用していましたが、後にGitへ移行しました。
*   **Git**: 現在主流の分散型バージョン管理システムです。
*   **サブモジュール (Sub-repositories)**: Goプロジェクトにおける「サブモジュール」は、Goのコアリポジトリとは別に管理されている `golang.org/x/` 配下の独立したリポジトリ群を指します。これらはGoのリリースプロセスにおいて、コアリポジトリと共に特定のバージョンで取得される必要があります。

## 技術的詳細

このコミットは、`makerelease.go` 内の `(b *Build) get(repoPath, revision string) error` 関数に変更を加えています。この関数は、指定されたリポジトリパスとリビジョンに基づいて、Goのソースコードを取得する役割を担っています。

変更前は、すべてのリポジトリに対して一律に `go get -d repoPath/...` を実行していました。これは一般的なGoパッケージの取得方法としては適切ですが、MercurialからGitへの移行期にある `golang.org/x/` リポジトリに対しては問題がありました。

変更後は、以下のロジックが追加されました。

1.  **`golang.org/x/` リポジトリの検出**: 取得しようとしているリポジトリパスが `golang.org/x/` で始まるかどうかを `strings.HasPrefix` でチェックします。
2.  **Mercurialからの手動チェックアウト**:
    *   もし `golang.org/x/` で始まるパスであれば、`go get` をバイパスし、Mercurialリポジトリとして特別に扱います。
    *   `os.MkdirAll` で目的のディレクトリを作成します。
    *   `repoPath` を `https://code.google.com/p/go.` で始まるMercurialリポジトリのURLに変換します（例: `golang.org/x/tools` は `https://code.google.com/p/go.tools` に）。
    *   `hg clone` コマンドを直接実行して、Mercurialリポジトリをクローンします。
    *   この特別な処理は、Go 1.4リリースのための一時的な措置であり、将来のGitベースのツリーには取り込まないことがコメントで明記されています。
3.  **その他のリポジトリ**: `golang.org/x/` で始まらないリポジトリについては、引き続き `go get -d repoPath/...` を使用して取得します。

リポジトリの取得後、指定されたリビジョンにチェックアウトする部分は、Gitリポジトリ (`.git` ディレクトリが存在する場合) とMercurialリポジトリ (`.hg` ディレクトリが存在する場合) の両方に対応するように、既存の `switch` 文がそのまま利用されます。このコミットでは、Mercurialリポジトリのクローン方法を変更しただけで、その後のリビジョンチェックアウトロジックは既存のものを活用しています。

## コアとなるコードの解説

変更の中心は `func (b *Build) get(repoPath, revision string) error` 関数です。

*   **変更前**:
    ```go
    // Fetch the packages (without building/installing).
    _, err := b.run(b.gopath, filepath.Join(b.root, "bin", "go"),
        "get", "-d", repoPath+"/...")
    if err != nil {
        return err
    }
    ```
    このコードは、すべてのリポジトリに対して `go get -d` を実行していました。`-d` フラグは、パッケージをダウンロードするだけでビルドやインストールは行わないことを意味します。

*   **変更後**:
    ```go
    dest := filepath.Join(b.gopath, "src", filepath.FromSlash(repoPath))

    if strings.HasPrefix(repoPath, "golang.org/x/") {
        // For sub-repos, fetch the old Mercurial repo; bypass "go get".
        // DO NOT import this special case into the git tree.

        if err := os.MkdirAll(filepath.Dir(dest), 0755); err != nil {
            return err
        }
        repo := strings.Replace(repoPath, "golang.org/x/", "https://code.google.com/p/go.", 1)
        if _, err := b.run(b.gopath, "hg", "clone", repo, dest); err != nil {
            return err
        }
    } else {
        // Fetch the packages (without building/installing).
        _, err := b.run(b.gopath, filepath.Join(b.root, "bin", "go"),
            "get", "-d", repoPath+"/...")
        if err != nil {
            return err
        }
    }
    ```
    1.  `dest` 変数で、リポジトリがクローンされるべきローカルパスを計算しています。
    2.  `if strings.HasPrefix(repoPath, "golang.org/x/")` で、現在のリポジトリが `golang.org/x/` 配下のサブモジュールであるかを判定しています。
    3.  もしサブモジュールであれば、以下の特別な処理を行います。
        *   `os.MkdirAll(filepath.Dir(dest), 0755)`: クローン先のディレクトリが存在しない場合に作成します。
        *   `repo := strings.Replace(repoPath, "golang.org/x/", "https://code.google.com/p/go.", 1)`: `golang.org/x/` のパスを、対応する古いMercurialリポジトリのURL (`https://code.google.com/p/go.`) に変換しています。これは、GoプロジェクトがMercurialからGitへ移行する過渡期において、`golang.org/x/` のパッケージがまだMercurialで管理されていたことを示唆しています。
        *   `b.run(b.gopath, "hg", "clone", repo, dest)`: `go get` を使わずに、直接 `hg clone` コマンドを実行してMercurialリポジトリをクローンしています。
        *   `// DO NOT import this special case into the git tree.` というコメントは、このMercurial対応が一時的なものであり、Gitへの完全移行後は不要になることを示しています。
    4.  サブモジュールでなければ、変更前と同様に `go get -d` を実行します。
    5.  `var err error` が追加されています。これは、`switch` 文のスコープ外で `err` 変数を宣言することで、`if` ブロック内で設定された `err` を `switch` 文でも利用できるようにするためです。

この変更により、`makerelease` ツールは、Go 1.4リリースにおけるMercurialベースの `golang.org/x/` サブモジュールと、一般的なGoパッケージの両方を適切に取得できるようになりました。
