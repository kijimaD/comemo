# [インデックス 2221] ファイルの概要

このコミットは、Go言語の標準ライブラリ`os`パッケージに、ファイルシステム操作に関する重要な機能を追加・改善するものです。具体的には、ディレクトリの作成・削除、ファイルパーミッションの変更、所有者の変更、ファイルサイズの変更、そしてユーザーが所属するグループ情報の取得といった機能が導入されています。また、`Getuid`などのユーザー情報取得関数におけるエラーハンドリングの変更も含まれています。

影響を受けるファイルは以下の通りです。

*   `src/lib/os/Makefile`: ビルド設定ファイル。`path.go`の追加に伴い更新。
*   `src/lib/os/file.go`: ファイル操作関連の関数を定義。`Chmod`, `Chown`, `Truncate`などの関数が追加。
*   `src/lib/os/os_test.go`: `os`パッケージのテストファイル。`Chmod`, `Chown`, `Truncate`のテストが追加。
*   `src/lib/os/path.go`: 新規追加されたファイル。`MkdirAll`と`RemoveAll`関数を定義。
*   `src/lib/os/path_test.go`: 新規追加されたファイル。`MkdirAll`と`RemoveAll`のテストを定義。
*   `src/lib/os/user.go`: ユーザー情報関連の関数を定義。`Getgroups`が追加され、`Getuid`などのエラーハンドリングが変更。
*   `src/lib/syscall/file_darwin.go`: Darwin (macOS) 環境におけるシステムコールラッパー。`Chmod`, `Fchmod`, `Chown`, `Lchown`, `Fchown`, `Truncate`, `Ftruncate`のシステムコールが追加。
*   `src/lib/syscall/file_linux.go`: Linux 環境におけるシステムコールラッパー。`Chmod`, `Fchmod`, `Chown`, `Lchown`, `Fchown`, `Truncate`, `Ftruncate`のシステムコールが追加。

## 元コミット内容

`os`パッケージに`MkdirAll`、`RemoveAll`、`Chmod`、`Chown`、`Truncate`、`Getgroups`の各機能を追加します。
また、`Getuid`などの関数はエラーを返さないように変更されます。これは、これらの関数がエラーを発生させることがないためです。

## 変更の背景

このコミットは、Go言語の初期段階において、`os`パッケージのファイルシステム操作機能を拡充し、より堅牢で使いやすいAPIを提供することを目的としています。

当時のGo言語の設計思想として、エラーハンドリングは非常に重要視されており、多くの関数がエラーを明示的に返すパターン（`if err != nil`）を採用していました。しかし、一部のシステムコール、特に`Getuid`や`Getgid`のようなユーザーID/グループIDを取得する操作は、通常、失敗することが想定されていません。これらの関数が常に成功すると仮定できる場合、エラーを返す必要はなく、APIをよりシンプルにすることができます。このコミットでは、そのような「エラーを発生させない」と判断された関数からエラー戻り値を削除し、APIの整合性と使いやすさを向上させています。

また、`MkdirAll`や`RemoveAll`といった再帰的なディレクトリ操作、`Chmod`や`Chown`といったパーミッション・所有者変更、`Truncate`といったファイルサイズ変更は、一般的なファイルシステム操作において頻繁に必要とされる機能です。これらの機能が`os`パッケージに直接提供されることで、開発者はより簡単に、かつプラットフォームに依存しない形でこれらの操作を実行できるようになります。特に、`MkdirAll`は親ディレクトリが存在しない場合に自動的に作成する機能を提供し、`RemoveAll`は指定されたパスとその配下の全てを削除する機能を提供することで、開発者の負担を大幅に軽減します。

このコミットは、Go言語の標準ライブラリが成熟し、より実用的なツールとして進化していく過程の一部と言えます。

## 前提知識の解説

### Go言語のエラーハンドリング

Go言語では、エラーは`error`インターフェースによって表現されます。関数がエラーを返す可能性がある場合、通常、最後の戻り値として`error`型を返します。呼び出し元は`if err != nil`という慣用句を使ってエラーの有無をチェックします。

*   **`*os.PathError`**: `os`パッケージのファイルシステム操作でエラーが発生した場合、多くの場合`*os.PathError`型のエラーが返されます。この構造体は、エラーが発生した操作（`Op`）、パス（`Path`）、そして基となるシステムコールエラー（`Err`）といった詳細な情報を含みます。これにより、開発者はエラーの原因をより具体的に特定できます。

### システムコールと`syscall`パッケージ

オペレーティングシステムが提供する低レベルな機能（ファイル操作、プロセス管理など）を利用するためのインターフェースを「システムコール」と呼びます。Go言語では、`syscall`パッケージがこれらのシステムコールへの直接的なアクセスを提供します。`os`パッケージの多くの関数は、内部的に`syscall`パッケージを呼び出すことで、プラットフォームに依存しない形でファイルシステム操作を実現しています。

### ファイルパーミッションと所有者

*   **パーミッション (Mode)**: ファイルやディレクトリへのアクセス権限を定義します。通常、読み取り（r）、書き込み（w）、実行（x）の3つの権限が、所有者、グループ、その他のユーザーに対して設定されます。数値（例: `0755`）で表現されることが多いです。
*   **UID (User ID)**: ユーザーを一意に識別する数値です。
*   **GID (Group ID)**: グループを一意に識別する数値です。
*   **`Chmod`**: ファイルやディレクトリのパーミッションを変更する操作です。
*   **`Chown`**: ファイルやディレクトリの所有者（UID）とグループ（GID）を変更する操作です。
*   **`Lchown`**: シンボリックリンク自体の所有者とグループを変更する操作です。`Chown`がリンクの指す先の所有者を変更するのに対し、`Lchown`はリンク自体を変更します。

### ファイルサイズ変更 (`Truncate`)

*   **`Truncate`**: ファイルのサイズを指定された長さに変更する操作です。指定された長さが現在のファイルサイズより小さい場合、ファイルは切り詰められます。大きい場合、ファイルは拡張され、新しく追加された領域は通常ヌルバイトで埋められます。

### ユーザーグループ情報 (`Getgroups`)

*   **`Getgroups`**: 現在のユーザーが所属しているすべてのグループのGID（グループID）のリストを取得する操作です。

## 技術的詳細

このコミットは、Go言語の`os`パッケージの機能拡張と、その基盤となる`syscall`パッケージの対応するシステムコールラッパーの追加を同時に行っています。

1.  **`os/path.go`の導入**: `MkdirAll`と`RemoveAll`という、再帰的なディレクトリ操作を行う高レベルな関数が`src/lib/os/path.go`という新しいファイルに分離されました。これにより、`os`パッケージ内のコードの関心事がより明確に分離され、保守性が向上しています。
    *   `MkdirAll`: 指定されたパスのディレクトリを、必要に応じて親ディレクトリもすべて作成します。既にディレクトリが存在する場合は何もしません。ファイル名と同じパスを指定された場合はエラーを返します。
    *   `RemoveAll`: 指定されたパスとその配下のすべてのファイル・ディレクトリを再帰的に削除します。削除中にエラーが発生した場合でも、可能な限り削除を試み、最初のエラーを返します。

2.  **`os/file.go`の機能拡張**: `Chmod`、`Chown`、`Truncate`といったファイル属性を変更する関数が追加されました。これらの関数は、ファイルパスを引数にとるグローバル関数と、`*File`型（開かれたファイルディスクリプタ）に対するメソッドの両方が提供されています。これにより、ファイルパスから直接操作することも、既に開いているファイルに対して操作することも可能になります。

3.  **`os/user.go`のエラーハンドリング変更と機能追加**:
    *   `Getuid`, `Getgid`, `Geteuid`, `Getegid`といったユーザー/グループID取得関数からエラー戻り値が削除されました。これは、これらのシステムコールが通常、エラーを返すことがないという設計判断に基づいています。これにより、これらの関数の呼び出しがより簡潔になります。
    *   `Getgroups`関数が追加され、ユーザーが所属するすべてのグループIDのリストを取得できるようになりました。この関数は、システムコールが返すグループIDの数を最初に問い合わせ、そのサイズでスライスを確保してから再度システムコールを呼び出して実際のグループIDを取得するという、一般的なパターンで実装されています。

4.  **`syscall`パッケージの更新**: `os`パッケージで追加された機能に対応するため、`src/lib/syscall/file_darwin.go`と`src/lib/syscall/file_linux.go`に、それぞれのOSに対応するシステムコールラッパー（例: `SYS_CHMOD`, `SYS_CHOWN`, `SYS_TRUNCATE`, `SYS_GETGROUPS`など）が追加されました。これにより、Goの`os`パッケージがこれらの低レベルなOS機能を利用できるようになります。

このコミットは、Go言語の標準ライブラリが、より包括的で実用的なファイルシステム操作APIを提供するための重要な一歩を示しています。エラーハンドリングの哲学に基づいたAPIの洗練と、一般的なユースケースに対応する高レベルな関数の導入が特徴です。

## コアとなるコードの変更箇所

### `src/lib/os/file.go`

`Chmod`, `Chown`, `Lchown`, `Truncate`の各関数とその`*File`メソッドが追加されています。これらは内部で`syscall`パッケージの対応する関数を呼び出しています。

```go
// Chmod changes the mode of the named file to mode.
// If the file is a symbolic link, it changes the uid and gid of the link's target.
func Chmod(name string, mode int) Error {
	r, e := syscall.Chmod(name, int64(mode));
	return ErrnoToError(e);
}

// Chmod changes the mode of the file to mode.
func (f *File) Chmod(mode int) Error {
	r, e := syscall.Fchmod(f.fd, int64(mode));
	return ErrnoToError(e);
}

// Chown changes the numeric uid and gid of the named file.
// If the file is a symbolic link, it changes the uid and gid of the link's target.
func Chown(name string, uid, gid int) Error {
	r, e := syscall.Chown(name, int64(uid), int64(gid));
	return ErrnoToError(e);
}

// Lchown changes the numeric uid and gid of the named file.
// If the file is a symbolic link, it changes the uid and gid of the link itself.
func Lchown(name string, uid, gid int) Error {
	r, e := syscall.Lchown(name, int64(uid), int64(gid));
	return ErrnoToError(e);
}

// Chown changes the numeric uid and gid of the named file.
func (f *File) Chown(uid, gid int) Error {
	r, e := syscall.Fchown(f.fd, int64(uid), int64(gid));
	return ErrnoToError(e);
}

// Truncate changes the size of the named file.
// If the file is a symbolic link, it changes the size of the link's target.
func Truncate(name string, size int64) Error {
	r, e := syscall.Truncate(name, size);
	return ErrnoToError(e);
}

// Truncate changes the size of the file.
// It does not change the I/O offset.
func (f *File) Truncate(size int64) Error {
	r, e := syscall.Ftruncate(f.fd, size);
	return ErrnoToError(e);
}
```

### `src/lib/os/path.go` (新規ファイル)

`MkdirAll`と`RemoveAll`の再帰的なロジックが実装されています。

```go
// MkdirAll creates a directory named path,
// along with any necessary parents, and returns nil,
// or else returns an error.
// The permission bits perm are used for all
// directories that MkdirAll creates.
// If path is already a directory, MkdirAll does nothing
// and returns nil.
func MkdirAll(path string, perm int) Error {
	// If path exists, stop with success or error.
	dir, err := os.Lstat(path);
	if err == nil {
		if dir.IsDirectory() {
			return nil;
		}
		return &PathError{path, ENOTDIR};
	}

	// Doesn't already exist; make sure parent does.
	i := len(path);
	for i > 0 && path[i-1] == '/' {	// Skip trailing slashes.
		i--;
	}

	j := i;
	for j > 0 && path[j-1] != '/' {	// Scan backward over element.
		j--;
	}

	if j > 0 {
		// Create parent
		err = MkdirAll(path[0:j-1], perm);
		if err != nil {
			return err;
		}
	}

	// Now parent exists, try to create.
	err = Mkdir(path, perm);
	if err != nil {
		// Handle arguments like "foo/." by
		// double-checking that directory doesn't exist.
		dir, err1 := os.Lstat(path);
		if err1 == nil && dir.IsDirectory() {
			return nil;
		}
		return &PathError{path, err};
	}
	return nil;
}

// RemoveAll removes path and any children it contains.
// It removes everything it can but returns the first error
// it encounters.
func RemoveAll(path string) Error {
	// Simple case: if Remove works, we're done.
	err := Remove(path);
	if err == nil {
		return nil;
	}

	// Otherwise, is this a directory we need to recurse into?
	dir, err1 := os.Lstat(path);
	if err1 != nil {
		return &PathError{path, err1};
	}
	if !dir.IsDirectory() {
		// Not a directory; return the error from Remove.
		return &PathError{path, err};
	}

	// Directory.
	fd, err := Open(path, os.O_RDONLY, 0);
	if err != nil {
		return &PathError{path, err};
	}
	defer fd.Close();

	// Remove contents & return first error.
	err = nil;
	for {
		names, err1 := fd.Readdirnames(100);
		for i, name := range names {
			err1 := RemoveAll(path + "/" + name);
			if err1 != nil && err == nil {
				err = err1;
			}
		}
		// If Readdirnames returned an error, use it.
		if err1 != nil && err == nil {
			err = &PathError{path, err1};
		}
		if len(names) == 0 {
			break;
		}
	}

	// Remove directory.
	err1 = Remove(path);
	if err1 != nil && err == nil {
		err = &PathError{path, err1};
	}
	return err;
}
```

### `src/lib/os/user.go`

`Getuid`などの関数からエラー戻り値が削除され、`Getgroups`が追加されています。

```go
// Getuid returns the numeric user id of the caller.
func Getuid() int {
	u, r2, e := syscall.Syscall(syscall.SYS_GETUID, 0, 0, 0);
	return int(u);
}

// Geteuid returns the numeric effective user id of the caller.
func Geteuid() int {
	u, r2, e := syscall.Syscall(syscall.SYS_GETEUID, 0, 0, 0);
	return int(u);
}

// Getgid returns the numeric group id of the caller.
func Getgid() int {
	g, r2, e := syscall.Syscall(syscall.SYS_GETGID, 0, 0, 0);
	return int(g);
}

// Getegid returns the numeric effective group id of the caller.
func Getegid() int {
	g, r2, e := syscall.Syscall(syscall.SYS_GETEGID, 0, 0, 0);
	return int(g);
}

// Getgroups returns a list of the numeric ids of groups that the caller belongs to.
func Getgroups() ([]int, os.Error) {
	// first call asks how many there are.
	r1, r2, err := syscall.Syscall(syscall.SYS_GETGROUPS, 0, 0, 0);
	if err != 0 {
		return nil, ErrnoToError(err);
	}

	if r1 < 0 || r1 > 1024 {	// the current max is 16; 1024 is a future-proof sanity check
		return nil, EINVAL;
	}
	a := make([]int, r1);
	if r1 > 0 {
		tmp := make([]uint32, r1);
		r1, r2, err = syscall.Syscall(syscall.SYS_GETGROUPS, r1, int64(uintptr(unsafe.Pointer(&tmp[0]))), 0);
		if err != 0 {
			return nil, ErrnoToError(err);
		}
		for i := 0; i < len(a); i++ {
			a[i] = int(tmp[i]);
		}
	}
	return a[0:r1], nil;
}
```

## コアとなるコードの解説

### `os/path.go` の `MkdirAll` と `RemoveAll`

*   **`MkdirAll(path string, perm int) Error`**:
    *   この関数は、指定された`path`にディレクトリを作成します。もし途中の親ディレクトリが存在しない場合、それらも再帰的に作成します。
    *   まず`os.Lstat(path)`でパスの情報を取得し、既にディレクトリが存在するか、あるいはファイルが存在するかをチェックします。
    *   ディレクトリが存在する場合は成功とみなし`nil`を返します。ファイルが存在する場合は`ENOTDIR`エラーを返します。
    *   パスが存在しない場合、パスを逆方向に辿り、親ディレクトリのパスを抽出します。そして、その親ディレクトリに対して再帰的に`MkdirAll`を呼び出します。
    *   親ディレクトリが作成された後、最後に`Mkdir(path, perm)`を呼び出して目的のディレクトリを作成します。
    *   エラーが発生した場合、`*PathError`を返して詳細な情報を提供します。

*   **`RemoveAll(path string) Error`**:
    *   この関数は、指定された`path`にあるファイルまたはディレクトリを、その内容すべてを含めて再帰的に削除します。
    *   まず`Remove(path)`を試みます。これが成功すれば、単一のファイルまたは空のディレクトリであったため、処理は完了です。
    *   `Remove`が失敗した場合、`os.Lstat(path)`でパスがディレクトリであるかを確認します。ファイルであれば`Remove`のエラーをそのまま返します。
    *   ディレクトリの場合、`Open`でディレクトリを開き、`Readdirnames`でその内容（ファイルやサブディレクトリの名前）を読み取ります。
    *   読み取った各エントリに対して再帰的に`RemoveAll`を呼び出し、内容を削除していきます。
    *   内容の削除が完了した後、最後に`Remove(path)`を呼び出して空になったディレクトリ自体を削除します。
    *   削除中に発生した最初のエラーを記録し、最終的にそのエラーを返します。これにより、部分的に削除が成功した場合でも、何らかの問題があったことを呼び出し元に通知できます。

### `os/file.go` の `Chmod`, `Chown`, `Truncate`

これらの関数は、ファイルやディレクトリの属性を変更するためのものです。
*   **`Chmod(name string, mode int) Error`**: 指定された`name`のファイルまたはディレクトリのパーミッションを`mode`に変更します。
*   **`*File.Chmod(mode int) Error`**: 開いているファイルディスクリプタ`f`のパーミッションを`mode`に変更します。
*   **`Chown(name string, uid, gid int) Error`**: 指定された`name`のファイルまたはディレクトリの所有者（`uid`）とグループ（`gid`）を変更します。
*   **`Lchown(name string, uid, gid int) Error`**: `Chown`と似ていますが、`name`がシンボリックリンクの場合、リンク自体ではなくリンクが指す先のファイル/ディレクトリの所有者を変更します。
*   **`*File.Chown(uid, gid int) Error`**: 開いているファイルディスクリプタ`f`の所有者とグループを変更します。
*   **`Truncate(name string, size int64) Error`**: 指定された`name`のファイルのサイズを`size`バイトに変更します。
*   **`*File.Truncate(size int64) Error`**: 開いているファイルディスクリプタ`f`のファイルのサイズを`size`バイトに変更します。

これらの関数はすべて、内部で対応する`syscall`関数を呼び出し、その結果を`ErrnoToError`でGoのエラー型に変換して返します。

### `os/user.go` の `Getuid` と `Getgroups`

*   **`Getuid() int`**:
    *   この関数は、現在のプロセスの実効ユーザーID（UID）を返します。
    *   以前はエラーを返していましたが、このコミットでエラー戻り値が削除されました。これは、`SYS_GETUID`システムコールが通常、失敗することがないため、エラーハンドリングのオーバーヘッドを減らし、APIを簡潔にするための設計判断です。
*   **`Getgroups() ([]int, os.Error)`**:
    *   この関数は、現在のユーザーが所属しているすべてのグループのGID（グループID）のリストを返します。
    *   まず、`syscall.SYS_GETGROUPS`を引数0で呼び出し、ユーザーが所属するグループの総数を取得します。
    *   その数に基づいて`[]int`スライスを`make`で作成します。
    *   次に、再度`syscall.SYS_GETGROUPS`を呼び出し、作成したスライスに実際のグループIDを格納します。
    *   システムコールがエラーを返した場合、`ErrnoToError`でGoのエラー型に変換して返します。

これらの変更により、Goの`os`パッケージは、より包括的で、かつGoのエラーハンドリング哲学に沿った形でファイルシステムとユーザー情報へのアクセスを提供できるようになりました。
