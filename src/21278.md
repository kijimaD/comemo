## 変更の背景

このコミットの主な背景は、Goプロジェクトが公式のバージョン管理システムとしてMercurialからGitへの移行を進めていたことです。2014年頃は、分散型バージョン管理システムとしてGitが業界標準となりつつあり、GitHubのようなプラットフォームの普及も相まって、多くのオープンソースプロジェクトがGitへ移行していました。Goプロジェクトもこの流れに乗り、ソースコードの取得や管理においてGitを推奨するようになりました。

この変更は、Goのソースコードをビルドして開発環境を構築するユーザーにとって、より現代的で一般的なツールセットを使用できるようにするためのものです。Mercurialの知識がなくてもGoの開発に参加しやすくなるという利点があります。

## 前提知識の解説

*   **バージョン管理システム (VCS)**: ソフトウェア開発において、ソースコードやその他のファイルの変更履歴を管理するためのシステムです。これにより、過去のバージョンに戻したり、複数の開発者による変更を統合したりすることが容易になります。
*   **Mercurial (Hg)**: 分散型バージョン管理システムの一つで、Pythonで書かれています。Goプロジェクトは初期にMercurialを使用していました。コマンドは`hg`で始まります。
*   **Git**: 現在最も広く使われている分散型バージョン管理システムです。Linuxカーネルの開発のためにLinus Torvaldsによって開発されました。コマンドは`git`で始まります。GitHubやGitLabなどのプラットフォームで利用されています。
*   **`go get`コマンド**: Go言語のパッケージ管理ツールの一部で、リモートリポジトリからGoのパッケージをダウンロードしてインストールするために使用されます。このコマンドは、内部的に適切なバージョン管理システム（GitやMercurialなど）を呼び出してリポジトリをクローンします。
*   **`all.bash`**: Goのソースツリーに含まれるシェルスクリプトで、Goのツールチェイン全体をビルドするために使用されます。Goのコンパイラ、標準ライブラリ、その他のツールが含まれます。

## 技術的詳細

このコミットは、主にGoの公式ドキュメントファイルである`doc/contribute.html`と`doc/install-source.html`の内容を更新しています。

1.  **`doc/contribute.html`の変更**:
    *   Goへの貢献方法を説明するドキュメントです。
    *   以前は、Goをソースからインストールしていることを前提とし、具体的なMercurialコマンド（`git clone https://go.googlesource.com/go`や`cd go/src`、`./all.bash`）を直接記載していました。
    *   今回の変更で、これらの具体的なコマンドの記載を削除し、代わりに「インストール手順」へのリンク（`/doc/install/source`）を参照するように変更されました。これは、インストール手順が別のドキュメントに集約され、一元的に管理されるようになったことを示しています。

2.  **`doc/install-source.html`の変更**:
    *   Goをソースからインストールするための詳細な手順を説明するドキュメントです。
    *   **MercurialからGitへの移行**:
        *   `Install Mercurial, if needed`の見出しが`Install Git, if needed`に変更されました。
        *   Mercurial (`hg`) のインストール手順やMercurial特有のCA証明書に関する説明が削除され、Git (`git`) のインストール手順へのリンク（`http://git-scm.com/downloads`）に置き換えられました。
        *   リポジトリのクローンコマンドが`hg clone -u release https://code.google.com/p/go`から`git clone https://go.googlesource.com/go`に変更されました。
        *   リリースタグのチェックアウト方法が`hg update default`から`git checkout go1.4`（例として`go1.4`タグを使用）に変更され、開発ブランチへの切り替えも`hg update default`から`git checkout master`に変更されました。
        *   `go get`コマンドがMercurialを必要とすることを示す記述が、Gitを必要とすることを示す記述に更新されました。
    *   **イシュートラッカーのURL更新**:
        *   バグ報告に使用するイシュートラッカーのURLが`//code.google.com/p/go/issues/list`から`//golang.org/issue/new`に更新されました。これは、GoプロジェクトのイシュートラッカーがGoogle CodeからGo独自のインフラに移行したことを示唆しています。
    *   **リリース更新手順の変更**:
        *   既存のソースツリーを最新リリースに更新する手順において、Mercurialコマンド（`hg pull`、`hg update release`）がGitコマンド（`git fetch`、`git checkout <tag>`）に置き換えられました。

これらの変更は、Goプロジェクトがバージョン管理システムをMercurialからGitへ完全に移行し、それに伴いドキュメントも最新の状態に保つためのものです。

## コアとなるコードの解説

このコミットのコアとなる変更は、Goのソースコードを扱う際に使用するバージョン管理システムをMercurialからGitへ切り替えるためのドキュメントの更新です。

*   **Mercurialコマンドの削除とGitコマンドへの置き換え**:
    *   `hg clone`が`git clone`に、`hg update`が`git checkout`にそれぞれ置き換えられています。これは、GoのソースコードリポジトリがMercurialからGitに移行したことを直接的に反映しています。
    *   Mercurial特有の複雑な設定（CA証明書など）に関する説明が削除され、Gitのシンプルなインストール手順へのリンクが提供されています。これにより、新規ユーザーがGoのソースコードを扱う際の障壁が低減されます。
*   **ドキュメントの構造化**:
    *   `doc/contribute.html`から具体的なインストールコマンドが削除され、`doc/install-source.html`への参照に置き換えられたことで、ドキュメントの役割分担が明確になり、情報の重複が避けられています。
*   **イシュートラッカーのURL更新**:
    *   イシュートラッカーのURLが更新されたことは、Goプロジェクトのインフラストラクチャが進化し、より統合されたGo独自のプラットフォームに移行していることを示しています。

これらの変更は、Goプロジェクトがより広範な開発者コミュニティにとってアクセスしやすく、現代的な開発ワークフローに適合するように進化していることを示しています。
