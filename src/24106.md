# [インデックス 24106] ファイルの概要

このコミットは、Go言語の標準ライブラリ`net`パッケージにおけるIPアドレスの識別ロジックのバグを修正するものです。具体的には、リンクローカルアドレスとグローバルユニキャストアドレスの誤認識を解消し、特にIPv4-mapped IPv6アドレスとIPv4ブロードキャストアドレスの扱いを改善しています。

## コミット

net: fix misidentification of link-local, global unicast IP addresses

addresses, an IPv4 broadcast address as a global unicast IP address.

## 変更の背景

Go言語の`net`パッケージは、IPアドレスの種別（ループバック、マルチキャスト、リンクローカル、グローバルユニキャストなど）を識別するためのメソッドを提供しています。しかし、このコミット以前のバージョンでは、これらの識別ロジックに不正確な点が存在していました。

具体的には、以下の2つの主要な問題が報告されていました（Go issue #11585に関連）。

1.  **IPv4-mapped IPv6アドレスの誤認識**: IPv4アドレスをIPv6アドレス形式で表現する「IPv4-mapped IPv6アドレス」が、誤ってIPv6のリンクローカルアドレスとして識別されるケースがありました。これは、IPv4アドレスの特性がIPv6の識別ロジックに不適切に適用された結果生じていました。
2.  **IPv4ブロードキャストアドレスの誤認識**: IPv4のブロードキャストアドレス（例: `255.255.255.255`や特定のネットワークブロードキャストアドレス）が、誤ってグローバルユニキャストアドレスとして識別されることがありました。グローバルユニキャストアドレスはインターネット上でルーティング可能な一意のアドレスを指すため、ブロードキャストアドレスがこれに含まれるのは不適切です。

これらの誤認識は、ネットワークアプリケーションがIPアドレスの特性に基づいて適切な処理を行う際に、予期せぬ動作やセキュリティ上の問題を引き起こす可能性がありました。特に、`IsGlobalUnicast`関数がICANN/IANAによって管理されるIPアドレスのセマンティクスを正しく適用していなかったことが、問題の根源の一つとされています。このコミットは、これらの問題を修正し、IPアドレスの正確な識別を保証することを目的としています。

## 前提知識の解説

このコミットの理解には、以下のネットワークおよびGo言語に関する知識が役立ちます。

### IPアドレスの種類と特性

*   **ユニキャストアドレス (Unicast Address)**: 1対1の通信に使用されるアドレス。特定の1つのインターフェースを識別します。
*   **マルチキャストアドレス (Multicast Address)**: 1対多の通信に使用されるアドレス。特定のグループに属する複数のインターフェースを識別します。IPv4では`224.0.0.0/4`、IPv6では`ff00::/8`の範囲が割り当てられています。
*   **ブロードキャストアドレス (Broadcast Address)**: 1対全の通信に使用されるアドレス。特定のネットワークセグメント内の全てのインターフェースにパケットを送信します。IPv4にのみ存在し、`255.255.255.255`やネットワークアドレスのホスト部が全て1のアドレスが該当します。
*   **リンクローカルアドレス (Link-Local Address)**: 単一のリンク（ネットワークセグメント）内でのみ有効なアドレス。ルーターを越えて転送されることはありません。IPv4では`169.254.0.0/16`（APIPA）、IPv6では`fe80::/10`の範囲が割り当てられています。
*   **グローバルユニキャストアドレス (Global Unicast Address)**: インターネット全体で一意であり、ルーティング可能なアドレス。インターネット上のホスト間で通信するために使用されます。
*   **ループバックアドレス (Loopback Address)**: 自身への通信に使用される特殊なアドレス。`127.0.0.1` (IPv4) や `::1` (IPv6) がこれに該当します。
*   **未指定アドレス (Unspecified Address)**: アドレスがまだ割り当てられていないことを示すアドレス。`0.0.0.0` (IPv4) や `::` (IPv6) がこれに該当します。

### IPv4-mapped IPv6アドレス

IPv4-mapped IPv6アドレスは、IPv6ネットワーク上でIPv4ノードと通信するために使用される特殊なIPv6アドレス形式です。`::ffff:0:0/96`のプレフィックスを持ち、その後にIPv4アドレスが続きます。例えば、IPv4アドレス`192.0.2.1`はIPv6-mapped IPv6アドレスでは`::ffff:192.0.2.1`と表現されます。Goの`net`パッケージでは、`IP`型がIPv4とIPv6の両方を表現できるため、このようなアドレスの識別が重要になります。

### Goの`net`パッケージと`IP`型

Goの`net`パッケージは、ネットワークI/Oのプリミティブ機能を提供します。`net.IP`型は、IPv4またはIPv6アドレスを表すバイトスライスです。この型には、アドレスの特性を判別するための様々なメソッド（例: `IsLoopback()`, `IsMulticast()`, `IsLinkLocalUnicast()`, `IsGlobalUnicast()`など）が定義されています。これらのメソッドは、IPアドレスのバイト列を検査し、そのアドレスが特定のカテゴリに属するかどうかをブール値で返します。

### ICANN/IANA

*   **ICANN (Internet Corporation for Assigned Names and Numbers)**: ドメイン名システム (DNS) の管理、IPアドレス空間の割り当て、プロトコルパラメータの管理など、インターネットのグローバルな調整を担当する非営利団体です。
*   **IANA (Internet Assigned Numbers Authority)**: ICANNの一部門であり、グローバルIPアドレス空間の割り当て、AS番号の割り当て、プロトコルポート番号の管理など、インターネットプロトコルに関連する数値識別子の調整を担当しています。

これらの組織によって定義されたIPアドレスの範囲や特性は、ネットワークスタックがアドレスを正しく識別し、ルーティングやセキュリティポリシーを適用するための基礎となります。

## 技術的詳細

このコミットは、`net`パッケージ内の`IP`型に定義されている複数の`Is*`メソッドのロジックを修正することで、IPアドレスの誤認識を解消しています。主な変更点は、IPv4アドレスとIPv6アドレスの識別ロジックをより厳密に分離し、特定のケースでの誤分類を防ぐことです。

以前の実装では、`IP`型のメソッドがIPv4アドレスを処理する際に、そのアドレスがIPv6の特定の範囲と偶然一致してしまう場合に、誤った結果を返す可能性がありました。特に、IPv4-mapped IPv6アドレスがIPv6のリンクローカルアドレスのプレフィックスと部分的に一致することが問題でした。

また、`IsGlobalUnicast`メソッドは、グローバルユニキャストアドレスではない特定のアドレス（例: ブロードキャストアドレス）を誤ってグローバルユニキャストとして報告していました。これは、グローバルユニキャストアドレスの定義から、ブロードキャストアドレスや未指定アドレス、ループバックアドレス、リンクローカルアドレスなどを除外する必要があるにもかかわらず、その除外ロジックが不完全であったためです。

この修正では、以下の点が改善されました。

*   **IPv4とIPv6の明確な分離**: `ip.To4()`メソッドを使用してIPv4アドレスとして扱える場合にのみIPv4固有のロジックを適用し、IPv6アドレスのチェックでは`len(ip) == IPv6len`という条件を追加することで、アドレスの長さに基づいた厳密な判別を行うようになりました。これにより、IPv4-mapped IPv6アドレスがIPv6のリンクローカルアドレスとして誤って識別されることを防ぎます。
*   **`IsGlobalUnicast`のロジック強化**: `IsGlobalUnicast`メソッドにおいて、IPv4ブロードキャストアドレス（`IPv4bcast`）を明示的に除外する条件が追加されました。また、アドレスの長さがIPv4またはIPv6のいずれかであることを最初に確認することで、不正な長さのIPアドレスが誤ってグローバルユニキャストとして扱われることを防ぎます。

これらの変更により、`net`パッケージはICANN/IANAの定義に基づき、より正確にIPアドレスの特性を識別できるようになりました。

## コアとなるコードの変更箇所

このコミットでは、主に`src/net/ip.go`ファイル内の`IP`型の以下のメソッドが変更されています。

*   `func (ip IP) IsUnspecified() bool`
*   `func (ip IP) IsLoopback() bool`
*   `func (ip IP) IsMulticast() bool`
*   `func (ip IP) IsLinkLocalMulticast() bool`
*   `func (ip IP) IsLinkLocalUnicast() bool`
*   `func (ip IP) IsGlobalUnicast() bool`

また、これらの変更を検証するために、`src/net/ip_test.go`ファイルに新しいテストケースが追加されています。特に、`nil` IPアドレスや、以前誤認識されていた特定のアドレスに対するテストが追加され、修正が正しく機能することを確認しています。

具体的な変更は、条件式の簡素化、IPv4とIPv6の判別ロジックの明確化、そして`IsGlobalUnicast`におけるブロードキャストアドレスの明示的な除外です。

## コアとなるコードの解説

### `IsUnspecified()`

変更前:
```go
func (ip IP) IsUnspecified() bool {
	if ip.Equal(IPv4zero) || ip.Equal(IPv6unspecified) {
		return true
	}
	return false
}
```
変更後:
```go
func (ip IP) IsUnspecified() bool {
	return ip.Equal(IPv4zero) || ip.Equal(IPv6unspecified)
}
```
`if`文を削除し、直接ブール値を返すように簡素化されました。機能的な変更はありませんが、コードの可読性が向上しています。

### `IsLoopback()`

変更前:
```go
func (ip IP) IsLoopback() bool {
	if ip4 := ip.To4(); ip4 != nil && ip4[0] == 127 {
		return true
	}
	return ip.Equal(IPv6loopback)
}
```
変更後:
```go
func (ip IP) IsLoopback() bool {
	if ip4 := ip.To4(); ip4 != nil {
		return ip4[0] == 127
	}
	return ip.Equal(IPv6loopback)
}
```
IPv4ループバックアドレスのチェックが`ip4[0] == 127`に簡素化されました。`ip4 != nil`のチェックは`if`文の条件に含まれているため、冗長な`&&`が削除されています。

### `IsMulticast()`

変更前:
```go
func (ip IP) IsMulticast() bool {
	if ip4 := ip.To4(); ip4 != nil && ip4[0]&0xf0 == 0xe0 {
		return true
	}
	return ip[0] == 0xff
}
```
変更後:
```go
func (ip IP) IsMulticast() bool {
	if ip4 := ip.To4(); ip4 != nil {
		return ip4[0]&0xf0 == 0xe0
	}
	return len(ip) == IPv6len && ip[0] == 0xff
}
```
IPv4マルチキャストアドレスのチェックが簡素化されました。IPv6マルチキャストアドレスのチェックでは、`len(ip) == IPv6len`という条件が追加され、IPアドレスの長さがIPv6の長さと一致する場合にのみIPv6のマルチキャストプレフィックス（`0xff`）をチェックするように変更されました。これにより、IPv4-mapped IPv6アドレスが誤ってIPv6マルチキャストとして扱われることを防ぎます。

### `IsLinkLocalMulticast()`

変更前:
```go
func (ip IP) IsLinkLocalMulticast() bool {
	if ip4 := ip.To4(); ip4 != nil && ip4[0] == 224 && ip4[1] == 0 && ip4[2] == 0 {
		return true
	}
	return ip[0] == 0xff && ip[1]&0x0f == 0x02
}
```
変更後:
```go
func (ip IP) IsLinkLocalMulticast() bool {
	if ip4 := ip.To4(); ip4 != nil {
		return ip4[0] == 224 && ip4[1] == 0 && ip4[2] == 0
	}
	return len(ip) == IPv6len && ip[0] == 0xff && ip[1]&0x0f == 0x02
}
```
`IsMulticast()`と同様に、IPv4リンクローカルマルチキャストアドレスのチェックが簡素化され、IPv6リンクローカルマルチキャストアドレスのチェックに`len(ip) == IPv6len`が追加されました。

### `IsLinkLocalUnicast()`

変更前:
```go
func (ip IP) IsLinkLocalUnicast() bool {
	if ip4 := ip.To4(); ip4 != nil && ip4[0] == 169 && ip4[1] == 254 {
		return true
	}
	return ip[0] == 0xfe && ip[1]&0xc0 == 0x80
}
```
変更後:
```go
func (ip IP) IsLinkLocalUnicast() bool {
	if ip4 := ip.To4(); ip4 != nil {
		return ip4[0] == 169 && ip4[1] == 254
	}
	return len(ip) == IPv6len && ip[0] == 0xfe && ip[1]&0xc0 == 0x80
}
```
`IsMulticast()`と同様に、IPv4リンクローカルユニキャストアドレスのチェックが簡素化され、IPv6リンクローカルユニキャストアドレスのチェックに`len(ip) == IPv6len`が追加されました。これにより、IPv4-mapped IPv6アドレスがIPv6リンクローカルユニキャストアドレスとして誤って識別される問題が修正されました。

### `IsGlobalUnicast()`

変更前:
```go
func (ip IP) IsGlobalUnicast() bool {
	return !ip.IsUnspecified() &&
		!ip.IsLoopback() &&
		!ip.IsMulticast() &&
		!ip.IsLinkLocalUnicast()
}
```
変更後:
```go
func (ip IP) IsGlobalUnicast() bool {
	return (len(ip) == IPv4len || len(ip) == IPv6len) &&
		!ip.Equal(IPv4bcast) &&
		!ip.IsUnspecified() &&
		!ip.IsLoopback() &&
		!ip.IsMulticast() &&
		!ip.IsLinkLocalUnicast()
}
```
このメソッドは最も重要な変更が加えられました。
1.  `(len(ip) == IPv4len || len(ip) == IPv6len)`: まず、IPアドレスの長さがIPv4またはIPv6のいずれかであることを確認します。これにより、不正な長さのIPアドレスがグローバルユニキャストとして扱われることを防ぎます。
2.  `!ip.Equal(IPv4bcast)`: IPv4ブロードキャストアドレス（`IPv4bcast`）を明示的にグローバルユニキャストアドレスから除外する条件が追加されました。これにより、以前の誤認識が修正されます。

これらの変更により、`IsGlobalUnicast`は、未指定、ループバック、マルチキャスト、リンクローカルユニキャスト、およびIPv4ブロードキャストアドレスではない、かつ有効な長さのIPアドレスのみをグローバルユニキャストとして正確に識別するようになりました。
