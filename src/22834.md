## 変更の背景

Go言語の`time`パッケージには、`time.Time`型の値を文字列にフォーマットするための`Format`メソッドが以前から存在していました。しかし、`Format`メソッドは常に新しい文字列を割り当てるため、特にループ内で頻繁に時刻のフォーマットを行うようなパフォーマンスが重視されるシナリオでは、不要なメモリ割り当てとガベージコレクションのオーバーヘッドが発生するという課題がありました。

この課題を解決し、時刻フォーマット処理の効率を向上させるために、Go 1.5で`time.AppendFormat`メソッドが導入されました。このメソッドは、既存の`[]byte`スライスにフォーマットされた時刻データを直接追加することを可能にし、新しい文字列の割り当てを回避することで、メモリ使用量と実行時間の両面で最適化を図ります。

このコミットは、`time.AppendFormat`の導入という重要な変更を、Go 1.5のリリースノートである`doc/go1.5.txt`に明記することで、ユーザーがこの新しい効率的なAPIの存在を認識し、活用できるようにすることを目的としています。

## 前提知識の解説

### `time.Time`型と時刻のフォーマット

Go言語の`time`パッケージは、日付と時刻を扱うための機能を提供します。`time.Time`型は特定の時点を表し、様々なメソッドを通じて時刻の操作や表示が可能です。

時刻のフォーマットにおいて最も基本的なメソッドは`Format`です。
`func (t Time) Format(layout string) string`
このメソッドは、指定されたレイアウト文字列に従って`time.Time`の値をフォーマットし、その結果を新しい`string`として返します。レイアウト文字列は、Go言語の特定の参照時刻（`Mon Jan 2 15:04:05 MST 2006`）を基準として、フォーマットのパターンを定義します。

例:
```go
t := time.Now()
s := t.Format("2006-01-02 15:04:05") // "YYYY-MM-DD HH:MM:SS"形式
```

### バイトスライス (`[]byte`)

Go言語におけるバイトスライスは、可変長のバイトシーケンスを表すデータ構造です。文字列（`string`）が不変であるのに対し、バイトスライスは可変であり、データの追加や変更が可能です。これは、特にI/O操作やバイナリデータの処理、あるいはメモリ割り当てを最小限に抑えたい場合に非常に有用です。

`time.AppendFormat`は、このバイトスライスに直接データを書き込むことで、文字列の再割り当てを避けるという最適化を実現しています。

## 技術的詳細

`time.AppendFormat`メソッドのシグネチャは以下の通りです。
`func (t Time) AppendFormat(b []byte, layout string) []byte`

このメソッドは、`time.Time`型のレシーバ`t`に対して呼び出され、以下の引数を取ります。
- `b []byte`: フォーマットされた時刻データを追加する先のバイトスライス。
- `layout string`: `time.Format`と同様に、時刻のフォーマットを指定するレイアウト文字列。

そして、フォーマットされた時刻データが追加された新しいバイトスライスを返します。この「新しい」バイトスライスは、元の`b`スライスの容量が足りない場合にのみ再割り当てが行われ、通常は既存のスライスの容量を再利用します。

### `Format`と`AppendFormat`の比較

| 特徴           | `time.Format`                               | `time.AppendFormat`                               |
| :------------- | :------------------------------------------ | :------------------------------------------------ |
| 戻り値         | `string`                                    | `[]byte`                                          |
| メモリ割り当て | 常に新しい`string`を割り当てる              | 既存の`[]byte`に追記。必要に応じてのみ再割り当て |
| 用途           | 単一の時刻文字列生成、簡潔なコード          | 多数の時刻フォーマット、パフォーマンス重視のシナリオ |
| 効率           | 低（頻繁な呼び出しでGC負荷増）             | 高（GC負荷低減）                                  |

`AppendFormat`は、例えばログ出力のように、大量の時刻データを特定のフォーマットで出力する必要がある場合に、非常に効果的な選択肢となります。既存のバッファを再利用することで、ヒープ割り当てを減らし、ガベージコレクションの頻度と時間を削減し、結果としてアプリケーション全体のパフォーマンスを向上させることができます。
