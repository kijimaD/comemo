# [インデックス 25590] ファイルの概要

このコミットは、Go言語のツールチェインにおけるアセンブラ (`cmd/asm`) に、MIPS64アーキテクチャ（ビッグエンディアンおよびリトルエンディアン）のサポートを追加するものです。具体的には、`GOARCH=mips64` および `GOARCH=mips64le` のターゲットに対するアセンブリコードの処理能力を導入します。これにより、GoプログラムをMIPS64ベースのシステム向けにクロスコンパイルできるようになります。

## 変更の背景

Go言語は、様々なアーキテクチャへのクロスコンパイルを強力にサポートしています。このコミットが行われた2015年当時、Go 1.6のリリースに向けて、MIPS64アーキテクチャへの対応が進行していました。MIPS64は、組み込みシステムやネットワーク機器などで広く利用される64ビットRISCアーキテクチャであり、Goプログラムがこれらのプラットフォームで動作できるようにすることは、Go言語の適用範囲を広げる上で重要でした。

この変更は、GoアセンブラがMIPS64およびMIPS64le（リトルエンディアン）の命令セットとレジスタセットを正しく解釈し、アセンブルできるようにするための基盤を構築するものです。これにより、Goランタイム自体や、パフォーマンスが重要なライブラリの一部をMIPS64向けにアセンブリで記述することが可能になります。

## 前提知識の解説

### MIPS64アーキテクチャ
MIPS64は、MIPS Technologiesによって開発された64ビットのReduced Instruction Set Computer (RISC) 命令セットアーキテクチャ (ISA) です。MIPS32 ISAの拡張版であり、後方互換性を保ちつつ、64ビットのアドレッシング、64ビットの汎用レジスタ、64ビットの命令ポインタを導入しています。これにより、より大きなメモリ空間を扱え、高性能なコンピューティング要件に対応できます。

*   **レジスタ**: 32個の64ビット汎用レジスタ (R0-R31) の他、浮動小数点レジスタ (F0-F31)、特殊な目的のレジスタ (HI, LOなど) を持ちます。HI/LOレジスタは乗算や除算の結果の上位/下位ビットを格納するために使用されます。
*   **エンディアン**: MIPS64は通常ビッグエンディアンですが、MIPS64le (little-endian) バリアントも存在します。エンディアンは、複数バイトのデータをメモリに格納する際のバイト順序を指し、異なるエンディアンのシステム間でのデータ交換には注意が必要です。
*   **命令セット**: ALU命令、ロード/ストア命令、フロー制御命令など、MIPS32の命令セットに64ビット操作のための命令が追加されています。

### Goアセンブラ (`cmd/asm`)
Go言語のツールチェインに含まれるアセンブラで、Goのアセンブリ言語 (`.s`ファイル) をオブジェクトファイル (`.o`ファイル) に変換します。Goアセンブラは、Plan 9アセンブラにインスパイアされた独自の構文を持ち、基盤となるCPUアーキテクチャのネイティブアセンブリ構文とは異なります。このアセンブラは、`GOOS` (オペレーティングシステム) と `GOARCH` (アーキテクチャ) 環境変数に基づいて、様々なターゲット向けにアセンブリコードを生成できます。Goランタイムや一部の標準ライブラリでは、パフォーマンス最適化や低レベルなハードウェア操作のためにアセンブリコードが使用されています。

### `cmd/internal/obj/mips` パッケージ
Goツールチェインの内部パッケージであり、MIPSアーキテクチャ固有の命令セット、レジスタ、定数を定義しています。このパッケージは、GoコンパイラとアセンブラがMIPSターゲット向けにコードを生成する際に必要な情報を提供します。

## 技術的詳細

このコミットの主要な目的は、`cmd/asm` がMIPS64およびMIPS64leアーキテクチャのアセンブリコードを正しく処理できるようにすることです。これには以下の技術的側面が含まれます。

1.  **アーキテクチャ定義の追加**: `src/cmd/asm/internal/arch/arch.go` に、`GOARCH` が `mips64` または `mips64le` の場合にMIPS64アーキテクチャを初期化するロジックが追加されました。これには、`cmd/internal/obj/mips` パッケージの `Linkmips64` および `Linkmips64le` を `LinkArch` として設定することが含まれます。
2.  **MIPS64固有のレジスタと命令の定義**: 新しいファイル `src/cmd/asm/internal/arch/mips64.go` が追加され、MIPS64アーキテクチャに特有のジャンプ命令 (`jumpMIPS64`)、比較命令 (`IsMIPS64CMP`)、乗除算命令 (`IsMIPS64MUL`)、およびレジスタ番号付けロジック (`mipsRegisterNumber`) が定義されています。これにより、アセンブラはMIPS64の命令とレジスタを正確に認識し、処理できるようになります。
    *   `archMips64()` 関数では、MIPS64の汎用レジスタ (R0-R31)、浮動小数点レジスタ (F0-F31)、特殊レジスタ (HI, LO) などがアセンブラ内部のレジスタマップに登録されます。特に、`R30` はGoのグローバルポインタ `g` に割り当てられるため、意図しない上書きを防ぐために特別な処理が施されています。
    *   MIPS64の命令セットも `instructions` マップに追加され、`obj.ABaseMIPS64` を基準としたオフセットで管理されます。
3.  **アセンブラの汎用処理の更新**: `src/cmd/asm/internal/asm/asm.go` では、アセンブラの命令処理ロジックがMIPS64の特性に合わせて更新されています。
    *   特に、MIPS64の3オペランドジャンプ命令（例: `BEQ R1, R2, target`）や、特殊な比較・乗除算命令 (`IsMIPS64CMP`, `IsMIPS64MUL`) の処理が追加されています。これは、Goアセンブラの汎用的な命令パースロジックにMIPS64固有のルールを組み込むことを意味します。
4.  **テストの追加**: `src/cmd/asm/internal/asm/endtoend_test.go` と `src/cmd/asm/internal/asm/operand_test.go` にMIPS64向けのテストケースが追加されています。
    *   `TestMIPS64EndToEnd` は、MIPS64アセンブリコードの全体的なアセンブルが正しく行われるかを確認します。
    *   `TestMIPS64OperandParser` は、MIPS64のオペランド（レジスタ、即値、アドレスなど）が正しくパースされるかを確認するための詳細なテストケース (`mips64OperandTests`) を含んでいます。
5.  **テストデータ**: `src/cmd/asm/internal/asm/testdata/mips64.s` は、MIPS64アセンブリの様々な命令パターンを網羅したテスト用のソースファイルです。これに対応するアセンブル結果が `src/cmd/asm/internal/asm/testdata/mips64.out` に格納され、テストの期待値として使用されます。

これらの変更により、GoアセンブラはMIPS64アーキテクチャの複雑な命令セットとレジスタの特性を理解し、Go言語のクロスコンパイルターゲットとしてMIPS64を完全にサポートできるようになります。

+	switch word {

+// IsMIPS64CMP reports whether the op (as defined by an mips.A* constant) is
+// one of the CMP instructions that require special handling.
+func IsMIPS64CMP(op int) bool {
+	switch op {
+	case mips.ACMPEQF, mips.ACMPEQD, mips.ACMPGEF, mips.ACMPGED,
+		mips.ACMPGTF, mips.ACMPGTD:
+		return true
+	}
+	return false
+}
+
+// IsMIPS64MUL reports whether the op (as defined by an mips.A* constant) is
+// one of the MUL/DIV/REM instructions that require special handling.
+func IsMIPS64MUL(op int) bool {
+	switch op {
+	case mips.AMUL, mips.AMULU, mips.AMULV, mips.AMULVU,
+		mips.ADIV, mips.ADIVU, mips.ADIVV, mips.ADIVVU,
+		mips.AREM, mips.AREMU, mips.AREMV, mips.AREMVU:
+		return true
+	}
+	return false
+}
+
+func mipsRegisterNumber(name string, n int16) (int16, bool) {
+	switch name {
+	case "F":
+		if 0 <= n && n <= 31 {
+			return mips.REG_F0 + n, true
+		}
+	case "FCR":
+		if 0 <= n && n <= 31 {
+			return mips.REG_FCR0 + n, true
+		}
+	case "M":
+		if 0 <= n && n <= 31 {
+			return mips.REG_M0 + n, true
+		}
+	case "R":
+		if 0 <= n && n <= 31 {
+			return mips.REG_R0 + n, true
+		}
+	}
+	return 0, false
+}

## コアとなるコードの解説

このコミットの核となるのは、`src/cmd/asm/internal/arch/arch.go` と `src/cmd/asm/internal/arch/mips64.go` でMIPS64アーキテクチャの特性をGoアセンブラに認識させる部分です。

`arch.go` の `Set` 関数は、`GOARCH` 環境変数に基づいて適切なアーキテクチャ定義を返します。このコミットでは、`mips64` と `mips64le` のケースが追加され、それぞれ `archMips64()` を呼び出しています。`archMips64()` は、MIPS64アーキテクチャの `Arch` 構造体を構築し、その中でMIPS64のレジスタセットと命令セットを定義しています。

特に注目すべきは、`archMips64()` 内でのレジスタの初期化です。
```go
	for i := mips.REG_R0; i <= mips.REG_R31; i++ {
		register[obj.Rconv(i)] = int16(i)
	}
	// ... (floating point and other registers)
	register["HI"] = mips.REG_HI
	register["LO"] = mips.REG_LO
	// ...
	delete(register, "R30")
	register["g"] = mips.REG_R30
```
ここでは、MIPS64の汎用レジスタ (R0-R31)、浮動小数点レジスタ (F0-F31)、特殊レジスタ (HI, LO) がアセンブラ内部のレジスタマップに登録されています。`R30` はGoのランタイムでグローバルポインタ `g` として使用されるため、通常の `R30` の定義を削除し、`g` という名前で `mips.REG_R30` を登録することで、Goの慣習に合わせたレジスタ利用を可能にしています。

また、`mips64.go` で定義されている `jumpMIPS64`, `IsMIPS64CMP`, `IsMIPS64MUL` といった関数は、MIPS64の命令セットの特殊な挙動（例: ジャンプ命令の種類、比較命令や乗除算命令のオペランドの扱い）をアセンブラが理解し、適切にコードを生成するために不可欠です。

`asm.go` の変更は、これらのアーキテクチャ固有の定義を利用して、アセンブラの汎用的な命令パースロジックをMIPS64に対応させるものです。例えば、MIPS64の3オペランドジャンプ命令の処理や、特殊な比較・乗除算命令のオペランドの解釈などが追加されています。

これらのコード変更により、GoアセンブラはMIPS64およびMIPS64leのアセンブリコードを正確に解析し、Goのオブジェクトファイル形式に変換できるようになり、MIPS64ベースのシステム上でのGoプログラムの実行を可能にする重要な一歩となります。
