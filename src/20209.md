## 変更の背景

Go言語のランタイムは、初期の段階ではパフォーマンスや低レベルなシステム操作のためにC言語で書かれた部分が多く存在しました。しかし、Go言語自体が成熟し、そのコンパイラやツールチェインが進化するにつれて、C言語で書かれた部分をGo言語に置き換える動きが活発になりました。このコミットもその一環です。

タイマーは、`time.Sleep`や`time.After`、`time.NewTimer`など、Goプログラムの基本的な時間管理機能の基盤となる重要なコンポーネントです。これまでのタイマー実装がC言語であったことには、以下のような課題がありました。

1.  **保守性の問題**: C言語とGo言語が混在するコードベースは、開発者が両方の言語の知識を持つ必要があり、デバッグや機能追加が複雑になる傾向があります。
2.  **Goの機能との統合**: C言語のコードは、Goのガベージコレクション、スケジューラ、インターフェースなどの高度な機能と直接連携することが難しい場合があります。Go言語で実装することで、これらのランタイム機能とのより密接な統合が可能になります。
3.  **安全性と堅牢性**: C言語はメモリ管理を開発者が手動で行うため、バグ（メモリリーク、セグメンテーション違反など）が発生しやすいというリスクがあります。Go言語の型安全性とガベージコレクションは、これらの問題を軽減します。
4.  **パフォーマンスの最適化**: Go言語のコンパイラとランタイムは、Go言語で書かれたコードに対して高度な最適化を適用できます。C言語のコードをGoに変換することで、Goの最適化パスに乗せることができ、潜在的なパフォーマンス向上が期待できます。

このコミットは、これらの課題を解決し、Goランタイム全体の品質と開発効率を向上させることを目的としています。

## 前提知識の解説

### Goランタイム

Goランタイムは、Goプログラムの実行を管理するソフトウェア層です。これには、ガベージコレクタ、スケジューラ（ゴルーチンの管理）、メモリ割り当て、プリミティブな同期メカニズム、そしてI/O操作などが含まれます。Goプログラムは、オペレーティングシステム上で直接実行されるのではなく、このランタイム上で動作します。

### Goにおけるタイマー

Go言語の`time`パッケージは、時間に関連する機能を提供します。その中でもタイマーは、指定された時間が経過した後に一度だけ、または定期的にイベントを発生させるためのメカニズムです。

*   **`time.Sleep(d Duration)`**: 指定された期間、現在のゴルーチンをスリープさせます。
*   **`time.After(d Duration)`**: 指定された期間が経過した後に、現在の時刻を送信するチャネルを返します。
*   **`time.NewTimer(d Duration)`**: 指定された期間が経過した後に、現在の時刻を送信する`Timer`オブジェクトを返します。この`Timer`オブジェクトは、停止したりリセットしたりできます。

これらの機能は、内部的にGoランタイムのタイマー機能に依存しています。

### ヒープデータ構造（最小ヒープ）

このコミットでタイマーの管理に用いられているのは、最小ヒープ（Min-Heap）というデータ構造です。

*   **ヒープの特性**: ヒープは、ツリーベースのデータ構造で、ヒープのプロパティ（親ノードの値が子ノードの値よりも常に小さい、または大きい）を満たします。最小ヒープの場合、ルートノード（最上位の要素）は常にヒープ内の最小値を持つ要素になります。
*   **タイマー管理への適用**: タイマーを管理する上で、次に期限が来るタイマーを効率的に取得できることが重要です。最小ヒープを使用すると、各タイマーの期限（`when`）を値としてヒープに格納することで、常にルートノードに最も早く期限が来るタイマーが配置されます。これにより、`O(1)`の時間で次のタイマーを取得でき、タイマーの追加（`addtimer`）や削除（`deltimer`）も`O(log N)`の時間で行うことができます（Nはタイマーの数）。
*   **`siftup`と`siftdown`**: ヒープのプロパティを維持するために使用される操作です。
    *   `siftup`（または`heapify-up`）: 新しい要素がヒープに追加された際、その要素を適切な位置まで上に移動させます。
    *   `siftdown`（または`heapify-down`）: ルート要素が削除された後、新しいルート要素が適切な位置まで下に移動させます。

### CgoとGo/C間の相互作用

Go言語は、C言語のコードを呼び出すための`cgo`というメカニズムを提供します。Goランタイムの初期バージョンでは、パフォーマンスが重要な部分や、OSとの直接的なインターフェースが必要な部分でC言語が使用されていました。しかし、C言語とGo言語の間でデータをやり取りしたり、関数を呼び出したりする際には、オーバーヘッドが発生したり、メモリ管理の複雑さが増したりする可能性があります。C言語のコードをGo言語に変換することは、これらの相互作用の複雑さを減らし、ランタイムの純粋なGo化を進める上で重要なステップです。

### ゴルーチンとスケジューラ

Goランタイムのスケジューラは、多数のゴルーチン（軽量スレッド）を効率的に管理し、CPUコアに割り当てて実行します。タイマーは、特定の時間が経過した後にゴルーチンを「起こす」（実行可能状態にする）役割を担います。このコミットでは、タイマーが期限切れになった際に、関連するゴルーチンを`goready`関数を使って実行可能状態にすることで、スケジューラにそのゴルーチンを実行させるように指示します。

## コアとなるコードの解説

このコミットの最も重要な部分は、`src/pkg/runtime/time.go`に新しく追加されたコードです。

### `type timer struct`

```go
type timer struct {
	i int // heap index

	// Timer wakes up at when, and then at when+period, ... (period > 0 only)
	// each time calling f(now, arg) in the timer goroutine, so f must be
	// a well-behaved function and not block.
	when   int64
	period int64
	f      func(interface{})
	arg    interface{}
}
```
これは個々のタイマーを表す構造体です。
*   `i`: タイマーがヒープ内で現在どのインデックスに位置しているかを示します。
*   `when`: タイマーが次に期限切れになるナノ秒単位の絶対時刻です。
*   `period`: タイマーが定期的に発生する場合の期間です。`0`の場合は一度だけ発生します。
*   `f`: タイマーが期限切れになったときに呼び出される関数です。
*   `arg`: `f`に渡される引数です。

### `var timers struct`

```go
var timers struct {
	lock         lock
	gp           *g
	created      bool
	sleeping     bool
	rescheduling bool
	waitnote     note
	t            []*timer
}
```
これは、システム全体のタイマーを管理するためのグローバルな構造体です。
*   `lock`: タイマーヒープへのアクセスを保護するためのミューテックスです。
*   `gp`: タイマー処理ゴルーチン（`timerproc`）へのポインタです。
*   `created`: `timerproc`ゴルーチンが既に作成されているかを示すフラグです。
*   `sleeping`: `timerproc`ゴルーチンが現在スリープ中であるかを示すフラグです。
*   `rescheduling`: `timerproc`ゴルーチンが再スケジューリング中であるかを示すフラグです。
*   `waitnote`: `timerproc`ゴルーチンがスリープから目覚めるために使用される同期プリミティブです。
*   `t`: `*timer`のポインタのスライスで、最小ヒープとして機能し、期限が近いタイマーが先頭に配置されます。

### `func timeSleep(ns int64)`

```go
func timeSleep(ns int64) {
	if ns <= 0 {
		return
	}

	t := new(timer)
	t.when = gonanotime() + ns
	t.f = goroutineReady
	t.arg = getg()
	golock(&timers.lock)
	addtimerLocked(t)
	goparkunlock(&timers.lock, "sleep")
}
```
`time.Sleep`のランタイム実装です。指定された期間（`ns`ナノ秒）だけ現在のゴルーチンをスリープさせます。新しいタイマーを作成し、その期限を設定し、期限が来たときに現在のゴルーチンを`goroutineReady`関数で実行可能状態にするように設定します。その後、`goparkunlock`を呼び出してゴルーチンをスリープさせます。

### `func addtimerLocked(t *timer)`

```go
func addtimerLocked(t *timer) {
	// when must never be negative; otherwise timerproc will overflow
	// during its delta calculation and never expire other runtime·timers.
	if t.when < 0 {
		t.when = 1<<63 - 1
	}
	t.i = len(timers.t)
	timers.t = append(timers.t, t)
	siftupTimer(t.i)
	if t.i == 0 {
		// siftup moved to top: new earliest deadline.
		if timers.sleeping {
			timers.sleeping = false
			gonotewakeup(&timers.waitnote)
		}
		if timers.rescheduling {
			timers.rescheduling = false
			goready(timers.gp)
		}
	}
	if !timers.created {
		timers.created = true
		go timerproc()
	}
}
```
タイマーをヒープに追加し、必要に応じて`timerproc`ゴルーチンを起動または起こします。新しいタイマーがヒープの最上位（最も早い期限）に来た場合、スリープ中の`timerproc`を起こして、新しい期限を考慮するようにします。

### `func deltimer(t *timer) bool`

```go
func deltimer(t *timer) bool {
	// Dereference t so that any panic happens before the lock is held.
	// Discard result, because t might be moving in the heap.
	_ = t.i

	golock(&timers.lock)
	// t may not be registered anymore and may have
	// a bogus i (typically 0, if generated by Go).
	// Verify it before proceeding.
	i := t.i
	last := len(timers.t) - 1
	if i < 0 || i > last || timers.t[i] != t {
		gounlock(&timers.lock)
		return false
	}
	if i != last {
		timers.t[i] = timers.t[last]
		timers.t[i].i = i
	}
	timers.t[last] = nil
	timers.t = timers.t[:last]
	if i != last {
		siftupTimer(i)
		siftdownTimer(i)
	}
	gounlock(&timers.lock)
	return true
}
```
タイマーをヒープから削除します。削除されたタイマーがヒープの最上位にあった場合でも、`timerproc`は自動的に次の最も早いタイマーを処理するため、特別な通知は不要です。

### `func timerproc()`

```go
func timerproc() {
	timers.gp = getg()
	timers.gp.issystem = 1
	for {
		golock(&timers.lock)
		timers.sleeping = false
		now := gonanotime()
		delta := int64(-1)
		for {
			if len(timers.t) == 0 {
				delta = -1
				break
			}
			t := timers.t[0]
			delta = t.when - now
			if delta > 0 {
				break // Next timer is in the future
			}
			// Timer has expired
			if t.period > 0 {
				// Periodic timer: adjust next fire time and re-heapify
				t.when += t.period * (1 + -delta/t.period)
				siftdownTimer(0)
			} else {
				// One-shot timer: remove from heap
				last := len(timers.t) - 1
				if last > 0 {
					timers.t[0] = timers.t[last]
					timers.t[0].i = 0
				}
				timers.t[last] = nil
				timers.t = timers.t[:last]
				if last > 0 {
					siftdownTimer(0)
				}
				t.i = -1 // mark as removed
			}
			f := t.f
			arg := t.arg
			gounlock(&timers.lock)
			if raceenabled {
				racerelease(unsafe.Pointer(t))
			}
			f(arg) // Execute timer function
			golock(&timers.lock)
		}
		if delta < 0 {
			// No timers left - put goroutine to sleep.
			timers.rescheduling = true
			timers.gp.isbackground = 1
			goparkunlock(&timers.lock, "timer goroutine (idle)")
			timers.gp.isbackground = 0
			continue
		}
		// At least one timer pending. Sleep until then.
		timers.sleeping = true
		gonoteclear(&timers.waitnote)
		gounlock(&timers.lock)
		gonotetsleepg(&timers.waitnote, delta)
	}
}
```
この関数は、すべてのタイマーイベントを処理する専用のゴルーチンで実行されます。
*   無限ループで実行され、タイマーヒープの最上位にあるタイマーの期限をチェックします。
*   期限が過ぎたタイマーがあれば、そのタイマーの関数`f`を実行します。
*   定期的なタイマー（`period > 0`）の場合は、次の期限を計算してヒープを再調整します。
*   一度限りのタイマー（`period == 0`）の場合は、ヒープから削除します。
*   処理すべきタイマーがない場合、または次のタイマーまで時間がある場合は、`gonotetsleepg`を使って指定された期間スリープします。これにより、CPUリソースを無駄に消費することなく、効率的に次のイベントを待機します。

### `func siftupTimer(i int)` と `func siftdownTimer(i int)`

```go
func siftupTimer(i int) {
	t := timers.t
	when := t[i].when
	tmp := t[i]
	for i > 0 {
		p := (i - 1) / 4 // parent
		if when >= t[p].when {
			break
		}
		t[i] = t[p]
		t[i].i = i
		t[p] = tmp
		t[p].i = p
		i = p
	}
}

func siftdownTimer(i int) {
	t := timers.t
	n := len(t)
	when := t[i].when
	tmp := t[i]
	for {
		c := i*4 + 1 // left child
		c3 := c + 2  // mid child
		if c >= n {
			break
		}
		w := t[c].when
		if c+1 < n && t[c+1].when < w {
			w = t[c+1].when
			c++
		}
		if c3 < n {
			w3 := t[c3].when
			if c3+1 < n && t[c3+1].when < w3 {
				w3 = t[c3+1].when
				c3++
			}
			if w3 < w {
				w = w3
				c = c3
			}
		}
		if w >= when {
			break
		}
		t[i] = t[c]
		t[i].i = i
		t[c] = tmp
		t[c].i = c
		i = c
	}
}
```
これらは、タイマーヒープのプロパティを維持するための補助関数です。
*   `siftupTimer`: 新しいタイマーが追加されたり、既存のタイマーの期限が早まったりした場合に、そのタイマーをヒープの適切な位置まで「持ち上げる」ために使用されます。
*   `siftdownTimer`: タイマーが削除されたり、定期的なタイマーの次の期限が更新されたりした場合に、ヒープのルート要素を適切な位置まで「沈める」ために使用されます。

これらのGo言語による実装は、C言語のコードを置き換えることで、Goランタイムの内部構造をより一貫性のあるものにし、Go開発者にとって理解しやすく、保守しやすいものにしています。

## 前提知識の解説

### Goランタイム

Goランタイムは、Goプログラムの実行を管理するソフトウェア層です。これには、ガベージコレクタ、スケジューラ（ゴルーチンの管理）、メモリ割り当て、プリミティブな同期メカニズム、そしてI/O操作などが含まれます。Goプログラムは、オペレーティングシステム上で直接実行されるのではなく、このランタイム上で動作します。

### Goにおけるタイマー

Go言語の`time`パッケージは、時間に関連する機能を提供します。その中でもタイマーは、指定された時間が経過した後に一度だけ、または定期的にイベントを発生させるためのメカニズムです。

*   **`time.Sleep(d Duration)`**: 指定された期間、現在のゴルーチンをスリープさせます。
*   **`time.After(d Duration)`**: 指定された期間が経過した後に、現在の時刻を送信するチャネルを返します。
*   **`time.NewTimer(d Duration)`**: 指定された期間が経過した後に、現在の時刻を送信する`Timer`オブジェクトを返します。この`Timer`オブジェクトは、停止したりリセットしたりできます。

これらの機能は、内部的にGoランタイムのタイマー機能に依存しています。

### ヒープデータ構造（最小ヒープ）

このコミットでタイマーの管理に用いられているのは、最小ヒープ（Min-Heap）というデータ構造です。

*   **ヒープの特性**: ヒープは、ツリーベースのデータ構造で、ヒープのプロパティ（親ノードの値が子ノードの値よりも常に小さい、または大きい）を満たします。最小ヒープの場合、ルートノード（最上位の要素）は常にヒープ内の最小値を持つ要素になります。
*   **タイマー管理への適用**: タイマーを管理する上で、次に期限が来るタイマーを効率的に取得できることが重要です。最小ヒープを使用すると、各タイマーの期限（`when`）を値としてヒープに格納することで、常にルートノードに最も早く期限が来るタイマーが配置されます。これにより、`O(1)`の時間で次のタイマーを取得でき、タイマーの追加（`addtimer`）や削除（`deltimer`）も`O(log N)`の時間で行うことができます（Nはタイマーの数）。
*   **`siftup`と`siftdown`**: ヒープのプロパティを維持するために使用される操作です。
    *   `siftup`（または`heapify-up`）: 新しい要素がヒープに追加された際、その要素を適切な位置まで上に移動させます。
    *   `siftdown`（または`heapify-down`）: ルート要素が削除された後、新しいルート要素が適切な位置まで下に移動させます。

### CgoとGo/C間の相互作用

Go言語は、C言語のコードを呼び出すための`cgo`というメカニズムを提供します。Goランタイムの初期バージョンでは、パフォーマンスが重要な部分や、OSとの直接的なインターフェースが必要な部分でC言語が使用されていました。しかし、C言語とGo言語の間でデータをやり取りしたり、関数を呼び出したりする際には、オーバーヘッドが発生したり、メモリ管理の複雑さが増したりする可能性があります。C言語のコードをGo言語に変換することは、これらの相互作用の複雑さを減らし、ランタイムの純粋なGo化を進める上で重要なステップです。

### ゴルーチンとスケジューラ

Goランタイムのスケジューラは、多数のゴルーチン（軽量スレッド）を効率的に管理し、CPUコアに割り当てて実行します。タイマーは、特定の時間が経過した後にゴルーチンを「起こす」（実行可能状態にする）役割を担います。このコミットでは、タイマーが期限切れになった際に、関連するゴルーチンを`goready`関数を使って実行可能状態にすることで、スケジューラにそのゴルーチンを実行させるように指示します。

### `func addtimerLocked(t *timer)`

```go
func addtimerLocked(t *timer) {
	// when must never be negative; otherwise timerproc will overflow
	// during its delta calculation and never expire other runtime·timers.
	if t.when < 0 {
		t.when = 1<<63 - 1
	}
	t.i = len(timers.t)
	timers.t = append(timers.t, t)
	siftupTimer(t.i)
	if t.i == 0 {
		// siftup moved to top: new earliest deadline.
		if timers.sleeping {
			timers.sleeping = false
			gonotewakeup(&timers.waitnote)
		}
		if timers.rescheduling {
			timers.rescheduling = false
			goready(timers.gp)
		}
	}
	if !timers.created {
		timers.created = true
		go timerproc()
	}
}
```

### `func deltimer(t *timer) bool`

```go
func deltimer(t *timer) bool {
	// Dereference t so that any panic happens before the lock is held.
	// Discard result, because t might be moving in the heap.
	_ = t.i

	golock(&timers.lock)
	// t may not be registered anymore and may have
	// a bogus i (typically 0, if generated by Go).
	// Verify it before proceeding.
	i := t.i
	last := len(timers.t) - 1
	if i < 0 || i > last || timers.t[i] != t {
		gounlock(&timers.lock)
		return false
	}
	if i != last {
		timers.t[i] = timers.t[last]
		timers.t[i].i = i
	}
	timers.t[last] = nil
	timers.t = timers.t[:last]
	if i != last {
		siftupTimer(i)
		siftdownTimer(i)
	}
	gounlock(&timers.lock)
	return true
}
```
タイマーをヒープから削除します。削除されたタイマーがヒープの最上位にあった場合でも、`timerproc`は自動的に次の最も早いタイマーを処理するため、特別な通知は不要です。

### `func timerproc()`

```go
func timerproc() {
	timers.gp = getg()
	timers.gp.issystem = 1
	for {
		golock(&timers.lock)
		timers.sleeping = false
		now := gonanotime()
		delta := int64(-1)
		for {
			if len(timers.t) == 0 {
				delta = -1
				break
			}
			t := timers.t[0]
			delta = t.when - now
			if delta > 0 {
				break // Next timer is in the future
			}
			// Timer has expired
			if t.period > 0 {
				// Periodic timer: adjust next fire time and re-heapify
				t.when += t.period * (1 + -delta/t.period)
				siftdownTimer(0)
			} else {
				// One-shot timer: remove from heap
				last := len(timers.t) - 1
				if last > 0 {
					timers.t[0] = timers.t[last]
					timers.t[0].i = 0
				}
				timers.t[last] = nil
				timers.t = timers.t[:last]
				if last > 0 {
					siftdownTimer(0)
				}
				t.i = -1 // mark as removed
			}
			f := t.f
			arg := t.arg
			gounlock(&timers.lock)
			if raceenabled {
				racerelease(unsafe.Pointer(t))
			}
			f(arg) // Execute timer function
			golock(&timers.lock)
		}
		if delta < 0 {
			// No timers left - put goroutine to sleep.
			timers.rescheduling = true
			timers.gp.isbackground = 1
			goparkunlock(&timers.lock, "timer goroutine (idle)")
			timers.gp.isbackground = 0
			continue
		}
		// At least one timer pending. Sleep until then.
		timers.sleeping = true
		gonoteclear(&timers.waitnote)
		gounlock(&timers.lock)
		gonotetsleepg(&timers.waitnote, delta)
	}
}
```
この関数は、すべてのタイマーイベントを処理する専用のゴルーチンで実行されます。
*   無限ループで実行され、タイマーヒープの最上位にあるタイマーの期限をチェックします。
*   期限が過ぎたタイマーがあれば、そのタイマーの関数`f`を実行します。
*   定期的なタイマー（`period > 0`）の場合は、次の期限を計算してヒープを再調整します。
*   一度限りのタイマー（`period == 0`）の場合は、ヒープから削除します。
*   処理すべきタイマーがない場合、または次のタイマーまで時間がある場合は、`gonotetsleepg`を使って指定された期間スリープします。これにより、CPUリソースを無駄に消費することなく、効率的に次のイベントを待機します。

### `func siftupTimer(i int)` と `func siftdownTimer(i int)`

```go
func siftupTimer(i int) {
	t := timers.t
	when := t[i].when
	tmp := t[i]
	for i > 0 {
		p := (i - 1) / 4 // parent
		if when >= t[p].when {
			break
		}
		t[i] = t[p]
		t[i].i = i
		t[p] = tmp
		t[p].i = p
		i = p
	}
}

func siftdownTimer(i int) {
	t := timers.t
	n := len(t)
	when := t[i].when
	tmp := t[i]
	for {
		c := i*4 + 1 // left child
		c3 := c + 2  // mid child
		if c >= n {
			break
		}
		w := t[c].when
		if c+1 < n && t[c+1].when < w {
			w = t[c+1].when
			c++
		}
		if c3 < n {
			w3 := t[c3].when
			if c3+1 < n && t[c3+1].when < w3 {
				w3 = t[c3+1].when
				c3++
			}
			if w3 < w {
				w = w3
				c = c3
			}
		}
		if w >= when {
			break
		}
		t[i] = t[c]
		t[i].i = i
		t[c] = tmp
		t[c].i = c
		i = c
	}
}
```
これらは、タイマーヒープのプロパティを維持するための補助関数です。
*   `siftupTimer`: 新しいタイマーが追加されたり、既存のタイマーの期限が早まったりした場合に、そのタイマーをヒープの適切な位置まで「持ち上げる」ために使用されます。
*   `siftdownTimer`: タイマーが削除されたり、定期的なタイマーの次の期限が更新されたりした場合に、ヒープのルート要素を適切な位置まで「沈める」ために使用されます。

これらのGo言語による実装は、C言語のコードを置き換えることで、Goランタイムの内部構造をより一貫性のあるものにし、Go開発者にとって理解しやすく、保守しやすいものにしています。
