# [インデックス 21258] ファイルの概要

このコミットは、Go言語プロジェクトのChrome拡張機能である`gophertool`内の`gopher.js`ファイルを更新するものです。`gopher.js`は、ユーザーが入力したGo関連のID（Issue番号、Code Review ID、コミットハッシュなど）に基づいて、適切なURLを生成するJavaScriptファイルです。このツールは、Goプロジェクトの各種リソースへの迅速なアクセスを支援することを目的としています。

## コミット

`misc/chrome/gophertool`ディレクトリにある`gopher.js`ファイルにおいて、参照先のURLを`code.google.com`から新しいホスト（`github.com`および`golang.org`）へ更新する変更です。これは、Goプロジェクトのインフラストラクチャ移行に伴う対応です。

## 変更の背景

このコミットの背景には、Go言語プロジェクトの主要な開発インフラストラクチャの移行があります。2014年、Googleは長年オープンソースプロジェクトのホスティングサービスを提供してきた「Google Code」の閉鎖を発表しました。これに伴い、GoプロジェクトもそのIssueトラッカー、ソースコードリポジトリ、およびコードレビューシステムを新しいプラットフォームへ移行する必要が生じました。

具体的には、以下の移行が行われました。
*   **Issueトラッカー**: Google CodeのIssueトラッカーからGitHub Issuesへ。
*   **ソースコードリポジトリ**: Google CodeのMercurialリポジトリからGitベースの`go.googlesource.com`（GitHubミラーも含む）へ。
*   **コードレビュー**: `codereview.appspot.com`（Rietveldベース）からGerritベースの`go-review.googlesource.com`（`golang.org/cl`としてアクセス可能）へ。

このコミットは、これらのインフラストラクチャの変更に対応し、`gophertool` Chrome拡張機能が引き続きGoプロジェクトの正しいリソースを参照できるようにするためのものです。

## 前提知識の解説

### Google Code

Google Codeは、Googleが提供していたオープンソースプロジェクトのホスティングサービスです。バージョン管理システム（SVN、Git、Mercurial）、Issueトラッカー、Wikiなどを提供し、多くのオープンソースプロジェクトに利用されていました。しかし、GitHubなどの台頭により利用が減少し、2015年に閉鎖されました。

### Goプロジェクトのインフラストラクチャ移行

Goプロジェクトは、その初期からGoogle Codeを主要な開発プラットフォームとして利用していました。しかし、Google Codeの閉鎖決定と、より現代的な開発ワークフローへの適応のため、2014年後半に大規模なインフラストラクチャ移行を実施しました。この移行により、GoプロジェクトはGitHubをIssueトラッカーとして、Gerritをコードレビューシステムとして、そしてGitをバージョン管理システムとして採用しました。`golang.org/cl/`はGerritのコードレビューへのショートリンクであり、`golang.org/change/`は特定のコミットハッシュへのショートリンクとして機能します。

### Chrome拡張機能

Chrome拡張機能は、Google Chromeブラウザの機能を拡張するための小さなソフトウェアプログラムです。JavaScript、HTML、CSSなどのWeb技術を使用して開発され、ブラウザのUIに統合されたり、バックグラウンドで動作したりすることで、ユーザーのブラウジング体験を向上させます。`gophertool`は、Go開発者がGoプロジェクトのIssueやコードレビューに素早くアクセスできるように設計されたChrome拡張機能です。

### URLの正規化とリダイレクト

Webアプリケーションでは、リソースへのアクセスを容易にするために、短縮URLや正規化されたURLがよく使用されます。`golang.org/cl/`や`golang.org/change/`のようなURLは、Goプロジェクトの特定のコードレビューやコミットへのアクセスを簡素化するためのものです。これらは通常、内部的にGerritやGitリポジトリのより複雑なURLにリダイレクトされます。このコミットでは、リダイレクトのレイテンシを避けるために、直接新しい正規URLを使用するよう変更されています。

## 技術的詳細

このコミットは、`misc/chrome/gophertool/gopher.js`ファイル内のJavaScriptコードを変更しています。このファイルは、ユーザーが入力した文字列を解析し、それがGoのIssue番号、コードレビューID、またはコミットハッシュであるかを判断し、それに応じた適切なURLを生成するロジックを含んでいます。

変更の核心は、Goプロジェクトのインフラストラクチャ移行に伴い、参照先のドメインとパスが変更されたことです。

1.  **Issue番号のURL変更**:
    *   旧: `http://code.google.com/p/go/issues/detail?id=`
    *   新: `https://github.com/golang/go/issues/`
    *   これは、GoのIssueトラッカーがGoogle CodeからGitHub Issuesへ移行したことを反映しています。コメントで「We could use the golang.org/cl/ handler here, but avoid some redirect latency and go right there, since one is easy.」とあるように、`golang.org/cl/`のようなリダイレクトを介さずに、直接GitHub IssuesのURLにリンクすることで、パフォーマンスの最適化を図っています。

2.  **コードレビューIDのURL変更**:
    *   旧: `http://codereview.appspot.com/`
    *   新: `https://golang.org/cl/`
    *   これは、GoのコードレビューシステムがRietveldベースの`codereview.appspot.com`からGerritベースの`go-review.googlesource.com`（`golang.org/cl/`でアクセス可能）へ移行したことを反映しています。

3.  **コミットハッシュのURL変更**:
    *   旧: `http://code.google.com/p/go/source/detail?r=`
    *   新: `https://golang.org/change/`
    *   これは、GoのソースコードリポジトリがGoogle CodeからGitベースのシステムへ移行し、特定のコミットへの参照方法が`golang.org/change/`という正規URLになったことを反映しています。

これらの変更により、`gophertool`はGoプロジェクトの最新のインフラストラクチャに対応し、ユーザーが常に正しいリソースにアクセスできるようになります。

## コアとなるコードの解説

上記のdiffは、`gopher.js`ファイル内の`urlForInput`関数におけるURL生成ロジックの変更を示しています。

*   **Issue番号の処理 (`if (t < 150000)`)**:
    *   元のコードでは、Issue番号（`t`）が150000未満の場合、`http://code.google.com/p/go/issues/detail?id=`にIssue番号を付加してGoogle CodeのIssueページへのURLを生成していました。
    *   変更後、このURLは`https://github.com/golang/go/issues/`にIssue番号を付加する形に変わりました。これは、GoプロジェクトのIssueトラッカーがGitHubへ移行したためです。コメントで示されているように、`golang.org/cl/`のようなリダイレクトを介さず、直接GitHubのURLを指定することで、リダイレクトによる遅延を避ける意図があります。

*   **コードレビューIDの処理 (`return "http://codereview.appspot.com/" + t + "/";` の行)**:
    *   元のコードでは、数値がIssue番号の範囲外の場合（つまりコードレビューIDと判断される場合）、`http://codereview.appspot.com/`にIDを付加してRietveldベースのコードレビューページへのURLを生成していました。
    *   変更後、このURLは`https://golang.org/cl/`にIDを付加する形に変わりました。これは、GoのコードレビューシステムがGerritベースの`golang.org/cl/`に移行したためです。

*   **コミットハッシュの処理 (`if (match)`)**:
    *   元のコードでは、正規表現`commitRE`にマッチする文字列（コミットハッシュ）が入力された場合、`http://code.google.com/p/go/source/detail?r=`にハッシュを付加してGoogle Codeのソースコード詳細ページへのURLを生成していました。
    *   変更後、このURLは`https://golang.org/change/`にハッシュを付加する形に変わりました。これは、GoのソースコードリポジトリがGitベースのシステムに移行し、コミットへの参照が`golang.org/change/`という正規URLになったためです。

*   **コメントの削除**:
    *   `// TODO: prefer localhost:6060 to golang.org if localhost:6060 is responding.`というコメントが削除されています。これは、ローカルのgodocサーバーへの参照に関するもので、今回のURL移行とは直接関係ないため、整理されたものと考えられます。

これらの変更は、Goプロジェクトのインフラストラクチャの進化に合わせた、`gophertool`の機能維持のための重要な更新です。
