このコミットは、Go言語の公式ドキュメントの一部である `doc/go1.4.html` ファイルに対する変更です。`go1.4.html` は、Go 1.4のリリースノートとして機能し、このバージョンで導入された新機能、改善点、および重要な変更点についてユーザーに情報を提供することを目的としています。リリースノートは、Goユーザーが新しいバージョンにアップグレードする際に、互換性の問題や新しい機能の利用方法を理解するための重要なリソースです。

## 変更の背景

このコミットの背景は、Go 1.4のリリースノート (`doc/go1.4.html`) に含まれていた「TODO」コメントの削除です。元のリリースノートには、Go 1.4がSWIG 3.0.3を必要とすること、そしてコミット作成時点ではSWIG 3.0.3がまだリリースされていないが、Go 1.4のリリース日までにリリースされることが期待されている、という旨の記述がありました。この記述の最後に「TODO」というコメントが付加されていました。

「TODO」コメントは、通常、将来的に対応が必要なタスクや、一時的な情報であることを示すためにコードやドキュメントに挿入されます。この場合、SWIG 3.0.3のリリース状況を確認し、その情報が確定した時点でドキュメントを更新するというタスクを示していました。

このコミットは、おそらくGo 1.4のリリースが近づくか、あるいはSWIG 3.0.3が実際にリリースされたことにより、この「TODO」が示すタスクが完了したため、不要になったコメントを削除し、ドキュメントを最終的な状態に近づけるためのクリーンアップ作業として行われました。これにより、リリースノートはより正確で、一時的な情報を含まないものとなります。

## 前提知識の解説

### Go言語 (Golang)

Goは、Googleによって開発されたオープンソースのプログラミング言語です。静的型付け、コンパイル型、並行処理に強い特徴を持ち、シンプルさと効率性を重視しています。システムプログラミング、Webサービス、ネットワークツールなど、幅広い分野で利用されています。Goは定期的に新しいバージョンがリリースされ、それぞれのバージョンでパフォーマンスの向上、新機能の追加、バグ修正などが行われます。

### Goリリースノート

Goの各メジャーリリース（例: Go 1.4, Go 1.5など）には、そのバージョンで導入された変更点をまとめたリリースノートが提供されます。これらのリリースノートは、Goの公式ウェブサイトで公開され、開発者が新しいバージョンへの移行を計画する際に参照する重要なドキュメントです。変更点には、言語仕様の変更、標準ライブラリの更新、ツールチェーンの改善、ランタイムの変更などが含まれます。

### SWIG (Simplified Wrapper and Interface Generator)

SWIGは、C/C++で書かれたプログラムやライブラリを、Python, Java, C#, Ruby, Goなど、様々なスクリプト言語や高水準言語から呼び出すためのインターフェースコードを自動生成するツールです。異なる言語間で相互運用性（FFI: Foreign Function Interface）を実現するために広く利用されています。Go言語においても、既存のC/C++ライブラリをGoプログラムから利用する際にSWIGが用いられることがあります。SWIGは、C/C++のヘッダーファイルから、ターゲット言語のバインディングコードを生成します。

### TODOコメント

プログラミングやドキュメンテーションにおいて、「TODO」は「To Do」（やるべきこと）の略で、将来的に対応が必要なタスクや、未完成な部分、一時的な解決策などを示すために挿入されるマーカーです。これらは通常、コードレビューやプロジェクト管理の際に、特定の箇所がまだ作業中であることや、後で修正・改善が必要であることを示すために使われます。ドキュメントにおけるTODOは、情報が確定していない、あるいは更新が必要な箇所を示すために使われることがあります。

## 技術的詳細

このコミットは、`doc/go1.4.html` ファイル内のSWIGに関するセクションのテキストを修正しています。具体的には、SWIG 3.0.3のリリース状況に関する一時的な情報と「TODO」コメントを削除し、より簡潔で確定的な記述に置き換えています。

元の記述は以下の通りでした：
```html
Due to the runtime changes in this release, Go 1.4 will require SWIG 3.0.3.
At time of writing that has not yet been released, but we expect it to be by
Go 1.4's release date.
TODO
```
この記述は、Go 1.4のランタイム変更によりSWIG 3.0.3が必要となるが、執筆時点では未リリースであり、Go 1.4のリリース日までにリリースされる見込みであること、そしてその情報が一時的であるため「TODO」が付いていることを示していました。

変更後の記述は以下の通りです：
```html
Due to runtime changes in this release, Go 1.4 requires SWIG 3.0.3.
```
この変更により、「At time of writing that has not yet been released, but we expect it to be by Go 1.4's release date. TODO」という部分が削除されました。これは、Go 1.4のリリースが近づくか、あるいはSWIG 3.0.3が実際にリリースされたため、SWIG 3.0.3がGo 1.4で必要であるという情報が確定し、もはや一時的な情報ではなくなったことを意味します。ドキュメントのクリーンアップと情報の正確性の向上を目的とした、典型的なドキュメント更新作業です。

-   `-` で始まる行は削除された行です。
-   `+` で始まる行は追加された行です。

このdiffからわかるように、以下の3行が削除されました：
1.  `At time of writing that has not yet been released, but we expect it to be by`
