## 変更の背景

Goコンパイラ（`gc`）は、Go言語のソースコードを解析し、実行可能なバイナリに変換する役割を担っています。このプロセスにおいて、ソースコードはまず抽象構文木（AST）という中間表現に変換されます。ASTは、プログラムの構造を木構造で表現したもので、コンパイラの様々なフェーズ（型チェック、最適化、コード生成など）で利用されます。

このコミット以前は、ASTのノード定義（`Node`構造体）や関連する操作（`NodeList`、ノードの種類を表す定数など）が、`go.go` や `subr.go` といった複数のファイルに分散していました。このようなコードの分散は、コードの可読性や保守性を低下させ、ASTの定義や操作を変更する際に複数のファイルを修正する必要があるという問題を引き起こしていました。

このコミットの背景には、コンパイラコードのモジュール化と整理の必要性がありました。ASTはコンパイラの中心的なデータ構造であるため、その定義と関連コードを一箇所に集約することで、コンパイラの全体的な構造をより明確にし、開発者がコードを理解しやすくすることが目的です。

## 前提知識の解説

### 抽象構文木 (AST: Abstract Syntax Tree)

ASTは、プログラミング言語のソースコードの抽象的な構文構造を木構造で表現したものです。コンパイラやインタプリタがソースコードを処理する際の最初の中間表現として広く用いられます。

-   **ノード (Node)**: ASTの各要素はノードとして表現されます。例えば、変数宣言、関数呼び出し、演算子、リテラルなどがそれぞれノードになります。
-   **木構造**: ノードは親子関係を持ち、プログラムの階層的な構造を反映します。例えば、`a + b * c` という式は、`+` 演算子ノードが親となり、その子に `a` と `*` 演算子ノードがあり、さらに `*` 演算子ノードの子に `b` と `c` がある、といった形で表現されます。
-   **抽象性**: ASTは、ソースコードの具体的な構文（括弧、セミコロンなど）の詳細を省略し、プログラムの論理的な構造に焦点を当てます。これにより、コンパイラの後のフェーズでの処理が簡素化されます。

コンパイラは、字句解析（トークン化）と構文解析（パース）を経てASTを構築します。ASTが構築された後、型チェック、最適化、コード生成といった様々な処理がASTに対して行われます。

### Goコンパイラ (`cmd/internal/gc`)

Go言語の公式コンパイラは、`gc` と呼ばれています。これはGo言語自体で書かれており、`src/cmd/compile` ディレクトリ以下にそのソースコードがあります。このコミットで変更されている `src/cmd/internal/gc` は、コンパイラの内部パッケージであり、コンパイラのコアロジックやデータ構造を定義しています。

## 技術的詳細

このコミットの主要な技術的変更は、GoコンパイラのAST表現に関するコードの移動と整理です。

1.  **`Node` 構造体の移動**:
    -   `src/cmd/internal/gc/go.go` から `Node` 構造体の定義が削除され、`src/cmd/internal/gc/syntax.go` に移動されました。
    -   `Node` 構造体は、Go言語のプログラムにおけるあらゆる構文要素（式、文、宣言など）を表現するための汎用的なデータ構造です。`Left`, `Right`, `Ninit`, `Nbody` などのフィールドは、ASTの木構造を形成するためのポインタや、初期化文、本体の文などを保持します。また、`Op` フィールドはノードの種類（例えば、加算、変数参照、関数呼び出しなど）を識別します。

2.  **`NodeList` 構造体と関連関数の移動**:
    -   `src/cmd/internal/gc/go.go` および `src/cmd/internal/gc/subr.go` から `NodeList` 構造体と、`concat`, `list1`, `list`, `listsort`, `count` といった `NodeList` を操作するヘルパー関数が削除され、`src/cmd/internal/gc/syntax.go` に移動されました。
    -   `NodeList` は、複数の `Node` を連結リストとして扱うための構造体です。コンパイラ内部では、文のリストや引数のリストなど、順序付けられたノードの集合を表現するために使用されます。
    -   移動された関数群は、これらのリストの結合、単一要素リストの作成、要素の追加、ソート、要素数のカウントといった基本的なリスト操作を提供します。

3.  **ノード操作定数 (`OXXX` など) の移動**:
    -   `src/cmd/internal/gc/go.go` に定義されていた `OXXX` で始まる多数の定数（例: `OADD`, `ONAME`, `OCALL` など）が `syntax.go` に移動されました。
    -   これらの定数は、`Node` 構造体の `Op` フィールドで使用され、ASTノードが表現する具体的な操作や構文の種類を識別します。例えば、`OADD` は加算演算、`ONAME` は名前（変数名など）、`OCALL` は関数呼び出しを表します。

4.  **`walkgen` 変数の移動**:
    -   `src/cmd/internal/gc/go.go` にあった `walkgen` というグローバル変数が `syntax.go` に移動されました。
    -   `walkgen` は、ASTの走査（トラバーサル）において、同じノードを複数回訪問するのを防ぐためのマーカーとして使用されます。これは、ASTがDAG（有向非巡回グラフ）であるため、同じノードが複数の親から参照される可能性がある場合に特に重要です。

5.  **`Array` 構造体の削除**:
    -   `src/cmd/internal/gc/go.go` から `Array` 構造体が削除されました。この構造体は、Goの配列型を表現するために使用されていた可能性がありますが、このコミットではASTの定義とは直接関係ないため、削除されたものと思われます。これは、ASTの定義をより純粋な形に保つための整理の一環である可能性があります。

これらの変更により、ASTの定義とそれに関連する基本的なユーティリティが `syntax.go` に集約され、コンパイラのコードベースがより構造化されました。

## コアとなるコードの解説

新しい `syntax.go` ファイルには、GoコンパイラのASTを構成する主要な要素が定義されています。

### `Node` 構造体

```go
type Node struct {
	Left           *Node
	Right          *Node
	Ntest          *Node
	Nincr          *Node
	Ninit          *NodeList
	Nbody          *NodeList
	Nelse          *NodeList
	List           *NodeList
	Rlist          *NodeList
	Op             uint8
	// ... (その他のフィールド)
}
```
`Node` 構造体は、ASTの基本的なビルディングブロックです。`Left`, `Right` は二項演算や条件分岐などの子ノードを指し、`Ninit`, `Nbody` などは初期化文やブロック内の文のリストを指します。`Op` フィールドは、このノードがどのような種類の構文要素（例: `OADD` は加算、`ONAME` は変数名）であるかを識別します。

### `NodeList` 構造体

```go
type NodeList struct {
	N    *Node
	Next *NodeList
	End  *NodeList
}
```
`NodeList` は、`Node` の連結リストを表現します。`N` は現在のノード、`Next` はリストの次の要素へのポインタ、`End` はリストの末尾へのポインタです。これにより、効率的なリスト操作が可能になります。

### ノード操作定数

```go
const (
	OXXX = iota
	ONAME
	ONONAME
	OTYPE
	// ... (その他の定数)
)
```
これらの定数は、`Node.Op` フィールドに割り当てられる値で、ASTノードの種類を列挙します。例えば、`OADD` は加算、`OSUB` は減算、`OCALL` は関数呼び出しなど、Go言語の様々な構文要素に対応しています。

### `walkgen` 変数

```go
var walkgen uint32
```
`walkgen` は、ASTの走査中にノードが既に訪問されたかどうかを追跡するために使用されるグローバルカウンターです。これにより、DAG構造を持つASTを効率的に走査し、無限ループや重複処理を防ぎます。

### `concat`, `list1`, `list`, `listsort`, `count` 関数

これらの関数は `NodeList` を操作するためのユーティリティです。
-   `concat(a *NodeList, b *NodeList) *NodeList`: 2つの `NodeList` を連結します。
-   `list1(n *Node) *NodeList`: 単一の `Node` からなる `NodeList` を作成します。
-   `list(l *NodeList, n *Node) *NodeList`: 既存の `NodeList` に `Node` を追加します。
-   `listsort(l **NodeList, f func(*Node, *Node) int)`: `NodeList` を指定された比較関数 `f` に基づいてソートします。マージソートアルゴリズムが使用されています。
-   `count(l *NodeList) int`: `NodeList` の要素数を返します。

これらの変更により、GoコンパイラのAST定義がより一貫性のある、独立したモジュールとして管理されるようになりました。
