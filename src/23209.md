## 変更の背景

このコミットの主な背景は、Go言語の `crypto/elliptic` パッケージにおける楕円曲線暗号 (ECC) の機能強化です。特に、ANSI X9.62標準で定義されている楕円曲線点の圧縮エンコーディングをサポートするために、`math/big` パッケージに新たな数学的機能が必要となりました。

楕円曲線上の点は通常、(x, y) 座標で表現されます。非圧縮エンコーディングではxとyの両方の座標が保存されますが、圧縮エンコーディングではx座標とy座標の符号（またはパリティ）を示す1ビットの情報のみが保存されます。これにより、データサイズを大幅に削減できます。

圧縮された点から元の (x, y) 座標を復元する際には、与えられたx座標と楕円曲線の方程式からy座標を計算する必要があります。この計算には、モジュラ平方根を求める操作が不可欠です。`ModSqrt` 関数は、このモジュラ平方根の計算を提供し、その内部でヤコビ記号 (`Jacobi`) 関数が利用されます。

この変更は、`golang.org/cl/1883` で導入されたANSI標準の圧縮エンコーディングのサポートを実現するための前提条件として行われました。これにより、GoのECC実装は、より効率的になり、他のシステムやライブラリとの相互運用性が向上しました。

## 前提知識の解説

### 楕円曲線暗号 (ECC) と点エンコーディング

楕円曲線暗号は、公開鍵暗号の一種で、有限体上の楕円曲線の数学的特性を利用します。楕円曲線上の点は、通常 (x, y) の座標ペアで表されます。

*   **非圧縮エンコーディング**: 点のx座標とy座標の両方をそのまま格納する方法です。ANSI X9.62標準では、`0x04` のプレフィックスが付けられます。
*   **圧縮エンコーディング**: 楕円曲線の方程式の性質上、x座標が与えられると、対応するy座標は通常2つしかありません（yと-y）。このため、圧縮エンコーディングではx座標と、どちらのy座標が正しいかを示す1ビット（またはプレフィックス）のみを格納します。ANSI X9.62標準では、y座標が偶数の場合は `0x02`、奇数の場合は `0x03` のプレフィックスが使用されます。これにより、データサイズが削減されます。

### ヤコビ記号 (Jacobi Symbol)

ヤコビ記号 `(a/n)` は、数論における概念で、ルジャンドル記号の一般化です。`n` が奇数である場合に定義され、`a` が `n` を法とする平方剰余であるかどうかを判定するために使用されます。

*   `(a/n) = 0`：`a` が `n` の倍数である場合。
*   `(a/n) = 1`：`a` が `n` を法とする平方剰余であり、かつ `a` が `n` の倍数でない場合。
*   `(a/n) = -1`：`a` が `n` を法とする平方非剰余である場合。

ヤコビ記号は、モジュラ平方根の存在判定や、Tonelli-Shanksアルゴリズムのようなモジュラ算術アルゴリズムの多くの部分で利用されます。

### モジュラ平方根 (Modular Square Root)

モジュラ平方根とは、与えられた整数 `x` と法 `p` に対して、`z^2 ≡ x (mod p)` となるような `z` を求める問題です。つまり、`x` の `p` を法とする平方根を計算します。

### Tonelli-Shanks アルゴリズム

Tonelli-Shanksアルゴリズムは、素数 `p` を法とする平方根を計算するための効率的なアルゴリズムです。このアルゴリズムは、`x` が `p` を法とする平方剰余である場合にのみ適用可能で、ヤコビ記号が `1` であることを確認してから実行されます。

## 技術的詳細

このコミットでは、`math/big` パッケージの `Int` 型に以下の2つの主要な関数が追加されました。

1.  **`Jacobi(x, y *Int) int`**:
    *   ヤコビ記号 `(x/y)` を計算します。
    *   `y` は奇数でなければなりません。そうでない場合、パニックが発生します。
    *   アルゴリズムは、"The Yacas Book of Algorithms" の第2章、セクション2.4に記述されている定式化に基づいています。
    *   `a` の2の因数を処理し、分子と分母を交換する際にヤコビ記号の性質を利用して `j` の符号を調整します。

2.  **`ModSqrt(x, p *Int) *Int`**:
    *   `x` の `p` を法とする平方根を計算し、結果を `z` に設定して返します。
    *   `p` は奇素数でなければなりません。
    *   `x` が `p` を法とする平方剰余でない場合（ヤコビ記号が `-1` の場合）、`z` は変更されず `nil` が返されます。
    *   `x` が `0` の場合、`0` が返されます。
    *   アルゴリズムのコア部分は、Tonelli-Shanksアルゴリズムの実装です。これは、Ezra Brownによる論文 "Square roots from 1; 24, 51, 10 to Dan Shanks" のセクション6に記述されている手順に従っています。
    *   `p-1` を `s * 2^e` の形式に分解し、`s` が奇数になるようにします。
    *   `p` を法とする非平方剰余 `n` を見つけます。
    *   メインループでは、`b` の位数 `ord_p(b)` を `2^m` となるような最小の `m` を見つけ、それに基づいて `y`, `b`, `g` を更新していきます。

テストファイル `src/math/big/int_test.go` には、これらの新しい関数の広範なテストケースが追加されています。これには、ランダムな素数と要素に対するテスト、および小さな値に対する網羅的なテストが含まれており、関数の正確性と堅牢性を保証しています。

## コアとなるコードの解説

### `Jacobi` 関数

`Jacobi` 関数は、ヤコビ記号 `(x/y)` を計算します。

```go
func Jacobi(x, y *Int) int {
	if len(y.abs) == 0 || y.abs[0]&1 == 0 {
		panic(fmt.Sprintf("big: invalid 2nd argument to Int.Jacobi: need odd integer but got %s", y))
	}

	// We use the formulation described in chapter 2, section 2.4,
	// "The Yacas Book of Algorithms":
	// http://yacas.sourceforge.net/Algo.book.pdf

	var a, b, c Int
	a.Set(x)
	b.Set(y)
	j := 1

	if b.neg {
		if a.neg {
			j = -1
		}
		b.neg = false
	}

	for {
		if b.Cmp(intOne) == 0 {
			return j
		}
		if len(a.abs) == 0 {
			return 0
		}
		a.Mod(&a, &b)
		if len(a.abs) == 0 {
			return 0
		}
		// a > 0

		// handle factors of 2 in 'a'
		s := a.abs.trailingZeroBits()
		if s&1 != 0 {
			bmod8 := b.abs[0] & 7
			if bmod8 == 3 || bmod8 == 5 {
				j = -j
			}
		}
		c.Rsh(&a, s) // a = 2^s*c

		// swap numerator and denominator
		if b.abs[0]&3 == 3 && c.abs[0]&3 == 3 {
			j = -j
		}
		a.Set(&b)
		b.Set(&c)
	}
}
```

*   まず、`y` が奇数であることを確認します。偶数の場合、パニックを発生させます。
*   `a` と `b` をそれぞれ `x` と `y` で初期化し、結果の符号 `j` を `1` に設定します。
*   `b` が負の場合、`a` の符号に応じて `j` を調整し、`b` を正に変換します。
*   ループ内で、ヤコビ記号の性質を利用して `a` と `b` を更新し、`j` の符号を調整します。
    *   `b` が `1` になれば `j` を返します。
    *   `a` が `0` になれば `0` を返します。
    *   `a` の2の因数を処理し、`b mod 8` の値に基づいて `j` の符号を反転させます。
    *   分子と分母を交換する際に、`b mod 4` と `c mod 4` の値に基づいて `j` の符号を反転させます。
*   最終的に `b` が `1` になるまでこのプロセスを繰り返します。

### `ModSqrt` 関数

`ModSqrt` 関数は、Tonelli-Shanksアルゴリズムを使用してモジュラ平方根を計算します。

```go
func (z *Int) ModSqrt(x, p *Int) *Int {
	switch Jacobi(x, p) {
	case -1:
		return nil // x is not a square mod p
	case 0:
		return z.SetInt64(0) // sqrt(0) mod p = 0
	case 1:
		break
	}
	if x.neg || x.Cmp(p) >= 0 { // ensure 0 <= x < p
		x = new(Int).Mod(x, p)
	}

	// Break p-1 into s*2^e such that s is odd.
	var s Int
	s.Sub(p, intOne)
	e := s.abs.trailingZeroBits()
	s.Rsh(&s, e)

	// find some non-square n
	var n Int
	n.SetInt64(2)
	for Jacobi(&n, p) != -1 {
		n.Add(&n, intOne)
	}

	// Core of the Tonelli-Shanks algorithm. Follows the description in
	// section 6 of "Square roots from 1; 24, 51, 10 to Dan Shanks" by Ezra
	// Brown:
	// https://www.maa.org/sites/default/files/pdf/upload_library/22/Polya/07468342.di020786.02p0470a.pdf
	var y, b, g, t Int
	y.Add(&s, intOne)
	y.Rsh(&y, 1)
	y.Exp(x, &y, p)  // y = x^((s+1)/2)
	b.Exp(x, &s, p)  // b = x^s
	g.Exp(&n, &s, p) // g = n^s
	r := e
	for {
		// find the least m such that ord_p(b) = 2^m
		var m uint
		t.Set(&b)
		for t.Cmp(intOne) != 0 {
			t.Mul(&t, &t).Mod(&t, p)
			m++
		}

		if m == 0 {
			return z.Set(&y)
		}

		t.SetInt64(0).SetBit(&t, int(r-m-1), 1).Exp(&g, &t, p)
		// t = g^(2^(r-m-1)) mod p
		g.Mul(&t, &t).Mod(&g, p) // g = g^(2^(r-m)) mod p
		y.Mul(&y, &t).Mod(&y, p)
		b.Mul(&b, &g).Mod(&b, p)
		r = m
	}
}
```

*   まず、`Jacobi(x, p)` を呼び出して `x` が `p` を法とする平方剰余であるかを確認します。
    *   `-1` の場合、平方根は存在しないため `nil` を返します。
    *   `0` の場合、平方根は `0` であるため `z.SetInt64(0)` を返します。
*   `p-1` を `s * 2^e` の形式に分解します。
*   `p` を法とする非平方剰余 `n` を見つけます。これは、ヤコビ記号が `-1` になる最小の整数から開始します。
*   Tonelli-Shanksアルゴリズムのコア部分を実行します。
    *   初期値 `y`, `b`, `g` を計算します。
    *   ループ内で、`b` の位数 `m` を見つけます。
    *   `m` が `0` の場合、`y` が平方根であるため `z.Set(&y)` を返します。
    *   `t` を計算し、それを使って `g`, `y`, `b` を更新し、`r` を `m` に設定して次のイテレーションに進みます。
