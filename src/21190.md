# [インデックス 21190] ファイルの概要

このコミットは、Go言語の標準ライブラリである`lib/time`パッケージにおけるタイムゾーンデータベースの更新に関するものです。具体的には、ICANN（Internet Corporation for Assigned Names and Numbers）が管理するタイムゾーンデータベースを2014jバージョンに更新しています。

## コミット

```
commit b2950a2931bd89323569c1389f780f2cd744e12c
Author: Rob Pike <r@golang.org>
Date:   Wed Dec 3 20:07:48 2014 -0800

    lib/time: update to ICANN time zone database 2014j
    
    Fixes #9189.
    
    LGTM=dsymonds
    R=golang-codereviews, dsymonds
    CC=golang-codereviews
    https://golang.org/cl/178660043
```

## GitHub上でのコミットページへのリンク

[https://github.com/golang/go/commit/b2950a2931bd89323569c1389f780f2cd744e12c](https://github.com/golang/go/commit/b2950a2931bd89323569c1389f780f2cd744e12c)

## 元コミット内容

このコミットは、Go言語の`lib/time`パッケージが使用するタイムゾーンデータベースを、ICANN/IANA Time Zone Databaseの2014jバージョンに更新するものです。これに伴い、タイムゾーン情報の更新スクリプトである`lib/time/update.bash`内のバージョン指定が変更され、新しい`zoneinfo.zip`バイナリファイルが取り込まれています。

## 変更の背景

タイムゾーン情報は、世界中の地域における夏時間（Daylight Saving Time, DST）の開始・終了、標準時の変更、政治的な決定によるタイムゾーン境界の変更など、様々な要因によって頻繁に更新されます。これらの変更は、正確な時刻計算やイベントスケジューリングを行うソフトウェアにとって非常に重要です。Go言語の`time`パッケージは、これらのタイムゾーン情報を内部的に保持しており、その情報源としてICANN/IANA Time Zone Database（通称 tz database または zoneinfo database）を利用しています。

このコミットは、Goの`time`パッケージが常に最新かつ正確なタイムゾーン情報を提供できるように、定期的なメンテナンスの一環として行われました。`Fixes #9189`という記述から、特定のバグ報告（おそらく古いタイムゾーン情報に起因する問題）に対応するための更新であったことが伺えます。

## 前提知識の解説

### ICANN/IANA Time Zone Database (tz database / zoneinfo database)

ICANN（Internet Corporation for Assigned Names and Numbers）は、インターネットのIPアドレス、ドメイン名、プロトコルパラメータなどを管理する国際的な非営営利団体です。その傘下にあるIANA（Internet Assigned Numbers Authority）は、タイムゾーンデータベースの公式な管理者でもあります。

tz databaseは、世界中のタイムゾーンルール（オフセット、夏時間の適用規則など）を網羅的に記録した公開データベースです。このデータベースは、世界中のオペレーティングシステムやプログラミング言語（Go、Java、Pythonなど）で広く利用されており、正確な時刻と日付の計算を可能にしています。データベースは、政治的、地理的、歴史的な変更に応じて定期的に更新されます。

### Go言語の`time`パッケージとタイムゾーン

Go言語の標準ライブラリである`time`パッケージは、日付と時刻の操作、フォーマット、タイムゾーン変換などの機能を提供します。Goの`time`パッケージは、内部的にtz databaseの情報を利用してタイムゾーンの解決を行っています。

Goの実行環境では、通常、システムにインストールされているtz databaseファイル（`/usr/share/zoneinfo`など）を参照します。しかし、クロスプラットフォームでの一貫性や、システムにtz databaseが存在しない環境（例: 静的リンクされたバイナリ、一部の組み込みシステム）での動作を保証するため、Goのバイナリには`zoneinfo.zip`という形でtz databaseのサブセットが埋め込まれることがあります。この`zoneinfo.zip`は、`lib/time`ディレクトリに配置され、ビルド時にGoのバイナリに組み込まれます。

## 技術的詳細

このコミットの技術的な詳細は、主に以下の2点に集約されます。

1.  **`lib/time/update.bash`スクリプトの役割**:
    `update.bash`スクリプトは、ICANN/IANAの公式FTPサイトから最新のtz databaseソースコードとデータをダウンロードし、Goの`time`パッケージが利用できる形式に変換・更新するための自動化スクリプトです。このスクリプトは、Goのタイムゾーン情報を最新の状態に保つための重要なツールです。

2.  **`zoneinfo.zip`バイナリファイルの更新**:
    `zoneinfo.zip`は、Goの`time`パッケージが内部的に使用するタイムゾーン情報の圧縮ファイルです。このファイルは、`update.bash`スクリプトによって生成または更新されます。このコミットでは、`update.bash`スクリプトが参照するバージョンが`2014d`から`2014j`に変更された結果、新しいタイムゾーン情報が反映された`zoneinfo.zip`が生成され、そのバイナリ内容が更新されています。コミットログに`Bin 358933 -> 360713 bytes`とあるように、ファイルサイズが増加しており、これは新しいタイムゾーンデータが追加されたことを示しています。

## コアとなるコードの変更箇所

```diff
diff --git a/lib/time/update.bash b/lib/time/update.bash
index 8e1662afde..caa8450fa6 100755
--- a/lib/time/update.bash
+++ b/lib/time/update.bash
@@ -7,8 +7,8 @@
 # downloaded from the ICANN/IANA distribution.
 
 # Versions to use.
-CODE=2014d
-DATA=2014d
+CODE=2014j
+DATA=2014j
 
 set -e
 rm -rf work
diff --git a/lib/time/zoneinfo.zip b/lib/time/zoneinfo.zip
index e0d3afe074..425d7c98fa 100644
Binary files a/lib/time/zoneinfo.zip and b/lib/time/zoneinfo.zip differ
```

## コアとなるコードの解説

このコミットにおける主要なコード変更は、`lib/time/update.bash`スクリプト内の以下の2行です。

```bash
-CODE=2014d
-DATA=2014d
+CODE=2014j
+DATA=2014j
```

-   `CODE`変数: これは、tz databaseのソースコード（ルール定義など）のバージョンを指定します。
-   `DATA`変数: これは、tz databaseのデータファイル（タイムゾーン定義など）のバージョンを指定します。

これらの変数を`2014d`から`2014j`に変更することで、`update.bash`スクリプトが次に実行された際に、ICANN/IANAのFTPサイトから2014jバージョンのタイムゾーンデータがダウンロードされ、それに基づいて`zoneinfo.zip`が再生成されるようになります。

`zoneinfo.zip`の変更は、バイナリファイルの差分として表示されており、具体的な内容の差分は示されていませんが、これは新しいタイムゾーンデータがこのファイルに反映されたことを意味します。
